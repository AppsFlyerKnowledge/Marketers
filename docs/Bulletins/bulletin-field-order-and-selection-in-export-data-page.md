In the [Export Data page](https://support.appsflyer.com/hc/articles/360008613838), you can now set the report column sequence in addition to the existing field selection option.

### Effective date
June 16, 2021

### Where
Export Data page

### What's changing
Use the **Report (CSV) field order** setting to specify the sequence of columns in reports.

| Setting | Field selection allowed | Remarks |
| --- | --- | --- |
| Default | Yes | - Selected fields are ordered according to an AppsFlyer template.<br>- Going forward, the sequence will be preserved. Future fields will be appended to the right of the existing fields. |
| Alphabetical (A-Z) | Yes | Selected fields are ordered alphabetically (ascending). |
| Alphabetical (Z-A) | Yes | Selected fields are ordered in reverse order alphabetically (descending). |
| Legacy | No | - Fields are ordered according to the sequence of columns in reports prepared using the previous version of the export data page.<br>- Field selection is fixed and can't be changed.<br>- There is some variation of the reports per field depending on the actual report. |

The [field order spreadsheet](https://docs.google.com/spreadsheets/d/e/2PACX-1vRGYcMOgC5yy_82yn3DWd3ucLE5KtuTA72eJfvu5KVB9fFH_mYwzM3KpR_inQOnat-KzgVjuuvXa6_g/pub?output=xlsx) contains both a Default and Legacy sheet containing the relevant field order list.

### Procedure

<Image src="https://files.readme.io/d81e8d0494cbf3a8ee959990200da10889bb7a581c6018711b7163d8fedcd2d8-360020954138.png" alt="FeldOrder.png" />

**To change the field order:**
1. In the **Report fields** tab, select a **Report (CSV) field order** option.
2. If required, change the selected fields by selecting or clear selecting the necessary fields.
3. Click **Download**.
