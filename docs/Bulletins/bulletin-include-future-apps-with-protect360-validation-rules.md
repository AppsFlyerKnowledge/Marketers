---
title: "Bulletin: Include future apps with Protect360 validation rules"
excerpt: "Learn how to automatically apply Protect360 validation rules to any future apps you add to your account."
---
| | |
| --- | --- |
| **What's new** | You can now include future apps when creating validation rules. |
| **Effective date** | August, 2024 |
| **What you need to know** | - When creating a validation rule, in the **App selection** section, if you choose All apps, you have the option to check **Include future apps.** This allows any future apps to be included in this rule. |
| **Implications** | Selecting **include future apps** when creating your validation rule, allows any future apps to be included in the rule. This saves you from having to go back and modify every rule created when you have a new app. More information, including how to set it up, can be found [here](https://support.appsflyer.com/hc/articles/115004703926-Validation-Rules-for-app-owners#rule-builder). |
