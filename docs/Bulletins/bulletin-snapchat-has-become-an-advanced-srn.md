---
| | |
| --- | --- |
| **Headline** | Snapchat has become and Advanced [Self-Reporting Network (SRN)](https://support.appsflyer.com/hc/articles/360001546905-Self-reporting-networks-SRNs-) |
| **Effective Date** | September 13, 2023 |
| **Where is it changing** | The Snapchat integration page in Active Integrations |
| **Required actions** | No action is required |
| **What's changing?** | As of September 12, 2023, Snapchat has become an advanced SRN. This means:<br>- Clicks and impressions are sent to AppsFlyer and attribution without IDFA will be done probabilistically<br>- Snapchat view-through conversions are [partially restricted](https://support.appsflyer.com/hc/articles/360006868017#media-source-restrictions) in raw data reports |
