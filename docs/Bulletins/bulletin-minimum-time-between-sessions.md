---
title: "Bulletin: Minimum time between sessions"
excerpt: "This bulletin details the change in the calculation of the sessions metric in AppsFlyer, introducing a minimum time between sessions timer."
---
| **What's new** | Change in the calculation of the sessions metric |
| **Effective Date** | February 15, 2021 |
| **What's changing** | The sessions metric is calculated by counting sessions reported by the SDK in the app.<br><br>Starting on the Effective Date, after the first 5 sessions, the sessions metric is calculated taking into account a minimum time between sessions timer. This means that some sessions aren't counted as illustrated in the example that follows.<br><br>The timer has a default duration of 10 minutes and the possible values are:<br>- 1-60 minutes<br>- 1-24 hours<br><br><Image src="https://files.readme.io/12bc7191a11dda474f57055a6cf5ce6bb69b3772ad33a2a0c7bfabc51e4c07ce-360015918477.jpg" alt="MinimumTimeBetweenSessions_us-en.jpg" /><br><br>**Example: Sessions counting with a minimum time between sessions of 10 minutes.**<br><br>In this example, the sessions reporting times are stated as minutes elapsed since 00:00<br><br>\| Example \| Session reporting times \| Number of sessions counted \| Sessions disregarded \|<br>\| --- \| --- \| --- \| --- \|<br>\| A \| 0, 10, 20, 30 \| 4 \| None \|<br>\| B \| 0, 1, 9, 11 \| 2 \| 1, 9 \|<br>\| C \| 0, 10, 15, 21 \| 3 \| 15 \|<br><br>**Impact of the change**<br>- Expect a reduction in the sessions metric starting from the Effective Date in the Analytics tools and sessions raw data available to clients having Data Locker.<br>- Ad network partners, if you consume the session event via postbacks expect a reduction due to this change. |
| **What's staying the same** | Implementation of this change (using the default setting of 10 minutes) won't affect any of the following metrics:<br>- Metrics:<br>  - Daily active users (DAU)<br>  - Monthly active users (MAU)<br>  - Retention<br>  - Loyal users using the default setting of 3 app opens<br>- Re-engagement conversions<br>- Historical data (sessions) recorded before the Effective Date<br>However, going forward consider that if the Minimum time between sessions is increased to more than one hour, and users don't open the app many times a day, then some retention metrics can be impacted. This is especially true in the case of apps where users typically open the app once a day. |
| **[Optional] Setting change** | If needed, you can change the default setting of 10 minutes, to one that suits your users’ behavior and interaction style with the app.<br>**To change the minimum time between sessions duration:**<br>1. In AppsFlyer. go to **Configuration** > **App settings**.<br>2. Set **Minimum time between sessions.**<br>3. Click **Save settings.**<br><br>The change takes effect within an hour. |
