title: "Bulletin: Event, Overview, and Activity dashboards deprecation"
excerpt: "The legacy Events, Overview, and Activity dashboards are being deprecated and replaced by My Dashboards, with full deprecation taking effect on June 30, 2026."
---
The **Events**, **Overview**, and **Activity** dashboards are getting deprecated as part of the transition to **My Dashboards** as the main analytics experience. After **June 30, 2026**, these legacy dashboards will no longer be accessible. The same data is available in My Dashboards, with enhanced analytics capabilities, flexible views, custom metrics, advanced filters, and shared or private dashboards. 

## Timeline and Details

* **Effective date:** Starting **May 30, 2026**, when you open a legacy dashboard from the **Analyze** tab, a pop up with a link to the corresponding template or view in My Dashboards will appear. Starting **June 30, 2026**, the legacy **Events**, **Overview**, and **Activity** dashboards will no longer be accessible. Your data and saved views will be available in My Dashboards.
* **Who needs to do it:** All advertisers, agencies, and partners using Events, Overview, and Activity dashboards.
* **Required actions:** Start using My Dashboards before the deprecation date to make sure your analytics workflows continue without interruption.

### How to get started

1. Go to **My Dashboards** from the left navigation menu.
2. Open the relevant template or view:
   - For Events data, open the **Events** template.
   - For Overview data, open the **Performance Analysis** or **Marketing Overview** template.
   - For Activity data, open the **Activity** view.
3. Customize the view using metrics, filters, and groupings.
4. Save the configuration as a shared or private view.

## What you should know

My Dashboards provides a more flexible and customizable analytics experience than the legacy dashboards. Key capabilities include:

- **Unified data:** View user acquisition and retargeting data in one place.
- **Enhanced tables:** Use tables with up to 4 groupings and export up to 100,000 rows to CSV.
- **Dashboard-level filters:** Apply filters across dashboard widgets.
- **Shared and private views:** Share views with your team or keep personal views private.
- **Custom metrics and dimensions:** Create metrics and dimensions that support your business needs.
- **Period comparison:** Compare data to a previous period.
- **Enhanced charts:** Use event widgets, cohort widgets, combo charts, and charts with multiple metrics.
- **Conditional formatting:** Highlight important table data.
- **Metric-based sorting:** Sort table data by the metric that fits your analysis.

### How to find and add [Dashboard templates](/docs/my-dashboards#dashboard-templates)

1. In My Dashboards, from the left menu, open any dashboard.
2. On the Dashboard main page, click the arrow to the right of the Dashboard name.
3. Search for the Dashboard or browse the templates.

## Dashboard Replacements

<Tabs>
<Tab title="Events Dashboard">

To view Events data in My Dashboards:
1. Go to **My Dashboards**.
2. Open the **Events** template.

The Events template provides a comprehensive view of in-app event data and includes:
- **Events widgets:** View in-app user behavior by dimensions such as media source, geo, and date.
- **Cohort-based event analysis:** Analyze events in a cohort context.
- **Business KPIs:** Build views around revenue events and other custom key performance indicators.
- **My Dashboards capabilities:** Use filters, shared views, CSV export, custom metrics, and up to 4 table groupings.

</Tab>

<Tab title="Overview Dashboard">

To view Overview data in My Dashboards:
1. Go to **My Dashboards**.
2. Open one of the following templates:
   - **Performance Analysis**
   - **Marketing Overview**

Existing saved views from the legacy Overview dashboard are being migrated to My Dashboards automatically.

The Performance Analysis and Marketing Overview templates include My Dashboards capabilities such as enhanced tables, dashboard-level filters, shared and private views, custom metrics and dimensions, period comparison, enhanced charts, conditional formatting, and metric-based sorting.

Existing saved views from the legacy Overview dashboard are being migrated to My Dashboards. After migration is enabled for your account, saved views that haven’t been used within 60 days will be removed. Open and save any views you want to keep.

</Tab>

<Tab title="Activity Dashboard">

To view Activity data in My Dashboards:
1. Go to **My Dashboards**.
2. Open the **Activity** view.

All Activity data is available in My Dashboards. The Activity view includes:
- **Metric-based sorting:** Sort table data by a specific metric. Campaigns that exist in Activity, such as campaigns with sessions, are no longer excluded when they have no lifetime value data.
- **Active Users over time:** View Active Users across a date range without averaged calculations.
- **Side-by-side analysis:** View Activity data together with lifetime value and cohort metrics.
- **My Dashboards capabilities:** Use conditional formatting, custom metrics, period comparison, filters, and shared or private views.

</Tab>
</Tabs>

## FAQ

<Accordion title="Will I lose my data?">

No. Your data remains available in My Dashboards. The underlying data is the same. Only the analytics interface is changing.

</Accordion>

<Accordion title="What happens to my saved views from the Overview dashboard?">

Existing saved views from the legacy Overview dashboard are being migrated to My Dashboards automatically.

After migration is enabled for your account, saved views that haven’t been used within 60 days will be removed. Open and save any views you want to keep.

</Accordion>

<Accordion title="Can I access the legacy dashboards after June 30, 2026?">

No. The legacy Events, Overview, and Activity dashboards will no longer be accessible after **June 30, 2026**.

</Accordion>

<Accordion title="What can I do if I need a feature that isn’t available in My Dashboards?">

Contact your CSM or AppsFlyer Support. AppsFlyer continues to improve My Dashboards and uses customer feedback to identify gaps and prioritize improvements.

</Accordion>

See [**My Dashboards**](/docs/my-dashboards).
