> **En bref :** listes des partenaires de réseau publicitaire qui ont une intégration SKAN avec AppsFlyer, et ID Apple SKAdNewtork de réseau publicitaire.

## Partenaires AppsFlyer SKAN

Les partenaires de la liste sont intégrés à AppsFlyer et envoient les postbacks iOS SKAN à AppsFlyer.

Ces partenaires envoient à AppsFlyer les postbacks SKAN qu'ils reçoivent des appareils iOS. Is ajoutent en outre des champs supplémentaires aux postbacks qui varient selon leur hiérarchie publicitaire et leurs systèmes de reporting. Ces champs supplémentaires enrichissent les données du postback et vous aident à analyser les performances de vos campagnes SKAN.

Notez que les postbacks SKAN sont intégrés au tableau de bord général SKAN, quel que soit le statut de la fonction **Activer le partenaire** de l'onglet Intégration du partenaire.

Les champs supplémentaires disponibles sont les suivants :

* **Localisation** : transmise par le réseau publicitaire attribué d’après le code pays.
* **ID de la campagne enrichi** : cet identifiant est différent de l'ID de campagne SKAN transmis dans le postback iOS (**qui est systématiquement disponible)**.
* **Nom de la campagne enrichi** : s'affiche dans les rapports et les tableaux de bord.
* **ID d’adset enrichi** : s'affiche dans les rapports et les tableaux de bord.
* **Nom d’adset enrichi** : s'affiche dans les rapports et les tableaux de bord.
* **ID publicitaire enrichi** : s'affiche dans les rapports et les tableaux de bord.
* **Nom publicitaire enrichi** : s'affiche dans les rapports et les tableaux de bord.
* **Coût enrichi** : s'affiche dans les rapports et les tableaux de bord.
* **L'attribution post-vue (APV) prend en charge :** ce champ n'est pas enrichi par le réseau publicitaire, mais indique plutôt si l’APV est disponible dans les postbacks SKAN.
* **Re-téléchargements :** disponible dans le cas des postbacks SKAN 2.0 pour les non-SRN.  
  Tous les SRN envoient l’ensemble des données d'installation dans les postbacks SKAN. Notez que certains SRN ont décidé de ne pas distinguer les nouvelles installations des re-téléchargements, de fait, pour certains SRN, les données de re-téléchargement ne s’affichent pas dans le tableau de bord SKAN.

[Liste des réseaux SKAN](/docs/skan-integrated-partners-list#intégrations-et-champs-denrichissement-skan-srn).
