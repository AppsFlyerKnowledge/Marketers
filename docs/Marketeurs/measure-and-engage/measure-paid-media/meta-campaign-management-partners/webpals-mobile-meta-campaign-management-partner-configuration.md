> **At a glance:** Webpals mobile - a Meta campaign management partner (formerly known as Facebook Marketing Partners), one of AppsFlyer's integrated partners, is a leader in mobile user acquisition and revenue maximization with global coverage.

## Setting up Webpals mobile

**Prerequisite:** An account with the partner. If you don't have an account, contact the partner to open one before setting up the integration.

**To set up a new integration:**

1. In AppsFlyer, go to **Collaborate > Partner Integrations > Marketplace** tab.  
   (**To edit an existing integration:** Go to **Collaborate > Partner Integrations > Active integrations** tab.)
2. Select the relevant app.
3. Search for the partner and select **Integrate**.
4. In the **Integration** tab, turn on the **Activate partner** toggle.   
   **Important note:** The toggle **must stay on (active) as long as you work with the partner**. <Anchor target="_blank" href="/marketers/fr/docs/partner-activation-deactivation">Learn more</Anchor>
5. Complete the configuration using the relevant tabs, as described below.

### In-app events

1. To send in-app event postbacks to Webpals mobile—Meta campaign management partner, enter **Facebook pixel\_id** under ***In-App Events Settings***.
2. Turn on **In-app event postbacks**.
3. Set the configuration according to the guidelines <Anchor target="_blank" href="/marketers/fr/docs/meta-ads-in-app-event-mapping#mappage-des-événements-prédéfinis">here</Anchor>.
4. Click **Save**.
