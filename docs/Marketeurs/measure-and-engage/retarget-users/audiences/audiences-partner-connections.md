## À propos des connexions de partenaires

Une connexion de partenaire vous permet d'envoyer en continu vos audiences aux partenaires afin de diffuser vos campagnes personnalisées. Vous trouverez ci-dessous la liste des partenaires d'Audiences, les exigences de connexion et les ID d'utilisateur qu'ils prennent en charge.

**Pour connecter un partenaire, identifiez-le dans le tableau ci-dessous et procédez comme suit :**

* Si le tableau contient un lien vers une procédure énoncée par un partenaire, ouvrez le lien et suivez les instructions.  
  **--OU--**
* Si le tableau contient la liste des identifiants requis :
  1. Obtenez les identifiants auprès du partenaire.
  2. Suivez les instructions pour <Anchor target="_blank" href="/marketers/fr/docs/audiences-guide#create-a-new-connection">créer une nouvelle connexion de partenaire</Anchor> dans Audiences.

<div id="amazon-s3" />

<Accordion title="Amazon S3">

La création d'une intégration S3 permet à AppsFlyer d'envoyer les ID des appareils de l'audience directement à votre compartiment S3. Le fichier transmis à S3 a les caractéristiques suivantes :

* Nom de fichier : nom et date de l'audience Ex : my\_audience\_2020-06-23.csv
* Contenu : colonne unique, sans en-tête, contenant les ID des appareils
* Un nouveau fichier est écrit chaque jour. Les fichiers existants ne sont pas supprimés
* Si des audiences séparées sont envoyées, un seul fichier ZIP est écrit, il contient un fichier distinct pour chaque partenaire (split)

**Pour connecter un public à Amazon S3** :

1. Dans AppsFlyer, allez dans **Audiences** et sélectionnez une audience.
2. Cliquez sur l'onglet **Connecter**.
3. Cliquez sur **+ Nouvelle connexion**.
4. Saisissez un **nom de connexion.**
5. Sélectionnez **Amazon S3**.  
   La fenêtre **Ajouter une connexion** s'ouvre.

   ![image__9_.png](https://files.readme.io/790f8a50bf14fbb4065d9dcee05e31fa866bc73f236f439ec73f2bc833b31be6-31237653533201.png)
6. Entrez l'**ARN du rôle multicompte**, le **nom du compartiment** et le **nom de la région**.   
   **Remarque :** Il est recommandé de toujours saisir le nom de la région. Si le nom de la région n'est pas automatiquement activé par défaut sur AWS, il doit être saisi ici, faute de quoi la connexion ne pourra pas être créée. Pour trouver la région sur la page d'accueil de la console AWS, cliquez sur la liste déroulante des pays en haut à droite de la page, et les régions s'afficheront. <Image alt="region_name.jpg" src="https://files.readme.io/a3b65660a638674cbbe0da2802b4f926929d167d0b528c25c12ded6a90b0e981-31237648137489.jpg" width="355px" />
7. Enregistrez l'**ID de compte** et l'**ID externe** pour une utilisation ultérieure.
8. Dans la console **AWS ,** **allez dans IAM** > **Politiques**.
9. Cliquez sur **Créer une politique**.
10. Cliquez sur **JSON.**
11. Collez l'extrait de politique suivant dans la fenêtre JSON.  

    ```json
    {
    							"Version": "2012-10-17",
    							"Statement": [
    							{
    							"Effect": "Allow",
    							"Action": "s3:*",
    							"Resource": "arn:aws:s3:::BUCKET-NAME/*"
    							}
    							]
    }
    ```
12. Remplacez **BUCKET-NAME** par le nom du compartiment dans lequel vous souhaitez que AppsFlyer importe votre audience.

    > 📘 **Note**
    >
    > La politique doit contenir uniquement le compartiment racine, sans aucun répertoire supplémentaire dans le chemin. Par exemple, la ressource **arn:aws:s3 : ::bucket-name/directory \* n'est pas prise en charge**. Si vous avez besoin de transférer les fichiers vers un répertoire spécifique, reportez-vous à l'étape 14.


    Les actions `PutObject,` `DeleteObject` et `ListBucket` sont obligatoires pour que AppsFlyer puisse interagir correctement avec votre compartiment.
13. Cliquez sur **Vérifier la politique**.
14. Entrez un **nom de politique.**
15. Cliquez sur **Créer une politique**.
16. Dans votre console AWS, allez dans **Gestion de l'accès** > **Roles**.

    [![](https://files.readme.io/85a4a81b5ebd131b6b3a20ca6ee136a0d10556363cff2deab96397ec889db141-31237648138513.png)](https://files.readme.io/85a4a81b5ebd131b6b3a20ca6ee136a0d10556363cff2deab96397ec889db141-31237648138513.png)
17. Cliquez sur **+Créer un rôle.**
18. Sélectionnez **Un autre compte AWS** pour fournir l'accès aller-retour entre votre compte AWS et le compte AWS AppsFlyer.

    [![](https://files.readme.io/1f8db2c84d1cbde4a88fd6d7dace3eb5cb65f8fc9608b0ec568921a2b7c85759-31237653535761.png)](https://files.readme.io/1f8db2c84d1cbde4a88fd6d7dace3eb5cb65f8fc9608b0ec568921a2b7c85759-31237653535761.png)
19. Saisissez l'**ID de compte.** Il s'agit de l'identifiant de compte que vous avez déjà copié depuis le tableau de bord AppsFlyer.
20. Sélectionnez **Exiger un ID externe**. Il s'agit de l'identifiant externe que vous avez déjà copié depuis le tableau de bord AppsFlyer.
21. Lorsque vous êtes invité à sélectionner une politique parmi les politiques existantes de votre compte AWS, choisissez la politique créée précédemment.
22. Cliquez sur le nom du rôle nouvellement créé pour ouvrir sa fenêtre de propriétés.

    [![](https://files.readme.io/9b61cf2c8ec3efd9f6548e1ee6b6ca945dd1160901516f93cd16ac3544d3aade-31237648139793.png)](https://files.readme.io/9b61cf2c8ec3efd9f6548e1ee6b6ca945dd1160901516f93cd16ac3544d3aade-31237648139793.png)
23. Enregistrez l'**ARN du rôle**.
24. Dans la fenêtre d'intégration AppsFlyer S3, entrez l'ARN et le nom du compartiment dans les champs demandés

    Si vous souhaitez transférer les fichiers dans un certain dossier du compartiment, indiquez le nom du compartiment avec les dossiers associés, séparés par "/", ex. (bucketname/foldername/foldername).

    Si vous indiquez un nom de dossier qui n'existe pas encore, AppsFlyer le créera en cours d'importation.
25. Cliquez sur **Ajouter une connexion**.Une fois le processus d'intégration terminé et une audience importée, un fichier CSV avec les ID des appareils est disponible dans le bucket.

</Accordion>

>
>
> <Tabs>
> <Tab title="Android">
>
> ```java
> Map<String, Object> brazeData = new HashMap<>();
> partnerData.put("external_user_id", "some-braze-external-id-value");
> AppsFlyerLib.getInstance().setPartnerData("braze_int", brazeData);
> ```
>
> </Tab>
>
> <Tab title="iOS">
>
> ```objectivec
> NSDictionary *brazeInfo = @{
> @"external_user_id":@"some-braze-external-id-value"
> };
> [[AppsFlyerLib shared] setPartnerDataWithPartnerId:@"braze_int"
> partnerInfo:brazeInfo];
> ```
>
> </Tab>
> </Tabs>

<div id="using-the-cuid-field" />

#### AVEC LE CHAMP CUID

Il n'est pas nécessaire de configurer un paramètre dédié pour l'ID externe Braze dans le cas où :

* Vous avez configuré le SDK pour envoyer à AppsFlyer un CUID pour chaque utilisateur
* Le CUID a la même valeur que l'ID externe Braze

**Pour créer une connexion de partenaire avec Braze :**

1. Dans votre compte Braze, allez dans **Integrations > Partenaires Technologie,** puis sélectionnez AppsFlyer.
2. Dans la section **Importation de données via l'importation de cohortes**, cliquez sur **Générer une nouvelle clé** pour générer votre **clé d'importation de données**.
   * **Remarque :** Si une clé apparaît déjà, il n'est pas nécessaire d'en générer une nouvelle.
   * **Important !** Assurez-vous de travailler dans la section Importation de **données à l'aide de l'importation de cohortes** de la page (et non dans la section d'attribution de l'installation).

     ![data_import_key.png](https://files.readme.io/4d288e6696da600d0e402b86a0986b3951f2cd35efd12084aa8feaeeb526fddf-31237653537681.png)
3. Copiez la **clé d'importation de données** et le **point de terminaison REST** à utiliser pour configurer la connexion dans le tableau de bord AppsFlyer.
4. Dans AppsFlyer Audiences, allez dans l'onglet **Connexions** et cliquez sur **+ Nouvelle connexion.**
5. Sélectionnez Braze comme partenaire, puis nommez la connexion.
6. Entrez la clé d'importation des données et le point de terminaison REST que vous avez copiés dans votre compte Braze à l'étape 3. 

   ![braze_connection.png](https://files.readme.io/200d1a1bef906ea50e40b3d8113bb9fd72068b6fda25a2f70b95b4510bd992de-31237653538449.png)

8. Une fois qu'une audience AppsFlyer a été importée sur Braze, vous pouvez l'utiliser comme filtre lors de la création de segments dans Braze.

   ![cohorts_as_filter.png](https://files.readme.io/eec9e014afcb488bb7ebe31167cd5871c38207c8f4542e20ea313b7019e8b43a-31237653538961.png)

4. Saisissez un **nom de connexion.**
5. Sélectionnez **Google Ads**.

   > Si vous laissez ce champ vide, les fichiers seront ajoutés au dossier racine de votre serveur SFTP.

8. Cliquez sur ***Enregistrer***.
