| **Quoi de neuf ?** | Les templates OneLink permettent de rediriger les utilisateurs qui n'ont pas installé votre app vers des app stores Android tiers. |
| --- | --- |
| **Date d'entrée en vigueur** | 19 mai 2021 |
| **Où** | <Anchor target="_blank" href="support.appsflyer.com/docs/bulletin-onelink-redirection-to-third-party-android-app-stores">Configuration du template OneLink</Anchor> |
| **Quoi** | **Avant la modification :** les modèles OneLink ont permis aux utilisateurs qui n'ont pas installé votre app d'être redirigés vers l'app store d'Apple, Google Play ou une URL web.<br /><br />**Après la modification :**  les modèles OneLink permettent également de rediriger les utilisateurs qui n'ont pas installé votre app vers les app stores Android tiers suivants :<ul><li>Huawei AppGallery</li><li>Xiaomi Market</li><li>Store Samsung Galaxy</li><li>Oppo App Market</li><li>Vivo App Store</li></ul> |
| **Ce que vous devez savoir** | <ul><li>Pour rediriger les utilisateurs vers des app stores Android tiers, le nom de package de votre app doit être identique dans l'app Android sélectionnée dans votre modèle OneLink et dans les autres magasins.</li><li>Le nom du package APK (par exemple : com.shop.app) est utilisé pour la redirection. Assurez-vous que le nom du package APK est le même dans l'app store tiers avant de le sélectionner.</li><li>Seul le nom du package est extrait de l'app Android pour rediriger les utilisateurs. Par exemple, si le nom AppsFlyer comprend également un canal, comme com.shop.app-store, seul com.shop.app est extrait.</li><li>Si vous sélectionnez une app Android qui n'est pas dans Google Play, vous devez saisir l'URL vers laquelle les utilisateurs Android seront redirigés.</li></ul>[![](https://files.readme.io/5e9df9148e5059160401391ef857ad965d1154e1ee7516bc33804de6badc5cd9-4403341605265.png)](https://files.readme.io/5e9df9148e5059160401391ef857ad965d1154e1ee7516bc33804de6badc5cd9-4403341605265.png) |
