| **Nouveautés** | Les revenus publicitaires au niveau des impressions sont désormais disponibles via l'API AdRevenue SDK, remplaçant le connecteur SDK des revenus publicitaires. |
| --- | --- |
| **À partir de** | la version 6.15 du SDK AppsFlyer |
| **Ce que vous devez savoir** | <ul><li>Jusqu'ici, les revenus publicitaires au niveau des impressions étaient disponibles via le **connecteur** du SDK de revenus publicitaires AppsFlyer. À partir de la date d'entrée en vigueur, l'intégration se fera directement via le **SDK** AppsFlyer (sans connecteur), en utilisant l'API SDK des revenus publicitaires.</li><li>Le connecteur SDK des revenus publicitaires continuera de fonctionner avec :<ul><li>AppsFlyer Android SDK version 6.14.2 et inférieures.</li><li>AppsFlyer iOS SDK version 6.14.6 et inférieures.</li></ul></li></ul> |
| **Ce que vous devez faire** | <ul><li>Si vous souhaitez mettre à jour vers la version 6.15+ du SDK AppsFlyer et que vous utilisez actuellement le connecteur SDK des revenus publicitaires, vous devez le supprimer et intégrer l'API SDK des revenus publicitaires.</li><li>Développeur requis. Consultez les instructions de l'API du SDK de revenus publicitaires pour les développeurs <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/ad-revenue">.</Anchor></li><li>En savoir plus sur l'<Anchor target="_blank" href="/marketers/fr/docs/integrate-the-roi360-ad-revenue-sdk-api">intégration de l'API SDK des revenus publicitaires au niveau des impressions</Anchor>.</li></ul> |
