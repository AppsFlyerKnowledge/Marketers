> **At a glance:** Analyze performance and trends over time of your collaborative campaigns using visualizations and table views.

Use the measurement dashboard to view and analyze campaign performance. It contains performance KPIs, over-time trends, impressions and clicks, revenue, and other metrics.

## The measurement dashboard

<Image align="center" alt="" src="https://files.readme.io/a69a72f87bbe6290548e52dea810d774ad09618ec1540bfb00db42e62d52f382-44443401136017.png" />

The dashboard includes the following components:

<div id="a-filter-bar" />

<Accordion title="A - Measurement panel">

Select the measurement you want to view in the dashboard panel (**B**). You can view either the live dashboard or one of the historical dashboards you set up. For more information about live and historical dashboards, see <Anchor target="_blank" href="/marketers/fr/docs/data-collaboration-platform-dcp-run-and-manage-measurement#about-the-measurement-run-modes">About measurement run modes</Anchor>.

</Accordion>

<div id="h_01KJWV7PG61YPCBMG2X3NGZN96" />

<Accordion title="B - Dashboard panel">

Displays the dashboard you selected in the measurement panel (**A**). The pane enables you to edit, duplicate, re-run, and share the dashboard with your collaborators. For more information, see <Anchor target="_blank" href="/marketers/fr/docs/data-collaboration-platform-dcp-run-and-manage-measurement#manage-measurements">Manage measurement</Anchor>.

</Accordion>

<div id="h_01KJWTTFECN74QDZ7GB2JCA9F5" />

<Accordion title="C - Filter bar">

Select the attribution date range, and display filters.

**Attribution date range**

Dates the attribution occurred.

**Filters**

Default filters available:

* Media source
* Campaign

</Accordion>
