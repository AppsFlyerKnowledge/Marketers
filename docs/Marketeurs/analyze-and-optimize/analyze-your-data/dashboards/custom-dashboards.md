## Tableaux de bord personnalisés

Chaque tableau de bord personnalisé se compose d'un ou plusieurs widgets qui fournissent des métriques d'acquisition d'utilisateurs. Vous configurez le widget avec l'assistant de widget, puis vous choisissez vos métriques, le format de présentation, les apps, etc.

Les métriques disponibles sont les mêmes que celles de l'acquisition d'utilisateur du tableau de bord général. Attention ! **Ne comparez jamais** les mesures du tableau de bord personnalisé avec celles de la vue d'ensemble unifiée **ni** de la vue de retargeting.

Une fois qu'un tableau de bord personnalisé est défini, il est disponible pour tous les utilisateurs du compte. 

<div id="dashboard-personalization" />

## Personnalisation du tableau de bord

Vous pouvez personnaliser un tableau de bord en déplaçant et redimensionnant ses widgets.

| Option de personnalisation | Description |
| --- | --- |
| Redimensionner le widget | Faites glisser l'angle situé en bas à droite d'un widget pour le modifier sa taille. |
| Position du widget | Glissez-déposez un widget pour le changer de place dans le tableau de bord |
| Actions | Survolez l'angle situé en haut à droite du widget, puis cliquez sur Actions. Les actions suivantes sont disponibles pour chaque widget :<ul><li>Modifier</li><li>Dupliquer</li><li>Supprimer</li><li>Exporter CSV</li></ul> |

<div id="procedures" />

## Marche à suivre

<div id="managing-dashboards" />

<Accordion title="Actions du tableau de bord">

| Action | Description |
| --- | --- |
| Dupliquer | Copie le tableau de bord actuel |
| Renommer | Modifie le nom du tableau de bord |
| Exporter au format PNG | Crée et télécharge un fichier PNG |
| Supprimer | Supprime le tableau de bord |

</Accordion>

<div id="add-a-custom-dashboard" />

<Accordion title="Ajouter un tableau de bord personnalisé">

**Pour ajouter un tableau de bord personnalisé :**

1. Dans AppsFlyer, dans le menu latéral, sélectionnez **Analyser** > **Tableaux de bord personnalisés**.  
   Un tableau de bord s'affiche.
2. Cliquez sur + (Ajouter un nouveau tableau de bord).
3. Saisissez le **titre de votre tableau de bord**.
4. Cliquez sur **Ajouter**.
5. Ajoutez un ou plusieurs widgets en suivant les instructions de la section suivante.

</Accordion>

<div id="managing-widgets" />

<Accordion title="Gestion des widgets">

**Pour ajouter un widget :**

1. Cliquez sur Ajouter un widget.
2. La fenêtre de widget s'ouvre.   

   <Image align="center" alt="WidgetConfigure_us-en.png" src="https://files.readme.io/f04544d8cb8b1d946526c4546565fffb405e5113e09dac65e5a28e218a1170a7-360015793618.png" />
3. Configurez le widget. Vous pouvez consulter le guide de configuration des widgets ci-dessous.
4. Ajoutez autant de widgets que nécessaire.

**Guide de configuration des widgets**

| Paramètre | Description |
| --- | --- |
| Type de widget | ![WidgetType_us-en.png](https://files.readme.io/00174da67c1b5046033655aad2f0af815d5abb3229cdc7c2f225f689c8adc7d8-360015793638.png)<br /><br />Sélectionnez un type de widget :<ul><li>Camembert</li><li>Diagramme en bâtons</li><li>Diagramme en lignes</li><li>Tableau de données</li><li>Carte de géolocalisation</li><li>Métrique</li><li>Tunnel de conversion</li></ul> |
| Description | Entrez la description du widget |
| Apps | Sélectionnez au moins 1 app (ou toutes) à inclure dans les données du widget. Si vous sélectionnez *toutes*, les 100 premières apps de votre compte seront prises en compte. |
| Les KPI | <ul><li>Sélectionnez les KPI qui s'afficheront dans le widget</li><li>Le tableau des données et le diagramme en bâtons sont classés selon le premier KPI sélectionné</li></ul> |
| Regrouper par | Sélectionnez le regroupement |
| Afficher le plus élevé | Saisissez le nombre de valeurs à afficher. |
| Pré-covid | Si cette option est activée, les données datant du 1er au 30 novembre 2019 (avant le COVID-19) seront affichées. |
| Filtres | Utilisez des filtres pour resserrer les données du widget :<ul><li>**Pays (géo)**</li><li>**Sources média**</li><li>**Campagnes**</li><li>**Canaux**</li></ul>Sélectionnez **Exclure les organiques** pour retirer les données non attribuées à une source média. |

</Accordion>

<div id="export-widget-data" />

<Accordion title="Exporter les données du widget">

<Image align="center" alt="Widget_table.png" src="https://files.readme.io/b04e80e16d0d34946e6783103fc6fbbdf89b390842db27226b4fdba6c1f7e506-360015717057.png" />

**Pour télécharger les données de widget dans un fichier CSV** :

1. Vérifiez que le widget contient bien un titre et des données.
2. Dans le widget, sélectionnez **Actions**.
3. Sélectionnez **Exporter le CSV**.  
   Le fichier se télécharge.  
   Les dates des fichiers CSV sont au format jj/mm/aaaa. Vous pouvez <Anchor target="_blank" href="https://answers.microsoft.com/en-us/msoffice/forum/msoffice_excel-mso_winother-mso_2010/how-to-convert-ddmmyyyy-to-mmddyyyy/41119ed6-4057-4598-a44c-1ebfdf301a43">les convertir dans un autre format</Anchor>, par exemple mm/jj/aaaa, en passant par Excel.

</Accordion>

## Caractéristiques et limitations

<div id="traits-and-limitations::6693dfa7" />

<Accordion title="Caractéristiques et limitations">

| Caractéristique | Remarques |
| --- | --- |
| Accès du réseau publicitaire au rapport | Non |
| Agences | Non prises en charge |
| Transparence de l'agence | Oui |
| Fuseau horaire propre à l'app | Si toutes les apps présentes dans le compte sont paramétrées sur le même fuseau horaire, les données s'affichent selon le fuseau horaire propre à l'application. Dans le cas contraire, les données s'affichent en UTC. |
| Devise spécifique à l'application | Si toutes les apps hébergées sur le compte sont paramétrées sur la même devise, les données s'affichent dans la devise spécifique à l'app. Dans le cas contraire, les données s'affichent en USD. |
| Données de coûts | Disponible uniquement s'il y a au moins 1 installation enregistrée. <Anchor target="_blank" href="/marketers/fr/docs/roi360-cost-aggregation-overview#cost-data-availability-and-reports">En savoir plus</Anchor> |
| Données organiques | Disponible |
| Données non organiques | Disponible |
| eCPA | <ul><li>Dans les tableaux de bord personnalisés, la formule de l’eCPA est la suivante : Dépenses totales / Nombre d'actions = eCPA</li><li>Elle diffère des autres tableaux de bord, y compris le tableau de bord général, où la formule est la suivante : Dépenses totales / **utilisateurs uniques** ayant effectué une action = eCPA</li></ul> |
| Actualisation des données | <Anchor target="_blank" href="/marketers/fr/docs/about-data-freshness-and-timezone-support#continuous-aka-realtime">Temps réel</Anchor>. Identique au tableau de bord général |
| Accès utilisateur du compte | Oui |
| Limitations | <ul><li>L'option d'exportation pleine page au format PDF n'est pas disponible.</li><li>L'exportation au format PNG n'est pas prise en charge par les navigateurs suivants : Edge, Firefox 69 (Max).</li><li>La recherche d'une campagne spécifique se limite aux cas où il y a moins de 100 campagnes. Si besoin est, réduisez la période et relancez la recherche.</li><li>Disponibilité des KPI : Les KPI en LTV d'acquisition d'utilisateurs sont disponibles. Les KPI liés au retargeting, à la rétention, à l'activité et à Protect360 ne sont pas disponibles. Attention ! Ne comparez pas les mesures du tableau de bord personnalisé avec les mesures unifiées ou de retargeting du tableau de bord général.</li><li>Les modifications de nom de campagne ne sont pas pris en charge.</li></ul> |
| Fuseaux horaires | <ul><li>Si toutes les apps présentes dans le compte sont paramétrées sur le même fuseau horaire, les données s'affichent selon le fuseau horaire propre à l'app. Dans le cas contraire, les données s'affichent en UTC.</li></ul> |
| Données historiques | 5 ans |

</Accordion>
