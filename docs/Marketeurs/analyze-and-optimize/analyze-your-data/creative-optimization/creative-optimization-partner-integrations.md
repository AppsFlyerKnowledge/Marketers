## À propos des intégrations de partenaires

L'intégration d'un partenaire permet d'importer en continu dans l'Optimisation des créations toutes les créations issues des campagnes menées par ce même partenaire.

### Disponibilité des données

Une fois l'intégration d'un partenaire ajoutée :

* Le système récupère les données créatives et de performance issues par AppsFlyer durant les 90 derniers jours. Les données sont généralement disponibles dans l'Optimisation des créations sous 24 heures.
* Les données créatives continueront ensuite d'être extraites des partenaires intégrés deux fois par jour, et ce au quotidien.
* Les données sont intégrées et matchées avec différentes données de performance AppsFlyer comme l'attribution, les dépenses, les clics, les impressions, les revenus, etc. (les données de performance AppsFlyer sont mises à jour toutes les heures).

Les tableaux de bord de l'optimisation des créations affichent l'ensemble des données décrites ci-dessus.

**Remarque :** Pour voir les données de coût AppsFlyer (comme le ROAS), l'<Anchor target="_blank" href="/marketers/fr/docs/roi360-cost-aggregation-overview">abonnement à ROI360</Anchor> est obligatoire.

## Intégration des partenaires média

Cette section décrit comment mettre en place des intégrations avec chaque partenaire.

<div id="adikteev" />

<Accordion title="Adikteev">

**Conditions préalables :**

* Vous devez fournir les informations suivantes pour l'intégration :
  * E-mail (Nom d'utilisateur Adikteev)
  * Mot de passe Adikteev

**Remarque :** Il doit s'agir des mêmes identifiants que ceux utilisés pour accéder à votre tableau de bord Adikteev.

* Pour nous permettre d'extraire toutes les données de coûts Adikteev, l'utilisateur qui a intégré <Anchor target="_blank" href="/marketers/fr/docs/roi360-cost-aggregation-overview">ROI360</Anchor> doit également être celui qui a intégré l'Optimisation des créations

**Pour ajouter une intégration :**

1. Connectez-vous à **Optimisation des créations** et effectuez l'une des opérations suivantes :

   * * Si vous n'avez pas d'intégrations de partenaires, cliquez sur + **Ajouter une nouvelle intégration**.
     * Sinon, cliquez sur l'icône  ⋮  en haut à droite du tableau de bord pour accéder aux **intégrations créatives**.  

       ![Main menu icon and filter bar New.jpg](https://files.readme.io/4af510b20e3cc27d1617fae01b06b4cfe35bb63e848abe7a257c6d5372ef2343-20128922257553.jpg)
2. Cliquez sur **+ Nouvelle intégration**.
3. Dans la liste des **partenaires**, sélectionnez **Adikteev**.
4. Sélectionnez les applications à promouvoir.
5. Saisissez l'e-mail et le mot de passe.
6. Cliquez sur ***Enregistrer***.

</Accordion>

## Intégrations des agences

Cette section décrit comment mettre en place des intégrations avec les agences.

<div id="agencies" />

<Accordion title="Agences">

Vous pouvez intégrer les données de vos agences partenaires dans le tableau de bord des créations.

**Pour ajouter une intégration d'agence :**

1. Connectez-vous à **Optimisation des créations** et effectuez l'une des opérations suivantes :

* * Si vous n'avez pas d'intégrations de partenaires, cliquez sur + **Ajouter une nouvelle intégration**.
  * Sinon, cliquez sur l'icône  ⋮  en haut à droite du tableau de bord pour accéder aux **intégrations créatives**.

![Main menu icon and filter bar New.jpg](https://files.readme.io/4af510b20e3cc27d1617fae01b06b4cfe35bb63e848abe7a257c6d5372ef2343-20128922257553.jpg)

2. Cliquez sur + **Nouvelle intégration**.

3. Après avoir sélectionné le partenaire et les apps dans la fenêtre d'intégration des partenaires, cochez la case **Agence**.

![Select_Agengy_with_arrow.jpg](https://support.appsflyer.com/hc/article_attachments/18565355455761)

4. Sélectionnez ensuite l'agence concernée dans le menu déroulant **Sélectionner une agence**.

5. Cliquez sur **Enregistrer**.

L'intégration de l'agence est alors ajoutée.

**Remarque :**

* Pour chaque agence dont vous souhaitez voir les données créatives dans le tableau de bord, vous devez créer une intégration partenaire en cochant la case *Agence*.
* Les données ne sont disponibles que pour les agences transparentes. <Anchor target="_blank" href="/marketers/fr/docs/view-agency-data">En savoir plus</Anchor>
* Les données créatives seront extraites de l'agence uniquement. Cela signifie que si vous sélectionnez Google Ads comme partenaire (exemple ci-dessus), mais que vous avez également des campagnes qui tournent directement avec Google Ads, vous devez créer une intégration de partenaire supplémentaire pour Google Ads.

</Accordion>
