| **What's new** | You can now bulk upload CSV files to select Protect360 validation rule conditions. |
| --- | --- |
| **Effective date** | August, 2024 |
| **What you need to know** | <ul><li>When selecting the operators **In list** or **not in list** inside of conditions that support it, you have the option to bulk upload a CSV file.</li><li>The CSV file can contain up to 17K values.</li></ul> |
| **Implications** | Bulk upload is now available to select validation rules. Allowing you to upload a CSV file containing a long list of values for the rule to work according to your business needs. More information, including how to set it up, can be found <Anchor target="_blank" href="/marketers/vi/docs/implement-validation-rules-to-prevent-fraud#bulk-upload">here</Anchor>. |
