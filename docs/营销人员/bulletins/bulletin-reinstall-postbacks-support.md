| 板块 | 详情 |
| --- | --- |
| **最新动态** | 对 **应用重新安装的回传** 现已推出。这些现在可以与首次安装区分开来。 |
| **生效日期** | 24/12/2025 |
| **重要须知** | 安装回邮现在也控制重新安装回贴。在 **主动集成** 侍从。<ul><li>**适配平台**目前仅限部分合作伙伴（例如Unity Ads）提供。更多合作伙伴将很快加入。</li><li>**地理位置：** 安装后文显示在 **默认回邮** 该分段 **归属** Tab。对于支持的网络，它现在还控制重装回邮。</li><li>配置你可以更改**对于来自以下用户** 下拉菜单 **只有这个搭档** 到 **所有媒体来源（包括有机媒体）**.</li><li>**格式：** 重装事件使用与安装事件相同的后回格式，宏为 `is_reinstall=true` 附录。</li><li>价值这可以改进测量和优化，特别是对于专注于再营销的合作伙伴。</li></ul> |
| **待办事项** | 此功能仅限指定合作伙伴使用。如果您有兴趣访问，请联系您的PDM。 |
