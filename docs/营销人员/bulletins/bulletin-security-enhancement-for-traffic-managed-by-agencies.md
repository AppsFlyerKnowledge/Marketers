| **最新动态** | 为了保障您的数据安全，降低作弊风险，我们目前正在针对代理流量（即代理代替广告主在广告平台上投放广告后产生的流量）强化防护措施。自2024年7月14日起，AppsFlyer仅记录并衡量相关广告平台的授权代理所产生的流量。<br /><br />**请注意：**<ul><li>即使归因链接中的af\_prt参数为空，也同样需要符合上述要求。</li><li>与<Anchor target="_blank" href="/marketers/zh/docs/self-reporting-networks-srns">SRN</Anchor>合作的代理不在此要求的适用范围之内。</li></ul> |
| --- | --- |
| **生效日期** | 2024年7月31日 |
| **面板位置** | <ul><li>**代理：** 对接页面</li><li>**广告平台：** 安全中心</li></ul> |
| **须知事项** | <ul><li>**代理：**</li><li>**广告平台：**</li></ul> |
| **具体影响** | 自该措施生效之日起，若某代理不在相关广告平台的批准名单中，则AppsFlyer不会记录或衡量其流量，且对于在该平台上投放广告的所有应用，该代理都没有其对接页面的访问权限。 |
