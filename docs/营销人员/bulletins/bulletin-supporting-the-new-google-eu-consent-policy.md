| <span id="whats-new"></span>**最新动态** | 为了应对即将生效的欧盟<Anchor target="_blank" href="https://commission.europa.eu/strategy-and-policy/priorities-2019-2024/europe-fit-digital-age/digital-markets-act-ensuring-fair-and-open-digital-markets_en">《数字市场法案》</Anchor>（DMA），Google对其<Anchor target="_blank" href="https://www.google.com/about/company/user-consent-policy/?sjid=15416941068016224808-NA">欧盟用户意见征求政策</Anchor>进行了更新。AppsFlyer正在进行必要调整，以支持Google的政策规定，同时确保广告主能充分发掘Google Ads作为营销渠道的价值。 |
| --- | --- |
| <span id="effective-date"></span>**生效日期** | 2024年3月6日 |
| <span id="relevant-integrations-and-audience"></span>**相关对接及受众** | 所有符合以下条件的广告主：1）具有与Google Ads或GMP DV360（googleadwords\_int、dv360\_int）对接的应用；2）具有位于欧洲经济区（EEA）的终端用户。 |
| <span id="required-actions"></span>**待办事项** | 根据Google的政策要求，广告主如需使用EEA及英国境内终端用户的个人数据，必须先征得其同意，并将用户授权数据发送给Google。AppsFlyer可通过SDK向Google发送授权信号（consent signals），帮助广告主高效完成此流程。请更新您的AppsFlyer SDK，以确保您符合Google的政策要求。详情请见<Anchor target="_blank" href="/marketers/zh/docs/support-google-eu-consent-policy">此文档</Anchor>。 |
