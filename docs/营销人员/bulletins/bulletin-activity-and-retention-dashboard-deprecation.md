| 板块 | 详情 |
| --- | --- |
| **最新动态** | 自2025年10月1日起，旧版活跃数据面板与留存面板将正式下线。此次调整旨在进一步优化分析平台，为您提供更灵活的自助式体验。与此同时，<Anchor target="_blank" href="/marketers/zh/docs/my-dashboards">My Dashboards</Anchor>也新增了更丰富的功能与自定义选项。 |
| **生效日期** | 2025年10月1日 |
| **重要须知** | 请在<Anchor target="_blank" href="/marketers/zh/docs/my-dashboards">My Dashboards</Anchor>中重新创建基于“活动数据”或“留存”面板创建和保存的视图或报告。<Anchor target="_blank" href="/marketers/zh/docs/my-dashboards">My Dashboards</Anchor>提供更高级的自定义和可视化功能，帮助您更高效地获取洞察。<br /><br />此次升级旨在为您打造更高效、更灵活的分析体验。<Anchor target="_blank" href="/marketers/zh/docs/my-dashboards">My Dashboards</Anchor>功能亮点：<ul><li>自定义微件布局</li><li>筛选并保存自定义视图</li><li>多样化的图表展示形式</li></ul> |
| **待办事项** | 请切换至<Anchor target="_blank" href="/marketers/zh/docs/my-dashboards">My Dashboards</Anchor>，继续追踪和分析用户活跃数据与留存趋势。 |
