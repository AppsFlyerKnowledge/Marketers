| **最新动态** | 现在AppsFlyer中的所有代理均已数据透明。此次更新可以让广告主获得更详尽的数据，以便更有效地分析并优化营销投入。 |
| --- | --- |
| **更新日期** | 2025年3月12日 |
| **重要须知** | **更新前**：数据不透明的代理所使用的媒体渠道显示为该代理的名称，而不是实际投放的广告平台名称。<br /><br />**更新后**：<ul><li>无论相关代理之前是否开启了数据透明化，所有由代理带来的投放数据都对广告主可见，且数据颗粒度细致到媒体渠道层级。也就是说，媒体渠道字段会显示实际投放的广告平台，而不是相关代理的名称。您仍然可以按代理对数据分组。</li><li>面板：代理的历史数据也将作透明化处理。</li><li>报告：对于广告主在此次更新前接收到的报告，其中的数据不会发生变更。比如，在更新前写入Data Locker的报告仍会包含不透明代理的数据，但更新后写入Data Locker的报告则会显示透明的代理数据。</li><li>Protect360的验证规则中所定义的“不透明代理”会调整为“代理”。相关的验证规则在更新后的透明代理框架下可无缝衔接，与其它既定设置一并持续生效。</li><li>如果您使用的是更新前上报的成本数据，可能会看到汇总成本被拆分为多行：一行显示在更新前的代理名称下，另一行显示在更新后的实际媒体渠道名称下。在这种情况下，建议您将更新前的成本数据替换为更新后的数据。</li></ul> |
| **待办事项** | 如果您的内部流程依赖当前将“代理名称”作为渠道名称的不透明代理，请检查并适当更新这些流程，以兼容此次更新。<br /><br />比如根据需求在面板中按渠道或代理进行数据分组，或在报告中使用`media_source`或`af_prt`字段。 |
