| **最新动态** | **事件**、**概览**和**活跃数据**面板即将下线。后续**My Dashboards**将成为主要的数据分析入口。<br /><br />自**2026年6月30日**起，以上旧版面板将不再支持访问。您可在My Dashboards中查看相关数据。与旧版面板相比，My Dashboards可提供更强大的分析能力，支持灵活视图、自定义指标、高级筛选条件，以及共享或个人专属面板。 |
| --- | --- |
| **生效日期** | 自**2026年5月30日**起，当您从 **“分析**”选项卡打开旧版面板时时，系统将弹出一个窗口，其中包含跳转至My Dashboards中对应模板或视图的链接。<br /><br />自**2026年6月30** 日起，旧版**事件**、**概览**和**活动数据**面板将不再支持访问。<br /><br />您可在My Dashboards中访问相关数据和已保存视图。 |
| **适用人群** | 所有正在使用事件、概览和活跃数据面板的广告主、代理和合作渠道。 |
| **待办事项** | 为避免分析您的工作流程受到影响，请在下线日期前提前开始使用My Dashboards。<br /><br />如何启用：<ol><li>从左侧导航菜单中进入**My Dashboards**。</li><li>打开对应的模板或视图：<ul><li>如需查看事件数据，请打开 **“事件**”模板。</li><li>如需查看概览数据，请打开 **“表现分析**”或 **“营销概览**”模板。</li><li>如需查看活跃数据，请打开 **“活跃数据**”视图。</li></ul></li><li>使用指标、筛选条件和分组功能创建自定义视图。</li><li>将配置保存为共享视图或个人视图。</li></ol> |
| **须知事项** | 相比旧版面板，My Dashboards可为您提供更灵活、更可自定义的分析体验。<br /><br />主要功能包括：<ul><li>**统一数据**在同一界面查看获客和再营销数据。</li><li>**增强型表格：** 表格最多支持4个分组，最多可将100,000行数据导出为CSV文件。</li><li>**面板级筛选条件：** 将筛选条件应用到面板内的所有微件。</li><li>**共享视图和个人视图：** 可与团队共享视图，也可创建仅自己可见的个人视图。</li><li>**自定义指标和维度：** 根据业务需求创建专属指标和维度。</li><li>**周期对比：** 将当前周期的数据与上一周期进行对比。</li><li>**增强型图表：** 持事件微件、群组微件、组合图，以及包含多个指标的图表。</li><li>**条件格式：** 突出显示表格中的关键数据。</li><li>**按指标排序：** 根据需求，按指定指标对表格数据进行排序。</li></ul>**<span id="how-to-find-and-add-dashboard-templates"></span>如何查找并添加<Anchor target="_blank" href="/marketers/zh/docs/my-dashboards#dashboard-templates">面板模板</Anchor>**<ol><li>在My Dashboards中，从左侧菜单打开任一面板。<br /><Image alt="" src="https://files.readme.io/26afca0c0285c01ff9019495cedd752b0dd823f071f58622a963c669fe38653a-46644427745937.png" width="93px" /></li><li>进入面板主页后，点击面板名称右侧的箭头。<br /><Image alt="" src="https://files.readme.io/046551ea88a85e488eee6e08fef4bf4eff23dcedc461e461732a1f5413fa4c68-46644427750801.png" width="186px" /></li><li>搜索所需面板，或浏览可用模板。<br /><Image alt="" src="https://files.readme.io/3cce1e11a371d8dc6cc04ef29f8db9ff82781c414ece3ad07ccdbb2da75ea56b-46644506493969.png" width="186px" /></li></ol> |
| 事件面板替代方案 | 如需在My Dashboards中查看事件数据：<ol><li>前往**My Dashboards**。</li><li>打开**事件**模板。</li></ol>事件模板可全面呈现应用内事件数据。<br /><br />事件模板包含：<ul><li>**事件微件：** 按媒体渠道、地区、日期等维度查看应用内用户行为。</li><li>**基于群组的事件分析：** 在群组语境下分析事件表现。</li><li>**业务KPI：** 围绕收入事件及其他自定义关键绩效指标创建视图。</li><li>**My Dashboards功能：** 使用筛选条件、共享视图、CSV导出、自定义指标，以及最多4个表格分组。</li></ul> |
| 概览面板替代方案 | 如需在My Dashboards中查看概览数据：<ol><li>前往**My Dashboards**。</li><li>打开以下任一模板：<ul><li>**表现分析**</li><li>**营销概览**</li></ul></li></ol>旧版概览面板中的现有已保存视图将自动迁移至My Dashboards。<br /><br />“表现分析和营销概览”模板支持My Dashboards的相关功能，包括增强型表格、面板级筛选器、共享视图和个人视图、自定义指标和维度、周期对比、增强型图表、条件格式以及按指标排序。<br /><br />旧版概览面板中的现有已保存视图将迁移至My Dashboards。<br /><br />为您的账户启用迁移后，过去60天内未使用的已保存视图将被移除。请打开并保存您希望保留的视图。 |
| 活跃数据面板替代方案 | 如需在My Dashboards中查看活跃数据：<ol><li>前往**My Dashboards**。</li><li>打开**活跃数据**视图。</li></ol>您可在My Dashboards中查看所有活跃数据。<br /><br />活跃数据视图包含：<ul><li>**按指标排序：** 按指定指标对表格数据排序。对于活跃数据面板中存在的Campaign，例如包含会话的Campaign，即使没有生命周期价值数据，也不会再被排除在外。</li><li>**活跃用户随时间的变化：** 查看指定日期范围内的活跃用户，且不进行平均计算。</li><li>**并排分析：** 查看活动数据，并结合终身价值和 用户群指标进行分析。</li><li>**My Dashboards功能：** 使用条件格式、自定义指标、周期对比、筛选器，以及共享视图或个人视图。</li></ul> |
| **<span id="faq"></span>常见问题解答**| **<span id="will-i-lose-my-data"></span>我的数据会丢失吗？**<br /><br />不会。您仍可在My Dashboards中使用或访问数据。底层数据保持不变，只是分析界面发生了变化。<br /><br />**<span id="what-happens-to-my-saved-views-from-the-overview-dashboard"></span>旧版概览面板中的已保存视图会如何处理？**<br /><br />旧版概览面板中的现有已保存视图将自动迁移至My Dashboards。<br /><br />为您的账户启用迁移后，过去60天内未使用的已保存视图将被移除。请打开并保存您希望保留的视图。<br /><br />**<span id="can-i-access-the-legacy-dashboards-after-june-30-2026"></span>2026年6月30日之后，我还能访问旧版面板吗？**<br /><br />不能。**2026年6月30日**之后，旧版事件、概览和活跃数据面板将不再支持访问。<br /><br />**<span id="what-can-i-do-if-i-need-a-feature-that-isn-t-available-in-my-dashboards"></span>如果My Dashboards中没有我需要的功能，该怎么办？**<br /><br />请联系您的客户成功经理（CSM）或 AppsFlyer 客服。AppsFlyer将持续优化My Dashboards，并根据客户反馈和任务优先级进行调整。<br /><br />**<span id="where-can-i-learn-more-about-my-dashboards"></span>从哪里可以了解更多My Dashboards相关信息？**<br /><br />请参阅<Anchor target="_blank" href="/marketers/zh/docs/my-dashboards">**My Dashboards**</Anchor>。 |
