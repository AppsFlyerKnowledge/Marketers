| **最新动态** | 自2026年4月1日起，LTV汇总数据（包括点击、展示和激活）将统一保留25个月（2年 + 1个月），不再延续此前5年的保留期。 |
| --- | --- |
| **生效日期** | 2026年4月1日 |
| **建议采取的行动** | 在2026年4月1日之前导出所有LTV历史汇总数据 |
| **补充信息** | 本次调整适用于以下产品和界面中的LTV汇总数据：<ul><li>My Dashboards</li><li>Protect360</li><li>SKAN面板：</li><li>Master API</li><li>数据透视表</li><li>自定义面板</li><li>数据总览面板</li><li>Pull API汇总数据</li><li>活跃数据控制面板</li><li>事件面板</li><li>AppsFlyer MCP</li></ul>**<span id="what-you-should-know"></span>须知事项**<ul><li>汇总LTV数据的可用期限（包括点击、展示和激活数据）最长为**25个月（2年+1个月）**。</li><li>自2026年4月1日起，超过25个月的汇总LTV数据将不再支持访问。</li><li>如对超出保留期限的汇总LTV数据发出查询或可视化请求，可能会返回**部分结果或空结果**。</li><li>25个月之前的群组和活动数据可能依然可用，因此不同数据集之间可能会出现差异。</li></ul> |
