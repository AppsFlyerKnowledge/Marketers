| **最新动态** | 活跃数据现以统一视图呈现，也就是说活跃数据中同时包含UA和再营销数据。 |
| --- | --- |
| **更新日期** | 2023年2月1日 |
| **面板位置** | 活跃数据面板、数据透视表以及Master API。 |
| **重要须知** | <ul><li>应用打开（session）和DAU等部分活跃维度的指标一直以来仅以UA数据为基础。</li><li>现在，所有活跃维度的指标都同时包含UA和再营销数据。**请注意**：仅提供统一视图；不支持将数据拆分为仅UA或仅再营销。</li><li>部分广告平台中原先归因到UA投放的事件现在可能会被归因到再营销投放。</li><li>此次更新上线后，DAU和MAU等指标可能会有所增长，这是因为计算这些指标时会纳入再营销数据。</li><li>活跃数据面板<ul><li>应用打开总数（sessions）：</li><li>日活</li><li>月活</li><li>日活用户数 DAU/月活用户数 MAU</li><li>ARPDAU</li><li>成本</li><li>点击</li><li>展示</li><li>转化率</li><li>eCPI（有效激活成本）</li></ul><ul><li>活跃KPI</li></ul></li></ul> |
