| <span id="whats-new"></span>最新动态 | Meta Ads现可利用名为**AdImpression**的广告收入回传事件来优化您的安卓应用推广广告（App promotion campaign）。 |
| --- | --- |
| <span id="update-date"></span>更新日期 | 1月18日 |
| <span id="what-you-need-to-know"></span>重要须知 | <ul><li>如果该功能显示为灰色（不可用），可能是因为该账号不符合[相关要求](https://www.facebook.com/business/help/571188993373447?id=561906377587030)。</li><li>此外，您还需要完成广告收入对接。支持以下两种对接类型：<Anchor target="_blank" href="/marketers/zh/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">1）SDK上报展示级别数据；2）SDK上报展示级别数据+S2S API上报设备级别数据</Anchor><ul><li>没有ROI360套餐的账号可以使用其他事件名称发送广告收入数据。</li></ul></li></ul> |
| <span id="what-you-need-to-do"></span>待办事项 | <ul><li>购买了ROI360的广告主请使用以下任一方式完成广告收入对接：<Anchor target="_blank" href="/marketers/zh/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">1）SDK上报展示级别数据；2）SDK上报展示级别数据+S2S API上报设备级别数据</Anchor></li><li><Anchor target="_blank" href="/marketers/zh/docs/meta-ads-in-app-event-mapping#mapping-ad-revenue-data-for-campaign-optimization">将af\_ad\_revenue事件映射到**Adimpression**</Anchor>。</li></ul> |
| <span id="additional-resources"></span>相关资源 | 在Meta Ads Manager中将转化量作为投放目标时，如需进一步了解充分提升转化的方式，请参考<Anchor target="_blank" href="https://www.facebook.com/business/help/330074040129013">Meta Business提供的说明文档</Anchor>。 |
