| **最新动态** | 鉴于业界对行业生态中数据透明度的日益重视，AppsFlyer现支持广告主与代理之间的数据透明化。<br /><br />2023年8月14日起，应用级别的<Anchor target="_blank" href="/partners/zh/docs/getting-started-agency-onboarding#代理数据透明化设置">代理数据透明化</Anchor>开关默认打开，且永久性保持打开状态。该次更新的影响范围包括新近入驻AppsFlyer的代理以及新近获得广告主授权的现有代理。 |
| --- | --- |
| **生效日期** | 2023年8月14日 |
| **更新前** | 所有获得广告主授权的代理账户可以选择打开或关闭**数据透明化**开关。 |
| 更新后： | <ul><li>对于新近入驻AppsFlyer的代理以及新近获得应用级别访问权限的现有代理，**数据透明化**开关将永久性处于打开状态。</li><li>如果现有代理的数据透明化开关目前仍处于关闭状态（已停用），可以选择打开开关或使其保持关闭。此开关一经开启后，将永久性保持开启状态，无法再重新关闭。</li></ul> |
| 例外情况 | 账户使用情况报告不支持代理数据透明化（无变化） |
| **面板位置** | 代理帐户从AppsFlyer后台的侧边栏中选择**配置** > **应用配置**。 |
| **必要的前期工作**： | 无需进行任何操作，但建议数据不透明的代理逐渐转换到透明化模式。 |
