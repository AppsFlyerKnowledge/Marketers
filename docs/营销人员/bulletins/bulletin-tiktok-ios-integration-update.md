| 板块 | 详情 |
| --- | --- |
| **功能介绍** | AppsFlyer正在对TikTokiOS高级自归因平台（SRN）对接中的隐私配置进行更新。具体变化如下：<ul><li>当前的<strong>「高级隐私」（Advanced Privacy, AP）</strong>开关将更名为<strong>「高级数据共享」（Advanced Data Sharing，ADS）</strong>，与AppsFlyer中其他SRN对接的设置命名保持一致。</li><li>更新后，AppsFlyer将与TikTok共享所有转化事件，无论广告ID（IDFA）是否可用。</li></ul>这意味更多iOS转化可以能够被归因，TikTok也可以基于更完整的效果数据优化您的广告系列。 |
| **生效日期** | 2026年6月23日 |
| **重要须知** | 您的设置将自动迁移，无需采取任何操作。当前配置与新开关的对应关系如下：<ul><li>如果<strong>「高级隐私」</strong>当前为**关闭状态**→<strong>「高级数据共享」</strong>将设置为**开启**状态</li><li>如果<strong>「高级隐私」</strong>当前为**开启状态**→<strong>「高级数据共享」</strong>将设置为**关闭**状态</li></ul> |
