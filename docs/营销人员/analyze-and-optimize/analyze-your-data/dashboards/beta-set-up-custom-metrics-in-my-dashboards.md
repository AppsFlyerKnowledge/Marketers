> **概要：** 您可以配置自定义的指标，并在“My Dashboards”中通过这些指标查看相应数据。

## 自定义指标

您可以根据现有数据定义自定义指标的计算方式，让面板中的分析数据紧密贴合您的业务需求。比起标准化的指标，自定义指标能帮助广告主更有效、更灵活地调控数据分析。广告主可以合并多种指标、创建预测分析并自行调整KPI。

举例来说，您可以根据您业务中特定的使用场景，创建以下指标的计算方式，代替“收入”或“点击量”等常规指标：

* 第60天收入预测 = 第1天收入 * 3
* 点击到购买的转化率 = 点击量/af\_purchase [独立用户数]

“My Dashboards”中的所有微件均可支持自定义指标的呈现，包括表格、图表和KPI。无论是监测广告投放ROI的市场营销人员，还是关注用户互动情况的产品经理，亦或是投放效果的分析师，都可以利用自定义指标优化趋势分析、发现商机，以最贴合您独特业务需求的方式调整数据洞察，从而做出更有效的决策——直接进入您的面板，即可享受上述所有优势。

**请注意**：自定义维度是在账户层级创建的，也就是说同一个AppsFlyer账户中的不同应用可以使用相同的自定义维度。

## 配置流程

<div id="create-a-custom-metric" />

<Accordion title="创建自定义指标">

**请按以下方式创建自定义指标**：

1. 进入您的面板，完成以下任一操作：
   * 点击 **+ 新建** > **自定义指标**。
   * 打开任何图表或表格的**指标**下拉菜单，点击其中的 **+ 创建自定义指标**。
2. 为您的指标命名。在自定义指标编辑窗口的顶部输入带有描述性的名称，用于识别您的指标（如“IPM”）。
3. 选择一个**指标类型**。可选的指标类型有数字、百分比或金额（货币）
4. 设定该指标的计算公式。您可以使用以下任一方式：
   * 快速启用：使用AF推荐的计算公式（显示在自定义指标编辑窗口的左侧）。选择完毕后，对模板公式进行编辑，使其贴合您的具体需求，比如选择更合适的应用内事件、更改乘数或其他参数。举例来说，假设您选择了模板`Retention rate D2 / Retention rate D7`，可以将D2和D7更改为不同的事件或时间段。
   * 通过互动式编辑器配置：使用相应按钮添加指标和运算符，并根据实际需求键入数字，完成计算公式的设定。
5. 在fx公式字段中检查该公式的预览。
6. 【可选】通过面板创建自定义指标时，请点击**保存并添加到图表**。  
   面板会创建一个新的图表，其中包含您的自定义指标。
7. 点击**保存**。
   * 通过某个微件创建自定义指标时，该指标会被自动添加到相关图表或表格中。
   * 通过面板创建自定义指标时，您可以将指标添加到任何您需要的微件中。

</Accordion>

<div id="edit-a-custom-metric" />

<Accordion title="编辑自定义指标">

您可以在面板或微件中编辑自定义指标。**请注意**：您对自定义指标所做的任何更改都会在账户层级生效，也就是说您账户下的所有用户和面板都会看到/呈现更改后的指标。

**要从仪表板编辑自定义指标**:

1. 进入您的面板，点击 **+ 新建** > **自定义指标**。
2. 进入自定义指标编辑窗口的左侧菜单，在“我的自定义指标”下找到您需要编辑的指标，并点击**编辑**图标。
3. 根据您的业务需求修改自定义指标的计算公式。
4. 点击**保存**。

**要从小部件编辑自定义指标**:

1. 进入任何一个图表或表格，在**指标**下拉菜单中找到您需要修改的指标，然后点击**编辑**图标。
2. 进入自定义指标编辑窗口的左侧菜单，在“我的自定义指标”下找到您需要编辑的指标，并点击**编辑**图标。
3. 根据您的业务需求修改自定义指标的计算公式。
4. 点击**保存**。

</Accordion>

<div id="delete-a-custom-metric" />

<Accordion title="删除自定义指标">

您可以在面板或微件中删除自定义指标。**请注意**：您对自定义指标所做的任何删除操作会在账户层级生效，也就是说该指标会从您账户下的所有用户和面板中删除。

**要从仪表板删除自定义指标**:

1. 进入您的面板，点击 **+ 新建** > **自定义指标**。
2. 进入自定义指标编辑窗口的左侧菜单，在“我的自定义指标”下找到您需要删除的指标，并点击**删除**图标。

**要从小部件删除自定义指标**:

* 进入任何一个图表或表格，在**指标**下拉菜单中找到您需要删除的指标，然后点击**删除**图标。

</Accordion>

## 其他相关信息

<div id="best-practices" />

<Accordion title="最佳实践">

* **开头从简**：刚开始配置自定义指标时，先从基础的指标开始，熟练掌握指标公式的设置方法后，再根据需求再逐渐提升复杂度。
* **对齐目标**：确保每个指标都关联到具体的业务目标或问题。
* **记录公式**：为您的自定义计算公式保留一份记录，以便日后更新或调试。
* **定期检查**：定期评估您设置的自定义指标，确保这些指标仍与业务相关。

</Accordion>

<div id="traits-and-limitations" />

<Accordion title="特点与局限性">

| 特点 | 说明 |
| --- | --- |
| 账户级别的访问权限 | 相关账户下的所有成员均可创建、查看、编辑和删除任何自定义指标，包括非本人创建的指标。 |
| 自定义指标 | <ul><li>每个账户的自定义指标上限为1,000个。</li><li>目前仅支持每日时间细分的自定义指标。不支持每周和每月的细分。</li></ul> |
| 公式复杂度 | 一个自定义指标中最多可使用5个常规指标来设定其计算公式。 |
| 嵌套限制 | 自定义指标的计算公式中不能使用自定义指标。 |

</Accordion>
