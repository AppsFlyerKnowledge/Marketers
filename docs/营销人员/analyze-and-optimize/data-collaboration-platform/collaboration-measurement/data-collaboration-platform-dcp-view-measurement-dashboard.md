> **概要：** 使用可视化和表格视图分析协作活动随时间的表现和趋势。

使用测量仪表板查看和分析活动表现。 它包含了表现关键绩效指标、长期趋势、展示量和点击量、收入和其他指标。

<div id="the-measurement-dashboard" />

## 测量仪表板

[![](https://files.readme.io/a69a72f87bbe6290548e52dea810d774ad09618ec1540bfb00db42e62d52f382-44443401136017.png)](https://files.readme.io/a69a72f87bbe6290548e52dea810d774ad09618ec1540bfb00db42e62d52f382-44443401136017.png)

仪表板包括以下组件：

<div id="a-filter-bar" />

<Accordion title="A - 测量面板">

在仪表板面板中选择您想要查看的测量值（**B**).您可以查看实时仪表板或您设置的其中一个历史仪表板。有关实时和历史仪表板的详细信息，请参阅 <Anchor target="_blank" href="/marketers/zh/docs/data-collaboration-platform-dcp-run-and-manage-measurement#about-measurement-run-modes">关于测量运行模式</Anchor>.

</Accordion>

<div id="h_01KJWV7PG61YPCBMG2X3NGZN96" />

<Accordion title="B - 仪表板面板">

在测量面板中显示您在测量面板中选择的仪表板（**A**).该窗格使您能够编辑、复制、重新运行仪表板，并与您的协作者共享仪表板。有关详细信息，请参阅 <Anchor target="_blank" href="/marketers/zh/docs/data-collaboration-platform-dcp-run-and-manage-measurement#管理衡量">管理测量</Anchor>.

</Accordion>

<div id="h_01KJWTTFECN74QDZ7GB2JCA9F5" />

<Accordion title="筛选条件栏">

选择归因日期范围和显示过滤器。

**归因日期范围**

发生归因的日期。

**筛选条件**

默认的筛选条件

* Media source（媒体渠道）
* 广告系列

</Accordion>

<div id="b-kpi-headline-metrics" />

<Accordion title="KPI标题指标">

| 指标 | 显示内容（基于选定时段） |
| --- | --- |
| 转化总量 | 在选定日期范围内的自然和非自然新增激活总数。总转化数 = 非有机转化数 + 有机转化数。 |
| 非自然转化 | 即归因到非自然媒体渠道的新增激活，这些激活通常发生在广告点击或展示之后。 |
| 自然转化 | 指用户未与任何媒体渠道上的广告互动，直接激活应用。 |
| 点击率 | 等于 点击/展示数 |
| 转化率 | 等于 转化数/点击数 |
| 总体收入 | 由有机和非有机转化事件触发的所有事件收入之和 |

</Accordion>
