> **概要：** 您可以在安全中心面板中统一查看并管理所有账号安全相关功能的状态。

<div id="what-can-i-do-from-the-security-center" />

## 安全中心的可用操作

**安全中心**面板为您提供简要全面的AF账号安全状态信息。您可以点击**安全中心**内的各个按钮，进入对应的功能板块。具体说明请见下表。

| 功能 | 说明 |
| --- | --- |
| <span id="user-management"></span>用户管理 | 创建并管理相关AppsFlyer账号下的用户。您可以为其开放各种功能、应用以及数据的访问权限。 |
| <span id="redirect-allowlist"></span><Anchor target="_blank" href="/marketers/zh/docs/set-up-your-domain-redirect-allowlist">跳转白名单</Anchor> | 设定可作为链接跳转终点的域名。 |
| <span id="list-of-authorized-agencies-for-ad-networks"></span><Anchor target="_blank" href="/partners/zh/docs/set-up-your-list-of-authorized-agencies">授权代理列表</Anchor>（适用于广告平台） | 管理代理授权，获得授权的代理才能通过您的平台对接投放广告。 |
| <span id="api-allowlist"></span><Anchor target="_blank" href="/marketers/zh/docs/set-up-your-api-allowlist">API白名单</Anchor> | 设定可用于API请求的IP地址 |
| <span id="enhanced-login-security"></span>强化登录安全性 | 配置<Anchor target="_blank" href="/marketers/zh/docs/set-up-sso-authentication-with-your-identity-provider-idp">单点登录（SSO）</Anchor>或<Anchor target="_blank" href="/marketers/zh/docs/implementing-and-using-2fa-login">双重身份验证（2FA）</Anchor> ，防止出现未授权登录。 |
| <span id="appsflyer-api-and-s2s-tokens"></span><Anchor target="_blank" href="/marketers/zh/docs/managing-appsflyer-tokens">AppsFlyer token</Anchor> | 使用AppsFlyer token，对API和S2S的调用请求进行验证。管理并定期更换token，充分保障数据安全。 |
| <span id="audit-log"></span><Anchor target="_blank" href="/marketers/zh/docs/audit-log">审计日志</Anchor> | 审核账户使用情况，识别未经授权的访问，包括登录、用户管理操作和API调用。 |

**安全中心的访问方式：**

* 从页面顶部导航栏打开账户菜单（点击右上角的邮箱地址，打开下拉菜单）> **安全中心**。
