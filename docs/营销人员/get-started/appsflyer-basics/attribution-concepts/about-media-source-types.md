> **概要：** 了解AppsFlyer中的基本媒体源类型。

媒体来源是指展示广告的实体。 AppsFlyer平台支持来自不同类型媒体的归属记录。

| 媒体来源类型 | 说明 |
| --- | --- |
| srn (自归因渠道) | <ul><li>通过API在AppsFlyer与网络之间提供归属确认和详细信息</li><li>示例Meta广告、谷歌、苹果搜索广告</li></ul> |
| 非SRN | <ul><li>提供包含在点击URL中的归属信息。</li><li>也被称为<Anchor target="_blank" href="/marketers/zh/docs/set-up-an-integrated-partner">归因-链接网络</Anchor> 或者广告网络。</li><li>如Unity 广告，Tapjoy，Applovin</li></ul> |
| 自有媒体 | <ul><li>自有媒体使用<Anchor target="_blank" href="/marketers/zh/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">OneLink 链接</Anchor>用于战役。</li><li>如电子邮件、短信、社交网络、落地页、二维码等等。</li></ul> |
