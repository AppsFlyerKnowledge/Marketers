> **概要：** AppsFlyer中数据和功能的访问权限取决于团队成员的账户类型、团队成员的个人权限以及账户权限。

## 分账户类型的数据访问权限

广告主、广告平台和代理的数据访问权限取决于他们的账户类型：

| 账户类型 | 可访问的数据 |
| --- | --- |
| 广告主 | AppsFlyer中所有的广告主数据，但部分数据会通过掩码或哈希处理，这类数据包括：<ul><li>归因到<Anchor target="_blank" href="/marketers/zh/docs/view-agency-data">不透明</Anchor>代理的流量</li><li>根据监管要求或数据共享条款归因到受限媒体渠道（restricted）的流量</li></ul> |
| 广告平台 | 归因到相关广告平台的数据 |
| 代理商 | 该代理的广告投放数据及其带来的流量相关数据 |

## 取决于角色和授权状态的数据访问权限

广告主打开某个广告平台或代理的授权开关后，其数据访问权限还会根据具体的账户角色而有所不同——即区分账户**管理员**和账户**团队成员**，详情请见下表。

**请注意：** 对于广告主已授权的数据，相关广告平台或代理的数据访问范围仅限其自身产生的流量。

缩写符号：

| 缩写 | 含义 |
| --- | --- |
| ✓ | 广告主打开主授权开关后即可获得访问权限 |
| P | 广告主打开其他特定授权开关后可获得访问权限 |
| L | 广告主授权后可获得有限的访问权限 |
| – | 无权限 |
