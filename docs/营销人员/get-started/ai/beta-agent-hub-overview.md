<span class="af-tag af-tag--beta-feature">Beta feature</span>

> **At a glance:** Agent Hub 是 AppsFlyer 的集中式平台，用于管理由 AI 驱动的预置型智能体，这些预置型智能体会主动分析数据，将可执行的营销洞察融入您的日常工作流中。这些智能体会持续分析您的数据，输出有价值的洞察并推荐可执行的优化建议，帮助团队在协作环境中高效开展工作。

## 关于 Agent Hub

每个智能体都能独立完成一项营销工作：分析数据、得出结论，并将结果发送到您的团队工作所在的位置。 Agent Hub 提供多种由 AppsFlyer 构建的预置型智能体，帮助您优化营销活动并发掘增长机会。此外，您还可以自定义智能体，根据您的需求完成工作。所有智能体都会以可靠、透明的方式开展工作，为团队决策提供支持。

## Agent Hub 页面

Agent Hub 页面包含两个选项卡：**我的智能体** 和 &lt;0>活动&lt;0>。您可以通过这两个标签页管理智能体，并查看已完成的运行记录。

使用 **我的智能体** 设置、部署和管理智能体。使用**活动&lt;0>查看已完成的运行结果和历史记录、提交反馈，并通过 AI Assistant 分析智能体的运行逻辑。**

<Accordion title="我的智能体">

**我的智能体** 选项页会显示您当前账户可用的智能体。

您可以在此标签页中：

* 查看可用的智能体。
* 设置并部署智能体。
* 管理已部署的智能体。
* 在智能体卡片中监控最近一次运行状态。

<div id="set-up-an-agent" />

#### 设置智能体

智能体可配置为按计划自动运行，也可手动运行。此外，您还可以配置运行结果的接收渠道，例如 Slack 或电子邮件。

在**我的智能体**选项卡中，您可以直接通过智能体卡片查看最近一次运行的状态。如需查看已完成的输出结果和历史运行记录，请点击 **活动** 标签页。

请按照以下步骤设置并部署智能体。

1. 登入 AppsFlyer。
2. 在左侧菜单中，前往 **Agent Hub**。
3. 在您要设置和部署的智能体中，点击 **部署**。
4. 在下一页面中，配置所需的智能体设置。
5. 根据需要添加您的电子邮件地址或连接 Slack 工作区。
   1. 请确保 Slack 频道已完成设置。[请参阅前提条件](#前提条件和权限)。
6. 选择运行计划（目前基于 UTC 时区，后续将支持更多时区）。
7. 点击 **部署智能体**。

该预置型智能体会显示在 **我的智能体** 下。如需查看可用预置型智能体的完整列表及其各自功能，请参阅下方的 **预置型智能体** 和 **自定义智能体**。

</Accordion>

<Accordion title="活跃数据标签页">

**活动** 选项卡用于查看已完成的智能体运行结果。当您的账号至少有一个智能体已生成输出结果后，系统才会显示此标签页。

您可以通过此标签页查看近期智能体活动、历史输出结果、提交反馈，并向 AI 助手提问，了解某次运行的具体情况。

活跃数据标签页包含以下两个部分：

| 部分 | 描述 |
| --- | --- |
| 近期活动 | 显示每个智能体实例最近一次已完成的运行。 |
| 历史运行记录 | 显示过去 30 天内已完成的运行记录。 |

您可以按以下条件筛选活动：

* 选择应用
* 智能体实例

注意：预置型智能体筛选基于具体的预置型智能体实例，而非预置型智能体类型。

<div id="view-activity-output" />

#### 查看活跃数据输出

查看活跃数据输出的方法：

1. 进入**Agent Hub**.
2. 点击**活动** 标签页。
3. 选择相应的应用或智能体实例筛选条件。
4. 点击某次运行以展开详情。

展开后会显示与通过 Slack 或电子邮件发送的相同输出内容。

在展开后的运行详情中，您可以：

* 复制输出内容。
* 提交正面或负面反馈。
* 添加文字反馈。
* 点击**分析活动** 向 AI 助手提问，分析此次运行。

<div id="analyze-activity-with-ai-assistant" />

#### 使用 AI 助手分析活动

通过 分析活动0> 向 AI 助手提问，分析此次运行。

所有智能体均可使用 **分析活动**。打开后，AI 助手会根据所选运行记录的上下文回答问题，帮助您了解智能体如何得出运行结果、使用了哪些数据，以及考虑或排除了哪些因素。

此功能并非与预置型智能体进行通用对话。 AI助手仅回答与所选运行记录相关的问题。不会执行新的智能体工作、访问此次运行范围之外的数据，也不会进行预测。

如需向 AI 助手提问，请按以下步骤操作：

1. 进入**Agent Hub**.
2. 点击 **活动** 标签页。
3. 点击某次运行以展开详情。
4. 点击 **分析活动**。
5. 选择推荐问题，或输入您自己的问题。

例如，您可以提问：

* 请详细说明你的分析过程。
* 此次分析基于哪些数据？
* 为什么优先展示这一发现？
* 智能体考虑了哪些因素？
* 智能体排除了哪些因素？

<div id="supported-and-unsupported-questions" />

##### 支持与不支持的问题

| 您可以询问 | 您无法询问 |
| --- | --- |
| 智能体如何得出输出结果 | 此次运行未包含的数据 |
| 智能体此次运行使用了哪些数据 | 此次运行未涉及的新分析 |
| 为什么某些发现被优先展示或排除 | 前瞻性预测 |
| 所选运行的上下文和推理过程 | 运行上下文之外的通用优化建议 |

<div id="notes" />

#### 注意

使用活跃数据标签页和分析活跃数据时，请注意以下事项：

* 账号必须启用AI助手。如果 AI 助手已禁用，则无法使用**分析活动**。请参阅 <Anchor target="_blank" href="/marketers/zh/docs/account-settings#agent-hub">账号设置</Anchor>。
* 活跃数据历史仅包含过去 30 天内已完成的运行记录。
* 删除智能体也会删除相关历史活跃数据，包括输出结果、发现和推理数据。此操作无法撤销。
* AI 助手仅回答与所选运行记录相关的问题。它不会执行新的分析、访问权限此次运行之外的数据，也不会做出预测。

</Accordion>

<div id="agent-types" />

## 智能体类型

Agent Hub 包含两类智能体：一类是由您自行配置、用于完成指定任务的自定义智能体，另一类是开箱即用、部署后即可运行的预置型智能体。

<div id="h_01M3PDTFQDFQNMHTWKP23JV1A8" />

<Accordion title="【封闭测试】自定义智能体">

Agent Hub 中的预置智能体负责执行特定的预定义任务，而自定义可以根据您的具体需求执行自定义任务。您只需使用自然语言描述任务、选择 App、审核智能体生成的执行计划，再设置结果的接收方式和发送时间。之后，智能体便会按需或按计划自动完成整个任务流程，并向您发送结果。

自定义智能体可分析数据、执行指定任务，并交付所需结果。结果可以是排名列表、每周表现摘要、根本原因分析、附带依据的建议，或复杂的临时分析。输出形式取决于任务需求。

您可以像向团队中的分析师交代任务一样，用自然语言向智能体说明需求。智能体会先确认对任务的理解，展示执行思路，并解释各项术语的定义。只有在您确认执行计划后，智能体才会开始运行。

<div id="create-a-custom-agent" />

#### 创建自定义智能体

创建过程分为三个步骤：定义任务、审核执行计划，然后配置并部署智能体。

<div id="step-1-define-the-agent" />

##### 步骤 1：定义任务

1. 在 AppsFlyer 中，前往左侧菜单中的 **Agent Hub**。
2. 在“自定义智能体”卡片中，点击**创建**。
3. 在 **选择您的应用**下，选择该应用。每个智能体只能关联一个应用。
4. （可选）设置 **地理位置** 和 **媒体渠道** 筛选条件。如需包含所有地区和媒体渠道，请将这两个字段留空。
5. 在 **任务** 中，描述该任务，或点击现成提示词并根据您的需求进行编辑。
6. 点击**生成计划**。

<div id="step-2-review-the-agent-plan" />

##### 步骤 2：审核智能体计划

智能体会先将您的任务转化为计划，并在运行任何内容之前展示给您。您可以借此确认智能体是否正确理解了任务，以及相关指标和定义是否符合团队的衡量标准。

| 计划部分 | 检查内容 |
| --- | --- |
| 目标 | 用一句话概括任务目标。 |
| 智能体计划 | 智能体将如何执行该任务。 |
| 定义 | 列出任务涉及的所有指标、时间范围和阈值，并明确其定义。例如，“第 7 天留存”的计算方式、“显著下降”的判定标准，以及纳入分析的媒体渠道。请修改与您实际采用的定义不一致的内容。 |
| 筛选条件 | 智能体将应用的 App、地理位置和媒体渠道。 |

审核计划时，您可以：

* **编辑**可更改任意字段，然后点击 **保存更改**。
* **重新开始**返回任务描述页面，重新定义任务。
* **接受计划**确认执行计划并进入下一步。

<div id="step-3-configure-and-deploy" />

##### 步骤 3：配置并部署

1. 输入 **智能体名称**。
2. 在 **选择您希望接收结果的方式** 下，选择 **Slack**、**电子邮件** 或同时选择两者。
   * Slack：如果工作区尚未连接，请点击 **连接到 Slack**，然后选择渠道。
   * 电子邮件：最多可填写 AppsFlyer 用户的五个电子邮件地址。
3. 在**运行计划**下，选择其中一个选项。
4. 点击 **部署智能体**。

计划以 UTC 运行。

部署完成后，该智能体会显示在 **我的智能体** 中。卡片上会显示最近一次运行的状态。您可以在 **活动**中查看已完成的运行记录，并按 App 和智能体名称筛选。

<div id="h_01M3PDTFQESQY349XK0SNH5NB8" />

<Accordion title="自定义智能体使用的数据">

自定义智能体有两个数据来源：事件级数据和汇总数据，智能体会根据任务自动选择数据来源，无需手动指定。对于某些任务，预置型智能体会在一次运行中同时使用这两个来源。在这种少见情况下，同一指标在运行结果的不同部分可能略有差异。如需了解智能体在一次运行期间使用了哪个来源，请使用 **活动** 功能查看该智能体的推理过程。

<strong>事件级数据。</strong>涵盖从用户互动到应用内活动的原始事件数据。与面板不同，自定义智能体可以基于这些数据自定义指标和比率、分析单个用户的行为，并追踪事件发生的先后顺序。

| 数据类别 | 详细说明 |
| --- | --- |
| 互动 | 点击和曝光 |
| 安装和再互动 | 转化 |
| 应用打开 | 应用打开事件 |
| 应用内事件 | 包括应用内购买收入 |
| 维度 | 媒体渠道、广告活动、地理位置（细化到城市）、设备、OS 版本、App 版本、广告、子渠道 ID 以及其他原始事件字段 |
| 数据时间范围 | 最近 30 天 |

**活动和群组数据（汇总）。** My Dashboards 中提供的所有数据点，包括成本。

| 数据类别 | 详细说明 |
| --- | --- |
| 指标 | 安装、转化、首次访问、应用打开、事件次数、唯一用户数、活跃用户数、收入、净收入、每用户平均收入（ARPU）、每唯一用户收入、每唯一用户次数、留存率 |
| 应用内事件、转化、卸载、应用打开 | 次数、唯一用户数、收入、净收入、首次事件次数 |
| 成本指标 | 支出（成本）、eCPI、ROAS、ROI |
| 维度 | 媒体渠道、渠道、广告活动 ID 和名称、广告组 ID 和名称、广告 ID 和名称、站点 ID、代理、关键词、sub\_param\_1、互动/交互类别、类型和目标、统一应用 ID、平台、安装应用商店、应用版本、OS 版本和国家/地区代码（转化）、汇总事件类型（转化、应用打开、应用内、卸载）、事件名称、转化名称及其类型、变现类型、是否归因、是否自然、是否为主要归因、事件日期（仅群组）、事件日期（转化）、转化后的天数、客户币种 |
| 数据时间范围 | 活动为 3 年，群组为 2 年 |

汇总数据以 USD 和您的账户币种显示。群组汇总数据按天细分。

<strong>当前限制。</strong>以下限制为临时限制，随着自定义智能体退出 beta 版，相关能力也会持续完善。

* 互动数据和成本来自不同的数据源。点击和曝光仅存在于事件层级数据中；成本仅存在于汇总数据中。智能体无法将两者关联起来，因此无法返回需要同时使用这两类数据的指标（例如 CPC、CPM、CTR、IPM 和 CPA）。不需要互动数据的成本类指标（支出、eCPI、ROAS、ROI）不受影响，可以正常使用。
* 缺失的数据：受众、SKAdNetwork、SSOT、Protect360、素材和增量分析生成的数据；广告收入和订阅收入（收入仅涵盖应用内购买）。
* 您在数据面板中定义的自定义指标或维度不会纳入分析。
* 对于 platform、sub\_param\_1、互动目标位置、互动类型和来源（organic vs. non-organic）等聚合维度，仅包含自 June 2025 起的数据。
* 无数据时显示 0，而非 N/A。
* 「首次访问」和「再次访问」仅适用于 Web 应用。

<div id="note" />

> 📘 **注意**
>
> 原始事件数据与数据面板数据之间可能会存在差异。事件层级数据（原始数据）与汇总（数据面板）数据的统计结果不一定完全一致；两者之间出现少量差距属于正常情况。同一应用和相同日期范围内，汇总数据应与 My Dashboards 中的数据一致。

</Accordion>

<div id="h_01M3PDTFQEF8ZPV4PP04YGNGBK" />

<Accordion title="如何编写高质量的任务描述">

智能体生成的执行计划取决于您提供的任务描述。请尽可能包含以下适用信息：

1. <strong>任务内容。</strong>用清晰直白的语言说明需要完成什么。建议使用动词：比较、排名、标记、查找、推荐、总结。
2. <strong>时间范围。</strong>设定明确的时间范围，例如「上一个完整周」或「最近 14 天对比之前 14 天」。请勿包含当天的数据，因为当天的数据尚未完整。
3. <strong>分析范围。</strong>说明重要的地理位置、媒体渠道、广告活动或平台。您还可以在任务框上方将地理位置和媒体渠道设为筛选条件。
4. <strong>指标和阈值。</strong>说明您的 KPI 以及定义方式。例如，「较前一周下降超过 10% 即视为显著」，这样智能体就能据此应用规则。
5. <strong>输出形式。</strong>如有要求，请明确说明，例如：「按支出排序的表格」、「包含三项主要发现的简短摘要」或「只标记问题，不需要文字说明」。
6. <strong>任务背景。</strong>用一句话说明任务背景，帮助智能体判断分析重点。

有关设置详情，请参阅上方的**先决条件和权限**。

</Accordion>

<div id="h_01M3PDTFQE6GP95M541FYHG15N" />

<Accordion title="查看并优化运行结果">

已完成的运行会显示在**活动**中，内容与通过 Slack 或电子邮件收到的结果一致。您可以复制运行结果、点赞或点踩、添加文字反馈，还可以打开[分析活动](#使用-ai-助手分析活动)，向 AI 助手询问智能体是如何得出该结果的。

如果某次运行返回空结果或偏离目标，请先阅读推理内容，再修改任务。在[分析活动](#使用-ai-助手分析活动)中，您可以询问智能体使用了哪些数据、为什么会得出该结果，以及计划中需要更改哪些内容。不要在不了解原因的情况下直接重写任务描述，否则可能只是得到另一个错误的结果。了解原因后，再修改执行计划或任务描述，并重新运行智能体。

如果推理结果同样为空，您可能请求了当前尚不存在的数据。请参阅上方的**限制**，调整任务描述后重试。

即用型智能体无需从头配置任务，选择所需的智能体、完成配置即可开始运行，并基于您的数据执行任务。下表概览了各智能体的功能。部署前，请先展开相应部分查看完整详情。

<div id="h_01M3PDTFQET68PRA9CN49CQ8Q7" />

<Accordion title="发现素材优化机会">

**功能：** 找出为您带来最佳表现的素材，并识别哪些渠道尚未投放这些素材。智能体会评估您过去 30 天内所有合作伙伴的素材表现，对优胜素材进行排名，然后逐一检查各渠道是否已投放这些素材。最终提供具体的投放建议，并附上相关数据依据。

**适用范围：** 过去 30 天内跨合作伙伴的素材层级花费和 ROAS。需启用素材优化。

**运行结果：** 表现最佳的素材及其花费和 ROAS；针对各合作渠道，列出尚未投放的优质素材，并说明建议新增投放的原因。结果通过 Slack 或电子邮件发送。

**运行频率：** 可通过标准运行计划选项配置，也可按需运行。

</Accordion>

<div id="h_01M3PDTFQE2WB2SNWBCS81C2DE" />

<Accordion title="生成效果摘要">

**功能：** 自动生成原本需要手动整理、用于向管理层和相关利益方汇报的效果摘要。智能体会根据您选择的 KPI 分析汇总数据，识别指定周期内的重要趋势、表现突出项和关键变化，并整理成附有建议的摘要，可直接转发。

**适用范围：** 涵盖各个应用、地理位置、媒体渠道等维度的汇总分析数据。无需高级订阅。

**运行结果：**

* 文字摘要：核心亮点、需要关注的问题、重要变化，以及建议的后续步骤。
* My Dashboards 视图，智能体根据您选择的 KPI 自动生成仪表板视图，方便您进一步查看摘要背后的详细数据。

以上两项内容均通过 Slack 或电子邮件发送。

**运行频率：** 可配置。通常选择按周发送。

**设置方式：** 选择应用、要涵盖的 KPI、分组层级，以及任何其他筛选条件（如媒体渠道、地理位置、代理）。

**温馨提示：** 配套的 My Dashboards 视图是临时生成的 AI 视图，可在 **My Dashboards** > **AI generated** 下中查看。每次 运行后，系统都会用最新数据覆盖该视图；如果未保存，视图将在 30 天后删除。

</Accordion>

<div id="h_01M3PDTFQEB9MKH44X5XX4AGDT" />

<Accordion title="深度研究分析">

**功能：** 每周运行一次调查，分析 发生了哪些变化及其原因。智能体会在每周一对比最近两个完整自然周（周一至周日）的数据，并深入分析各合作渠道、地区、操作系统版本和 SDK 版本的原始事件级数据，发现汇总仪表板无法呈现的变化，包括可能被误认为效果波动的配置问题。

**适用范围：** 已充分积累、适合分析的原始事件级 数据。智能体会刻意排除当前周， 以避免使用不完整或尚未成熟的数据。例如，在周一， 1 月 26 日，它会将 1 月 12–18 日与 1 月 5–11 日进行比较。无需高级版订阅。

**运行结果：** 一份文字报告，说明每周环比变化中的重要发现、变化原因，以及分析过程中发现的配置问题。结果通过 Slack 或电子邮件发送。结果通过 Slack 或电子邮件发送。

**运行频率：** 每周一运行，或按需运行。

</Accordion>

<div id="h_01M3PDTFQEPFMS38RWXT923VX7" />

<Accordion title="检测效果异常">

**功能：** 每天监控您的关键 KPI， 并在出现不应发生的变动时通知您。 智能体会将每项指标与其预期范围进行比较，标记显著的正向或负向异常，并说明发生了什么变化以及变化出现在哪里：某个渠道的 CPI 飙升、某个地理位置的 IPM 下降，或某个广告活动出现断崖式下滑。

**分析数据：** 覆盖渠道、广告系列和地理位置的每日 KPI 数据。无需高级版订阅。

**运行结果：以事件说明形式呈现的异常提醒，指出发生变化的指标、变化幅度、涉及的合作渠道、广告系列或地区，以及可能的原因。结果通过 Slack 或电子邮件发送。没有异常的日期不会发送提醒。[确认]**

**运行频率：** 可通过标准运行计划选项配置，也可按需运行。

</Accordion>

<div id="h_01M3PDTFQEFHYR29GN1XMRM16N" />

<Accordion title="检测配置问题">

**功能：** 检查归因和衡量配置，及时发现可能影响数据质量的问题。 智能体会检查 SKAdNetwork 和 Cost 对接是否处于非活跃状态、是否通过概率建模关闭了展示归因，以及其他配置问题，帮助您在这些问题影响广告系列效果分析之前及时处理。

**适用范围：** 各应用和合作渠道的对接状态及配置状态。无需高级版订阅。

**运行结果：** 提醒中会列出 发现的每个问题、其所在位置以及修复方法。 结果通过 Slack 或电子邮件发送。

**运行频率：** 可通过标准 调度选项配置，或按需运行。

</Accordion>

<div id="h_01M3PDTFQEP6E7D4TF5G4PX1KV" />

<Accordion title="监控应用版本发布">

**功能：** 让您无需等待开发团队， 也能及时了解自有应用的发布情况。智能体 会监控 iOS 和 Android 应用商店中的应用发布，在某个版本上线时提醒您，追踪发布进度，并 标出与营销相关的变化：新功能、 应用内行为变化，以及新增或移除的事件。 借助这些信息，您可以根据应用的实际功能和事件配置调整用户获取（UA）广告系列。

**适用范围：** 自有应用的应用商店版本发布数据及应用内事件定义。无需高级订阅。

**运行结果：** 版本发布提醒，包含版本、分阶段发布状态以及与营销相关的变更摘要。结果通过 Slack 或电子邮件发送。

**运行频率：** 可通过标准计划选项配置，或按需执行。

**适用范围：** Protect360 数据。需要 Protect360 和 Protect360 封闭 beta 功能。

**功能：** 检查网页端应用的事件采集情况，以及转化归因到营销来源的方式。 该报告会显示哪些方面运行良好，标记可能导致归因不准确的问题，并针对您的实施提供改进建议。

**适用范围：** 您所选的网页端应用的归因设置，以及近期的 SDK 或服务器到服务器数据。检查范围包括数据收集、事件和收入、广告活动链接、referrer、身份以及跨平台设置。默认分析窗口为七天。

## 常见问题

<Accordion title="我可以创建自己的预置型智能体吗？">

可以。您可以借助自定义智能体按照您的需求完成的任务。请参阅上方的 [**自定义智能体**](#h_01M3PDTFQDFQNMHTWKP23JV1A8)。

</Accordion>

<Accordion title="Agent Hub 是否适用于所有账号类型？">

不。 Agent Hub 目前仅面向广告主开放。

</Accordion>

<Accordion title="所有用户都可以使用全部智能体吗？">

智能体的可用性取决于您的 AppsFlyer 订阅方案以及是否拥有高级产品访问权限。具体详情请联系您的 CSM。

</Accordion>

<Accordion title="管理员可以为账号停用 Agent Hub 吗？">

可以。管理员可以在 Account settings > AI capabilities 中管理 Agent Hub 的可用状态。

默认情况下，账号已启用 Agent Hub。

如果管理员停用 Agent Hub：

* 所有用户都将无法访问 Agent Hub。
* 所有现有智能体都会被永久删除，且无法恢复。
* 所有正在运行的智能体任务都会停止。

如果管理员之后重新启用 Agent Hub，用户可以再次访问，但需要从头创建并部署智能体。

如需了解更多信息，请参阅 <Anchor target="_blank" href="/marketers/zh/docs/account-settings#agent-hub">账户设置</Anchor>。

</Accordion>

<Accordion title="可以通过哪些渠道接收通知？">

您可以通过 email 或 Slack 接收通知。如需接收 email 通知，您必须在通知中心订阅 AI 功能通知。

</Accordion>

<Accordion title="为什么我没有收到 Agent Hub 的电子邮件通知？">

如果您已完成接收电子邮件通知所需的设置，但仍未收到 Agent Hub 的邮件，可能是因为您之前取消订阅了 AppsFlyer 的电子邮件。请联系AppsFlyer支持团队获取帮助。

</Accordion>

<Accordion title="AppsFlyer 会使用我的数据训练 AI 模型吗？">

不会。 AppsFlyer 不会使用您的数据训练任何 AI 模型。 AI 可能会生成不准确或不完整的结果请在采取行动前仔细核查。

</Accordion>
