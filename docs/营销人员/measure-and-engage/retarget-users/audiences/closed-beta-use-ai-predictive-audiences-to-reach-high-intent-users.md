## 关于预测受众

作为 AppsFlyer <Anchor target="_blank" href="/marketers/zh/docs/audiences-guide">Audiences</Anchor> 的一部分，“预测受众”功能可帮助您创建由人工智能驱动的受众群体，这些用户最有可能采取关键行动。利用该功能预测未来7天内最有可能购买的用户，从而将营销活动聚焦于购买意愿强烈的用户，从而提升营销活动效率。

您可以调整意向范围，从而创建一个意向更强烈的精确定众，或一个覆盖面更广的受众群体，然后将该受众与合作伙伴对接以进行营销激活。受众创建完成后，系统会每天更新，并自动持续推送给您关联的合作伙伴。

<div id="create-a-predictive-audience" />

## 创建预测受众

<div id="prerequisites" />

### 前期准备

要开始使用“预测受众”功能，请按照以下步骤操作：

* **前提条件：** AppsFlyer <Anchor target="_blank" href="/marketers/zh/docs/audiences-guide">Audiences</Anchor> 订阅服务。“预测受众”功能目前处于测试阶段，需按账户逐一启用。如需获取访问权限，请联系您的客户成功经理。

<div id="step-1-define-the-goal" />

<Accordion title="第1步：明确目标">

在此步骤中，您需要通过选择应用、目标事件和受众的预测目标，来定义希望“预测受众”预测的内容。

**目标定义：**

1. 点击 AppsFlyer 侧边菜单中的 **“互动”>“受众**”，即可访问受众数据。
2. 在 **“受众**”中，点击 **“新建预测受众”**。
3. 输入受众名称 。

   [<Image alt="定义目标（已输入的数值）.png" src="https://files.readme.io/9dd260c4552be231e2f313db451d92501b6090664e6f7010c660357f9af71efb-45796747476497.png" width="1666px" />](https://files.readme.io/9dd260c4552be231e2f313db451d92501b6090664e6f7010c660357f9af71efb-45796747476497.png)
4. 选择应用
5. 选择目标事件。
6. 选择一个预测目标（**“可能购买**”）。
7. 点击**继续**，进入下一步。

</Accordion>

<div id="step-2-set-the-probability-range" />

<Accordion title="第2步：设置概率范围">

在此步骤中，您需要设置概率范围，以平衡精度和覆盖率。更高的最低门槛会形成规模较小但购买意愿更强的受众群体，而较低的最低门槛则能在保持高效果的同时扩大覆盖范围。

您可以选择系统推荐的预设，或拖动图表标记来自定义范围。随着您进行调整，预估受众规模会实时更新，这有助于您了解规模与转化概率之间的权衡关系。

**要设置概率范围：**

1. 选择一个预设（**高意向**、**平衡**或**最大覆盖范围**）来设置默认范围。我们建议选择 **“平衡”模式**。

**或**

2. 要自定义范围，请拖动图表上的最小值和最大值标记。

   <Image alt="设置概率范围 正确版本.png" src="https://files.readme.io/8dd9b6368d86e5641e99e7fe66e137b1137adf8fdf7760d597826f7c2d5be745-45796825322385.png" width="1898px" />

   **预计受众规模**会根据您的选择实时更新。

<div id="compare-audiences-optional" />

#### 比较受众（可选）：

“比较受众”是一项可选功能，可让您将预测受众与一个或多个现有受众进行比较。它允许您对比各项关键绩效指标（KPI）的表现，例如广告投资回报率（ROAS）和转化率。您可以选择任意受众群体进行对比；但目前仅提供与 Facebook、TikTok、Google 或 Snap 关联的广告系列的表现数据。

</Accordion>

<div id="step-3-connect-to-partners" />

<Accordion title="第3步：连接到渠道">

在此步骤中，您需要将预测受众与合作伙伴关联，以便在创建时即可激活并上传。

**为了与合作伙伴建立联系并激活受众：**

1. 选择现有的合作伙伴连接，或添加新的连接。

   连接到渠道
2. 请在右侧的“**摘要**”中查看您的选择。
3. 点击 **“连接”并完成**。

您的首个预测受众将在24小时内准备就绪，并自动与您的合作伙伴同步。

创建完成后，您的新预测受众将显示在 **“受众**”表格中。

</Accordion>

<div id="traits-and-limitations" />

## 特点与局限性

| 特点 | 描述 |
| --- | --- |
| 可用性 | 该测试版功能需按账户启用，并需要用户明确同意。目前仅适用于电子商务应用。 |
| 预测窗口 | 预测7天内购买的可能性。 |
| 针对不同受众，各有一款应用 | 不支持多应用预测受众。 |
| 基于资格的筛选与数据限制 | 只有符合条件且拥有最低数据量的应用和活动才会显示在下拉菜单中（例如，过去30天内有1000名活跃用户）。 |
| 数据保护 | 您的受众数据可能会被处理，以支持基于人工智能的受众功能。您的账户数据绝不会被分享，仅用于改进内部模型和预测。 |
| 每日刷新 | 受众数据每天都会更新并上传给合作伙伴。 |
