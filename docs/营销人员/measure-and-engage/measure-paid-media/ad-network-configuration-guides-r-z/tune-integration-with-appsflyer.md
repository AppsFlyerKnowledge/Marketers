**<span id="setting-up-tune-integration"></span>前期准备：** 设置对接前，请务必先<Anchor target="_blank" href="/marketers/zh/docs/partner-integrations#联系相关渠道">联系相关渠道</Anchor>并在其平台上开设账户。

**请按以下方式启用或修改该对接：**

1. **启用方式：** 从AppsFlyer的侧边栏中选择**协作** > **Partner Marketplace**。  
   **修改方式**：从AppsFlyer的侧边栏中选择协作 > **活跃对接**。
2. 搜索并选择相关渠道。
3. 点击**设置对接**。 界面会跳转到对接设置页。
4. 在渠道对接选项卡中，打开**启用该渠道**开关。  
   **请注意： 在您与该渠道合作期间，请确保该开关总是处于打开（即启用）状态。**
5. 参考下文说明，根据您的具体需求在相关选项卡中完成各项配置。
6. 点击保存对接。
