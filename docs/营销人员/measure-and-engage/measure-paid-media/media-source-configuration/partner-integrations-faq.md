## Partner Marketplace平台的使用方法

<div id="what-information-can-i-see-on-a-partner-card-without-entering-the-page" />

<Accordion title="如果不进入渠道页面，可以从渠道卡片上看到哪些信息？">

渠道卡片能帮助您快速评估渠道的适配度，省去进入页面查看详情的麻烦。您可以在<Anchor target="_blank" href="/marketers/zh/docs/partner-integrations#渠道简介卡片">渠道卡片</Anchor>中看到以下信息：

* 该渠道支持的三大主要功能
* 渠道投放效果——仅限在AppsFlyer中有流量数据的渠道。点击该链接后即可进入渠道投放效果表，查看其真实的效果数据。
* 媒体平台类型
* 对接状态（<Anchor target="_blank" href="/marketers/zh/docs/partner-activation-deactivation?query=activate">活跃</Anchor>时会显示）

</Accordion>

<div id="how-do-i-use-filters-with-a-search-query" />

<Accordion title="搜索渠道时如何使用筛选条件？">

进入Partner Marketplace平台时，页面会根据您应用的使用情况（行业及地区）使用默认的筛选条件。您可以清除或更改这些条件，之后也可以恢复到默认设置。

| 所需结果 | 使用方式 |
| --- | --- |
| 结合关键词和筛选条件的搜索结果 | 建议先使用搜索栏，然后再使用筛选条件对搜索结果进行筛选。 |
| 清除原先的删选条件，但保留关键词 | 点击清除所有（在搜索栏下方） |
| 恢复默认的筛选条件，同时保留关键词 | 点击恢复默认（在搜索栏下方） |
| 重置搜索，包括结合了筛选条件和关键词的搜索结果 | <ul><li>点击搜索栏中的**X**</li><li>点击左上角的**Partner Marketplace**图标</li></ul> |

> 📘 **注意**
>
> * AppsFlyer会自动保存您上一次的选择，在同一台设备上再次搜索渠道时会沿用上一次的设置。
> * 详情请见<Anchor target="_blank" href="/marketers/zh/docs/partner-integrations?query=marketplace#filters">各筛选条件说明</Anchor>

</Accordion>

<div id="with-the-new-marketplace-how-do-i-integrate-with-new-partners" />

<Accordion title="如何通过Partner Marketplace平台对接新的渠道？">

如需进行对接设置，请前往**活跃对接渠道**设置页；如需搜寻并联络新的合作渠道，请前往Partner Marketplace平台。Partner Marketplace平台会根据您的行业分区展示渠道，同时呈现其投放效果水平，并提供更全面的筛选功能，便于您快速找到最合适的渠道。

详情请见<Anchor target="_blank" href="/marketers/zh/docs/partner-integrations?query=marketplace#integrate-with-a-new-partner">通过Partner Marketplace平台对接新渠道</Anchor>的说明文档。

</Accordion>

## 问题排查

<div id="if-i-see-an-interesting-partner-without-any-contact-details-what-should-i-do" />

<Accordion title="如果我感兴趣的渠道没有提供联系信息怎么办？">

我们正在尽力确保所有渠道都带有联系信息，如果仍有缺失，请联系您的AppsFlyer客户经理。

</Accordion>
