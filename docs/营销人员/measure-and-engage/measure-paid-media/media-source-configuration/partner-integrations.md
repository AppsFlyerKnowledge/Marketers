> **概要**：针对您所在的垂类探索业务对口的媒体渠道和平台，了解其服务内容和投放效果，与其取得联系并进行对接，这些工作都可以直接在Partner Marketplace渠道平台中完成。

## 速览

Partner Marketplace为您呈现已与AppsFlyer对接的渠道，其中囊括了各种不同的渠道类型，如广告平台、营销合作伙伴、代理、分析平台、邮件营销服务商（ESP）等等，总量超过一万家。这些媒体渠道和平台分别有自己专攻的垂类和地区。在这个Marketplace中，您不仅可以**找到您不熟悉的渠道**并查看其业务表现，还可以探索并发掘其他垂类中的新兴服务，推动您的业务发展壮大、与时俱进。

您可以通过Partner Marketplace[访问您现有的渠道对接](/docs/partner-integrations#管理现有对接)，并在现有对接中添加其他应用。

> 📘 **注意**
>
> Partner Marketplace现已对广告主开放，但尚不支持代理和渠道访问。

## 快速入门

探索Partner Marketplace渠道平台，发掘新商机、联手新渠道。

**Partner Marketplace平台的使用**

1. **进入Partner Marketplace：** 从AppsFlyer后台的侧边栏中选择**协作** > **Partner Marketplace**。
2. [**发掘合作渠道**](/docs/partner-integrations#发掘合作渠道)
3. [**查看渠道详情**](/docs/partner-integrations#深入了解具体渠道)：选择一个渠道，进入渠道详情页。
4. [**与该渠道对接**](/docs/partner-integrations#对接新渠道)

### 探索Partner Marketplace平台

为了便于您找到最贴合您需求的渠道，该页面会根据您所在的垂类将渠道分别呈现在不同板块中。使用场景示例:

* **推荐渠道：** 增长率、留存率和应用内购买率较高的渠道。
* [**数据净室（DCR）合作平台：**](#dcr合作平台)提供第一方和第三方数据的技术合作平台，您可以利用这些平台扩充您的数据并优化投放效果。
* **受同类广告主欢迎的渠道：** 在您的主要垂类中活跃对接数量最多的渠道。
* **上次浏览的渠道：** 您最近在Marketplace平台上浏览过的渠道。

#### 渠道简介卡片

<Image align="center" alt="google_meta.png" src="https://support.appsflyer.com/hc/article_attachments/30603947722129" />

您可以在渠道简介卡片中快速了解关于渠道服务的基础信息。

* **活跃**状态图标——用于标记活跃对接渠道
* 公司名称以及该渠道获得的**质量徽章**（我们会向达到特定质量标准的渠道授予质量徽章，具体请见[下文](/docs/partner-integrations#渠道页面)说明）或[**DCR合作平台**](#dcr合作平台)标识。
* 媒体平台类型
* [**为我牵线**](/docs/partner-integrations#联系相关渠道)
* **应用对接：** 过去30天中，该渠道下产生流量的应用对接数量
* **页面浏览量：** 该广告平台的详情页在最近30天内的浏览数量
* **设置**图标——会出现在对接渠道中

#### DCR合作平台

DCR合作平台是指提供第一方和第三方数据的技术平台。<Anchor target="_blank" href="/marketers/zh/docs/data-clean-room-data-enrichment-through-tech-partner-integrations">AppsFlyer的数据净室（DCR）</Anchor>可将DCR合作平台提供的用户级别数据匹配到广告主的用户级别数据，将两者合并后实现相关数据的扩充。AppsFlyer可使用这些数据创建汇总报告，帮助您得出汇总的数据分析信息，在保障用户隐私的前提下优化投放效果。

**请注意：** 如果您还没有<Anchor target="_blank" href="/marketers/zh/docs/data-clean-room-overview">DCR</Anchor>套餐，可以通过相关渠道页面提交DCR申请。

### 筛选渠道列表

您可以使用页面顶部的一系列筛选条件，找到符合您要求的渠道。进入Partner Marketplace时，页面会根据相关应用的活跃情况（即其所在的垂类及地区）使用默认的筛选条件。AppsFlyer会自动保存您上一次的选择，在同一台设备上再次搜索渠道时会沿用上一次的设置。下表列出了可用的筛选条件及其细化搜索结果的方式：

| 筛选条件 | 说明 |
| --- | --- |
| <span id="category-subcategorysubsubcategory"></span>垂类、细分垂类、  <br />次级细分垂类 | 按垂类（由渠道定义）筛选渠道。点击相关字段，查看垂类、细分垂类和次级细分垂类列表。 |
| <span id="target-region"></span>目标地区 | 根据选定地区的活跃情况筛选渠道。 |
| <span id="target-geos"></span>目标国家 | 筛选出主要活跃于选定国家的渠道。 |
| <span id="supported-capabilities"></span>适用功能 | 按渠道支持的功能进行筛选，如投放优化或A/B测试等。这些功能由渠道定义。 |
| <span id="supported-platforms"></span>适配平台 | 筛选出支持指定平台的渠道，如iOS或安卓（由渠道定义）。 |
| <span id="pricing-model"></span>价格模型 | 筛选出支持指定定价模式的渠道（由渠道定义）。 |
| <span id="ad-type"></span>广告样式 | 筛选出支持指定广告样式的渠道（由渠道定义）。 |
| <span id="supported-features"></span>支持的功能 | 根据[适用于相关对接的功能](#filter-by-supported-features)筛选渠道。 |
| <span id="appsflyer-performance-index"></span>AppsFlyer《广告平台综合表现报告》排名 | 勾选该选项后，界面仅显示在最新一期AppsFlyer《广告平台综合表现报告》中排到名次的渠道。 |
| <span id="high-quality-traffic"></span>优质流量 | 勾选该选项后，界面仅显示获得了低作弊率徽章的渠道（根据近一个月的流量进行评估）。 |

> 📘 **注意**
>
> 使用搜索栏时，之前用到的筛选条件不会对搜索结果生效。如需同时使用搜索和筛选功能，请先进行搜索，并在页面显示搜索结果后设置筛选条件。

## 深入了解具体渠道

您可以通过渠道详情页进一步了解相关渠道，并与其取得联系。点击[渠道简介卡片](/docs/partner-integrations#渠道简介卡片)后即可看到渠道详情页。

### 渠道页面

您可以在渠道页面中完成以下操作：

* [联系相关渠道](#联系相关渠道)
* [设置新对接](/docs/partner-integrations#对接新渠道)
* [管理现有对接](/docs/partner-integrations#管理现有对接)

您可以在渠道页面中看到以下信息：

* 渠道达到特定质量标准后，会相应地获得以下徽章：
  * **《广告平台综合表现报告》排名**：点击该徽章后会进入该渠道的排名信息部分（位于页面底部）。仅当相关渠道在最新一期的《广告平台综合表现报告》中排到名次时，其页面中才会呈现排名信息。
  * **优质流量**徽章：表示该渠道近几个月的流量中作弊率非常低。
* **应用对接：** 过去30天中，该渠道下产生流量的应用对接数量
* **页面浏览量：** 该广告平台的详情页在最近30天内的浏览数量
* **适用功能：** 该渠道支持的[AppsFlyer对接](#filter-by-supported-features)功能。
* **渠道表现：** 这部分会呈现相关[渠道在各方面的表现](/docs/partner-integrations#渠道表现)，用以说明其质量水平。
* 您所在垂类中，浏览过该渠道的广告主同时还查看过的其他渠道
* **渠道详情：** 由该渠道提供的信息，包括其服务内容、适用功能、服务条款等。
* **对接数据净室（**<Anchor target="_blank" href="/marketers/zh/docs/data-clean-room-overview">**DCR**</Anchor>**）合作平台：** 将您的DCR与相关平台的数据源相连接，用于扩充您的数据并优化投放效果。  
  **请注意：** 如果您还没有<Anchor target="_blank" href="/marketers/zh/docs/data-clean-room-overview">DCR</Anchor>套餐，可以通过相关渠道页面提交DCR申请。

> 📘 **注意**
>
> * 点击左上角的**AppsFlyer图标**后，界面回到您在AppsFlyer平台中最近一次访问的页面。
> * 点击左上角的**Marketplace图标**后，界面回到您在Partner Marketplace中最近一次访问的页面。

#### 联系相关渠道

AppsFlyer可以代您向相关渠道发送介绍函，帮助您与其取得联系。您可以在发送介绍函之前查看其文本内容。

1. 在渠道详情页中点击**为我牵线**。
2. 【可选】将鼠标悬停在**查看完整的电子邮件文本**上，即可看到介绍函的完整内容。
3. 点击**发送简短介绍**。

> 📘 **注意**
>
> * 渠道提供相关联系信息后，界面中才会显示**为我牵线**按钮
> * 部分渠道更希望广告主通过落地页与其联系。这时页面会显示**联系渠道**按钮，而不是**为我牵线**。

#### 渠道表现

<Image align="center" alt="Partner performance page.png" src="https://support.appsflyer.com/hc/article_attachments/30603976126097" />

为了便于广告主判断是否要与某个具体渠道对接，我们会在这部分展示该渠道在各个方面的投放效果指标，以说明其质量水平。

**活跃渠道**

这部分会根据下列标准说明相关渠道的服务级别。

* **平均活跃生命周期：** 广告主在选定渠道中活跃投放广告的平均周期。此指标衡量最近至少12个月内的数据，且仅取流量时间净值。
* **广告主留存率：** 过去一年与该渠道合作的广告主中，在当天仍处于活跃投放状态的广告主比例。

**分国家和垂类的转化率**

* **显示热门国家/地区和垂类：** 默认显示相关渠道的前10个最热门（投放最多）国家/地区和垂类，按激活量排序。使用该板块右上方的渠道表现作为筛选条件时，则会根据选定条件显示排序结果。
* **分垂类及国家的转化率：** 显示选定垂类和国家中的再营销/用户获取率细分情况。

默认图表显示该渠道较为活跃的前10个垂类和国家，覆盖所有平台。您可以使用右上角的筛选条件更改该默认设置，最多可选择10个其他的国家或垂类，以及任何可用平台。

## 对接新渠道

[发现合适的新渠道](/docs/partner-integrations#发掘合作渠道)并了解[其综合表现](/docs/partner-integrations#深入了解具体渠道)后，您可以着手设置对接。  您将相关应用对接到这些渠道之后，就可以在您的面板中看到非自然数据。

> 📘 **注意**
>
> 设置对接前，请务必先联系相关渠道并在其平台上开设账户。

**请按以下方式设置新渠道的对接：**

1. 从AppsFlyer后台的侧边栏中选择**协作** > **Partner Marketplace**。
2. 搜索并选择相关渠道。 您会跳转到对应的[渠道详情页面](/docs/partner-integrations#渠道页面)。
3. 点击**设置对接**，界面会跳转到对接设置页。
4. 打开**启用该渠道**开关，并<Anchor target="_blank" href="/marketers/zh/docs/set-up-an-integrated-partner">完成相关的对接配置</Anchor>。

对接配置完毕后，该渠道就会变成<Anchor target="_blank" href="/marketers/zh/docs/partner-activation-deactivation#active-partners">活跃</Anchor>对接渠道。您可以点击**分板块显示活跃渠道**，仅查看活跃对接渠道。

### 在AppsFlyer中添加新的对接渠道

如果您使用的广告平台还未与AppsFlyer对接，您可以向他们发送邀请链接。

<div id="note-3" />

<div id="validation-period-for-new-integrations" />

#### 新增平台的验证期

在Partner Marketplace中添加新的广告平台对接时，相关平台需要先通过AppsFlyer的验证。该验证期最多可持续60天，在此期间，AppsFlyer会评估其流量质量。

> 📘 **注意**
>
> * 仅账号<Anchor target="_blank" href="/marketers/zh/docs/user-management#在appsflyer中添加新的对接渠道">管理员</Anchor>可通过邀请链接邀请新的渠道。
> * 该选项对购买了Growth和Enterprise<Anchor target="_blank" href="/marketers/zh/docs/account-management-plans-payments-and-billing#appsflyer-plans">套餐</Anchor>的客户开放。

**请按以下步骤邀请新渠道与AppsFlyer进行对接：**

1. 从AppsFlyer后台的侧边栏中选择**协作** > **Partner Marketplace**。
2. 点击Partner Marketplace页面右上角的三个竖点图标，并选择**邀请新渠道**。   
   <Image align="center" alt="invite_new_partner.png" src="https://support.appsflyer.com/hc/article_attachments/30603976129297" />
3. 输入渠道名称和对应的邮箱地址。  
   该渠道会收到一封带有注册链接的邮件，他们可以使用该链接进行注册。

## 管理现有对接

您可以管理现有的<Anchor target="_blank" href="/marketers/zh/docs/partner-activation-deactivation#active-partners">活跃</Anchor>对接，并<Anchor target="_blank" href="/marketers/zh/docs/set-up-an-integrated-partner#i-connect-more-apps-optional">将其他应用也对接到相关渠道</Anchor>。您可以通过以下各种方式进入当前选定应用的<Anchor target="_blank" href="/marketers/zh/docs/set-up-an-integrated-partner">对接设置</Anchor>页面：

* 从AppsFlyer后台左侧的菜单栏中选择**协作** > **活跃对接**。
* 进入**活跃对接**部分或Marketplace中的页面（见下文说明），选择相关[渠道简介卡片](/docs/partner-integrations#渠道简介卡片)。
* 在Partner Marketplace的搜索栏中搜索某个渠道时，点击对接渠道旁显示的<Image alt="manage_integration_cogwheel.png" src="https://support.appsflyer.com/hc/article_attachments/30603947731089" width="19px" />图标。

### 活跃渠道

您可以通过以下方式找到相关的活跃对接渠道：

* 在Partner Marketplace页面顶部的[**活跃对接**部分](/docs/partner-integrations#活跃对接部分)中查看最近浏览过的渠道
* 您可以按以下方式[查看所有的活跃对接渠道](/docs/partner-integrations#活跃对接页面)：进入**活跃对接**部分，点击页面中的**全部显示**按钮。
* 使用活跃对接中的搜索栏，通过渠道名称或PID找到相关渠道
* 在Partner Marketplace页面左侧的菜单栏中选择**分板**块**显示活跃渠道**后，界面就会在不同板块中分别呈现相应的活跃渠道，如“热搜”、“推荐”或“热门”

> 📘 **注意**
>
> * 点击渠道简介卡片后会进入渠道配置页。
> * 对于符合质量标准的渠道，当鼠标悬停在其渠道简介卡片时会出现**渠道表现**图标![partner](https://support.appsflyer.com/hc/article_attachments/30603947739793)。点击该图标后就会进入[渠道效果数据表](/docs/partner-integrations#渠道表现)。

#### 活跃对接部分

[![marketplace_active_integrations_section.JPG](https://support.appsflyer.com/hc/article_attachments/30603947742225)](https://support.appsflyer.com/hc/article_attachments/30603947742225)**活跃对接**部分位于Partner Marketplace页面顶部，其中显示当前选定应用下的近期<Anchor target="_blank" href="/marketers/zh/docs/partner-activation-deactivation#active-partners">活跃渠道</Anchor>（即进入Partner Marketplace前最后一次选择的应用）。

点击**查看全部**后，界面会打开**活跃对接**页面，其中显示您所有应用下的活跃对接渠道。

#### 活跃对接页面

<Image align="center" alt="active integratins page.png" src="https://support.appsflyer.com/hc/article_attachments/30603976137617" />

**活跃对接渠道**页面仅呈现您正在使用的所有<Anchor target="_blank" href="/marketers/zh/docs/partner-activation-deactivation">活跃</Anchor>渠道。您可以通过此页面管理现有对接，搜索具体的活跃渠道，并针对尚未连接到当前选定应用的渠道创建新对接。**活跃对接**页面分为以下两个部分；

* **当前选定应用**的活跃对接渠道
* 除了当前选定应用外，**所有其他应用**下的对接活跃渠道

> 📘 **注意**
>
> * **活跃对接**页面中的活跃渠道列表会根据您当前选定的应用而有所变化（即进入Marketplace平台前最后一次选择的应用）。您可以点击左上角的应用图标，选择其他应用，查看与该应用对接的渠道。
> * 该列表按您近三个月的浏览次数对渠道对接进行排序。您也可以将其改成按字母顺序排列。
> * 如果您的部分对接渠道近期不活跃，就会在**活跃对接**页面中看到对应的提示消息。
