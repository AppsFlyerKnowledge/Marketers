| **¿Qué hay de nuevo?** | La configuración de Smart Banner te permite elegir varios tipos de fuentes de medios para la atribución. Ya no están limitados a un solo tipo de URL web-to-app. |
| --- | --- |
| **Fecha de entrada en vigor** | Agosto 25, 2021 |
| **Donde** | Smart Banners - Configuración del grupo de banners |
| **Qué** | **Antes del cambio:** Se admitía un tipo de fuente de medios por grupo de banners. Los usuarios tenían que elegir entre usar los parámetros de atribución del enlace entrante, **O** enlaces entrantes con parámetros UTM, **O** los parámetros de atribución predeterminados (que también se usaban como respaldo). Esto significaba que AppsFlyer buscaba "pid" o “utm\_source” en la URL entrante.<br /><br />**Después del cambio:** Los grupos de banners no están limitados a un solo tipo de fuente de medios. Se pueden configurar para admitir una o varias de las fuentes de medios anteriores. Esto significa que los usuarios pueden elegir entre los parámetros de atribución del enlace entrante **Y/O** los parámetros UTM del enlace entrante **Y/O** los parámetros de atribución predeterminados. Esto ofrece mayor flexibilidad para personalizar el enlace detrás del banner y ofrecer la mejor experiencia Web-to-app al usuario final. |
| **Lo que debes saber** | <ul><li>Si ya tienes Smart Banners y grupos de banners, tu configuración seguirá siendo la misma.</li><li>En los grupos de banners nuevos, la interfaz ha cambiado para permitirte elegir más de una opción de fuente de medios.</li><li>Debes tener integrado el <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2#smart-banners-only">SDK web de Smart Banners</Anchor> actual; esta función no es compatible con el SDK web antiguo (obsoleto).</li></ul>[![](https://files.readme.io/35d3888899ee7d95cb81152ab5a72de5bfcf1df40568b7f2fea00c947658fd42-4406108511633.png)](https://files.readme.io/35d3888899ee7d95cb81152ab5a72de5bfcf1df40568b7f2fea00c947658fd42-4406108511633.png) |
