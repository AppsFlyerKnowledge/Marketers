| **What’s new?** | The **Events**, **Overview**, and **Activity** dashboards are getting deprecated as part of the transition to **My Dashboards** as the main analytics experience.<br /><br />After **June 30, 2026**, these legacy dashboards will no longer be accessible. The same data is available in My Dashboards, with enhanced analytics capabilities, flexible views, custom metrics, advanced filters, and shared or private dashboards. |
| --- | --- |
| **Effective date** | Starting **May 30, 2026**, when you open a legacy dashboard from the **Analyze** tab, a pop up with a link to the corresponding template or view in My Dashboards will appear.<br /><br />Starting **June 30, 2026**, the legacy **Events**, **Overview**, and **Activity** dashboards will no longer be accessible.<br /><br />Your data and saved views will be available in My Dashboards. |
| **Who needs to do it** | All advertisers, agencies, and partners using Events, Overview, and Activity dashboards. |
| **Required actions** | Start using My Dashboards before the deprecation date to make sure your analytics workflows continue without interruption.<br /><br />To get started:<ol><li>Go to **My Dashboards** from the left navigation menu.</li><li>Open the relevant template or view:<ul><li>For Events data, open the **Events** template.</li><li>For Overview data, open the **Performance Analysis** or **Marketing Overview** template.</li><li>For Activity data, open the **Activity** view.</li></ul></li><li>Customize the view using metrics, filters, and groupings.</li><li>Save the configuration as a shared or private view.</li></ol> |
| **What you should know** | My Dashboards provides a more flexible and customizable analytics experience than the legacy dashboards.<br /><br />Key capabilities include:<ul><li>**Unified data:** View user acquisition and retargeting data in one place.</li><li>**Enhanced tables:** Use tables with up to 4 groupings and export up to 100,000 rows to CSV.</li><li>**Dashboard-level filters:** Apply filters across dashboard widgets.</li><li>**Shared and private views:** Share views with your team or keep personal views private.</li><li>**Custom metrics and dimensions:** Create metrics and dimensions that support your business needs.</li><li>**Period comparison:** Compare data to a previous period.</li><li>**Enhanced charts:** Use event widgets, cohort widgets, combo charts, and charts with multiple metrics.</li><li>**Conditional formatting:** Highlight important table data.</li><li>**Metric-based sorting:** Sort table data by the metric that fits your analysis.</li></ul>**<span id="how-to-find-and-add-dashboard-templates"></span>How to find and add [Dashboard templates](/docs/my-dashboards#dashboard-templates)**<ol><li>In My Dashboards, from the left menu, open any dashboard.<br />![](https://files.readme.io/26afca0c0285c01ff9019495cedd752b0dd823f071f58622a963c669fe38653a-46644427745937.png)</li><li>On the Dashboard main page, click the arrow to the right of the Dashboard name.<br />![](https://files.readme.io/046551ea88a85e488eee6e08fef4bf4eff23dcedc461e461732a1f5413fa4c68-46644427750801.png)</li><li>Search for the Dashboard or browse the templates.<br />![](https://files.readme.io/3cce1e11a371d8dc6cc04ef29f8db9ff82781c414ece3ad07ccdbb2da75ea56b-46644506493969.png)</li></ol> |
| Events dashboard replacement | To view Events data in My Dashboards:<ol><li>Go to **My Dashboards**.</li><li>Open the **Events** template.</li></ol>The Events template provides a comprehensive view of in-app event data.<br /><br />The Events template includes:<ul><li>**Events widgets:** View in-app user behavior by dimensions such as media source, geo, and date.</li><li>**Cohort-based event analysis:** Analyze events in a cohort context.</li><li>**Business KPIs:** Build views around revenue events and other custom key performance indicators.</li><li>**My Dashboards capabilities:** Use filters, shared views, CSV export, custom metrics, and up to 4 table groupings.</li></ul> |
| Overview dashboard replacement | To view Overview data in My Dashboards:<ol><li>Go to **My Dashboards**.</li><li>Open one of the following templates:<ul><li>**Performance Analysis**</li><li>**Marketing Overview**</li></ul></li></ol>Existing saved views from the legacy Overview dashboard are being migrated to My Dashboards automatically.<br /><br />The Performance Analysis and Marketing Overview templates include My Dashboards capabilities such as enhanced tables, dashboard-level filters, shared and private views, custom metrics and dimensions, period comparison, enhanced charts, conditional formatting, and metric-based sorting.<br /><br />Existing saved views from the legacy Overview dashboard are being migrated to My Dashboards.<br /><br />After migration is enabled for your account, saved views that haven’t been used within 60 days will be removed. Open and save any views you want to keep. |
| Activity dashboard replacement | To view Activity data in My Dashboards:<ol><li>Go to **My Dashboards**.</li><li>Open the **Activity** view.</li></ol>All Activity data is available in My Dashboards.<br /><br />The Activity view includes:<ul><li>**Metric-based sorting:** Sort table data by a specific metric. Campaigns that exist in Activity, such as campaigns with sessions, are no longer excluded when they have no lifetime value data.</li><li>**Active Users over time:** View Active Users across a date range without averaged calculations.</li><li>**Side-by-side analysis:** View Activity data together with lifetime value and cohort metrics.</li><li>**My Dashboards capabilities:** Use conditional formatting, custom metrics, period comparison, filters, and shared or private views.</li></ul> |
| **<span id="faq"></span>FAQ**| **<span id="will-i-lose-my-data"></span>Will I lose my data?**<br /><br />No. Your data remains available in My Dashboards. The underlying data is the same. Only the analytics interface is changing.<br /><br />**<span id="what-happens-to-my-saved-views-from-the-overview-dashboard"></span>What happens to my saved views from the Overview dashboard?**<br /><br />Existing saved views from the legacy Overview dashboard are being migrated to My Dashboards automatically.<br /><br />After migration is enabled for your account, saved views that haven’t been used within 60 days will be removed. Open and save any views you want to keep.<br /><br />**<span id="can-i-access-the-legacy-dashboards-after-june-30-2026"></span>Can I access the legacy dashboards after June 30, 2026?**<br /><br />No. The legacy Events, Overview, and Activity dashboards will no longer be accessible after **June 30, 2026**.<br /><br />**<span id="what-can-i-do-if-i-need-a-feature-that-isn-t-available-in-my-dashboards"></span>What can I do if I need a feature that isn’t available in My Dashboards?**<br /><br />Contact your CSM or AppsFlyer Support. AppsFlyer continues to improve My Dashboards and uses customer feedback to identify gaps and prioritize improvements.<br /><br />**<span id="where-can-i-learn-more-about-my-dashboards"></span>Where can I learn more about My Dashboards?**<br /><br />See [**My Dashboards**](/docs/my-dashboards). |
