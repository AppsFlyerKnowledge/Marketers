---
title: "Bulletin: Unified data in the Activity dashboard"
excerpt: "Activity metrics in the Activity and Pivot dashboards, as well as the Master API, are now unified to include both UA and retargeting data."
---
| | |
| --- | --- |
| **What's new** | Activity data is unified, meaning all data includes both UA and retargeting data. |
| **Update date** | February 1, 2025 |
| **Where** | Activity and Pivot dashboards, and Master API. |
| **What you need to know** | - Until now, some activity metrics, for example, sessions and DAU, were based on only UA data.<br />- Now, all activity metrics include both UA and retargeting data. **Note**: Only unified view is available; you can't split the data to view only UA or retargeting.<br />- For some ad networks, events previously attributed to UA campaigns may now be attributed to retargeting campaigns. <br />- Metrics such as DAU and MAU may increase due to this change, as retargeting traffic is now included in the calculations.<br />- For data from before February 1, 2025, the following metrics include only UA traffic data:<br />  - In Activity dashboard:<br />    - Total sessions<br />    - DAU<br />    - MAU<br />    - DAU/MAU<br />    - ARPDAU<br />    - Cost<br />    - Clicks<br />    - Impressions<br />    - Conversion rate<br />    - eCPI<br />  - In Pivot dashboards and Master API: Activity KPIs |
