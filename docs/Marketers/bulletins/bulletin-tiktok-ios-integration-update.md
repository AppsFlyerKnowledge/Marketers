title: "Bulletin: TikTok iOS integration update"
excerpt: "AppsFlyer is updating the privacy configuration for the TikTok iOS integration, replacing the Advanced Privacy toggle with Advanced Data Sharing."
---
| Section | Details |
| --- | --- |
| **What's new** | AppsFlyer is updating the privacy configuration for the Advanced Self-Reporting Network (SRN) integration with TikTok for iOS. Here's what's changing:<br /><br />* The existing **Advanced Privacy (AP)** toggle is being replaced by a new **Advanced Data Sharing (ADS)** toggle, bringing TikTok in line with other SRN integrations in AppsFlyer.<br />* With this change, AppsFlyer will share all conversion events with TikTok regardless of whether an Advertising ID (IDFA) is available.<br /><br />This means more of your iOS conversions get attributed, and TikTok can optimize your campaigns against a more complete picture of performance. |
| **Effective date** | June 23, 2026 |
| **What you need to know** | Your settings will be migrated automatically — no action is required. Here's how your current configuration maps to the new toggle:<br /><br />* If **Advanced Privacy** is currently **OFF** → **Advanced Data Sharing** will be set to **ON**<br />* If **Advanced Privacy** is currently **ON** → **Advanced Data Sharing** will be set to **OFF** |
