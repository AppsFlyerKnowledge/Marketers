## Search

| **What's new** | Get Meta ads campaign raw data of ads that direct to Google Play Store using the Install Referrer. |
| --- | --- |
| **What's changing**<br>**![Information_icon.png](https://files.readme.io/cc1ff74668360a2be64ec90db8f771d751b0a95847ecaee582c2e31c60e310cf-20445036062993.png)** | Starting October 29, 2021, user-level attribution data (raw data) of users brought by Meta ads **after** this date are restricted. Meta ads makes this data available to MMPs like AppsFlyer, but not to advertisers.<br>However, if the ad directs users to Google Play Store, attribution fields are available to advertisers in the Google Install Referrer which must be [integrated into your app.](https://support.appsflyer.com/hc/articles/207032066#attribute-apps-published-on-google-play) The fields provided via the referrer populate AppsFlyer raw data reports available to you and enable AppsFlyer to attribute users who don't have an advertising ID (LAT-enabled).<br>Using the referrer mechanism requires AppsFlyer SDK V5.4+<br>**Note:** Referrer data has priority over data provided by API and isn't restricted. <br>Data in the referrer is encrypted by Meta ads and is decrypted using a key available to you in your Meta ads developer account. You must provide us with the decryption key described in the actions required row. <br>**Campaign attribution fields available via the referrer:**<br>- Ad ID<br>- Ad name<br>- Adset ID<br>- Adset name<br>- Campaign ID<br>- Campaign name<br>- Account ID<br>- Channel<br>- Ad type (this field is not yet available)<br>**Note**:  <br>- No other fields are available via the referrer.<br>- This solution applies to click-through attribution and not view-through attribution.<br>- Referrer data isn't applicable to re-engagement campaigns, as users don't go through the store.<br>**When will AppsFlyer roll out this change?**<br>- Starting October 29, 2021:<br>  - Meta ads restrictions to click-through data (in other words attribution raw data) are implemented.<br>  - Advertisers can update the referrer decryption key in AppsFlyer.<br>- Starting November 3, 2021:<br>  - AppsFlyer populates raw data and attributes using data provided by the referrer mechanism. |
| **Data availability summary** | | How attributed | Attribution data source | Data available to advertisers | Remarks |<br>--- | --- | --- | --- |<br>Raw data | Aggregate data |  |<br>Click-through | Referrer (applies to Android apps downloaded from Google Play Store) | Available | Available | - LAT users attribution data available.<br>- Referrer takes priority over MMP data if both are available.<br>- Not applicable to re-engagement campaigns. |<br>Click-through | MMP API | Restricted\* | Available |  |<br>View-through | MMP API | Restricted\* | Available | Referrer mechanism not supported. |<br>**Note:** When data availability is restricted:<br>- Install and in-app event postbacks are sent to the restricting ad networks only. Third-party partners, such as analytics partners, don't get postbacks for restricted attribution. <br>- Unattributed postbacks (not containing attribution fields) are sent to ad networks that were configured to receive all events (including organic and unattributed). This includes Meta campaign management partners. |
| **Action required** | **To get your decryption key from Meta ads:**<br>[The following information is based on information provided to us by Facebook]<br>1. Log in to your Meta developer portal.<br>2. Navigate to **My Apps** in the upper right-hand corner.<br>3. Select the app for which you would like to access your decryption key.<br>4. Navigate to **Settings** \> **Basic** on the left-hand side of the page.<br>   <br>   ![FBUIforKey.png](https://files.readme.io/7581629ac17217154300bc796fd54416c1b04c08353b21ae7b93662fe182f694-4409669308049.png)<br>   <br>5. Scroll down to the **Android** section and you will see your decryption key labeled **Install Referrer decryption key** underneath the **Package Names** field. **Note**: This is the same section in which you configured your package name and the Google Play Store.<br>**To enable the referrer mechanism in AppsFlyer.**<br>1. [Mandatory] Verify that AppsFlyer SDK V5.4+ is adopted in your app. Don't rely on earlier versions. <br>2. Do one of the following:<br>   1. [Coming soon] Set the decryption key via API.<br>   2. To set the decryption key via the user interface: <br>      1. In AppsFlyer, go to **Configuration** \> **Active Integrations**.<br>      2. Select Meta ads.<br>         <br>         <br>         ![meta-ads-install-referrer-decryption-key.png](https://files.readme.io/adf6caa8d7cee493695eb8fb7db1b61c60e6a1cef0273e615c43a05ad8a9485d-13963525463825.png)<br>   3. In the **Integration** tab, paste the key in **Install Referrer** **Decryption Key**.<br>   4. Click **Save integration**. |
| **Update the decryption key via API** | **[Coming soon]**<br>We will release an API that updates the decryption key. |
| **Raw data availability going forward** | - If the attribution data is obtained via the referrer mechanism the data is unrestricted and is available via the raw data reports.<br>- If the attribution data is obtained via API, then raw data of users brought by Meta ads is assigned to the _restricted_ media source<br>- This change has no impact on the raw data of users brought before the change. In other words before October 29, 2021, 08:00 UTC. |
| **What's staying the same** | AppsFlyer continues to receive device-level data from Meta ads, meaning that our attribution and reporting abilities (including multi-touch attribution, LTV, ROI, cohort, retention reports, fraud protection, Audiences, and other services) remain unchanged. See [aggregate and analytics reporting tools](https://support.appsflyer.com/hc/articles/360005437257-Aggregate-and-analytics-reporting-overview).<br>**Note**: If you provide us with the decryption key, we can attribute users who don't have an advertising ID (LAT-enabled). This improves attribution accuracy. |
| **Changes to attribution** | Deferred deeplinking via GCD will be available for Android apps using the Google Install Referrer mechanism. It isn't available for iOS apps. |
| **FAQs** | - **Does the install referrer decryption key need to be updated?**<br>  <br>  Once submitted, the decryption key doesn't need to be updated.<br>- **When can I see user-level data in raw data reports?**<br>  <br>  User-level data is displayed in raw date reports once a valid install referrer decryption key is submitted and an install is attributed to Meta ads.<br>- **Is user-level attribution data available for installs that occurred between October 29, 2021, and November 3, 2021?**<br>  <br>  Unfortunately, this data is not available. |

<Accordion title="Does the install referrer decryption key need to be updated?">

Once submitted, the decryption key doesn't need to be updated.

</Accordion>

<Accordion title="When can I see user-level data in raw data reports?">

User-level data is displayed in raw date reports once a valid install referrer decryption key is submitted and an install is attributed to Meta ads.

</Accordion>

<Accordion title="Is user-level attribution data available for installs that occurred between October 29, 2021, and November 3, 2021?">

Unfortunately, this data is not available.

</Accordion>
