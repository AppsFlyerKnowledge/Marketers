Meta ads makes this data available to MMPs like AppsFlyer, but not to advertisers.</p><p>However, if the ad directs users to Google Play Store, attribution fields are available to advertisers in the Google Install Referrer which must be <a href="./basic-sdk-integration-guide#attribute-apps-published-on-google-play">integrated into your app.</a> The fields provided via the referrer populate AppsFlyer raw data reports available to you and enable AppsFlyer to attribute users who don't have an advertising ID (LAT-enabled).</p><p>Using the referrer mechanism requires AppsFlyer SDK V5.4+</p><p><strong>Note:</strong> Referrer data has priority over data provided by API and isn't restricted. </p><p>Data in the referrer is encrypted by Meta ads and is decrypted using a key available to you in your Meta ads developer account. You must provide us with the decryption key described in the actions required row. </p><p><strong>Campaign attribution fields available via the referrer:</strong></p><ul><li><span>Ad ID</span></li><li><span>Ad name</span></li><li><span>Adset ID</span></li><li><span>Adset name</span></li><li><span>Campaign ID</span></li><li><span>Campaign name</span></li><li><span>Account applies to click-through attribution and not view-through attribution.</li><li>Referrer data isn't applicable to re-engagement campaigns, as users don't go through the store.</li></ul><p><strong>When
