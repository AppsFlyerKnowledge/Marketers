| **What's new** | Two new conditions - **currency** and **revenue** have been added to the Protect360 validation rules. |
| **Effective date** | August, 2024 |
| **What you need to know** | - As part of enhancing the power of validation rules, both **currency** and **revenue** conditions have been added.<br />- When selecting **revenue**, you must also select **currency** in the same rule.<br />- These conditions can be found [under the in-app events](/docs/implement-validation-rules-to-prevent-fraud#install-conditions).<br />- These condition are available for Protect360 premium users only. |
| **Example use case** | - Some apps may have a minimum purchase amount, and users shouldn't be able to place orders below this specified amount. When such orders occur, these can be flagged as fraudulent. |
