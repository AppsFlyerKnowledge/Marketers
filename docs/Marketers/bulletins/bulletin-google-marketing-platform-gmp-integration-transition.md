<table><tbody><tr><td><strong>What's new?</strong></td><td><p>As part of preparations for enforcing the <a href="https://commission.europa.eu/strategy-and-policy/priorities-2019-2024/europe-fit-digital-age/digital-markets-act-ensuring-fair-and-open-digital-markets_en">Digital Marketing Act</a> (DMA), Google is updating its <a href="https://www.google.com/about/company/user-consent-policy/?sjid=15416941068016224808-NA">EU user consent policy</a>. AppsFlyer is making the necessary changes to support Google’s policy requirements.</p><p>The following Google Marketing Platform (GMP) integrations are currently available:</p><ul><li>[Legacy] CM360 (DoubleClick) <kbd>doubleclick_int</kbd></li><li><a href="./google-marketing-platform-display-video-360-dv360-integration">DV360 (new integration)</a> <kbd>dv360_int</kbd></li></ul><p>As of September 9th 2025, the legacy <code>doubleclick_int</code> integration will be deprecated If you're using this integration, you'll need to transition to the new DV360 integration to continue running campaigns and measuring them using GMP.</p></td></tr><tr><td><strong>Action required</strong></td><td>Transition to the new DV360 <code>dv360_int</code> integration as soon as possible, and no later than June 30, 2025.</td></tr><tr><td><strong>Steps to take</strong></td><td><p>Make sure to configure both platforms, GMP and AppsFlyer:</p><p><strong>Configure in GMP</strong></p><ol><li>Log in to your CM360 or DV360 account. <br/><strong>Note:</strong> Completing the steps in CM360 negates the need for completing them in DV360.</li><li>Create or reuse your partner attribution link (Link ID) using <a href="https://support.google.com/displayvideo/answer/10956727">these instructions</a>. </li></ol><p><strong>Configure in AppsFlyer</strong></p><ol><li>Complete your DV360 integration in AppsFlyer using <a href="./google-marketing-platform-display-video-360-dv360-integration#integration-procedures">these instructions</a>. <br/><strong>Note:</strong> To maintain data consistency, make sure the configuration is similar to the legacy integration (lookback windows, in-app event postbacks, etc).</li><li><strong>Test the new integration: </strong><br/>Wait for about a day to confirm the new integration data. You can then disable the legacy integration.</li></ol></td></tr><tr><td><strong>What you must know</strong></td><td> </td></tr><tr><td> </td><td><figure><table><thead><tr><th><strong>Considerations</strong></th><th>Available options</th></tr></thead><tbody><tr><td colspan="2"><strong>Media source PID</strong></td></tr><tr><td>After completing the migration, the DV360 media source PID changes from <kbd>doubleclick_int</kbd> to <kbd>dv360_int</kbd>.</td><td>If you're pulling raw data from AppsFlyer into your BI or any 3rd party analytics tool, consider the change in the media source name.</td></tr><tr><td colspan="2"><strong>Out-of-store apps</strong></td></tr><tr><td>Apps from unofficial app stores aren't supported in the DV360 integration. The integration relies on a link ID, which is generated for apps obtained through official app stores.</td><td>If your app is downloaded from sources outside official app stores, contact your CSM or <a href="mailto:hello@appsflyer.com">hello@appsflyer.com</a>.</td></tr><tr><td colspan="2"><strong>Attribution data distribution</strong></td></tr><tr><td colspan="2">When both integrations are active and claim attribution for installs, <strong>attribution is randomly split between them</strong>, with one being the primary source and the other acting as a contributor. This ensures data isn't duplicated. For example, if DV360 is responsible for 100 installs, you might see 70 installs from the legacy integration and 30 from DV360, or 80 installs from DV360 and 20 installs from the legacy integration.</td></tr><tr><td colspan="2">In-app events for installs/re-engagements attributed to the legacy integration remain credited accordingly.</td></tr><tr><td colspan="2"><p><strong>Re-engagement</strong></p><p>Re-engagement attribution is supported in the DV360 integration.</p></td></tr></tbody></table></figure><p><strong>Field discrepancies</strong></p><p>Due to differences between available data fields in the legacy and updated APIs, you may see differences in some AppsFlyer fields, as seen below:</p><figure><table><thead><tr><th><strong>AppsFlyer field</strong></th><th><strong>Legacy field (doubleclick_int)</strong></th><th><strong>DV360 field (dv360_int)</strong></th></tr></thead><tbody><tr><td>Campaign name</td><td>placement_id</td><td>line_item_name</td></tr><tr><td>Campaign ID</td><td>placement_id</td><td>line_item_id</td></tr><tr><td>Adset name</td><td>ad_id</td><td>NA (not supported)</td></tr><tr><td>Adset ID</td><td>ad_id</td><td>NA (not supported)</td></tr><tr><td>Ad name</td><td>creative_id</td><td>NA (not supported)</td></tr><tr><td>Ad ID</td><td>creative_id</td><td>creative_id</td></tr></tbody></table></figure></td></tr></tbody></table>
