| **¿Qué hay de nuevo?** | Optimización creativa tiene una integración de API con Unity que nos permite obtener datos de rendimiento de las creatividades. La API se actualizará pronto. Como parte de esta actualización, necesitas actualizar el rol de organización de tu cuenta de servicio en Unity para seguir obteniendo datos de Unity. |
| --- | --- |
| **Fecha de actualización** | 10 de octubre de 2024 |
| **Lo que debes saber:** | <ul><li>Unity presenta una nueva integración de API.</li><li>La antigua integración de la API puede obtener datos hasta su fecha de fin de vida útil, el 14 de noviembre de 2024.</li></ul> |
| **Lo que debes hacer** | Debes actualizar el rol de organización de tu cuenta de servicio en Unity para incluir el rol "Advertisers API Stats Viewer" role, además de otro rol, para seguir obteniendo datos después del 14 de noviembre de 2024.<br /><br /><Anchor target="_blank" href="/marketers/es/docs/creative-optimization-partner-integrations#para-seleccionar-un-rol-de-cuenta-de-servicio-organización">Sigue nuestras instrucciones para actualizar el rol de Unity</Anchor> |
