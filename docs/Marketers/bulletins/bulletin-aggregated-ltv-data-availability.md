| **What's new** | Starting April 1, 2026, LTV aggregated data (including clicks,impressions and installs) will be retained for 25 months (2 years + 1 month) instead of 5 years. |
| --- | --- |
| **Effective date** | April 1, 2026 |
| **Recommended action** | Export any required historical aggregated LTV data before April 1, 2026 |
| **Additional information** | This change applies to aggregated LTV data in the following AppsFlyer products and interfaces:<ul><li>My Dashboards</li><li>Protect 360</li><li>SKAN Dashboard</li><li>Master API</li><li>Pivot Dashboard</li><li>Custom Dashboard</li><li>Overview Dashboard</li><li>Aggregated Pull API</li><li>Activity Dashboard</li><li>Events Dashboard</li><li>AppsFlyer MCP</li></ul>**<span id="what-you-should-know"></span>What you should know**<ul><li>Aggregated LTV data availability (including clicks,impressions and installs) is limited to **25 months (2 years + 1 month)**.</li><li>After April 1, 2026, aggregated LTV data older than 25 months is no longer accessible.</li><li>Queries or visualizations that request aggregated LTV data beyond the retention window may return **partial or empty results**.</li><li>For older date ranges, cohort and activity data may still be available, which can result in differences between datasets.</li></ul> |
