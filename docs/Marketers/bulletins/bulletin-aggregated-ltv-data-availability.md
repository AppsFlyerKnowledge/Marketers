---
title: "Bulletin: Aggregated LTV data availability"
excerpt: "Starting April 1, 2026, AppsFlyer is updating its aggregated LTV data retention policy to 25 months."
table_of_contents: false
---
| | |
| --- | --- |
| **What's new** | Starting April 1, 2026, LTV aggregated data (including clicks,impressions and installs) will be retained for 25 months (2 years + 1 month) instead of 5 years. |
| **Effective date** | April 1, 2026 |
| **Recommended action** | Export any required historical aggregated LTV data before April 1, 2026 |
| **Additional information** | This change applies to aggregated LTV data in the following AppsFlyer products and interfaces:<br />- My Dashboards<br />- Protect 360<br />- SKAN Dashboard<br />- Master API<br />- Pivot Dashboard<br />- Custom Dashboard<br />- Overview Dashboard<br />- Aggregated Pull API<br />- Activity Dashboard<br />- Events Dashboard<br />- AppsFlyer MCP<br />#### **What you should know**<br />- Aggregated LTV data availability (including clicks,impressions and installs) is limited to **25 months (2 years + 1 month)**.<br />- After April 1, 2026, aggregated LTV data older than 25 months is no longer accessible.<br />- Queries or visualizations that request aggregated LTV data beyond the retention window may return **partial or empty results**.<br />- For older date ranges, cohort and activity data may still be available, which can result in differences between datasets. |
