| **¿Qué hay de nuevo?** | Ahora puedes cargar de forma masiva archivos CSV para seleccionar condiciones de las reglas de validación de Protect360. |
| --- | --- |
| **Fecha de entrada en vigor** | Agosto de 2024 |
| **Lo que debes saber:** | <ul><li>Al seleccionar los operadores **En la lista** o **No en la lista** dentro de las condiciones que lo admiten, tienes la opción de cargar de forma masiva un archivo CSV.</li><li>El archivo CSV puede contener hasta 17 mil valores.</li></ul> |
| **Implicaciones** | La carga masiva ya está disponible para determinadas reglas de validación. Esto te permite cargar un archivo CSV que contenga una lista larga de valores para que la regla funcione según las necesidades de tu empresa. Puedes encontrar más información, incluida la configuración, <Anchor target="_blank" href="/marketers/es/docs/implement-validation-rules-to-prevent-fraud#carga-masiva">aquí</Anchor>. |
