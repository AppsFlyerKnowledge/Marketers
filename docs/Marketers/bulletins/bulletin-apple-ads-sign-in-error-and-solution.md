Solve the sign-in error that displays during Apple Ads cost integration.

| | |
| --- | --- |
| **Issue date** | From May 5, 2021 |
| **Error** | When you try to sign in to Apple Ads for AppsFlyer [cost integration](https://support.appsflyer.com/hc/articles/213747963-Apple-Search-Ads-guide#cost-tab), the following error message may display:<br>! |
| **Solution** | 1. Close all of your open browsers.<br>2. Relaunch the AppsFlyer dashboard.<br>3. Try to [enable Apple Ads cost integration](https://support.appsflyer.com/hc/articles/213747963-Apple-Search-Ads-guide#cost-tab) again. |
