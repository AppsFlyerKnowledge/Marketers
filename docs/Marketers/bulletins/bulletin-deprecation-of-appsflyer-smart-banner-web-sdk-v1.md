> **Resumen:** A partir del 8 de noviembre de 2023, el SDK web de AppsFlyer Smart Banner v1 queda en desuso.

| **Qué ha cambiado** | El SDK web de AppsFlyer para Smart Banners v1 quedó en desuso el 8 de noviembre de 2023. Para mostrar Smart Banners en tu sitio web, necesitas actualizar a la v2. |
| --- | --- |
| **Lo que debes saber** | <ul><li>Si tu sitio web usa Smart Banner SDK V1.0, DEBES integrar la versión más reciente del SDK (v2) para seguir mostrando Smart Banners en tu sitio web.</li><li>Actualizar a la versión más reciente es un proceso sencillo. Haz clic <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2">aquí</Anchor> para ver el proceso.</li></ul>**Soporte para nuevas funciones**<ul><li>Algunas funciones no son compatibles con el SDK v1, incluidas las <Anchor target="_blank" href="/marketers/es/docs/smart-banners-mobile-web-to-app-for-marketers#3-banner-setup">plantillas de diseño creativo</Anchor> añadidas recientemente.</li></ul> |
| **¿Cómo puedes saber si estás usando Smart Banner SDK v1?** | Si el fragmento de código de Smart Banner de tu sitio web incluye  <br />https://cdn.appsflyer.com/web-sdk/banner/latest/sdk.min.js  <br />significa que estás usando V1 y que deberías actualizar.<br /><br />Haz clic <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2">aquí</Anchor> para ver el proceso y actualizar. |
