| **What's changing** | AppsFlyer Smart Banner web SDK v1 was deprecated on Nov. 8th, 2023. To show Smart Banners on your website you need to upgrade to v2. |
| --- | --- |
| **What you must know** | <ul><li>If your website uses Smart Banner SDK V1.0 you MUST integrate the latest SDK version (v2) to continue showing Smart Banners on your website.</li><li>Updating to the latest version is a simple process. Click [here](https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2) to see the process.</li></ul>**New features support**<ul><li>Some features are not supported in SDK v1 including newly added [creative design templates](/docs/smart-banners-mobile-web-to-app-for-marketers#3-banner-setup).</li></ul> |
| **How can you tell if you’re using Smart Banner SDK v1?** | If the Smart Banner code snippet on your website includes  <br />https://cdn.appsflyer.com/web-sdk/banner/latest/sdk.min.js  <br />that means you are using V1 and should upgrade.<br /><br />Click [here](https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2) to see the process and upgrade. |
