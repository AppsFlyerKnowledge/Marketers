<table><tbody><tr><td><p><strong>What's changing</strong></p></td><td>In the <a href="/docs/raw-data-export-page">Export Data page</a>, you can now set the report column sequence in addition to the existing field selection option.</td></tr><tr><td><strong>Effective date</strong></td><td><span>June 16, 2021</span></td></tr><tr><td><strong>Where</strong></td><td>Export Data page</td></tr><tr><td><p> </p><p><strong>What's changing</strong></p></td><td><p>Use the <strong>Report (CSV) field order</strong> setting to specify the sequence of columns in reports.</p><table><tbody><tr><th>Setting</th><th>Field selection allowed</th><th>Remarks</th></tr><tr><td>Default</td><td>Yes</td><td><ul><li>Selected fields are ordered according to an AppsFlyer template.</li><li>Going forward, the sequence will be preserved. Future fields will be appended to the right of the existing fields.</li></ul></td></tr><tr><td>Alphabetical (A-Z)</td><td>Yes</td><td>Selected fields are ordered alphabetically (ascending).</td></tr><tr><td>Alphabetical (Z-A)</td><td>Yes</td><td>Selected fields are ordered in reverse order alphabetically (descending).</td></tr><tr><td>Legacy</td><td>No</td><td><ul><li>Fields are ordered according to the sequence of columns in reports prepared using the previous version of the export data page.</li><li>Field selection is fixed and can't be changed.</li><li>There is some variation of the reports per field depending on the actual report. </li></ul></td></tr></tbody></table><p>The <a href="https://docs.google.com/spreadsheets/d/e/2PACX-1vRGYcMOgC5yy_82yn3DWd3ucLE5KtuTA72eJfvu5KVB9fFH_mYwzM3KpR_inQOnat-KzgVjuuvXa6_g/pub?output=xlsx">field order spreadsheet</a> contains both a Default and Legacy sheet containing the relevant field order list.</p></td></tr><tr><td><p><strong>Procedure</strong></p></td><td><p><img alt="FeldOrder.png" src="https://files.readme.io/d81e8d0494cbf3a8ee959990200da10889bb7a581c6018711b7163d8fedcd2d8-360020954138.png"/></p><p><strong>To change the field order:</strong></p><ol><li>In the <strong>Report fields</strong> tab, select a <strong>Report (CSV) field order</strong> option.</li><li>If required, change the selected fields by selecting or clear selecting the necessary fields.</li><li>Click <strong>Download</strong>.</li></ol></td></tr></tbody></table>
