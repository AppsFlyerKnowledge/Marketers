---
title: "Bulletin: Protect360 and ProtectLITE dashboards display fraud from organic sources"
excerpt: "Protect360 and ProtectLITE dashboards now display fraud data for installs from organic sources, which was previously only available in raw data reports."
table_of_contents: false
---
|     |     |
| --- | --- |
| **What's new** | Protect360 and ProtectLITE dashboards display fraud from organic sources |
| **Effective date** | December 20, 2021 |
| **Where** | [Protect360](/docs/protect360-dashboard) and [ProtectLITE](/docs/basic-fraud-detection-and-insights-with-protectlite-dashboard-and-reporting) dashboards |
| **What** | **Before the change:** Fraud from organic sources was only available in raw data reports.<br />**After the change:** Fraud for installs from organic sources is also displayed in the Protect360 and ProtectLITE dashboards. In-app event fraud from organic sources is not supported. |
| **What you must know** | - Main dashboard filter: You can now filter by organic and/or non-organic traffic.<br />- Identified fraud trend chart: Can be filtered by source type organic. <br />  <br />- Estimated savings chart: Is not relevant for organic traffic.<br />- Hijacked installs attribution correction chart: Can display correction to organic, but not from organic.<br />  <br />- Identified fraud breakdown table: Includes data for organic traffic.<br />- Agencies and ad networks: Cannot view data for organic traffic.<br />Recommended: Don't name owned media sources as organic, as they can be confused and interfere with genuine organic data. |
