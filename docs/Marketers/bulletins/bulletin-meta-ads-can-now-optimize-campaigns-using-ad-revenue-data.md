| <span id="whats-new"></span>¿Qué hay de nuevo? | Meta Ads ahora pueden optimizar tus campañas de promoción de apps de Android usando el evento de postback de ingresos por anuncios **AdImpression**. |
| --- | --- |
| <span id="update-date"></span>Fecha de actualización | 1 de enero de 2025 |
| <span id="what-you-need-to-know"></span>Lo que debes saber: | <ul><li>Actualmente, la optimización a través del evento **Adimpression** está disponible para campañas de promoción de apps de Android.</li><li>Cuando esté en gris, [puede que no se cumplan los criterios de elegibilidad](https://www.facebook.com/business/help/571188993373447?id=561906377587030).</li><li>El evento Adimpression está mapeado al evento af\_ad\_revenue, que está disponible solo para planes con una <Anchor target="_blank" href="/marketers/es/docs/roi360-guide-cost-and-revenue-data">suscripción avanzada de ROI360</Anchor>. Además, necesitas el <Anchor target="_blank" href="/marketers/es/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">tipo de integración de ingresos publicitarios a nivel de impresión (a través de SDK) o a nivel de impresión (a través de SDK) con nivel de dispositivo (a través de la API S2S)</Anchor>.<ul><li>Los planes que no son ROI360 pueden enviar datos de ingresos publicitarios utilizando otros nombres de eventos.</li></ul></li></ul> |
| <span id="what-you-need-to-do"></span>Lo que debes hacer | <ul><li>Para clientes de ROI360, utiliza el <Anchor target="_blank" href="/marketers/es/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">tipo de integración de ingresos publicitarios a nivel de impresión (a través de SDK) o a nivel de impresión (a través de SDK) con nivel de dispositivo (a través de la API S2S)</Anchor>.</li><li><Anchor target="_blank" href="/marketers/es/docs/meta-ads-in-app-event-mapping#mapeo-de-datos-de-ingresos-por-anuncios-para-la-optimización-de-campañas">Asigna el evento af\_ad\_revenue a **Adimpression**</Anchor>.</li></ul> |
| <span id="additional-resources"></span>Recursos adicionales | Visita el <Anchor target="_blank" href="https://www.facebook.com/business/help/330074040129013">Centro de ayuda de Meta Business</Anchor> para saber más sobre cómo maximizar el valor de las conversiones como objetivo de performance para los anuncios de aplicaciones en Meta Ads Manager. |
