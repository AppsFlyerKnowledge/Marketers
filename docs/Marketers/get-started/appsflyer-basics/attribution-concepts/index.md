  <Card title="Measure reinstalls" href="/docs/measure-reinstalls" icon="fa-solid fa-chart-line">
    A reinstall occurs when a user installs an app, uninstalls it, and then reinstalls it. Reinstalls result in one of the following attribution types: non-organic reinstall, organic reinstall, or re-attribution (retargeting). Reinstalls help avoid multiple charges for users that uninstall and install again.
