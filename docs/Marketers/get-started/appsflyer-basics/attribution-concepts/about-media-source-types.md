**At a glance:** Understand the basic media source types in AppsFlyer.

A media source is an entity that displays ads. The AppsFlyer platform enables attribution recording from different types of media sources.

| Type of media source | Description |
| --- | --- |
| [Self-reporting network (SRN)](https://support.appsflyer.com/hc/articles/360001546905) | - Provide attribution confirmation and details via an API between AppsFlyer and the network<br>- Examples: Meta ads, Google, Apple Search Ads |
| Non-SRN | - Provide attribution information contained in a click URL.  <br>- Also known as [attribution-link network](https://support.appsflyer.com/hc/articles/4410395957521) or ad network.<br>- Examples: Unity Ads, Tapjoy, Applovin |
| Owned media | - Owned media use [OneLink links](https://support.appsflyer.com/hc/articles/208874366) for campaigns.<br>- Examples: Email, SMS, social networks, landing pages, QR codes, and so on. |
