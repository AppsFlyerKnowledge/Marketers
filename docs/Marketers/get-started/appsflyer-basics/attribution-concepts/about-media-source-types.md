> **En resumen:** Comprende los tipos de fuente de medios básicos en AppsFlyer.

Una fuente de medios es una entidad que muestra anuncios. La plataforma AppsFlyer permite la grabación de atribuciones de diferentes tipos de fuentes de medios.

| Tipo de fuente de medios | Descripción |
| --- | --- |
| <Anchor target="_blank" href="/marketers/es/docs/self-reporting-networks-srns">Red de autorreporte (SRN)</Anchor> | <ul><li>Proporciona la confirmación y los detalles de la atribución a través de una API entre AppsFlyer y la red</li><li>Ejemplos: Meta ads, Google, Apple Search Ads</li></ul> |
| No SRN | <ul><li>Proporciona la información de atribución incluida en la URL de un clic.</li><li>También conocida como <Anchor target="_blank" href="/marketers/es/docs/set-up-an-integrated-partner">red de enlace de atribución</Anchor> o ad network.</li><li>Ejemplos: Unity Ads, Tapjoy, Applovin</li></ul> |
| Medios propios | <ul><li>Los medios propios utilizan <Anchor target="_blank" href="/marketers/es/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">enlaces de OneLink</Anchor> para campañas.</li><li>Ejemplos: Correo electrónico, SMS, redes sociales, landing pages, QR codes, etc.</li></ul> |
