At a glance: The ability to access data and features in AppsFlyer depends on team member account type, individual team member permissions, and account permissions.

## Access to data by account type

Advertisers, ad networks, and agencies have access to data according to their account type:

| Account type | Can access |
| --- | --- |
| Advertiser | All their data in AppsFlyer, although some data is masked or hashed:<br />- Traffic attributed to restricted media sources due to regulatory requirements or data-sharing terms. |
| Ad network | Data attributed to the ad network |
| Agency | Data relating to campaigns run by the agency and to which the traffic is attributed |

## Access to data by roles and permissions

When the advertiser turns on the Permission toggle for an ad network (see [Ad network permissions](/docs/set-up-an-integrated-partner#ad-network-permissions)) or an agency (see [Agency permissions](/docs/set-up-an-integrated-partner#agency-permissions)), there is a further distinction between access to data according to roles—account **admin** and account **team members**, as listed in the tables that follow.

> 📘 Note
>
> Where allowed, access is limited to the traffic generated by the ad network or the agency.

Abbreviations key:

| Abbreviation | Meaning |
| --- | --- |
| **✓** | Access is granted when the main permission toggle is enabled by the advertiser |
| P | Access is granted when additional specific permissions are enabled by the advertiser |
| L | Limited access is granted when permission is enabled by the advertiser |
| – | No access |

#### Access for advertisers

The [Admin role](/docs/user-management#admin%E2%80%94a-special-role) in an advertiser account has access to all features listed in the [table above](/docs/manage-data-access-permissions#access-by-feature). All other users have access according to the [roles](/docs/user-management#more-about-roles) they're assigned to.
