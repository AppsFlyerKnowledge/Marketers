> **En resumen:** La capacidad de acceder a datos y funciones en AppsFlyer depende del tipo de cuenta del miembro del equipo, los permisos individuales de los miembros del equipo y los permisos de la cuenta.

<div id="access-to-data-by-account-type" />

## Acceso a datos por diferentes tipos de usuarios

Los anunciantes, las redes de publicidad y las agencias tienen acceso a los datos de acuerdo con su tipo de cuenta:

| Tipo de cuenta | Pueden acceder a |
| --- | --- |
| Red publicitaria | Todos sus datos en AppsFlyer, aunque algunos datos están enmascarados o con hash:<ul><li>Tráfico atribuido a fuentes de medios restringidas debido a requisitos reglamentarios o términos de intercambio de datos.</li></ul> |
| Red publicitaria | Datos atribuidos a la red de publicidad. |
| Agencia | Datos relacionados con las campañas ejecutadas por la agencia y a los que se atribuye el tráfico. |

<div id="access-to-data-by-roles-and-permissions" />

## Acceso a los datos por roles y permisos

Cuando el anunciante activa el interruptor de permisos para una ad network (consulta <Anchor target="_blank" href="/marketers/es/docs/set-up-an-integrated-partner#permisos-de-ad-network">Permisos de ad network</Anchor>) o una agencia (consulta <Anchor target="_blank" href="/marketers/es/docs/set-up-an-integrated-partner#permisos-de-la-agencia">Permisos de agencia</Anchor>), existe una distinción adicional entre el acceso a los datos según los roles: **administrador** de la cuenta y **miembros del equipo** de la cuenta, tal como se indica en las tablas siguientes.

**Nota:** Cuando esté permitido, el acceso se limita al tráfico generado por la red publicitaria o la agencia.

Referencia para las abreviaturas:

| Abreviatura | Significado |
| --- | --- |
| ✓ | El acceso se otorga cuando el anunciante habilita el botón de permiso principal. |
| P | El acceso se otorga cuando el anunciante habilita permisos específicos adicionales. |
| L | Se otorga acceso limitado cuando el anunciante habilita el permiso |
| – | Sin acceso |

#### Acceso para anunciantes

El <Anchor target="_blank" href="/marketers/es/docs/user-management#administrador">rol de administrador</Anchor> en una cuenta de anunciante tiene acceso a todas las funciones enumeradas en la [tabla anterior](/docs/manage-data-access-permissions#acceso-por-página-de-característica-para-agencias-y-redes-de-publicidad). Todos los demás usuarios tienen acceso de acuerdo a los <Anchor target="_blank" href="/marketers/es/docs/user-management#gestionar-roles">roles</Anchor> que tienen asignados.
