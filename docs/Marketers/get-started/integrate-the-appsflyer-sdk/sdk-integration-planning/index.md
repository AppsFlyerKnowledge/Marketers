Our step-by-step guide for integrating the SDK from planning to testing

<Cards>
  <Card title="SDK integration overview" href="/docs/sdk-integration-overview" icon="fa-solid fa-code">
    Learn about the AppsFlyer SDK functionalities that are available and determine which APIs you want your Android or iOS app to use.
  </Card>
  <Card title="Basic SDK integration guide" href="/docs/basic-sdk-integration-guide" icon="fa-solid fa-code">
    Work with your mobile or CTV app developer to integrate and install the SDK into Android or iOS apps. Once basic integration tasks are complete, your app is ready for install attribution and in-app event measurement.
  </Card>
  <Card title="Additional SDK integration guide" href="/docs/additional-sdk-integration-guide" icon="fa-solid fa-code">
    Consider the additional SDK functionalities that are available and work with your developer to implement APIs such as uninstall measurement, user invite attribution, push notifications, and privacy settings.
  </Card>
  <Card title="For iOS and Android: The SDK integration wizard" href="/docs/for-ios-and-android-the-sdk-integration-wizard" icon="fa-solid fa-sack-dollar">
    Create and test your SDK integration code automatically.
  </Card>
  <Card title="Testing the SDK integration for marketers" href="/docs/testing-the-sdk-integration-for-marketers" icon="fa-solid fa-code">
    Test your Android or iOS app integration with AppsFlyer.
  </Card>
  <Card title="Registering test devices" href="/docs/registering-test-devices" icon="fa-solid fa-vial">
    When performing attribution tests, register your test device to make sure each install is recorded as a new install. A registered test device prevents installs from being recorded as reinstalls.
  </Card>
  <Card title="SDK integration general FAQ" href="/docs/sdk-integration-general-faq" icon="fa-solid fa-circle-question">
    The AppsFlyer SDK lets you safely advertise your app, attribute, deep-link, and collect behavioral information of your mobile users. You can set up and start working with any ad network and/or platform in a manner of minutes—not weeks or months!
  </Card>
</Cards>
