title: "Security Center"
excerpt: "Review and manage the status of all the security-related features of your AppsFlyer account from a single location."
---
The **Security Center** provides you with an at-a-glance overview of your AppsFlyer account's security status. Click the button in any section of the **Security Center** to access the following features:

| Feature | Description |
| --- | --- |
| User management | Create and manage your AppsFlyer users. Assign them permissions to access the features, apps, and data they need. |
| [Redirect allowlist](/docs/set-up-your-domain-redirect-allowlist) | Define allowed domains for link redirects. |
| [List of authorized agencies](/docs/set-up-your-list-of-authorized-agencies) (for ad networks) | Manage which agencies you authorize to run campaigns through your network integration. |
| [API allowlist](/docs/set-up-your-api-allowlist) | Define allowed IP addresses for API requests. |
| Enhanced login security | Configure [single sign-on (SSO)](/docs/set-up-sso-authentication-with-your-identity-provider-idp) or [two-factor authentication (2FA)](/docs/implementing-and-using-2fa-login) to keep your account safe from unauthorized entry. |
| [AppsFlyer tokens](/docs/managing-appsflyer-tokens) | Use AppsFlyer tokens to authenticate your API and S2S calls. Manage the tokens and replace them periodically to ensure maximum security |
| [Audit log](/docs/audit-log) | Review account activity to identify unauthorized access: logins, user management actions, and API calls. |

**To access the Security Center:**

- From the top bar, open the account menu (email address dropdown) > **Security center.**
