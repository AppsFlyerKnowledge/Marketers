> **요약:** 네이버 검색 광고 집행시 대량의 키워드를 원링크를 이용하여 간단히 성과 측정하는 팁을 알려드립니다.

**Q :** 네이버 검색 광고의 인스톨 및 리타겟팅(리어트리뷰션 및 리인게이지먼트) 기여 성과를 키워드별로 측정하고자 할 때, 키워드별로 원링크 커스텀 링크를 생성해야 하나요? 네이버 검색 광고 시스템에 등록할 키워드가 많아 키워드 별로 일일이 원링크 커스텀 링크를 생성하는 것이 번거로운데, 어떻게 하면 간단히 키워드별 기여 성과를 측정할 수 있을까요?

**A :** 네이버 검색 광고에서 지원하는 <Anchor target="_blank" href="https://saedu.naver.com/help/faq/ncc/view.naver?faqSeq=120">URL 치환변수</Anchor>들 중 키워드 치환변수인 `{keyword}`를 활용하여 원링크 커스텀 링크를 만든 후, 이를 네이버 검색 광고의 랜딩페이지 URL (연결 URL) 로 세팅하시면 됩니다.

**예시:** yourbrand.onelink.me/AB12?pid=naver\_search\_ad&c=your\_campaign&af\_keywords=**`{keyword}`**

> ❗️ **주의 사항**
>
> Naver 검색광고의 `{keyword}`는 클릭 시점에 Naver가 실제 키워드로 치환하므로 숏링크 문자열 안에 포함될 수 없습니다. `af_keywords={keyword}`는 **롱링크 안에 포함**시켜 사용하시기 바랍니다.
>
> 권장 예시: `yourbrand.onelink.me/AB12?pid=naver_search_ad&c=your_campaign&af_keywords={keyword}`
>
> **[Secure Shortlinks 주의]** 생성된 숏링크 뒤에 `?af_keywords={keyword}`를 외부에서 덧붙이는 방식은 사용하지 마세요. 템플릿의 **Secure Shortlinks**("Don't attribute clicks with added parameters") 설정이 ON이면 해당 클릭이 어트리뷰션되지 않아 키워드별 성과가 측정되지 않습니다. **2026년 8월 6일 이후 생성된 템플릿은 이 설정이 기본 ON**입니다.
>
> 리디렉션 파라미터(`af_android_url`, `af_ios_url`, `af_web_dp`) 값에는 `{keyword}`를 넣지 마세요. `{}`가 포함되면 지정 랜딩페이지 대신 스토어로 리디렉션됩니다.
