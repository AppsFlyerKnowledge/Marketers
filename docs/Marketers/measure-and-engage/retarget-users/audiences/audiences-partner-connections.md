## Acerca de las conexiones de partners

Una conexión de partners te permite enviar de forma sencilla y continua tus audiencias a los partners para que puedan servir tus campañas a medida. A continuación se muestra una lista de los partners de Audiences, los requisitos de conexión y los identificadores de usuario que admite cada uno.

**Para conectarse a un partner, identifícalos en la tabla a seguir y sigue estos pasos:**

* Si la tabla contiene un enlace a instrucciones específicas para Partners, haz clic en el enlace y sigue las instrucciones proporcionadas.  
  **--O--**
* Si la tabla contiene la lista de requisitos de conexión (credenciales) requeridos:
  1. Obtén las credenciales del partner.
  2. Sigue las instrucciones para <Anchor target="_blank" href="/marketers/es/docs/audiences-guide#create-a-new-connection">crear una nueva conexión con un partner</Anchor> en audiencias.

**Nota:** Se recomienda un máximo de 50 conexiones con partners por audiencia.

<Accordion title="Amazon S3">

Crear una integración S3 permite a AppsFlyer enviar las ID de dispositivo de la audiencia directamente a tu bucket S3. El archivo enviado a S3 tiene las siguientes características:

* Nombre del archivo: nombre y fecha de la audiencia. Por ejemplo, my\_audience\_2020-06-23.csv
* Contenido: una sola columna, sin encabezado, que contiene los ID de dispositivo
* Cada día se escribe un archivo adicional. Los archivos existentes no se eliminan
* Si se envían audiencias divididas, se escribe un solo archivo ZIP, que contiene un archivo separado para cada partner (dividido)

**Para conectar una audiencia a Amazon S3**:

1. En AppsFlyer, ve a **Audiencias** y selecciona una audiencia.
2. Haz clic en la pestaña **Conectar** .
3. Haz clic en **+ Nueva conexión**.
4. Introduce un nombre de **conexión**.
5. Selecciona **Amazon S3**.  
   Se abre la ventana **Añadir conexión**.

   ![image__9_.png](https://files.readme.io/790f8a50bf14fbb4065d9dcee05e31fa866bc73f236f439ec73f2bc833b31be6-31237653533201.png)
6. Introduce el **ARN del rol entre cuentas**, el **nombre del bucket** y el **nombre de la región**.  
   **Nota:** Se recomienda introducir siempre el nombre de la región. Si el nombre de la región no está habilitado automáticamente por defecto en AWS, debe ingresarse aquí o la conexión no se podrá crear. Para encontrar la región en la página de inicio de la consola de AWS, haz clic en el menú desplegable del país en la esquina superior derecha de la página y se mostrarán las regiones. <Image alt="region_name.jpg" src="https://files.readme.io/a3b65660a638674cbbe0da2802b4f926929d167d0b528c25c12ded6a90b0e981-31237648137489.jpg" width="355px" />
7. Registra el **ID de cuenta** y el **ID externo** para su uso posterior.
8. En la consola de **AWS**, ve a **IAM** > **Políticas**.
9. Haz clic en **Crear política**.
10. Haz clic en **JSON.**
11. Pega el siguiente fragmento de política en la ventana JSON.

    ```json
    {
    							"Version": "2012-10-17",
    							"Statement": [
    							{
    							"Effect": "Allow",
    							"Action": "s3:*",
    							"Resource": "arn:aws:s3:::BUCKET-NAME/*"
    							}
    							]
    }
    ```
12. Reemplaza **BUCKET-NAME** con el nombre del bucket al que quieres que AppsFlyer suba tu audiencia.

    <div id="note" />

    > 📘 **Advertencia**
    >
    > La política debe contener solo el bucket raíz y no directorios adicionales en la ruta. Por ejemplo, el recurso **arn:aws:s3:::BUCKET-NAME/Directory/\*** no es compatible. Si necesitas que los archivos se transfieran a un directorio específico, consulta el paso 14.


    Las acciones `PutObject`, `DeleteObject` y `ListBucket` son obligatorias para que AppsFlyer realice las acciones necesarias en tu bucket.
13. Haz clic en **Revisar política**.
14. Introduce un **nombre de política.**
15. Haz clic en **Crear política**.
16. En tu consola de AWS, ve a **Administración de acceso** > **Roles**.

    [![](https://files.readme.io/85a4a81b5ebd131b6b3a20ca6ee136a0d10556363cff2deab96397ec889db141-31237648138513.png)](https://files.readme.io/85a4a81b5ebd131b6b3a20ca6ee136a0d10556363cff2deab96397ec889db141-31237648138513.png)
17. Haz clic en **Crear rol.**
18. Selecciona **Otra cuenta de AWS** para proporcionar acceso entre cuentas entre tu cuenta de AWS y la cuenta de AWS de AppsFlyer.

    [![](https://files.readme.io/1f8db2c84d1cbde4a88fd6d7dace3eb5cb65f8fc9608b0ec568921a2b7c85759-31237653535761.png)](https://files.readme.io/1f8db2c84d1cbde4a88fd6d7dace3eb5cb65f8fc9608b0ec568921a2b7c85759-31237653535761.png)
19. Introduce **ID de cuenta.** Este es el ID de cuenta que ya copiaste del Dashboard de AppsFlyer.
20. Selecciona **Requerir ID externo**. Este es el ID externo que has copiado del dashboard de AppsFlyer.
21. Cuando se te pida seleccionar una política de las políticas existentes en tu cuenta de AWS, elige la política creada anteriormente.
22. Haz clic en el nombre del rol recién creado para abrir su ventana

    [![](https://files.readme.io/9b61cf2c8ec3efd9f6548e1ee6b6ca945dd1160901516f93cd16ac3544d3aade-31237648139793.png)](https://files.readme.io/9b61cf2c8ec3efd9f6548e1ee6b6ca945dd1160901516f93cd16ac3544d3aade-31237648139793.png)
23. Registra el **ARN del rol**.
24. En la ventana de integración de AppsFlyer S3, ingresa el ARN y el nombre del bucket en los campos apropiados.

    Si quieres transferir los archivos a una carpeta específica dentro de un bucket, proporciona el nombre del bucket con las carpetas subsiguientes dentro de él, separadas por "/"; por ejemplo (bucketname/foldername/foldername).

    Si proporcionas un nombre de carpeta que no existe, AppsFlyer la crea durante el proceso de carga.
25. Haz clic en **Agregar conexión**.  
    Una vez que el proceso de integración esté completo y se haya cargado una audiencia, un CSV con los IDs de los dispositivos estará disponible en el bucket.

</Accordion>

>
> Para cargar audiencias en Braze, utiliza la función `setPartnerData` del SDK de AppsFlyer para pasar el ID externo de Braze de cada usuario a AppsFlyer. A continuación se muestran algunos ejemplos de uso:

>
> <Tabs>
> <Tab title="Android">
>
> ```java
> Map<String, Object> brazeData = new HashMap<>();
> brazeData.put("external_user_id", "some-braze-external-id-value");
> AppsFlyerLib.getInstance().setPartnerData("braze_int", brazeData);
> ```
>
> </Tab>
>
> <Tab title="iOS">
>
> ```objectivec
> NSDictionary *brazeInfo = @{
> @"external_user_id":@"some-braze-external-id-value"
> };
> [[AppsFlyerLib shared] setPartnerDataWithPartnerId:@"braze_int"
> partnerInfo:brazeInfo];
> ```
>
> </Tab>
> </Tabs>
>

No es necesario configurar un parámetro dedicado para el ID Externo de Braze si:

* El CUID tiene el mismo valor que el ID Externo de Braze.
