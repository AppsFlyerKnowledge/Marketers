## Setting up Amazon Fire TV ad attribution

App owners can attribute app installs and in-app events generated by Amazon Fire TV advertising.

Requirements: 

1. <Anchor target="_blank" href="https://developer.amazon.com/docs/fire-tv/getting-started-developing-apps-and-games.html">Develop an Amazon Fire TV app.</Anchor>
2. <Anchor target="_blank" href="https://developer.amazon.com/apps-and-games">Publish your app in the Amazon Appstore</Anchor>.
3. <Anchor target="_blank" href="/marketers/docs/set-up-multi-store-android-attribution#set-up-tasks">Set up attribution</Anchor> and viewing for your Amazon Fire TV app installs and in-app data.  
   Use the single or multiple app set-up methods.  
   

| Set-up method | Description |
| --- | --- |
| <Anchor target="_blank" href="/marketers/docs/set-up-multi-store-android-attribution#single-dashboard-apk-preparation">Single app</Anchor> | View combined, out-of-store market results for a single app |
| <Anchor target="_blank" href="/marketers/docs/set-up-multi-store-android-attribution#dashboard-per-store-apk-preparation">Multiple apps</Anchor> | <ul><li>View individual, out-of-store market results for each app</li><li>For Amazon Fire ads: Amazon Appstore install data is associated with each app</li></ul> |

4. <Anchor target="_blank" href="/marketers/docs/testing-the-sdk-integration-for-marketers#testing-from-the-dashboard">Test the integration</Anchor> using the Android SDK testing method in the AppsFlyer dashboard.
