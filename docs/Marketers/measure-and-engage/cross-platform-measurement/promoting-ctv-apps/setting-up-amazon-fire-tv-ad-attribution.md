## Setting up Amazon Fire TV ad attribution

App owners can attribute app installs and in-app events generated by Amazon Fire TV advertising.

Requirements: 

1. [Develop an Amazon Fire TV app.](https://developer.amazon.com/docs/fire-tv/getting-started-developing-apps-and-games.html)
2. [Publish your app in the Amazon Appstore](https://developer.amazon.com/apps-and-games).
3. [Set up attribution](/docs/set-up-multi-store-android-attribution#set-up-tasks) and viewing for your Amazon Fire TV app installs and in-app data.  
   Use the single or multiple app set-up methods.  
   

| Set-up method | Description |
| --- | --- |
| [Single app](/docs/set-up-multi-store-android-attribution#single-dashboard-apk-preparation) | View combined, out-of-store market results for a single app |
| [Multiple apps](/docs/set-up-multi-store-android-attribution#dashboard-per-store-apk-preparation) | <ul><li>View individual, out-of-store market results for each app</li><li>For Amazon Fire ads: Amazon Appstore install data is associated with each app</li></ul> |

4. [Test the integration](/docs/testing-the-sdk-integration-for-marketers#testing-from-the-dashboard) using the Android SDK testing method in the AppsFlyer dashboard.
