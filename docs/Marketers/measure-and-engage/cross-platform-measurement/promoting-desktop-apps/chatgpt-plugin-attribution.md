## What are ChatGPT plugins?

ChatGPT plugins are like apps within the chat, that users can get from the Plugin marketplace.

There’s a simple API that enables those plugins to generate some actions directly from the chat. For example, users can purchase items, search private databases, or create documents from the chat content on Google Drive.

You can read about ChatGPT plugins and join the waitlist [here](https://openai.com/blog/chatgpt-plugins).

### How do marketers use ChatGPT plugins?

OpenAI still has ChatGPT plugins in Beta, and very few companies have actually implemented them so far. However, the possibilities for marketers are almost endless.

AppsFlyer enables marketers to measure the usage and LTV of users on those “apps” across multiple platforms side by side, for a truly holistic view of users.

### ChatGPT attribution examples

Find below 3 use cases of combining ChatGPT plugin data with other platforms.

#### Use case 1 - Holistic LTV

An existing travel app user installs the app's ChatGPT plugin, which requires the user's authentication. When the user books a hotel via the chat plugin, the plugin sends to AppsFlyer a purchase in-app event. According to the marketer's setup, the ChatGPT events are attributed to the original media source of the user on the mobile app, where the holistic LTV of the user across the mobile app and ChatGPT plugin is displayed.

#### Use case 2 - Platform performance comparison

Ori Mind Me is a reminder app, which enables generating reminders by either the mobile app or ChatGPT plugin. All reminders are recorded in AppsFlyer as in-app events. This enables the marketer to compare in AppsFlyer the quantity and type of reminders generated by each platform.

#### Use case 3 - Show me the movie

Webmovs is a streaming service, which promotes a new ChatGPT plugin on CTV ads. The plugin enables users to describe details about the movie they wish to watch and stream it. AppsFlyer can attribute plugin activity to the CTV impressions.
