Set up Protect360 Validation Rules and alerts to protect your traffic from fraud

<Cards>
  <Card title="Protect360 anti-fraud guide" href="/docs/protect360-anti-fraud-guide" icon="fa-solid fa-shield-halved">
    Attribution fraud drains marketing budgets, pollutes marketing performance data, and can turn successful campaigns into losing ones. Protect360 provides app owners with real-time fraud protection and post-attribution detection.
  </Card>
  <Card title="[Closed beta] Validation Rules API" href="/docs/closed-beta-validation-rules-api" icon="fa-solid fa-shield-halved">
    Automate the creation and management of Validation Rules at scale. The Validation Rules API lets technical teams programmatically create, update, patch, and delete rules, going beyond the UI's value limits and cutting out manual rule management overhead.
  </Card>
  <Card title="Closed Beta: Protect360 Explore insights with Val anti-fraud assistant" href="/docs/closed-beta-protect360-explore-insights-with-val-anti-fraud-assistant" icon="fa-solid fa-shield-halved">
    Val is a preemptive anti-fraud assistant in Protect360 that provides weekly insights to help highlight trends, recommend actions, and improve fraud protection. By surfacing actionable intelligence, Val transforms fraud detection from reactive to proactive.
  </Card>
  <Card title="Protect360 onboarding guide" href="/docs/protect360-onboarding-guide" icon="fa-solid fa-rocket">
    Quickly and effectively safeguard your marketing investments by following this step-by-step onboarding guide to maximize your Protect360 value within just 6 weeks.
  </Card>
  <Card title="[Beta] Fraud protection studio" href="/docs/beta-fraud-protection-studio" icon="fa-solid fa-shield-halved">
    Fraud protection studio (FPS) provides greater control over how fraud detection is applied than usual methods. With FPS, you can choose whether fraud detection data is blocked and reported as fraud or tagged, empowering tailored fraud management.
  </Card>
  <Card title="[Closed beta] Implementing Series of Events Rule for advanced fraud prevention" href="/docs/closed-beta-implementing-series-of-events-rule-for-advanced-fraud-prevention" icon="fa-solid fa-shield-halved">
    Series of events in validation rules allows advertisers to define an event sequence a real user should go through. Any deviation from your defined order, or from the timing between events, is detected and blocked.
  </Card>
  <Card title="Protect360 dashboard" href="/docs/protect360-dashboard" icon="fa-solid fa-shield-halved">
    The Protect360 dashboard provides insights about fraudulent traffic and installs blocked due to the application of validation rules.
  </Card>
  <Card title="Basic fraud detection and insights​ with ProtectLITE dashboard and reporting" href="/docs/basic-fraud-detection-and-insights-with-protectlite-dashboard-and-reporting" icon="fa-solid fa-shield-halved">
    ProtectLITE provides insights about fraudulent installs blocked by our basic, free protection engine, and installs blocked due to the application of validation rules.
  </Card>
  <Card title="Protect360 raw data reports" href="/docs/protect360-raw-data-reports" icon="fa-solid fa-shield-halved">
    Raw data reports describe installs and in-app events blocked by the Protect360 engine, as well as from manually added Validation Rules.
  </Card>
  <Card title="Implement validation rules to prevent fraud" href="/docs/implement-validation-rules-to-prevent-fraud" icon="fa-solid fa-shield-halved">
    Validation rules add a custom layer of protection against incorrectly targeted campaigns and fraud. The rules enable app owners to control which installs and in-app event attributions get blocked, or attributed to the last valid source.
  </Card>
  <Card title="Implement Google License Verification Library (LVL)" href="/docs/implement-google-license-verification-library-lvl" icon="fa-solid fa-code">
    Protect your apps against unauthorized use by adding the Google License Verification Library (LVL) to handle all license-related communication with Google Play.
  </Card>
  <Card title="Implement Apple App Store (itunes) install validation" href="/docs/implement-apple-app-store-itunes-install-validation" icon="fa-solid fa-code">
    Prevent attribution of fraudulent activities by using the Apple install validation service for any iOS install (both organic and non-organic).
  </Card>
  <Card title="[Beta] Advanced Security Protect360 Module" href="/docs/beta-advanced-security-protect360-module" icon="fa-solid fa-shield-halved">
    Strengthen fraud protection for your Android app with the Advanced Security Module. This real-time solution detects and blocks attribution spoofing and manipulated traffic before installs are attributed. Designed for high-traffic apps and Protect360 clients, especially those working with affiliates. The module is fully configurable by you, allowing initial setup and ongoing maintenance to adapt to evolving fraud patterns and protect data integrity.
