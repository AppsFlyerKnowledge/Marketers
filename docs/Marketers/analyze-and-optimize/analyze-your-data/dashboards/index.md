Set up your AppsFlyer dashboards to get the most from your data (including PBA)

<Cards>
  <Card title="Getting started with AppsFlyer dashboards" href="/docs/getting-started-with-appsflyer-dashboards" icon="fa-solid fa-rocket">
    The platform contains multiple dashboards. These dashboards enable you to view your campaign performance and app behavior.
  </Card>
  <Card title="My Dashboards" href="/docs/my-dashboards" icon="fa-solid fa-gauge-high">
    Use "My Dashboards" to design your own dashboard, adding and customizing widgets, charts, and tables that display the exact performance metrics you want, in the way you want to view them.
  </Card>
  <Card title="Activity metrics in My Dashboards" href="/docs/activity-metrics-in-my-dashboards" icon="fa-solid fa-gauge-high">
  </Card>
  <Card title="[Beta] Set up custom metrics in My Dashboards" href="/docs/beta-set-up-custom-metrics-in-my-dashboards" icon="fa-solid fa-gauge-high">
    Define your own metrics and use them to view data in My Dashboards.
  </Card>
  <Card title="Cohort and retention dashboard" href="/docs/cohort-and-retention-dashboard" icon="fa-solid fa-gauge-high">
    The Cohort and retention dashboard (also referred to as simply "Cohort") groups app users by acquisition date. Perform performance analysis across user life cycles (LTV). Use the dashboard to gain insights as to how campaign differences alter campaign metrics.
  </Card>
  <Card title="iOS metrics in the Overview dashboard (SKAN and AppsFlyer metrics side-by-side)" href="/docs/ios-metrics-in-the-overview-dashboard-skan-and-appsflyer-metrics-side-by-side" icon="fa-solid fa-lock">
    View metrics of SKAdNetwork (SKAN) and AppsFlyer attribution frameworks side-by-side in the Overview dashboard. Identify the framework with the best campaign performance metric for you, then leverage it to gain insights and optimize campaigns.
  </Card>
  <Card title="SKAdNetwork (SKAN) overview dashboard by AppsFlyer" href="/docs/skadnetwork-skan-overview-dashboard-by-appsflyer" icon="fa-solid fa-lock">
    The SKAdNetwork (SKAN) dashboard displays campaign metrics reported via iOS SKAN postbacks and additional data points during initial user measurement windows. Modeled metrics which consider null conversions are also available. Data displays using the install or postback arrival date.
  </Card>
  <Card title="Custom dimensions" href="/docs/custom-dimensions" icon="fa-solid fa-file-lines">
    Define your own dimensions and use them to group and view data in the Overview dashboard.
  </Card>
  <Card title="Activity dashboard" href="/docs/activity-dashboard" icon="fa-solid fa-gauge-high">
    See app activity, engagement, and in-app metrics during a given period. Current day metrics update in real-time.
  </Card>
  <Card title="Troubleshooting discrepancies in AppsFlyer dashboards and reports" href="/docs/troubleshooting-discrepancies-in-appsflyer-dashboards-and-reports" icon="fa-solid fa-circle-question">
    Understand why there can be differences and discrepancies when comparing data from different dashboards and reports. Often, this may be because data in one place is lifetime value (LTV) data and in another it's activity data. LTV data is related to installs that occurred during a specified date range. Activity data is events that occurred during a specified date range.
  </Card>
  <Card title="Advanced filter and group by options in events and activity dashboards" href="/docs/advanced-filter-and-group-by-options-in-events-and-activity-dashboards" icon="fa-solid fa-gauge-high">
    Use advanced filter and group by options in events and activity dashboards.
  </Card>
  <Card title="Custom dashboards" href="/docs/custom-dashboards" icon="fa-solid fa-gauge-high">
    Build your own customized dashboards inside AppsFlyer. You can easily select, name, and position the data in your own customized reports.
  </Card>
  <Card title="Using PBA dashboards" href="/docs/using-pba-dashboards" icon="fa-solid fa-gauge-high">
    Get the most out of our PBA dashboard features.
  </Card>
  <Card title="PBA Website Attribution dashboard" href="/docs/pba-website-attribution-dashboard" icon="fa-solid fa-diagram-project">
    Measure the impact of marketing efforts to drive effective website traffic. Which media sources, types, and channels are responsible for visits, conversion events and ad-level metrics are available.
  </Card>
  <Card title="PBA Web-Assisted Installs" href="/docs/pba-web-assisted-installs" icon="fa-solid fa-globe">
    Use the PBA Web-Assisted Installs dashboard to understand the impact of your web marketing efforts on mobile app installs and to enhance the performance of web campaigns.
  </Card>
  <Card title="SDK information (version & consent) dashboard" href="/docs/sdk-information-version-consent-dashboard" icon="fa-solid fa-user-shield">
    Dashboard view of SDK, operating system (iOS, Android) adoption rates, and iOS ATT consent metrics.
  </Card>
</Cards>
