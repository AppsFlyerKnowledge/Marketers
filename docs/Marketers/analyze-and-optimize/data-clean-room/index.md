Leverage data from your AppsFlyer account to obtain privacy-preserving insights

<Cards>
  <Card title="Data Clean Room—Overview" href="/docs/data-clean-room-overview" icon="fa-solid fa-handshake-angle">
    Enrich your user-level data by matching it with AppsFlyer user-level attribution data to create aggregated reports and obtain insights that leverage the value of the combined data.
  </Card>
  <Card title="Data Clean Room—Setting up cloud services" href="/docs/data-clean-room-setting-up-cloud-services" icon="fa-solid fa-handshake-angle">
    Set up one or more data warehouses (BigQuery, Snowflake) and/or cloud storage buckets (Amazon S3, GCS) to share data with the Data Clean Room and receive reports.
  </Card>
  <Card title="Data Clean Room—Working with connections" href="/docs/data-clean-room-working-with-connections" icon="fa-solid fa-handshake-angle">
    Connect your cloud services to the Data Clean Room in order to upload data and receive reports.
  </Card>
  <Card title="Data Clean Room—Working with sources" href="/docs/data-clean-room-working-with-sources" icon="fa-solid fa-handshake-angle">
    Set up the custom data sources you share with the Data Clean Room (DCR) for matching with attribution data and creating DCR reports.
  </Card>
  <Card title="Data Clean Room—Working with reports" href="/docs/data-clean-room-working-with-reports" icon="fa-solid fa-handshake-angle">
    Work with the reports you have set up in the Data Clean Room (DCR).
  </Card>
  <Card title="Data Clean Room—Creating Attribution data reports" href="/docs/data-clean-room-creating-attribution-data-reports" icon="fa-solid fa-handshake-angle">
    Create Attribution data reports to match user-level data from installs/retargeting events with data from your systems.
  </Card>
  <Card title="Data Clean Room—Creating In-app event reports" href="/docs/data-clean-room-creating-in-app-event-reports" icon="fa-solid fa-handshake-angle">
    Create In-app event reports to focus on user activity occurring after an app has been installed. Extract specific event parameters from your in-app event raw data, optionally match the data with custom sources, then process and present it in aggregated form.
  </Card>
  <Card title="Data Clean Room—Dynamic Query" href="/docs/data-clean-room-dynamic-query" icon="fa-solid fa-handshake-angle">
    Run custom DCR queries in real time on your attribution data in the AppsFlyer system, your custom sources, or a combination. Preview the results of your queries or download the full results.
  </Card>
  <Card title="Data Clean Room—Data enrichment through tech partner integrations" href="/docs/data-clean-room-data-enrichment-through-tech-partner-integrations" icon="fa-solid fa-handshake-angle">
    Enrich your data and enhance your Data Clean Room (DCR) reports with data from our integrated tech partners.
  </Card>
