**At a glance:** Work with the reports you have set up in the Data Clean Room (DCR).

## Introduction

This article covers working with the reports you have already created. You can view the full list of these reports and their status in the **Reports** tab of the DCR.  
  
If you are looking for instructions on creating new DCR reports, you can find them in these articles:

* <Anchor target="_blank" href="/marketers/docs/data-clean-room-creating-attribution-data-reports">Creating Attribution data reports</Anchor>
* <Anchor target="_blank" href="/marketers/docs/data-clean-room-creating-in-app-event-reports">Creating In-app event reports</Anchor>

## Editing or deleting a report

**To edit a report:**

1. Go to the **Reports** tab of the **Data Clean Room.**
2. In the list of reports, hover over the row of the report you want to edit.
3. Click the edit button ![edit_button.png](https://files.readme.io/f1694e9f696448da210e0a8b6458acaca9e50c0ed5f3931acbac66b0f6102b1e-7430545546129.png) that displays on the right side of the row.
4. On the **Edit report** page, make changes to the report settings as necessary.
   * Report name can not currently be edited.
5. To edit the report destination:
   1. Scroll down to the **Report destination** section.
   2. Click the edit button ![edit_button.png](https://files.readme.io/f1694e9f696448da210e0a8b6458acaca9e50c0ed5f3931acbac66b0f6102b1e-7430545546129.png) next to the current report destination.
   3. Make the necessary changes in the **Report destination** dialog.
   4. Click **Apply** to implement your changes.
6. Click the **Update** button to save the report with the new settings or click **Discard changes** to undo your changes.

**To delete a report:**

1. Go to the **Reports** tab of the **Data Clean Room.**
2. In the list of reports, hover over the row of the report you want to delete.
3. Click the delete button ![delete_button.png](https://files.readme.io/6a9aa9444651449ba4c11cabbb6964bb4661aaad8806bdf8198c3e3e1b66ca72-7430526510737.png) that displays on the right side of the row.
4. In the dialog, confirm that you want to delete the report.
