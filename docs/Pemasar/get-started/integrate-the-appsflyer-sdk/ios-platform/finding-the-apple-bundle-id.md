> **Sekilas:** Menemukan ID bundel Apple dan menggunakannya sesuai kebutuhan.

ID bundel Apple adalah identifier unik yang diasosiasikan dengan aplikasi iOS.

* Pemilik aplikasi mengatur ID ini
* Apple merekomendasikan bahwa pemilik aplikasi menamai ID menggunakan notasi nama domain terbailk.  
  Contoh: com.domain.appname

**Untuk menemukan ID bundel Apple:**

1. Masuk ke akun [iTunes Connect](https://itunesconnect.apple.com/).
2. Klik aplikasi yang relevan.
3. Buka **Umum** > **Informasi Aplikasi.  
   ID Bundel** ditampilkan.
