## Apa yang dapat saya lakukan dari pusat Keamanan?

**Pusat Keamanan** memberi Anda gambaran sekilas tentang status keamanan akun AppsFlyer Anda. Klik tombol di bagian mana pun dari **Pusat keamanan** untuk mengakses fitur berikut:

* Kelola pengguna akun Anda
* Menerapkan atau mengelola keamanan login yang ditingkatkan – <Anchor target="_blank" href="/marketers/id/docs/set-up-sso-authentication-with-your-identity-provider-idp">sistem masuk tunggal (SSO)</Anchor> atau <Anchor target="_blank" href="/marketers/id/docs/implementing-and-using-2fa-login">autentikasi dua faktor (2FA)</Anchor>
* Ambil atau setel ulang <Anchor target="_blank" href="/marketers/id/docs/managing-appsflyer-tokens">token API AppsFlyerAnda</Anchor>
* Terapkan atau kelola <Anchor target="_blank" href="/marketers/id/docs/set-up-your-api-allowlist">daftar izin OneLinkAnda</Anchor>
* Unduh <Anchor target="_blank" href="/marketers/id/docs/audit-log">log audit</Anchor> untuk aktivitas login dan panggilan API

## Akses pusat Keamanan

**Untuk mengakses pusat Keamanan:**

1. Dari bilah menu, akses menu pengguna (tarik-turun alamat email).
2. Pilih **Security center.**
