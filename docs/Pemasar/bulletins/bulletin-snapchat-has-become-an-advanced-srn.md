| **Headline** | Snapchat has become and Advanced <Anchor target="_blank" href="/marketers/id/docs/self-reporting-networks-srns">Self-Reporting Network (SRN)</Anchor> |
| --- | --- |
| **Effective Date** | September 13, 2023 |
| **Where is it changing** | The Snapchat integration page in Active Integrations |
| **Required actions** | No action is required |
| **What's changing?** | As of September 12, 2023, Snapchat has become an advanced SRN. This means:<ul><li>Clicks and impressions are sent to AppsFlyer and attribution without IDFA will be done probabilistically</li><li>Snapchat view-through conversions are <Anchor target="_blank" href="/marketers/id/docs/about-raw-data-identifier-restrictions#pembatasan-sumber-media">partially restricted</Anchor> in raw data reports</li></ul> |
