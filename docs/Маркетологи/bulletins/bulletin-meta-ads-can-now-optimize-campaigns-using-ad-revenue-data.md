| <span id="whats-new"></span>Что нового? | В Meta ads появилась возможность оптимизировать кампании по продвижению Android-приложений с помощью события постбэка по доходу от рекламы **AdImpression**. |
| --- | --- |
| <span id="update-date"></span>Дата обновления | 24 октября 2024 г. |
| <span id="what-you-need-to-know"></span>Что нужно знать | <ul><li>На данный момент оптимизация через событие **Adimpression** доступна только для:</li><li>Отображение серым цветом может означать, что [критерии соответствия требованиям не соблюдены](https://ru-ru.facebook.com/business/help/571188993373447?id=561906377587030).</li><li>Событие *af\_ad\_revenue* доступно только для тарифов с <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-cost-and-revenue-data">расширенной подпиской ROI360</Anchor>. Кроме того, вам необходимы <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">доход от рекламы на уровне показов (через SDK), либо интеграция уровня показов (через SDK) с уровнем устройства (через S2S API)</Anchor>.<ul><li>Тарифы, не включающие в себя ROI360, могут отправлять данные о доходах от рекламы, используя другие названия событий.</li></ul></li></ul> |
| <span id="what-you-need-to-do"></span>Что необходимо сделать | <ul><li>Для клиентов с ROI360: используйте <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">доход от рекламы на уровне показов (через SDK) или интеграцию уровня показов (через SDK) с уровнем устройства (через S2S API)</Anchor>.</li><li><Anchor target="_blank" href="/marketers/ru/docs/meta-ads-in-app-event-mapping#сопоставление-данных-о-доходах-от-рекламы-для-оптимизации-кампании">Сопоставьте событие af\_ad\_revenue с **Adimpression**</Anchor>.</li></ul> |
| <span id="additional-resources"></span>Дополнительные ресурсы | В [справочном центре для бизнеса](https://ru-ru.facebook.com/business/help/330074040129013) более подробно говорится о том, как получить максимум от значений конверсии в качестве целевого показателя эффективности для рекламных объявлений приложений в Ads Manager от Meta. |
