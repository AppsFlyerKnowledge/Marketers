| **Что нового** | Теперь доходы от рекламы на уровне показов доступны через API AdRevenue в SDK, а не через коннектор SDK для доходов от рекламы. |
| --- | --- |
| **Начиная с** | AppsFlyer SDK версии 6.15 |
| **Что нужно знать** | <ul><li>До сих пор доход от рекламы на уровне показов был доступен через **коннектор** SDK AppsFlyer для доходов от рекламы. С момента введения изменений интеграция будет осуществляться непосредственно через AppsFlyer **SDK**, используя API для доходов от рекламы в SDK.</li><li>Коннектор SDK для доходов от рекламы продолжит работать с версиями:<ul><li>AppsFlyer SDK для Android версии 6.14.2 и ниже.</li><li>AppsFlyer SDK для iOS версии 6.14.6 и ниже.</li></ul></li></ul> |
| **Что нужно сделать** | <ul><li>Чтобы перейти на AppsFlyer SDK версии 6.15+, если у вас уже установлен коннектор SDK для доходов от рекламы, вам необходимо удалить его и интегрировать новый API SDK для доходов от рекламы.</li><li>Требуется разработчик. См. <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/ad-revenue">инструкции по API SDK для доходов от рекламы</Anchor> для разработчиков.</li><li>Узнать больше об <Anchor target="_blank" href="/marketers/ru/docs/integrate-the-roi360-ad-revenue-sdk-api">интеграции API для доходов от рекламы на уровне показов в SDK</Anchor>.</li></ul> |
