    <tr>
      <td>
        Что меняется
      </td>
      <td>
        Частота обновления данных об установках и событиях в приложении меняется. В таблице указана частота обновления до и после изменения.

        #### Частота обновления данных по типу события

        | SDK (пакет средств разработки ПО) | До изменения (мин.) | После изменения<br /><br />(минуты) |
        | --- | --- | --- |
        | Установка, реатрибуция, повторное вовлечение | 3-5 | 15-30 |
        | Внутреннее событие приложения | 90 | 30-60 |
      </td>
    </tr>
    <tr>
      <td>
        Что меняется
      </td>
      <td>
        Изменение частоты обновления данных затрагивает перечисленные дэшборды и инструменты отчетности. Изменение будет происходить поэтапно:

        **Этап 1—sначиная с 12 сентября 2021 г. (дата может измениться)**

        * Дэшборды:
          * Информация о компании
          * Обзор V2
          * Тип периода подписки
          * KPIdays.jpg
          * Специфика
        * Агрегированные отчеты с использованием Pull API.

        **Этап 2—начиная с 6 октября 2021 г. (запланировано)**

        * Дэшборды:
          * Активные
          * Ретаргетинг
        * API: Cohort
      </td>
    </tr>
    <tr>
      <td>
        Что не меняется
      </td>
      <td>
        Master API и сырые данные
      </td>
    </tr>
    <tr>
      <td>
        Требуется действие пользователя
      </td>
      <td>
        * При просмотре или загрузке данных учитывайте изменившуюся актуальность данных.
        * Если вы используете обзорный дэшборд для теста интеграции SDK или интеграции с партнером по рекламной сети, события установки будут отображаться с задержкой. Для проверки тестов интеграции используйте отчеты о сырых данных.
      </td>
