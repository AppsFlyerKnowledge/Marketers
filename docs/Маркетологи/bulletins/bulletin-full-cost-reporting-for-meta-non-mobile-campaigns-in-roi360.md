| **Раздел** | **Срок** |
| --- | --- |
| **Новинка** | После этого обновления ROI360 теперь отражает полную стоимость немобильных кампаний Meta в отчетах по каналам и гео, а количество зарегистрированных кликов Meta увеличилось. Это изменение устраняет известное расхождение между дэшбордом Meta и отчетами по гео и каналам.<br /><br />Meta отражает стоимость немобильных кампаний без идентификаторов приложений. ROI360 относит эту стоимость к приложениям, у которых настроена атрибуция в AppsFlyer, и распределяет ее между ними пропорционально числу конверсий каждого приложения. Этот подход применяется как в отчете по гео, так и в отчете по каналам. После обновления:<ul><li>Стоимость на уровне кампании одинакова в отчетах по гео и каналам, поскольку оба отчета включают все затраты, о которых сообщает Meta.</li><li>Стоимость на уровне приложения может различаться в отчетах по гео и каналам. ROI360 распределяет стоимость между приложениями, сопоставляя разбивку стоимости с разбивкой по конверсиям. Поскольку в этих двух отчетах используется разная детализация (по гео и по каналам), разбивка конверсий по приложениям различается, поэтому различается и стоимость, распределенная по каждому приложению.</li></ul> |
| **Дата вступления в силу** | 9 ноября 2026 г.<br /><br />Изменения внедряются постепенно. Они применяются к новым данным в дальнейшем и заполняют исторические данные за последние 7 дней. |
| **Что нужно сделать** | Если вы используете внутреннюю логику, чтобы дополнить стоимость из Meta в отчетах по каналам и гео, удалите эту логику после выхода обновления, чтобы избежать завышения стоимости в отчетности. |
| **Что нужно знать** | **Отчет по каналам**<ul><li>Изменение: сегодня ROI360 учитывает только ту стоимость, которую можно однозначно отнести к мобильному приложению (iOS или Android). После этого обновления ROI360 отражает общую стоимость немобильных кампаний Meta и определяет приложения с помощью данных атрибуции и логики разделения стоимости. Это устраняет известное расхождение с Meta.</li><li>Влияние: общая стоимость в отчете по каналам увеличивается на уровнях кампании и приложения, чтобы соответствовать вашим фактическим затратам в Meta.</li></ul>Пример см. в разделе [Пример отчета по каналу](#REPLACE_CHANNEL_EXAMPLE_ID).<br /><br />**Отчет по геоданным**<ul><li>Изменение: сегодня стоимость на уровне гео для немобильных кампаний Meta доступна только бета-клиентам. После этого обновления стоимость на уровне гео доступна всем клиентам в дэшборде и в отчете Cost ETL Geo. ROI360 распределяет стоимость между гео и атрибутированными приложениями с помощью логики разделения стоимости.</li><li>Влияние: общая стоимость, измеряемая в Meta с детализацией по гео, увеличивается на уровнях кампании и приложения.</li></ul>Пример см. в разделе [Пример отчета по гео](#REPLACE_GEO_EXAMPLE_ID).<br /><br />**Метрика «Клики»**<ul><li>Изменение: **после этого обновления ROI360 использует в Meta другую метрику для кликов.** Сейчас ROI360 использует в Meta метрику Inline clicks, которая измеряет только количество кликов по ссылкам на выбранные целевые направления или пользовательский опыт — на ресурсах, принадлежащих Meta, и за их пределами. После этого обновления ROI360 использует метрику кликов Meta, которая измеряет общее количество кликов по рекламе. Сюда могут входить клики по встроенным ссылкам, отметки «Нравится» для страниц, комментарии к публикациям и ответы на события.</li><li>Воздействие: количество кликов, отражаемых в отчетности Meta, увеличится.</li></ul> |

## Примеры

### Пример отчёта по каналу

**Когда дэшборд Meta показывает стоимость по устройству показа:**

| **Устройство показа** | **затраты;** |
| --- | --- |
| iPhone | 100 долл. |
| Android; | 200 долл. |
| Десктоп | 50 долл. |
| **В общем** | **$350** |

**До обновления ROI360 показывает частичную стоимость:**

| **Строка** | **затраты;** |
| --- | --- |
| id12345 | 100 долл. |
| android.com | 200 долл. |
| **В общем** | **$300** |

ROI360 показывает только ту стоимость, которая однозначно относится к мобильным приложениям. Остальное он не показывает. В этом примере это $50, которые Meta вернула с параметром «устройство показа = desktop».

**После обновления ROI360 отражает все расходы:**

| **Строка** | **Соотношение** | **затраты;** |
| --- | --- | --- |
| id12345 | 0.3 | $105 |
| android.com | 0.6 | $210 |
| www.test.com | 0.1 | $35 |
| **В общем** |  | **$350** |

ROI360 показывает всю стоимость на уровне кампании в соответствии с отчетностью Meta. Он распределяет стоимость между атрибутированными приложениями (мобильными и немобильными).

### Пример гео-отчета

**Когда дэшборд Meta показывает стоимость по гео:**

| **Регион** | **затраты;** |
| --- | --- |
| Великобритания | 200 долл. |
| BE | $150 |
| **В общем** | **$350** |

**После обновления ROI360 показывает стоимость по гео и приложению:**

| **Регион** | **Строка** | **затраты;** |
| --- | --- | --- |
| Великобритания | id12345 | 50 долл. |
| Великобритания | android.com | $150 |
| BE | id12345 | 50 долл. |
| BE | android.com | 100 долл. |
| **В общем** |  | **$350** |
