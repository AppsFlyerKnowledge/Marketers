| **Что нового** | У оптимизации креативов есть API-интеграция с Unity, которая позволяет нам получать данные об эффективности креативов. В ближайшее время API будет обновлен. В рамках этого обновления вам нужно обновить роль организации сервисного аккаунта в Unity, чтобы продолжать получать данные Unity. |
| --- | --- |
| **Дата обновления** | Октябрь 10, 2024 г. |
| **Что важно знать** | <ul><li>Unity вводит новую интеграцию API.</li><li>Старая API-интеграция позволяет получать данные до даты ее отключения — 14 ноября 2024 года.</li></ul> |
| **Что необходимо сделать:** | Вам необходимо обновить роль организации сервисного аккаунта в Unity, добавив роль "Advertisers API Stats Viewer" в дополнение к другой роли, чтобы продолжать получать данные после 14 ноября 2024 года.<br /><br /><Anchor target="_blank" href="/marketers/ru/docs/creative-optimization-partner-integrations#для-выбора-роли-аккаунта-службы-организации">Следуйте нашим инструкциям, чтобы обновить роль в Unity</Anchor> |
