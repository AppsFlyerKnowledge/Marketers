        **Что нового?**
      </td>
      <td>
        В отчеты по сырым данным добавлены новые поля.

        * SDK (пакет средств разработки ПО)
        * contributor1\_engagement\_type
        * contributor2\_engagement\_type
        * contributor3\_engagement\_type

        Параметры могут возвращать следующие значения: preload (предварительная загрузка), click\_to\_download (от клика к скачиванию), click\_to\_app (от клика в приложение), engaged\_click (клик взаимодействия), engaged\_view (просмотр взаимодействия), view (просмотр), listening (прослушивание), или, если не сообщается, они будут пусты.

        | Значение IP-адреса | Description(Описание) |
        | --- | --- |
        | preload (предварительная загрузка) | Приложение предварительно загружено OEM на заводе или поставщиком при первой активации устройства. В качестве альтернативы мастер загрузки предлагает пользователям загрузить приложение при первой активации устройства. |
        | click\_to\_download (по клику к скачиванию) | Когда пользователь взаимодействует с рекламой, приложение автоматически загружается и устанавливается на устройство без перенаправления в магазин приложений. |
        | click\_to\_app (по клику в приложение) | Клик по рекламе, сканирование QR-кода, диплинк или любой другой клик, который перенаправляет пользователя на приложение или в соответствующий магазин приложений для загрузки приложения. |
        | engaged\_click (вовлеченный клик) | Клик, при котором пользователь остается в том же контексте, взаимодействуя с рекламой, и НЕ направляет его в магазин приложений или для запуска приложения. |
        | engaged\_view (вовлеченный просмотр) | Просмотр взаимодействия — это когда происходит осмысленный просмотр. В качестве примера: когда пользователь просматривает не менее 10 секунд видеорекламы с возможностью пропуска или завершения видео. |
        | view (просмотр) | Просмотр объявления — это когда объявление отображается, и происходит показ. Примеры: баннеры, рекламные вставки или видеоролики без взаимодействия. |
        | listening (прослушивание) | Прослушивание — это когда пользователь слушает аудиорекламу, например рекламу в подкасте. |
      </td>
    </tr>

        **На что это влияет**
      </td>
      <td>
        * Рекламодатели и агентства, имеющие доступ к сырым данным, работают с рекламными сетями, которые сообщают об этих полях.
          * Preload и click\_to\_app для диплинков будут заполнены AppsFlyer независимо от того, сообщают ли рекламные сети об этих полях.
        * Это относится к следующим отчетам по сырым данным: Data Locker, Pull API, Export Page и Push API.
          * Эти поля не выбраны по умолчанию (за исключением выбора всех в Push API). Чтобы использовать эти поля, необходимо вручную выбрать их в продукте сырых данных.
