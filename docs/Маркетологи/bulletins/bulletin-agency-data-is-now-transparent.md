| **Что нового** | Теперь все агентства прозрачны. Это изменение расширяет ваши возможности анализа и оптимизации своих маркетинговых инвестиций, обеспечивая бóльшую детализацию. |
| --- | --- |
| **Дата обновления** | 12 марта 2025 г. |
| **Что важно знать** | **До изменения**: У непрозрачных агентств в поле «Медиаисточник» отображалось название агентства, а не конкретной рекламной сети.<br /><br />**После изменения**:<ul><li>Вам будут полностью доступны данные всех кампаний, управляемых агентствами, вплоть до уровня медиаисточника, независимо от ранее заданных настроек прозрачности. То есть в поле медиаисточника будет отображаться конкретная рекламная сеть, а не название агентства. Вы по-прежнему сможете группировать данные по агентствам.</li><li>Дэшборды: Данные агентств за прошлые периоды также будут прозрачны.</li><li>Отчеты: Данные в отчетах, полученных до внесения изменений, обновляться не будут. Например, отчеты для Data Locker до обновления будут содержать непрозрачные данные агентства, а отчеты, сгенерированные после обновления, будут содержать прозрачные данные агентства.</li><li>Правила валидации Protect360, определенные для «непрозрачных агентств», будут переклассифицированы как правила для «агентств». Правила продолжат работать без изменений в рамках обновленной модели прозрачности агентств с сохранением всех остальных заданных настроек.</li><li>При работе с данными о затратах, полученными до этого изменения, агрегированные затраты могут отображаться в нескольких строках: одна — с прежним названием агентства (до изменения), а другая — непосредственно с названием медиаисточника (после изменения). В этом случае данные о затратах, полученные до изменения, следует заменить данными, полученными после изменения.</li></ul> |
| **Что необходимо сделать:** | Если для каких-то из ваших внутренних рабочих процессов используется текущее «название агентства», представленное в качестве медиаисточника для непрозрачных агентств, пересмотрите эти рабочие процессы и рассмотрите возможность их модификации с учетом этого изменения.<br /><br />Например, группировка данных на дэшбордах по медиаисточникам или агентствам. В отчетах при необходимости можно использовать поля `media_source` или `af_prt`. |
