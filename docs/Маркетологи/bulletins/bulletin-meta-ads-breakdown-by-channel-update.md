| Раздел | Подробности |
| --- | --- |
| **Что нового** | Meta теперь требует отдельного подтверждения согласия для каждого рекламного аккаунта на использование разбивки `impression_device`, начиная с 6 августа 2026 года. Поскольку API отчетности Meta не может возвращать данные о расходах с разбивкой одновременно по географии и каналу в одном запросе, у учетных записей без этого согласия данные будут неполными:<ul><li>В представлении Мои дэшборды по умолчанию могут отсутствовать данные о стоимости с разбивкой по каналам</li><li>Данные Meta могут отсутствовать в Cost ETL</li></ul>Это же ограничение также влияет на данные об эффективности креативов с разбивкой по каналам. |
| **Дата вступления в силу** | 6 августа 2026 г. |
| **Что важно знать** | Meta автоматически применяет это согласие для клиентских аккаунтов AppsFlyer. До 6 августа вам не нужно предпринимать никаких действий.<ul><li>Если после 6 августа у вас отсутствуют данные о стоимости с разбивкой по каналам или данные об эффективности креативов с разбивкой по каналам, значит, автоматическое подтверждение еще не применено к вашему аккаунту.</li></ul> |
| **Что необходимо сделать:** | Выполните следующие шаги:<ol><li>После 6 августа проверьте данные о стоимости с разбивкой по каналам (Мои дэшборды) и данные об эффективности креативов с разбивкой по каналам.</li><li>Если вы заметите расхождение, обратитесь напрямую в Meta за инструкциями по включению функции согласия или к представителю AppsFlyer за помощью.</li><li>Когда подтверждение будет применено к вашему аккаунту, данные за прошлые периоды вскоре автоматически догрузятся.</li><li>Вы также можете напрямую проверить в Ads Manager, включен ли уже для аккаунта параметр Устройство показа. Пошаговые инструкции см. ниже в разделе [Проверка «Показы по устройствам» в Менеджер рекламы](#проверьте-показы-по-устройствам-в-менеджере-рекламы).</li></ol> |

## Проверьте Показы по устройствам в Менеджере рекламы

Чтобы проверить, включены ли уже «Показы по устройствам» для рекламного аккаунта:

1. Перейдите в <Anchor target="_blank" href="https://adsmanager.facebook.com/">Менеджер объявлений</Anchor> и выберите **Настройки**.

[![Панель инструментов Менеджер рекламы с кнопкой «Настройки»](https://files.readme.io/64c9ac8d571e88bfd098b542456886cc64d6320bf3856721335a077c4f19e5b5-49469436208529.png)](https://files.readme.io/64c9ac8d571e88bfd098b542456886cc64d6320bf3856721335a077c4f19e5b5-49469436208529.png)

2. На панели Обзор креативов выберите **Доставка**.
3. В разделе "Доставка" найдите **A"Дополнительные разбивки"**.
4. В разделе Дополнительные разбивке проверьте, выбран ли уже значок плюса рядом с **Показы по устройствам** (`impression_device`). Если да, значит, подтверждение согласия активно для этого аккаунта.

[![Панель Дополнительные разбивки в Менеджере рекламы со значками плюса для Время суток, Показы по устройствам и Значение частоты](https://files.readme.io/71eb7c75a3f49a82e98522fcf418acbc6ef378eeda5f093535a168aa8505ade1-49469462456081.png)](https://files.readme.io/71eb7c75a3f49a82e98522fcf418acbc6ef378eeda5f093535a168aa8505ade1-49469462456081.png)
