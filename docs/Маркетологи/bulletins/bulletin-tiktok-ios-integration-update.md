| **Что нового** | AppsFlyer обновляет настройки конфиденциальности для интеграции с TikTok через сеть Advanced Self-Reporting Network (SRN) для iOS. Вот что изменится:<ul><li>Существующий переключатель **«Расширенная конфиденциальность» (AP)** заменяется новым переключателем **«Расширенный обмен данными» (ADS)**, что позволит привести TikTok в соответствие с другими интеграциями SRN в AppsFlyer.</li><li>В связи с этим изменением AppsFlyer будет передавать все события конверсии в TikTok независимо от того, доступен ли рекламный идентификатор (IDFA).</li></ul>Это означает, что будет учитываться больше конверсий в iOS, и TikTok сможет оптимизировать ваши кампании на основе более полной картины их эффективности. |
| **Дата вступления в силу** | 23 июня 2026 г. |
| **Что важно знать** | Ваши настройки будут перенесены автоматически — никаких действий с вашей стороны не требуется. Вот как ваша текущая настройка соотносится с новым переключателем:<ul><li>Если **«Расширенная конфиденциальность»** в данный момент **выключена** → **функция «Расширенный обмен данными»** будет включена</li><li>Если **функция «Расширенная конфиденциальность»** в данный момент **включена** → **функция «Расширенный обмен данными»** будет **отключена**</li></ul> |
