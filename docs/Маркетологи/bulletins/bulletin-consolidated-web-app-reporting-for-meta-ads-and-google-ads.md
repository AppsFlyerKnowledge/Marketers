| Раздел | Подробности |
| --- | --- |
| **Что нового** | <ul><li>Любая атрибуция к `metaweb_int` теперь будет отражаться в отчетах как `Facebook Ads`.</li><li>Любая атрибуция к `googleads_int` теперь будет отражаться в отчетах как `googleadwords_int`.</li><li>Изменение влияет только на новые атрибуции. Существующая атрибуция не изменяется задним числом.</li><li>Это изменение применяется во всех инструментах отчетности, включая дэшборды и экспорт сырых данных.</li><li>Преобразование в «официальный» медиаисточник (например, Facebook Ads, Google Adwords\_int) автоматически **происходит на стороне бэкенда**.</li><li>Полная стоимость веба для Meta Web и Google Web отражается в дэшборде и Cost ETL под основными PID: `facebook_int` и `googleadwords_int` соответственно.</li></ul> |
| **Дата общедоступного выпуска** | 02 ноября 2025 г. |
| **Почему это важно?** | Консолидация обеспечивает целостную отчетность по ВСЕМ вашим кампаниям в конкретной рекламной сети, например Meta или Google, включая полные данные о затратах на мобильные и веб-кампании. |
| **Что необходимо сделать:** | <ul><li>**Процесс настройки кампании не меняется**. Продолжайте использовать исходные идентификаторы PID (`metaweb_int` и `googleads_int`). Это гарантирует, что AppsFlyer будет корректно маршрутизировать постбэки через соответствующие веб-интеграции.</li><li>**В инструментах сырых данных:**<ul><li>поле `original_url` по-прежнему будет отображать исходный PID, использованный в рекламном объявлении,</li><li>поля медиаисточника атрибуции будут отражать обновленные названия.</li></ul></li><li>**Чтобы получать данные о расходах на веб-кампании,** добавьте идентификатор кампании в ссылку атрибуции для получения данных о расходах из Meta Web и Google Web.</li></ul> |
| **Практические рекомендации** | <ul><li>Добавляйте тип кампании в названия кампаний, чтобы упростить классификацию.</li><li>Чтобы включить полную отчетность по стоимости для веб-кампаний, подключите аккаунт сети на вкладке «Стоимость», соответствующей основной интеграции (Facebook Ads, googleadwords\_int).</li></ul> |
| **Будущая поддержка** | <ul><li>AppsFlyer планирует добавить новое измерение (`engagement_platform_group`) для указания типа кампании (приложение или веб).</li><li>Предстоящие PID для CAPI-интеграции будут включать:</li></ul><ul><li>`snapweb_int` → сопоставляется с **snapchat\_int**</li><li>`tiktokweb_int` → сопоставляется с **tiktokglobal\_int**</li><li>`twitterweb_int` → сопоставляется с **Twitter**</li></ul>**<span id="h_01K6T5WZKJ2XP34V3T64TWG153"></span>Примечание**<br />Эти сопоставления уже активны — любые атрибуции, использующие указанные выше PID, автоматически преобразуются в основные PID SRN еще до появления полной поддержки интеграции. |
