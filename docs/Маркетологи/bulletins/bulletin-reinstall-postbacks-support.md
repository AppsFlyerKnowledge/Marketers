| Раздел | Подробности |
| --- | --- |
| **Что нового** | Поддержка **постбэков повторных установок приложения** теперь доступна. Теперь их можно отличить от новых установок. |
| **Дата вступления в силу** | 01/09/2025: |
| **Что важно знать** | Постбэки установки теперь также управляют постбэками повторной установки. Настройте их на странице **Активная интеграция**.<ul><li>**Поддерживаемые сети:** На данный момент доступно только у избранных партнеров (например, Unity Ads). Дополнительные партнеры будут скоро добавлены.</li><li>**Местоположение:** Постбэк установки появляется в разделе **Стандартные постбэки** вкладки **Атрибуция**. Для поддерживаемых сетей эта настройка теперь также управляет постбэками переустановок.</li><li>**Настройки:** Вы можете изменить выпадающий список **Для пользователей из** с **Только этот партнер** на **Все медиаисточники (включая органические)**.</li><li>**Формат:** События повторной установки используют тот же формат постбэка, что и события установки, с добавленным макросом `is_reinstall=true`.</li><li>**Значение:** Это позволяет улучшить измерение и оптимизацию, особенно для партнеров, ориентированных на ретаргетинг.</li></ul> |
| **Что необходимо сделать:** | Эта функция доступна только назначенным партнерам. Если вы хотите получить к ней доступ, свяжитесь с вашим менеджером по развитию партнерства. |
