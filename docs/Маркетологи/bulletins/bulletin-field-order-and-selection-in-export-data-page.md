      <td>
        **Что меняется**
      </td>
      <td>
        Используйте параметр **Порядок полей отчета (CSV)**, чтобы задать последовательность столбцов в отчетах.

        | Параметр | Выбор полей разрешен | Специфика |
        | --- | --- | --- |
        | Значение по умолчанию | Да | * Выбранные поля упорядочены в соответствии с шаблоном AppsFlyer.<br />* В дальнейшем последовательность будет сохранена. Будущие поля будут добавляться справа от существующих полей. |
        | По алфавиту (А-Я) | Да | Выбранные поля упорядочены в алфавитном порядке (по возрастанию). |
        | По алфавиту (Я-А) | Да | Выбранные поля упорядочены в обратном алфавитном порядке (по убыванию). |
        | Устаревший | Ни один | * Поля упорядочены в соответствии с последовательностью столбцов в отчетах, подготовленных с использованием предыдущей версии страницы экспорта данных.<br />* Выбор поля фиксирован и не может быть изменен.<br />* Различия в отчетах по полям зависят от конкретного отчета. |

        В [электронной таблице порядка полей](https://docs.google.com/spreadsheets/d/e/2PACX-1vRGYcMOgC5yy_82yn3DWd3ucLE5KtuTA72eJfvu5KVB9fFH_mYwzM3KpR_inQOnat-KzgVjuuvXa6_g/pub?output=xlsx) есть листы «По умолчанию» и «Устаревшее», содержащие соответствующий список порядка полей.
      </td>
    </tr>
    <tr>

        **Чтобы изменить порядок полей:**

        1. На вкладке **Поля отчета** выберите параметр **Порядок полей отчета (CSV)**.
        2. При необходимости измените выбранные поля, выбирая нужные поля или отменяя их выбор.
        3. Нажмите **Скачать**.
