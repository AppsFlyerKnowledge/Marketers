      </td>
      <td>
        * **Для кого:** Рекламодатели
        * **Что:**
          * Ознакомьтесь с новым интерфейсом и новыми возможностями.
          * **Для существующих правил никаких действий не требуется; они переносятся автоматически.**
          * Рекламодателям с тарифом Protect360 Premium следует использовать отчеты Protect360 по фроду для установок, событий в приложении и постбэков установок вместо отчетов по правилам валидации таргетинга.

    <tr>
      <td>
        **Основные цифры**
      </td>
      <td>
        Начиная с даты вступления в силу становятся доступны новый макет и новая функциональность. 

        Изменения:

        * **Список правил**: На странице правил перечислены все правила в вашей учетной записи.
        * **Конструктор правил**: 
          * Допускаются несколько комбинаций правил.
          * Правила можно применять к одному или нескольким приложениям.
          * Правила можно применять ко всем источникам трафика: органическому, неорганическому, агентскому, SRN и т. д.
          * Один конструктор правил для правил таргетинга кампаний и правил Protect360 (для клиентов Protect360 доступны дополнительные параметры).
          * Клиенты Protect360 также могут создавать правила для блокировки событий в приложении.
          * Доступны новые условия правил.
          * Новые параметры правил позволяют либо блокировать установки, либо блокировать атрибуцию.
          * Установки/события в приложении могут блокироваться несколькими правилами.
        * **Отчеты о сырых данных**:  

        <table><thead><tr><th rowspan="2">Отчеты по правилам валидации для таргетинга </th><th colspan="2">Где теперь доступны данные</th></tr><tr><th>С планом Protect360 Premium</th><th>Без плана Protect360 Premium</th></tr></thead><tbody><tr><td>Недействительные установки</td><td><p><span>Отчет о сырых данных Protect360 по установкам</span></p></td><td><p><span>Отчет о сырых данных Protect360 по установкам</span></p></td></tr><tr><td>Отчет о недействительных событиях</td><td><p><span>Отчет Protect360 с сырыми данными по внутренним событиям</span></p></td><td>-</td></tr><tr><td>Постбэки о недействительных установках</td><td><span>Отчет Protect360 по постбэкам заблокированных установок</span></td><td><span>Отчет Protect360 по постбэкам заблокированных установок</span></td></tr></tbody></table>

          * Отчеты о сырых данных содержат имя правила, введенное создателем/редактором правила, как blocked\_reason\_value, а не идентификатор правила.
        * **Постбэки**: содержат название правила, введённое создателем/редактором правила, в виде blocked\_reason\_value; а не идентификатора правила.
      </td>
    </tr>
    <tr>
      <td>
        **Что вы должны знать**
      </td>
      <td>
        * Рекламным сетям и агентствам нужны <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешения</Anchor> для доступа к отчетам о сырых данных.
        * Рекламные сети и агентства клиентов, не использующих Protect360, не могут получить доступ к дэшбордам Protect360 для просмотра данных правил валидации.
        * Правила с условием **CTIT** при миграции изменяются на **CTIT** AND **is\_preinstalled=no** AND **is\_deeplink=no**.
      </td>
