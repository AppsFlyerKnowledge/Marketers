| **Что нового** | eCPI в обзорном дэшборде теперь включает органические данные. |
| --- | --- |
| **Дата вступления в силу** | 20.03.2024 |
| **Где** | Обзорный дэшборд |
| **Что вам нужно знать** | <ul><li>До даты вступления в силу органические данные не включались в показатель eCPI; только неорганические.</li><li>С даты вступления в силу органические данные включаются в показатель eCPI.</li><li>Это может привести к снижению eCPI, указанного в обзорном дэшборде.</li></ul> |
