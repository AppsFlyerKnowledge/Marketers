| **Что нового** | Срок действия (TTL) по умолчанию для коротких URL-адресов OneLink, созданных с помощью массовой загрузки, SDK (приглашения пользователя) и API OneLink, продлевается каждый раз, когда по ссылке кликают:<ul><li>Массовая загрузка: 365 дней</li><li>Приглашение пользователя в SDK: 60 дней</li><li>API OneLink: 31 день</li></ul> |
| --- | --- |
| **Дата вступления в силу** | 14 января 2024 г |
| **Где** | <ul><li>Массовая загрузка OneLink</li><li>Ссылки для приглашения пользователя (URL-адреса OneLink, созданные через SDK)</li><li>OneLink API</li></ul> |
| **Что меняется** | **До изменения**: у коротких URL-адресов OneLink, созданных с помощью массовой загрузки, SDK (приглашение пользователя) и API OneLink, был срок действия (TTL). После истечения TTL ссылки переставали работать должным образом и не предоставляли данные атрибуции.<br /><br />**После изменения**: у коротких URL-адресов OneLink, созданных с помощью массовой загрузки, SDK (приглашение пользователя) и API OneLink, по-прежнему есть TTL. Однако TTL продлевается каждый раз, когда по ссылке кликают:<ul><li>Массовая загрузка: 365 дней</li><li>Приглашение пользователя в SDK: 60 дней</li><li>API OneLink: 31 день</li></ul> |
| **Что вы должны знать** | <ul><li>Изменение затрагивает новые и уже существующие короткие URL-адреса OneLink с TTL.</li><li>Для API OneLink:<ul><li>Вы можете изменить TTL по умолчанию, добавив параметр `ttl={value}` и указав количество дней, часов или минут. Например, `ttl=7d`, `ttl=12h` или `ttl=10m`.</li></ul></li><li>Для API OneLink и массовой загрузки:<ul><li>Если вы не хотите, чтобы TTL ссылок автоматически продлевался, добавьте в ссылки параметр `renew_ttl=false`.<br />**Примечание**:<ul><li>Параметр `renew_ttl` не отображается в фактическом URL-адресе.</li><li>Для API OneLink значение является булевым: true (по умолчанию) или false.</li></ul></li></ul></li></ul> |
