| **Что нового** | Теперь AppsFlyer поддерживает измерение ретаргетинга, повторное вовлечение и реатрибуцию для расширенных (немобильных) платформ: [Комментарий: уточнен порядок слов] CTV, ПК и консоли. Ранее эти платформы поддерживали только атрибуцию привлечения пользователей.<br /><br />Ретаргетинг для расширенных платформ включает два типа конверсии:<ul><li>**Повторное вовлечение** засчитывает кампаниям возврат уже существующего, ранее установившего приложение пользователя.</li><li>**Повторная атрибуция** (ретаргетинг на повторную установку) учитывает кампании, которые стимулируют пользователя, ранее не пользовавшегося приложением, повторно установить и открыть его. Более подробную информацию см. в разделе <Anchor target="_blank" href="/marketers/ru/docs/measure-reinstalls#reattribution">«Измерение повторной атрибуции»</Anchor>.</li></ul>Это устраняет ключевой пробел для рекламодателей, использующих маркетинг жизненного цикла, когда для корректного учета кампаний, которые повторно активируют пользователей, стимулируют повторное потребление и снижают отток, необходимы повторное вовлечение и повторная атрибуция. Это также повышает точность оценки когорты и LTV. Ранее, без поддержки ретаргетинга, последующая активность в приложении привязывалась к первоначальной дате установки, что искажало когорты, окупаемость и анализ LTV. Подробнее о том, как AppsFlyer измеряет расширенные платформы, см. раздел <Anchor target="_blank" href="/marketers/ru/docs/ctv-pc-and-console-platform-attribution-concepts">«Понятия атрибуции для CTV, ПК и консолей»</Anchor>. |
| **Дата вступления в силу** | 1 августа 2026 года |
| **Что следует сделать** | Существует три уровня конфигурации: приложение, медиаисточник или интеграция и ссылка атрибуции.<ol><li>В <Anchor target="_blank" href="/marketers/ru/docs/app-settings#настройки-атрибуции">настройках приложения</Anchor> включите переключатель **«Атрибуция повторного вовлечения»**. Это главный переключатель для приложения. Если он выключен, вы не сможете включить повторное вовлечение ни для одного медиаисточника для этого приложения.</li><li>На вкладке **«Интеграция»** страницы **«Активные интеграции»** для каждого партнера или медиаисточника, с которым вы хотите запускать ретаргетинг , включите **параметр «Атрибуция переустановки»**, чтобы засчитывать повторную атрибуцию, и **параметр «Атрибуция при повторном вовлечении»,** чтобы засчитывалось повторное вовлечение . Включите также **Атрибуция повторного вовлечения по просмотрам**, если нужно засчитывать показы; иначе оставьте ее выключенной, чтобы учитывать только клики.</li><li>Для сетей, не относящихся к SRN, добавьте`af_campaign_type=retargeting` к ссылке атрибуции. Чтобы добавить этот параметр автоматически, включите **параметр «Включить настройки ретаргетинга»** на вкладке **«Ссылка атрибуции»** на странице **«Активные интеграции»**. Для получения информации о процессе создания ссылки см. <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide">руководство по атрибуции ретаргетинга</Anchor> и <Anchor target="_blank" href="/marketers/ru/docs/ctv-pc-and-console-platform-direct-attribution-links">ссылки для прямой атрибуции на платформах CTV, PC и консолях</Anchor>. Использовать эту ссылку в своих кампаниях.</li></ol>**<span id="h_01KZTHWRSZJW2W0JCDCWCK3P5P"></span>Примечание**<br />Roku, в настоящее время единственная доступная для этих платформ сеть SRN, поддерживает только повторное вовлечение. Он не поддерживает повторную атрибуцию, нет возможности настроить ссылку атрибуции. Для Roku любой запрос может быть использован для ретаргетинга, если соответствующие переключатели включены. |
| **Что вам нужно знать** | При измерении ретаргетинга на расширенных платформах следует иметь в виду что:<ul><li>**Поддерживаемые платформы:** Ретаргетинг для расширенных платформ применяется ко всем платформам, кроме Android, iOS, Windows Phone и веб-сайтов. На практике это означает приложения для CTV, ПК и консолей.</li><li>**Область применения** Эта функция доступна только для немобильных платформ (CTV, ПК, консоли). Кроссплатформенный ретаргетинг на мобильных устройствах не поддерживается. Например, реклама на CTV, стимулирующая установку мобильного приложения, по-прежнему не поддерживается. Однако веб-реклама, ведущая к установке приложений на ПК, поддерживается.</li><li>**Ограничение SRN:** Roku – единственная SRN, доступная сегодня для этих платформ, поддерживает только повторное вовлечение, а не переустановку и не повторную атрибуцию. Это может оказаться неверным для других SRN, добавленных в будущем.</li><li>**Дополнительные окна:** Окно повторного вовлечения (по умолчанию 30 дней) задает период, в течение которого события внутри приложения в основном атрибутируются конверсии повторного вовлечения. Окно неактивности (по умолчанию 7 дней) определяет, как долго пользователь должен оставаться неактивным, чтобы подходить для ретаргетинга. Эти окна работают так же, как и на мобильных устройствах. См. <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide#окна-включения">руководство по атрибуции ретаргетинга</Anchor> и <Anchor target="_blank" href="/marketers/ru/docs/set-retargeting-inactivity-window">Настройте окно неактивности для ретаргетинга</Anchor> .</li><li>**Где отображаются результаты:** Только в расширенных отчетах Data Locker и «Моих дэшбордах». В классических отчетах Data Locker нет нового отчета по сырым данным ретаргетинга. Чтобы узнать, как дэшборд ведет себя на каждой платформе, см. раздел «Обзорный дэшборд — привлечение пользователей и.ретаргетинг LTV».</li></ul> |
