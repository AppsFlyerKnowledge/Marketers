| **Что нового** | В дэшбордах Protect360 и ProtectLITE отображается мошенничество на показах из органических источников |
| --- | --- |
| **Дата вступления в силу** | 20.12.2021 |
| **Где** | дэшборды <Anchor target="_blank" href="/marketers/ru/docs/protect360-dashboard">Protect360</Anchor> и <Anchor target="_blank" href="/marketers/ru/docs/basic-fraud-detection-and-insights-with-protectlite-dashboard-and-reporting">ProtectLITE</Anchor> |
| **Описание** | **До изменения:** фрод из органических источников был доступен только в отчетах о сырых данных.<br /><br />**После изменения:** фрод для установок из органических источников также отображается в дэшбордах Protect360 и ProtectLITE. Фрод in-app событий из органических источников не поддерживается. |
| **Что вы должны знать** | <ul><li>Фильтр главного дэшборда: теперь вы можете фильтровать по органическому и/или неорганическому трафику.</li><li>Диаграмма тренда выявленного фрода: можно фильтровать по типу источника «органический».</li><li>Диаграмма предполагаемой экономии: не относится к органическому трафику.</li><li>Диаграмма корректировки атрибуции перехваченных установок: может отображать корректировку на органические установки, но не из органических.</li><li>Таблица разбивки выявленного фрода: включает данные по органическому трафику.</li><li>Агентства и рекламные сети: не могут просматривать данные по органическому трафику.</li></ul>Рекомендация: не называйте медиаисточники собственных медиа органическими, так как это может вызвать путаницу и повлиять на корректность реальных органических данных. |
