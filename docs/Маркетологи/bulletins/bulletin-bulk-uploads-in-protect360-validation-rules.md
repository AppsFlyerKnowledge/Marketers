| **Что нового** | Теперь вы можете массово загружать файлы CSV для некоторых условий правил валидации Protect360. |
| --- | --- |
| **Дата вступления в силу** | Август 2024 года |
| **Что нужно знать** | <ul><li>При выборе операторов **В списке** или **Не в списке** в условиях, которые это поддерживают, вы можете массово загрузить файл CSV.</li><li>CSV-файл может содержать до 17K значений.</li></ul> |
| **Влияние** | Массовая загрузка теперь доступна для некоторых правил валидации. Это позволяет загружать CSV-файл, содержащий длинный список значений, чтобы правило работало в соответствии с потребностями вашего бизнеса. Подробнее, включая инструкции по настройке, можно узнать <Anchor target="_blank" href="/marketers/ru/docs/implement-validation-rules-to-prevent-fraud#массовая-загрузка">здесь</Anchor>. |
