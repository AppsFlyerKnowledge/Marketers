| Раздел | Детали |
| --- | --- |
| **Что нового** | Мы обновляем свежесть данных (как быстро появляются новые события) для метрик активности в разделе «Мои дэшборды». События из веба, приложений для CTV, ПК и игровых консолей будут появляться быстрее. События из мобильных приложений будут появляться немного медленнее, чем сейчас.<br /><br />Ожидаемая свежесть данных для метрик активности:<ul><li>**Веб-приложения:** до 3,5 часов</li><li>**Приложения для CTV, PC и консолей:** до 50 минут</li><li>**Мобильные приложения:** до 70 минут</li></ul> |
| **Дата вступления в силу** | Начиная с **25 октября 2026 г.** обновление будет постепенно внедряться в течение следующих двух недель. |
| **Требуется действие** | Никаких действий не требуется. Изменение применяется автоматически. |
| **Что нужно знать** | Обратите внимание на следующее:<ul><li>**На кого это влияет:** все рекламодатели, агентства и партнеры.</li><li>**Только показатели активности:** изменения не затрагивают когортные показатели и периоды расчета пожизненной ценности клиента (LTV).</li><li>**Только классическая атрибуция:** обновление распространяется на классическую атрибуцию. Свежесть кроссплатформенных данных в разделе «Мои дэшборды» по-прежнему обновляется ежедневно.</li><li>**LTV-метрики для приложений CTV, PC и консолей:** частота обновления данных не меняется. Данные по-прежнему появляются в реальном времени.</li><li>**Метрики дохода от рекламы:** В разделе «Мои дэшборды» свежесть данных не меняется. Данные поступают непрерывно и появляются через 15–60 минут после события.</li><li>**Постепенное внедрение:** изменение будет постепенно применяться для аккаунтов. Обновленные данные могут стать доступны вам в любой момент по мере внедрения изменений.</li></ul> |
