> **Коротко:** с 8 ноября 2023 года веб-SDK AppsFlyer Smart Banner v1 признан устаревшим.

| **Что меняется** | Веб SDK AppsFlyer для смарт-баннеров v1 устарел с 8 ноября 2023 года. Для показа смарт-баннеров на вашем сайте необходимо обновить версию до v2. |
| --- | --- |
| **Что вы должны знать** | <ul><li>Если на вашем сайте используется Smart Banner SDK V1.0, вы ОБЯЗАТЕЛЬНО должны интегрировать последнюю версию SDK (v2), чтобы и дальше показывать Smart Banners на вашем сайте.</li><li>Обновление до последней версии — простой процесс. Нажмите<Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2">здесь</Anchor>, чтобы увидеть процесс.</li></ul>**Поддержка новых возможностей**<ul><li>Некоторые функции не поддерживаются в SDK v1, включая недавно добавленные <Anchor target="_blank" href="/marketers/ru/docs/smart-banners-mobile-web-to-app-for-marketers#3-banner-setup">шаблоны дизайна креативов</Anchor>.</li></ul> |
| **Как определить, используете ли вы Smart Banner SDK v1?** | Если фрагмент кода Smart Banner на вашем сайте содержит  <br />https://cdn.appsflyer.com/web-sdk/banner/latest/sdk.min.js  <br />это означает, что вы используете V1 и вам нужно обновить версию.<br /><br />Нажмите <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2">здесь</Anchor>, чтобы посмотреть процесс и обновить версию. |
