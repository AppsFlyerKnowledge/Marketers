        **Что нового?**
      </td>
      <td>
        Получайте сырые данные о рекламе в Meta Ads, которые направляются в магазин Google Play, с помощью реферера установки.

      <td>
        **Что изменилось?**

        **![Information_icon.png](https://files.readme.io/cc1ff74668360a2be64ec90db8f771d751b0a95847ecaee582c2e31c60e310cf-20445036062993.png)**
      </td>
      <td>
        С 29 октября 2021 г. данные атрибуции на уровне пользователя (сырые данные) для пользователей, привлеченных Meta Ads **после** этой даты, ограничены. Meta Ads предоставляет эти данные MMP, таким как AppsFlyer, но не рекламодателям.

        Однако если реклама ведет пользователей напрямую в Google Play, поля атрибуции доступны рекламодателям в Google Install Referrer, который должен быть <Anchor target="_blank" href="/marketers/ru/docs/basic-sdk-integration-guide#attribute-apps-published-on-google-play">интегрирован в ваше приложение</Anchor>. Поля, предоставленные через реферер, поступают в доступные вам отчеты AppsFlyer с сырыми данными. Благодаря этому AppsFlyer может атрибутировать пользователей, у которых нет рекламного идентификатора (с включенным LAT).

        Для использования механизма реферера требуется SDK AppsFlyer V5.4+.

        **Внимание!** Данные реферера не скрыты и имеют приоритет над данным, предоставленными через API.

        Данные в реферере зашифрованы Meta Ads. Чтобы их расшифровать, требуется ключ, доступный вам в аккаунте разработчика Meta Ads. Вы должны предоставить нам ключ расшифровки, указанный в строке требуемых действий.

        **Поля атрибуции по кампании, доступные через реферер:**

        * ID рекламы.
        * Имя рекламы
        * ID блока рекламы
        * Название блока рекламы
        * ID кампании
        * Название кампании
        * ID аккаунта
        * Канал
        * Тип рекламы (это поле пока недоступно)

        **Внимание**:

        * Другие поля не доступны через реферер.
        * Это решение применимо к атрибуции по кликам и не применимо к атрибуции по просмотрам.
        * Данные реферера неприменимы для кампаний повторного вовлечения, поскольку пользователи не проходят через магазин.

        **Когда AppsFlyer введет это изменение?**

        * С 29 октября 2021 г.
          * Будут реализованы ограничения Meta Ads на доступ к данным по кликам (т.е. к сырым данным по атрибуции).
          * Рекламодатели могут обновить ключ расшифровки реферера в AppsFlyer.
        * С 3 ноября 2021 г.
          * AppsFlyer заполняет сырые данные и атрибутирует на основе данных, предоставленных механизмом реферера.

        **Необходимое действие**
      </td>
      <td>
        **Чтобы получить ключ расшифровки от Meta Ads:**

        [Данная информация основана на информации, предоставленной нам Facebook]

        1. Войдите в свой аккаунт на портале Meta для разработчиков.
        2. Перейдите в **My Apps** (Мои приложения) в правом верхнем углу.
        3. Выберите приложение, для которого требуется получить ключ расшифровки.
        4. Перейдите в **Settings** (Настройки) > **Basic** (Основные) в левой части страницы.

           [![FBUIforKey.png](https://files.readme.io/253be6d4cd2a75cc2c038c5b14ed3df067612c46bea174475adba3d196f25789-30354101891985.png)](https://files.readme.io/253be6d4cd2a75cc2c038c5b14ed3df067612c46bea174475adba3d196f25789-30354101891985.png)
        5. Прокрутите страницу до раздела **Android**. В нем под полем **Package Names** (Имена пакетов) вы увидите **ключ расшифровки для Install Referrer**. **Примечание**. Это тот же раздел, в котором вы настраивали имена пакетов и Google Play.

        **Чтобы включить механизм реферера в AppsFlyer:**

        1. [обязательно] Убедитесь, что в приложении установлен SDK AppsFlyer версии 5.4+. Не используйте более ранние версии.
        2. Произведите одно из следующих действий:
           1. [Скоро] Задайте ключ расшифровки через API.
           2. Чтобы задать ключ расшифровки через пользовательский интерфейс:
              1. В AppsFlyer перейдите в раздел **Настройки** > **Активные интеграции**.
              2. Выберите Meta Ads.  

                 ![meta-ads-install-referrer-decryption-key.png](https://files.readme.io/adf6caa8d7cee493695eb8fb7db1b61c60e6a1cef0273e615c43a05ad8a9485d-13963525463825.png)
           3. На вкладке **Integration** (Интеграция) вставьте ключ в поле **Install Referrer** **Decryption Key** (Ключ расшифровки для Install Referrer).
           4. Нажмите **Сохранить интеграцию**.

        * Если данные атрибуции получены через механизм реферера, данные не ограничены и доступны в отчетах о сырых данных.
        * Если данные атрибуции получены через API, то сырые данные о пользователях, привлеченных Meta Ads, назначаются *ограниченному* медиа-источнику.
        * Это изменение не повлияет на сырые данные о пользователях, переданные до изменения, то есть до 29 октября 2021 г., 08:00 UTC. то есть до 29 октября 2021 г., 08:00 UTC.

        **Что остается прежним**
      </td>
      <td>
        AppsFlyer продолжит получать из Meta Ads данные уровня устройства. Это значит, что наши возможности атрибуции и отчетности (включая мультиканальную атрибуцию, LTV, ROI, когортные отчеты, отчеты об удержании пользователей, защиту от фрода, Аудитории и другие сервисы) не изменятся. См. <Anchor target="_blank" href="/marketers/ru/docs/aggregated-and-analytics-reporting-overview">Инструменты для агрегированных и аналитических отчетов</Anchor>.

        **Примечание**. Если вы предоставите нам ключ расшифровки, мы сможем атрибутировать пользователей, у которых нет рекламного идентификатора (с поддержкой LAT). Это повышает точность атрибуции.

      <td>
        **Вопросы и ответы**
      </td>
      <td>
        * **Нужно ли обновлять ключ расшифровки для реферера установки?**  
          После отправки ключ расшифровки не нужно обновлять.
        * **Когда я смогу увидеть данные уровня пользователя в отчетах по сырым данным?**  
          Данные уровня пользователя отображаются в отчетах по сырым данным после отправки действительного ключа расшифровки для реферера установки и атрибуции установки Meta Ads.
        * **Доступны ли данные атрибуции уровня пользователя для установок, которые произошли в период с 29 октября 2021 г. по 3 ноября 2021 г.?**  
          К сожалению, эти данные не доступны.
