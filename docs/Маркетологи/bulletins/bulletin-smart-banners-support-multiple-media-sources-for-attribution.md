| **Что нового** | Настройки смарт-баннера позволяют выбрать несколько типов медиаисточников для атрибуции. Они больше не ограничены одним типом web-to-app URL-адреса. |
| --- | --- |
| **Дата вступления в силу** | 25 августа 2021 |
| **Где** | Смарт-баннеры — настройка группы баннеров |
| **Описание** | **До изменения:** Для каждой группы баннеров поддерживался один тип медиаисточника. Пользователям нужно было выбрать: параметры входящей ссылки атрибуции **ИЛИ** входящие ссылки с UTM-параметрами **ИЛИ** параметры атрибуции по умолчанию (которые также использовались как резервный вариант). Это означало, что AppsFlyer искал во входящем URL-адресе либо "pid", либо “utm\_source”.<br /><br />**После изменения:** Группы баннеров больше не ограничены одним типом медиаисточника. Их можно настроить так, чтобы они поддерживали один или несколько указанных выше медиаисточников. То есть пользователи могут выбирать между параметрами входящей ссылки для атрибуции **AND/OR** входящими UTM-параметрами ссылки **AND/OR** параметрами атрибуции по умолчанию. Это дает больше гибкости для настройки ссылки за баннером и помогает обеспечить оптимальный web-to-app опыт для конечного пользователя. |
| **Что вы должны знать** | <ul><li>Если у вас уже есть смарт-баннеры и группы баннеров, ваши настройки останутся без изменений.</li><li>Для новых групп баннеров интерфейс изменен: теперь вы можете выбрать несколько вариантов медиаисточников.</li><li>У вас должен быть интегрирован актуальный <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2#smart-banners-only">Web SDK Smart Banners</Anchor>; эта функция не поддерживается старым (устаревшим) Web SDK.</li></ul>[![](https://files.readme.io/35d3888899ee7d95cb81152ab5a72de5bfcf1df40568b7f2fea00c947658fd42-4406108511633.png)](https://files.readme.io/35d3888899ee7d95cb81152ab5a72de5bfcf1df40568b7f2fea00c947658fd42-4406108511633.png) |
