        Pinterest перешел на новую конечную точку на базе собственной инфраструктуры API конверсий (CAPI). Вам необходимо обновить настройки, чтобы продолжать отправлять события вашего приложения в Pinterest. Поддержка устаревшей конечной точки будет прекращена 30 сентября 2025 года.

      </td>

      </td>

        **Что важно знать**
      </td>
      <td>
        Этот бюллетень содержит информацию, относящуюся к этапу миграции на CAPI. Общую информацию об интеграции с Pinterest смотрите в <Anchor target="_blank" href="/marketers/ru/docs/pinterest-create-a-mobile-app-integration#настройки-внутренних-событий-приложения">этой статье</Anchor>.

        Обновление в соответствии с новыми настройками внутренних событий приложения обеспечит непрерывность измерения в Pinterest. Это обновление также включает в себя:

        * **Больше типов событий**: отслеживайте дополнительные события, чтобы точнее учитывать ваши цели, например «Лид», «Поиск», «Просмотр категории», «Посещение страницы» и другие.
          * **Примечание**: названия событий для нового конечного пункта Pinterest V5 изменились. Если вы не обновите настройки в дэшборде, в отчете о событиях будет отображено значение «неизвестно». Пожалуйста, ознакомьтесь с новыми названиями событий ниже.
        * **Повышенное качество данных:** более эффективное сопоставление и более высокая точность атрибуции.

        Для новой интеграции нужны **Идентификатор рекламного аккаунта** и **Токен доступа**. Чтобы сохранить функциональность постбэков, партнерам необходимо перейти на новый конечный пункт постбэка до 30.09.2025 г.   

        **Как найти идентификатор рекламного аккаунта Pinterest в AppsFlyer**  
        Текущий идентификатор рекламного аккаунта для отчетов о конверсиях Pinterest в AppsFlyer можно найти в **Управление бизнесом** Pinterest или в отчетах **Конверсии** Pinterest.

        1. Войдите в свой бизнес-аккаунт Pinterest (для доступа к параметрам хаба необходимо использовать бизнес-профиль).
        2. Введите или вставьте в ваш браузер https://www.pinterest.com/business/hub/ и нажмите «Ввод».
        3. Найдите темно-серую панель навигации в левой части Hub. Если панель свернута, нажмите на значок «≡» (три полоски) в верхнем левом углу, чтобы развернуть ее.
        4. Прокрутите немного вниз, пока не увидите раздел с заголовком «Управление бизнесом».
        5. Нажмите на Конверсии (находится прямо под «Управление бизнесом»). Откроется дэшборд Конверсии, где вы можете просмотреть конверсии AppsFlyer, отправленные в Pinterest.
        6. Идентификатор рекламного аккаунта будет содержаться в URL.
        7. Если несколько идентификаторов рекламных аккаунтов Pinterest получают дубликаты конверсий от AppsFlyer, проверьте все существующие идентификаторы рекламных аккаунтов с конверсиями в разделе Pinterest «Управление бизнесом». Убедитесь, что выбран исходный идентификатор родительского рекламного аккаунта для конверсий AppsFlyer.

        **Как найти токен доступа Pinterest в AppsFlyer**  
        Следуйте инструкциям, приведенным <Anchor target="_blank" href="https://help.pinterest.com/en/business/article/getting-started-with-the-conversions-api">здесь</Anchor> в Справочном центре Pinterest. После перехода в Конверсии Pinterest, нажмите на **API конверсий** > **Настроить API** и сгенерируйте новый токен доступа для аккаунта.  

        **Важно!** Если вы уже настроили API конверсий для Pinterest отдельно вне AppsFlyer, используйте тот же токен доступа здесь для конверсий AppsFlyer.

        **Что необходимо сделать:**
      </td>
      <td>
        Пожалуйста, следуйте инструкциям ниже для настройки и миграции постбэков событий внутри приложения в дэшборде AppsFlyer.

        1. **Настройки внутренних событий приложения и обработка параметров дэшборда**  
           В настоящее время мы поддерживаем следующие параметры дэшборда для сопоставления ваших событий AppsFlyer с Pinterest:

           * **Идентификатор рекламного аккаунта** (видимый)
           * **Токен доступа** (видимый)
           * **Идентификатор тега** (не виден на панели управления, но поддерживается на серверной стороне для помощи в переходе на новую версию V5. После того как переход на конечную точку V5 будет полностью поддерживаться, Tag ID также будет удален из бэкенда.)

           **Обратите внимание:**  
           Для новой настройки постбэка необходимо ввести как **идентификатор рекламного аккаунта**, так и **токен доступа** (их можно получить в Pinterest, если это еще не было сделано). **Если одно из этих значений отсутствует, постбэк не будет отправлен**. Проверьте, чтобы оба параметра были правильно заполнены на странице **Активная интеграция** в Pinterest. Для получения дополнительной информации смотрите <Anchor target="_blank" href="/marketers/ru/docs/pinterest-create-a-mobile-app-integration#настройки-внутренних-событий-приложения">статью в Центре поддержки</Anchor>.  
           Ваше содействие поможет обеспечить плавный переход. Спасибо за вашу поддержку!
        2. **Сопоставление внутренних событий приложения и настройки постбэков**
           1. <span class="af-ol-a"></span>Пожалуйста, замените и сопоставьте текущие названия событий Pinterest с новыми названиями событий API конверсий Pinterest для раздела **Название событий партнера**. Например, если в настоящее время вы используете `pin_add_to_cart` в разделе "Событие партнера", замените его на `add_to_cart`. Для получения дополнительной информации смотрите <Anchor target="_blank" href="/marketers/ru/docs/pinterest-create-a-mobile-app-integration#httpssupportappsflyercomhcarticle_attachments360001712765">статью в Базе знаний</Anchor>.

        | название события (устаревшее) | название события (новый API конверсий) |
        | --- | --- |
        | pin\_add\_to\_cart | add\_to\_cart |
        | pin\_purchase | checkout |
        | pin\_search | search |
        | pin\_registration | signup |
        | pin\_sign\_up | signup |
        | pin\_category\_view | view\_category |
        | add\_cart | add\_to\_cart |
        | start\_checkout | checkout |
        | content\_view | view\_category |

              **Примечание.** Если не заменить устаревшие названия событий на правильные названия событий для API конверсий, в Pinterest вместо правильного названия события будет отображаться «Другое».
           2. Выберите **За весь срок** для параметра **Окно постбэков событий в приложении**, чтобы Pinterest мог получать максимальное количество конверсий для оптимизации рекламы.
           3. Выберите **Все медиаисточники, включая органические** для параметра **Для пользователей из**, чтобы Pinterest мог получать максимальное количество конверсий для оптимизации рекламы. Для получения дополнительной информации смотрите <Anchor target="_blank" href="/marketers/ru/docs/pinterest-create-a-mobile-app-integration#httpssupportappsflyercomhcarticle_attachments360001712765">статью в Базе знаний</Anchor>.
        3. **Процесс отката в случае возникновения проблем**  
           Рекламодателям рекомендуется отслеживать конверсии своих приложений AppsFlyer в Pinterest, чтобы выявлять любые неполадки или проблемы, связанные с переходом. Подождите до 30 минут, пока данные о конверсиях AppsFlyer появятся в Pinterest, и регулярно отслеживайте их в течение нескольких дней, чтобы убедиться в успешности перехода.  

           Рекламодатели могут вернуться к устаревшей конечной точке, удалив `account_id` или `access_token` либо оба этих параметра из настроек интеграции.

           **Правила поведения:**

           * Отсутствует и `account_id`, и `access_token` → Постбэки отправляются на устаревшую (старую) конечную точку.
           * Есть только `account_id` (т.е. `access_token` пусто) → Постбэки отправляются на устаревшую конечную точку.
           * Есть только `access_token` (т.е. `account_id` пусто) → Постбэки отправляются на устаревшую конечную точку.
           * Есть и `account_id`, и `access_token` → Постбэки отправляются на новую конечную точку.

           Если у вас возникли какие-либо проблемы, свяжитесь с поддержкой AppsFlyer по адресу support@appsflyer.com. По любым вопросам по Pinterest, обращайтесь по адресу api-support@pinterest.com или свяжитесь со своим представителем в Pinterest.
