## Настройка

Существует две версии OneLink Smart Script:

**OneLink Smart Script V2 (рекомендуется)**: Если вы впервые настраиваете OneLink Smart Script, лучше всего использовать эту версию. Его можно создать в пользовательском интерфейсе AppsFlyer без помощи разработчика. Если по каким-то причинам нужен разработчик, то его рабочая часть проще. И его также можно настроить с помощью Google Tag Manager. <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_script_v2">См. инструкции для разработчика</Anchor>

<Anchor target="_blank" href="/marketers/ru/docs/legacy-onelink-smart-script-v1-setup">**OneLink Smart Script V1 (устарело)**</Anchor>: Если у вас уже настроен Onelink Smart Script, используйте документацию к этой версии, чтобы поддерживать и редактировать этот скрипт. **Примечание**: Хотя это необязательно, рассмотрите переход на версию V2 для правильного получения <Anchor target="_blank" href="https://www.appsflyer.com/glossary/view-through-attribution/">атрибуций по показам</Anchor> посредством OneLink Smart Script.

<div id="set-up-onelink-smart-script" />

### Настройка OneLink Smart Script

Чтобы настроить Smart Script, вы можете:

* Встроить скрипт на свой сайт.
* Или использовать Google Tag Manager.

<div id="scope-of-work" />

#### Объем работ

**Кто задействован**

* **Рекламодатель**:
  * Решает, что должен содержать исходящий URL, на основе [аргументов](/docs/set-up-smart-script-to-convert-web-visitors#arguments) в скрипте, обрабатывающих входящий URL. Это определяет данные атрибуции и диплинкинга, которые добавляются к исходящему URL, либо путем изменения входящего URL, либо путем принудительного ввода определенных значений.
  * Генерирует Smart Script в пользовательском интерфейсе AppsFlyer.
  * Проверяет, что все кампании, ведущие на мобильный сайт, имеют входящие URL с параметрами, на которые работает скрипт.
  * <Anchor target="_blank" href="https://appsflyersdk.github.io/appsflyer-onelink-smart-script/examples/test_page.html">Тестирует Smart Script</Anchor>.
* **Веб-разработчик**:
  * Проверяет, что скрипт работает на мобильном сайте/страницах, на которых он должен работать.
  * Использует значение результата по мере необходимости, например, чтобы разместить его в качестве ссылки на кнопке CTA на вашем сайте.
  * Может потребоваться для создания QR-кодов с помощью скрипта.
  * Может потребоваться, чтобы вручную добавить дополнительные аргументы в скрипт.

**Необходимые условия**

* Аккаунт AppsFlyer с хотя бы одним приложением.
* <Anchor target="_blank" href="/marketers/ru/docs/create-a-onelink-template#создание-шаблонов-onelink">Шаблон OneLink</Anchor>, который выступает как значение [параметра OneLinkURL](/docs/set-up-smart-script-to-convert-web-visitors#arguments).

<div id="how-to-create-a-onelink-smart-script" />

<Accordion title="Как создать OneLink Smart Script">

**Как создать OneLink Smart Script:**

1. В AppsFlyer в боковом меню выберите **Привлечение** > **Web-to-app** > **Smart Script**.
2. ***Для новых пользователей***
   1. *Нажмите кнопку **Начать.***
   2. *Выполните шаги 4 и далее.*
3. Нажмите кнопку **+ Новый Smart Script** в верхней части страницы.
4. Следуйте инструкциям на экране, чтобы дать название Smart Script.
5. Выберите шаблон OneLink, на котором будет основан скрипт. В шаблоне содержатся базовые настройки перенаправления.
6. Сопоставьте параметры, которые должен содержать исходящий URL. Эти параметры основаны на параметрах входящего URL. **Примечание**: Параметр медиа-источника (pid) является обязательным.
   1. Выберите исходящий параметр/показатель для сопоставления.  
      Часто имя параметра AppsFlyer нельзя изменить, но в некоторых случаях вам нужно ввести имя параметра.
   2. Настройте значение исходящего параметра на основе одного из следующего:
      * Параметры входящего URL: Перечислите один или несколько возможных параметров входящего URL, которые необходимо заменить параметром исходящего URL. Значения параметров входящего URL будут значениями параметра исходящего URL.
        * Пример: any\_param\_name, utm\_param\_name. Если utm\_param\_name найден во входящем URL, его значение будет использоваться в качестве значения выбранного вами параметра исходящего URL.
        * Smart Script проводит поиск в списке параметров слева направо и сопоставляет первое совпадение с URL исходящего параметра.
        * Разработчики называют этот список параметров ключами.
      * Значение по умолчанию: Введите желаемое значение по умолчанию для исходящего параметра, если параметр входящего URL не найден или если в списке нет параметров входящего URL.
        * Пример: Если во параметре входящего URL перечислены any\_paramname, utm\_paramname и если ни один из параметров в списке не найден, то в качестве значения исходящего параметра будет использовано значение по умолчанию.
      * Значения для переопределения: Настройте одно или несколько значений из входящего URL вместе со значениями исходящего URL, на которые вы хотите их заменить.
        * Пример: Для параметра кампании, если значение во входящем URL — campaign\_name, значение в исходящем URL может быть изменено на new\_campaign\_name.
   3. [Необязательно] Нажмите **+ Новый параметр** для сопоставления дополнительных параметров. Посмотрите все [дополнительные аргументы](/docs/set-up-smart-script-to-convert-web-visitors#arguments) (конфигурации параметров), которые вы можете использовать.
7. [Необязательно] В разделе **Web** **referrer mapping** включите **Media Source for organic search installs,** чтобы автоматически задавать медиаисточник для органического поискового трафика, если он еще не определен в разделе сопоставления параметров URL-адреса. [Узнать больше](#seo-referrer-mapping)
8. Выберите способ внедрения Smart Script на вашем сайте:
   * **Встроить скрипт на свой сайт.**
   * **Или использовать Google Tag Manager.**
9. Нажмите **Тестировать**, чтобы протестировать скрипт на <Anchor target="_blank" href="https://appsflyersdk.github.io/appsflyer-onelink-smart-script/examples/test_page.html">странице тестирования Smart Script</Anchor>. Убедитесь, что сгенерирован правильный исходящий URL.
10. Клик
    1. **Сохранить**, чтобы сохранить изменения.
    2. **Сохранить и сгенерировать**, чтобы сохранить настройки и создать скрипт.
       1. Нажмите **Скачать скрипт**.
11. Если вы решили встроить скрипт в свой веб-сайт: Отправьте скрипт своему веб-разработчику для реализации и укажите, что нужно сделать со сгенерированным исходящим URL. Например, разместить его за кнопкой CTA на мобильном сайте или представить QR-код в полной версии сайта. <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/onelink-smart-script-v2web-to-app-url-generator#embed-the-script-in-your-website">Инструкции для разработчика</Anchor>
12. Если вы выбрали использование Google Tag Manager:
    1. В Google Tag Manager создайте новый тэг, присвойте ему имя, нажмите **Tag Configuration** (Конфигурация тэга) и выберите **Custom HTML** (Пользовательский HTML).
    2. В поле HTML вставьте сгенерированный код Smart Script.
    3. Нажмите **Triggering** (Триггер), создайте новый триггер, дайте ему имя и выберите **Trigger Configuration** (Конфигурация триггера), например, все просмотры страниц. <Anchor target="_blank" href="https://support.google.com/tagmanager/answer/7679319?hl=en&ref_topic=7679108">Дополнительные сведения см. в документации GTM.</Anchor>
    4. Нажмите **Сохранить**.
    5. Укажите веб-разработчику, что нужно сделать со сгенерированным исходящим URL. Например, разместить его за кнопкой CTA на мобильном сайте или представить QR-код в полной версии сайта. <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/onelink-smart-script-v2web-to-app-url-generator#embed-the-script-in-your-website">Инструкции для разработчика</Anchor>
13. Сохраненные скрипты можно просмотреть в [выпадающем меню](/docs/set-up-smart-script-to-convert-web-visitors#how-to-edit-or-delete-a-script).

<div id="argument-structure" />

<Accordion title="Структура аргументов">

OneLink Smart Script использует аргументы для генерации исходящего URL на основе параметров входящего URL и аргументов, определенных в скрипте. Аргумент afParameters имеет структуру, состоящую из нескольких других аргументов (параметров), используемых для атрибуции и диплинкинга, каждый из которых содержит структуру (которую разработчики называют объектом конфигурации), содержащую ключи, значения для переопределения и значение по умолчанию, как описано в следующей таблице.

| Аргумент | Описание | Пример |
| --- | --- | --- |
| Параметры входящего URL (разработчики называют их ключами) | <ul><li>Список строк</li><li>Список возможных параметров во входящем URL, которые ищет скрипт, значение которых помещается в качестве значения в исходящем URL.</li><li>Скрипт выполняет поиск слева направо и останавливается на первом совпадении.</li></ul> | <ul><li>Пример: ['in\_channel', 'utm\_channel']</li><li>Для параметра channel (канал) в скрипте скрипт ищет во входящей ссылке значение in\_channel и использует его в качестве значения для channel.</li></ul> |
| Значение по умолчанию | <ul><li>строка</li><li>Укажите, каким должно быть значение "fallback".</li><li>Если параметр не найден в списке ключей, в исходящем URL используется значение по умолчанию defaultValue.</li><li>Вы можете принудительно установить значение по умолчанию, передав пустой список ключей.</li></ul> | Пример: ['web\_video']<br /><br />Для параметра канала channel в скрипте, если параметр in\_channel не найден, в качестве значения channel используется web\_video. |
| Значения для переопределения | <ul><li>Словарь \{string: string\}</li><li>Перечислите значения во входящем URL, которые вы хотите изменить в исходящей ссылке, а также то, на что вы хотите их заменить.</li><li>Скрипт заменяет значения param входящего URL на определенные вами значения.</li></ul> | Пример: \{'video': 'video\_new'\}<br /><br />Для параметра channel в скрипте, если входящее значение video, скрипт меняет его на video\_new в исходящей ссылке. |

</Accordion>

## Примеры использования

В следующих разделах представлены примеры использования Smart Script для некоторых распространенных сценариев кампаний / медиа-источников.

<div id="utm-parameters" />

<Accordion title="Параметры UTM">

**Чтобы настроить скрипт для параметров UTM**:

1. Создайте список параметров UTM во входящем URL-адресе (например, **utm\_source** и **utm\_campaign**) и сопоставьте их с параметрами исходящего URL (например, **media\_source** и **campaign**).
2. Предоставьте их разработчику в [списке аргументов](/docs/set-up-smart-script-to-convert-web-visitors#arguments).

**Результат**: Значения входящих параметров (**utm\_source** и **utm\_campaign**) используются для заполнения значений параметров (**media\_source** и **campaign**) в исходящей ссылке.

</Accordion>

<div id="google-ads-gclid" />

<Accordion title="Google Ads GCLID">

В ходе обычного процесса атрибуции установки, которая пришла из кампаний Google Ads (содержащих параметр GCLID), пользователи, нажавшие на вашу рекламу, перенаправляются на URL страницы приложения в магазине приложений.

Поскольку в этом случае вы перенаправляете лидов из Google Ads на веб-страницу/лендинг, скрипт берет параметр GCLID из URL кампании установки Google Ads и помещает его в исходящий URL. Начиная со Smart Script версии 2.9.0, параметры GCLID, WBRAID и GBRAID, если они доступны, автоматически пересылаются «как есть» на исходящие URL-адреса, сгенерированные Smart Script.

Вы также можете сопоставить идентификаторы кликов с другими исходящими параметрами (**af\_sub[1-5]**), чтобы они были доступны в отчетах AppsFlyer по сырым данным.

**Примечание!**

* Это относится к кампаниям установки. Для поисковых кампаний, не относящихся к ACI, то есть кампаний повторного вовлечения пользователей, Google может быть атрибутирован в качестве медиа-источника, несмотря на выходные данные Smart Script.
* Если GCLID найден, скрипт ищет ключевое слово входящего параметра. Если находит, то помещает значение ключевого слова в исходящий URL в качестве значения af\_keywords.

**Необходимые условия**: На дэшборде Google <Anchor target="_blank" href="https://support.google.com/analytics/answer/1033981?hl=en">Включите автоматическую пометку</Anchor>.   
Если автоматическая пометка включена, URL-адрес лендинга содержит параметр *GCLID*.

**Настройка скрипта для сопоставления Google Ads GCLID с другими параметрами**:

1. Выберите параметр в исходящем URL, который будет содержать GCLID.  
   Практические рекомендации: Выбирать **af\_sub[1-5]**, чтобы данные отображались в отчетах по сырым данным AppsFlyer.
2. Предоставьте их разработчику в [списке аргументов](/docs/set-up-smart-script-to-convert-web-visitors#arguments). В результате в исходящем URL GCLID будет значением параметра **af\_sub[1-5]**.

**Чтобы уведомить Google Ads об этих установках:**

**Рекомендуется:** настройте <Anchor target="_blank" href="/marketers/ru/docs/google-ads-adwords-create-web-based-campaigns">веб-интеграцию Google</Anchor>. Эта интеграция поддерживает автоматические постбэки для установок.

**Если у вас нет этой интеграции:**

1. Получите данные GCLID из параметра **af\_sub[1-5]** через CSV или Push API в режиме реального времени для каждой установки.
2. Загрузите данные GCLID в Google <Anchor target="_blank" href="https://support.google.com/adwords/answer/7014069">вручную</Anchor> или через <Anchor target="_blank" href="https://developers.google.com/google-ads/api/docs/start">Google Ads API</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Это решение GCLID официально не поддерживается и не рекомендуется компанией Google. В случае, если Google прекратит использование параметра GCLID, мы изменим скрипт в соответствии с изменениями. Нажмите кнопку **Подписаться** в заголовке статьи, чтобы получать информацию об обновлении статьи или скрипта.

</Accordion>

Начиная с версии Smart Script 2.8.1, FBCLID будет автоматически пересылаться "как есть" на исходящие URL-адреса, сгенерированные Smart Script. Вы также можете сопоставить идентификаторы кликов с другими исходящими параметрами, чтобы они были доступны в отчетах AppsFlyer по сырым данным.

**Настройка скрипта для сопоставления FBCLID с другими параметрами:**

1. Выберите параметр в исходящем URL, который будет содержать FBCLID.   
   Практические рекомендации: Выберите**af\_sub[1-5]**, чтобы данные отображались в отчетах AppsFlyer по сырым данным.
2. Предоставьте их разработчику в [списке аргументов](/docs/set-up-smart-script-to-convert-web-visitors#arguments). В результате в исходящем URL FBCLID будет значением параметра **af\_sub[1-5]**.

</Accordion>

<div id="tiktok-ttclid-x-twclid-and-snapsccid" />

<Accordion title="TikTok (ttclid), X (twclid) и Snap (ScCid)">

Атрибуция установок для рекламных кампаний TikTok, X (ранее Twitter) и Snap основана на параметрах идентификатора клика, специфичных для каждой сети, которые добавляются к рекламным кликам и используются для сопоставления установок и событий после установки с исходной рекламой.

Когда трафик впервые перенаправляется на веб-страницу или лендинг, идентификатор клика должен быть сохранен и передан дальше, чтобы обеспечить корректную атрибуцию. В этом случае Smart Script захватывает входящий параметр идентификатора клика и добавляет его в исходящий URL-адрес, который генерирует.

Идентификатор клика фиксируется при установке и используется в будущих событиях, связанных с этой установкой.

Начиная с версии Smart Script 2.10.0 следующие параметры идентификатора клика, если они доступны, автоматически пересылаются «как есть» в исходящих URL-адресах, сгенерированных Smart Script:

* TikTok: ttclid
* X (ранее Twitter): twclid
* Snap: ScCid

Вы также можете сопоставить эти идентификаторы кликов с другими исходящими параметрами — например, af\_sub1–af\_sub5 — чтобы они были доступны в отчетах AppsFlyer о сырых данных.

См. следующие статьи по веб-интеграции:

* <Anchor target="_blank" href="/marketers/ru/docs/tiktok-for-business-create-web-based-campaigns">TikTok</Anchor>
* <Anchor target="_blank" href="/marketers/ru/docs/snapchat-create-web-based-campaigns">Snap</Anchor>

</Accordion>

<div id="srns-owned-media-and-other-media-source-links" />

<Accordion title="Ссылки в SRN, собственных медиа и других медиа-источниках">

<Anchor target="_blank" href="/marketers/ru/docs/self-reporting-networks-srns#srn-интегрированные-с-appsflyer">SRN</Anchor>, такие как Snapchat или X Ads, работают иначе, чем Google Ads или целевые платформы типа Meta ads. Кампании этих SRN приводят ваших пользователей на веб-страницу / лендинг, и в ваш счет включаются клики от всех лидов, независимо от полученных мобильных пользователей.

Для этих SRN настройка скрипта такая же, как и для ссылок из собственных медиа или других медиа-источников, которые вы можете использовать.

**Чтобы настроить скрипт**:

1. Составьте список названий параметров для медиа-источников и кампаний, которые содержатся во входящих ссылках.
2. Предоставьте их разработчику в [списке аргументов](/docs/set-up-smart-script-to-convert-web-visitors#arguments).  

   Тип источника SRN/медиа должен быть значением источника медиа во входящем URL. Скрипт находит его и использует в качестве значения **media\_source** в исходящем URL-адресе OneLink за кнопкой загрузки на веб-странице/лендинге. Если вы хотите изменить исходящий параметр **media\_source**, укажите входящее значение медиа-источника и переопределите значение media\_source в [списке аргументов](/docs/set-up-smart-script-to-convert-web-visitors#arguments), который вы передаете разработчику.

**Результат:** Для этих SRN / медиа-источников значения параметров медиа-источника и кампании во входящей ссылке используются для заполнения значений параметров **media\_source** и **campaign** в исходящей ссылке.

<div id="example" />

> 📄 **Пример**
>
> **Входящий URL**: https://hotel.me/incoming_mediasource=twitter&incoming_campaign=big_social
>
> **Исходящий URL**: Нет исходящего URL.

</Accordion>

<Accordion title="Ссылки атрибуции AppsFlyer">

Ссылки атрибуции AppsFlyer можно использовать, когда медиа-источник является рекламной сетью, из которой пришел клик. Когда вы настраиваете такую ссылку в AppsFlyer, у вас есть возможность добавить параметр **URL-адрес перенаправления (af\_r)** с желаемым путем URL на ваш мобильный сайт для атрибуции переходов из веб-кампании в приложение. Возможно, вы не хотите, чтобы скрипт создавал исходящий URL-адрес OneLink, поскольку некоторые данные из исходного клика могут быть потеряны.

**Действие:** Используйте аргумент **urlSkipList** для составления списка параметров **af\_r**.

**Результат**: Если Smart Script находит параметр **af\_r** во входящей ссылке, Smart Script не создает исходящий URL, и разработчик должен решить, какую ссылку поместить в качестве исходящего URL, и реализовать ее.

<div id="web-referrer-mapping" />

<Accordion title="Сопоставление веб-реферов">

Сопоставление веб-реферера показывает, с какой страницы пользователи пришли на ваш сайт (например, из результатов органического поиска), и дополняет имеющиеся у вас данные для анализа установок и повторных вовлечений из вашего потока Smart Script web-to-app.

Вы можете настроить Smart Script на сбор этой информации из поля `Referer`заголовка HTTP лендинга или сайта. Это поле содержит базовый URL страницы, с которой пользователи перешли по ссылке на вашу веб-страницу.

**Чтобы настроить скрипт для сбора информации о веб-реферере**

1. Откройте страницу **Smart Script**
2. В разделе **сопоставления веб-реферера** выберите ключ параметра исходящего URL для значения веб-реферера:
   * af\_channel — параметр доступен на дэшбордах и в сырых данных
   * af\_sub1-5 — параметр доступен в сырых данных в столбцах **af\_sub1-5** и в столбце **исходного URL**.
   * Настраиваемый параметр — состоит из имени и значения параметра. Параметр показан в сырых данных в столбце **исходного URL**.

Об атрибуции органического поиска для повторных вовлечений с использованием универсальных ссылок и App Links см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-organic-search-seo-and-organic-ai-answers-aeo-re-engagement-attribution">здесь</Anchor>.

</Accordion>

<div id="seo-referrer-mapping" />

<Accordion title="Сопоставление SEO-реферера">

Вы можете включить **«Медиаисточник для установок из органического поиска»**, чтобы автоматически задавать медиаисточник для трафика из органического поиска, если он еще не определен в разделе **«Сопоставление параметров URL-адреса»**.

* Если веб-реферер пользователя соответствует поддерживаемой поисковой системе (например, google.com или bing.com), медиаисточник задается как соответствующий канал (например, google\_organic\_seo).
* Если совпадения нет, используется **значение по умолчанию**, настроенное в сопоставлении параметров URL-адреса.

</Accordion>

<div id="desktop" />

<Accordion title="Десктоп">

Большинство вариантов использования в этой статье пользователей, пришедших с мобильных устройств. Поэтому, когда они перенаправляются с мобильного сайта в магазин приложений, они могут сразу скачать ваше приложение.

Однако пользователи настольных компьютеров не должны сразу же отправляться в магазин приложений, потому что их устройство (настольный компьютер или ноутбук) не совместимо с загрузкой мобильных приложений.

**Чтобы настроить скрипт для пользователей настольных компьютеров**:

* В <Anchor target="_blank" href="/marketers/ru/docs/create-a-onelink-template#создание-шаблонов-onelink">шаблоне OneLink</Anchor> задайте URL назначения для опции **When link is clicked on desktop** (Если ссылку нажимают на настольном ПК). URL должен перенаправлять пользователей на специальную страницу / лендинг. Лендинг может содержать веб-форму, в которой они вводят свои данные, чтобы получить SMS или электронное письмо со ссылкой для загрузки приложения. Вы сами должны создать веб-форму и указать ее URL в скрипте.

**Результат:** Скрипт определяет устройство или платформу, на которой находится пользователь. Если это десктоп, скрипт создает исходящий URL-адрес OneLink, который перенаправляет пользователя на специальную страницу / лендинг.

См. также <Anchor target="_blank" href="/marketers/ru/docs/qr-to-app-conversion">Конверсия от ПК до приложения.</Anchor>

<Accordion title="Показы">

OneLink Smart Script можно использовать для подсчета показов на вашем сайте. Для этого разработчику необходимо вызвать функцию показа. Затем установки будут атрибутироваться показам с помощью <Anchor target="_blank" href="/marketers/ru/docs/measure-view-through-engagements">атрибуции по просмотрам</Anchor>.

**Примечание**:

* Подсчет показов производится в дополнение к подсчету кликов обычным URL, созданным Smart Script. Smart Script можно использовать для подсчета кликов, показов или и того, и другого.
* Атрибуция по просмотрам с помощью Smart Script работает только на мобильных устройствах, но не на настольных ПК.

**Чтобы атрибутировать новые установки этим показам (то есть использовать атрибуцию по просмотрам):**

1. Убедитесь, что при настройке Smart Script  вы используете версию Smart Script 2.3+.
2. Скажите своему разработчику, чтобы он <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/onelink-smart-script-v2web-to-app-url-generator#fire-an-impression">вызвал функцию показов</Anchor> в Smart Script.
3. Убедитесь, <Anchor target="_blank" href="/marketers/ru/docs/measure-view-through-engagements">что атрибуция по просмотрам включена</Anchor>.

<div id="will-the-incoming-url-for-onelink-link-generation-work-if-the-user-browses-to-a-different-page-on-the-website" />

#### Будет ли работать входящий URL для генерации ссылок OneLink, если пользователь перейдет на другую страницу сайта?

Да. Параметры входящего URL сохраняются в течение всего сеанса просмотра и применяются к параметрам исходящей ссылки OneLink, созданной Smart Script. Для получения дополнительной информации о реализации см. <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_script_v2#preserve-incoming-url-parameters-across-pages">наш хаб разработчиков</Anchor>.

<div id="why-do-i-get-an-error-when-implementing-smart-script-via-google-tag-manager" />

#### **Почему я получаю ошибку при внедрении Smart Script через Google Tag Manager?**

Иногда, когда вы создаете Smart Script в AppsFlyer и пытаетесь вставить его в Google Tag Manager (GTM), появляется ошибка «JavaScript too long» (Слишком длинный JavaScript). Если это произошло, удалите тег GTM и создайте новый.

<div id="can-i-add-parameters-that-are-not-listed" />

#### **Можно добавить параметры, которых нет в списке?**

Да. На странице OneLink Smart Script нажмите на + **Новый параметр** для сопоставления дополнительных параметров.

* Новые параметры могут быть пользовательскими или зарезервированными AppsFlyer параметрами, которые не перечислены в выпадающем списке.
  * Посмотрите все [дополнительные аргументы](/docs/set-up-smart-script-to-convert-web-visitors#arguments) (конфигурации параметров), которые вы можете использовать.
* Используйте опцию Custom (Пользовательский) из выпадающего списка и ваш параметр в поле **Параметры исходящего URL**.

Например, чтобы добавить is\_retargeting в качестве параметра, в **сопоставлении** для поля будет выбрано Custom, а затем наш параметр is\_retargeting в поле **Параметры исходящего URL**.

<div id="adset-and-other-parameters-are-not-showing-in-the-dropdown" />

#### **Группа объявлений и другие параметры не отображаются в выпадающем списке**

При создании или добавлении новых параметров мы рекомендуем отключить все блокировщики рекламы, установленные в вашем браузере. Иногда блокировщики рекламы удаляют опцию, если в ней есть слово «Ad» (реклама).

<div id="what-browsers-does-smart-script-work-on" />

#### **В каких браузерах работает Smart Script?**

Smart Script использует Javascript и должен работать во всех браузерах.
