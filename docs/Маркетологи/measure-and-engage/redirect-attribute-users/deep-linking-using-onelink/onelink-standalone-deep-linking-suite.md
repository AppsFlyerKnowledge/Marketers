> **Кратко:** Отдельный пакет диплинкинга OneLink предоставляет диплинкинг и перенаправление для путей в собственных медиа (email-to-app, web-to-app, QR-to-app, social-to-app, referrals, SMS/text и т. д.) без необходимости подключать пакет атрибуции для платных медиа.

## Об отдельном пакете диплинкинга OneLink

Отдельный пакет диплинкинга создан для команд, которым нужен **надежный, масштабируемый диплинкинг, перенаправление и атрибуция для собственных каналов** без интеграций с каналами платных медиа и постбэков партнеров.

Доступны три тарифных плана:

* Стандартный
* Расширенные настройки
* Категория "Премиум"

### Что включено

Все тарифные планы отдельного пакета диплинкинга поддерживают основные сценарии использования в собственных медиа, включая:

* **Диплинкинг и отложенный диплинкинг** для направления пользователей в нужный раздел приложения
* **Кроссплатформенное перенаправление и резервное поведение**, если приложение не установлено
* **Самостоятельное создание ссылок и управление ими** в интерфейсе AppsFlyer

Планы различаются в основном по масштабу, возможностям управления ссылками и доступу к расширенным функциям, таким как брендированные домены, массовое создание ссылок, Smart Banners, OneLink API, интеграция с ESP и Data Locker.

## Сравнение тарифных планов отдельного пакета диплинкинга

### Основные различия

| План | Лучше всего для | Основные цифры |
| --- | --- | --- |
| **Стандартный** | Начало работы с диплинкингом в собственных каналах | Включает основные возможности диплинкинга и отложенного диплинкинга для путей в собственных медиа, а также Smart Script и User Invites. |
| **Расширенные настройки** | Масштабирование операций со ссылками между командами | Включает все возможности плана **Standard**, а также массовое создание ссылок, брендированные домены, Smart Banners, OneLink API (до 100 тыс. запросов в месяц) и экспорт сырых данных из интерфейса. |
| **Категория "Премиум"** | Запуск расширенных собственных программ диплинкинга | Включает все возможности плана **Advanced**, а также более высокие лимиты OneLink API (до 7,5 млн запросов в месяц), интеграцию с ESP и Data Locker. |

### Сравнение функций

| Возможность | Стандартный | Расширенные настройки | Категория "Премиум" |
| --- | --- | --- | --- |
| Пользовательские приглашения | ✓ | ✓ | ✓ |
| Смарт баннеры | **X** | ✓ | ✓ |
| Smart Script | ✓ | ✓ | ✓ |
| Брендированные домены | **X** | ✓ | ✓ |
| Пакетные ссылки | **X** | ✓ | ✓ |
| OneLink API | **X** | До 100 тыс. запросов в месяц. | До 7,5 млн запросов в месяц. |
| Интеграция с ESP | **X** | **X** | ✓ |
| Отчет Data Locker | **X** | **X** | ✓ |
| Экспорт сырых данных через UI | **X** | ✓ | ✓ |
| Менеджер по работе с клиентами | **X** | ✓ | ✓ |

> 📘 **Примечания**
>
> * Отдельный пакет диплинкинга Standalone Deep Linking Suite предназначен только для кейсов использования в собственных медиа. Партнерские интеграции по атрибуции платных медиа не включены в эти тарифные планы.
> * Для большинства функций OneLink требуется <Anchor target="_blank" href="/marketers/ru/docs/account-management-plans-payments-and-billing#appsflyer-plans">платный тарифный план AppsFlyer</Anchor>.
> * Если ваш тарифный план подписки будет отменен, большинство функций OneLink станет недоступно, а соответствующие потоки конечных пользователей могут пострадать.
> * Отложенный диплинкинг не поддерживается для подписок плана Zero.
