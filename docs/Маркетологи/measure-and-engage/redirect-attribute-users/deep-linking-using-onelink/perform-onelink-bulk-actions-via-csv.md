> **Краткий обзор.** Страница массовых ссылок OneLink позволяет мгновенно генерировать большое количество настраиваемых ссылок OneLink и просматривать их в одной панели.

Массовые ссылки позволяют создавать и просматривать ссылки, созданные в массовом порядке. Эти массовые ссылки группируются в удобном формате коллекции, что позволяет выполнять действия над всей коллекцией, например, добавлять новые ссылки или скачивать их.

## Начало работы

1. В AppsFlyer перейдите в раздел **Интерфейсы и диплинкинг** > **Массовые ссылки OneLink**.
2. Вы увидите вводную страницу с одной из следующих кнопок:
   1. **Начало работы** — отправит вас на создание первой коллекции.
   2. **Создайте шаблон OneLink** — для создания коллекции необходим шаблон OneLink. См. раздел <Anchor target="_blank" href="/marketers/ru/docs/create-a-onelink-template">Шаблоны OneLink</Anchor>.
   3. **Обновите пакет** — массовые ссылки недоступны в вашем текущем пакете. Свяжитесь с вашим менеджером или напишите по адресу [hello@appsflyer.com](mailto:hello@appsflyer.com) по поводу обновления вашего пакета.

## Создание вашей первой коллекции

1. Нажмите **Начать**.
2. Введите название коллекции.  
   Выберите название, отражающее назначение коллекции, чтобы впоследствии вы могли легко ее идентифицировать.
3. Выберите шаблон OneLink. Примечание: все ссылки коллекции будут основаны на этом шаблоне.
4. Нажмите **Сохранить и продолжить.**
5. Загрузите свой CSV-файл. Вы можете использовать следующий <Anchor target="_blank" href="https://cdn.appsflyer.com/onelink-bulk-links-mgmt/sample_file.csv">пример CSV</Anchor> в качестве руководства.  
   См. [Формат загрузки](/docs/perform-onelink-bulk-actions-via-csv#upload-format), чтобы убедиться, что ваш CSV совместим и успешно загружается. После загрузки CSV-файла он будет проверен. Если есть неверные строки, будет доступен для загрузки отчет о проверке CSV, который поможет исправить ваш файл. Следуйте инструкциям пользовательского интерфейса и загрузите исправленный файл.
6. Нажмите **Создать коллекцию.**

## Управление массовыми ссылками с помощью коллекций

Массовые ссылки управляются в коллекциях.

* В верхней части страницы виджет **Использование массовых ссылок в этом месяце** показывает количество запросов на ссылки (включая создание и обновление ссылок) из месячной квоты на текущий месяц.
  * В настоящее время по умолчанию установлен лимит в 20 000 созданий ссылок в месяц

* Раздел **Коллекции** позволяет создать новую коллекцию и выполнить другие действия с текущими коллекциями ссылок.
* Если имеется более семи коллекций, вы можете искать по списку коллекций и фильтровать его.
* Максимум 2000 ссылок на одну коллекцию

## Другие действия

Ниже перечислены другие действия, которые можно выполнить с коллекцией:

<div id="creating-a-new-collection" />

<Accordion title="Создание новой коллекции">

Создание новой коллекции доступно, если не превышен [месячный объем](/docs/perform-onelink-bulk-actions-via-csv#collection-features) использования.

2. Следуйте инструкциям.

</Accordion>

<div id="downloading-a-collection-of-links" />

<Accordion title="Скачивание коллекции">

Опция скачивания коллекции доступна, когда:

* В коллекции есть активные ссылки.
* У вас есть разрешения на доступ к приложениям, по крайней мере, к одному из мобильных приложений в шаблоне OneLink, связанном с коллекцией.

Чтобы скачать коллекцию:

1. В AppsFlyer в боковом меню выберите **Вовлечение** > **Массовые ссылки**
2. Нажмите на значок скачивания в строке коллекции.
3. Выберите домен для вывода короткого URL.
4. Нажмите **Скачать**.

> 🚧 **Важно!**
>
> AppsFlyer рекомендует использовать брендированные домены, поскольку они повышают эффективность кампании за счет доверия и повышают узнаваемость бренда. <Anchor target="_blank" href="/marketers/ru/docs/brand-onelink-with-your-domain">Подробнее здесь.</Anchor>

</Accordion>

<div id="downloading-a-collection-of-qr-codes" />

<Accordion title="Загрузка коллекции QR-кодов">

Вы можете создать изображения QR-кодов для всей коллекции.

1. В AppsFlyer в боковом меню выберите **Вовлечение** > **Массовые ссылки**
2. В строке коллекции нажмите значок загрузки изображений QR-кодов <Image alt="generate qr.png" src="https://files.readme.io/23dbd4b2e3ed248e868ae7d5deee3cac383b0e018ae17204f9547f5707a428c9-21656949404561.png" width="22px" />.
3. В диалоговом окне **Создать изображения QR-кодов** укажите следующее:
   * **Домен:** выберите поддомен или брендированный домен URL-адреса, который конечные пользователи будут видеть после сканирования QR-кода.
   * **Формат изображения QR-кода:** выберите PNG или SVG в качестве формата изображения QR-кода.
   * **Формат имени файла QR-кода:** выберите параметр, значения которого будут использоваться в качестве префикса имен файлов изображений QR-кодов. Убедитесь, что значения этого параметра добавляют осмысленный контекст к именам файлов и помогают определить назначение каждого QR-изображения.
4. Нажмите **Генерировать.** Вы можете отслеживать процесс создания файла на панели **Загрузить изображения QR-кодов**.
5. Чтобы загрузить ZIP-файл, нажмите значок загрузки <Image alt="download-bulk.png" src="https://files.readme.io/8436aed2633bbed2f6cb65c00690711766c153c97042b5b157c199333e8723c2-21656949409041.png" width="18px" />.

> 📘 **Примечание**
>
> * После успешного создания файл будет доступен на панели в течение 24 часов, после чего будет автоматически удален.
> * Загруженный файл предоставляется в формате ZIP, поскольку содержимое включает несколько файлов изображений QR-кодов. Если браузер запросит разрешение на загрузку ZIP-файлов, подтвердите его, чтобы продолжить.
> * Вы можете одновременно запускать до 2 процессов создания QR-кодов.

</Accordion>

<div id="adding-links-to-a-collection" />

<Accordion title="Добавление ссылок в коллекцию">

Опция добавления ссылок доступна, когда:

* У вас есть разрешения на доступ к приложениям, по крайней мере, к одному из мобильных приложений в шаблоне OneLink, связанном с коллекцией.
* В коллекции насчитывается менее 2000 активных ссылок.
* [Месячное использование](/docs/perform-onelink-bulk-actions-via-csv#collection-features) не превышено.

Чтобы добавить ссылки в коллекцию, нажмите на **меню** > **Добавить ссылки в коллекцию**.

* Ссылки будут добавляться тем же методом, который описан в разделе [Создание вашей первой коллекции](/docs/perform-onelink-bulk-actions-via-csv#создание-вашей-первой-коллекции), начиная с пункта 5.

</Accordion>

<div id="editing-links-in-a-collection" />

<Accordion title="Редактирование ссылок в коллекции">

Опция редактирования ссылок доступна, когда:

* В коллекции есть активные ссылки.
* У вас есть разрешения на доступ к приложениям, по крайней мере, к одному из мобильных приложений в шаблоне OneLink, связанном с коллекцией.
* [Месячное использование](/docs/perform-onelink-bulk-actions-via-csv#collection-features) не превышено.

**Для редактирования ссылок в коллекции:**

1. Нажмите **меню** > **Редактировать ссылки**.
2. Загрузите базу коллекций в формате CSV. Этот файл содержит все ссылки в коллекции, которые можно редактировать.
3. Для редактирования параметров ссылки следуйте инструкциям, приведенным в первом шаге. Для всех ссылок, которые вы хотите обновить, убедитесь, что параметр **Mark for update** (Отметить для обновления) установлен как **true**.
4. Нажмите **Далее**.
5. Загрузите отредактированный CSV. См. [Формат загрузки](/docs/perform-onelink-bulk-actions-via-csv#upload-format), чтобы убедиться, что ваш CSV совместим и успешно загружается.
   * После загрузки CSV-файл проходит проверку.
   * Если есть неверные строки, доступен для загрузки отчет о проверке CSV, который поможет исправить ваш файл. Следуйте инструкциям пользовательского интерфейса и загрузите исправленный файл.
6. Нажмите **Обновить ссылки**.

> 📘 **Примечания**
>
> * Если вы загрузили изображения QR-кодов из этой коллекции ссылок, вы можете обновить параметры ссылок и продолжить использовать те же изображения, поскольку сами QR-коды не меняются.
> * Обновление ссылок с помощью массового редактирования продлит срок действия ссылок (TTL) на 365 дней.

</Accordion>

<div id="viewing-the-collection-history" />

<Accordion title="Просмотр истории коллекции">

Чтобы просмотреть историю коллекции, нажмите на **меню** > **Просмотр истории коллекции**.

В окне истории будут показаны следующие действия, а также дата и время, когда и кем они были выполнены:

* **Изменения в названии** — изменения в названии коллекции.
* **Ссылки добавлены** — когда ссылки были добавлены в коллекцию.
* **Ссылки обновлены** — когда ссылки в коллекции были отредактированы и обновлены.
* **Коллекция** **создана** — когда была создана коллекция.
* **ZIP-файл QR-кодов загружен**: когда для коллекции были созданы и загружены изображения QR-кодов.

**Ссылки добавлены и обновлены** также показывает, как изменения повлияли на ваше [месячное использование](/docs/perform-onelink-bulk-actions-via-csv#collection-features) и позволяет скачать отчет о действиях в связи с этим изменением.

* Отчеты о действиях можно скачать, только если у вас есть разрешения на доступ хотя бы к одному из мобильных приложений в шаблоне OneLink, связанном с коллекцией.

</Accordion>

<div id="deleting-empty-collections" />

<Accordion title="Удаление пустых коллекций">

Если коллекция пустая, и у вас есть разрешения на доступ хотя бы к одному из мобильных приложений в шаблоне OneLink, связанном с коллекцией, ее можно удалить, нажав на кнопку **меню -> Удалить коллекцию**.

**Зачем**

1. Агентствам необходимо вручную добавить параметр `af_prt` к своим ссылкам.
2. Нажмите меню действий рядом с коллекцией, которую хотите удалить, и выберите **Удалить коллекцию**.

> 📘 **Вкладка «Затраты»**
>
> * Убедитесь, что вы хотите удалить коллекцию. Удаление коллекции с активными ссылками приведет к тому, что ссылки перестанут работать: пользователи, которые нажмут на них, не будут корректно атрибутированы или перенаправлены. **Удаление коллекции необратимо.**
> * Если вы хотите сохранить запись о том, какие ссылки были удалены, вы можете загрузить коллекцию перед удалением. **Чтобы загрузить файл CSV:**
>   Нажмите **Загрузить коллекцию** в сообщении с подтверждением.

<div id="upload-format" />

<Accordion title="Формат загрузки">

Чтобы ваш CSV загружался без ошибок, убедитесь, что файл соответствует следующим стандартам.

* Файл должен быть в формате CSV
* Файл не может быть больше 4 МБ
* Файл должен содержать только контент для создаваемых/обновляемых ссылок.
* Каждая ссылка должна находиться в отдельной строке
* Столбец Custom Link ID является уникальным и позволяет пользователю задать идентификатор ID короткого URL-адреса ссылки. Идентификатор короткого URL-адреса нельзя изменить после создания ссылки. Чтобы узнать больше об идентификаторе URL-адреса, см. <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#url-id">здесь</Anchor>.
* Максимум 35 столбцов с параметрами
* Принимается только кодировка символов UTF-8

</Accordion>

<div id="parameters-in-the-uploaded-csv" />

<Accordion title="Параметры CSV">

* Параметры в CSV могут быть любыми параметрами, которые допустимы в ссылке AppsFlyer. Это могут быть зарезервированные параметры для атрибуции (например: c, af\_channel, af\_adset, и т.д.), для перенаправления и диплинкинга (например: af\_ios\_url, af\_dp, deep\_link\_value, и т.д.) или настраиваемые параметры.
* Параметр медиа-источника (pid) является обязательным.
* Даже если в шаблоне OneLink задана схема URI, для ссылок, создаваемых в массовом порядке, параметр af\_dp со схемой URI должен быть указан в CSV-файле.

</Accordion>

## Часто задаваемые вопросы

<div id="qr-with-long-links-vs-short-links---is-there-any-difference" />

<Accordion title="QR-коды с длинными ссылками VS короткими — есть ли разница?">

Ваш QR-код будет работать как с длинным, так и с коротким URL-адресом. Однако, если вы используете короткий URL-адрес, вы сможете обновлять параметры и поведение ссылки через дэшборд OneLink (в разделе управления ссылками) без замены опубликованного QR-кода, поскольку сам короткий URL-адрес остается неизменным.

* **Короткие URL-адреса:** Если вы измените параметры в конфигурации короткого URL-адреса, QR-код останется прежним. Вам не нужно публиковать его повторно.
* **Длинные URL-адреса (например, Smart Script):** Если вы измените параметры в длинном URL-адресе, QR-код тоже изменится. После публикации вы не сможете удаленно обновить содержимое URL-адреса — потребуется сгенерировать и распространить новый QR-код.

</Accordion>

<div id="can-you-create-a-qr-code-and-change-the-behavior-behind-it-retroactively-after-printing-the-qr-for-example" />

<Accordion title="Можно ли создать QR-код, а затем задним числом изменить то, как он работает, например после печати QR-кода?">

Да, можно — если QR-код основан на коротком URL-адресе OneLink, который можно редактировать (например, созданном через интерфейс OneLink). **QR-код — это визуальное представление URL-адреса, на который он ведет**.  Изменение самого URL-адреса приведет к созданию нового соответствующего QR-кода (например, QR-код для mike.onelink.me/123A/shorturl отличается от QR-кода для mike.onelink.me/123A/example).

Однако, поскольку короткий URL-адрес OneLink является хешированным URL-адресом, его параметры и правила перенаправления настраиваются на бэкенде и не видны в URL-адресе. Это означает, что вы можете сохранить тот же видимый URL-адрес и QR-код, редактируя его конфигурацию на бэкенде.

</Accordion>

<div id="what-options-are-available-for-generating-qr-codes-in-appsflyer" />

<Accordion title="Какие варианты создания QR-кодов доступны в AppsFlyer?">

Доступны следующие варианты:

* **Через дэшборд AppsFlyer → интерфейс OneLink:**
  * QR-код автоматически создается при создании ссылки
  * Динамическая настройка QR-кода
  * Можно экспортировать в формате SVG или PNG
  * На основе короткого URL-адреса
* **Массовое создание QR-кодов (через страницу Bulk Links):**
  * Динамическая настройка QR-кода
  * Можно экспортировать в формате SVG или PNG
  * Поддерживает контекстное именование файлов
  * На основе коротких URL-адресов
* Чтобы проверить QR-код:
  * На основе динамически создаваемых длинных URL-адресов
  * QR-коды создаются соответствующим образом
  * Динамическая настройка QR-кода
  * Поддерживает массовое создание QR-кодов для URL-адресов

</Accordion>
