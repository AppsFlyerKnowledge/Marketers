> **Краткий обзор**. Начиная с iOS 14, при отправке приложения в App Store разработчики приложений должны предоставлять сведения о методах обеспечения конфиденциальности. В App Store такие сведения публикуются в формате *информационной этикетки.*

**Примечание юриста:** *Информация в данном руководстве не может считаться рекомендациями юриста. Информация предоставляется только для ознакомления. Вам необходимо обратиться к юристам и другим профессиональным консультантам, чтобы определить, насколько и как именно к вам применимы политики Apple.*

<div id="nutrition-labels-and-the-app-store-review" />

## Информационные этикетки и проверка App Store

* Чтобы создать этикетки с информацией о конфиденциальности, при отправке приложения в App Store Connect разработчики приложений должны заполнить анкету, которая включает следующие разделы:
  * Типы собираемых данных
  * [Цели сбора данных](/docs/preparing-for-the-app-store-review-nutrition-labels#цели-использования-данных)
  * [Связан ли тип данных с идентификацией личности](/docs/preparing-for-the-app-store-review-nutrition-labels#данные-связанные-с-идентификацией-личности)
  * Используются ли данные для отслеживания (в том числе в связи с применением любого стороннего сервиса или SDK, включенных в приложение).
* Разработчики приложений:
  * Могут сами внедрять и настраивать программное обеспечение AppsFlyer, а также решать, какие данные собирать и как их использовать.
  * Могут по-разному отвечать на вопросы анкеты в зависимости от того, как именно они настраивают программное обеспечение AppsFlyer и какие данные собирают.
* Согласно тому, как AppsFlyer понимает политику Apple, программное обеспечение AppsFlyer не выполняет *отслеживание*. При этом разработчики приложений должны отвечать на вопросы анкеты в соответствии с конкретным использованием приложения и интеграцией партнеров.
* Если вы используете собираемые данные в целях отслеживания, вам необходимо реализовать запрос на ATT.
* Далее предполагается применение настроек программного обеспечения AppsFlyer по умолчанию. Разработчики приложений самостоятельно адаптируют приложения в соответствии с конкретными настройками и сценариями использования.

#### Типы собираемых данных

| **Тип данных** | **Сбор данных AppsFlyer** | **Примечания** |
| --- | --- | --- |
| **Контактная информация**<ul><li>Имя</li><li>Электронная почта (в т.ч. в хешированном виде)</li><li>Номер телефона (в т.ч. в хешированном виде)</li><li>Физический адрес</li><li>Другие контакты пользователя</li></ul> | Нет | Не следует собирать контактную информацию. Однако, если вы настроили в приложении передачу адресов электронной почты или телефонов в хешированном виде, укажите это в анкете App Store. |
| **Фитнес** | Нет | Данные не собираются. |
| **Финансовая информация**<ul><li>Payment Info (Платежная информация)</li><li>Информация о кредитоспособности</li><li>Другая финансовая информация</li></ul> | Нет | Данные не собираются. |
| **Информация о местоположении**<ul><li>Точное местоположение</li><li>Примерное местоположение</li></ul> | См. примечания | <ul><li>Точное местоположение: нет.</li><li>Примерное местоположение: да. Сведения об IP-адресе собираются и сопоставляются с приблизительным географическим местоположением.</li></ul> |
| **Конфиденциальная информация** | Нет | Данные не собираются. |
| **Контакты** | Нет | Данные не собираются. |
| **Пользовательский контент**<ul><li>Электронные письма или текстовые сообщения</li><li>Фото или видео</li><li>Аудиоданные</li></ul> | Нет | Данные не собираются. |
| **История просмотра сайтов** | Нет | Данные не собираются. |
| **История поиска в интернете** | Нет | Данные не собираются. |
| **Идентификаторы**<ul><li>Идентификатор пользователя</li><li>Идентификатор устройства (IDFA)</li></ul> | НЕОБЯЗАТЕЛЬНОЕ | <ul><li>Идентификатор пользователя: разработчики приложений могут задавать и передавать идентификатор пользователя (CUID).</li><li>Идентификатор устройства: идентификатор рекламы (IDFA) собирается только тогда, когда он доступен.</li></ul> |
| **Покупки**<ul><li>История покупок</li></ul> | НЕОБЯЗАТЕЛЬНОЕ | Разработчики приложений могут настроить измерение определенных событий покупки в приложении. |
| **Данные об использовании**<ul><li>Взаимодействие с продуктом</li><li>Рекламные данные</li><li>Прочие данные об использовании</li></ul> | <ul><li>Да</li><li>НЕОБЯЗАТЕЛЬНОЕ</li><li>Нет</li></ul> | <ul><li>Взаимодействие с продуктом: измеряются запуски приложения, а также любое другое взаимодействие с пользователем, настроенное разработчиком приложения.</li><li>Рекламные данные: их получают, если разработчик приложения использует модуль доходов от рекламы AppsFlyer.</li></ul> |
| **Данные диагностики**<ul><li>Данные о сбоях</li><li>Данные об эффективности</li><li>Другие данные диагностики</li></ul> | <ul><li>Нет</li><li>Да</li><li>Нет</li></ul> | Могут быть получены данные о времени запуска и/или об уровне заряда батареи для обнаружения мошенничества. |
| **Прочие данные**<ul><li>Прочие типы данных</li><li>IDFV</li></ul> | Да | <ul><li>AppsFlyer получает техническую информацию об устройстве (например, ОС, тип устройства, язык, размер экрана и т. д.) или информацию о сети (например, IP-адрес, пользовательский агент HTTP).</li><li>AppsFlyer применяет идентификатор установки AF ID к каждой установке приложения.</li><li>Собираются данные IDFV</li></ul> |

<div id="data-use-purposes" />

### Цели использования данных

У Apple есть список целей, из которых разработчики приложений выбирают подходящий вариант, как подробно описано в следующей таблице. Для каждого типа данных вам необходимо определить соответствующие цели, связанные с конкретным сценарием использования вашего приложения.

| Цель использования данных | Выбирается на основе того, как будут использоваться данные из AppsFlyer |
| --- | --- |
| Сторонняя реклама | Выберите, если вы передаете данные этого типа третьей стороне с целью отображения сторонней рекламы в вашем приложении. |
| Реклама или маркетинг разработчика | Выберите, если вы показываете в приложении собственные объявления (в том числе при показе ваших объявлений совместно с третьими лицами) или для других маркетинговых целей. |
| Аналитика | Да |
| Персонализация продукта | Выберите, если вы используете данные для персонализации продукта. |
| Функционал приложения | Да |
| Прочие цели | Выберите, если вы используете данные для каких-либо целей, не указанных выше. |

<div id="data-linked-to-an-identity" />

### Данные, связанные с идентификацией личности

Типы данных, собираемые с помощью AppsFlyer, обычно при настройке связываются с идентификаторами, например, с идентификатором устройства (если он доступен), или другими идентификаторами, например, выданными клиентом.

Поэтому разработчики приложений должны указать **Да** в качестве ответа на вопрос о том, связаны ли данные с идентификацией личности.
