> **Кратко:** AppLovin — интегрированный партнер AppsFlyer и известная рекламная сеть для трафика мобильных приложений. Помимо мобильной атрибуции по кликам AppLovin также предлагает атрибуцию стоимости, дохода от рекламы и атрибуцию по просмотрам, которые вы можете регистрировать с помощью AppsFlyer.

<div id="setting-up-applovin" />

## Настройка AppLovin

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнера

При **первом посещении** здесь нужно перевести кнопку **Активировать партнера** в положение «ВКЛ.», чтобы можно было настроить параметры вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="note" />

> 📘 **Примечание**
>
> Как сеть ALL-Installs, AppLovin предпочитает получать постбэки для всех новых установок вашего приложения из ЛЮБОГО источника, включая органические. Рекомендуется выбрать *События, атрибутируемые любому партнеру*, чтобы отправлять в AppLovin все постбэки по установкам.

<div id="general-settings" />

### Общие настройки

**Передавать признак органической/неорганической установки**

Если этот переключатель включен и постбэк установки отправляется для всех медиаисточников, включая органические, AppLovin получит информацию о том, была ли установка органической или неорганической.

**Ключ SDK**

AppLovin подключается к AppsFlyer с помощью уникального sdk\_key. Если у вас еще нет sdk\_key, получите его в AppLovin, чтобы продолжить интеграцию.

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение "Включено", если хотите атрибутировать установки по просмотрам от AppLovin. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Отправляйте автоматические постбэки в AppLovin после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят только от пользователей, атрибутированных AppLovin.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять AppLovin отчеты о событиях всей вашей пользовательской базы.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе вы можете сопоставить, какие из ваших событий AppsFlyer отправлять в AppLovin через постбэки.

1. Снова укажите здесь sdk\_key AppLovin.
2. Включите переключатель «Постбэки по внутренним событиям приложения».
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне AppLovin.  <br />Получите соответствующее имя события в AppLovin и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

<div id="applovin-billable-cost" />

> 🚧 **Выставляемая AppLovin стоимость**
>
> С 1 августа 2024 года AppLovin выставляет счета всем своим клиентам на основе вероятностных установок. До этой даты некоторым клиентам выставлялись счета на основе установок SKAN. <Anchor target="_blank" href="https://support.applovin.com/hc/en-us/articles/28531589437965-iOS-Billing-Method">Дополнительные сведения см. в AppLovin</Anchor>
>
> Интеграция данных о стоимости между AppsFlyer и AppLovin точно отражает эту оплачиваемую стоимость. Это означает, что стоимость в AppsFlyer корректно соответствует стоимости на платформе AppLovin.

<div id="ad-network-permissions" />

### Ad Network Permissions (Разрешения для рекламной сети)

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* **Разрешить настраивать интеграцию** - разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по событиям в приложении)
* **Разрешение настраивать постбэки по событиям внутри приложения**: разрешить партнеру сопоставлять себе постбэки по внутренним событиям приложений на вкладке интеграции.
* **Предоставление доступа к отчету об удержании пользователей**: партнер получает доступ только к собственным данным об удержании пользователей.
* **Allow access to your aggregate loyal user data** (Разрешить доступ к агрегированным данным о лояльных пользователях): партнер получает доступ только к собственным данным о лояльных пользователях.
* **Предоставление доступа к агрегированным данным о внутренних событиях приложения**: партнер получает доступ только к собственным данным о внутренних событиях.
* **Предоставление доступа к агрегированным данным о доходе**: партнер получает доступ к данным только по атрибутированным ему доходам.
* **Разрешить доступ к дэшборду Protect360**: партнер получает доступ только к собственным данным Protect360, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
