## Интеграция Aura from Unity в AppsFlyer

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. **Примечание. Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации/деактивации партнеров</Anchor>.**
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

Подключитесь к Aura from Unity, активировав интеграцию и задав параметры на вкладке Integration.

**Чтобы настроить интеграцию**:

1. Включите **«Активировать партнера»**.
2. В разделе **General settings** включите или отключите **атрибуцию просмотров**:
   * [По умолчанию] **Включить**: активируйте этот параметр, чтобы атрибутировать установки по просмотрам в Aura from Unity . Окно атрибуции настраивается на вкладке **Attribution link**.
   * **Отключить**: установки по просмотрам от партнера не атрибутируются.
3. **Постбэки по умолчанию** отправляются в Aura from Unity для:
   * **Установки**: постбэки отправляются каждый раз, когда пользователь устанавливает приложение. Выберите, хотите ли вы отправлять постбэки для пользователей, атрибутированных Aura from Unity, или для всех пользователей, включая органические установки.
   * **Отклоненные установки**: при использовании **Protect360** постбэки отправляются, когда <Anchor target="_blank" href="/partners/ru/docs/rejected-attribution-postbacks-to-integrated-partners">установка отклоняется из-за фрода</Anchor>. Отображаются данные только по пользователям, атрибутированным для Aura from Unity.
4. **Настройки in-app событий**: чтобы отправлять постбэки, сопоставьте идентификаторы ID своих in-app событий с in-app идентификаторами Aura from Unity. Настройте параметры следующим образом:
   * Включите **постбэки по событиям в приложении**.
   * Параметр отправки: выберите, хотите ли вы отправлять **только события, атрибутированные этому партнеру**, или **события, атрибутированные любым партнерам**, включая органические установки.
   * Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие). Заполните параметры, описанные в таблице ниже.

| Название настройки | Description(Описание) |
| --- | --- |
| Имя события в SDK | Название события, полученное AppsFlyer из:<ul><li>SDK, интегрированный в приложение</li><li>Межсерверные события (S2S)</li></ul>**Совет:** Если нужного события нет в списке, выполните неорганическую установку на устройстве, а затем проверьте снова. |
| Идентификатор события партнера | Уникальное имя события или идентификатор ID, определенный в Aura from Unity.<br /><br />Выберите название события (из раскрывающегося списка), которое наиболее точно соответствует событию. |
| Отправить доход | [По умолчанию] **Не включено:** отправляет в Aura from Unity все параметры в приложении, кроме параметра дохода (`af_revenue`).<br /><br />**Включено**: отправляет все параметры в приложении, включая, если доступно, значение дохода. |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

Сгенерируйте и сохраните ссылки атрибуции и отправьте их партнеру, чтобы атрибутировать определенные кампании, группы объявлений и отдельные объявления — как для кампаний по привлечению пользователей, так и для ретаргетинговых кампаний. Вы можете использовать либо ссылку для конкретной платформы, либо <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">OneLink</Anchor>.   
<Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">Подробнее о структуре и параметрах ссылок атрибуции</Anchor>. **Чтобы создать ссылку атрибуции,** следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#attribution-link-tab">этой инструкции</Anchor>.

</Accordion>

Подробную информацию о поддерживаемых параметрах, метриках и функциях см. в <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">таблице интеграции затрат рекламной сети</Anchor>. **Примечание**: Для получения данных о затратах требуется подписка ROI360.

**Чтобы включить API данных о затратах**:

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#enable-cost-api">этим инструкциям по интеграции</Anchor>.

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API данных о затратах</Anchor> и время, когда AppsFlyer получил соответствующие данные о затратах в последний раз, либо на дэшборде статуса интеграции затрат (и доходов от рекламы), либо на дэшборде отдельной рекламной сети. 

Полный список партнеров, поддерживающих данные о стоимости <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">см. здесь</Anchor>.

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

Вы можете предоставить Aura from Unity разрешение на просмотр информации или внесение изменений в интеграцию. Тип разрешения зависит от характера деловых отношений (рекламная сеть/агентство), которые у вас есть с Aura from Unity.

**Внимание!** Можно предоставить Aura from Unity разрешения, даже если с ними нет активной интеграции.

<div id="ad-network-permissions" />

<Accordion title="Ad Network Permissions (Разрешения для рекламной сети)">

**Чтобы включить разрешения рекламной сети**:

1. Включите **разрешения рекламной сети**.
2. Предоставьте участникам команды Aura from Unity доступ к одному или нескольким из следующих элементов:
   * **Разрешить настройку интеграции**: Разрешить партнеру настраивать вкладку интеграции (за исключением постбэков событий в приложении).
   * **Разрешить настройку постбэков событий в приложении**: Разрешить партнеру сопоставлять постбэки событий в приложении с самим собой на вкладке интеграции.
   * **Разрешить доступ к вашему отчету об удержании**: Доступ предоставляется только к собственным данным партнера об удержании.
   * **Разрешить доступ к вашим сводным данным о лояльных пользователях**: Доступ предоставляется только к собственным данным партнера о лояльных пользователях.
   * **Разрешить доступ к вашим сводным данным о событиях в приложении**: Доступ предоставляется только к собственным данным партнера о событиях в приложении.
   * **Предоставить доступ к вашим сводным данным о доходе:** Доступ предоставляется только к данным о доходе, атрибутированном партнеру.
   * **Разрешить загрузку данных о расходах**: разрешить партнеру загружать данные о расходах на рекламу для этого приложения.
   * **Разрешить доступ к вашему дэшборду Protect360**: доступ предоставляется только к собственным данным партнера в **Protect360**, если эта функция включена для рекламодателя.

</Accordion>
