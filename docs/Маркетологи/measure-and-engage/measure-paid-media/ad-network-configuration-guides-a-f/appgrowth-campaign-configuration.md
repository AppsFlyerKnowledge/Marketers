> **Краткий обзор:** Appgrowth — интегрированный партнер рекламной сети AppsFlyer и производитель оригинального контента для специалистов по росту мобильных приложений. Помимо мобильной атрибуции по кликам Appgrowth также предлагает атрибуцию по просмотрам, которую можно регистрировать с помощью AppsFlyer.

<div id="setting-up-appgrowth" />

## Настройка Appgrowth

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

<div id="activate-partner" />

### Активация партнера

При **первом посещении** нужно перевести кнопку **Активировать партнера** в положение «Включено», чтобы настроить параметры на вкладке интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="note" />

#### Примечание:

Как сеть, ориентированная на все установки, Appgrowth предпочитает получать постбэки для всех новых установок вашего приложения из любого источника, включая органические. Рекомендуется выбрать **События, атрибутированные любому партнеру**, чтобы отправлять в Appgrowth постбэки по всем установкам.

<div id="general-settings" />

### Общие настройки

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение «Включено», если хотите атрибутировать установки по просмотрам из Appgrowth. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Appgrowth после установок пользователей и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, которые поступают только от пользователей, атрибутированных Appgrowth.  
Выберите **События, атрибутированные любому партнеру или органические**, чтобы передавать в Appgrowth данные обо всей вашей пользовательской базе.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе вы можете сопоставить события AppsFlyer с Appgrowth через постбэки.

1. Установите переключатель «Постбэки событий в приложении» в положение «Включено»
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Appgrowth.  <br />Получите соответствующий идентификатор события в Appgrowth и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке вы можете создавать ссылки атрибуции, которые нужно отправить в Appgrowth для атрибуции кампаний, групп объявлений или отдельных рекламных объявлений Appgrowth. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** — добавьте этот параметр, чтобы сравнивать разные кампании в Appgrowth.  
  **Параметр ссылки атрибуции:** c
* **Группа объявлений** — укажите названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Appgrowth.  
  **Параметр ссылки атрибуции:** af\_adset
* **Название объявления** — укажите названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Appgrowth.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки конкретным паблишерам. При наличии большого количества паблишеров рекомендуем ограничить число используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы избежать <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">превышения ограничений Site ID</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика для вставки полезных значений. Обратите внимание: эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

<div id="click-through-attribution" />

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от клика до установки**. Appgrowth атрибутируются только те установки (первые запуски), которые произошли в рамках окна атрибуции.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте его в Appgrowth, чтобы он активировался, когда потенциальные клиенты нажимают на соответствующее объявление.

<div id="view-through-attribution-lookback-window" />

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. Appgrowth атрибутируются только те установки (первые запуски), которые произошли в рамках этого окна атрибуции после показа рекламы, при условии отсутствия других кликов по объявлению, относящихся к этой установке.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

<div id="impressions-attribution-link" />

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в Appgrowth для активации при просмотре соответствующей рекламы, обычно в течение 1 секунды или более.

</Accordion>

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API данных о затратах</Anchor> и время, когда AppsFlyer получил соответствующие данные о затратах в последний раз, либо на дэшборде статуса интеграции затрат (и доходов от рекламы), либо на дэшборде отдельной рекламной сети. .

В Appgrowth интеграция доходов от рекламы недоступна.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке вы можете выбрать разрешения, которые будут предоставлены Appgrowth. Обратите внимание, что даже если атрибуция отключена для Appgrowth, вкладка разрешений остается активной, и вы можете предоставить Appgrowth права управления.

Используйте эти переключатели, чтобы предоставить рекламной сети разрешения на управление собственной конфигурацией вашего приложения: Разрешения рекламной сети

* **Разрешение настраивать интеграцию**: разрешить партнеру управлять настройками на вкладке интеграции (за исключением постбэков по внутренним событиям приложений).
* **Разрешение настраивать постбэки по событиям внутри приложения**: разрешить партнеру сопоставлять себе постбэки по внутренним событиям приложений на вкладке интеграции.
* **Предоставление доступа к отчету об удержании пользователей**: партнер получает доступ только к собственным данным об удержании пользователей.
* **Allow access to your aggregate loyal user data** (Разрешить доступ к агрегированным данным о лояльных пользователях): партнер получает доступ только к собственным данным о лояльных пользователях.
* **Разрешить доступ к своим сводным данным о событиях в приложении** — только к собственным данным партнера о событиях в приложении
* **Предоставление доступа к агрегированным данным о доходе**: партнер получает доступ к данным только по атрибутированным ему доходам.
* **Разрешить доступ к дэшборду Protect360**: партнер получает доступ только к собственным данным Protect360, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
