> **Кратко:** Adikteev — интегрированный партнер AppsFlyer, рекламная сеть и ad-tech-компания, специализирующаяся на технологиях in-app ретаргетинга и рекламе для повторного вовлечения. Adikteev предлагает мобильную атрибуцию как по кликам, так и по просмотрам. Кроме того, Adikteev также предлагает ретаргетинг по кликам, который можно записывать с помощью AppsFlyer.

## Настройка Adikteev

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<Accordion title="Вкладка «Интеграция»">

### Активация партнера

При **первом посещении** вам нужно перевести кнопку ***Activate Partner*** в положение «Включено», чтобы получить возможность настроить параметры вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Этот переключатель должен быть <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активирован</Anchor> все время, пока вы работаете с этим партнером.Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

Общие настройки

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение «Включено», если хотите атрибутировать установки после просмотра из Adikteev. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Adikteev после установок пользователей и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, поступающих только от пользователей, атрибутированных Adikteev.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы вся ваша база пользователей была доступна для передачи отчетности в Adikteev.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события в AppsFlyer с Adikteev и настроить отправку постбэков.

1. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Adikteev.  <br />Получите соответствующий идентификатор ID события в Adikteev и задайте его в текстовом поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые нужно отправить в Adikteev, чтобы атрибутировать кампании, группы объявлений или отдельные объявления Adikteev. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные с Adikteev.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках конкретных кампаний Adikteev.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия объявлений, чтобы сравнивать разные креативы в конкретных группах объявлений в рамках конкретных кампаний Adikteev.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов site ID и использовать параметр идентификатора subsite ID, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить ограничения по site ID</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика для вставки полезных значений. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

### Настройки ретаргетинга

При активации этой настройки AppsFlyer распознает ссылку как <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide">ссылку атрибуции для ретаргетинга</Anchor>, а не как ссылку для привлечения пользователей, добавляя `&is_retargeting=true` к ссылке регистрации нажатий. Обратите внимание, что ретаргетинг в данное время поддерживается только для атрибуции по нажатиям, а для атрибуции по просмотрам — нет.  
**Параметр ссылки атрибуции:** is\_retargeting.

Когда ретаргетинг активирован, отображаются следующие настройки.

1. Стандартная ссылка и ссылка OneLink

Вариант ***стандартная ссылка атрибуции*** следует выбирать в следующих случаях:

* URL-адрес не будет использоваться в качестве глубинной ссылки или
* Планируете использовать только <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#general-settings">схемы URI</Anchor> для диплинкинга

Выберите ***Use OneLink*** для:

* Для приложений на Android и iOS используется одна и та же ссылка или
* Для диплинкинга используются универсальные ссылки или ссылки приложений

Обратите внимание, что при выборе OneLink ссылка для регистрации нажатий превращается из ссылки для конкретного приложения в <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">URL-адрес OneLink</Anchor>.

2. URL-адрес диплинка

Используйте это поле, если ссылка предназначена для прямого перехода пользователей к какому-либо конкретному действию в вашем приложении.  
**Параметр ссылки атрибуции:** af\_dp  
Подробную информацию о решении AppsFlyer для диплинкинга можно найти <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">в этом руководстве.</Anchor>

3. Окно повторного вовлечения

Задайте временной интервал после повторного вовлечения, в течение которого внутренние события приложения пользователя будут атрибутироваться медиа-источнику ретаргетинга. Вы можете задать ценность, значение в днях (1-90), часах (до 23) или даже на весь период.

**Параметр ссылки атрибуции:** af\_reengagement\_window

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. Только установки (первые запуски), совершенные в пределах окна атрибуции, могут быть атрибутированы Adikteev.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне лукбэка по кликам см. здесь</Anchor>.

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте его в Adikteev, чтобы он активировался, когда потенциальные клиенты кликают по соответствующему рекламному объявлению.

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. Для Adikteev атрибутируются только те установки (первые запуски), которые произошли в рамках этого окна атрибуции после показа рекламы, при условии отсутствия других релевантных кликов по объявлению.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в Adikteev, чтобы он активировался, когда клиенты просматривают соответствующее рекламное объявление, обычно в течение 1 секунды или дольше.

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке вы можете выбрать разрешения, которые хотите предоставить Adikteev. Обратите внимание, что, даже если атрибуция для Adikteev отключена, вкладка разрешений остается активной и вы можете предоставить Adikteev разрешение на управление.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — только к собственным сводным данным партнера о лояльных пользователях
* ***Разрешить доступ к своим сводным данным о событиях в приложении** —* только к собственным данным партнера о событиях в приложении
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
