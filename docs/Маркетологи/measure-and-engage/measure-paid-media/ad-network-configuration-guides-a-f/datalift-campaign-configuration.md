> **Кратко:** DataLift — интегрированный партнер AppsFlyer, который позволяет маркетологам приложений программно получать доступ ко всем основным источникам мобильного рекламного инвентаря по всему миру и управлять своими кампаниями через единую собственную технологическую платформу, обеспечивая расширенную интеграцию данных, а также расширенные возможности таргетинга и управления аудиториями. Помимо мобильной атрибуции по кликам, DataLift также предлагает ретаргетинг, который можно регистрировать с помощью AppsFlyer.

<div id="setting-up-datalift" />

## Настройка DataLift

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

В окне конфигурации DataLift есть 3 активные вкладки: Integration, Attribution link и Permissions. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

<div id="activate-partner" />

### Активация партнера

При **первом посещении** здесь вам нужно перевести кнопку ***Activate Partner*** в положение ON, чтобы стала доступна настройка параметров вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="general-settings" />

### Общие настройки

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в DataLift после установок и повторного вовлечения пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые поступают только от пользователей, атрибутированных DataLift.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы данные обо всей вашей пользовательской базе были доступны для передачи в Datalift Retargeting.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно настроить сопоставление событий AppsFlyer с DataLift через постбэки.

1. Введите API\_KEY
2. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, заданные на стороне ретаргетинга Datalift.  <br />Получите соответствующий идентификатор ID события в DataLift и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создать ссылки атрибуции, которые вы хотите отправить в DataLift Retargeting для атрибуции кампаний, групп объявлений или даже отдельных рекламных объявлений DataLift. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в DataLift.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний DataLift.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Datalift Retargeting.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. Если паблишеров много, рекомендуем ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы избежать <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">превышения ограничений по идентификатору сайта</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание, что эти параметры парсятся и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

<div id="retargeting-settings" />

### Настройки ретаргетинга

Если этот параметр включен, AppsFlyer распознает ссылку как ссылку атрибуции для <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide">ретаргетинга</Anchor>, а не как ссылку для привлечения пользователей, добавляя `&is_retargeting=true` в ссылку регистрации клика. Обратите внимание, что ретаргетинг в настоящее время поддерживается только для атрибуции по кликам, но не для атрибуции по просмотрам.  
**Параметр ссылки атрибуции:** is\_retargeting.

Когда ретаргетинг активирован, отображаются следующие настройки.

1. Стандартная ссылка и ссылка OneLink

Выберите вариант ***стандартная ссылка атрибуции***, если:

* URL-адрес не будет использоваться в качестве глубинной ссылки или
* Планируете использовать только <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#general-settings">схемы URI</Anchor> для диплинкинга

Выберите ***Use OneLink*** для:

* Для приложений на Android и iOS используется одна и та же ссылка или
* Для диплинкинга используются универсальные ссылки или ссылки приложений

Обратите внимание, что при выборе OneLink ссылка регистрации клика меняется со ссылки для конкретного приложения на <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">URL-адрес OneLink</Anchor>.

2. URL-адрес диплинка

Используйте это поле, если ссылка предназначена для прямого перехода пользователей к какой-либо конкретной активности в вашем приложении.  
**Параметр ссылки атрибуции:** af\_dp  
Подробнее о решении AppsFlyer для <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">диплинкинга читайте в этом руководстве.</Anchor>

3. Окно повторного вовлечения

Задайте временной интервал после повторного вовлечения, в течение которого внутренние события приложения пользователя будут атрибутироваться медиа-источнику ретаргетинга. Вы можете задать ценность, значение в днях (1-90), часах (до 23) или даже на весь период.

**Параметр ссылки атрибуции:** af\_reengagement\_window

<div id="click-through-attribution" />

### Атрибуция по кликам

С помощью этого ползунка можно задать **максимальное время от клика до установки**. Только установки (первые запуски), которые произошли в пределах окна атрибуции, могут быть атрибутированы DataLift.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне лукбэка по кликам см. здесь</Anchor>.

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в DataLift, чтобы она активировалась, когда лиды кликают по соответствующей рекламе.

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для DataLift в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что, даже если атрибуция для DataLift отключена, вкладка разрешений остается активной и вы можете предоставить DataLift разрешение на управление.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

Полномочия для рекламной сети

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по событиям в приложении)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Разрешить доступ к своим агрегированным данным о лояльных пользователях*** — только к собственным данным партнера о лояльных пользователях
* ***Разрешить доступ к своим агрегированным данным о событиях в приложении** —* только к собственным данным партнера о событиях в приложении
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
