> **Кратко:** Adcash — рекламная сеть, интегрированный партнер AppsFlyer, и это глобальная рекламная платформа, предоставляющая полностью программируемую платформу DSP самообслуживания.

<div id="setting-up-adcash" />

## Настройка Adcash

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом посещении** здесь вам нужно включить **Активировать партнера**, чтобы включить настройку параметров вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
    Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

В окне настройки Adcash есть 3 активные вкладки: Integration, Attribution link и Permissions. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

<div id="activate-partner" />

### Активация партнера

При **первом посещении** необходимо включить параметр **Активировать партнера**, чтобы настроить параметры на вкладке «Интеграция». Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации/деактивации партнеров</Anchor>.

<div id="general-settings" />

### Общие настройки

Чтобы включить интеграцию с Adcash, введите учетные данные **Goal ID (Adcash)**. Обратите внимание: идентификатор не может содержать символы или пробелы.

<div id="default-postbacks" />

### Постбэки по умолчанию

Постбэки по умолчанию для установок отправляются в Adcash, если установка была атрибутирована Adcash, то есть если пользователь, выполнивший ее, пришел из Adcash.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события в AppsFlyer с событиями в Adcash и настроить отправку постбэков.

1. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
2. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
3. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного в приложение, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор каждого события, определенные на стороне Adcash.  <br />Получите соответствующий идентификатор события в Adcash и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые нужно передать Adcash для атрибуции кампаний, групп объявлений или отдельных объявлений Adcash. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Adcash.  
  **Параметр ссылки атрибуции:** c
* **Adset** — укажите названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках отдельных кампаний Adcash.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — укажите названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Adcash.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметры Site ID и Sub Site ID, чтобы атрибутировать установки конкретным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить ограничение по Site ID</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание: эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

**Параметр ссылки атрибуции:** af\_reengagement\_window

<div id="click-through-attribution" />

### Атрибуция по кликам

С помощью этого ползунка можно задать **максимальное время от клика до установки**. К Adcash могут быть атрибутированы только те установки (первые запуски), которые произошли в пределах окна атрибуции.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте его в Adcash, чтобы он активировался, когда потенциальные клиенты нажимают на соответствующее объявление.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения, которые вы хотите предоставить Adcash. Обратите внимание: даже если атрибуция для Adcash отключена, вкладка разрешений остается активной, и вы можете предоставить Adcash контроль.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

<div id="ad-network-permissions" />

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Allow to configure in-app event postbacks*** (Разрешить настройку постбэков внутренних событий приложений) — разрешить партнеру настраивать постбэки внутренних событий приложений и отображать эти настройки на вкладке интеграции
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate loyal user data*** (Разрешить доступ к своим сводным данным о лояльных пользователях) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate in-app events data*** (Разрешить доступ к своим сводным данным о внутренних событиях приложения) — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
