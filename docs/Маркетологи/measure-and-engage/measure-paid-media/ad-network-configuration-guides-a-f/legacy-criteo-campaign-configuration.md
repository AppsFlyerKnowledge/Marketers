> **Краткий обзор:** Criteo (Legacy) — интегрированный партнер AppsFlyer в качестве рекламной сети и компания, специализирующаяся на персонализированном ретаргетинге. Она работает с интернет-ритейлерами, показывая персонализированную онлайн-рекламу пользователям, которые ранее посещали сайт рекламодателя. Помимо мобильной атрибуции по кликам, Criteo (Legacy) также предлагает ретаргетинг, данные которого можно регистрировать с помощью AppsFlyer.

<div id="setting-up-criteo-legacy" />

## Настройка Criteo (legacy)

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

Окно конфигурации Criteo (legacy) содержит 4 вкладки: Интеграция, Ссылка атрибуции, Обогащение данных и Разрешения. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

Подробное описание заголовка окна «Partner Configuration» (Настройки партнёра) см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

<div id="activate-partners" />

### Активация партнеров

При **первом посещении** необходимо включить кнопку ***Активировать партнера***, чтобы включить настройку параметров вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть типа ALL-Installs, Criteo (Legacy) предпочитает получать постбэки обо всех новых установках вашего приложения из ЛЮБОГО источника, включая органические. Рекомендуется выбрать **События, атрибутируемые любому партнеру**, чтобы отправлять в Criteo (Legacy) все постбэки по установкам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Criteo (Legacy) после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят только от пользователей, атрибутированных Criteo (Legacy).  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы в отчетность для Criteo (Legacy) попадала вся ваша пользовательская база.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с Criteo (Legacy) посредством постбэков.

1. Включите переключатель «Постбэки по внутренним событиям приложения».
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Criteo (Legacy).  <br />Получите соответствующий идентификатор ID события в Criteo (Legacy) и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые вы хотите отправлять в Criteo (Legacy) для атрибуции кампаний, групп объявлений или отдельных объявлений Criteo (Legacy). Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Criteo (Legacy).  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Criteo (Legacy).  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия групп объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Criteo (Legacy).  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">избежать превышения ограничений по идентификаторам сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика, чтобы передавать полезные значения. Обратите внимание, что эти параметры обрабатываются и отображаются в Отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

<div id="retargeting-settings" />

### Настройки ретаргетинга

При активации этой настройки AppsFlyer распознает ссылку как ссылку атрибуции для <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide">ретаргетинга</Anchor>, а не как ссылку для привлечения пользователей, добавляя `&is_retargeting=true` к ссылке регистрации кликов. Обратите внимание, что ретаргетинг в настоящее время поддерживается только для атрибуции по кликам, а не по просмотрам.  
**Параметр ссылки атрибуции:** is\_retargeting.

Когда ретаргетинг включен, отображаются следующие настройки.

1. Стандартная ссылка и ссылка OneLink

Вариант ***стандартная ссылка атрибуции*** следует выбирать в следующих случаях:

* URL-адрес не будет использоваться в качестве глубинной ссылки или
* Планируете использовать только <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#general-settings">схемы URI</Anchor> для диплинкинга

select ***Use OneLink*** for:

* Для приложений на Android и iOS используется одна и та же ссылка или
* Для диплинкинга используются универсальные ссылки или ссылки приложений

Обратите внимание, что при выборе OneLink ссылка для регистрации кликов меняется со ссылки для конкретного приложения на <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">URL-адрес OneLink</Anchor>.

2. URL-адрес диплинка

Используйте это поле, если ссылка предназначена для прямого перехода пользователей к какому-либо конкретному действию в вашем приложении.  
**Параметр ссылки атрибуции:** af\_dp  
Подробные сведения о решении AppsFlyer для диплинкинга см. <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">в этом руководстве.</Anchor>

3. Окно повторного вовлечения

Задайте временной интервал после повторного вовлечения, в течение которого внутренние события приложения пользователя будут атрибутироваться медиа-источнику ретаргетинга. Вы можете задать ценность, значение в днях (1-90), часах (до 23) или даже на весь период.

**Параметр ссылки атрибуции:** af\_reengagement\_window

<div id="click-through-attribution" />

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. Для Criteo (Legacy) атрибутируются только те установки (первые запуски), которые произошли в пределах окна атрибуции/лукбэка.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в Criteo (Legacy), чтобы она активировалась, когда лиды кликают по соответствующему рекламному объявлению.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения, которые вы предоставляете Criteo (Legacy), независимо от того, выступает ли партнер в качестве рекламной сети, агентства или в обеих ролях. Обратите внимание, что даже если атрибуция для Criteo (Legacy) отключена, вкладка разрешений остается активной, и вы можете предоставить Criteo (Legacy) разрешение на управление.

**Ad Network Permissions (Разрешения для рекламной сети)**

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

<div id="agency-permissions" />

### Разрешения агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* ***Главный переключатель*** — установите в положение «Включено», чтобы открыть параметры разрешений для агентства
* ***Разрешить настройку постбэков по событиям в приложении*** — разрешить агентству настраивать сопоставление постбэков по событиям в приложении с самим собой на вкладке интеграции
* ***Разрешить доступ к отчету об удержании*** — доступ предоставляется только к собственным данным агентства об удержании
* ***Разрешить доступ к агрегированным органическим данным***
* ***Разрешить настраивать постбэки для событий в приложении*** - разрешить агентству настроить сопоставление постбэков для событий в приложении с собой на вкладке интеграции

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.

</Accordion>
