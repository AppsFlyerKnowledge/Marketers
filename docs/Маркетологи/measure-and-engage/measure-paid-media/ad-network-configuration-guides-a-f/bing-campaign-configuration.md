> **Краткий обзор:** Bing, интегрированный партнер рекламной сети AppsFlyer, — одна из ведущих поисковых систем в мире. Вы можете управлять кампаниями по привлечению пользователей через Bing и атрибутировать их с помощью AppsFlyer.

> 📘 **Примечание:**
>
> Microsoft требует от поставщиков атрибуции удалять данные на уровне пользователей через 13 месяцев после установки. Это означает, что события этих пользователей, которые произошли через 13 месяцев после установки приложения, считаются органическими. Агрегированные данные за прошлое время не изменяются.

## Настройка Bing

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной.   
   **Важное примечание:** переключатель **должен оставаться включенным (активным), пока вы работаете с партнером**. <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">Узнать больше</Anchor>
5. Завершите настройку, используя соответствующие вкладки, как описано ниже.

См. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">окно настройки партнера</Anchor>

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

#### Активация партнера

При **первом посещении** необходимо включить кнопку ***Активировать партнера***, чтобы включить настройку параметров вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

#### Постбэки по умолчанию

Отправляйте автоматические постбэки в Bing после установок пользователей.

> 📘 **Примечание:**
>
> Параметр **Только события, атрибутированные этому партнеру** — единственный вариант для Bing и выбран по умолчанию.

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

Формируйте и сохраняйте ссылки атрибуции и отправляйте их партнеру, чтобы атрибутировать определенные кампании, группы объявлений и отдельные объявления — как для кампаний по привлечению пользователей, так и для ретаргетинговых кампаний. Вы можете использовать либо ссылку для конкретной платформы, либо <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">OneLink</Anchor>.  
<Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">Подробнее о структуре и параметрах ссылок атрибуции</Anchor>.

**Чтобы создать ссылку атрибуции,** следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#attribution-link-tab">этой инструкции</Anchor>.

</Accordion>
