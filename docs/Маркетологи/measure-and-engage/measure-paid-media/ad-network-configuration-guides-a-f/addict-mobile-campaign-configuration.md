> **Кратко:** Addict Mobile — интегрированный партнер AppsFlyer в категории рекламных сетей и эксперт в области мобильного performance-маркетинга для привлечения пользователей и ретаргетинга на мобильных устройствах. Помимо мобильной атрибуции по кликам, Addict Mobile также предлагает атрибуцию по просмотрам, которую можно регистрировать с помощью AppsFlyer.

<div id="setting-up-addict-mobile" />

## Настройка Addict Mobile

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<Accordion title="Вкладка «Интеграция»">

<div id="activate-partner" />

### Активация партнера

При **первом посещении** необходимо включить кнопку ***Активировать партнера***, чтобы включить настройку параметров вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="general-settings" />

### Общие настройки

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение «Включено», если хотите атрибутировать установки по просмотрам из Addict Mobile. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Отправляйте автоматические постбэки в Addict Mobile после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, поступающих только от пользователей, атрибутированных Addict Mobile.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять в Addict Mobile отчеты о событиях всех пользователей, которые есть в вашей базе.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события в AppsFlyer с событиями в Addict Mobile и настроить отправку постбэков.

1. Включите переключатель «Постбэки по внутренним событиям приложения».
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.
   * **Только события, атрибутируемые этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.
   * **События, атрибутируемые любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Addict Mobile.  <br />Получите соответствующий идентификатор события у Addict Mobile и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые вы хотите отправить в Addict Mobile для атрибуции кампаний, групп объявлений или отдельных объявлений Addict Mobile. Обратите внимание, что AppsFlyer НЕ сохраняет созданные вами ссылки атрибуции.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Addict Mobile.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках отдельных кампаний Addict Mobile.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках отдельных кампаний Addict Mobile.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров мы рекомендуем ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы избежать <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">превышения ограничений по идентификаторам сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика, чтобы передавать полезные значения. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

<div id="click-through-attribution" />

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от клика до установки**. К Addict Mobile могут быть отнесены только те установки (первые запуски), которые произошли в пределах окна атрибуции.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции кликов см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в Addict Mobile, чтобы она активировалась, когда потенциальные клиенты нажимают на соответствующее объявление.

<div id="view-through-attribution-lookback-window" />

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. К Addict Mobile относятся только те установки (первые запуски), которые произошли в рамках этого окна атрибуции после показа рекламы, при условии что не было другого релевантного клика по рекламе.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

<div id="impressions-attribution-link" />

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в Addict Mobile, чтобы она активировалась при просмотре соответствующей рекламы, обычно в течение 1 секунды или более.

</Accordion>

</Accordion>

<div id="ad-revenue-tab" />

<Accordion title="Вкладка «Доходы от рекламы»">

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для Addict Mobile в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что, даже если атрибуция для Addict Mobile отключена, вкладка разрешений остается активной и вы можете предоставить Addict Mobile разрешение на управление.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

<div id="ad-network-permissions" />

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к агрегированным данным о лояльных пользователях*** — только к данным партнера о собственных лояльных пользователях.
* ***Разрешить доступ к агрегированным данным о событиях в приложении*** — только к собственным данным партнера о событиях в приложении
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

<div id="agency-permissions" />

### Разрешения агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* ***Главный переключатель*** — установите в положение «Включено», чтобы получить доступ к параметрам разрешений для агентства
* ***Разрешить доступ к вашему отчету об удержании*** — только к собственным данным агентства по удержанию
* ***Разрешить доступ к агрегированным органическим данным***
* ***Разрешить настройку постбэков по событиям в приложении*** — разрешить агентству настраивать постбэки по событиям в приложении с сопоставлением самому себе на вкладке интеграции

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.

</Accordion>
