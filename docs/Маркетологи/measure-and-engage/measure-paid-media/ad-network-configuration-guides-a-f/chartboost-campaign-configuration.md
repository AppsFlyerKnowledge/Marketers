> **Краткий обзор:** Chartboost, интегрированный партнер AppsFlyer в качестве рекламной сети, — одна из крупнейших рекламных платформ только для мобильных игр, помогающая увеличивать доход. Помимо мобильной атрибуции по кликам, Chartboost также предлагает атрибуцию затрат, дохода от рекламы и по просмотрам, данные которых можно регистрировать с помощью AppsFlyer.

<div id="note" />

> 📘 **Примечание:**
>
> Интеграция SDK Chartboost необходима только в том случае, если вы выступаете паблишером Chartboost и хотите атрибутировать доход от рекламы. В противном случае достаточно SDK AppsFlyer. Для получения дополнительной информации см. [раздел этой статьи о доходе от рекламы](/docs/chartboost-campaign-configuration#ad-revenue-tab).

<div id="setting-up-chartboost" />

## Настройка Chartboost

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

На вкладке ***Интеграция*** есть несколько разделов, которые описаны ниже.

<div id="activate-partners" />

### Активация партнеров

При первом посещении необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation#активировать-интеграцию-партнера">активировать партнера</Anchor>, включив переключатель ***Активировать партнера***, чтобы настроить его.

<div id="general-settings" />

### Общие настройки

**ID приложения Chartboost и подпись**

Для подключения к AppsFlyer Chartboost требуется уникальный идентификатор приложения и подпись. Если вы не знаете свой идентификатор, вы можете получить его напрямую у Chartboost.

**Активация атрибуции по просмотрам**

Включите эту опцию, если хотите атрибутировать установки по просмотрам с Chartboost. Слайдер лукбэка по просмотрам доступен на вкладке ***Ссылка атрибуции***.

<div id="default-postbacks" />

### Постбэки по умолчанию

Отправляйте автоматические постбэки в Chartboost после установок и отклоненных установок. Используйте этот раздел, чтобы определить **источник пользователей** для постбэков.

Выберите ***Только этот партнер*** для установок, поступающих только от пользователей, атрибутированных к Chartboost.  
Выберите ***Все источники, включая органические***, чтобы вся ваша база пользователей была доступна для отчетов в Chartboost.

Отклоненные установки можно отправлять только при выборе опции **Только этот партнер**.

<div id="launch-postbacks" />

#### Постбэки при запуске

С 1 июля 2020 года мы больше не отправляем постбэки при запуске в Chartboost. Если ваша интеграция была настроена до этой даты, в ваших конфигурациях могут быть изменения. В таблице ниже описаны возможные изменения и ваши действия, если применимо:

| Ваша конфигурация | Будет обновлена до | Ваши дальнейшие действия |
| --- | --- | --- |
| Отправлять в Chartboost **все запуски** (из всех медиаисточников, включая органические) | Отправлять в Chartboost:<ul><li>**все установки** (из всех медиаисточников, включая органические)</li><li>**все события** `af_app_opened` (из всех медиаисточников, включая органические)</li></ul> | Никаких дополнительных действий не требуется. Это обновление не оказывает фактического воздействия на конфигурацию. |

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе вы можете настроить отправляемые в Chartboost постбэки о событиях в приложении.

**Чтобы настроить постбэки для внутренних событий приложения:**

1. Активируйте ***постбэк события в приложении***.
2. Выберите, что следует отправлять партнеру: только избранные события или все.
   * Примечание: Если вы выберете отправку всех событий, событие *af\_app\_opened* отправляться не будет.
3. Если вы хотите выбрать события вручную, нажмите ***Add event*** (Добавить событие), чтобы добавить в список события SDK.

| Название параметра | Description(Описание) |
| --- | --- |
| **SDK event name** *(Имя события SDK) (требуется только при выборе вручную)* | Название события, полученное AppsFlyer либо из SDK, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, активируйте его на устройстве с неорганической установкой, и повторите поиск. |
| **Sending option (Вариант отправки)** | Выберите вариант отправки события:  <br />**Только этому партнеру** для событий, поступающих **только** от пользователей, атрибутированных Chartboost.  <br />**Все источники, включая органические**, чтобы партнер получал сведения о событиях всех пользователей, которые есть в вашей базе. |
| **Отправить данные о событии** | <ul><li>**Нет значений и нет дохода:** отправляет только само событие без значения.</li><li>**Значения, нет дохода:** отправляет все параметры, кроме значения дохода.</li><li>**Значения и доход**: отправляет все параметры события, включая значение дохода (если оно есть в событии).</li></ul> |

4. Нажмите кнопку ***Сохранить***.

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые нужно передать Chartboost для атрибуции кампаний, групп объявлений и отдельных объявлений Chartboost. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнивать разные кампании в Chartboost.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Chartboost.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия объявлений, чтобы сравнивать разные креативы в рамках определенных групп объявлений в определенных кампаниях Chartboost.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить ограничение по Site ID</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание: эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

<div id="click-through-attribution" />

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от клика до установки**. Chartboost могут быть атрибутированы только те установки (первые запуски), которые произошли в рамках окна атрибуции.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте её в Chartboost, чтобы она активировалась, когда потенциальные клиенты кликают по соответствующему рекламному объявлению.

<div id="view-through-attribution-lookback-window" />

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. Chartboost атрибутируются только те установки (первые запуски), которые произошли в рамках этого окна атрибуции после показа рекламы, при условии отсутствия других релевантных кликов по объявлению.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

<div id="impressions-attribution-link" />

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в Chartboost для активации при просмотре соответствующей рекламы.

</Accordion>

В этом случае вам, безусловно, будет интересно получить показатели вовлеченности пользователей, привлеченных из различных источников, чтобы выявить самые прибыльные.

**Чтобы включить API доходов от рекламы**:

<div id="important" />

> 🚧 **Важно!**
>
> Если вы используете Chartboost как паблишер, помимо настройки AppsFlyer необходимо выполнить еще два требования:
>
> 1. [Интегрируйте Chartboost SDK](https://answers.chartboost.com/en-us/child_article/ios) — это требуется, только если вы выступаете как паблишер. **Если вы используете Chartboost только для рекламы своего приложения, вам достаточно интегрировать только AppsFlyer SDK**.
> 2. [Включите Chartboost S2S](https://answers.chartboost.com/en-us/child_article/s2s-setup) — этот шаг нужен, чтобы AppsFlyer мог запрашивать у Chartboost данные о доходе от рекламы. **Не путайте это с** <Anchor target="_blank" href="/marketers/ru/docs/server-to-server-events-api-for-mobile-s2s-mobile">**AppsFlyer S2S**</Anchor> **— способом отправки событий в приложении в AppsFlyer через специальный API.**

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения, которые будут предоставлены Chartboost, в зависимости от того, выступает ли партнер как рекламная сеть, агентство или в обоих качествах. Обратите внимание: даже если атрибуция для Chartboost отключена, вкладка разрешений остается активной, и вы можете предоставить Chartboost права управления.

Используйте эти переключатели, чтобы предоставить рекламной сети разрешения на управление собственной конфигурацией вашего приложения: Разрешения рекламной сети

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate loyal user data*** (Разрешить доступ к своим сводным данным о лояльных пользователях) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate in-app events data*** (Разрешить доступ к своим сводным данным о внутренних событиях приложения) — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>

<div id="discrepancies-between-chartboost-and-appsflyer" />

## Расхождения между Chartboost и AppsFlyer

Иногда возможны расхождения между дэшбордом Chartboost и дэшбордом AppsFlyer.

Рекламодателям следует учитывать следующие причины:

| Причина | Chartboost | AppsFlyer: |
| --- | --- | --- |
| **Окно атрибуции** | Окно атрибуции Chartboost — 21 день | Окно атрибуции AppsFlyer — 7 дней<br /><br />**\*\* Это основная причина расхождений между AppsFlyer и Chartboost** |
| **Многоканальная атрибуция источников** | Атрибуция Chartboost функционирует, как указано выше, независимо от других источников. | AppsFlyer использует атрибуцию по последнему клику (подробные сведения об атрибуции AppsFlyer см. <Anchor target="_blank" href="/marketers/ru/docs/appsflyer-attribution-model">здесь</Anchor>) |

<div id="note-1" />

> 📘 **Примечание:**
>
> Хотя в Chartboost все установки ретаргетинговой кампании отображаются в одном месте, на дэшборде AppsFlyer установки разделены между страницей Overview (новые установки) и страницей Retargeting (повторная атрибуция и повторные вовлечения).
