> **Краткий обзор:** AdColony — это премиум рекламная сеть видеорекламы и интегрированный партнер AppsFlyer по рекламным сетям. Она предоставляет рекламодателям и брендам вовлеченную и отзывчивую аудиторию, а также предлагает решения для монетизации паблишерам и разработчикам. Помимо мобильной атрибуции по кликам, AdColony также предлагает атрибуцию затрат, дохода от рекламы и атрибуцию по просмотрам, данные которой можно регистрировать с помощью AppsFlyer.

<div id="setting-up-adcolony" />

## Настройка AdColony

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Общие настройки

<div id="enable-view-through-attribution" />

#### Активация атрибуции по просмотрам

Включите этот параметр, если хотите атрибутировать установки по показам из AdColony. Слайдер окна ретроспективы атрибуции по просмотрам доступен на вкладке ***Ссылка атрибуции***.

<div id="default-postbacks" />

### Постбэки по умолчанию

Отправляйте автоматические постбэки в AdColony после установок и отклоненных установок. Используйте этот раздел, чтобы определить **источник пользователей** для постбэков.

Выберите ***Только этот партнер*** для установок, поступающих только от пользователей, атрибутированных AdColony.  
Выберите ***Все источники, включая organi*c**, чтобы вся ваша база пользователей была доступна для отчетов в AdColony.

Отклоненные установки можно отправлять для параметра **Только этот партнер**.

<div id="launch-postbacks" />

#### Постбэки запусков приложения

С 1 июля 2020 года мы больше не отправляем постбэки запусков в AdColony. Если ваша интеграция была настроена до этой даты, в конфигурациях могут быть изменения. В таблице ниже описаны возможные изменения и необходимые действия, если применимо:

| Ваша конфигурация | Будет обновлено до | Ваши дальнейшие действия |
| --- | --- | --- |
| Отправлять в AdColony **все запуски** (из всех медиаисточников, включая органические) | Отправлять в AdColony:<ul><li>**все установки** (из всех медиаисточников, включая органический трафик)</li><li>**все** `af_app_opened` **события** (из всех медиаисточников, включая органические)</li></ul> | Никаких дополнительных действий не требуется. Это обновление фактически не оказывает воздействия на конфигурацию. |
| Отправлять в AdColony **только первые запуски с атрибуцией** | Отправлять в AdColony **установки**, атрибутированные только AdColony | Если вы также хотите отправлять события `af_app_open`:<ul><li>В AppsFlyer на странице интеграции AdColony настройте отправку события в разделе ***In-app event postbacks***</li></ul> |
| Отправлять в AdColony **все запуски** (из всех медиаисточников, включая органические)<br /><br />**НО**<br /><br />За 3 месяца до 1 июля 2020 года ни одна конверсия не была атрибутирована AdColony | Отправлять **все установки**<br /><br />**И**<br /><br />В течение 30 дней после 1 июля 2020 года — **все запуски** | Если вы также хотите отправлять события `af_app_open`:<ul><li>В AppsFlyer на странице интеграции AdColony настройте отправку события в разделе ***In-app event postbacks***.</li></ul>Если сделать это в течение 30-дневного периода, мы прекратим отправлять все запуски и вместо этого начнем отправлять все события `af_app_open`.<br /><br />Если сделать это по истечении 30-дневного периода, мы прекратим отправлять запуски и не будем отправлять события `af_app_open`, пока не будет настроено иное. |

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе вы можете настроить постбэки событий в приложении, которые отправляются в AdColony.

**Чтобы настроить постбэки для внутренних событий приложения:**

1. Активируйте ***Постбэки о внутренних событиях***.
2. Кликните ***Добавить событие***, чтобы добавить событие SDK в список
3.
   | Имя параметра | Description(Описание) |
   | --- | --- |
   | **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, либо из межсерверных событий.  <br />**Совет**: Если в списке нет нужного вам события, активируйте его на устройстве с неорганической установкой, и повторите поиск. |
   | **Идентификатор события партнера** | Уникальное имя или идентификатор каждого события, определенные партнером. Выберите наиболее подходящее предопределенное событие для события SDK. |
   | **Вариант отправки** | Выберите вариант отправки события:  <br />**Только от этого партнера** — для событий, поступающих **только** от пользователей, атрибутированных AdColony.  <br />**Все источники, включая органические**, чтобы партнер получал сведения о событиях всех пользователей, которые есть в вашей базе. |
   | **Отправить данные о событии** | * **Нет значений и нет дохода:** отправляется только само событие без значения.<br />* **Значения, нет дохода:** отправляются все параметры, кроме значения дохода.<br />* **Значения и доход**: отправляются все параметры события, включая значение дохода (если оно есть в событии). |

4. Нажмите кнопку ***Сохранить***.

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке вы можете выбрать разрешения, которые хотите предоставить AdColony. Обратите внимание: даже если атрибуция для AdColony отключена, вкладка разрешений остается активной, и вы можете предоставить AdColony разрешение на управление.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

<div id="ad-network-permissions" />

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера о лояльных пользователях
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
