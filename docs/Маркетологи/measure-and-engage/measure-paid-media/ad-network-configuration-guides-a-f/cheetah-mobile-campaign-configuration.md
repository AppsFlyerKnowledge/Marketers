> **Кратко:** Cheetah Mobile — интегрированный партнер AppsFlyer ad network, который стремится предоставлять пользователям мобильных устройств по всему миру ведущие приложения и связывать пользователей с персонализированным контентом на мобильной платформе. Помимо мобильной атрибуции по кликам, Cheetah Mobile также предлагает атрибуцию по стоимости и атрибуцию по просмотрам, которые можно регистрировать с помощью AppsFlyer.

## Настройка Cheetah Mobile

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнеров

При **первом посещении** необходимо включить кнопку ***Активировать партнера***, чтобы настроить параметры вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

> 📘 **Примечание:**
>
> Как сеть, ориентированная на все установки, Cheetah Mobile предпочитает получать постбэки для всех новых установок вашего приложения из любого источника, включая органические. Рекомендуется выбрать **События, атрибутированные любому партнеру**, чтобы отправлять в Cheetah Mobile постбэки по всем установкам.

### Общие настройки

**Активация атрибуции по просмотрам**

Переведите этот переключатель в положение «Включено», если вы хотите атрибутировать установки по просмотрам от Cheetah Mobile. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

### Постбэки по умолчанию

Отправляйте автоматические постбэки в Cheetah Mobile после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят исключительно от пользователей, атрибутированных Cheetah Mobile.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять Cheetah Mobile отчеты о событиях всех пользователей, которые есть в вашей базе.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно настроить отправку в Cheetah Mobile постбэков о событиях AppsFlyer.

1. Включите переключатель «Постбэки по внутренним событиям приложения».
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в ваше приложение, или из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Cheetah Mobile.  <br />Получите соответствующий идентификатор ID события у Cheetah Mobile и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые нужно отправить в Cheetah Mobile для атрибуции кампаний, групп объявлений или отдельных объявлений Cheetah Mobile. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **кампания** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Cheetah Mobile.  
  **Параметр ссылки атрибуции:** c
* **Adset** - задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Cheetah Mobile.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** - задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Cheetah Mobile.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых site ID и использовать параметр sub site ID, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить ограничения по site ID</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание, что эти параметры анализируются и отображаются в Raw Data Report, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от клика до установки**. Только установки (первые запуски), которые происходят в рамках окна атрибуции, могут быть атрибутированы Cheetah Mobile.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в Cheetah Mobile, чтобы она активировалась, когда лиды кликают по соответствующему рекламному объявлению.

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. Только установки (первые запуски), которые происходят в рамках этого окна атрибуции после показа рекламы, атрибутируются Cheetah Mobile при условии, что не было другого релевантного клика по рекламе.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в Cheetah Mobile для активации при просмотре соответствующей рекламы, обычно в течение 1 секунды или более.

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке вы можете выбрать разрешения, которые предоставляете Cheetah Mobile, независимо от того, выступает ли партнер в качестве рекламной сети, агентства или и того, и другого. Обратите внимание, что даже если атрибуция отключена для Cheetah Mobile, вкладка разрешений остается активной, и вы можете предоставить Cheetah Mobile права управления.

### Ad Network Permissions (Разрешения для рекламной сети)

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по событиям в приложении)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

### Разрешения агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* ***Главный переключатель*** — установите в положение «Вкл.», чтобы отобразить параметры разрешений для агентства
* ***Разрешить настройку постбэков по событиям в приложении*** — разрешить агентству настраивать на вкладке интеграции маппинг постбэков по событиям в приложении на себя
* ***Разрешить доступ к агрегированным органическим данным***
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным агентства об удержании

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.

</Accordion>
