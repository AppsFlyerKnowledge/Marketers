> **Кратко:** Criteo — интегрированный партнер рекламной сети AppsFlyer, который стимулирует рост благодаря технологиям машинного обучения, данным и эффективности в масштабе, а также обеспечивает измеримый ROI для своих клиентов. Помимо мобильной атрибуции по нажатиям, Criteo также предлагает атрибуцию ретаргетинга, данные которой можно регистрировать с помощью AppsFlyer.

<div id="setting-up-criteo" />

## Настройка Criteo

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<div id="activate-partner" />

### Activate Partner (Активировать партнера)

При **первом посещении** вам нужно перевести кнопку ***Активация партнера*** в положение «Включено», чтобы стала доступна настройка параметров вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть ALL-Installs, Criteo предпочитает получать постбэки по всем новым установкам вашего приложения из ЛЮБОГО источника, включая органические. Рекомендуется выбрать **События, атрибутированные любому партнеру**, чтобы отправлять в Criteo постбэки по всем установкам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Criteo после установок приложения и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, которые поступают только от пользователей, атрибутированных Criteo.  
Выберите **События, атрибутированные любому партнеру или органические**, чтобы вся ваша база пользователей была доступна для отчетности Criteo.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с Criteo и настроить отправку постбэков.

1. Включите переключатель «Постбэки по внутренним событиям приложения».
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
   **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или ID каждого события, определенные на стороне Criteo.  <br />Получите соответствующий ID события в Criteo и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

<div id="warning" />

> ❗️ **Предупреждение**
>
> <Anchor target="_blank" href="/marketers/ru/docs/in-app-events-overview#what-are-complex-inapp-events-and-how-do-i-set-them-up">Комплексные события в приложении</Anchor> вызывают проблемы с постбэками в Criteo. Если необходимо, чтобы событие полностью сопоставлялось с Criteo, отправляйте отдельные события для каждого действия пользователя (например, отправляйте событие "Добавить в корзину" для каждого добавленного товара). Используйте сырые данные внутренних событий приложения, чтобы сгруппировать эти события.

</Accordion>

<div id="cost-tab" />

<Accordion title="Вкладка «Стоимость»">

AppsFlyer получает информацию о затратах через API. Подробную информацию <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">о поддерживаемых параметрах, метриках и функциях см. в</Anchor> таблице интеграции затрат рекламной сети.

**Примечание**:

* Для получения данных о затратах требуется подписка ROI360.
* Данные по стоимости от Criteo можно получить только для загрузок из Google Play или Apple App Store. Для Android данные по затратам для сторонних магазинов приложений Android не поддерживаются.
* Данные о расходах агентства доступны только по <Anchor target="_blank" href="/marketers/ru/docs/view-aggregated-cost-data-for-attribution-links">клику</Anchor>, но не через интеграцию API.

**Чтобы активировать API стоимости**:

* Следуйте соответствующему методу в <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-ad-revenue-attribution#внедрение">руководстве по интеграции выручки от рекламы.</Anchor>

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API данных о затратах</Anchor> и время, когда AppsFlyer получил соответствующие данные о затратах в последний раз, либо на дэшборде статуса интеграции затрат (и доходов от рекламы), либо на дэшборде отдельной рекламной сети.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для Criteo в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание: даже если атрибуция для Criteo отключена, вкладка разрешений остается активной, и вы можете предоставить Criteo контроль.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

Полномочия для рекламной сети

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate loyal user data*** (Разрешить доступ к своим сводным данным о лояльных пользователях) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate in-app events data*** (Разрешить доступ к своим сводным данным о внутренних событиях приложения) — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
