> **Кратко:** Appnext, интегрированный партнер AppsFlyer (рекламная сеть), использует технологии и решения на основе данных для премиум-монетизации мобильных приложений, маркетинга приложений и повторного вовлечения. Помимо мобильной атрибуции по кликам Appnext также предлагает атрибуцию по стоимости, ретаргетингу и просмотрам, которую вы можете регистрировать с помощью AppsFlyer.

<div id="setting-up-appnext" />

## Настройка Appnext

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнера

При **первом посещении** вам нужно будет включить переключатель. Нажмите кнопку **Активировать партнера**, чтобы включить настройку параметров на вкладке интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Appnext после установок и повторного вовлечения пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Примечание: для установок можно выбрать либо **Only events attributed to this partner** (для событий только от пользователей, атрибутированных Appnext), либо **Events attributed to any partner or organic** (для событий от всех партнеров и из органики). Для отклоненных установок и повторных вовлечений, **только события, атрибутированные этому партнеру** могут быть отправлены через постбэк.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть ALL-Installs, Appnext предпочитает получать постбэки по всем новым установкам вашего приложения из любого источника, включая органический. Рекомендуется выбрать **Events attributed to any partner**, чтобы отправлять в Appnext все постбэки по установкам.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с Appnext посредством постбэков.

1. Включите переключатель «Постбэки по внутренним событиям приложения».
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Appnext.  <br />Получите соответствующий идентификатор события в Appnext и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

### Ad Network Permissions (Разрешения для рекламной сети)

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* **Разрешение настраивать интеграцию**: разрешить партнеру управлять настройками на вкладке интеграции (за исключением постбэков по внутренним событиям приложений).
* **Разрешение настраивать постбэки по событиям внутри приложения**: разрешить партнеру сопоставлять себе постбэки по внутренним событиям приложений на вкладке интеграции.
* **Предоставление доступа к отчету об удержании пользователей**: партнер получает доступ только к собственным данным об удержании пользователей.
* **Allow access to your aggregate loyal user data** (Разрешить доступ к агрегированным данным о лояльных пользователях): партнер получает доступ только к собственным данным о лояльных пользователях.
* **Разрешить доступ к вашим сводным данным о событиях в приложении** - только к собственным данным партнера о событиях в приложении
* **Предоставление доступа к агрегированным данным о доходе**: партнер получает доступ к данным только по атрибутированным ему доходам.
* **Разрешить доступ к дэшборду Protect360**: партнер получает доступ только к собственным данным Protect360, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

<div id="agency-permissions" />

### Разрешения агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* **Главный переключатель** - установите в положение «Включено», чтобы получить доступ к списку разрешений для агентства
* **Разрешить доступ к отчету об удержании** — доступ предоставляется только к собственным данным агентства
* **Разрешить доступ к агрегированным органическим данным**
* **Разрешить настройку постбэков по внутренним событиям приложений**: разрешить агентству сопоставлять себе постбэки по внутренним событиям приложений на вкладке интеграции.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.
