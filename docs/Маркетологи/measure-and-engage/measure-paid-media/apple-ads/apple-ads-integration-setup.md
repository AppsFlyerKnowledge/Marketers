> **At a glance:** Apple Ads — партнер AppsFlyer, сеть с самостоятельной атрибуцией (SRN, Self-Reporting Network), которая помогает пользователям находить ваше приложение в магазине приложений с помощью ключевых слов.

<Image align="center" alt="medium_originaljpeg_apple_ads_logo_blk_highres_720 (1) (1).jpg" src="https://files.readme.io/f89d1a5ec1a1de2ec2dfdec7465465fc2be73e0cf41ddd6be8b2e3f62de3c9e8-47598828154001.jpg" width="719px" />

От релевантности приложения зависит, будет ли ваша реклама показываться по поисковому запросу в App Store. Отклик пользователя на рекламу — показатель ее релевантности. По откликам пользователей Apple Ads определяет, какие рекламные объявления показывать чаще.

> 📘 **Note**
>
> * AppsFlyer поддерживает мобильную атрибуцию Apple Ads на основе кликов, ретаргетинг пользователей и данные о стоимости через API (с подпиской ROI360).
> * Начиная с 27 марта 2025 года, AppsFlyer также будет поддерживать мобильную атрибуцию на основе показов для Apple Search Ads.
> * Начиная с 1 сентября 2026 года Apple Ads добавляет точную временную метку ко всем заявлениям об атрибуции iOS.

## Настройте интеграцию Apple Ads

<Accordion title="Начало">

**Необходимое условие**

* Принята самая последняя версия SDK AppsFlyer для iOS

**Настройка Apple Search Ads в AppsFlyer:**

Настройка выполняется со страницы **Активные интеграции**, но для поиска новых партнеров необходимо сначала перейти в <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations">маркетплейс партнеров</Anchor>. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе.

> 📘 **Note**
>
> Перед настройкой интеграции обязательно свяжитесь с партнером и откройте у него аккаунт.

</Accordion>

<Accordion title="Вкладка «Затраты»">

Интеграция затрат предоставляет следующие агрегированные данные:

* Данные по затратам для кампаний, групп объявлений, гео/стран и ключевых слов. Подробную информацию о поддерживаемых параметрах, метриках и функциях см. в таблице <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">интеграции затрат рекламной сети</Anchor>.  
  **Примечание:** Для получения данных о затратах требуется подписка на ROI360.
* Данные о кликах, показах и расширенные данные—ключевые слова, названия кампаний и группы объявлений.

> 📘 **Note**
>
> * Поддерживается использование нескольких аккаунтов Apple Ads. Иными словами, если вы запускаете кампании для одного и того же приложения, используя разные аккаунты Apple Ads, AppsFlyer может получать эти данные из всех аккаунтов.
> * Данные о затратах для «групп кампаний» не поддерживаются в API отчетов Apple Ads, поэтому данные о «группах кампаний» недоступны в AppsFlyer.
> * Чтобы войти с помощью Apple, вам необходимы разрешения **Campaign Group Manage** в Apple Ads (Account Read Only или Account Read and Write).
> * При входе с помощью Apple авторизация групп кампаний Apple Ads не суммируется. Это означает, что при интеграции нового приложения авторизация групп кампаний, выбранная для предыдущих приложений, аннулируется, если не выбрана заново.
> * При входе в систему Apple вы не можете использовать федеративный вход.

**Чтобы включить данные о затратах, кликах, показах и обогащенные данные:**

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#enable-cost-api">этим инструкциям по интеграции</Anchor>.

<Accordion title="Настройка маркетингового партнера">

**Порядок настройки маркетингового партнера:**

1. При необходимости активируйте **интеграцию с Apple Search Ads:**
   1. В AppsFlyer перейдите в раздел **Настройки**> **Активные интегрированные партнеры** > **Apple Ads**.
   2. Установите переключатель **Активировать партнера** в положение «Включено».
   3. Нажмите **Сохранить.**
2. **На дэшборде Apple Search Ads**:![](https://files.readme.io/722ab215c9a096628b42caefc6838dfe790d726524839c588d9e01c061620711-21589950935057.png) получите идентификатор группы кампаний в Apple Search Ads, связанный с данным маркетинговым партнером. Чтобы найти идентификатор, следуйте указаниям на скриншоте ниже.

   <Image align="center" alt="ASACGroupID.png" src="https://files.readme.io/722ab215c9a096628b42caefc6838dfe790d726524839c588d9e01c061620711-21589950935057.png" />
3. **В AppsFlyer настройте маркетингового партнера Apple Ads:**
   1. В AppsFlyer в боковом меню выберите **Сотрудничество**> **Активные интеграции**.
   2. Запустите поиск *маркетингового партнера*** Apple Search Ads**.  
      На экране появится список маркетинговых партнеров.
   3. Выберите маркетингового партнера.
   4. Установите переключатель **Активировать партнера** в положение «Включено».
   5. Укажите **идентификатор группы рекламных кампаний Apple Search Ads** этого партнера, полученный на предыдущем шаге. Введите только цифры.
   6. Нажмите **Сохранить**.
4. [Необязательно] Настройте постбэки по внутренним событиям приложений:
   1. Активируйте **постбэки внутренних событий приложений**.
   2. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
   3. Введите следующие параметры:
      1. **Название события в SDK**: название события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события. **Совет:** если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск.
      2. **Отправка данных о доходе**. Выберите один из следующих вариантов: без значений и без дохода; значения без дохода; значения и доход.
5. Нажмите **Save integration** (Сохранить интеграцию).

<Accordion title="Настройка агентства">

Рекламодатели могут разрешить агентствам запускать кампании от своего имени с помощью Apple Search Ads. И рекламодатели, и агентства выполняют действия по настройке в AppsFlyer, описанные в данном разделе.

**Необходимые условия**

Перед настройкой агентства в AppsFlyer агентство и рекламодатель должны выполнить следующие шаги на платформе Apple Ads:

* **Агентство:**
  1. Создайте отдельные группы кампаний в учетной записи агентства.
  2. Пригласите рекламодателя в качестве менеджера группы кампаний или через роль «Связать учетные записи», чтобы подключить их учетную запись App Store Connect.
* **Рекламодатель:** После получения приглашения на связывание учетных записей, рекламодатель должен связать группы кампаний со своей учетной записью App Store Connect.

Смотрите документацию Apple Ads о том, <Anchor target="_blank" href="https://searchads.apple.com/help/get-started/0012-link-app-store-connect-accounts">как связать учетную запись App Store Connect клиента с учетной записью агентства.</Anchor>

**Группа рекламных кампаний Apple Search Ads**

* Кампании агентства и кампании рекламодателя должны иметь разные идентификаторы групп кампаний в Apple Search Ads.
* В названии группы нельзя использовать специальные символы и пробелы.
* При входе через Apple авторизация групп кампаний Apple Ads не является накопительной. Это означает, что при интеграции нового приложения авторизация групп кампаний, выбранная для предыдущих приложений, аннулируется, если не выбрана заново. Вам необходимо выбрать **ограниченный доступ** и каждую из соответствующих групп кампаний (относящихся к приложениям, которые вы хотите подключить для рекламодателя).

<div id="advertiser-actions" />

#### **Действия рекламодателя**

**Необходимые условия**:

<Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">Предоставить доступ агентству</Anchor>.

**Порядок активации атрибуции Apple Search Ads для рекламодателя:**

1. В AppsFlyer в боковом меню выберите **Сотрудничество**> **Активные интеграции**.
2. Выбрать **Apple Search Ads.**
3. Перейти на вкладку **Integration** (Интеграция) и установить флажок **Activate partner** (Активировать партнера).
4. [Необязательно] Чтобы атрибутировать пользователей, которые повторно устанавливают приложение во время окна повторной атрибуции, включите **Reinstall attribution** (Атрибуция повторных установок).
5. Нажмите **Сохранить.**

<div id="agency-actions" />

### Данные о затратах, кликах и показах

Если активирован API данных о затратах, AppsFlyer получает данные о затратах, кликах и показах из Apple Ads через API. Подробную информацию о поддерживаемых параметрах, метриках и функциях см. в таблице <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">интеграции затрат рекламной сети</Anchor>. **Примечание**: Для получения данных о затратах требуется подписка на ROI360. Без ROI360 поступают только данные о кликах и показах.

**Чтобы включить API данных о затратах**:

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#enable-cost-api">этим инструкциям по интеграции</Anchor>. При появлении запроса на вход в свой аккаунт Apple Search Ads в разделе **Select permissions (Выбор разрешений)** выберите один из следующих вариантов:
  * **Account Read and Write (Аккаунт для чтения и записи)**
  * **Только чтение учетной записи**  
     **Примечание**: если вы выбрали ограниченный доступ и определенную группу кампаний, могут возникнуть ошибки предоставления данных.

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API данных о затратах</Anchor> и время, когда AppsFlyer получил соответствующие данные о затратах в последний раз, либо на дэшборде статуса интеграции затрат (и доходов от рекламы), либо на дэшборде отдельной рекламной сети.

> 📘 **Note**
>
> Данные о затратах Apple Ads недоступны в дэшборде SKAdNetwork (SKAN) или в SKAN Pull API, потому что постбэки SKAN не содержат данных на уровне кампании. Тем не менее, данные о стоимости доступны в отчётах SSOT, которые объединяют данные о установках SKAN с информацией о затратах, полученные через нашу классическую интеграцию с Apple Search Ads.

## Дополнительные сведения

<Accordion title="Атрибуция Apple Ads">

Apple Ads работает независимо от SKAdNetwork и детерминированно атрибутирует пользователей независимо от согласия на ATT (App Tracking Transparency). Это означает, что для пользователей, атрибутированных к Apple Ads, вам доступен полный набор функций и измерений, предоставляемых нашей <Anchor target="_blank" href="/marketers/ru/docs/appsflyer-attribution-model">моделью атрибуции LTV.</Anchor>

Атрибуция Apple Ads не полагается на IDFA, атрибуция выполняется с помощью токена устройства (детерминированная атрибуция).

<div id="after-september-1-2026" />

#### После 1 сентября 2026 г

Время клика и показа доступно независимо от статуса ATT. Окно атрибуции задает рекламодатель, а AppsFlyer применяет к взаимодействию свои правила атрибуции по последнему касанию.

<div id="before-september-1-2026" />

#### До 1 сентября 2026 г

Доступность времени клика и показа, а также окно атрибуции различаются в зависимости от согласия на ATT:

| **Согласие ATT** | **Время клика/показа доступно** | **Окно атрибуции по кликам/показам** | **Примечания** |
| --- | --- | --- | --- |
| Да | Да | Устанавливается рекламодателем | Используются правила атрибуции AppsFlyer по последнему касанию |
| Ни один | Нет | Клики: 30 дней (задается в Apple Ads), Показы: 24 ч | Время клика или впечатления не указано. Приоритет отдается детерминированным кандидатам. |

</Accordion>

<Accordion title="Расхождения">

AppsFlyer и Apple Search Ads используют разную логику атрибуции, что приводит к расхождениям между этими платформами. <Anchor target="_blank" href="/marketers/ru/docs/self-reporting-networks-srns#атрибуция">Apple Search Ads</Anchor>, сеть с самостоятельной атрибуцией (SRN), передает данные о новых установках через API.

**Передача данных из Apple Search Ads в AppsFlyer через API**

* Кампании агрегируются по региону.
* Следующее не фиксируется в отчете: показы, клики и затраты по регионам, где менее 100 показов в рамках данной кампании.
* При группировке по региону в AppsFlyer, регионы с недоступными данными не отображаются, а общее количество недоступных данных отображается в разделе N/A.

| <span id="target-redownloaders"></span>Нацеливайтесь на повторное скачивание | Вероятнее всего ваши бывшие пользователи — это лучшая аудитория для таргетинга с помощью Apple Ads.<br /><br />Пользователь, который удалил ваше приложение и в результате вашей ретаргетинговой кампании Apple Ads повторно его установил, называется в Apple Ads Re-Downloader. <Accordion title="Влияние Агрегированной расширенной конфиденциальности (Aggregated Advanced Privacy)">

Начиная с iOS 14 [ATTrackingManager](https://developer.apple.com/documentation/apptrackingtransparency/attrackingmanager/authorizationstatus/) (ATT) управляет доступностью IDFA, а Apple Ads контролирует данные атрибуции на уровне пользователя по установкам, принесенным Apple Ads. Таким образом, доступность данных на уровне пользователя по установкам, принесенным Apple Ads, не зависит от режима <Anchor target="_blank" href="/marketers/ru/docs/apply-aggregated-advanced-privacy-framework">Aggregated Advanced Privacy</Anchor>.

| --- | --- | --- | --- | --- | --- |
