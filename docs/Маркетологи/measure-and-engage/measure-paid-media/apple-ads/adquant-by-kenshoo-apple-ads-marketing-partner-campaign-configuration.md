> **Кратко:** Оптимизируйте кампании Apple Ads с помощью Adquant by Kenshoo. После настройки AppsFlyer отправляет постбэки в Adquant.

## Включение отправки постбэков в Adquant (маркетинговый партнер Apple Ads)

И рекламодатели, и агентства могут включить атрибуцию для Apple Ads.

> 📘 **Примечание:**
>
> Если рекламодатель или агентство отключает атрибуцию для Apple Ads, атрибуция для этого приложения, включая отправку постбэков маркетинговым партнерам Apple Ads, прекращается.

* **Рекламодатели:** следуйте приведенным ниже инструкциям, чтобы включить атрибуцию для Apple Ads.
* **Агентства:** <Anchor target="_blank" href="/marketers/ru/docs/apple-ads-integration-setup#agency-setup">следуйте этим инструкциям</Anchor>, чтобы включить атрибуцию для Apple Ads.

### Настройка Adquant by Kenshoo

**Чтобы настроить Adquant:**

1. При необходимости активируйте **интеграцию с Apple Search Ads:**
   1. В AppsFlyer в боковом меню выберите **Сотрудничество** > **Маркетплейс партнёров**.
   2. Найдите и выберите партнера. Вы перенаправлены на страницу конфигурации партнера.
   3. На вкладке **Интеграция** включите **Активировать партнёра**.
   4. Нажмите кнопку **Save Integration** (Сохранить интеграцию).
2. **На дэшборде Apple Ads**: получите идентификатор группы кампаний Apple Ads, связанный с Adquant. Чтобы найти идентификатор, следуйте указаниям на скриншоте ниже.

   ![ASACGroupID.png](https://files.readme.io/722ab215c9a096628b42caefc6838dfe790d726524839c588d9e01c061620711-21589950935057.png)
3. **В AppsFlyer настройте Adquant:**
   1. В AppsFlyer в боковом меню выберите **Сотрудничество** > **Интеграции партнеров**.
   2. Найдите Adquant by Kenshoo среди маркетинговых партнеров Apple Ads.  
      Отображается список маркетинговых партнеров.
   3. Выберите маркетингового партнера Apple Ads Adquant by Kenshoo.
   4. Установите переключатель **Активировать партнера** в положение «Включено».
   5. Введите **идентификатор кампании Apple Ads** Adquant, полученный на предыдущем шаге. Введите только цифры.
   6. В поле **action\_identifier** введите домен, используемый для отправки постбэков.
   7. [Необязательно] **Запретить передачу геолокации пользователя:** Чтобы прекратить передачу геолокации пользователя, в поле **Disable\_Country\_Sending** введите `1`.
   8. Нажмите **Save** (Сохранить).

### Постбэки по умолчанию

Эти постбэки начинают отправляться автоматически после активации партнера.

### Настройка постбэка по событиям в приложении

**Чтобы настроить постбэки по событиям внутри приложения:**

1. Введите acion\_identifier.
2. Включите **постбэк событий в приложении**.
3. Нажмите **Add Event**, чтобы добавить в список событие SDK или событие server-to-server к списку.
4. Введите следующие параметры:

   

| Название параметра | Description(Описание) |
| --- | --- |
| <span id="appsflyer-event"></span>**AppsFlyer event (Событие AppsFlyer)** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.**Совет**: Не нашли нужное вам событие?<ul><li>Убедитесь, что событие активировано на устройстве с неорганической установкой, и повторите поиск.</li><li>Введите его в поле **Событие AppsFlyer** и нажмите **Добавить другое**. Подробнее о <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#пользовательские-события">сопоставлении пользовательских событий</Anchor> читайте здесь.</li></ul> |
| <span id="mapped-to-partner-event"></span>**сопоставлено с партнерским событием** | Уникальное имя или идентификатор каждого события, определённого на стороне партнёра. <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#методы-сопоставления">Возможны следующие настройки сопоставления</Anchor>:<ul><li>**Текстовое поле**. Введите в него соответствующий идентификатор события, полученный от партнера.</li><li>**Раскрывающийся список:** Выберите наиболее подходящее предопределенное событие партнера.</li><li>**Как есть**: Отправляйте события в исходном виде, без сопоставления имени события.</li></ul> |
| <span id="for-users-from"></span>**для пользователей от** | Выберите вариант отправки для события:<ul><li>**Только этот партнёр**: постбэки отправляются только в том случае, когда событие атрибутируется этому партнеру, то есть когда пользователь, выполнивший событие, пришел от этого партнера.</li><li>**Все медиа-источники и органический трафик**: постбэки отправляются для событий, атрибутированных любому партнеру, а также для органических событий, то есть когда пользователь, выполнивший событие, пришел из любого медиа-источника.</li></ul> |
| <span id="including"></span>**Включая** | Выберите, <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#данные-для-включения-в-постбэки">какие данные о событиях</Anchor> следует передать партнеру в постбэке:<ul><li>**Нет значений и дохода** отправляется само событие без каких-либо параметров (значений или доходов).</li><li>**Значение без дохода**: отправляются все параметры, **кроме** значения дохода.</li><li>**Значение и доход**: Отправляются все параметры события, **включая** значение дохода (если оно есть в событии).</li></ul> |

5. Нажмите **Сохранить интеграцию**.
