> **Краткий обзор.** Настройте запись для разных аккаунтов Google Рекламы, чтобы правильно атрибутировать трафик.

## Введение

Трафик Google Рекламы часто поступает из разных аккаунтов, например, из агентств, специализирующихся на Google Рекламе, или даже из разных локальных команд в организации владельца приложения. Важно понимать, как настраивать записи для разных аккаунтов Google Рекламы, чтобы атрибутировать трафик к правильным сторонам.

В этой статье мы рассмотрим все эти случаи, от измерения агентств до использования управляющих аккаунтов (MCC).

> 📘 **Примечание**
>
> Нижеследующее относится **только** к клиентам, использующим новый API Google Рекламы.

Подробную информацию о настройке аккаунта агента в Google Рекламе можно найти <Anchor target="_blank" href="/marketers/ru/docs/google-ads-adwords-integration-setup-for-agencies">здесь.</Anchor>

## Важные определения

* **Link ID (идентификатор ссылки)** — **уникальный идентификатор мобильного приложения, определенный в Google Рекламе**.

> 📘 **Примечание:**
>
> Для версий одного и того же приложения для Android и iOS требуются разные идентификаторы ссылок.

* **Customer ID (Идентификатор клиента)** — **уникальный идентификатор аккаунта Google Рекламы**.  
  Каждый аккаунт может рекламировать несколько идентификаторов ссылок, например, для всех приложений этой компании. При связывании аккаунтов агентств с существующими приложениями на дэшборде AppsFlyer вы можете определить до 10 идентификаторов клиентов.
* **MCC** — управляющий аккаунт в Google Рекламе (MCC, ранее назывался «My Clients Center») — это **инструмент** Google Рекламы **для работы с несколькими аккаунтами Google Рекламы**.  
  С помощью аккаунта MCC вы можете связать несколько аккаунтов, чтобы просматривать их в одном месте (<Anchor target="_blank" href="https://support.google.com/google-ads/answer/6139186?hl=en&ref_topic=7554904">СМ. подробнее</Anchor>).

## Настройка записи Google Рекламы

AppsFlyer может регистрировать один идентификатор ссылки для каждого приложения. **Если несколько аккаунтов работают с одним и тем же приложением, все они должны использовать один и тот же идентификатор ссылки.** Это должно быть настроено на дэшборде AppsFlyer для целей атрибуции.

### Предоставление идентификатора ссылки Google другим аккаунтам

Владельцы приложений, имеющие один аккаунт Google Рекламы, или те, кто планирует работать с агентствами, управляющими трафиком Google Рекламы, должны использовать следующий метод.

Владелец приложения может поделиться любым идентификатором ссылки с любым другим аккаунтом, идентифицируемым по идентификатору клиента, как показано на рисунке ниже. Вот некоторые дополнительные сведения о <Anchor target="_blank" href="/marketers/ru/docs/google-ads-adwords-integration-setup-for-agencies#настройка-атрибуции-google-ads-для-агентств">передаче идентификатора ссылки агентству</Anchor>.

> 🚧 **Важно!**
>
> * Если MCC является менеджером записи для субаккаунтов, то нет необходимости передавать Link ID от MCC к субаккаунтам. Однако если субаккаунт под управлением MCC является менеджером записи сам для себя, то MCC должен предоставить Link ID менеджеру записи субаккаунта.
> * Импорт конверсий: Если MCC является менеджером записи, то MCC отвечает за импорт конверсий для управляемых им субаккаунтов. Однако если субаккаунт в MCC является менеджером записи сам для себя, то этот субаккаунт также должен импортировать конверсии.

> 📘 **Примечание:**
>
> * На панели Google Рекламы нажмите меню (3 точки) >>. ***Связанные аккаунты*** >> ***Данные аналитики сторонних приложений*** [![](https://support.appsflyer.com/hc/article_attachments/49929447608849)](https://support.appsflyer.com/hc/article_attachments/49929447608849)
> * Другой аккаунт должен одобрить предоставление данных.
> * В результате другой аккаунт получает право запускать рекламные кампании Google Рекламы для приложения.

> 👍 **Совет**
>
> AppsFlyer рекомендует передавать идентификатор ссылки из основного аккаунта рекламодателя в другие аккаунты, а не генерировать идентификаторы ссылок в этих аккаунтах напрямую. Это самый быстрый вариант, к тому же он позволяет легко расстаться рекламодателю и агентству после завершения совместной работы.

## MCC

Агентства или крупные рекламодатели, управляющие несколькими аккаунтами Google Рекламы часто используют MCC (My Client Center), который позволяет просматривать все их аккаунты в одном месте.

Во время настройки MCC можно настроить, кто будет управлять конверсиями — управляющий аккаунт или субаккаунты.

## MCC для MCC

[![](https://support.appsflyer.com/hc/article_attachments/49929447611793)](https://support.appsflyer.com/hc/article_attachments/49929447611793)

Крупные рекламодатели, работающие с несколькими агентствами, могут использовать аккаунт MCC для других MCC. Аналогично стандартному аккаунту MCC. Рекомендуется, чтобы идентификатор ссылки генерировал MCC самого высокого уровня или рекламодатель. Правильная настройка этой структуры требует, чтобы субаккаунты выбрали правильный уровень MCC (скорее всего, самый высокий уровень MCC) в качестве менеджера записи. Если используется именно такая настройка, то идентификатор ссылки не нужно передавать субаккаунтам, и достаточно импортировать конверсии на самом высоком уровне.

## Открытие кампании Google Рекламы

MCC не может напрямую открыть кампанию Google Рекламы. Это нужно сделать через стандартный субаккаунт Google Рекламы.

Существует два варианта записи конверсий:

1. **MCC управляет записью субаккаунтов**  
   Обычно используется, когда в одной компании есть разные команды, например, **аккаунт Google Рекламы для каждого географического региона в одной компании**.  
   MCC хранит конфигурацию записи (менеджер записи) для всех своих субаккаунтов. Любые изменения в конфигурации записи производятся только на уровне MCC, а все субаккаунты наследуют ее автоматически.  
   MCC также необходимо импортировать конверсии, что делается один раз и охватывает все субаккаунты, а также получить идентификаторы ссылок, предоставленные для субаккаунтов.
2. **Субаккаунты управляют собственными записями**  
   Обычно используется для аккаунтов, которые не связаны между собой, за исключением того, что их обслуживает одна организация, например, **одно агентство обслуживает разные аккаунты клиентов-рекламодателей**.  
   Импорт конверсий в этом случае необходимо выполнять для каждого субаккаунта отдельно. AppsFlyer регистрирует один идентификатор ссылки для каждого приложения, поэтому для записи мобильных данных MCC или рекламодатель должен поделиться идентификатором ссылки с субаккаунтами.

Конверсии в Google Рекламе можно импортировать ТОЛЬКО после того, как произойдет первая конверсия, будь то установка или событие в приложении.
