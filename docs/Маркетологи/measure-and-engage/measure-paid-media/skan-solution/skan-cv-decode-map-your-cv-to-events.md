> **Краткий обзор.** AppsFlyer декодирует и преобразует заданное вами значение конверсии в события. События используются для заполнения дэшборда SKAN, сырых данных и постбэков партнерам.

![SKAdNetwork_-_Custom__1_.png](https://files.readme.io/74f0d3836ee6a73f6746afa2d6d6a468c09cba696561c5a2075149ca360b78bf-34255690318097.png)

## Декодирование значения конверсии SKAN

Рекламодатели используют декодирование значения конверсии в качестве альтернативы опциям, доступным в <Anchor target="_blank" href="/marketers/ru/docs/skan-conversion-studio">Conversion Studio</Anchor>. Если вы используете декодирование, это означает, что вы несете ответственность за настройку <Anchor target="_blank" href="https://developer.apple.com/documentation/storekit/skadnetwork/4097267-updatepostbackconversionvalue">updatePostbackConversionValue</Anchor> в соответствии с логикой вашего приложения.

За исключением настройки значения конверсии (CV) в приложении, остальная часть процесса, функции и параметры отчетности такие же, как описаны в <Anchor target="_blank" href="/marketers/ru/docs/skadnetwork-skan-solution-guide">руководстве по решению SKAN</Anchor>. Это означает, что по истечении окна активности (установленного вами) iOS отправляет постбэк в рекламную сеть, которая пересылает его в AppsFlyer. AppsFlyer декодирует CV в соответствии с вашим сопоставлением в события, обрабатываемые так же, как декодированные CV, установленные SDK.

## Настраиваемое значение конверсии — декодирование

Для реализации настраиваемого декодирования CV необходимо загрузить CSV-файл, содержащий сопоставление вашего CV, на платформу AppsFlyer.

**Принципы сопоставления для декодирования**

* Предоставьте сопоставление декодирования для точных значений конверсии (1–63) и приблизительных (низкое, среднее и высокое) для окон 1–3. Не обязательно сопоставлять весь диапазон значений. Например, вы можете сопоставить значения 1, 2, 10 и 43.
* Значение 0 всегда сопоставлено с установкой. Вы не можете это изменить.
* Таблица сопоставления загружается в AppsFlyer в виде CSV-файла. При необходимости вы можете загрузить обновленную таблицу сопоставления.
* После получения постбэка от iOS CV декодируется в события, как показано в примерах.
* Дата установки определяется по времени прибытия постбэка.
* События имеют то же время, что и время установки.
* Чтобы лучше понять, как подготовить схему, ознакомьтесь со сценариями сопоставления, приведенными ниже.
* <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#пользовательские-события">Разрешены пользовательские названия событий в приложении</Anchor>.
  * Это означает, что вы отправляете новые имена событий, даже если они никогда не отправлялись из SDK.
  * Вы можете сопоставить внутренние события приложения с внутренними событиями рекламной сети.
  * Это также справедливо для интеграции Meta ads, при условии соблюдения специфических для Meta правил, подробно описанных в следующем разделе.

#### **Правила, специфичные для Meta**

При интеграции с Meta ads придерживайтесь следующих правил:

* Минимальные и максимальные значения дохода для заданного значения конверсии должны быть разными. Они не могут быть равны.
* Значения не должны перекрываться и должны располагаться в последовательном порядке, как показано для conversion\_value 1-2 и 62 в следующей таблице.
* Счетчик событий event\_counter: Meta ads не учитывают это значение. [Рекомендация] Заполните его значением 1.

<Accordion title="Поддержка Единого источника истины SSOT для режима Decode">

#### Информация о компании

Клиенты, использующие режим Decode, теперь могут получить доступ к атрибуции по модели Единого источника истины (SSOT), что дает преимущества дедупликации, ранее доступные только пользователям режима Encode. Это повышает точность измерения неорганической эффективности без необходимости внедрять режим Encode.

#### Ключевые преимущества

* Получайте через API индикатор в реальном времени о том, атрибутирована ли установка (неорганическая) или нет (органическая) в AppsFlyer.
* Учитывайте сигнал атрибуции Единого источника истины SSOT при обновлении значений конверсии.
* Используйте совместимые с SSOT схемы Decode, загружая обновленные файлы схемы со специальным флагом SSOT.
* Получите доступ к дэшбордам Единого источника истины SSOT и отчетам DataLocker.
* Выполняйте дедупликацию неорганических установок во всех сетях.
* Обеспечьте более точную атрибуцию и отчетность.
* Сократите сложность разработки и контроля качества.

#### Как включить SSOT для режима декодирования

1. **Извлеките идентификатор AppsFlyer —** <Anchor target="_blank" href="/marketers/ru/docs/server-to-server-events-api-for-mobile-s2s-mobile#fetching-the-appsflyer-id">получите идентификатор AppsFlyer из SDK во время установки</Anchor>.
2. **Вызовите SSOT API -** используйте идентификатор AppsFlyer и идентификатор приложения, чтобы проверить, была ли установка атрибутирована AppsFlyer.
   * API возвращает:  
     `"is-non-organic-install": true/false`
3. **Примените сигнал атрибуции —** используйте этот сигнал, чтобы скорректировать логику CV. Например, отразите атрибуцию, добавив событие `af_attribution_flag` в соответствующие записи CV.
4. **Загрузите обновленный файл схемы —** [используйте существующую схему декодирования](/docs/skan-cv-decode-map-your-cv-to-events#decode-mapping-scenario-rules). Для CV, затронутых атрибуцией SSOT, добавьте событие `af_attribution_flag`, чтобы указать дедупликацию.
5. **Доступ к отчетам**  
   Дэшборды SSOT и файлы DataLocker теперь включают данные режима декодирования.

#### Часто задаваемые вопросы

**В: Когда следует вызывать API, чтобы получить флаг атрибуции SSOT?**  
**О:**

* Вызывайте API сразу после установки.
* Повторяйте запрос каждые 10 секунд (до 5 раз), чтобы учесть задержку атрибуции.
* Либо выполните запрос один раз не менее чем через 25 секунд после установки, чтобы обеспечить точность.

</Accordion>

<div id="upload-conversion-value-schema-file" />

<Accordion title="Загрузить файл со схемой значений конверсии">

**Прежде чем начать**:

* Подготовьте CSV-файл со схемой значений конверсии.
* Если вы интегрируетесь с Meta ads и измеряете доход, убедитесь, что ваша схема соответствует [правилам для Meta.](/docs/skan-cv-decode-map-your-cv-to-events#правила-специфичные-для-meta) Если этого не сделать, Meta ads не сможет интерпретировать схему.

**Чтобы включить измерение SKAN с помощью декодирования:**

1. В AppsFlyer перейдите в раздел **Настройки**  > **SKAN Conversion Studio**.
2. Нажмите значок других действий (⋮), выберите **Загрузить файл сопоставления декодирования**.
3. Если вы еще не перешли на SKAN 4, выберите загрузку файла для SKAN 4 или предыдущей версии SKAN. После обновления до SKAN 4 выбор других версий будет недоступен.
4. Выполните одно из следующих действий:
   * **Нажмите «Перетащить файл».**
   * **Загрузите обновленный файл сопоставления.**
5. Следуйте инструкциям в пользовательском интерфейсе, чтобы загрузить файл.
6. Включите **Измерение SKAN**.
7. Нажмите **Сохранить изменения**.   
   Примечание. В течение следующих 48–72 часов данные на дэшборде будут неоднозначными. Это означает, что из-за проблем с таймером iOS мы не можем быть уверены, соответствует ли сопоставление декодирования сопоставлению кодирования, которое вы используете.
8. Убедитесь, что вы сопоставили события в приложении с событиями партнеров, чтобы они могли правильно использовать постбэки.

</Accordion>

## Устранение неполадок при загрузке CSV-файла

<div id="upload-error-messages" />

<Accordion title="Сообщения об ошибках загрузки">

Одно или несколько значений в файле не соответствуют требуемому формату: Формат файла был изменен с 7 июня 2021 года. Убедитесь, что формат вашего файла соответствует примеру в этой статье.

</Accordion>

<Accordion title="Использование Excel для форматирования столбца event_revenue_usd">

При использовании таблиц Excel/Google для создания CSV-файла столбец event\_revenue\_usd должен быть правильно отформатирован перед сохранением файла в формате CSV.

После сохранения CSV-файла проверьте правильность форматирования его содержимого. **Примечание:** Не используйте Excel для проверки, лучше воспользуйтесь **редактором**.

#### Форматирование ячеек event\_revenue\_usd в Excel

Обычно Excel форматирует ячейки со значениями с помощью запятой для отделения тысяч, как показано на рисунке. Этот формат не подходит для загрузки CSV-файлов. Вам также необходимо удалить символ $.

![mceclip0.png](https://files.readme.io/3b2aface429f87eb651e6d678760ee3a4b85234a11b0ae2da771d7af7279c1e7-34255643021073.png)

Это можно исправить, отформатировав ячейки в Excel.

Для форматирования сумм затрат без отделителя тысяч и знака $:

1. Выберите ячейки, которые необходимо отформатировать.
2. Щелкните правой кнопкой мыши и выберите **Форматировать ячейки**.  
   Откроется окно форматирования ячеек.
3. Выберите **Number** (Число).  

   <Image alt="Formatnumbers.png" src="https://files.readme.io/4c1b61d1eae9149e818d4cc9793128fbdaafed5daed9acf6cbc503571475cc0e-34255643022481.png" width="381px" />

1. Очистите поле **Использовать 1000-й сепаратор (,)** .
2. (Необязательно) Установите количество **знаков после десятичного разделителя**. По умолчанию установлено значение 2. Максимально допустимое значение — 5.
3. Нажмите кнопку **OK**.  
   Ячейки отформатированы правильно.

<Accordion title="CSV-файлы, создаваемые Excel, не имеют запятых в качестве разделителей">

Если Excel создает CSV-файл, в котором в качестве разделителя используется точка с запятой «;» или другой символ, но не запятая:

* Это происходит, когда в региональных настройках компьютера установлен язык/регион, отличный от английского.
* Особенно часто эта проблема возникает, когда в региональных настройках выбран немецкий язык.
* Решение зависит от операционной системы компьютера (macOS или Windows).
* Чтобы решить эту проблему, найдите последнее руководство от <Anchor target="_blank" href="https://support.office.com/en-us/article/import-or-export-text-txt-or-csv-files-5250ac4c-663c-47ce-937b-339e391393ba#ID0EAAFAAA=Office_2016-2010">Microsoft</Anchor> или пообщайтесь на других форумах. Используйте следующие поисковые запросы: *Операционная система (macOS или Windows) Excel меняет разделитель для файлов CSV.*

</Accordion>
