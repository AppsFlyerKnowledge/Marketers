> **Краткий обзор:** Для приложений с iOS 15 и выше: настраивайте своё приложение для отправки копий постбэков в AppsFlyer, в дополнение к их отправке в рекламные сети. Это позволит AppsFlyer проверять значение конверсии (CV) и целостность постбэка. Настройте одновременную отправку копий постбэков через AppsFlyer Push API на дополнительную конечную точку.

> 📘 **Примечание**
>
> В этой статье термин **SKAN** включает как **SKAdNetwork**, так и новейший фреймворк **AdAttributionKit (AAK)**.

## Зачем отправлять копии постбэков в AppsFlyer?

* Соберите все постбэки в одном месте: Постбэки содержат важную информацию для рекламодателей, в частности, значение конверсии (CV), по которому измеряется качество пользователей. В постбэках CV не зашифровано и не является частью подписи постбэка. В результате, CV, передаваемое рекламной сетью, нельзя проверить. Кроме того, оно открыто для манипуляций. AppsFlyer будет пересылать копии постбэков через Push API на определённые вами конечные точки.
  * Обязательно для Apple Ads: для отчетности AA SKAN требуется пересылка постбэков (iOS 15+).
* Просмотр метрик по повторным скачиваниям; некоторые рекламные сети не предоставляют AppsFlyer данные о повторных скачиваниях. Для полноты картины используются копии постбэков.
* Просмотр данных о приложении издателя.
* Просмотр взаимодействий по типам взаимодействия.

**Примечание!** В AppsFlyer по-прежнему должны приходить постбэки из рекламных сетей, поскольку в них содержатся дополнительные данные, предоставляемые рекламными сетями, (например, название кампании).

## Настройка приложения для отправки копий постбэков в AppsFlyer

Согласно документации Apple, вы можете установить одну конечную точку постбэка SKAN.

**Чтобы зарегистрировать конечную точку AppsFlyer:**

1. Попросите своего разработчика iOS <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/integrate-ios-sdk#sending-skan-postback-copies-to-appsflyer">добавить AppsFlyer</Anchor> в качестве конечной точки постбэка SKAN в следующей версии приложения.
2. Отправьте приложение для iOS.
3. Постбэки будут отправляться в AppsFlyer после публикации новой версии (не из TestFlight).
4. Вы можете просмотреть полученные постбэки в отчёте <Anchor target="_blank" href="/marketers/ru/docs/skan-raw-data-reports">по копиям постбэков</Anchor>.

> 🚧 **Важно!**
>
> В приложениях без трафика SKAN будет отображаться следующее сообщение даже после завершения настройки: «Ваше Приложение не настроено на отправку копий постбэков iOS (iOS 15+) в AppsFlyer. Их отправка необходима для обеспечения целостности при измерении SKAN.»

## Распространенные заблуждения

> 📘 **Не верьте всему, что слышите!**
>
> Верны ли эти утверждения?
>
> ![TrueOrFalse.png](https://files.readme.io/77212d5a12ce2af35b0a4c87ca9e58213b4f9fd88c775007793e7abb5aaa3f04-35682597298577.png)
>
> * Рекламодатели больше не зависят от рекламных сетей для получения постбэков.
>   * **Ложь.** Рекламодатель по-прежнему зависит от рекламной сети в части расшифровки значительных фрагментов данных. Например, только рекламная сеть может сопоставить идентификатор кампании SKAN с названием кампании.
> * Как только я настрою дополнительную конечную точку, на нее будут отправляться копии всех постбэков.
>   * **Ложь.** Функция дополнительной конечной точки доступна только для устройств с iOS 15 и выше. Копии постбэков не отправляются с устройств, работающих на более ранних версиях.

## Характеристики и ограничения

После настройки приложения для отправки копий постбэка в AppsFlyer может потребоваться несколько дней, прежде чем это отобразится на дэшборде.
