> **Краткий обзор:** ChatGPT Ads — рекламная платформа OpenAI и интегрированный партнер AppsFlyer . Настройте интеграцию, чтобы измерять и атрибутировать установки мобильного приложения, события внутри приложения и конверсии на веб-сайте, полученные из ваших кампаний ChatGPT Ads.

## Об интеграции с ChatGPT Ads

Интеграция AppsFlyer с ChatGPT Ads (OpenAI) позволяет измерять и атрибутировать установки приложений, события внутри приложения, события в приложении и конверсии на веб-сайте, полученные в результате ваших кампаний в ChatGPT Ads. Он поддерживает измерение как мобильного приложения, так веб-сайтов.

* **Мобильное приложение** — AppsFlyer атрибутирует установки и повторные взаимодействия вашим кампаниям ChatGPT Ads, а также отправляет постбэки о событиях внутри приложения.
* **Веб-сайт** — AppsFlyer передает веб-события (например, просмотры страниц, просмотры контента и покупки), зафиксированные с помощью Web SDK AppsFlyer , в Conversions API (CAPI) сервиса ChatGPT Ads — в дополнение к JavaScript-пикселю ChatGPT Ads (или вместо него).

Если вы также запускаете на своем сайте пиксель ChatGPT Ads, ChatGPT Ads выполняет дедупликацию серверных событий (отправленных через Conversions API, или CAPI) с событиями пикселя с помощью общего идентификатора события, поэтому вы можете параллельно запускать CAPI и пиксель, не завышая количество конверсий.

Укажите этот общий идентификатор как `af_customer_event_id` в полезной нагрузке события, которое вы отправляете в AppsFlyer. См. [Интеграция вашего сайта](#интегрируйте-свой-сайт) ниже.

## Настройка интеграции

Настройте интеграцию отдельно для каждого мобильного приложения и веб-сайта, которые вы хотите измерять. Для каждого из них вам понадобятся ID пикселя и API -ключ из вашего аккаунта в Ads Manager ChatGPT Ads (OpenAI).

**Обязательные требования:**

* Перед настройкой интеграция создайте аккаунт в ChatGPT Ads.
* Ваши мобильное и веб-приложения настроены в AppsFlyer. <Anchor target="_blank" href="/marketers/ru/docs/adding-an-app-to-appsflyer">Узнать больше</Anchor>

**Для настройки интеграции:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите **Сотрудничество** > **Партнерские интеграции** > **Marketplace** .  
   **Чтобы отредактировать:** В AppsFlyer в боковом меню выберите **Сотрудничество** > **Партнерские интеграции** > **Активные интеграции** .
2. Настройте интеграцию для вашего:

* [**Мобильное приложение**](#интегрируйте-свое-мобильное-приложение) — атрибуция установок, повторных взаимодействий и события в приложении кампаниям ChatGPT Ads.
* [**Веб-сайт**](#интегрируйте-свой-сайт) — передача событий веб-конверсии в Conversions API для ChatGPT Ads с дедупликацией данных относительно пикселя ChatGPT Ads.

## Интегрируйте свое мобильное приложение

Чтобы настроить атрибуцию и постбэки событий в приложении для ChatGPT Ads, потребуются следующие действия в вашем мобильном приложении.

**Чтобы интегрировать ваше мобильное приложение:**

1. В AppsFlyer в боковом меню выберите **Сотрудничество** > **Партнерские интеграции** > **Marketplace** .
2. Выберите свое мобильное приложение из выпадающего меню.  
   **Примечание:** Вам потребуется повторить эти действия для каждой платформы, на которой работает ваше приложение (например, для версий на Android и iOS) .
3. Найдите **ChatGPT Ads (OpenAI)** и нажмите **«Интегрировать»** .
4. Выполните настройку на вкладках, как описано ниже.

<Accordion title="Вкладка «Интеграция»">

#### Активация партнёра

**Чтобы активировать интеграцию:**

Включите переключатель **Активировать партнёра**.

**Важно!** Переключатель **должен оставаться включенным,** пока вы работаете с ChatGPT Ads. Деактивация интеграции отключит атрибуцию и постбэки для ваших кампаний.  
Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации партнёров</Anchor>.

#### Общие настройки

Введите следующие учетные данные:

* **ID пикселя** — пиксель создается в вашем ChatGPT Ads Manager. Получите его на вкладке «Конверсии» в вашем аккаунте Ads Manager.
* **Ключ API** — ключ API необходим для аутентификации вызовов Events API . Получите его на вкладке «Конверсии» в вашем аккаунте ChatGPT Ads Manager.   
  **Примечание:** Убедитесь, что используете ключ конверсий API , а не ключ API для управления рекламой, поскольку требуемые права привязаны именно к ключу CAPI.

##### **Продвинутая защита данных**

Переключатель Advanced Privacy (AP) определяет, как события отправляются в OpenAI для пользователей iOS (14.5 и выше), которые не сделали свой IDFA доступным:

* Advanced Privacy **отключена**: события отправляются со всеми доступными идентификаторами пользователя (IP-адреса, user agent и т. д.), даже если IDFA недоступен.
* Advanced Privacy **включена**: отправляются только события, атрибутированные к `openai_int`, и эти постбэки содержат только данные атрибуции. Перед отправкой из постбэка удаляются все идентификаторы уровня пользователя.

##### **Обмен данными Advanced Matching**

Включите этот параметр, чтобы передавать в ChatGPT Ads поля расширенного сопоставления, такие как хешированные адреса электронной почты, номера телефонов, имена и фамилии, если эти поля содержатся в данных о событиях, отправляемых в AppsFlyer. Более подробную информацию см. здесь: <Anchor target="_blank" href="/marketers/ru/docs/advanced-matching-data-sharing">Обмен данными с расширенным сопоставлением</Anchor>.

#### Постбэки по умолчанию

Постбэк — это уведомление, передаваемое напрямую между серверами (server-to-server), которое AppsFlyer отправляет в ChatGPT Ads для отчета об атрибутированном событии (например, об установке или действии в приложении). В этом разделе отображаются ваши постбэки. Узнайте, как <Anchor target="_blank" href="/marketers/ru/docs/set-up-re-attribution-window">настроить постбэки для установки и реатрибуции</Anchor> .

Узнать больше о <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#default-postbacks">настройке постбэков по умолчанию</Anchor> .

#### Настройки внутренних событий приложения

Чтобы отправлять постбэки о событии в приложении в ChatGPT Ads, введите необходимые учетные данные:

* ID пикселя:
* Ключ API

Подробности см. в разделе [«Общие настройки»](#общие-настройки) выше.

#### Постбэки событий внутри приложения

Настройте отправку постбэков о событии в ChatGPT Ads. <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration">Узнать больше</Anchor>

**Активируйте постбэки по событиям в приложении.**

Включите переключатель **постбэков для событий в приложении** .

**Окно постбэков по внутренним событиям**

Определите период после установки, повторной атрибуции или повторного вовлечения, в течение которого AppsFlyer отправляет постбэки событий в приложении в ChatGPT Ads. <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration">Узнать больше</Anchor>

**Составьте карту событий**

Чтобы ваши события соответствовали событиям в ChatGPT Ads, сопоставьте названия событий. <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#сопоставление-событий">Узнать больше</Anchor>

ChatGPT Ads поддерживает следующие стандартные события, а также любое **пользовательское** резервное событие, не включенное в список ниже:

| Название события ChatGPT Ads | Когда использовать |
| --- | --- |
| page\_viewed | Пользователь переходит на важную страницу или просматривает её. |
| contents\_viewed | Пользователь просматривает конкретный товар, объявление, статью или единицу контента. |
| items\_added | Пользователь добавляет один или несколько товаров в корзину, комплект или подборку. |
| checkout\_started | Пользователь начинает оформление заказа. |
| order\_created | Покупка завершена |
| registration\_completed | Пользователь завершает регистрацию учетной записи или событие. |
| lead\_created | Пользователь отправляет форму для сбора лидов или запрашивает обратную связь. |
| appointment\_scheduled | Пользователь записывается на встречу, заказывает демонстрацию или консультацию. |
| trial\_started | Начался бесплатный пробный период |
| subscription\_created | Начинается платная подписка. |
| app\_opened | Мобильное приложение открыто. |
| custom | Любое событие, не охваченное стандартной таксономией. |

**Устранение дубликатов событий**

Если вы также используете пиксель ChatGPT Ads на своем сайте, отправляйте один и тот же идентификатор события и в AppsFlyer, и в ChatGPT Ads, чтобы AppsFlyer мог дедуплицировать события:

* Добавьте `af_customer_event_id` в полезную нагрузку события, которое вы отправляете в AppsFlyer: внутри eventValue для Web SDK или event\_value для S2S API (server-to-server).
* Отправьте то же значение в соответствующем событии пикселя.

AppsFlyer передает это значение в ChatGPT Ads как идентификатор события. Затем ChatGPT Ads использует его, чтобы дедуплицировать серверное событие, полученное от AppsFlyer, с событием пикселя, чтобы AppsFlyer засчитал конверсию один раз.

Если вы не отправляете `af_customer_event_id`, AppsFlyer автоматически создает идентификатор события. Этот идентификатор не будет совпадать с событиями пикселя.

Дополнительную информацию см. в разделе «Интеграция Web SDK AppsFlyer».

Использовать целевую страницу в качестве места назначения рекламы, а затем использовать <Anchor target="_blank" href="/marketers/ru/docs/onelink-smart-script-overview">Smart Script</Anchor> или <Anchor target="_blank" href="/marketers/ru/docs/smart-banners-mobile-web-to-app-for-marketers">Smart Banner</Anchor>, чтобы направить пользователя в магазин приложений или Google Play (при этом создавая ссылку, которая обеспечит атрибуцию).

#### Выберите параметр

Выберите параметры ссылки атрибуции, которые вы хотите включить.

* Выберите параметры ссылки атрибуции, которые хотите включить (например, **Название кампании** и **идентификатор сайта**), и задайте **окно атрибуции/лукбэк по кликам** (7 дней — рекомендуемое AppsFlyer значение по умолчанию). AppsFlyer автоматически генерирует ссылку атрибуции, которую можно использовать в рекламных кампаниях ChatGPT.
* Следующие параметры URL-адреса могут автоматически заполняться в ChatGPT с помощью этих динамических макросов URL:
  * `af_partner_account_id={ad_account_id}`
  * `af_c_id={campaign_id}`
  * `af_adset_id={ad_group_id}`
  * `af_ad_id={ad_id}`
  * `clickid={oppref}`
* Макросы поля названия не поддерживаются.

> 🚧 **Важно!**
>
> * Чтобы AppsFlyer мог зафиксировать идентификатор клика из ChatGPT Ads и отправить его обратно в ChatGPT Ads, обязательно используйте `clickid={oppref}`, если ваши объявления ведут напрямую в магазин приложений или Google Play. Если целевая страница объявления — лендинг со Smart Script, убедитесь, что входящий параметр `oppref` сохраняется и сопоставляется с `clickid` в исходящем URL-адресе.
> * ChatGPT Ads обрабатывает макросы (например, `{campaign_id}`) только тогда, когда соответствующие параметры указаны в поле **Tracking parameters**, а не в поле **Ad destination URL**. Вставьте параметры запроса (например, `af_c_id={campaign_id}`) в поле **Tracking parameters**, а поле **Ad destination URL** используйте только для самого URL-адреса назначения.

Примечание: **Ваша сгенерированная ссылка содержит** (ID интеграции ChatGPT Ads в AppsFlyer).

## Интегрируйте свой сайт

Используйте следующие шаги, чтобы настроить серверную пересылку событий на ChatGPT Ads для вашего сайта.

**Для интеграции вашего сайта:**

1. В AppsFlyer в боковом меню выберите **Сотрудничество** > **Партнерские интеграции** > **Marketplace** .
2. Выберите ваше веб-приложение из выпадающего меню.
3. Найдите **ChatGPT Ads (OpenAI)** и нажмите **«Интегрировать»** .
4. Завершите настройку на вкладке интеграция , как описано ниже.

Включите переключатель **Активировать партнёра**.

**Важно!** Переключатель **должен оставаться включенным,** пока вы работаете с ChatGPT Ads. Деактивация интеграции отключит пересылку события для вашего сайта.  
Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации партнёров</Anchor>.

#### Настройки внутренних событий приложения

Чтобы иметь возможность отправлять постбэки о событии в ChatGPT Ads, введите следующие учетные данные:

* **ID пикселя** — пиксель создается в вашем ChatGPT Ads Manager. Получите его на вкладке «Конверсии» в вашем аккаунте Ads Manager.
* **Ключ API** — ключ API необходим для аутентификации вызовов Events API . Получите его на вкладке «Конверсии» в вашем аккаунте ChatGPT Ads Manager.

**Обмен данными с расширенным сопоставлением:** Включите передачу полей расширенного сопоставления — хэшированного email, номера телефона, имени и фамилии — в ChatGPT Ads, если эти поля включены в данные о событии, отправляемые в AppsFlyer. Более подробную информацию см. здесь: <Anchor target="_blank" href="/marketers/ru/docs/advanced-matching-data-sharing">Обмен данными с расширенным сопоставлением</Anchor>.
