> **Краткий обзор.** ironSource, интегрированный партнер AppsFlyer, создает инструменты монетизации, вовлечения, аналитики и обнаружения для разработчиков приложений, производителей устройств, мобильных операторов и рекламодателей. Помимо мобильной атрибуции по кликам, ironSource также предлагает атрибуцию затрат, дохода от рекламы, ретаргетинга и атрибуцию по просмотрам, данные которых можно регистрировать с помощью AppsFlyer

## Настройка ironSource

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом входе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
    Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна «Настройки партнера» см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

> 📘 **Примечание**
>
> Как сеть, ориентированная на все установки, ironSource предпочитает получать постбэки для всех новых установок вашего приложения из любого источника, включая органические. Чтобы отправлять в ironSource постбэки по всем установкам, выберите **События, атрибутируемые любому партнеру, или органические**.

Окно конфигурации ironSource содержит 5 вкладок: Интеграция, Ссылка атрибуции, Затраты, Доход от рекламы и Разрешения. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

### Активация партнеров

На вкладке **Интеграция** включите переключатель **Активировать партнера**.  
 Этот переключатель должен быть <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активирован</Anchor> все время, пока вы работаете с этим партнером.Этот переключатель должен быть <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активирован</Anchor> все время, пока вы работаете с этим партнером.Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="advanced-privacy" />

#### Расширенные настройки конфиденциальности

Только для приложений iOS, когда **Расширенная конфиденциальность (для iOS 14.5+ и выше)** включена, вы можете <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#b">контролировать, какие данные передаются</Anchor> в ironSource через постбэки и отчеты.

<div id="transaction-id" />

### Идентификатор транзакции

Только для приложений iOS, когда переключатель **Предоставлять идентификатор транзакции SKAN** включен, вы  разрешаете AppsFlyer <Anchor target="_blank" href="/marketers/ru/docs/skadnetwork-skan-solution-guide#sending-postbacks-to-integrated-partners">передавать идентификатор транзакции постбэков SKAdNetwork</Anchor> в ironSource. Таким образом, ironSource может декодировать ваши значения конверсии SKAdNetwork.

<div id="note-2" />

> 📘 **Примечание**
>
> Для взаимодействия SKAN с AppsFlyer обратитесь к своему аккаунт-менеджеру ironSource, чтобы <Anchor target="_blank" href="https://developers.is.com/ironsource-mobile/general/universal-skan-reporting/#step-1">разрешить отправку данных SKAN в MMP</Anchor>.

<div id="general-settings" />

### Общие настройки

**ID рекламодателя**

ironSource подключается к AppsFlyer посредством уникального идентификатора рекламодателя (6 цифр) и пароля. Если у вас еще нет идентификатора рекламодателя и пароля, вы должны получить их от ironSource, чтобы продолжить интеграцию. Если они есть, скопируйте ID и пароль и вставьте их в соответствующие поля.

<div id="install-and-re-engagement-attribution" />

### Атрибуция установок и повторного вовлечения

Эти два переключателя позволяют атрибутировать к ironSource новые установки и реатрибуцию пользователей, которые **просмотрели** ваше объявление, но **не нажали** на него. Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/measure-view-through-engagements">атрибуции по просмотрам</Anchor>.

**Для атрибуции новых установок:**

1. Включите **Атрибуцию установок по просмотрам**.
2. Настройте длительность **окна атрибуции по просмотрам** на вкладке [Ссылка атрибуции](/docs/ironsource-campaign-configuration#attribution-link-tab).

 Для атрибуции новых вовлечений имеющихся пользователей:

1. Включите **Атрибуцию повторного вовлечения по просмотрам**.
2. Настройте длительность **окна атрибуции по просмотрам** на вкладке [Ссылка атрибуции](/docs/ironsource-campaign-configuration#attribution-link-tab).

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте в ironSource постбэки после установок приложений и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят исключительно от пользователей, атрибутированных ironSource.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять в ironSource отчеты о событиях всех пользователей, которые есть в вашей базе.

<div id="note-3" />

> 📘 **Примечание**
>
> Как сеть, ориентированная на все установки, ironSource предпочитает получать постбэки для всех новых установок вашего приложения из ЛЮБОГО источника, включая органические. Чтобы отправлять в ironSource постбэки по всем установкам, выберите «События, атрибутируемые любому партнеру».

<div id="in-app-event-postbacks" />

### Постбэки по внутренним событиям приложений

Настройте сопоставление внутренних событий приложения с событиями ironSource, отправляемыми через постбэки:

1. Активируйте **Постбэки по внутренним событиям приложения**.
2. Чтобы добавить в список событие, определенное в SDK, или межсерверное событие, нажмите **Добавить событие**. В таблице ниже описаны поля, которые необходимо заполнить:

| Имя параметра | Описание |
| --- | --- |
| **Событие AppsFlyer** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.<br />**Совет**: Не нашли здесь нужное событие?<ul><li>Убедитесь, что событие активировано на устройстве с неорганической установкой, и повторите поиск.</li><li>Введите его в поле **Событие AppsFlyer** и нажмите **Создать свое**. Подробнее о сопоставлении пользовательских событий <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#пользовательские-события">читайте здесь</Anchor>.</li></ul> |
| **сопоставлено с событием партнера** | Уникальное имя или идентификатор каждого события, определенные партнером. Возможны следующие настройки сопоставления:<ul><li>**Текстовое поле**. Введите в него соответствующий идентификатор события, полученный от партнера.</li><li>**Раскрывающийся список**. Выберите наиболее подходящее предопределенное событие AppsFlyer.</li><li>Переход к маркетплейс: в верхнем меню любой страницы AppsFlyer нажмите **Маркетплейс**.</li></ul> |
| **для пользователей от** | Выберите вариант отправки для события.<ul><li>**Только события партнера**: постбэки отправляются только в том случае, когда событие атрибутируется к этому партнеру.</li><li>**Все медиа-источники и органический трафик**: отправляйте постбэки для событий, атрибутированных к любому партнеру, а также для органических событий.</li></ul> |
| **Включая** | <ul><li>**Нет данных (по умолчанию)**: отправляет только само событие без значения.</li><li>**Значения и доход**: отправляет все параметры события, **включая** значение дохода (если оно есть в событии).</li><li>**Значения без дохода**: отправляет все параметры, **кроме** значения дохода.</li></ul> |

3. [Необязательно] Нажмите на значок **Добавить условие** <Image alt="conditional-iae-postbacks-icon.png" src="https://files.readme.io/575c9ab0dd82a125319591072b17604a7f9d1b71fff6baff4124d99edc1a7fc7-16570673855121.png" width="30px" /> , чтобы <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#условные-постбэки-по-событиям-в-приложении">установить условия</Anchor> для события.
4. Нажмите **Сохранить интеграцию**.
5. [Необязательно] После сохранения интеграции, оставаясь на странице конфигурации, вы можете интегрировать с этим партнером другие свои приложения:
   1. В левом верхнем углу под именем партнера нажмите на название приложения, чтобы открыть список приложений.
   2. Выберите другое приложение из выпадающего списка.
   3. Повторите <Anchor target="_blank" href="/marketers/ru/docs/amazon-ads-campaign-configuration#integration-tab">шаги по интеграции</Anchor> для выбранного приложения.

>
> * Только для приложений на iOS: Ваш контроль над данными, передаваемыми партнеру через постбэки и <Anchor target="_blank" href="/marketers/ru/docs/about-raw-data-identifier-restrictions">отчеты</Anchor>, зависит от состояния переключателя **Расширенная конфиденциальность (для iOS 14.5+ и более поздних версий)**<Anchor target="_blank" href="/marketers/ru/docs/tiktok-for-business-advanced-srn-integration-setup#advanced-privacy">.</Anchor>

>   * **Название события:** af\_ad\_revenue
>   * **Сопоставлено с:** adRevenue

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для ironSource в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что даже если атрибуция для ironSource отключена, вкладка разрешений остается активной и вы можете предоставить ironSource разрешение на управление.

Эти переключатели позволяют предоставить рекламной сети право самостоятельно выполнять настройки для вашего приложения:

<div id="ad-network-permissions" />

### Разрешения для рекламной сети

* **Разрешение настраивать интеграцию**: разрешить партнеру управлять настройками на вкладке интеграции (за исключением постбэков по внутренним событиям приложений).
* **Разрешение настраивать постбэки по событиям внутри приложения**: разрешить партнеру сопоставлять себе постбэки по внутренним событиям приложений на вкладке интеграции.
* **Предоставление доступа к отчету об удержании пользователей**: партнер получает доступ только к собственным данным об удержании пользователей.
* **Предоставление доступа к агрегированным данным о лояльных пользователях**: партнер получает доступ только к собственным данным о лояльных пользователях.
* **Предоставление доступа к агрегированным данным о внутренних событиях приложения**: партнер получает доступ только к собственным данным о внутренних событиях.
* **Предоставление доступа к агрегированным данным о доходе**: партнер получает доступ к данным только по атрибутированным ему доходам.
* **Разрешить доступ к дэшборду Protect360**: партнер получает доступ только к собственным данным Protect360, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

<div id="agency-permissions" />

### Разрешения для агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* **Главный переключатель** — установите в положение «Включено», чтобы получить доступ к списку разрешений для агентства
* **Разрешить доступ к отчету об удержании** — доступ предоставляется только к собственным данным агентства
* **Разрешить доступ к агрегированным органическим данным**
* **Разрешить настройку постбэков по внутренним событиям приложений**: разрешить агентству сопоставлять себе постбэки по внутренним событиям приложений на вкладке интеграции.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.
