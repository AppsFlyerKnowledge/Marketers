> **Кратко:** Ibotta — партнер рекламной сети, интегрированной с AppsFlyer, который упрощает пользователям получение кэшбэка за повседневные покупки через одно приложение для смартфона.

<Image alt="" src="https://cdn.appsflyer.com/marketplace/static/logo/ibotta.png?v=1" width="119px" />

## Настройка Ibotta

**Необходимые условия.** Если у вас нет\n аккаунта, перед настройкой интеграции свяжитесь с партнером, чтобы открыть аккаунт.

**Чтобы активировать интеграцию:**

1. В AppsFlyer перейдите на вкладку\n **Collaborate > Partner Integrations > Marketplace**.  
    **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. На вкладке **интеграции** включите\n переключатель **Activate partner**.   
    **Примечание:** переключатель **должен оставаться включенным (активным), пока вы работаете с партнером**. Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробнее о\n <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner">интеграциях с партнерами.</Anchor>

> 👍 **Совет**
>
> * Этап <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#d-general-settings">Общие настройки</Anchor> на вкладке Интеграция необходимо **обязательно** выполнять для всех партнеров.
> * Все остальные этапы описаны только для сведения или же являются **необязательными**.

### Активация партнера

При **первом посещении** вам нужно перевести переключатель ***Activate Partner*** в положение ON, чтобы включить настройку параметров вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации/деактивации партнеров</Anchor>.

Постбэки по умолчанию

Автоматически отправляйте постбэки в Ibotta после установок приложения и повторного вовлечения пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят только от пользователей, атрибутированных Ibotta.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с Ibotta и настроить отправку постбэков.

> 👍 **Совет**
>
> Для простой и быстрой интеграции выберите **Отправлять все события, исключая значение дохода** или **Отправлять все события, включая значение дохода**

1. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из событий «сервер—сервер».  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Ibotta.  <br />Получите соответствующий идентификатор события в Ibotta и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра выручки (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создать ссылки атрибуции, которые вы хотите отправить в Ibotta, чтобы атрибутировать кампании Ibotta, группы объявлений или даже отдельные рекламные объявления. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Ibotta.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Ibotta.  
  **Параметр ссылки атрибуции:** af\_adset
* **Название объявления** — задайте названия рекламных объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Ibotta.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. Если паблишеров много, рекомендуем ограничить количество используемых идентификаторов Site ID и использовать параметр Sub Site ID, чтобы избежать <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">превышения ограничений Site ID</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** - используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание, что эти параметры разбираются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье **<Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">Структура и параметры ссылки атрибуции AppsFlyer</Anchor>.**

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. Только установки (первые запуски), произошедшие в пределах окна атрибуции, могут быть атрибутированы Ibotta.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам читайте здесь</Anchor>.

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в Ibotta, чтобы активировать, когда лиды кликают по соответствующей рекламе.

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для Ibotta в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что даже если атрибуция для Ibotta отключена, вкладка разрешений остается активной, и вы можете предоставить Ibotta контроль.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** - только к собственным данным партнера о лояльных пользователях
* ***Разрешить доступ к своим сводным данным о событиях в приложении** -* только к собственным данным партнера о событиях в приложении
* **Allow access to your aggregate revenue data** (Разрешить доступ к своим сводным данным о доходах) — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
