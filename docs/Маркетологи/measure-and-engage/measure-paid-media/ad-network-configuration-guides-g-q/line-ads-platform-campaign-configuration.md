> **Краткий обзор.** LINE Ads Platform, интегрированный партнер AppsFlyer, сочетает в себе систему биддинга и настраиваемого таргетинга. Помимо мобильной атрибуции по кликам, LINE Ads Platform также предлагает атрибуцию ретаргетинга, данные которой можно регистрировать с помощью AppsFlyer.

## Настройка платформы LINE Ads

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

> 📘 **Примечание:**

> Как сеть, ориентированная на все установки LINE предпочитает получать постбэки для всех новых установок вашего приложения из любого источника, включая органические. Чтобы отправлять в LINE постбэки по всем установкам, выберите **События, атрибутированные любому партнеру**. Это может сделать только владелец аккаунта.

### Активация партнера

При **первом посещении** вам нужно будет переключить параметр ниже. При **первом посещении** вам нужно будет включить переключатель ***Активировать партнера***, чтобы включить настройку параметров на вкладке интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

### Общие настройки

**Идентификатор аккаунта и идентификатор приложения**

LINE Ads Platform подключается к AppsFlyer через уникальные LINE\_Ad\_account\_id и LINE\_Ad\_app\_ID.  
**Чтобы включить интеграцию:** Введите ваши уникальные <Anchor target="_blank" href="https://lineforbusiness.com/th-en/service/line-ads/manual#Tracking:~:text=Tracking%20app%20conversions">LINE\_Ad\_account\_id и LINE\_Ad\_app\_ID</Anchor>.

* Введите свои уникальные **LINE\_Ad\_account\_id** и **LINE\_Ad\_app\_ID**.   
  См. <Anchor target="_blank" href="https://lineforbusiness.com/th-en/service/line-ads/manual#Tracking:~:text=Tracking%20app%20conversions">документацию Line Ads о создании бизнес-идентификатора</Anchor>.

#### Подключение нескольких аккаунтов и приложений

Вы можете подключить к AppsFlyer несколько аккаунтов Line Ads и приложений, вручную добавив в ссылку атрибуции после ее создания параметр идентификатора ID аккаунта или идентификатора ID приложения.

> 📘 **Примечание:**
>
> Параметры, указанные и в ссылке атрибуции, и в разделе **General settings**, приводят к конфликтам. Чтобы этого избежать, перед добавлением параметров в ссылку атрибуции ознакомьтесь с описанной ниже **логикой приоритета параметров**.

**Логика приоритета параметров**

* Если в ссылке атрибуции включены оба типа параметров — идентификатор аккаунта и идентификатор приложения (line\_ad\_account\_id, line\_ad\_app\_id), то любые соответствующие идентификаторы, заданные в разделе General settings, будут переопределены.
* Если один из типов параметров отсутствует в ссылке атрибуции, но задан в General settings, для подключения будет использоваться значение из общих настроек.
* Если оба типа параметров — идентификатор аккаунта и идентификатор приложения — отсутствуют и в General settings, и в ссылках атрибуции, интеграция может работать не так, как ожидается.

**Чтобы подключить несколько параметров идентификатора ID аккаунта и идентификатора ID приложения:**

1. Настройте одну или несколько <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">ссылок атрибуции</Anchor>.
2. Добавьте в каждую ссылку атрибуции параметр идентификатора аккаунта и параметр идентификатора приложения, используя строчные буквы. См. выделенную часть в примере ниже.

> 📄 **Пример**
>
> Пример ссылки атрибуции с параметрами идентификатора ID аккаунта и идентификатора ID приложения:
>
> ```http
> https://app.appsflyer.com/id123456789?pid=example_int;...line_ad_account_id=A123456789123&line_ad_app_id=1234567891234&...;redirect=false
> ```

### Постбэки по умолчанию

Автоматически отправляйте постбэки в LINE Ads Platform после установок приложений и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, которые приходят исключительно от пользователей, атрибутированных к LINE Ads Platform.  
Выберите **События, атрибутированные любому партнеру или органические**, чтобы предоставлять в LINE Ads Platform отчеты о событиях всех пользователей, которые есть в вашей базе.

### Настройки внутренних событий приложения

В этом разделе можно сопоставить события в AppsFlyer с событиями в LINE Ads Platform и настроить отправку постбэков.

1. Введите ваши LINE\_Ad\_account\_id и LINE\_Ad\_app\_ID еще раз.
2. Включите переключатель «Постбэки по внутренним событиям приложения».
3. Выберите в поле «Вариант отправки» значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. В раскрывающемся списке выберите ***имя события в SDK***.
5. В раскрывающемся списке ***Идентификатор события партнера*** выберите соответствующий параметр.
6. Нажмите кнопку ***Добавить событие***, чтобы добавить дополнительные названия событий.
7. Введите следующие параметры:

| Имя параметра | Описание |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор каждого события, определенные в LINE Ads Platform.  <br />Получите соответствующий идентификатор события из LINE Ads Platform и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра выручки (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

### Сопоставление настраиваемых внутренних событий приложения

В AppsFlyer есть возможность сопоставить любое настраиваемое внутреннее событие приложения для отправки в LINE, используя опцию «Пользовательский идентификатор события партнера».

Имена и значения событий (в том числе параметры событий), заданные в SDK, передаются в LINE как есть.
