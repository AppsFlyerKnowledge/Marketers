> **Кратко:** MOLOCO, интегрированный партнер AppsFlyer, преобразует пользовательские данные в эффективность рекламы, помогая мобильным компаниям реализовывать программы маркетинга и монетизации рекламы.

## Настройка MOLOCO

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом посещении** этого раздела вам нужно перевести кнопку ***Activate Partner*** в положение «Включено», чтобы включить настройку параметров вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
    Дополнительная информация об активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

В окне настроек MOLOCO есть 3 активные вкладки: Integration, Attribution link и Permissions. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

> * Все остальные этапы описаны только для сведения или же являются **необязательными**.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

<div id="activate-partner" />

### Активация партнера

При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации/деактивации партнеров</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть, ориентированная на все установки, MOLOCO предпочитает получать постбэки для всех новых установок вашего приложения из любого источника, включая органические. Чтобы отправлять в MOLOCO постбэки по всем установкам, выберите **События, атрибутированные любому партнеру** тобы отправлять все постбэки установок в MOLOCO.

<div id="general-settings" />

### Общие настройки

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение "Включено", если хотите атрибутировать установки по просмотрам от MOLOCO. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в MOLOCO после установок приложения и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят исключительно от пользователей, атрибутированных MOLOCO.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять MOLOCO отчеты о событиях всех пользователей, которые есть в вашей базе.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с MOLOCO через постбэки.

1. Включите переключатель «Постбэки по внутренним событиям приложения».
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру** для событий **только** от пользователей, атрибутированных этому партнеру  
   **- События, атрибутированные любому партнеру или органические** чтобы вся ваша база пользователей была доступна для передачи в отчет партнеру
3. Чтобы добавить в список событие, определенное в SDK, нажмите  **Add Event**, чтобы добавить SDK-событие в список.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **AppsFlyer event (Событие AppsFlyer)** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.<br />**Совет**: Не нашли здесь нужное событие?<ul><li>Убедитесь, что событие активировано на устройстве с неорганической установкой, и повторите поиск.</li><li>Введите его в поле **Событие AppsFlyer**, затем нажмите **Добавить другое**. Подробнее о <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#пользовательские-события">сопоставлении пользовательских событий.</Anchor></li></ul> |
| **сопоставлено с событием партнёра** | Уникальное имя или идентификатор каждого события, определенные партнером. Возможны следующие настройки сопоставления:<ul><li>**Текстовое поле**. Введите соответствующий идентификатор события, полученный от партнера.</li><li>**Раскрывающийся список**. Выберите наиболее подходящее предопределенное событие AppsFlyer.</li><li>**Как есть**: События отправляются в исходном виде, без сопоставления названий.</li></ul> |
| **для пользователей от** | Выберите вариант отправки для события.<ul><li>**Только этот партнер**: постбэки отправляются только в том случае, когда событие атрибутируется этому партнеру.</li><li>**Все медиа-источники и органический трафик**: отправляйте постбэки для событий, атрибутированных любому партнеру, а также для органических событий. В Unity Ads данная опция является рекомендованной.</li></ul> |
| **включая** | <ul><li>**Нет данных (по умолчанию)**: отправляет только само событие без значения.</li><li>**Значения и доход**: отправляет все параметры события, **включая** значение дохода (если оно есть в событии). В Unity Ads данная опция является рекомендованной.</li><li>**Значения без дохода**: передача всех параметров события, **кроме** значения дохода.</li></ul> |

<div id="note-1" />

> 📘 **Примечание:**
>
> Вы можете отправлять в MOLOCO <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-ad-revenue-attribution#ad-revenue-event-postbacks-for-ad-networks">постбэки по доходу от рекламы</Anchor> с помощью события `af_ad_revenue`, чтобы MOLOCO могла оптимизировать кампании.

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

Формируйте и сохраняйте ссылки атрибуции и отправляйте их партнеру, чтобы атрибутировать определенные кампании, группы объявлений и отдельные объявления — как для кампаний по привлечению пользователей, так и для ретаргетинговых кампаний. Вы можете использовать либо ссылку для конкретной платформы, либо <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">OneLink</Anchor>.  
<Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">Подробнее о структуре и параметрах ссылок атрибуции</Anchor>.

**Чтобы создать ссылку атрибуции,** следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#attribution-link-tab">этой инструкции</Anchor>.

</Accordion>

<div id="cost-tab" />

<Accordion title="Вкладка «Стоимость»">

AppsFlyer получает информацию о затратах через API. Подробную информацию <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">о поддерживаемых параметрах, метриках и функциях см. в</Anchor> таблице интеграции затрат рекламной сети. **Примечание**. Для получения сведений о затратах требуется подписка ROI360.

**Чтобы включить API данных о затратах:**

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#enable-cost-api">этим инструкциям по интеграции</Anchor>.

Данные за вчерашний день становятся доступны в Moloco примерно в 4:00 утра (в зависимости от настроек часового пояса в вашем аккаунте MOLOCO). Например, если событие произошло в понедельник, AppsFlyer сможет получить данные о стоимости во вторник примерно в 4:00 утра. После получения данных о стоимости от MOLOCO AppsFlyer анализирует и подготавливает их, и после завершения этого процесса данные становятся доступны для использования.

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API данных о затратах</Anchor> и время, когда AppsFlyer получил соответствующие данные о затратах в последний раз, либо на дэшборде статуса интеграции затрат (и доходов от рекламы), либо на дэшборде отдельной рекламной сети.

</Accordion>

<div id="ad-revenue-tab" />

<Accordion title="Вкладка «Доходы от рекламы»">

Интеграция доходов от рекламы для этого партнера недоступна.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для MOLOCO в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание: даже если атрибуция для MOLOCO отключена, вкладка разрешений остается активной, и вы можете предоставить MOLOCO контроль.

<div id="-ad-network-permissions" />

#### ![MOLOCO_permissions.png](https://files.readme.io/f443306f1b56197709308c0a33e436dc26adc7a0e80e6c2887edc63a5697b6d4-360002616197.png)Полномочия для рекламной сети

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* **Разрешение настраивать интеграцию**: разрешить партнеру управлять настройками на вкладке интеграции (за исключением постбэков по внутренним событиям приложений).
* **Разрешение настраивать постбэки по событиям в приложении** — разрешить партнеру настроить сопоставление постбэков по событиям в приложении с самим собой на вкладке интеграции
* **Предоставление доступа к отчету об удержании пользователей** - только к собственным данным партнера об удержании пользователей
* **Разрешить доступ к дэшборду Protect360** - только к собственным данным партнера Protect360, при условии что эта функция включена для рекламодателя

Узнайте больше о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
