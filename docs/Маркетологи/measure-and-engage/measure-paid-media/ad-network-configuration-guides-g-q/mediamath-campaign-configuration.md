> **Кратко:** MediaMath, интегрированный партнер AppsFlyer, специализируется на технологиях programmatic-маркетинга, включая платформы управления данными и многоканальные DSP. Помимо мобильной атрибуции по кликам, MediaMath также предлагает ретаргетинг и атрибуцию по просмотрам, данные о которых можно передавать в AppsFlyer.

![](https://cdn.appsflyer.com/marketplace/static/logo/mediamath.png)

## Настройка MediaMath

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. **Примечание. Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации/деактивации партнеров</Anchor>.**
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

Включение **Advanced Data Sharing** позволит AppsFlyer отправлять MediaMath атрибутированный источник и данные referrer для постбэков по установкам. Переключатель «CB\_AD» делает то же самое для событий в приложении.

В окне настроек MediaMath есть 3 активные вкладки: Integration, Attribution link и Permissions. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнера

При **первом посещении** вам нужно будет переключить тумблер ниже. При **первом посещении** вам нужно будет включить переключатель ***Активировать партнера***, чтобы включить настройку параметров на вкладке интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

> 📘 **Примечание:**
>
> Как сеть, ориентированная на все установки, MediaMath предпочитает получать постбэки по всем новым установкам вашего приложения из ЛЮБОГО источника, включая органические. Чтобы отправлять в MediaMath постбэки по всем установкам, выберите **События, атрибутированные любому партнеру**.

### Общие настройки

**Partner ID (Идентификатор партнера)**

MediaMath подключается к AppsFlyer через уникальные Advertiser ID и Pixel ID. Если у вас еще нет Advertiser ID и Pixel ID, необходимо получить их в MediaMath, чтобы продолжить интеграцию.

**Обмен расширенными данными**

Установите этот переключатель в положение "Включено", если хотите, чтобы AppsFlyer отправлял дополнительную информацию в MediaMath.

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение "Включено", если хотите атрибутировать установки после просмотра из MediaMath. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

### Постбэки по умолчанию

Автоматически отправляйте постбэки в MediaMath после установок приложения и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Only events attributed to this partner** для событий, которые приходят только от пользователей, атрибутированных MediaMath.  
Выберите **События, атрибутированные любому партнеру или органические**, чтобы всю вашу пользовательскую базу можно было включать в отчетность для MediaMath.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с MediaMath и настроить отправку постбэков.

1. Введите Advertiser ID еще раз.
2. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор каждого события, определенные в MediaMath.  <br />Получите соответствующий идентификатор события в MediaMath и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра выручки (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для MediaMath в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что, даже если атрибуция для MediaMath отключена, вкладка разрешений остается активной и вы можете предоставить MediaMath разрешение на управление.

### Ad Network Permissions (Разрешения для рекламной сети)

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate loyal user data*** (Разрешить доступ к своим сводным данным о лояльных пользователях) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate in-app events data*** (Разрешить доступ к своим сводным данным о внутренних событиях приложения) — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
