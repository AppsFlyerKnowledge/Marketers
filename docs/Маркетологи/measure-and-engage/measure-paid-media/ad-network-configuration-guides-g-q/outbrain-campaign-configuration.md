> **Коротко:** Outbrain — премиум-платформа для рекомендаций и интегрированный партнер AppsFlyer, которая помогает маркетологам находить свою целевую аудиторию с помощью персонализированных рекомендаций на сайтах ведущих паблишеров мира.

## Настройка интеграции с Outbrain

Интеграция AppsFlyer с Outbrain поддерживает атрибуцию по кликам.

![](https://cdn.appsflyer.com/marketplace/static/logo/outbrain.png?v=1)

**Необходимые условия:** Перед настройкой интеграции обязательно [свяжитесь с партнёром](#) и откройте у него аккаунт. Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной.   
   **Важно:** переключатель **должен оставаться включенным (активным), пока вы работаете с партнером**. <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">Узнать больше</Anchor>
5. Завершите настройку, используя соответствующие вкладки, как описано ниже.

При необходимости внесите дополнительные изменения в настройки в соответствии с кампаниями и постбэками, которые вы запускаете с партнером.

| Настройка | Замечания |
| --- | --- |
| **Интеграция** | При необходимости настройте дополнительные параметры <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#attribution-link-tab">интеграции</Anchor>. |
| **Ссылка атрибуции** | Создайте <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#attribution-link-tab">ссылки атрибуции</Anchor> |
| **затраты;** | Недоступно для этого партнера |
| **Дата и время** | Недоступно для этого партнера |
| **Разрешения** | При необходимости настройте <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешения</Anchor> рекламной сети. |

**Изменить существующую интеграцию:**

В AppsFlyer перейдите на вкладку **Сотрудничество> Партнерские интеграции> Активные интеграции**, найдите партнера и внесите изменения.

Узнать больше о <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner">партнерских интеграциях</Anchor>.
