> **Кратко:** Glispa, интегрированный партнер AppsFlyer в категории рекламных сетей, создает решения, которые упрощают для агентств и брендов взаимодействие с целевыми аудиториями, а для паблишеров — монетизацию своих приложений. Помимо мобильной атрибуции по кликам Glispa также предлагает атрибуцию по стоимости и view-through атрибуцию, которую можно регистрировать с помощью AppsFlyer.

<Image alt="" src="https://cdn.appsflyer.com/marketplace/static/logo/glispacpa.png?v=1" width="168px" />

## Настройка Glispa

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

### Активация партнера

При **первом посещении** этого раздела вам нужно перевести кнопку ***Activate Partner*** в положение «Включено», чтобы можно было настроить параметры вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

### Общие настройки

**Активация атрибуции по просмотрам**

[![appl013.png](https://files.readme.io/513c24cf8bcf72d8efc3324411a1bea1fd45e8c7cb721c7f1144463fa030492c-50706625495953.png)](https://files.readme.io/513c24cf8bcf72d8efc3324411a1bea1fd45e8c7cb721c7f1144463fa030492c-50706625495953.png)

Установите этот переключатель в положение «Включено», если хотите атрибутировать установки view-through из Glispa. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Glispa после установок и повторного вовлечения пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, которые поступают только от пользователей, атрибутированных Glispa.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять Glispa отчеты по всей вашей пользовательской базе.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить, какие события AppsFlyer отправлять в Glispa через постбэки.

1. Включите переключатель «Постбэки по внутренним событиям приложения».
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного с вашим приложением, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Отправка данных о доходе** | **Если флажок не установлен** — партнеру отправляются все параметры насыщенного события в приложении, кроме параметра дохода, который содержится в параметре **af\_revenue**.  <br />**Если флажок установлен** — отправляются все параметры, включая значение дохода (если оно есть в событии). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создать ссылки атрибуции, которые вы хотите отправить в Glispa для атрибуции кампаний, групп объявлений и даже отдельных объявлений Glispa. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** - добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Glispa.  
  **Параметр ссылки атрибуции:** c
* **Adset** - задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Glispa.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** - задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Glispa.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить допустимое количество идентификаторов сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика для передачи полезных значений. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации данных или их фильтрации.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от клика до установки**. Только установки (первые запуски), которые произошли в пределах окна атрибуции, могут быть атрибутированы Glispa.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

[![](https://files.readme.io/72e192640be302ffede694bc264f1ce5746022242bfa441b29f835605a07004d-50706581523217.png)](https://files.readme.io/72e192640be302ffede694bc264f1ce5746022242bfa441b29f835605a07004d-50706581523217.png)

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте его в Glispa, чтобы он активировался, когда потенциальные клиенты нажимают на соответствующее объявление.

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. Glispa атрибутируются только те установки (первые запуски), которые произошли в рамках окна атрибуции после показа рекламы, при условии отсутствия других кликов по объявлению, относящихся к этой установке.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в Glispa для активации при просмотре соответствующего рекламного объявления, обычно в течение 1 секунды или более.

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

Эти переключатели позволяют предоставить Glispa права на самостоятельную настройку конфигурации для вашего приложения:

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

### Разрешения агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* ***Главный переключатель*** — установите в положение «Включено», чтобы получить доступ к параметрам разрешений для агентства
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным агентства об удержании
* ***Разрешить доступ к агрегированным органическим данным***
* ***Разрешить настройку постбэков по событиям в приложении*** — разрешить агентству настраивать сопоставление постбэков по событиям в приложении для себя на вкладке интеграции

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.

</Accordion>
