> **Кратко:** Leadbolt, партнер AppsFlyer по интеграции рекламной сети, — это высокоэффективная платформа мобильной рекламы для привлечения пользователей и монетизации в приложении. Помимо мобильной атрибуции по кликам, Leadbolt также предлагает атрибуцию по просмотрам, которую вы можете регистрировать с помощью AppsFlyer.

<Image alt="" src="https://cdn.appsflyer.com/marketplace/static/logo/leadbolt.png" width="172px" />

## Настройка интеграции с Leadbolt

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнера

При **первом посещении** здесь вам нужно перевести кнопку ***Активировать партнера*** в положение «Включено», чтобы включить настройку параметров вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

> 📘 **Примечание:**
>
> Как сеть ALL-Installs, Leadbolt предпочитает получать постбэки по всем новым установкам вашего приложения из ЛЮБОГО источника, включая органические. Чтобы отправлять в Leadbolt постбэки по всем установкам, выберите **События, атрибутированные любому партнеру**.

### Общие настройки

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение "Включено", если хотите атрибутировать установки по просмотрам из Leadbolt. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Leadbolt после установок приложения и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят только от пользователей, атрибутированных Leadbolt.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять Leadbolt отчеты о событиях всей вашей пользовательской базы.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события в AppsFlyer с событиями в Leadbolt и настроить отправку постбэков.

1. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определённые на стороне Leadbolt.  <br />Получите соответствующий идентификатор события в Leadbolt и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые нужно отправить в Leadbolt, чтобы атрибутировать кампании, группы объявлений или даже отдельные объявления Leadbolt. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнивать разные кампании в Leadbolt.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Leadbolt.  
  **Параметр ссылки атрибуции:** af\_adset
* **Название объявления** — задайте названия групп рекламных объявлений, чтобы сравнивать разные креативы в определенных группах рекламных объявлений в рамках конкретных кампаний Leadbolt.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить допустимое количество идентификаторов сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика для передачи полезных значений. Обратите внимание: эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от клика до установки**. Leadbolt атрибутируются только те установки (первые запуски), которые произошли в рамках окна атрибуции.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции кликов см. здесь</Anchor>.

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте его в Leadbolt, чтобы он активировался, когда потенциальные клиенты нажимают на соответствующее объявление.

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. Leadbolt атрибутируются только те установки (первые запуски), которые произошли в рамках этого окна атрибуции после показа рекламы, при условии отсутствия других релевантных кликов по объявлению.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в Leadbolt для активации при просмотре соответствующего рекламного объявления, обычно в течение 1 секунды или более.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для Leadbolt в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что, даже если атрибуция для Leadbolt отключена, вкладка разрешений остается активной и вы можете предоставить Leadbolt разрешение на управление.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Разрешить доступ к своим агрегированным данным о лояльных пользователях*** — только к собственным данным партнера о лояльных пользователях
* ***Разрешить доступ к своим агрегированным данным о событиях в приложении** —* только к собственным данным партнера о событиях в приложении
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
