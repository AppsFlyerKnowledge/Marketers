## Интеграция Hotstar в AppsFlyer

**Необходимые условия.** Если у вас нет аккаунта, перед настройкой интеграции свяжитесь с партнером, чтобы открыть его.

**Чтобы активировать интеграцию:**

1. В AppsFlyer перейдите на вкладку **Collaborate > Partner Integrations > Marketplace** .  
    **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. На вкладке **Интеграция** включите переключатель **Активировать партнера**.   
    **Примечание:** переключатель **должен оставаться включенным (активным), пока вы работаете с партнером**. Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробнее о <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner">партнерских интеграциях.</Anchor>

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

Подключитесь к Hotstar, активировав и задав параметры на вкладке интеграции.

**Чтобы настроить интеграцию**:

1. Включите **Активировать партнера.**
2. **В разделе** **General settings** **включите/отключите** **атрибуцию по просмотрам:**
   * [По умолчанию] **Включить**: активируйте, чтобы атрибутировать установки после просмотра Hotstar. Длина окна атрибуции настраивается на вкладке «Attribution link».
   * **Отключить**: установки по просмотрам от партнера не атрибутируются.
3. **Постбэки по умолчанию**: отправляйте постбэки в Hotstar после того, как пользователь установит приложение. В отчетность попадают только пользователи, атрибутированные Hotstar.
4. **Настройки событий в приложении**: чтобы отправлять постбэки, сопоставьте идентификаторы ваших событий в приложении с in-app ID Hotstar. Заполните параметры следующим образом:
   * Активируйте **постбэки по событиям в приложении**.
   * Параметр отправки: **в Hotstar можно отправлять только события, атрибутированные этому партнеру**.
   * Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие). Заполните параметры, как описано в следующей таблице.

| Название настройки | Description(Описание) |
| --- | --- |
| Имя события в SDK | Имя события, которое AppsFlyer получает из:<ul><li>SDK, интегрированный в приложение</li><li>Межсерверные события (S2S)</li></ul>**Совет:** если нужного события нет в списке, выполните неорганическую установку на устройстве, а затем проверьте еще раз. |
| Идентификатор события партнера | Уникальное имя события или идентификатор ID, заданный в Hotstar. Получите в Hotstar идентификатор события, соответствующий событию SDK, и вставьте его в текстовое поле. |
| Отправить доход | [По умолчанию] **Не включено:** отправляйте в Hotstar все параметры в приложении, кроме параметра дохода (`af_revenue`).<br /><br />**Включено**: отправляйте все параметры в приложении, включая, если доступно, сумму дохода. |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

Создавайте ссылки атрибуции для кликов и показов, которые будет использовать Hotstar. В следующей таблице объясняется разница между ссылкой для клика и ссылкой для показа, а также значимость окон атрибуции/лукбэк.

| Тип ссылки атрибуции | Активация ссылки | Окна атрибуции |
| --- | --- | --- |
| Клик | Потенциальный клиент нажимает на рекламу, размещенную Hotstar | **Окно атрибуции по кликам** — это **максимальное время от клика до установки**.<br /><br />Hotstar получает атрибуцию, если потенциальный клиент нажал на рекламу и установил приложение до истечения окна атрибуции.<br /><br />**Имя параметра**: `af_click_lookback`  <br />**Значение по умолчанию**: 7 дней  <br />**Диапазон:** 1–23 часа или 1–30 дней |
| Показ | Потенциальный клиент просматривает рекламу (не менее 1 секунды), размещенную Hotstar | Окно атрибуции по **просмотрам** — это **максимальное время от показа до установки**.<br /><br />Hotstar получает атрибуцию, если потенциальный клиент увидел (показ) приложение, а затем установил его до истечения окна атрибуции. Это применимо, если нет других релевантных кликов по рекламе.<br /><br />**Имя параметра**: `af_viewthrough_lookback`  <br />**Значение по умолчанию**: 1 день  <br />**Диапазон:** 1–23 часа или 1–7 дней |

<Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">Узнать больше о структуре ссылок и параметрах</Anchor>.

**Типичные параметры ссылок:**

| Параметр | Название параметра | Description(Описание) |
| --- | --- | --- |
| Доступно только в <Anchor target="_blank" href="/marketers/ru/docs/about-data-locker-advanced-reports">расширенных отчётах</Anchor>. | c | Название кампании |
| Блок рекламы | af\_adset | Название группы объявлений. Используется для различения групп объявлений в рамках кампании |
| **SDK**: Собрано с помощью SDK (пакет средств разработки ПО) в приложении. | af\_ad | Название конкретного рекламного объявления. Используется для различения креативов в группе объявлений |
| Доступно только в <Anchor target="_blank" href="/marketers/ru/docs/about-data-locker-advanced-reports">расширенных отчётах</Anchor>. | af\_siteid  <br />af\_sub\_siteid | Идентификатор ID паблишера, используемый для атрибуции установок конкретным паблишерам.<br /><br />**Полезный совет!** Если издателей много,<ul><li>Ограничьте количество используемых идентификаторов сайта.</li><li>Используйте параметр subsite ID, чтобы избежать <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">превышения лимита идентификатора ID сайта</Anchor>.</li></ul> |
| Параметры подписчика | af\_sub1–af\_sub5 | Используйте для вставки значений:<ul><li>Параметры анализируются и включаются в отчет о сырых данных.</li><li>Используйте их для агрегации или фильтрации данных.</li></ul> |

**Чтобы создать ссылки атрибуции**:

1. Выберите название в раскрывающемся списке **Название параметра**, затем задайте значение параметра.
2. Чтобы добавить дополнительные параметры, нажмите **Добавить параметр** и повторите предыдущий шаг.
3. Определите продолжительность окна атрибуции по кликам.
4. Определите продолжительность окна атрибуции по просмотрам.
5. Скопируйте ссылки атрибуции по кликам и показам, чтобы использовать их в своих кампаниях Hotstar.  
   **Примечание**: AppsFlyer не сохраняет партнерские ссылки.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

Вы можете предоставить Hotstar разрешение на просмотр информации или настройку изменений в интеграции. Тип разрешения зависит от связей с Hotstar в рамках деловых отношений (рекламная сеть/рекламное агентство).

**Примечание**: Hotstar можно предоставить разрешения, даже если активная интеграция с ним отсутствует.

<div id="ad-network-permissions" />

#### Ad Network Permissions (Разрешения для рекламной сети)

**Чтобы включить разрешения рекламной сети**:

1. Включите **разрешения рекламной сети**.
2. Предоставьте участникам команды Hotstar доступ к одному или нескольким из следующих пунктов:
   * **Разрешение настраивать интеграцию**: разрешить партнеру управлять настройками на вкладке интеграции (за исключением постбэков по внутренним событиям приложений).
   * **Разрешить настройку постбэков событий в приложении** - разрешить партнеру сопоставлять постбэки событий в приложении с собой на вкладке интеграции
   * **Предоставление доступа к отчету об удержании пользователей**: партнер получает доступ только к собственным данным об удержании пользователей.
   * **Разрешить доступ к вашим агрегированным данным о лояльных пользователях** - только к собственным данным партнера о лояльных пользователях
   * **Предоставить доступ к вашим агрегированным данным о событиях в приложении** - только к собственным данным партнера о событиях в приложении
   * **Предоставление доступа к агрегированным данным о доходе**: партнер получает доступ к данным только по атрибутированным ему доходам.
   * **Разрешить загрузку данных о расходах** — на уровне приложения.
   * **Разрешить доступ к дэшборду Protect360** — только к собственным данным Protect360 партнера, при условии что эта функция включена для рекламодателя.

</Accordion>
