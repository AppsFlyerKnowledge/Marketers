> **Краткий обзор:** InMobi — партнер AppsFlyer, интегрированная рекламная сеть, которая помогает пользователям находить новые продукты и услуги благодаря контекстным и тщательно подобранным рекомендациям на мобильных устройствах. Помимо мобильной атрибуции по кликам, InMobi также предлагает атрибуцию затрат, ретаргетинга и по просмотрам, данные которой можно регистрировать с помощью AppsFlyer.

## Настройка InMobi

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом посещении** этого раздела переведите кнопку **Активировать партнера** в положение «Включено», чтобы стала доступна настройка параметров вкладки интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
    Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

Окно конфигурации InMobi включает 4 активные вкладки: **Интеграция, Ссылка атрибуции, Стоимость** и **Разрешения**. Чтобы узнать больше о настройке вкладки, кликните по следующим пунктам.

<div id="tip" />

> 👍 **Совет.**
>
> * Этап <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#d-general-settings">Общие настройки</Anchor> на вкладке Интеграция необходимо **обязательно** выполнять для всех партнеров.
> * Все остальные этапы описаны только для сведения или же являются **необязательными**.

### Активация партнеров

При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации/деактивации партнеров</Anchor>.

<div id="note" />

> 📘 **Примечание**
>
> Как сеть ALL-Installs, InMobi предпочитает получать постбэки по всем новым установкам вашего приложения из любого источника, включая органические. Для этого выберите **События, атрибутированные любому партнеру**, чтобы отправлять в InMobi постбэки по всем установкам.

<div id="general-settings" />

### Общие настройки

**gpm\_ID**

InMobi подключается к AppsFlyer через уникальный идентификатор сети. Если у вас еще нет идентификатора сети, получите его в InMobi, чтобы продолжить интеграцию.

![Inmobi_msc_new_3.png](https://files.readme.io/9c2efaed833211582a33b3a2bbd7d07336bc78d6e2d4e3a7645b5ca14be2fd73-360001865845.png)

**Активация атрибуции по просмотрам**

Установите этот переключатель в положение «Включено», если хотите атрибутировать установки по просмотрам из InMobi. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в InMobi после установок приложения и повторного вовлечения пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, которые приходят только от пользователей, атрибутированных InMobi.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять InMobi отчеты о событиях всей вашей пользовательской базы.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с InMobi и настроить отправку постбэков.

1. Здесь снова задайте InMobi gpm\_id.
2. Включите переключатель «Постбэки по внутренним событиям приложения».
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
   **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне InMobi.  <br />Получите соответствующий идентификатор ID события в InMobi и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра выручки (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнить разные кампании, запущенные в InMobi.  
  **Параметр ссылки атрибуции:** c
* **Adset** — вы можете настроить названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках отдельных кампаний InMobi.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия рекламных объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках отдельных кампаний InMobi.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки конкретным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить допустимое количество идентификаторов сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

[![](https://files.readme.io/f026eec1923611f33be47d7ad3b1a8654f697145be30f552cef5578fe895944c-360002234165.png)](https://files.readme.io/f026eec1923611f33be47d7ad3b1a8654f697145be30f552cef5578fe895944c-360002234165.png)

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

<div id="retargeting-settings" />

### Настройки ретаргетинга

При активации этих настроек AppsFlyer распознает ссылку как ссылку атрибуции для <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide">ретаргетинга</Anchor>, а не как ссылку для привлечения пользователей, и добавляет к ссылке регистрации нажатий параметр `&is_retargeting=true`. Обратите внимание, что ретаргетинг в настоящее время поддерживается только для атрибуции по кликам, а для view-through атрибуции — нет.  
**Параметр ссылки атрибуции:** is\_retargeting.

Когда ретаргетинг активирован, отображаются следующие настройки.

![msc_new_7.png](https://files.readme.io/b90bbd6e3bea9dd862808343896b005071b7d9e564d31039c188c3ebf8e81077-360002254489.png)

1. Стандартная ссылка и ссылка OneLink

Вариант **стандартная ссылка атрибуции** следует выбирать в следующих случаях:

* URL-адрес не будет использоваться в качестве глубинной ссылки или
* Планируете использовать только <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#general-settings">схемы URI</Anchor> для диплинкинга

выберите **Использовать OneLink** для:

* Для приложений на Android и iOS используется одна и та же ссылка или
* Для диплинкинга используются универсальные ссылки или ссылки приложений

Обратите внимание, что при выборе OneLink ссылка для регистрации нажатий превращается из ссылки для конкретного приложения в <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">URL-адрес OneLink</Anchor>.

2. URL-адрес диплинка

Используйте это поле, если ссылка предназначена для прямого перехода пользователей к какой-либо конкретной активности в вашем приложении.  
**Параметр ссылки атрибуции:** af\_dp  
Подробные сведения о решении AppsFlyer для диплинкинга см. в <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">этом руководстве.</Anchor>

3. Окно повторного вовлечения

Задайте временной интервал после повторного вовлечения, в течение которого внутренние события приложения пользователя будут атрибутироваться медиа-источнику ретаргетинга. Вы можете задать ценность, значение в днях (1-90), часах (до 23) или даже на весь период.

**Параметр ссылки атрибуции:** af\_reengagement\_window

<div id="click-through-attribution" />

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от нажатия до установки**. К InMobi могут быть атрибутированы только те установки (первые запуски), которые произошли в пределах окна атрибуции.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте это в InMobi, чтобы активировать, когда лиды кликнут по соответствующей рекламе.

<div id="view-through-attribution-lookback-window" />

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. InMobi атрибутируются только те установки (первые запуски), которые произошли в рамках окна атрибуции после показа рекламы, при условии, что не было другого релевантного клика по рекламному объявлению.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

<div id="impressions-attribution-link" />

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте это в InMobi, чтобы активировать при просмотре соответствующей рекламы, обычно в течение 1 секунды или дольше.

</Accordion>
