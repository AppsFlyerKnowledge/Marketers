> **Краткий обзор.** Pinterest, интегрированный партнер AppsFlyer, является одним из основных источников трафика для блогеров и брендов. Pinterest предлагает мобильную атрибуцию как по кликам, так и по просмотрам. Кроме того, Pinterest также предлагает ретаргетинг по кликам, который можно записывать с помощью AppsFlyer.

> 📘 **Примечание**
>
> * Приняв Условия использования рекламы Pinterest, примите Правила и условия измерения мобильного трафика Pinterest <Anchor target="_blank" href="https://ads.pinterest.com/terms/app_install/">здесь</Anchor>.
> * Pinterest требует от поставщиков услуг атрибуции удалять свои данные уровня пользователей через <Anchor target="_blank" href="/marketers/ru/docs/user-level-data-retention#установленные-партнерами-сроки-хранения-данных">6 месяцев после установки</Anchor>. Это означает, что события этих пользователей, которые произошли через 6 месяцев после установки приложения, считаются органическими. Сводные данные за прошлое время не изменяются.
> * С 4 сентября 2023 года Pinterest требует от поставщиков услуг атрибуции <Anchor target="_blank" href="/marketers/ru/docs/about-raw-data-identifier-restrictions#ограничения-медиа-источников">ограничивать доступность некоторых полей в отчетах по необработанным данным</Anchor>, чтобы сохранить конфиденциальность пользователей и обеспечить соответствие нормативным требованиям.

## Настройка Pinterest

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнера

При **первом посещении** вам нужно включить переключатель **Активировать партнера**, чтобы начать настройку параметров вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

### Общие настройки

Ниже приведены общие настройки вкладки интеграции в Pinterest.

**Активация атрибуции по просмотрам**

Включите эту опцию, если хотите атрибутировать установки по просмотрам с Pinterest. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

**Обмен данными Advanced Matching**

Включите этот параметр, чтобы передавать в Pinterest поля Advanced Matching, такие как хешированный email, хешированный номер телефона, хешированное имя и хешированная фамилия, если эти поля включены в информацию о событии, отправляемую в AppsFlyer. Более подробную информацию см. здесь: <Anchor target="_blank" href="/marketers/ru/docs/advanced-matching-data-sharing">Обмен данными с расширенным сопоставлением</Anchor>.

### Настройки внутренних событий приложения

Чтобы отправлять в Pinterest постбэки по внутренним событиям приложения, необходимо ввести идентификатор тега. Эти учетные данные будут включены в постбэки событий, отправляемые в Pinterest.

* **Идентификатор рекламного аккаунта** — уникальный идентификатор вашего аккаунта Pinterest.
* **Токен доступа** - Токен доступа, созданный в Pinterest.

Идентификатор рекламного аккаунта и токен доступа можно найти непосредственно в интерфейсе Pinterest Ads Manager (см. [документацию Pinterest](https://developers.pinterest.com/docs/api-features/tracking-conversions/#getting-your-access-token-and-ad-account-id)).  Если вам нужна помощь, обратитесь в команду Pinterest.

**Укажите учетные данные Pinterest:**

1. В AppsFlyer на странице Pinterest **Активная интеграция** > вкладка **Интеграция** прокрутите до раздела **Настройки событий в приложении.**
2. Введите значения ID рекламного аккаунта и токена доступа в соответствующие поля.

#### Идентификатор тега

**Чтобы получить Tag ID и настроить постбэки событий в приложении:**

1. На странице **Конверсии** скопируйте **идентификатор тега**.  
   Нажмите кнопку **Create Tag** (Создать тег), если у вас еще нет тега, и завершите процесс создания. Скопируйте новый тег.
2. В AppsFlyer на странице Pinterest **Активная интеграция** > вкладка **Интеграция** прокрутите до раздела **Настройки событий в приложении** и введите Pinterest Tag ID.

| Имя параметра | Описание |
| --- | --- |
| <span id="appsflyer-event-name"></span>**Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br /> **Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| <span id="partner-event-name"></span>**Идентификатор события партнера** | Уникальное имя или идентификатор каждого события, определенный Pinterest.  <br /> Получите соответствующий идентификатор события в Pinterest и укажите его в текстовом поле. |
| <span id="to-users-from"></span>**Пользователям из** | <ul><li>**- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.</li><li>**- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.</li></ul> |
| <span id="including"></span>**преимущества** | Выберите, передается ли партнеру в постбэке доход от события или значения параметров, либо эти данные не включаются.<br /><br />**Флажок не установлен** — AppsFlyer отправляет партнеру все параметры внутреннего комплексного события приложения, за исключением параметра дохода (содержится в **af\_revenue**).  <br /> **Флажок установлен** — AppsFlyer отправляет все параметры, в том числе значение дохода (если применимо к событию). |

5. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).

#### Ссылка атрибуции для кампании ретаргетинга

Pinterest рекомендует использовать для кампаний ретаргетинга ссылки атрибуции в соответствии с ОС. Выберите опцию **Использовать одноплатформенную ссылку** и добавьте необходимые параметры в ссылку атрибуции ретаргетинга.

#### URL-адрес диплинка

> 📘 **Примечание**
>
> Диплинки, содержащиеся в пине, будут работать корректно только в том случае, если ваше приложение включено в список разрешений Pinterest.
> Обратитесь к представителю Pinterest или [отправьте электронное письмо по адресу apps@pinterest.com](mailto:apps@pinterest.com), чтобы получить доступ к диплинкингу.

Используйте это поле, если ссылка предназначена для прямого перехода пользователей к какому-либо конкретному действию в вашем приложении.

AppsFlyer получает информацию о затратах через API. Подробную информацию о поддерживаемых параметрах, метриках и функциях см. в <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">таблице интеграции затрат рекламной сети</Anchor>. **Примечание**: Для получения данных о затратах требуется подписка ROI360.

**Чтобы включить API данных о затратах**:

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#enable-cost-api">этим инструкциям по интеграции</Anchor>.

### Состояние синхронизации данных о расходах

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API данных о затратах</Anchor> и время, когда AppsFlyer получил соответствующие данные о затратах в последний раз, либо на дэшборде статуса интеграции затрат (и доходов от рекламы), либо на дэшборде отдельной рекламной сети.

### Остановка синхронизации расходов Pinterest

**Чтобы удалить связанный аккаунт:**

* <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#deleting-connected-accounts-in-the-cost-tab">В столбце действий наведите курсор на аккаунт и нажмите ***Удалить подключение***</Anchor>. После его удаления AppsFlyer перестанет получать данные о расходах. Удаление подключения не влияет на исторические данные.
