> **Краткий обзор.** VK Ads (Реклама ВКонтакте) — это платформа мобильной рекламы, ставящая целью связать рекламодателей с русскоязычными пользователями мобильных устройств. Используя VK Ads, рекламодатели могут размещать таргетированную рекламу в социальных сетях (ВКонтакте, Одноклассники, Мой мир) и на платформах группы Mail.Ru. Помимо мобильной атрибуции по кликам, VK Ads также предлагает атрибуцию ретаргетинга.

## Настройка VK Ads

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнеров

При **первом заходе** сюда вам нужно перевести кнопку ***Активация партнера*** в положение «Включено», чтобы настройка параметров вкладки интеграции стала возможной. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="app-id" />

### Идентификатор приложения

### Enable View-Through attribution (Активировать атрибуцию по просмотрам)

Включите, если вы хотите атрибутировать установки по просмотрам с Reddit. На вкладке [***Ссылка атрибуции***](/docs/vk-ads-mytarget-mail-ru-campaign-configuration#attribution-link-tab) имеется слайдер окна атрибуции по просмотрам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в VK Ads после установок приложений и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые приходят исключительно от пользователей, атрибутированных VK Ads.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять VK Ads отчеты о событиях всех пользователей, которые есть в вашей базе.

<div id="in-app-events-postbacks" />

### Постбэки внутренних событий приложений.

В этом разделе вы можете настроить отправляемые в VK Ads постбэки о внутренних событиях в приложении.

1. Активируйте ***In-app event postbacks*** (Постбэки о внутренних событиях).
2. Выберите, что следует отправлять партнеру: только **избранные события** или **все**.
   * Примечание. Если вы решите выполнять отчетность по всем событиям, событие *af\_app\_opened* не будет включено в отчетность.
3. Если вы хотите выбрать события вручную, нажмите ***Add event*** (Добавить событие), чтобы добавить в список события SDK.
4. Введите следующие параметры:

| Имя параметра | Описание |
| --- | --- |
| **SDK event name** *(Имя события SDK) (требуется только при выборе вручную)* | Имя события, полученное AppsFlyer из SDK или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, активируйте его на устройстве с неорганической установкой, и повторите поиск. |
| **Sending option (Вариант отправки)** | Выберите вариант отправки события:  <br />**Только от этого партнера** для событий, поступающих **только** от пользователей, атрибутированных VK Ads.  <br />**Все источники, включая органические**, чтобы партнер получал сведения о событиях всех пользователей, которые есть в вашей базе. |
| **Send event data (Отправить данные о событии)** | <ul><li>**Нет значений и нет дохода:** отправляет только само событие без значения.</li><li>**Значения, нет дохода:** отправляет все параметры, кроме значения дохода.</li><li>**Значения и доход**: отправляет все параметры события, включая значение дохода (если оно есть в событии).</li></ul> |

5. Нажмите кнопку ***Save*** (Сохранить)

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для VK Ads в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что, даже если атрибуция для VK Ads отключена, вкладка разрешений остается активной и вы можете предоставить VK Ads разрешение на управление.

Эти переключатели позволяют предоставить рекламной сети право самостоятельно выполнять настройки для вашего приложения:

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Allow to configure in-app event postbacks*** (Разрешить настройку постбэков внутренних событий приложений) — разрешить партнеру настраивать постбэки внутренних событий приложений и отображать эти настройки на вкладке интеграции
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate loyal user data*** (Разрешить доступ к своим сводным данным о лояльных пользователях) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate in-app events data*** (Разрешить доступ к своим сводным данным о внутренних событиях приложения) — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
