> **Краткий обзор:** YouAppi, интегрированный партнер рекламной сети AppsFlyer, — ведущая платформа мобильного маркетинга роста для премиум-брендов мобильных приложений. Помимо мобильной атрибуции по кликам YouAppi также предлагает атрибуцию стоимости, дохода от рекламы, ретаргетинга и атрибуцию по просмотрам, которую можно регистрировать с помощью AppsFlyer.

Чтобы настроить кампании с использованием YouAppi, выполните следующие действия.

<div id="setting-up-youappi" />

## Настройка YouAppi

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

В конфигурации YouAppi есть 4 активные вкладки: Интеграция, Ссылка атрибуции, Стоимость и Разрешения. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

<div id="tip" />

> 👍 **Совет.**
>
> * Этап <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#d-general-settings">Общие настройки</Anchor> на вкладке интеграции необходимо **обязательно** выполнять для всех партнеров.
> * Все остальные этапы описаны только для сведения или же являются **необязательными**.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

<div id="activate-partner" />

### Активация партнера

При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации/деактивации партнеров</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть ALL-Installs, YouAppi предпочитает получать постбэки по всем новым установкам вашего приложения из ЛЮБОГО источника, включая органические. Чтобы отправлять в YouAppi постбэки по всем установкам, выберите **События, атрибутированные любому партнеру**.

<div id="general-settings" />

### Общие настройки

**trackerToken**

YouAppi подключается к AppsFlyer через trackerToken. Если у вас еще нет trackerToken, получите его в YouAppi, чтобы продолжить интеграцию.

**Активация атрибуции по просмотрам**

Переведите переключатель в положение "Включено", если хотите атрибутировать установки по просмотрам из YouAppi. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в YouAppi после установок приложения и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, которые приходят только от пользователей, атрибутированных YouAappi.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять YouAppi отчеты о событиях всех пользователей, которые есть в вашей базе.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события в AppsFlyer с YouAppi и настроить отправку постбэков.

1. Снова введите trackerToken.
2. Активируйте постбэки по внутренним событиям.
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
   **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне YouAppi.  <br />Получите соответствующий идентификатор события ID в YouAppi и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые нужно передать YouAppi для атрибуции кампаний YouAppi, групп объявлений и даже отдельных рекламных объявлений. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** — добавьте, чтобы сравнивать разные кампании, запущенные в Youappi.  
  **Параметр ссылки атрибуции:** c
* **Набор объявлений** — задайте название группы объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Youappi.  
  **Параметр ссылки атрибуции:** af\_adset
* **Название объявления** — задайте название объявления, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Youappi.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки конкретным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить допустимое количество идентификаторов сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика для передачи полезных значений. Обратите внимание: эти параметры парсятся и отображаются в Отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

<div id="click-through-attribution" />

### Атрибуция по кликам

На этой шкале можно задать **максимальное время от клика до установки**. К YouAppi атрибутируются только те установки (первые запуски), которые произошли в пределах окна атрибуции.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об окне атрибуции по кликам <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в YouAppi, чтобы она активировалась, чтобы он активировался, когда потенциальные клиенты нажимают на соответствующее объявление.

<div id="view-through-attribution-lookback-window" />

### Окно лукбэк на основе просмотров

На этой шкале можно задать **максимальное время от показа до установки**. К YouAppi атрибутируются только те установки (первые запуски), которые произошли в рамках этого окна атрибуции после показа рекламы, при условии отсутствия других релевантных кликов по объявлению.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7).

**Параметр ссылки атрибуции:** af\_viewthrough\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">атрибуции по просмотрам см. здесь</Anchor>.

<div id="impressions-attribution-link" />

### Ссылка на атрибуцию показов

Ссылка атрибуции показа содержит такие же данные атрибуции, как и ссылка регистрации кликов (за исключением другого окна атрибуции). Отправьте ее в YouAppi, чтобы она активировалась при просмотре соответствующего рекламного объявления, обычно в течение 1 секунды или более.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для YouAppi в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что, даже если атрибуция для YouAppi отключена, вкладка разрешений остается активной и вы можете предоставить YouAppi разрешение на управление.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

<div id="ad-network-permissions" />

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Allow to configure in-app event postbacks*** (Разрешить настройку постбэков внутренних событий приложений) — разрешить партнеру настраивать постбэки внутренних событий приложений и отображать эти настройки на вкладке интеграции
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

<div id="agency-permissions" />

### Разрешения агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* ***Главный переключатель*** — установите в положение «Включено», чтобы открыть параметры разрешений для агентства
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным агентства об удержании пользователей
* ***Разрешить доступ к агрегированным органическим данным***
* ***Разрешить настройку постбэков событий в приложении*** — разрешить агентству настраивать сопоставление постбэков событий в приложении на вкладке интеграции с самим собой

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.

</Accordion>
