> **Кратко:** Sojern for Advertisers — интегрированный партнер AppsFlyer в категории рекламных сетей, специализирующийся на программатик-закупках для туристического рынка.

Чтобы настроить ваши кампании в Sojern for Advertisers, выполните следующие действия.

<div id="setting-up-sojern-for-advertisers" />

## Настройка Sojern for Advertisers для рекламодателей

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнера

При **первом посещении** вам нужно включить переключатель ***Активировать партнера***, чтобы открыть возможность настройки параметров интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть, ориентированная на все установки, Sojern for Advertisers предпочитает получать постбэки обо всех новых установках вашего приложения из любого источника, включая органические установки. Чтобы отправлять в Sojern for Advertisers постбэки по всем установкам, выберите **События, атрибутированные любому партнеру**.

<div id="general-settings" />

### Общие настройки

**Partner ID (Идентификатор партнера)**

Sojern for Advertisers подключается к AppsFlyer через уникальный идентификатор партнера ID. Если у вас еще нет идентификатора партнера, чтобы продолжить интеграцию, его нужно получить в Sojern for Advertisers.

### Постбэки по умолчанию

Автоматически отправляйте в Sojern for Advertisers постбэки после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, которые поступают только от пользователей, атрибутированных Sojern for Advertisers.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы вся ваша база пользователей была доступна для отчетности в Sojern for Advertisers.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе вы можете сопоставить события AppsFlyer с событиями Sojern for Advertisers с помощью постбэков.

1. Снова введите идентификатор партнера Sojern for Advertisers.
2. Включите переключатель «Постбэки по внутренним событиям приложения».
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие SDK, нажмите **Добавить событие**.  
   Подробнее о событиях в приложении Sojern for Advertisers читайте здесь.
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Sojern for Advertisers.  <br />Получите соответствующий идентификатор события в Sojern for Advertisers и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

На этой вкладке можно создавать ссылки атрибуции, которые вы хотите отправить в Sojern for Advertisers для атрибуции кампаний, групп объявлений или даже отдельных объявлений. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Sojern for Advertisers.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Sojern for Advertisers.  
  **Параметр ссылки атрибуции:** af\_adset
* **Название объявления** — задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Sojern for Advertisers.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить допустимое количество идентификаторов сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Параметры подписчика** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. Только установки (первые запуски), выполненные в пределах окна атрибуции, могут быть атрибутированы Sojern for Advertisers.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам читайте здесь</Anchor>.
