> **Краткий обзор.** Рекламная сеть RTB House, интегрированный партнер AppsFlyer, предоставляет технологии ретаргетинга для компаний электронной коммерции и игрового бизнеса. Компания RTB House разработала собственное решение для ретаргетинга, основанное на алгоритмах глубокого обучения, для покупки онлайн-рекламы в модели ставок в реальном времени. В дополнение к мобильной атрибуции на основе кликов, RTB House предлагает атрибуцию ретаргетинга, которую можно записывать в AppsFlyer.

<div id="setting-up-rtb-house" />

## Настройка RTB House

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. На вкладке **Интеграция** включите переключатель **Активировать партнера**.  
    **Примечание.** Этот переключатель должен быть <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активирован</Anchor> все время, пока вы работаете с этим партнёром.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

Окно конфигурации RTB House включает в себя 3 активные вкладки: Интеграция, Ссылка атрибуции, Разрешения. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

<div id="tip" />

> 👍 **Совет**
>
> * Этап <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#d-general-settings">Общие настройки</Anchor> на вкладке Интеграция необходимо **обязательно** выполнять для всех партнеров.
> * Все остальные этапы описаны только для сведения или же являются **необязательными**.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

<div id="activate-partner" />

### Активация партнера

При **первом посещении** этого раздела вам нужно будет включить опцию **Активировать партнера**, чтобы можно было настроить параметры интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="default-postbacks" />

### Постбэки по умолчанию

Отправляйте автоматические постбэки в RTB House после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть, ориентированная на все установки, RTB House предпочитает получать постбэки для всех новых установок вашего приложения из любого источника, включая органические. Чтобы отправлять в RTB House постбэки по всем установкам, выберите **События, атрибутированные любому партнеру**.

<div id="in-app-events-settings" />

### Настройки внутренних событий приложения

В этом разделе можно сопоставить события в AppsFlyer с событиями в RTB House и настроить отправку постбэков.

<div id="region" />

#### Регион

Укажите регион, в котором находится центр обработки данных RTB House. Возможные варианты: **ЕМЕА**, **США**, **Азия**.

<div id="in-app-event-postback-settings" />

#### Настройки постбэков по внутренним событиям приложений

1. Активируйте Постбэки по внутренним событиям приложения.
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Описание |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор каждого события, определенные в RTB House.  <br />Получите соответствующий идентификатор события из RTB House и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

Вы можете использовать либо ссылку для конкретной платформы, либо <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">OneLink</Anchor>.  
<Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">Подробнее о структуре и параметрах ссылок атрибуции</Anchor>.

**Чтобы создать ссылку атрибуции,** следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#attribution-link-tab">этой инструкции</Anchor>.

</Accordion>

</Accordion>

<div id="ad-revenue-tab" />

<Accordion title="Вкладка «Доходы от рекламы»">

Доход от рекламы не поддерживается при интеграции с этим партнером.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для RTB House в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что даже если атрибуция отключена для RTB House, вкладка разрешений остается активной, и вы можете предоставить RTB House права управления.

<div id="ad-network-permissions" />

### Разрешения для рекламной сети

Эти переключатели позволяют предоставить рекламной сети право самостоятельно выполнять настройки для вашего приложения:

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Разрешить настройку постбэков внутренних событий приложений*** — разрешить партнеру настраивать постбэки внутренних событий приложений и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к дэшборду Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
