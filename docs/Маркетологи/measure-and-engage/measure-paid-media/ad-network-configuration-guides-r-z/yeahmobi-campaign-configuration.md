> **Краткий обзор:** Yeahmobi, интегрированный партнер рекламной сети AppsFlyer, — это рекламная видеосеть для iOS и Android. Помимо мобильной атрибуции на основе кликов, Yeahmobi предоставляет данные о затратах, которые можно регистрировать в AppsFlyer.

Чтобы настроить кампании с использованием Yeahmobi, выполните следующие действия.

## Настройка Yeahmobi

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<Accordion title="Вкладка «Интеграция»">

### Активация партнеров

При **первом посещении** вам нужно перевести кнопку ***Активировать партнера*** в положение «Включено», чтобы включить настройку параметров вкладки интеграции. Этот переключатель **должен** быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

### Постбэки по умолчанию

Отправляйте автоматические постбэки в Yeahmobi после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутируемые этому партнеру** для событий, поступающих только от пользователей, атрибутированных Yeahmobi.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы обеспечить передачу отчетности в Yeahmobi по всем пользователям из вашей базы.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с событиями Yeahmobi через постбэки.

1. Активируйте постбэки по внутренним событиям.
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
   **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всей вашей базы пользователей.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Add Event** (Добавить событие).
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из событий «сервер—сервер».  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Yeahmobi.  <br />Получите соответствующий идентификатор события в Yeahmobi и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые вы хотите отправить в Yeahmobi для атрибуции кампаний Yeahmobi, групп объявлений или даже отдельных рекламных объявлений. Обратите внимание, что AppsFlyer **не** сохраняет созданные вами ссылки атрибуции партнера.

На этой вкладке есть несколько разделов:

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Кампания** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Yeahmobi.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках конкретных кампаний Yeahmobi.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия рекламных объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках конкретных кампаний Yeahmobi.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки конкретным паблишерам. При наличии большого количества паблишеров рекомендуем ограничить количество используемых идентификаторов Site ID и использовать параметр Sub Site ID, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить ограничения по Site ID</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика для вставки полезных значений. Обратите внимание: эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. Только установки (первые запуски), которые произошли в пределах окна атрибуции, могут быть атрибутированы Yeahmobi.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции кликов см. здесь</Anchor>.

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в Yeahmobi, чтобы она активировалась, когда потенциальные клиенты нажимают на соответствующее объявление.

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения, предоставляемые партнеру, в зависимости от того, в каком качестве он действует: рекламной сети, агентства или в обоих. Обратите внимание на то, что, даже если атрибуция для партнера отключена, вкладка разрешений остается активной и вы можете предоставить партнеру разрешение на управление.

### Ad Network Permissions (Разрешения для рекламной сети)

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Allow to configure in-app event postbacks*** (Разрешить настройку постбэков внутренних событий приложений) — разрешить партнеру настраивать постбэки внутренних событий приложений и отображать эти настройки на вкладке интеграции
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим агрегированным данным о лояльных пользователях*** — только к собственным данным партнера о лояльных пользователях
* ***Разрешить доступ к своим агрегированным данным о событиях в приложении** —* только к собственным данным партнера о событиях в приложении
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

### Разрешения агентства

Эти переключатели позволяют предоставить агентству право самостоятельно выполнять настройки для вашего приложения:

* ***Главный переключатель*** — установите в положение «Включено», чтобы открыть параметры разрешений для агентства
* ***Разрешить настройку постбэков по событиям в приложении*** — разрешить агентству настраивать сопоставление постбэков по событиям в приложении с собой на вкладке интеграции
* ***Разрешить доступ к агрегированным органическим данным***
* ***Разрешить доступ к отчету об удержании*** — доступ предоставляется только к собственным данным агентства об удержании

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.

</Accordion>
