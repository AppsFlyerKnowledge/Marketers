> **Краткий обзор:** Vungle, интегрированный партнер рекламной сети AppsFlyer, предлагает платформу видеорекламы в приложении для специалистов по маркетингу эффективности. Помимо мобильной атрибуции по кликам, Vungle также предлагает атрибуцию затрат и атрибуцию по просмотрам, данные которых можно регистрировать в AppsFlyer.

<Image alt="" src="https://cdn.appsflyer.com/marketplace/static/logo/vungle.png?v=1" width="91px" />

## Настройка Vungle

**Необходимые условия.** Если у вас нет аккаунта, перед настройкой интеграции свяжитесь с партнером, чтобы открыть его.

**Чтобы активировать интеграцию:**

1. В AppsFlyer перейдите на вкладку **Collaborate > Partner Integrations > Marketplace**.  
    **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. На вкладке **Интеграция** включите переключатель **Активировать партнера**.   
    **Примечание:** переключатель **должен оставаться включенным (активным), пока вы работаете с партнером**. Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе. Узнайте больше о <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner">партнерских интеграциях.</Anchor>

> 👍 **Совет**
>
> * Этап <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#d-general-settings">Общие настройки</Anchor> на вкладке Интеграция необходимо **обязательно** выполнять для всех партнеров.
> * Все остальные этапы описаны только для сведения или же являются **необязательными**.

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

### Активация партнеров

Подключите Vungle, активировав интеграцию и задав параметры на вкладке интеграции. Для подключения к AppsFlyer Vungle должен предоставить свой уникальный идентификатор сети ***app\_id***.

> 📘 **Примечание**
>
> Как сеть, ориентированная на все установки, Vungle предпочитает получать постбэки по всем новым установкам вашего приложения из любого источника и рекомендует выбрать **Все медиаисточники, включая органические**, чтобы отправлять в Vungle все постбэки по установкам.

**Чтобы настроить интеграцию**:

1. Включите ***Активировать партнера***. Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации партнера</Anchor>.
2. **В разделе *Общие настройки* включите или отключите *атрибуцию по просмотрам*:**
   * [По умолчанию] **Включено**: активируйте, чтобы атрибутировать установки после просмотра в Vungle. Длина окна атрибуции настраивается на вкладке «Ссылка атрибуции».
   * **Отключить**: установки по просмотрам от этого партнера не атрибутируются.
3. ***Постбэки по умолчанию***: отправляйте постбэки в Vungle после установок и повторных вовлечений пользователей. Используйте этот раздел, чтобы определить пользователей, которые будут источником этих постбэков. В разделе ***Параметр отправки***

   * Выберите **Только события, атрибутируемые этому партнеру** для событий, атрибутированных пользователям Vungle.
   * Выберите **События, атрибутируемые любому партнеру или органические**, чтобы сделать всю вашу базу пользователей доступной для отчетности в Vungle.
4. ***Настройки* *событий в приложении***: чтобы отправлять постбэки в Vungle, сопоставьте идентификаторы событий в приложении с идентификаторами Vungle. Настройте параметры следующим образом:
   * Введите Vungle app\_id.
   * Включите ***постбэки событий в приложении***.
   * Выберите ***вариант отправки***.
   * Чтобы добавить в список событие, определенное в SDK, нажмите ***Добавить событие***. Заполните параметры, как описано в следующей таблице.

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из:<ul><li>SDK, интегрированный в приложение</li><li>Межсерверные события (S2S)</li></ul>**Совет:** если нужного события нет в списке, выполните неорганическую установку на устройстве, а затем проверьте еще раз. |
| **Идентификатор события партнера** | Уникальное имя события или идентификатор ID, заданный Vungle.<br /><br />Получите в Vungle идентификатор ID события, соответствующий вашему событию SDK, и вставьте его в текстовое поле. |
| **Отправить доход** | [По умолчанию] **Не включено:** отправляет все параметры событий в приложении в Vungle, кроме параметра дохода (`af_revenue`).<br /><br />**Включено**: отправляет все параметры событий в приложении, включая сумму дохода, если она доступна. |

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

Вы можете предоставить Vungle разрешение на просмотр информации или изменение настроек интеграции. Тип разрешения зависит от ваших бизнес-отношений с Vungle (рекламная сеть/рекламное агентство).

**Примечание**: Vungle можно предоставить разрешения, даже если с ними нет активной интеграции.

### Ad Network Permissions (Разрешения для рекламной сети)

**Чтобы включить разрешения для рекламной сети:**

1. Включите ***разрешения для рекламной сети***.
2. Предоставьте участникам команды Vungle доступ к одному или нескольким из следующих разделов:

| **Allow to configure integration (Разрешение настраивать интеграцию)** | Настройте вкладку интеграции (кроме постбэков событий в приложении). |
| --- | --- |
| Разрешение настраивать постбэки по событиям внутри приложения | Настройте постбэки событий в приложении, сопоставленные с вкладкой интеграции. |
| Allow access to your retention report (Предоставление доступа к отчету об удержании пользователей) | Данные об удержании пользователей партнера |
| Allow access to your aggregate loyal users data (Предоставление доступа к агрегированным данным о лояльных пользователях) | Данные партнера о лояльных пользователях |
| Allow access to your aggregate in-app events data (Предоставление доступа к агрегированным данным о внутренних событиях приложения) | Данные партнера о событиях в приложении |
| Allow access to your aggregate revenue data (Предоставление доступа к агрегированным данным о доходе) | Данные о доходе, атрибутированном партнёру. |
| Allow spend ingestion (Разрешение импорта данных о расходах) |  |
| Allow access to your Protect360 dashboard (Разрешить доступ к панели управления Protect360) | [Если включено] Данные партнера Protect360 |

Узнайте больше о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

### Разрешения агентства

Вы можете разрешить Vungle настроить ваше Приложение как агентство.

**Чтобы включить разрешения для агентства:**

1. Включите ***разрешения*** **для агентства**.
2. Предоставьте Vungle как агентству доступ к одному или нескольким из следующих элементов:

| **Allow access to your Protect360 dashboard (Разрешить доступ к панели управления Protect360)** | [Если включено для вашего аккаунта] Данные агентства Protect360 |
| --- | --- |
| **Allow access to your retention and cohort reports (Предоставление доступа к отчетам об удержании пользователей и когортным отчетам)** | Данные агентства об удержании пользователей и когортах |
| **Разрешить доступ к агрегированным органическим данным** | Агрегированные органические данные агентства |
| **Разрешение настраивать постбэки по событиям внутри приложения** | Настройка постбэков событий в приложении, сопоставленных со вкладкой интеграции. |

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">разрешений для агентства</Anchor>.

</Accordion>
