> **Краткий обзор:** Spotify — рекламная сеть, интегрированный партнер AppsFlyer, которая использует свое усовершенствованное решение для мобильной рекламы, чтобы создавать стратегические, масштабируемые и интеллектуальные кампании, отвечающие потребностям мобильных пользователей. В Spotify клики генерируются, когда пользователь нажимает кнопку CTA во время просмотра или прослушивания рекламы.

## Настройка Spotify

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. Переключатель должен оставаться во включенном положении все время, которое вы работаете с Medialyzer. Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации партнеров</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже.

Узнайте больше о <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">заголовке окна конфигурации партнера</Anchor>.

Подробнее о <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation#активировать-интеграцию-партнера">правилах активации партнера</Anchor>.

### Общие настройки

**Активация атрибуции по просмотрам**

Если вы хотите атрибутировать установки по просмотрам из Spotify, включите этот переключатель. Чтобы задать окно атрибуции по просмотрам, перейдите на вкладку «Ссылка атрибуции» (описано ниже).

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

У Spotify есть серверная интеграция с AppsFlyer, поэтому ссылки атрибуции не используются для измерения кампаний. Если при настройке кампании Spotify вы выберете свое приложение в качестве источника измерения конверсий, интеграция с AppsFlyer активируется автоматически, а Spotify будет отправлять в AppsFlyer данные о показах и кликах вместе с необходимыми идентификаторами для атрибуции.

</Accordion>

<div id="cost-tab" />

<Accordion title="Вкладка «Стоимость»">

Интеграция расходов недоступна для Spotify.

</Accordion>

<div id="ad-revenue-tab" />

<Accordion title="Вкладка «Доходы от рекламы»">

Доход от рекламы недоступен для Spotify.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для Spotify в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание: даже если атрибуция для Spotify отключена, вкладка разрешений остается активной, и вы можете предоставить Spotify контроль.

После того как вы включите предоставление разрешений Spotify, вы можете добавить членов команды, чтобы предоставить им доступ к данным в соответствии с выбранными разрешениями.  
Разрешения могут быть предоставлены только сотрудникам Spotify, у которых есть аккаунт участника команды рекламной сети в AppsFlyer.  
**Чтобы предоставить разрешения членам команды рекламной сети:**

1. Нажмите **Добавить участника команды.**
2. Введите адрес электронной почты члена команды рекламной сети.
3. Нажмите **Добавить**.

<div id="important-1" />

> 🚧 **Важно!**
>
> * Когда вы предоставляете Spotify разрешения на настройку интеграции и изменение постбэков по событиям в приложении, вы позволяете им потенциально получить доступ ко всем событиям атрибуции, включая органический и неорганический трафик из всех медиаисточников.
> * Изменения, которые вносит Spotify, переопределяют текущую конфигурацию, даже если ее задал рекламодатель.

Ниже перечислены типы разрешений, которые рекламодатели могут предоставить Spotify:

* **Разрешить настраивать интеграцию** — разрешить партнеру настроить вкладку интеграции (за исключением постбэков по событиям в приложении).
* **Разрешить настраивать постбэки по событиям в приложении** — разрешить партнеру настроить сопоставление постбэков по событиям в приложении для себя на вкладке интеграции.
* **Разрешить доступ к вашему отчету об удержании** — только к собственным данным партнера об удержании.
* **Разрешить доступ к вашим агрегированным данным о лояльных пользователях** — только к собственным данным партнера о лояльных пользователях.
* **Разрешить доступ к вашим агрегированным данным о событиях в приложении** - только к собственным данным партнера о событиях в приложении.
* **Разрешить доступ к вашим агрегированным данным о доходе** — только к данным о доходе, атрибутированном партнеру.
* **Разрешить доступ к вашему дэшборду Protect360 & сырым данным через API** — только к собственным данным Protect360 партнера и при условии, что функция включена для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
