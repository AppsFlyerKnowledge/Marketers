> **Кратко:** Yahoo, интегрированный партнер AppsFlyer среди рекламных сетей, предлагает поисковую и нативную рекламу на одной рекламной платформе. Помимо мобильной атрибуции по кликам Yahoo также предлагает атрибуцию по стоимости и атрибуцию по просмотрам, которые можно регистрировать в AppsFlyer.

<div id="setting-up-yahoo" />

## Настройка Yahoo

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

> 👍 **Совет.**
>
> Этап <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#d-general-settings">Общие настройки</Anchor> на вкладке интеграции **обязателен**. Все остальные шаги носят описательный характер или являются **необязательными**.

<div id="click-through-attribution" />

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. К Yahoo атрибутируются только те установки (первые запуски), которые произошли в пределах окна атрибуции.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 30). Мы рекомендуем установить значение окна атрибуции по кликам на 7 дней, что соответствует стандартному значению этого параметра в Yahoo.

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне атрибуции по кликам см. здесь</Anchor>.

**Активация атрибуции по просмотрам**

Включите эту опцию, если хотите атрибутировать установки по просмотрам с Yahoo. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

Это значение можно задать в часах (от 1 до 23) или в днях (от 1 до 7). Мы рекомендуем установить окно атрибуции по просмотрам на 1 день, чтобы это соответствовало Yahoo.

<div id="agency-configuration" />

### Настройки для агентств

Прежде чем начать работать с Yahoo, рекламодатель должен активировать интеграцию со своей стороны, иначе конверсии нельзя будет атрибутировать вам.

Для вашей учетной записи Yahoo введите идентификатор учетной записи Yahoo. Для Yahoo DSP введите идентификатор рекламодателя.

**Примечание.**

* Если и рекламодатель, и агентство продвигают приложение в Yahoo, им нужно использовать отдельные учетные записи Yahoo.
* Агентство может использовать в Yahoo только одну учетную запись.

Чтобы найти идентификатор ID аккаунта, войдите в дэшборд Yahoo, нажмите значок шестерёнки, чтобы открыть меню ***Settings***, и выберите ***Billing***:

![gemini-account-number.png](https://files.readme.io/77f464c6dadefc54acb3a84d97ab0d0751610b253d2da90523bc117f1f26683c-50705625726865.png)

Окна атрибуции по кликам и просмотрам доступны только для чтения и должны настраиваться рекламодателем.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события AppsFlyer с Yahoo с помощью постбэков.

1. Введите идентификатор Dot Tag, предоставленный Yahoo.  
   Чтобы найти его на дэшборде Yahoo, кликните значок шестерёнки, чтобы открыть меню **Settings**, и выберите **View Dot tag code**. Скопируйте код с дэшборда:

   [![yahoo-dot-tag.png](https://files.readme.io/6ceaea7447d1c3a81451dac3aa7c3c3063a5cf2c0051b4dfad6cf7aeba40ab24-small-50705593680401.png)](https://files.readme.io/6ceaea7447d1c3a81451dac3aa7c3c3063a5cf2c0051b4dfad6cf7aeba40ab24-small-50705593680401.png)
2. Активируйте постбэки по внутренним событиям
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Название события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Yahoo.  <br />Получите соответствующий идентификатор ID события в Yahoo и задайте его в текстовом поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

**Примечание.**

Для агентств параметр ***Sending option*** и список событий, доступных для маппинга, зависят от разрешений, предоставленных агентству рекламодателем.

### Включение и тестирование интеграции стоимости Yahoo

Интеграция затрат предоставляет следующие агрегированные данные:

* Данные о стоимости для ваших кампаний, групп объявлений, рекламы и гео/стран. Подробную информацию о поддерживаемых параметрах, метриках и функциях см. в таблице <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">интеграции затрат рекламной сети</Anchor>.  
  **Примечание:** Для получения данных о затратах требуется подписка на <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview?query=xpend">ROI360</Anchor>.
* Данные о кликах, показах и расширенные данные (ключевые слова, названия кампаний и группы объявлений).

**Чтобы включить API данных о затратах**:

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#enable-cost-api">этим инструкциям по интеграции</Anchor>.

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API стоимости</Anchor> и время, когда AppsFlyer в последний раз удалось получить соответствующие данные о стоимости либо на дэшборде статуса интеграции стоимости (и доходов от рекламы), либо на дэшборде отдельной рекламной сети.

<div id="warning" />

> ❗️ **Предупреждение**
>
> После настройки стоимости Yahoo не изменяйте название какой-либо запущенной кампании, группы объявлений или отдельного объявления, так как это может привести к серьёзным расхождениям или отсутствию данных о стоимости.

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

В этой вкладке вы можете выбрать разрешения, которые хотите предоставить Yahoo. Обратите внимание, что, даже если атрибуция для Yahoo отключена, вкладка разрешений остаётся активной, и вы можете предоставить Yahoo контроль.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Allow to configure in-app event postbacks*** (Разрешить настройку постбэков внутренних событий приложений) — разрешить партнеру настраивать постбэки внутренних событий приложений и отображать эти настройки на вкладке интеграции
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate loyal user data*** (Разрешить доступ к своим сводным данным о лояльных пользователях) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate in-app events data*** (Разрешить доступ к своим сводным данным о внутренних событиях приложения) — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированным партнеру
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
