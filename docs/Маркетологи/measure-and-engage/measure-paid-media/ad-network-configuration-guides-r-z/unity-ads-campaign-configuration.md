> **Краткий обзор.** Unity Ads, интегрированный партнер рекламной сети AppsFlyer, — это рекламная видеосеть для iOS и Android. Помимо мобильной атрибуции по кликам, Unity Ads также предлагает атрибуцию затрат, дохода от рекламы и атрибуцию по просмотрам, данные которых можно регистрировать в AppsFlyer

Чтобы настроить кампании с использованием Unity Ads, выполните следующие действия.

## Настройка Unity Ads

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Активация партнеров

При первом входе вам нужно включить переключатель **Активация партнера**, чтобы настроить интеграцию. Переключатель должен оставаться во включенном положении все время, которое вы работаете с данным партнером.  
Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

### Общие настройки

**Передача идентификатора устройства (рекламного идентификатора) в Unity**

В верхней части вкладки Интеграция есть примечание о том, что Unity Ads требует передачи идентификатора устройства для каждой установки—это происходит автоматически, вам ничего не нужно делать.

[![Unity_msc_new_2.png](https://files.readme.io/4291f0b69f8231f6644872f2dfaec84e7c93047e81f653e76ff7266387fa10a9-360002583918.png)](https://files.readme.io/4291f0b69f8231f6644872f2dfaec84e7c93047e81f653e76ff7266387fa10a9-360002583918.png)

**Идентификатор игры Unity Ads**

Unity Ads требует подключения к AppsFlyer посредством уникального идентификатора игры. Если вы не знаете свой идентификатор, вы можете получить его непосредственно из Unity Ads или найти его после загрузки игры в разделе **Apps** (Приложения) > **Campaigns** (Кампании), как показано на скриншоте ниже.

[![](https://files.readme.io/c3315765f33e957b82c39b638bb8113e207bfe80f242bf2e6dde3dce30287a6f-8109147574673.png)](https://files.readme.io/c3315765f33e957b82c39b638bb8113e207bfe80f242bf2e6dde3dce30287a6f-8109147574673.png)

Платформа Unity Ads сопоставляет одно приложение с одним идентификатором игры Unity Ads на уровне аккаунта (рекламодатели и агентства будут иметь разные идентификаторы игры для одного и того же приложения). Несколько аккаунтов на платформе Unity Ads не могут запускать одно и то же приложение с разными идентификаторами игры.

**Активация атрибуции по просмотрам**

Включите эту опцию, чтобы атрибутировать установки по просмотрам из Unity Ads. На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

![Unity_ads_msc_new_3.png](https://files.readme.io/fab459ace7e8f1354d3bbfbca8ddefcd11376b7426a8e361abfab1b42b623880-360001875405.png)

### Постбэки по умолчанию

![Screen_Shot_2022-07-28_at_13.07.25.png](https://files.readme.io/a571ddc49e490373b34144e34626a18c6c18908cec3345cd7ac70c49aa855c05-7975491293329.png)

Автоматически отправляйте постбэки в Unity Ads после установки приложений и повторного вовлечения. В этом разделе можно определить источник пользователей, который позволяет отправлять постбэки.

* **Только этот партнер**: для событий, поступающих только от пользователей, атрибутированных Unity Ads.
* **Все медиа-источники и органический трафик**: чтобы передавать в Unity Ads отчеты о событиях всех пользователей, которые есть в вашей базе.

> 📘 **Примечание**
>
> Как сеть, ориентированная на все установки, Unity Ads предпочитает получать постбэки по всем новым установкам приложения изо всех источников. Рекомендуется выбрать вариант **Все медиа-источники и органический трафик** для передачи всех постбэков по установкам в Unity Ads.

### Настройки внутренних событий приложения

Сопоставляйте события AppsFlyer с партнером с помощью постбэков. Если отправка постбэков активирована, они будут включать отклоненные внутренние события (события, признанные несоответствующими по правилам таргетинга или заблокированные Protect360).

[![](https://files.readme.io/e0d0af3c57c8452b646dfede7b4899215825ef8455d4e41293088f98ecc026eb-7975565240337.png)](https://files.readme.io/e0d0af3c57c8452b646dfede7b4899215825ef8455d4e41293088f98ecc026eb-7975565240337.png)

#### Для настройки постбэков по внутренним событиям приложения:

1. Введите **game\_id**. Убедитесь, что game\_id правильный и совпадает с тем, который используется для атрибуции установки.
2. Активируйте **Постбэки по внутренним событиям приложения**.
3. При необходимости настройте окно **Постбэки по внутренним событиям приложения**(подробнее о<Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#окно-постбэков-по-внутренним-событиям"> настройке окна постбэков по внутренним событиям приложения</Anchor>).
4. Чтобы добавить в список событие, определенное в SDK, или межсерверное событие, нажмите **Добавить событие**.
5. Введите следующие параметры:

| Имя параметра | Описание |
| --- | --- |
| **Событие AppsFlyer** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.<br />**Совет**: Не нашли здесь нужное событие?<ul><li>Убедитесь, что событие активировано на устройстве с неорганической установкой, и повторите поиск.</li><li>Введите его в поле **Событие AppsFlyer**, затем нажмите **Добавить другое**. Подробнее о <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#пользовательские-события">сопоставлении пользовательских событий.</Anchor></li></ul> |
| **сопоставлено с событием партнера** | Уникальное имя или идентификатор каждого события, определенные партнером. Возможны следующие настройки сопоставления:<ul><li>**Текстовое поле**. Введите соответствующий идентификатор события, полученный от партнера.</li><li>**Раскрывающийся список**. Выберите наиболее подходящее предопределенное событие AppsFlyer.</li><li>Переход к маркетплейс: в верхнем меню любой страницы AppsFlyer нажмите **Маркетплейс**.</li></ul> |
| **для пользователей от** | Выберите вариант отправки для события.<ul><li>**Только этот партнер**: постбэки отправляются только в том случае, когда событие атрибутируется этому партнеру.</li><li>**Все медиа-источники и органический трафик**: отправляйте постбэки для событий, атрибутированных любому партнеру, а также для органических событий. В Unity Ads данная опция является рекомендованной.</li></ul> |
| **Включая** | <ul><li>**Нет данных (по умолчанию)**: передача только самого события, без значения.</li><li>**Значения и доход**: отправляет все параметры события, **включая** значение дохода (если оно есть в событии). В Unity Ads данная опция является рекомендованной.</li><li>**Значения без дохода**: передача всех параметров события, **кроме** значения дохода.</li></ul> |

> 🚧 **Важно!**
>
> Выберите правильный идентификатор определенного в SDK события / межсерверного события и события партнера. Не дублируйте события (не проводите одни и те же события под разными именами определенного в SDK события / межсерверного события).

> 📘 **Примечание**
>
> Вы можете отправлять <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-ad-revenue-attribution#ad-revenue-event-postbacks-for-ad-networks">постбэки о доходах от рекламы</Anchor> в Unity Ads, чтобы они могли оптимизировать кампании на основе данных о доходах от рекламы:
>
> * **Название события:** af\_ad\_revenue
> * **Сопоставлено с:** ad\_revenue

<div id="cost-tab" />

<Accordion title="Вкладка «Стоимость»">

Затраты по кликам не поддерживаются. AppsFlyer получает данные о затратах при помощи API. Подробную информацию о поддерживаемых параметрах, метриках и функциях см. в <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">таблице интеграции затрат рекламной сети</Anchor>.

**Примечание**:

* Для получения данных о затратах требуется подписка ROI360.
* Данные по затратам от Unity Ads можно получить только для загрузок из Google Play или Apple App Store. Для Android данные по затратам для сторонних магазинов приложений Android не поддерживаются.
* Затраты агентства не поддерживаются через затраты по кликам и через API. Рекламодатели могут отправлять данные о затратах агентства через <Anchor target="_blank" href="/marketers/ru/docs/import-cost-data">Импорт данных о расходах</Anchor>.

**Чтобы включить API данных о затратах**:

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#enable-cost-api">данным инструкциям по интеграции</Anchor>. **Примечание**. Для интеграции затрат на Unity все приложения с одним и тем же ключом API должны содержать один и тот же Org ID. В противном случае пострадает получение данных о затратах. Обязательно выберите **основной идентификатор организации**.

<Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#статус-api-затрат">Просмотрите статус вашего API данных о затратах</Anchor> и последний раз, когда AppsFlyer получил соответствующие данные о затратах, либо на дэшборде статуса интеграции затрат (и доходов от рекламы), либо на дэшборде отдельной рекламной сети.

</Accordion>

В этом случае вам, безусловно, будет интересно получить показатели вовлеченности пользователей, привлеченных из различных источников, чтобы выявить самые прибыльные.

**Чтобы включить API доходов от рекламы**:

* Следуйте <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-ad-revenue-attribution#connect-to-ad-revenue-integrated-partners">этим инструкциям по интеграции</Anchor>.
