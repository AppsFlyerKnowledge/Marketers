> **Кратко:** Remerge — интегрированный партнер AppsFlyer, рекламная сеть, которая помогает маркетологам приложений показывать более релевантную и персонализированную рекламу. Помимо мобильной атрибуции по кликам, Remerge предлагает мобильную атрибуцию по просмотрам и ретаргетинг по кликам, которые можно регистрировать в AppsFlyer.

<div id="setting-up-remerge" />

## Настройка Remerge

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

<Accordion title="Вкладка «Интеграция»">

<div id="activate-partner" />

### Активация партнера

При **первом посещении** вам нужно будет включить переключатель ниже. При **первом посещении** вам нужно будет включить переключатель ***Активировать партнера***, чтобы включить настройку параметров на вкладке интеграции. Кнопка ДОЛЖНА оставаться в положении «Включено», пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Как сеть, ориентированная на все установки, Remerge предпочитает получать постбэки обо всех новых установках вашего приложения из любого источника, включая органические. Чтобы отправлять в Remerge постбэки по всем установкам, выберите **События, атрибутированные любому партнеру**.

<div id="install-and-re-engagement-attribution" />

### Атрибуция установок и повторного вовлечения

Эти два переключателя позволяют атрибутировать пользователей, которые только просмотрели вашу рекламу, но не кликнули по ней, к Remerge.

* Включите ***Install view-through attribution***, чтобы атрибутировать к Remerge новые установки, совершенные только после показов.
* Включите ***Re-engagement view-through attribution***, чтобы атрибутировать к Remerge новые повторные вовлечения ваших существующих пользователей, совершенные только после показов.

<div id="default-postbacks" />

### Постбэки по умолчанию

Автоматически отправляйте постбэки в Remerge после установок пользователей и повторных вовлечений. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Выберите **Только события, атрибутированные этому партнеру** для событий, которые приходят исключительно от пользователей, атрибутированных Remerge.  
Выберите **События, атрибутированные любому партнеру или органические**, чтобы вся ваша база пользователей была доступна для передачи отчетов в Remerge.

<div id="in-app-events-settings" />

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе вы можете сопоставить события AppsFlyer с Remerge с помощью постбэков.  
Если вы решите сопоставить все события (как с передачей значений дохода, так и без нее), событие af\_app\_opened НЕ будет отправлено в Remerge.  
Если вы хотите отправлять в Remerge события af\_app\_opened, необходимо добавить каждое событие вручную.

1. Активируйте Постбэки по внутренним событиям приложения.
2. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Название события, полученное AppsFlyer либо из SDK, интегрированного в ваше приложение, либо из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Отправка данных о доходе** | **Флажок не установлен** — партнеру отправляются все параметры насыщенного внутреннего события приложения, за исключением параметра дохода (параметр **af\_revenue**).  <br />**Флажок установлен** — отправляются все параметры, в том числе значение дохода (если применимо к событию). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке вы можете создавать ссылки атрибуции, которые нужно отправлять в Remerge для атрибуции кампаний Remerge, групп объявлений или даже отдельных рекламных объявлений. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в Remerge.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках определенных кампаний Remerge.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках определенных кампаний Remerge.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки конкретным паблишерам. Если паблишеров много, рекомендуем ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы избежать <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">превышения ограничений на идентификаторы сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика, чтобы вставлять полезные значения. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

<div id="retargeting-settings" />

### Настройки ретаргетинга

При включении этой опции AppsFlyer распознает ссылку как ссылку атрибуции для <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide">ретаргетинга</Anchor>, а не как ссылку для привлечения пользователей, добавляя `&is_retargeting=true` к ссылке регистрации кликов. Обратите внимание, что ретаргетинг в настоящее время поддерживается только для атрибуции по кликам, а не по просмотрам.  
**Параметр ссылки атрибуции:** is\_retargeting.

Когда ретаргетинг активирован, отображаются следующие настройки.

1. Стандартная ссылка и ссылка OneLink

Вариант ***стандартная ссылка атрибуции*** следует выбирать в следующих случаях:

* URL-адрес не будет использоваться в качестве глубинной ссылки или
* Планируете использовать только <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#general-settings">схемы URI</Anchor> для диплинкинга

select ***Use OneLink*** for:

* Для приложений на Android и iOS используется одна и та же ссылка или
* Для диплинкинга используются универсальные ссылки или ссылки приложений

Обратите внимание, что при выборе OneLink ссылка регистрации кликов меняется со ссылки для конкретного приложения на <Anchor target="_blank" href="/marketers/ru/docs/onelink-guide">URL-адрес OneLink</Anchor>.

2. URL-адрес диплинка

Используйте это поле, если ссылка предназначена для диплинкинга пользователей к определенной активности в вашем приложении.  
**Параметр ссылки атрибуции:** af\_dp  
Подробные сведения о решении AppsFlyer для диплинкинга см. <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">в этом руководстве.</Anchor>

3. Окно повторного вовлечения

Задайте временной интервал после повторного вовлечения, в течение которого внутренние события приложения пользователя будут атрибутироваться медиа-источнику ретаргетинга. Вы можете задать ценность, значение в днях (1-90), часах (до 23) или даже на весь период.

**Параметр ссылки атрибуции:** af\_reengagement\_window

<div id="click-through-attribution" />

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. Remerge могут быть атрибутированы только те установки (первые запуски), которые произошли в рамках окна атрибуции/лукбэк.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об окне атрибуции по кликам <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">см. здесь</Anchor>.

<div id="click-attribution-link" />

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте ее в Remerge, чтобы она активировалась, когда лиды кликают по соответствующему рекламному объявлению.

</Accordion>

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке можно выбрать разрешения для Remerge в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. Обратите внимание, что даже если атрибуция для Remerge отключена, вкладка «Разрешения» остается активной, и вы можете предоставить Remerge контроль.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

<div id="ad-network-permissions" />

### Ad Network Permissions (Разрешения для рекламной сети)

* ***Allow to configure integration*** (Разрешить настройку интеграции) — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков внутренних событий приложений)
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Allow access to your retention report*** (Разрешить доступ к своему отчету об удержании) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate loyal user data*** (Разрешить доступ к своим сводным данным о лояльных пользователях) — доступ предоставляется только к собственным данным партнера
* ***Allow access to your aggregate in-app events data*** (Разрешить доступ к своим сводным данным о внутренних событиях приложения) — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Allow access to your Protect360 dashboard*** (Разрешить доступ к панели управления Protect360) — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
