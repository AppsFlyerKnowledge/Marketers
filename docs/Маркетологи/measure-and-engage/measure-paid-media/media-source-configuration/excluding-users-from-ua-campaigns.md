> **Краткий обзор**. Исключите имеющихся пользователей из кампаний по привлечению пользователей (UA), чтобы получить больше установок в рамках того же бюджета и повысить ROAS.

<div id="issues-and-consequences" />

## Проблемы и последствия

Если ваше приложение получает трафик из нескольких медиа-источников, то эти источники могут нацеливаться на ваших имеющихся пользователей в рамках своих UA-кампаний.

Эффективность кампании может снизиться по следующим причинам:

* **Двойная оплата** — оплата показов/кликов пользователя, за которые вы уже платили ранее.
* **Искаженные показатели конверсии** — UA-кампании кажутся менее успешными. Установок становится меньше, так как показы тратятся на имеющихся пользователей.
* **Потеря альтернативных пользователей** — будущие пользователи могли бы увидеть рекламу и стать вашими мобильными пользователями.

<Anchor target="_blank" href="/marketers/ru/docs/self-reporting-networks-srns#what-is-srn-mistargeting">Неправильный таргетинг SRN</Anchor> такая же распространенная проблема эффективности кампании. Она может возникнуть, если и UA-кампании, и ретаргетинговые кампании проводятся в рамках одной SRN-сети. <Anchor target="_blank" href="/marketers/ru/docs/self-reporting-networks-srns#является-ли-неправильное-направление-таргетинга-проблемой">Узнать подробнее</Anchor>

<div id="solutions" />

## Решения

Эти решения показывают, как обновить рекламные сети, чтобы исключить имеющихся пользователей из кампаний по привлечению пользователей.

<div id="manual-update" />

### Ручное обновление

Запросите у AppsFlyer сырые данные по установкам на уровне пользователя, чтобы создать списки идентификаторов устройств. Затем отправьте эти списки рекламной сети, чтобы исключить пользователей.

Добавить эти сырые данные в вашу бизнес-аналитику можно разными способами:

* Скачать отчеты по сырым данным
* Отправлять периодические запросы на сырые данные через Pull API
* Собирать данные в реальном времени через Push API
* Получать данные о конверсиях через SDK

<div id="note" />

> 📘 **Примечание**
>
> В промежутке между ручной отправкой списков в рекламные сети, UA-кампании могут нацеливаться на новых пользователей вашего приложения.

<div id="audiences" />

### Аудитории

**<Anchor target="_blank" href="/marketers/ru/docs/audiences-guide">Audiences</Anchor>** — это функция AppsFlyer категории «Премиум». Каждый день выбранные сегменты вашей базы пользователей автоматически отправляются в различные рекламные сети, выбранные вами.

Функция **Audiences** очень полезна для поддержки списков для исключения пользователей:

* **Не требует усилий** — не требуются специальные разработки или поддержка ни с вашей стороны, ни со стороны рекламной сети.
* **Удобный интерфейс** — после короткой начальной настройки вы можете начать загрузку аудиторий.
* **Эффективно** — сегменты отправляются в рекламные сети автоматически каждые 24 часа.
