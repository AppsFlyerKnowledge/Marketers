> **Кратко:** Tencent AMS — интегрированный партнер AppsFlyer и рекламная сеть, которая управляет активами в сфере социальных сетей и мобильных утилит в Китае и позволяет маркетологам запускать кампании по установке приложений в: WeChat, мобильной коммуникационной платформе компании, QQ, сервисе мгновенного обмена сообщениями, QQ Music, QQ Browser, Myapp и других.

## Настройка Tencent AMS

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество**> **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

### Общие настройки

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже. Для интеграции TencentAMS с AppsFlyer потребуются следующие учетные данные: **account\_id, user\_action\_set\_id и access\_token**. Если у вас еще нет этих значений, получите их напрямую у Tencent AMS, прежде чем продолжить интеграцию.

<Image alt="tencent.png" src="https://files.readme.io/56bfdc43b976f1f29f5ba121986aa66228cd79029025e84278cb3c304989fc3e-38300461521041.png" width="248px" />

> 📘 **Примечание**
>
> **access\_token** выдается Tencent AMS и действует 30 дней. Согласно требованию Tencent, вы (или ваше управляющее агентство) должны **вручную обновлять токен каждые 30 дней и обновлять его в указанном выше поле**.
>
> * Если срок действия токена истечет, постбэки в Tencent AMS не будут отправляться, пока не будет введен новый токен.
> * Если вы не знаете, как получить или обновить токен, обратитесь за инструкциями к менеджеру вашего аккаунта Tencent AMS.
>
> **Трафик под управлением агентства:** если ваш трафик продвигается через агентство, **агентство также должно заполнить и поддерживать токен со своей стороны**.

#### Активация атрибуции по просмотрам

Чтобы включить атрибуцию установок после просмотра, включите этот параметр.  
На вкладке «Ссылка атрибуции» (описана ниже) имеется шкала для окна атрибуции по просмотрам.

#### Постбэки по умолчанию

AppsFlyer может отправлять автоматические постбэки в Tencent AMS после установок пользователей. В этом разделе отображается **источник пользователей**, для которых можно отправлять эти постбэки.

#### Настройки внутренних событий приложения

В этом разделе вы можете настроить отправляемые в Tencent AMS постбэки о событиях в приложении.

**Чтобы настроить постбэки по событиям в приложении**,

1. Включите **постбэк по событиям в приложении** .
2. Если требуется, установите **окно постбэков по внутренним событиям** (подробнее о<Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#окно-постбэков-по-внутренним-событиям">настройке окна постбэков по внутренним событиям</Anchor>).
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Заполните следующие параметры в таблице ниже

| Название параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK или из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, активируйте его на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор каждого события, определенные партнером. Выберите наиболее подходящее предопределенное событие для события SDK. |
| **Sending option (Вариант отправки)** | Выберите вариант отправки события:  <br />**Только от этого партнера** для событий, поступающих **только** от пользователей, атрибутированных Tencent AMS.  <br />**Все источники, включая органические**, чтобы партнер получал сведения о событиях всех пользователей, которые есть в вашей базе. |
| **Отправить данные о событии** | <ul><li>**Нет значений и нет дохода:** отправляет только само событие без значения.</li><li>**Значения, нет дохода:** отправляет все параметры, кроме значения дохода.</li><li>**Значения и доход**: отправляет все параметры события, включая значение дохода (если оно есть в событии).</li></ul> |

5. Нажмите кнопку **Save Integration** (Сохранить интеграцию).

</Accordion>

<div id="permissions-tab" />

<Accordion title="Вкладка Permissions (Разрешения)">

На этой вкладке вы можете выбрать разрешения, которые нужно предоставить Tencent AMS. Обратите внимание, что, даже если атрибуция для Tencent AMS отключена, вкладка разрешений остается активной и вы можете предоставить Tencent AMS разрешение на управление.

Используйте эти переключатели, чтобы уполномочить рекламную сеть самостоятельно обрабатывать конфигурацию для вашего приложения:

* **Разрешить настраивать интеграцию** - разрешить партнеру настроить вкладку интеграции (кроме постбэков по событиям в приложении)
* **Разрешение настраивать постбэки по событиям внутри приложения**: разрешить партнеру сопоставлять себе постбэки по внутренним событиям приложений на вкладке интеграции.
* **Предоставление доступа к отчету об удержании пользователей**: партнер получает доступ только к собственным данным об удержании пользователей.
* **Разрешить доступ к агрегированным данным о лояльных пользователях** - партнер получает доступ только к собственным данным о лояльных пользователях
* **Разрешить доступ к агрегированным данным о событиях в приложении** - партнер получает доступ только к собственным данным о событиях в приложении
* **Предоставление доступа к агрегированным данным о доходе**: партнер получает доступ к данным только по атрибутированным ему доходам.
* **Разрешить импорт данных о расходах** - разрешить партнеру отправлять данные о расходах на рекламу в виде файлов только для этого приложения.
* **Разрешить доступ к вашему дэшборду Protect360 & и сырым данным** — партнер получает доступ только к собственным данным Protect360 при условии, что эта функция активирована для рекламодателя

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-рекламной-сети">разрешений рекламной сети</Anchor>.

</Accordion>
