> **Кратко:** Узнайте, как измерять кампании в WeChat с помощью AppsFlyer.

## Введение

WeChat — один из интегрированных партнеров AppsFlyer. Это китайское многофункциональное приложение для обмена сообщениями, социальных сетей и мобильных платежей, разработанное Tencent.

Чтобы настроить кампании с использованием WeChat, выполните следующие действия.

## Настройка кампании в WeChat

Перед тем как продолжить интеграцию WeChat в AppsFlyer, настройте кампанию в WeChat.

В WeChat выполните следующие действия:

1. Заполните и проверьте ключ Tencent
2. Выберите тип конверсии из списка:

   * установка
   * Регистрация
   * покупка;
   * добавление в корзину;

   Обратите внимание: WeChat допускает только одну цель конверсии для каждого приложения.
3. Введите [URL-адрес атрибуции кликов](#attribution-link-tab) AppsFlyer

![wechat-configuration.png](https://files.readme.io/228ee10ef3dc113ae8af8de0f283b144206db1857f6d1f9169355f294155b8f8-50900431174033.png)

После ввода этой информации подтвердите ее, нажав выделенную кнопку. На следующем этапе вы получите *encrypt\_key* и *sign\_key*:

![wechat-keys.png](https://files.readme.io/cd7a2406ae9981eaabb4089813c9a1b847f0e6f750b9c0c0a0ac5e726dfe44be-50900431177361.png)

Скопируйте ключи и используйте их при настройке кампании в AppsFlyer.

### Настройка кампании WeChat агентством

В WeChat у агентств есть разные типы аккаунтов. В зависимости от типа аккаунта некоторые агентства могут создавать цели конверсии, а некоторые — нет.

Если ваш аккаунт позволяет создавать цель конверсии, вы можете продолжить, следуя приведенным выше инструкциям.

Если вам не разрешено создавать цель конверсии, в WeChat вы можете увидеть цель, созданную другой учетной записью, которая управляет тем же приложением. В этом случае попросите рекламодателя предоставить вам *encrypt \_key* и *sign\_key* и используйте их для настройки кампании в AppsFlyer.

## Настройка WeChat в AppsFlyer

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите **Сотрудничество**> **Маркетплейс партнёров.Чтобы изменить**: В AppsFlyer в боковом меню выберите **Сотрудничество**> **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции.   
   **Важное примечание:** переключатель **должен оставаться включенным (активным) до тех пор, пока вы работаете с партнером**. <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">Узнать больше</Anchor>
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе.

В окне настроек WeChat есть 4 вкладки: "Integration", "Attribution link", "Data enrichment" и "Permissions". Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

### Активация партнера

При **первом посещении** вам нужно будет включить переключатель ниже. При **первом посещении** вам нужно будет включить переключатель ***Активировать партнера***, чтобы включить настройку параметров на вкладке интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

> 📘 **Примечание:**
>
> Как сеть, ориентированная на все установки, WeChat предпочитает получать постбэки по всем новым установкам вашего приложения из ЛЮБОГО источника, включая органический. Рекомендуется выбрать **События, атрибутированные любому партнеру**, чтобы отправлять в WeChat постбэки по всем установкам.

### Общие настройки

**Partner ID (Идентификатор партнера)**

Wechat подключается к AppsFlyer с помощью трех уникальных параметров:

1. ID подписи
2. ID приложения WeChat
3. Ключ шифрования

Если у вас еще нет Sign ID, ID приложения WeChat и Encrypt Key, вы должны получить их в WeChat, чтобы продолжить интеграцию.

<Image alt="wechat-integration-general-settings.png" src="https://files.readme.io/f1e0675a26116b628629b07616a7b9b86e8413ee36d7504f415207cb1590cb82-50900431178001.png" width="390px" />

### Постбэки по умолчанию

AppsFlyer может автоматически отправлять постбэки в WeChat после установок приложения и повторного вовлечения. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

![wechat-default-postbacks.png](https://files.readme.io/1a2703b97a71bf82bcc77f5393459bc94b5443b83a4c4965d2624eda0e9f166f-50900402778129.png)

Выберите **Only events** **attributed to this partner** для событий, которые приходят только от пользователей, атрибутированных WeChat.  
Выберите **События, атрибутируемые любому партнеру или органические**, чтобы предоставлять WeChat отчеты о событиях всей вашей пользовательской базы.

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить ваши события AppsFlyer с WeChat с помощью постбэков.

![wechat_in_app_event_postbacks.png](https://files.readme.io/cd6234df4809b27044e361ad8835d4ae92100c491e0aa7c8f003336cdf2ad49d-50900431180561.png)

1. Введите ключ шифрования еще раз.
2. Введите ID подписи
3. Введите ID приложения WeChat
4. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
5. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
6. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
7. Введите следующие параметры:

| Имя параметра | Описание |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное название или идентификатор каждого события, как определено на стороне WeChat.  <br />Получите соответствующий идентификатор события в WeChat и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — AppsFlyer отправляет партнеру все параметры насыщенного события в приложении, за исключением параметра дохода, который содержится в параметре **af\_revenue**.  <br />**Флажок установлен** — AppsFlyer отправляет все параметры, в том числе значение дохода (если оно есть в событии). |

</Accordion>

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые вы хотите отправлять в WeChat для атрибуции кампаний, групп объявлений или даже отдельных объявлений WeChat. Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** — добавьте этот параметр, чтобы сравнивать разные кампании, запущенные в WeChat.  
  **Параметр ссылки атрибуции:** c
* **Adset** — задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках отдельных кампаний WeChat.  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** — задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках отдельных кампаний WeChat.  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить допустимое количество идентификаторов сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

![attribution-link-parameters.png](https://files.readme.io/9cc0845f4492c981fd1db843cb82caf48aecc446fac7800829ee43f858f67e64-360002880417.png)

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции в AppsFlyer**</Anchor>.

### Атрибуция по кликам

Этот ползунок позволяет задать **максимальное время от клика до установки**. Только установки (первые запуски), которые происходят в рамках окна атрибуции, могут быть атрибутированы WeChat.

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробные сведения об окне атрибуции по кликам <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">см. здесь</Anchor>.

[![](https://files.readme.io/86114a765dea30da658a676d1a7506c6ba385bdf8ebcf7241a1ce85f8c413077-50900402782737.png)](https://files.readme.io/86114a765dea30da658a676d1a7506c6ba385bdf8ebcf7241a1ce85f8c413077-50900402782737.png)

### Ссылка атрибуции для клика

Это ссылка атрибуции, которая содержит все заданные для нее настройки. Отправьте её в WeChat, чтобы она активировалась, когда потенциальные клиенты нажимают на соответствующее объявление.
