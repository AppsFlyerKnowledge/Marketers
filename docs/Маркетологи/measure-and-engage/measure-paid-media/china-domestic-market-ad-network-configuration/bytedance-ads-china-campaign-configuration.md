> **Краткий обзор.** ByteDance Ads China (Ocean Engine), интегрированный партнер AppsFlyer, — это интернет-технологическая компания, управляющая несколькими контент-платформами с поддержкой машинного обучения.

<div id="note" />

> 📘 **Примечание:**
>
> Если вы хотите продвигать свои приложения для Android с помощью ByteDance Ads China, вам необходимо отправить свой OAID в AppsFlyer SDK в соответствии с инструкциями в разделе <Anchor target="_blank" href="/marketers/ru/docs/sdk-integration-overview">Интеграция AppsFlyer SDK для Android. Сервис Google Play заблокирован в Китае, OAID — самый популярный идентификатор устройства Android для атрибуции рекламы.</Anchor>

Помимо мобильной атрибуции по кликам, ByteDance Ads China также предлагает атрибуцию по просмотрам, которую можно регистрировать с помощью AppsFlyer.

Чтобы настроить кампании с ByteDance Ads China, выполните следующие действия.

<div id="setting-up-bytedance-ads-china" />

## Настройка ByteDance Ads China

**Необходимые условия:** Перед настройкой интеграции обязательно [свяжитесь с партнёром](#) и откройте у него аккаунт. Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

Совет

> 👍 **Tip**
>
> * Этап <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#d">Общие настройки</Anchor> на вкладке интеграции необходимо **обязательно** выполнять для всех партнеров.
> * Все остальные этапы описаны только для сведения или же являются **необязательными**.

### Настройки внутренних событий приложения

В этом разделе вы можете сопоставить события AppsFlyer с ByteDance Ads China через постбэки.

1. Включите постбэки во внутренним событиям приложения.
2. Выберите в поле «Вариант отправки» значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
3. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
4. Введите следующие параметры:

| Имя параметра | Описание |
| --- | --- |
| **Событие AppsFlyer** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.<br />**Совет**: Не нашли здесь нужное событие?<ul><li>Убедитесь, что событие активировано на устройстве с неорганической установкой, и повторите поиск.</li><li>Введите его в поле **Событие AppsFlyer** и нажмите **Добавить другое**. Подробнее о <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#пользовательские-события">сопоставлении пользовательских событий</Anchor> читайте здесь.</li></ul> |
| **сопоставлено с событием партнёра** | Уникальное имя или идентификатор каждого события, определенные партнером. Возможны следующие настройки сопоставления:<ul><li>**Текстовое поле:** Получите соответствующий идентификатор события от партнера.</li><li>**Раскрывающийся список:** Выберите наиболее подходящее предопределённое событие AppsFlyer.</li><li>**Как есть**: События отправляются в исходном виде, без сопоставления названий событий.</li></ul> |
| **для пользователей от** | Выберите вариант отправки для события.<ul><li>**Только этот партнёр**: постбэки отправляются только в том случае, когда событие атрибутируется этому партнеру, то есть когда пользователь, выполнивший событие, пришел от этого партнера.</li><li>**Все медиа-источники и органический трафик**: Отправлять постбэки для событий, связанных с любым партнером и органических событий, то есть для случаев, когда пользователь пришёл из любого медиа-источника.</li></ul> |
| **включая** | Выберите, какие данные о событиях следует передать партнеру в постбэке:<ul><li>**Без значения и дохода**: Отправляется только само событие без каких-либо параметров (значений или доходов).</li><li>**Значение без дохода**: Отправляются все параметры, **кроме** значения дохода.</li><li>**Значение и доход**: Отправляются все параметры события, **включая** значение дохода (если оно есть в событии).</li></ul> |

<div id="ad-network-permissions" />

### Разрешения для рекламной сети

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
