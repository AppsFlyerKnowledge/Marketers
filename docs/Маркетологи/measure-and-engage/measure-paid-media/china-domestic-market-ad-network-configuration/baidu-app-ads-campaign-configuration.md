> **Кратко:** Baidu App Ads (Baitong) — рекламная сеть, интегрированная с партнерами AppsFlyer, и одна из крупнейших платформ для продвижения и распространения приложений на внутреннем рынке Китая. Она объединяет мобильный трафик магазинов приложений (Baidu Mobile Assistant, Android Market, 91 Mobile Assistant и т. д.), Baidu Mobile Search, Super App и партнеров Baidu.

<div id="setting-up-baidu-app-ads-baitong" />

## Настройка Baidu App Ads (Baitong)

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции.   
   **Важно:** переключатель **должен оставаться включенным (активным), пока вы работаете с партнером**. <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">Узнать больше</Anchor>
5. Завершите настройку, используя соответствующие вкладки, как описано ниже.

В окне настроек Baidu App Ads есть 3 активные вкладки: Integration, Attribution link и Permissions. Чтобы ознакомиться с настройками этих вкладок, нажмите на названия пунктов ниже.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

<div id="activate-partner" />

### Активация партнера

При **первом посещении** необходимо включить кнопку ***Активировать партнера***, чтобы включить настройку параметров вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.

<div id="default-postbacks" />

### Постбэки по умолчанию

AppsFlyer может отправлять автоматические постбэки в Baidu App Ads (Baitong) после установок и повторных вовлечений пользователей. В этом разделе можно определить **источник пользователей**, который позволяет отправлять постбэки.

Интеграция с Baidu Baitong Ads поддерживает для постбэков по умолчанию только событие установки.

<div id="attribution-link-tab" />

<Accordion title="Вкладка «Ссылки атрибуции»">

На этой вкладке можно создавать ссылки атрибуции, которые нужно отправить в Baidu App Ads (Baitong) для атрибуции кампаний, групп объявлений и даже отдельных объявлений в Baidu App Ads (Baitong). Обратите внимание, что AppsFlyer НЕ сохраняет ссылки атрибуции, созданные для вашего партнера.

На этой вкладке есть несколько разделов:

<div id="attribution-link-parameters" />

### Параметры ссылки атрибуции

В этом разделе можно выбрать параметры для добавления в ссылку атрибуции.

Здесь можно задавать дополнительные параметры ссылки атрибуции, чтобы затем использовать их для детального анализа. Параметры, уже заданные в ссылке атрибуции, можно редактировать, добавляя их и их новые значения здесь.

* **Campaign** - добавьте этот параметр, чтобы сравнивать различные кампании, запущенные в Baidu App Ads（Baitong).  
  **Параметр ссылки атрибуции:** c
* **Adset** - задайте названия групп объявлений, чтобы сравнивать разные группы объявлений в рамках отдельных кампаний Baidu App Ads（Baitong).  
  **Параметр ссылки атрибуции:** af\_adset
* **Ad Name** - задайте названия объявлений, чтобы сравнивать разные креативы в определенных группах объявлений в рамках отдельных кампаний Baidu App Ads（Baitong).  
  **Параметр ссылки атрибуции:** af\_ad
* **Site ID** и **Sub Site ID** — задайте параметр Site ID, чтобы атрибутировать установки определенным паблишерам. При наличии большого количества паблишеров рекомендуется ограничить количество используемых идентификаторов сайтов и использовать параметр идентификатора подсайта, чтобы <Anchor target="_blank" href="/marketers/ru/docs/measure-exceeded-dimensions-and-cardinality-limits#exceeded_siteid_limit">не превысить допустимое количество идентификаторов сайтов</Anchor>.  
  **Параметры ссылки атрибуции:** af\_siteid и af\_sub\_siteid
* **Subscriber Parameters** — используйте любой из 5 параметров подписчика, чтобы вставить полезные значения. Обратите внимание, что эти параметры анализируются и отображаются в отчете о сырых данных, что делает их очень удобными для агрегации или фильтрации данных.  
  **Параметры ссылки атрибуции:** af\_sub1, af\_sub2, af\_sub3, af\_sub4, af\_sub5

Если нужно добавить в ссылку атрибуции другой параметр, просто введите его в поле нового параметра. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/about-link-structure-and-parameters">**Структура и параметры ссылки атрибуции AppsFlyer**</Anchor>.

<div id="click-through-attribution" />

### Атрибуция по кликам

С помощью этого ползунка можно задать **максимальное время от клика до установки**. Только установки (первые запуски), которые происходят в пределах окна атрибуции/лукбэк, могут быть атрибутированы Baidu App Ads（Baitong).

**Параметр ссылки атрибуции:** af\_click\_lookback

Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/set-up-lookback-windows">окне ретроспективы кликов читайте здесь</Anchor>.

<div id="click-attribution-link" />

На этой вкладке можно выбрать разрешения для RTB House в зависимости от того, в каком качестве выступает партнер: как рекламная сеть, агентство или и то, и другое. <div id="ad-network-permissions" />

### Ad Network Permissions (Разрешения для рекламной сети)

Эти переключатели позволяют предоставить рекламной сети право самостоятельно выполнять настройки для вашего приложения:

* ***Разрешить настройку интеграции*** — разрешить партнеру настраивать вкладку интеграции (за исключением постбэков по внутренним событиям приложения).
* ***Разрешить настройку постбэков по внутренним событиям приложения*** — разрешить партнеру настраивать постбэки по внутренним событиям и отображать эти настройки на вкладке интеграции.
* ***Разрешить доступ к своему отчету об удержании*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о лояльных пользователях*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о внутренних событиях приложения*** — доступ предоставляется только к собственным данным партнера.
* ***Разрешить доступ к своим сводным данным о доходах*** — доступ предоставляется только к данным о доходах, атрибутированных партнеру.
* ***Разрешить доступ к панели управления Protect360*** — доступ предоставляется только к собственным данным Protect360 этого партнера, при условии что эта функция активирована для рекламодателя.

См. дополнительные сведения о предоставлении <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#permissions-tab">разрешений рекламной сети</Anchor>.

</Accordion>
