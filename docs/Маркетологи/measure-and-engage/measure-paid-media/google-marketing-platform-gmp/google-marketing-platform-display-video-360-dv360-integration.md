> **Краткий обзор.** Google Платформа для маркетинга — Display & Video 360 (GMP-DV360) — это партнер AppsFlyer в области сетей с самостоятельной атрибуцией (SRN), объединяющий рекламу и аналитику. Интеграция GMP-DV360 (dv360\_int) включают в себя рекламу и аналитику для улучшения связей с клиентами, получения аналитических сведений и улучшения маркетинговых результатов.

## Обзор

Интеграция GMP-DV360 использует идентификатор ссылки для измерения конверсии. Вы можете работать с GMP-DV360напрямую, через агентство или обоими способами, используя следующие интеграции:

* [DV360 для рекламодателей](#настройка-gmp-dv360-для-рекламодателей): Заполнить один раз — обязательно
* [DV360 для агентств](#настройка-gmp-dv360-для-агентств): Необязательно для каждого агентства

<div id="note" />

> 📘 **Примечание**
>
> Имейте в виду следующее:
>
> * Интеграция GMP-DV360 призвана заменить устаревшую интеграцию GMP DV360/CM (doubleclick\_int), которая будет прекращена к концу второго квартала 2024 года.
> * Чтобы использовать API, обратитесь к своему менеджеру по работе с клиентами GMP-DV360.

В таблице ниже описаны решения по интеграции GMP:

| Решение GMP | Описание | Необходимые действия для интеграции |
| --- | --- | --- |
| DV360 | Интегрируйте DV360 с AppsFlyer для измерения атрибуции dv360\_int | Завершите [интеграцию рекламодателя](#настройка-gmp-dv360-для-рекламодателей) |
| CM360 & DV360 | Купите трафик DV360 через CM360, измеряемый как атрибуция dv360\_int в AppsFlyer. | Завершите [интеграцию рекламодателя](#настройка-gmp-dv360-для-рекламодателей) |
| CM360 и сторонний медиа-источник не-DV360 | Купите трафик из сторонних медиа-источников и измерение в СМ360 конверсий мобильных приложений, происходящих из этого трафика. | <Anchor target="_blank" href="/marketers/ru/docs/gmp-use-case-of-traffic-measurement-from-3rd-parties-in-cmp360">Измерение стороннего трафика с помощью CM360</Anchor> |

### Обмен данными между AppsFlyer и GMP — DV360

**Данные, предоставленные AppsFlyer:** AppsFlyer отправляет в GMP-DV360 постбэки, касающиеся конверсий и внутренних событий приложения.

**Данные, предоставленные в AppsFlyer:** Когда GMP-DV360 регистрирует конверсию, в AppsFlyer предоставляются параметры источника медиа. Эти параметры используются для заполнения аналитических отчетов и отчетов по необработанным данным. В таблице ниже показаны параметры сопоставления для GMP-DV360 и AppsFlyer.

| GMP | AppsFlyer: |
| --- | --- |
| `Тип взаимодействия` | `attributed_touch_type (атрибутированный тип взаимодействия)` |
| `временная метка` | `attributed_touch_time` |
| `line_item_id` | `campaign_id (идентификатор кампании)` |
| `line_item_name` | `campaign_name` |
| `creative_id` | `ad_id (идентификатор объявления)` |
| `product_type` | `af_channel` |
| `external_customer_id` | `network_account_id` |
| `site_id (идентификатор сайта)` | `af_siteid` |
| `insertion_order_id` | `af_sub4` |

## Настройка GMP-DV360 для рекламодателей

**Необходимые условия** 

Перед настройкой интеграции обязательно:

* <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">Свяжитесь с партнером</Anchor> и создайте аккаунт в его системе.
* <Anchor target="_blank" href="https://support.google.com/displayvideo/answer/10956727">Получите идентификатор ссылки GMP-DV360</Anchor>.

  <div id="note-1" />

  > 📘 **Примечание:**
  >
  > ID ссылки из DV360 должен соответствовать следующим требованиям:
  >
  > * Он должен содержать цифры и буквы.
  > * Он должен быть длиннее 20 символов.
  > * Для Android и iOS нужно использовать разные идентификаторы ссылок.


**Чтобы настроить новую интеграцию:**  
  
**Предварительное условие:** учётная запись у партнёра. Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.  
    Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

#### Атрибуция установок

Установите различные окна атрибуции для атрибуции новых установок (первых запусков) пользователей, которые просмотрели или нажали на вашу рекламу. Это означает максимальное время от клика/просмотра до установки. Только установки, выполненные в течение периода атрибуции, могут быть атрибутированы к Google Платформе для маркетинга — Display & Video 360 (DV360).

1. Установите для **окна атрибуции установок по кликам** значение 1-23 часа или 1-30 дней.
2. [Необязательно] Включите опцию **Установить атрибуцию по просмотрам** и установите окно атрибуции на 1–23 часа или 1–30 дней.

<div id="re-engagement-attribution" />

#### Атрибуция повторного вовлечения

Установите различные окна атрибуции для атрибуции повторных вовлечений существующих пользователей, которые просмотрели или нажали на вашу рекламу. Обратите внимание, что только повторные вовлечения в течение периода атрибуции могут быть атрибутированы к GMP-DV360.

1. Установите **период атрибуции по кликам с повторным вовлечением** на 1–23 часа или 1–30 дней.
2. [Необязательно] Включите **атрибуцию** **по просмотрам с повторным вовлечением** и установите окна атрибуции на 1–23 часа или 1–7 дней.

<div id="note-2" />

> 📘 **Примечание:**
>
> Повторная атрибуция не поддерживается для кампаний DV360

Узнайте больше о <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide#reengagement-rules-and-windows">правилах и окнах атрибуции для повторных вовлечений</Anchor>.

<div id="re-engagement-window" />

#### Окно повторного вовлечения

Задайте временной интервал, в течение которого внутренние события приложения атрибутируются в первую очередь конверсии повторного вовлечения. <Anchor target="_blank" href="/marketers/ru/docs/retargeting-attribution-guide#setup-reengagement-window">Подробнее</Anchor>.

* Установите **окно повторного вовлечения** на 1–23 часа, 1–90 дней или **Пожизненно**.

<div id="ignore-active-users-for-retargeting" />

#### Игнорирование активных пользователей для ретаргетинга

Установите временной интервал, в течение которого будут <Anchor target="_blank" href="/marketers/ru/docs/set-retargeting-inactivity-window#период-неактивности">игнорироваться повторные вовлечения и повторные атрибуции</Anchor> пользователей, запустивших ваше приложение. Это означает, что их активность в течение указанного периода времени не регистрируется в AppsFlyer.

<div id="note-3" />

> 📘 **Примечание**
>
> Конверсии повторного вовлечения и реатрибуции пользователей, которые в заданный период времени были **неактивны**, **регистрируются**.

1. Включите опцию **Игнорировать активных пользователей для ретаргетинга**.
2. Задайте окно неактивности.

#### Сопоставление параметра U

AppsFlyer поддерживает отправку дополнительных параметров (параметров u), ограниченных значением u26. Параметры U предварительно сопоставлены и зафиксированы на стороне AppsFlyer. Примите во внимание следующее:

* Поскольку эти параметры предварительно сопоставлены, то настроить дополнительные пользовательские параметры U невозможно.
* Если данные для определенного параметра U отсутствуют, AppsFlyer не будет их отправлять. Например, если отсутствуют данные об операторе, то AppsFlyer не отправляет параметр U5.

<Accordion title="Вкладка «Ссылки атрибуции»">

**Ссылки атрибуции AppFlyerс можно использовать с DV360 только для регистрации показов и нажатий**. Эти ссылки НЕ используются для атрибуции, и любая дополнительная информация, которая в них содержится, не анализируется и не используется для каких-либо целей.

Чтобы измерять с помощью AppsFlyer количество кликов, полученных от сервиса DV360, необходимо добавить URL-адрес ссылки атрибуции AppsFlyer на дэшборд DV360. Убедитесь, что название кампании в URL-адресе ссылки атрибуции **совпадает** с идентификатором размещения в GMP. Иначе AppsFlyer не сможет получать данные по кликам и добавлять их к соответствующим кампаниям.

<div id="important-1" />

> 🚧 **Важно!**
>
> Использование ссылок атрибуции для **DV360**не является обязательным.
>
> **Ограничение:** Ссылки атрибуции для DV360, которые включают параметр `af_prt`, в настоящее время **не поддерживаются для аккаунтов агентств**.

Чтобы вести в AppsFlyer учет **кликов**, используйте эту ссылку:

```http
https://app.appsflyer.com/ADD-APP-ID?pid=dv360_int&af_siteid=${UNIVERSAL_SITE_ID}
&af_ad_id=${CREATIVE_ID}&c=${PLACEMENT_ID}&af_c_id=${PLACEMENT_ID}
```

Чтобы вести в AppsFlyer учет **показов** , используйте эту ссылку:

```http
https://impression.appsflyer.com/ADD-APP-ID?pid=dv360_int&af_siteid=%24{UNIVERSAL_SITE_ID}
&af_ad_id=${CREATIVE_ID}&c=${PLACEMENT_ID}&af_c_id=${PLACEMENT_ID}
```

</Accordion>

<div id="cost-tab-for-cost-clicks-and-impressions" />

<Accordion title="Вкладка «Затраты» (для затрат, кликов и показов)">

Для этой интеграции через ROI360 поддерживаются данные о стоимости, кликах и показах.

Клиенты ROI360 могут создавать и редактировать интеграции затрат на вкладке **Затраты** и в разделе **Настройки затрат**. См. <Anchor target="_blank" href="/marketers/ru/docs/set-up-roi360-cost-api-to-measure-cost-data#включение-api-затрат">как включить интеграцию затрат</Anchor>.

Начиная с 7 сентября 2026 года клики и показы больше не будут передаваться через атрибуцию. Чтобы продолжать получать эти метрики, настройте интеграцию DV360 SRN/интеграцию стоимости.

<div id="note-5" />

> 📘 **Вкладка «Разрешения»**
>
> Клики и показы для этой интеграции отображаются в:
>
> * Панели управления
> * Отчёты ETL по стоимости (только для клиентов ROI360)
> * Агрегированные API AppsFlyer
>
> В зависимости от того, когда будет активирована интеграция с DV360, в каждом из указанных выше показателей может временно возникнуть расхождение:
>
> * Активация не позднее 6 сентября: в этот период клики и показы учитываются дважды — один раз в атрибуции AppsFlyer и один раз через API DV360, поэтому ожидается временное расхождение.
> * Активация до 12 сентября включительно: в некоторые даты ожидается расхождение из-за автоматического дозаполнения данных DV360 за последние 7 дней.
> * Активация после 12 сентября: расхождений не ожидается.

</Accordion>

Доход от рекламы не поддерживается для этой интеграции.

## Расхождения с GMP-DV360

Ознакомьтесь с возможными причинами расхождений и способами их минимизации:

| Причина | Описание | Совет AppsFlyer |
| --- | --- | --- |
| Интервал атрибуции по просмотрам | В GMP-DV360 используется окно атрибуции по просмотрам в 14 дней, а в AppsFlyer по умолчанию установлен интервал в 1 день. | Чтобы уменьшить расхождение, установите в AppsFlyer максимальное 7-дневное окно просмотра. |
| Неправильное сопоставление | Неправильное сопоставление между AppsFlyer и GMP-DV360 | <ul><li>Проверьте идентификатор ссылки</li><li>Убедитесь, что внутренние события приложения правильно сопоставлены</li></ul> |
