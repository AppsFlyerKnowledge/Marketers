> Краткий обзор: Импортируйте предопределенные сегменты аудиторий из ваших внутренних систем (таких как бизнес-аналитика и CRM) в AppsFlyer аудитории, что позволит вам использовать аудитории для подключения и поддержания этих сегментов с вашими рекламными партнерами.

## Почему стоит импортировать аудитории?

В некоторых случаях у вас могут быть предопределенные сегменты аудиторий во внутренних системах. Импорт этих аудиторий (в виде списков идентификаторов устройств и/или пользователей) в AppsFlyer позволяет использовать аудитории в качестве центральной точки для подключения и поддержки всех сегментов вашей аудитории с рекламными партнерами. Кроме этого, вы сможете в полной мере использовать другие функции аудиторий, такие как сопоставление идентификаторов/обогащение данных и связанные метрики кампаний.

Рассмотрим следующие примеры:

> 📄 **Примеры**
>
> Промо-ремаркетинг
> Вы хотите предоставить специальные предложения пользователям в месяц их дня рождения.
>
> Вот как это сделать с помощью аудиторий:
>
> 1. Используйте свою внутреннюю CRM для создания списка пользователей с указанием их дней рождения.
> 2. Сегментируйте список по месяцу рождения и экспортируйте его как отдельные списки рекламных ID.
> 3. Импортируйте эти списки в AppsFlyer как аудитории и подключите их к партнерам, с которыми вы хотите запускать рекламные кампании.
> 4. Настройте кампании с соответствующими партнерами, чтобы эффективно таргетировать аудитории.
>
> Привлечение новых пользователей
> Ваша студия разработки приложений приобретает другую студию. Приобретенная вами студия имеет идентификаторы устройств пользователей, которые ранее установили их приложения, и вы хотите привлечь этих пользователей для установки ваших существующих приложений.
>
> Вот как это сделать с помощью аудиторий:
>
> 1. Получите список идентификаторов устройств из приобретенной вами студии и импортируйте его в AppsFlyer как аудиторию.
> 2. Подключите аудиторию к партнерам, с которыми вы хотите запускать кампании.
> 3. Настройте кампании с соответствующими партнерами, чтобы эффективно таргетировать этих пользователей.

## Импорт аудиторий V2.0

В этой статье описываются концепции и процедуры, связанные с новой функцией импорта аудиторий V2.0 (с возможностями импорта через CSV и API).

## Типы импортированных аудиторий

При импорте аудитории вы выбираете один из двух типов, что определяет, как AppsFlyer будет обрабатывать и загружать её Партнёрам. **Тип определяется при первом импорте аудитории и не может быть изменён позднее.**

**Стандартная импортированная аудитория:**

* Проходит сопоставление идентификаторов и обогащение данных—процесс, в ходе которого аудитории сопоставляет импортированные идентификаторы с существующими в базе данных аудиторий (для того же пользователя в том же приложении) с целью обогащения данных об аудитории для загрузки Партнёрам.
* Загружается Партнёрам в соответствии с политикой идентификации пользователей вашей учетной записи.
* Необходимо импортировать с использованием функции импорта V2.0, описанной в этой статье.

**Импортированная аудитория «как есть»:**

* Не проходит сопоставление идентификаторов и обогащение данных.
* Загружается Партнёрам без учёта политики идентификации пользователей вашей учетной записи (то есть все импортированные идентификаторы загружаются Партнерам).
* Можно импортировать с помощью функции импорта V2.0 (описанной в этой статье).

> 🚧 **Важно!**
>
> * Все аудитории, существующие по состоянию на 23 ноября 2021 г., **обозначаются как аудитории «как есть» и не могут быть изменены на стандартные аудитории.** Вы можете продолжать обновлять эти аудитории по мере необходимости, используя функцию импорта V2.0 (описанную в этой статье).
> * Вы можете иметь до 500 активных импортированных аудиторий одновременно.
> * Только администратор может назначить новую импортированную аудиторию как аудиторию «как есть».
> * При импорте аудитории с CUID в качестве идентификатора, связь CUID должна быть получена AppsFlyer при установке (а не только в событиях после установки) для полной привязки к соответствующим устройствам и успешного обогащения данными идентификаторов устройств (например, GAID, IDFA). <Anchor target="_blank" href="/marketers/ru/docs/customer-user-id-field-cuid#установка-cuid">Узнать больше</Anchor>

## Процедуры импорта аудитории

Импортируйте аудиторию, загрузив файл CSV или используя API импорта аудитории.

<Accordion title="Импорт файла CSV">

Подготовьте CSV файл со следующими характеристиками:

**Формат**

* Один столбец для каждого загружаемого идентификатора пользователя.
* Строка заголовка с именем идентификатора в каждом столбце (все строчные буквы).
* Нет пустых строк.
* Максимальное количество строк: 1 млн
* Если вы подготавливаете файл с помощью Excel, сохраните его как **CSV (с разделителями-запятыми) (\*.csv)**, как показано на следующем изображении:

<Image alt="CSV.jpg" src="https://files.readme.io/863505596fd525ff0750f05db70413e9aaee51beb208bd0fbc8ab718ad4e4576-32897281151633.jpg" width="339px" />

#### Хэш идентификатора.

> 📘 **Примечание:**
>
> Этот формат CSV предназначен для импорта сегментов аудиторий. Если вместо этого вы импортируете данные атрибутов пользователей, см. <Anchor target="_blank" href="/marketers/ru/docs/audiences-create-better-audiences-with-user-attribute-data">Create better audiences with user attribute data</Anchor>, где используется другой формат CSV без строки заголовков.

**Столбцы и идентификаторы**

* Данные распознаются с использованием строки заголовка для идентификации данных в каждом столбце, поэтому:
  * Нет никаких требований к конкретному порядку столбцов.
  * Нет необходимости включать столбцы для идентификаторов, которые не загружаются.
  * Вы можете импортировать столько идентификаторов, сколько хотите, в один CSV файл, если каждая строка содержит необходимые идентификаторы, как указано ниже.
* Доступные идентификаторы:
  * app\_id (идентификатор приложения)
  * IDFV
  * IDFA
  * gaid
  * oaid
  * imei
  * cuid
  * emails
  * телефон
  * телефон\_e164
  * braze\_id
  * amplitude\_id  

    **Примечание.** Дополнительные идентификаторы, такие как электронные адреса и телефоны, должны быть либо в зашифрованном формате sha256, либо оставлены пустыми.
* Обязательные идентификаторы:
  * Для Android аудиторий: **app\_id** + один из: **gaid** ИЛИ **oiad** ИЛИ **imei** ИЛИ **cuid** ИЛИ **braze\_id** ИЛИ **amplitude\_id**
  * Для iOS аудиторий: **app\_id** + один из: **idfv** ИЛИ **cuid** ИЛИ **braze\_id** ИЛИ **amplitude\_id**
* В соответствии с соблюдением правовых норм Google о <Anchor target="_blank" href="/marketers/ru/docs/audiences-user-identifier-policy#eu-digital-markets-act">Цифровом законе о рынках (DMA)</Anchor> от 6 марта 2024 года, при импорте аудитории «как есть» необходимо добавить два дополнительных столбца согласия AppsFlyer. Они:

| Столбцы согласия AppsFlyer | Поле Google | ценности, значения | Объяснение поля |
| --- | --- | --- | --- |
| <span id="ad_personalization"></span>ad\_personalization\_enabled | ad\_personalization | true\/false | Дал ли пользователь согласие Google на использование своих данных для персонализированной рекламы? |
| <span id="ad_user_data"></span>ad\_user\_data\_enabled | ad\_user\_data | true\/false | Дал ли пользователь согласие на отправку своих данных в Google? |

Если поля согласия не заполнены значениями, они будут отправлены в Google как «Не указано» и, скорее всего, не будут включены в аудиторию на стороне Google. Заполнение этих полей гарантирует максимальное включение пользователей из <Anchor target="_blank" href="https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Glossary:European_Economic_Area_(EEA)">Европейской экономической зоны (ЕЭЗ)</Anchor> в ваши аудитории Google.

<span id="01ECF4ZD0RB90HZC6ZFNTKMDSG"></span>**Чтобы создать и импортировать новую аудиторию с помощью CSV файла:**

1. На левой панели AppsFlyer перейдите в раздел **Вовлеченность** > **Аудитории**.
2. Нажмите **Новая аудитория**.
3. Выберите **Импортировать аудиторию**.  
   Откроется окно **Импорт аудитории**.
4. Введите уникальное **Имя аудитории.Примечание:** Названия аудиторий не могут содержать специальные символы (" ’ # % & * + / : ; `< = >` ? ( ) [ ] `{ }` \ | ~)
5. Выберите платформу аудитории: **Android** или **iOS.**
6. Укажите, является ли эта аудитория [**стандартной** аудиторией или аудиторией **как есть**](/docs/audiences-import-audience-segments-from-internal-systems#типы-импортированных-аудиторий).
7. Для стандартной аудитории оставьте флажок снятым.
8. Для аудитории как есть установите флажок. (**Примечание:** Эта опция доступна только администраторам.)
9. Нажмите **Далее**.  
   **Отображается вкладка Импорт.**
10. В разделе **Импорт с помощью CSV** оставьте значение по умолчанию **Добавить новые устройства/пользователей** (так как это новая аудитория).
11. Выберите CSV файл для загрузки.  
    Дождитесь сообщения с подтверждением **Загружено успешно.**
12. Нажмите **Далее**.  
    **Отображается вкладка Подключиться.**
13. **(Необязательно)** Следуйте инструкциям по <Anchor target="_blank" href="/marketers/ru/docs/audiences-guide#connect-an-audience-to-media-partners">подключению аудитории к партнерам</Anchor>.
14. Нажмите **Готово.**

Ваша аудитория теперь видна на дэшборде аудиторий, она импортирована и подключена к партнерам. Однако обратите внимание, что недавно импортированный список аудиторий пока недоступен для отправки партнерам, так как обработка данных выполняется с <Anchor target="_blank" href="/marketers/ru/docs/about-data-freshness-and-timezone-support#eod">свежестью данных ежедневно</Anchor>.

**Чтобы обновить существующую аудиторию с помощью CSV файла:**

1. На левой панели AppsFlyer перейдите в раздел **Вовлеченность** > **Аудитории**.
2. Нажмите на название аудитории, которую хотите обновить.  
   Откроется экран **Изменить аудиторию** с отображаемой вкладкой **Определить**.
3. Если вы хотите изменить название аудитории, вы можете сделать это здесь. В противном случае выберите вкладку **Импорт**, чтобы загрузить новый CSV файл.
4. В разделе **Импорт с помощью CSV** выберите, что делать с загруженным списком:
5. **Добавить новые устройства/пользователей:** Добавьте идентификаторы устройств/пользователей к существующей аудитории.
6. **Удалить устройства/пользователей из существующей аудитории:** Удалите идентификаторы устройств/пользователей в загруженном списке из аудитории.
7. **Перезаписать существующую аудиторию новыми устройствами/пользователями:** Замените всю аудиторию загруженным списком.
8. Выберите CSV файл для загрузки.  
   Дождитесь сообщения с подтверждением **Загружено успешно.**
9. Нажмите **Далее**.  
   **Отображается вкладка Подключиться.**
10. При необходимости внесите изменения в <Anchor target="_blank" href="/marketers/ru/docs/audiences-guide#connect-an-audience-to-media-partners">подключение к партнерам</Anchor> для этой аудитории.
11. Нажмите **Готово.**

Ваша аудитория обновлена с использованием CSV файла. Однако следует отметить, что обновлённый список аудитории ещё не загружен Партнерам, так как импортированные аудитории обрабатываются с <Anchor target="_blank" href="/marketers/ru/docs/about-data-freshness-and-timezone-support#eod">ежедневным обновлением данных</Anchor>.

<Accordion title="Использовать API импорта аудитории">

API импорта аудитории используется для добавления или удаления устройств из аудитории.

**Чтобы импортировать новую аудиторию с помощью API:**

1. На левой панели AppsFlyer перейдите в раздел **Вовлеченность** > **Аудитории**.
2. Клик **Новая аудитория.**
3. Выберите **Импортировать аудиторию**.  
   Откроется окно **Импорт аудитории**.
4. Введите уникальное **Имя аудитории.**  
   **Примечание:** Названия аудиторий не могут содержать специальные символы (" ’ # % & * + / : ; `< = >` ? ( ) [ ] `{ }` \ | ~)
5. Выберите платформу аудитории: **Android** или **iOS.**
6. Укажите, является ли эта аудитория [**стандартной** аудиторией или аудиторией **как есть**](/docs/audiences-import-audience-segments-from-internal-systems#типы-импортированных-аудиторий).
   * Для **стандартной аудитории** оставьте флажок неотмеченным.
   * Для **аудитории «как есть»** установите флажок (обратите внимание, что эта опция доступна только администраторам). <Anchor target="_blank" href="/marketers/ru/docs/audiences-user-identifier-policy#импорт-аудиторий">Два дополнительных поля согласия</Anchor> требуются при импорте аудитории «как есть» в соответствии с соблюдением правовых норм Google Закона о цифровых рынках (DMA) от 6 марта 2024 года. Заполнение этих полей гарантирует максимальное включение пользователей из <Anchor target="_blank" href="https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Glossary:European_Economic_Area_(EEA)">Европейской экономической зоны (ЕЭЗ)</Anchor> в ваши аудитории Google.
7. Нажмите **Сохранить**.  
   Отображается страница импорта.
8. В разделе **Импорт с помощью API** оставьте значение по умолчанию **Добавить новые устройства/пользователей** (так как это новая аудитория).
9. Скопируйте URL-адрес запроса API со страницы <Anchor target="_blank" href="https://dev.appsflyer.com/hc/reference/audience-import-post">Импорт нового API аудитории</Anchor> (токен API уже включен).
10. Затем скопируйте и вставьте тело запроса API.
11. Нажмите **Готово**.  
    **Отображается вкладка Подключиться.**
12. **(Необязательно)** Следуйте инструкциям по <Anchor target="_blank" href="/marketers/ru/docs/audiences-guide#connect-an-audience-to-media-partners">подключению аудитории к партнерам</Anchor>.
13. Нажмите **Готово.**
14. Подготовьте запрос API, включая идентификаторы пользователя/устройства, и отправьте его POST в AppsFlyer.

**Чтобы обновить существующую аудиторию с помощью API:**

1. На левой панели AppsFlyer перейдите в раздел **Вовлеченность** > **Аудитории**.
2. Нажмите на название аудитории, которую хотите обновить.  
   Откроется экран **Изменить аудиторию** с отображаемой вкладкой **Определить**.
3. Если вы хотите изменить название аудитории, вы можете сделать это здесь. В противном случае выберите вкладку **Импорт**.
4. В разделе **Импорт с помощью API** выберите, что делать с загруженным списком:
5. Добавить новые устройства/пользователей: Добавьте идентификаторы устройств/пользователей в существующую аудиторию.
6. **Удалить устройства/пользователей из существующей аудитории:** Удалите идентификаторы устройств/пользователей из существующей аудитории.
7. Скопируйте **URL-адрес запроса API** со страницы <Anchor target="_blank" href="https://dev.appsflyer.com/hc/reference/audience-import-post">Импорт новой аудитории API</Anchor> (токен API уже включен). **Примечание:** Изменение этой опции изменяет путь к конечной точке в копируемом коде. Обязательно используйте правильную конечную точку для действия, которое вы предпринимаете (в этом и будущих запросах API).
8. Затем скопируйте **тело запроса API.**
9. Нажмите **Далее**.  
   **Отображается вкладка Подключиться.**
10. При необходимости внесите изменения в <Anchor target="_blank" href="/marketers/ru/docs/audiences-guide#connect-an-audience-to-media-partners">подключение к партнерам</Anchor> для этой аудитории.
11. Нажмите **Готово.**
12. Подготовьте запрос API, включая идентификаторы пользователя/устройства, и отправьте его POST в AppsFlyer.

**Примечание:** При импорте через API для обновления аудитории потребуется 24 часа.

**Ограничения API**

* Вы можете добавлять устройства только в одну аудиторию за один запрос.
* За один запрос можно удалить устройства только из одной аудитории.
* Вы можете отправить до 10 000 идентификаторов устройств за один запрос.
* Вы можете отправлять до 350 запросов в минуту.
