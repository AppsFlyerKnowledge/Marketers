## Настройка атрибуции рекламы Amazon Fire TV

Владельцы приложений могут атрибутировать установки приложения и события в приложении, связанные с рекламой Amazon Fire TV.

Требования: 

1. <Anchor target="_blank" href="https://developer.amazon.com/docs/fire-tv/getting-started-developing-apps-and-games.html">Разработайте приложение для Amazon Fire TV.</Anchor>
2. <Anchor target="_blank" href="https://developer.amazon.com/apps-and-games">Опубликуйте приложение в Amazon Appstore</Anchor>.
3. <Anchor target="_blank" href="/marketers/ru/docs/set-up-multi-store-android-attribution#настройка">Настройте атрибуцию</Anchor> и просмотр для установок приложения Amazon Fire TV и данных в приложении.  
   Используйте метод настройки для одного или нескольких приложений.  
   

| Метод настройки | Description(Описание) |
| --- | --- |
| <Anchor target="_blank" href="/marketers/ru/docs/set-up-multi-store-android-attribution#single-dashboard-apk-preparation">Одно приложение</Anchor> | Просматривайте объединенные результаты для одного приложения по внешним магазинам приложений |
| <Anchor target="_blank" href="/marketers/ru/docs/set-up-multi-store-android-attribution#dashboard-per-store-apk-preparation">Несколько приложений</Anchor> | <ul><li>Просматривайте отдельные результаты по внешним магазинам приложений для каждого приложения</li><li>Для рекламы Amazon Fire: данные об установках из Amazon Appstore связаны с каждым приложением</li></ul> |

4. <Anchor target="_blank" href="/marketers/ru/docs/testing-the-sdk-integration-for-marketers#testing-from-the-dashboard">Протестируйте интеграцию</Anchor>, используя метод тестирования Android SDK на дэшборде AppsFlyer.
