> **Краткий обзор.** Изменяйте названия кампаний, не создавая дублирования данных.

## Изменения в названиях кампаний

Изменение названий кампаний влияет на отображение **совокупных данных** на дэшбордах и в отчетах. AppsFlyer отображает кампании, используя в качестве ключа идентификатор кампании. Если с одним и тем же идентификатором кампании связано несколько названий, для отображения данных используется последнее указанное название.

* Хотя в этой статье мы упоминаем изменения названий **кампаний**, те же правила применяются к изменениям названий групп объявлений и отдельных объявлений.
* Изменение названия влияет на отображение всех данных, связанных с кампанией, включая установки, события в приложении, расходы и доходы.
* Большинство рекламных сетей поддерживают изменение названий кампаний, но некоторые этого не делают, и в таких случаях вы можете увидеть дублирующиеся строки с одинаковыми данными.
* Изменение названий не влияет на сырые данные.

В следующей таблице показано, какие дэшборды и отчеты поддерживают изменение названия кампании.

| Дэшборд/отчет | Поддерживает изменение названия кампании |
| --- | --- |
| Обзорный дэшборд | Да, за исключением представления CTV |
| Дэшборд активности | Да |
| Ретаргетинг | Да |
| API когорт | Да |
| Pull API | Не поддерживается в Pull API V5 и ниже |
| Дэшборд сводной таблицы Pivot | Нет |
| Кастомизируемые панели управления | Нет |
| Дэшборд удержания клиентов | Нет |
| Дэшборд событий | Нет |
| Дэшборд Protect360 | Нет |
| ETL по затратам | Да |
| Обзорный дэшборд SKAN | Нет |

> 📄 **Пример**
>
> * 1 января запущена кампания **example\_a1**.
> * 2 января название кампании было изменено с **example\_a1**на **example\_a2**.
>

> | --- | --- | --- | --- | --- |
> | 1 января | example\_a1 | 123 | 100 | 100 долл. |
> | 2 января | example\_a2 | 123 | 200 | 200 долл. |
>

### Практические рекомендации:

* Большинство рекламных сетей поддерживают изменение названий кампаний, но некоторые этого не делают, и в таких случаях вы можете увидеть дублирующиеся строки с одинаковыми данными. Чтобы избежать подобных аномалий отображения, убедитесь, чтокампаниям присвоен уникальный идентификатор.
* Не используйте одно и то же название кампании с разными идентификаторами кампании.
* Не используйте одно и то же название объявления с разными идентификаторами объявлений.
