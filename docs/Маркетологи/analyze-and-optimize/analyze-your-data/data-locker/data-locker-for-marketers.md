> **Краткий обзор:** Data Locker отправляет данные отчетов в облачное хранилище для загрузки в ваши системы бизнес-аналитики. Вы можете выбрать между различными вариантами: корзина AppsFlyer в AWS или принадлежащее вам хранилище в AWS, GCS, Яндекс, BigQuery и Snowflake. Data Locker поддерживает [различные хранилища](/docs/data-locker-for-marketers#multipleconnections-principles-more-than-one-destination). Это означает, что вы можете отправлять все данные в несколько хранилищ, разделять данные по хранилищам или сочетать оба варианта.

## Обзор

## Настройка параметров отчета Data Locker

Чтобы настроить конфигурацию Data Locker, выполните следующие шаги для подключения вашего облачного сервиса, определения настроек экспорта и настройки содержания отчета:

<div id="1-set-up-your-cloud-service" />

<Accordion title="1. Настройка вашего облачного сервиса">

Вы можете подключить свой Data Locker к одному или нескольким поставщикам облачных сервисов. См. ниже инструкции о том, как настроить их для работы с Data Locker:

* Корзина <Anchor target="_blank" href="/marketers/ru/docs/data-locker-cloud-service-setup#aws-storage">AWS</Anchor>
* Корзина <Anchor target="_blank" href="/marketers/ru/docs/data-locker-cloud-service-setup#gcs-storage">GCS</Anchor>
* [Бета] <Anchor target="_blank" href="/marketers/ru/docs/data-locker-cloud-service-setup#beta--azure-storage">Azure</Anchor> Blob
* [Бета] Корзина на <Anchor target="_blank" href="/marketers/ru/docs/data-locker-cloud-service-setup#yandex">Яндекс</Anchor>
* Хранилище данных <Anchor target="_blank" href="/marketers/ru/docs/data-locker-cloud-service-setup#bigquery">BigQuery</Anchor>
* Хранилище данных <Anchor target="_blank" href="/marketers/ru/docs/data-locker-cloud-service-setup#snowflake">Snowflake</Anchor>

**Важно!** Если у вас нет подписки на Data Locker и вы имеете доступ к данным SKAN или когортной аналитике, вы должны выполнить процедуру настройки облачного хранилища, принадлежащего маркетологу.

</Accordion>

<div id="2-add-a-connection-to-your-cloud-service" />

<Accordion title="2. Добавьте подключение к вашему облачному сервису">

После настройки учетной записи облачного сервиса для работы с Data Locker (см. «Настройка вашего облачного сервиса» выше) создайте соединение в Data Locker, используя учетные данные вашей учетной записи. Вы можете создать до двух соединений.

<div id="note" />

> 📘 **Примечание:**
>
> По умолчанию каждая учётная запись может открыть до **двух соединений Data Locker**. Если вам нужны дополнительные соединения, свяжитесь со своим менеджером по работе с клиентами.

Чтобы создать соединение с вашим облачным провайдером, выполните следующие действия:

1. В AppsFlyer перейдите из бокового меню в раздел **Экспорты** > **Data Locker**.
2. С правой стороны нажмите на **Новое соединение.**
3. В **Название соединения** введите название для вашего соединения. Используйте только строчные буквы, цифры и дефисы «-».
4. Нажмите на значок облачного сервиса, к которому вы хотите подключиться.
5. В зависимости от выбранного вами сервиса введите следующую информацию для подключения.

   <div id="aws-cloud-bucket-connection" />

   <Accordion title="Подключение к облачной корзине AWS">

   Перед настройкой соединения с AWS создайте корзину в AWS. Чтобы узнать, как, см. <Anchor target="_blank" href="/marketers/ru/docs/data-locker-cloud-service-setup#aws-storage">здесь</Anchor>.

   Чтобы настроить соединение:

   1. Введите название своей корзины AWS S3. Префикс `af-` является обязательным и должен быть введен вручную.
   2. Нажмите **Тестировать подключение**.
   3. Убедитесь в отсутствии сообщения об ошибке, указывающего на неверный путь к корзине.
   4. Выберите, нужно ли **сделать это подключение совместимым с Adobe Experience Platform**. Если выбрано, нажмите **Сохранить** и продолжите [выбор глобальных фильтров](#select-global-level-filters).
   5. Нажмите **Сохранить**.

   </Accordion>

   <div id="gcs-cloud-bucket-connection" />

   <Accordion title="Подключение к облачному хранилищу GCS">

   Чтобы настроить соединение:

   1. Введите **название вашей корзины GCS**.

   Чтобы настроить соединение:

   2. Нажмите **Тестировать подключение**.

<div id="3-set-the-report-output-settings" />

<Accordion title="3. Настройка параметров вывода отчета">

После настройки соединения с облачным сервисом вы можете продолжить настройку общих параметров отчетов вашего Data Locker. **Если вы используете BigQuery или Snowflake, вы можете пропустить этот шаг**.

1. В разделе **Настройки вывода отчета** выберите структуру папок ([разделение данных](/docs/data-locker-for-marketers#app-segregation)):
   * **Объединенная** (по умолчанию): Отчетные файлы включают записи из всех приложений.
   * **Разделение по приложениям:** Каждый отчетный файл посвящен одному приложению.
2. Выберите формат файла отчёта: Parquet (по умолчанию) или CSV.
3. Выберите тип сжатия файлов отчета:
   * Snappy (доступно только для файлов Parquet)
   * GZIP
4. Выберите максимальное количество строк для своего файла: 10k, 25k, 50, 100k, 200k или 500k. Большее количество строк в файле означает меньшее количество файлов, но больший размер файла.

   <div id="note-2" />

   > 📘 **Примечание:**
   >
   > В **Ожидаемом пути** вы можете просмотреть шаблоны путей для ваших отчетов. Примечание: Реальный путь может отличаться от отображаемого.


</Accordion>

<div id="select-global-level-filters" />

<Accordion title="4. Выберите фильтры глобального уровня">

Фильтры глобального уровня позволяют вам **фильтровать ваши отчеты по приложениям или медиа-источникам**. Эти фильтры применяются ко всем отчётам в вашем аккаунте Data Locker, но вы также можете установить их на уровне отчёта (см. [выбор фильтров на уровне отчётов](#select-the-report-level-filters) ниже). Если один и тот же фильтр применяется на обоих уровнях, фильтр уровня отчёта имеет приоритет.

Чтобы применить фильтр, выполните следующие действия:

1. В разделе **Отчёты** нажмите на фильтр и выберите элементы, которые нужно включить в отчёт. Например, нажмите на фильтр **Приложения** <Image alt="Untitled.png" src="https://files.readme.io/817568835d9f564c139dca673bf30f570f3f4984deb466b91509404b10634ef4-34623601353745.png" width="53px" /> и выберите приложения, которые нужно включать в отчёты.
2. Затем нажмите кнопку ввода (⏎).

</Accordion>

<div id="5-select-the-report" />

<Accordion title="5. Выберите группу отчётов">

Выберите отчёты, которые вы хотите получать в своём облачном сервисе. Отчёты разбиты на группы. Нажатие на название группы отчётов разворачивает или сворачивает группы.

* Чтобы выбрать отчёт, нажмите <Image alt="down.png" src="https://files.readme.io/3f59bcc54434374270c0099394a740cc650a3b4a1be0f3f34d298be1ebcad40c-34623601355409.png" width="20px" /> , чтобы развернуть группу отчётов. По каждому отчёту в группе показана следующая информация:
  * **Название отчёта:** наименование отчета.
  * **Название массива данных:** название массива данных, который содержит записи отчёта.
  * **Актуальность данных:** Как часто обновляется отчёт (например, каждый час, ежедневно или по версиям).
  * **Поля:** количество полей (или столбцов), которые вы выбрали для отчёта по сравнению с общим количеством доступных для выбора полей.

</Accordion>

<div id="customize-or-duplicate" />

<Accordion title="6. Настройки или дублирование отчёта">

После выбора одного или нескольких отчётов из группы отчётов вы можете либо **настроить оригинальный отчёт**, либо **создать отдельную пользовательскую копию**, продублировав его. Это позволяет вам адаптировать поля и фильтры отчёта под свои конкретные нужды, не внося изменения в оригинальную версию.

**Вариант A: Настройка оригинального отчёта**

1. Нажмите кнопку **Настроить** <Image alt="customize.png" src="https://files.readme.io/35f4653b944cd5dc81c6de76f8dcacd9c3413ea49915ba2b5865a244ede3c4b6-35437232722833.png" width="20px" /> рядом с названием отчёта.
2. Откроется редактор отчётов, позволяющий вам выбирать поля и применять фильтры.
3. Изменения будут сохранены в конфигурации оригинального отчёта.

*Примечание: таким образом изменяется способ доставки отчёта в ваше облачное хранилище.*

**Вариант Б: Дублирование отчёта**

* Нажмите <Image alt="Untitled 2.png" src="https://files.readme.io/b3792460554dedede76f7d78346490280d3bfe00d38696a04c6d8f6f283e0f20-34623592674321.png" width="5px" /> рядом с названием отчёта.
* Выберите **Дублировать** <Image alt="duplicate2.png" src="https://files.readme.io/d8fbf09b3a8e3839f80a0a4fec90e0360dc1c2a4a066bf58438364c0d8a15c65-35439088509073.png" width="17px" /> из выпадающего меню.
* Будет создана копия отчёта с префиксом `copy_of_`.
* Копия отчёта откроется в режиме редактирования для дальнейшей настройки.

*Совет: дублирование идеально подходит для создания разных вариантов отчёта для различных целей.*

После того, как вы решите, будете ли вы настраивать или дублировать отчёт, настройте поля отчёта, как описано на следующем шаге.

</Accordion>

<div id="6-select-the-report-fields" />

<Accordion title="7. Выбор полей отчёта">

Как только вы выбрали настройку или дублирование отчёта, следующим шагом будет определение, какие поля данных должны быть включены в него. Каждый отчёт содержит полный набор доступных полей, и вы можете включить только то, что актуально для вашего анализа или интеграции. По умолчанию выбраны все поля, но вы можете настроить отчёт, внеся изменения вручную.

Как выбрать поля для включения в отчёт:

1. В диалоговом окне выбранного отчёта, во вкладке **Поля**, наведите курсор на поле, чтобы увидеть его описание.

## Разрешения для пользователя

Доступ к Data Locker могут получить как администраторы, так и члены команды с необходимыми разрешениями.

* Администраторы могут иметь доступ к странице Data Locker, создавать и управлять всеми соединениями, добавлять редакторов и назначать владельцев для существующих соединений.
* Члены команды могут иметь доступ к странице Data Locker, редактировать существующие подключения, которыми они владеют, или создавать новые подключения. Они не могут управлять правами владельца (устанавливать владельца и редакторов), даже если они являются владельцами учётной записи.

## Архитектура хранилища данных

<div id="zd-overview" />

<div id="overview" />

<Accordion title="Обзор">

Структура данных в хранилище зависит от того, в какое хранилище отправляются данные: облачное или локальное. Описанная здесь структура папок относится к облачному хранилищу (корзинам). В случае локального хранилища данных учитывайте, что ссылка на папки относится к просмотрам.

Данные записываются в выбранный вами тип хранилища. Если вам нужно облачное хранилище, тогда это хранилище AppsFlyer в AWS или ваше хранилище в AWS, GCS или Яндекс. Вы можете в любой момент перейти с одного варианта на другой или настроить отправку некоторых или всех данные в несколько хранилищ.

Данные в облачной корзине организованы с помощью иерархической структуры папок по типам отчетов, дате и времени. Ниже представлен пример такой структуры.

<Image align="center" alt="DLFolderOVerview.png" src="https://files.readme.io/78f360ec1df72253e5b2cd725f3eecf4e17548a7f06b544a94a75a2c319d77a0-18107910420369.png" />

Данные конкретного отчета содержатся в папках по часам (h), связанных с этим отчетом:

* Количество часовых папок зависит от частоты обновления данных (раз в час, ежедневно или с контролем версий).
* Данные предоставляются в сжатых файлах Snappy или GZIP, или в виде несжатых файлов в формате Parquet или CSV.
* Файлы с данными состоят из столбцов (полей).
* Структура схемы (поля) <Anchor target="_blank" href="/marketers/ru/docs/data-locker-advertiser-reports#user-journey">отчетов о пути пользователя</Anchor> идентична и зависит от выбранных вами полей. Другие отчеты имеют свои собственные явные поля, так называемые, отчеты без схемы. Доступные отчеты и ссылки на спецификации отчетов см. в отчетах <Anchor target="_blank" href="/marketers/ru/docs/data-locker-advertiser-reports#user-journey">Data Locker для маркетолога</Anchor>.

</Accordion>

Пример. Часовой пояс приложения UTC+10 (Сидней, Австралия). Пример. Часовой пояс приложения UTC−7 (Лос-Анджелес, США). Чтобы получить все почасовые данные за вторник (Лос-Анджелес), вы должны импортировать следующие папки: Вторник: h=7–23 (с 07:00 до 23:00) и late, среда: h=0–6 (с 00:00 до 06:00) и 7-8 (с 07:00 до 08:00). Это значит, что самые актуальные данные за конкретный день предоставляются несколько раз. Поскольку данные могут продолжить обновляться из-за позднего поступления или уточнения данных, появляется несколько версий одного отчета. При этом последняя версия – самая точная.<br /><br />Отчеты за определенный день содержатся в папке версий за этот день. Так, данные могут записываться в папку за 1 января позже, например, 14 января. Если корзина принадлежит вам, рекомендуем настроить в облачном сервисе уведомление, запускающее процесс импорта (<Anchor target="_blank" href="https://docs.aws.amazon.com/AmazonS3/latest/userguide/NotificationHowTo.html">AWS</Anchor> \| <Anchor target="_blank" href="https://cloud.google.com/storage/docs/pubsub-notifications">GCS</Anchor>) |

<div id="notice-to-security-officers-in-the-case-of-customer-controlled-storage" />

#### **Уведомление сотрудникам службы безопасности о хранилищах, контролируемых клиентом**

Обратите внимание:

* Корзина или хранилище предназначены только для использования AppsFlyer. Никакой другой субъект не должен записывать данные в этот вариант хранения.
* Вы можете удалить данные в хранилище через 25 часов после того, как мы их запишем.
* Данные, которые мы записываем в хранилище, являются копией данных, уже находящихся на наших серверах. Данные продолжают находиться на наших серверах в соответствии с нашей политикой хранения данных.
* По техническим причинам мы иногда удаляем и переписываем данные. По этой причине нам нужны разрешения на удаление и списки. Эти разрешения не несут для вашей безопасности никакой угрозы. В отношении списков мы являемся единственным субъектом, осуществляющим записи в корзине. Что касается удаления, мы можем восстановить данные.
* Для получения дополнительной информации обратитесь в нашу службу безопасности по адресу [hello@appsflyer.com](mailto:hello@appsflyer.com) или к своему менеджеру.

<div id="multipleconnections-principles-more-than-one-destination" />

<Accordion title="Принципы множественных подключений (более одного пункта назначения)">

В Data Locker вы можете отправить некоторые или все ваши данные в два разных хранилища (определенные в настройках подключения). Например, вы можете отправить данные приложения A в AWS, а данные приложения B – в GCS.

Каждое подключение состоит из полного набора настроек Data Locker, включая пункт назначения. Настройки подключений не зависят друг от друга.

При управлении подключениями учитывайте следующее:

* В настройках Data Locker подключения отображаются на вкладках. Каждое подключение имеет собственную вкладку настроек, на которой можно управлять подключением. Значок каждой вкладки представляет тип хранилища.
* Чтобы просмотреть сведения о подключении, дублировать или удалить подключение, нажмите ⋮ (опции).

</Accordion>

<div id="listing-files-and-folders" />

### Список файлов и папок

В вашей корзине Data Locker есть три типа папок:

* Тип отчета `t=`
* Дата `dt=`
* Час `h=`

Чтобы вывести список всех отчетов определенного типа:

```bash
aws s3 ls s3://af-ext-reports/{home-folder}/data-locker-hourly/t=installs/
```

Чтобы вывести список всех отчетов определенного типа за определенный день:

```bash
aws s3 ls s3://af-ext-reports/{home-folder}/data-locker-hourly/t=installs/dt=2019-01-17
```

Чтобы вывести список всех отчетов определенного типа за определенный час определенного дня:

```bash
aws s3 ls s3://af-ext-reports/{home-folder}/data-locker-hourly/t=installs/dt=2019-01-17/h=23
```

Чтобы скачать файлы за определенную дату:

```bash
aws s3 cp s3://af-ext-reports/<home-folder>/data-locker-hourly/t=installs/dt=2020-08-01/h=9/part-00000.gz ~/Downloads/
```

   * **Путь**: `{Имя корзины}/{Домашняя папка}` Например: **af-ext-reports/1234-abc-ffffffff**
5. Закройте окно. Для этого нажмите Х в верхнем правом углу.
6. Выберите соединение.  
   Отобразятся каталоги данных.

</Accordion>

<Accordion title="Браузер Amazon S3">

**Прежде чем начать**:

* Установите браузер Amazon S3.
* В AppsFlyer перейдите в Data Locker и получите информацию с панели учетных данных.

**Чтобы настроить браузер Amazon S3**:

1. В браузере S3 нажмите **Accounts (Аккаунты)** > **Add** **New Account (Добавить новый аккаунт)**.  
   Открывается окно Добавить новый аккаунт. [![mceclip0.png](https://files.readme.io/f7ea8b02f27a5e7eaf89b578b177a9e1a9f34273eaa41d41652156a6dbb23d5c-32966274485009.png)](https://files.readme.io/f7ea8b02f27a5e7eaf89b578b177a9e1a9f34273eaa41d41652156a6dbb23d5c-32966274485009.png)
2. Заполните поля следующим образом:
   * **Account Name (Имя учетной записи):** произвольный текст.
   * **Access Key ID (Ключ доступа):** скопируйте ключ доступа AWS, как он отображается на панели учетных данных в AppsFlyer.
   * **Secret Access Key:** скопируйте секретный ключ доступа к корзине, как он отображается на панели учетных данных в AppsFlyer.
   * Выберите **Encrypt Access Keys** с помощью пароля и введите пароль. Запишите этот пароль.
   * Выберите **Use secure transfer** (Безопасная передача данных).
3. Выберите **Сохранить изменения**.
4. Нажмите **Buckets (Корзины)** > **Add External Bucket (Добавить внешнюю корзину)**.  
   Откроется окно Add External Bucket (Добавить внешнюю корзину).  
   <Image align="center" alt="mceclip2.png" src="https://files.readme.io/88dd43f62dbd68d0295b52a7f7b9b09449bd915e6a6d52703c24a50583e05a6e-32966264054929.png" width="433px" />
5. Введите **Bucket name (Имя корзины).** Название корзины имеет следующий формат: `{Имя корзины}/{Домашняя папка}`. Значения, необходимые для имени корзины и домашней папки, появятся в окне учетных данных.
6. Нажмите **Добавить внешний бакет.** Нажмите **Добавить внешнюю корзину**.Корзина создана и отображается на левой панели окна.  
   Теперь вы можете получить доступ к файлам Data Locker.
