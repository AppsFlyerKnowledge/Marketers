> **At a glance:** Продвинутые отчеты предоставляют консолидированные, типизированные данные на уровне событий с единообразными названиями для мобильных, веб- и CTV (connected TV)-платформ в одном отчете, чтобы вы тратили меньше времени на подготовку данных и больше — на их использование.

## О продвинутых отчетах

В разделах ниже описано, как продвинутые отчеты консолидируют данные по продуктам, поставляются готовыми к использованию без дополнительной подготовки и позволяют точно контролировать, какие данные включает каждый отчет.

### Консолидированные данные по продуктам данных

Advanced Reports организуют сырые данные на уровне событий по продуктам данных.

* Каждый отчет охватывает один полный продукт данных, поэтому не нужно объединять разрозненные файлы.
* Данные с мобильных, веб- и CTV-платформ хранятся в одном файле с общей схемой.

### Данные, готовые к использованию

Устаревшие отчеты возвращали все поля в виде обычных строк с несогласованными названиями, поэтому перед началом анализа командам приходилось приводить данные к нужным типам, переименовывать поля и согласовывать схемы. В Advanced Reports базовая подготовка уже выполнена:

* **Типизированные поля:** целые числа, булевы значения, временные метки и перечисления вместо обычных строк.
* **Единая схема:** согласованная, проверенная структура для всех продуктов данных.
* **Понятные названия полей:** единообразны и понятны во всех отчетах, что упрощает работу с данными напрямую в инструментах BI (business intelligence), в рабочих процессах аналитиков и в приложениях на базе ИИ.

### Точный контроль над получаемыми данными

Advanced Reports позволяют настроить каждый отчет точно под ваши потребности без какой-либо постобработки:

* **Настройка схемы:** добавляйте или удаляйте поля в соответствии с требованиями ваших последующих процессов.
* **Фильтры на уровне отчета:** ограничивайте данные определенной платформой, типом конверсии, страной или событием.
* **Готовые шаблоны:** мгновенно начинайте работу с конфигурациями полей и фильтров, разработанными для типовых кейсов.

## Продвинутые отчеты vs.

В таблице ниже показаны основные различия между Advanced Reports и устаревшими отчетами.

|  | Устаревшие отчеты | Продвинутые отчеты |
| --- | --- | --- |
| **Структура данных** | Фрагментированы по нескольким отчетам | Консолидированы: один отчет охватывает весь продукт данных |
| **Типы полей** | Все поля передаются как обычные строки | Типизированные поля: целые числа, логические значения, временные метки, перечисления |
| **Названия полей** | Несогласованные названия в разных отчетах; не оптимизированы для удобства чтения | **Понятные без дополнительных пояснений**, единообразные названия во всех отчетах |
| **Схема** | Несогласованно; различающаяся структура в разных отчетах | Единая проверенная схема для всех продуктов данных |
| **Охват платформ** | Отдельные отчеты для каждой платформы с разными схемами | Данные по мобильным устройствам, вебу и CTV объединены в одном отчете с общей схемой |
| **Параметр** | Базовый выбор фильтров | Множественный выбор фильтров на уровне отчета по нескольким измерениям, а также готовые шаблоны для типовых сценариев использования |
| **Готовность к ИИ и бизнес-аналитике** | Требовались приведение типов, выравнивание схемы, нормализация и переименование полей | Поля типизированы, валидированы и единообразно именованы, а их **понятные без пояснений** названия легко интерпретировать как людям, так и приложениям на базе ИИ |

## Доступные отчеты

Каждый отчет соответствует продукту данных — структурированному и подготовленному набору данных, представляющему определенную область ваших маркетинговых данных, например конверсии, вовлеченность или события пользователей. Сегодня доступны следующие отчеты.

<Accordion title="Типы взаимодействия">

Отчет Engagements объединяет данные о мобильных кликах и показах в рамках привлечения пользователей и ретаргетинга. Он предоставляет единое представление о взаимодействии пользователей с вашей рекламой, позволяя проводить углубленный анализ эффективности верхней части воронки, оценку креативов и каналов, а также оптимизацию стоимости и охвата на уровне вовлеченности.

* **Платформы:** мобильная
* **Актуальность данных:** 1–3 часа
* **Поля отчета:** [Загрузить пример отчета](https://docs.google.com/spreadsheets/d/e/2PACX-1vQcBDMTizVe22HrquKhPhPyprLa8k9_GptkfMNOl7-ai2dtiBp_D8gXTcgdUHlZpndAZjUqEzY-eqeR/pub?output=csv)

</Accordion>

<Accordion title="Конверсии">

Отчет о конверсиях дает полное представление обо всех установках приложения, включая органические и неорганические источники на мобильных, веб- и CTV-платформах. Централизуя данные конверсии, вы можете проводить комплексный анализ роста с помощью единого оптимизированного набора данных, а также точно измерять и оптимизировать эффективность маркетинга.

* **Платформы:** мобильные, веб, CTV
* **Актуальность данных:** 1–3 часа
* **Поля отчета:** [Загрузить пример отчета](https://docs.google.com/spreadsheets/d/e/2PACX-1vQmF8gMIBuWzS3aw7M8TSzuxS3MYNC0m1RZzPAND-1jP3MjDcRUZmvggoaZRDAKb5uI1R77sufCLQeU/pub?output=csv)

</Accordion>

<Accordion title="События конечных пользователей">

Отчет о событиях конечных пользователей содержит подробные данные о событиях в приложении, включая сессии, покупки, регистрации и прохождение уровней, на мобильных, веб- и CTV-платформах. Каждое событие обогащено полным контекстом атрибуции, что позволяет анализировать поведение пользователей, удержание и пожизненную ценность при полной прослеживаемости атрибуции.

* **Платформы:** мобильные, веб, CTV
* **Актуальность данных:** 1–3 часа
* **Поля отчета:** [Загрузить пример отчета](https://docs.google.com/spreadsheets/d/e/2PACX-1vRm4xYgov7i-xClroQR0eS5vtQvtOavmo-V9zWiGmZMOIyBmIl0swmfj34tYgVinIC7uZp0dyPXD8wI/pub?output=csv)

## Шаблоны отчетов

Шаблоны — это предварительно настроенные пресеты отчетов, предназначенные для типовых сценариев использования. Каждый шаблон связан с определенным продуктом данных и предварительно содержит поля и фильтры, наиболее подходящие для типовых сценариев использования этого отчета. При выборе шаблона автоматически загружаются нужные поля и фильтры. Перед сохранением вы можете изменить предварительно заполненное название отчета.

После сохранения отчет, созданный на основе шаблона, становится полностью независимым. Изменения в шаблоне не влияют на отчеты, уже сохраненные на его основе.

Доступны следующие предопределенные шаблоны:

| Название шаблона | Отчёт | Description(Описание) |
| --- | --- | --- |
| **Веб-конверсии** | Конверсии | Опорные точки атрибуции для веба, включая первые посещения, повторные посещения и события привлечения пользователей. Все последующие события пользователей наследуют сведения о кампании из этих конверсий. |
| **Веб-события** | События конечных пользователей | Все веб-события и сессии. Используйте этот отчет в качестве основного для анализа на уровне посещений и событий. |

## Фильтры на уровне отчета

Фильтры на уровне отчета позволяют ограничить отчет определенным подмножеством данных, например конкретной платформой, типом конверсии или страной.

Набор доступных фильтров зависит от продукта данных. В таблице ниже показано, какие фильтры поддерживаются для каждого отчета. Со временем появятся дополнительные фильтры.

| Отчёт | Доступные фильтры |
| --- | --- |
| **Конверсии** | Тип конверсии, страна, группа платформ, платформа, медиаисточник и приложение |
| **Типы взаимодействия** | Тип кампании, тип вовлеченности, страна, медиаисточник и приложение |
| **События конечных пользователей** | Название события, группа платформ, тип конверсии, страна, является основной атрибуцией, медиаисточник и приложение |
| **Кроссплатформенные события конечных пользователей** | Название события, группа платформ, тип конверсии, страна, является основной атрибуцией, медиаисточник и приложение |
