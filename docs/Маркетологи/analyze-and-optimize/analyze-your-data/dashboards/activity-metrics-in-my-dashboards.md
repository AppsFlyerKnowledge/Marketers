## О метриках активности

Метрики активности в Моих дэшбордах позволяют пользователям анализировать данные об активности, LTV и когортах в одном месте. Это позволяет вам отслеживать эффективность бизнеса и получать более глубокие инсайты. Для этого:

* Анализируйте **активность и вовлеченность пользователей** с учетом данных в реальном времени.
* Измеряйте **эффективность событий, выручку и тенденции сеансов.**  
  Получите унифицированное представление о LTV, фактических данных и когортах в одном дэшборде.
* Настройте отчеты с **ежедневной или ежемесячной** детализацией (Активные пользователи).

Примечание: В Моих дэшбордах раздел **Активность** был переименован в **Актуальные**. Это изменение уточняет, что данные метрики отражают реальные действия пользователей в пределах выбранного диапазона дат и не связаны с агрегацией LTV. Период «Актуальный» также применяется по умолчанию для показателей «Сессии», «Валовая прибыль» и «Общий доход».

## Информация на дэшборде

**Представление «Активность»**

Шаблон **Представление «Активность»** помогает маркетологам быстро оценивать производительность приложения, выявлять тенденции вовлечённости, анализировать доход и выявлять проблемы на ранних этапах, что ускоряет принятие решений на основе данных по кампаниям и платформам.

**Добавление виджетов на дэшборд**

Вы можете добавить виджеты на свой дэшборд, нажав кнопку **+ Создать новое** в правом верхнем углу дэшборда и выбрав тип виджета, который вы хотите создать: таблицу, KPI, таблицу внутренних событий приложения, диаграмму внутренних событий приложения, текст или пользовательскую метрику. Подробные инструкции можно найти <Anchor target="_blank" href="/marketers/ru/docs/my-dashboards#add-widget">здесь</Anchor>.

**Добавьте метрики в свою диаграмму или таблицу**

В Настройках диаграммы или Настройках таблицы, нажмите на Метрики + знак знак плюс.

Затем можно добавить «Группировать по» и выбрать Фильтры.

Подробные инструкции можно найти <Anchor target="_blank" href="/marketers/ru/docs/my-dashboards#add-metric">здесь</Anchor>.

## Доступные метрики активности

* Все метрики, кроме Активных пользователей, Активных пользователей за последние 31 день и DAU/MAU, также поддерживают периоды когорт и LTV.

| **метрику** | **Описание** |
| --- | --- |
| Активные пользователи | <ul><li>Количество уникальных активных пользователей, которые открывали приложение хотя бы один раз в течение выбранного периода, рассчитывается по сессиям в соответствии с выбранным параметром разбивки времени.</li><li>Если выбран ежедневный период, он отображается как DAU.</li><li>Если месячный, он отображается как MAU.</li><li>При просмотре в линейных диаграммах, столбчатых диаграммах или таблице, сгруппированной по дате, он отображается как DAU.</li><li>Чтобы узнать, как запрашивать отчёты с необработанными данными для показателей DAU и MAU, см.: <Anchor target="_blank" href="/marketers/ru/docs/calculate-daily-and-monthly-active-users-dau-and-mau">Рассчитать количество активных пользователей за день/месяц (DAU и MAU)</Anchor>.</li></ul> |
| Активные пользователи за последние 31 день | Количество уникальных пользователей (учитываются только один раз), которые открывали приложение хотя бы один раз за последние 31 день (не привязано к календарному месяцу). |
| DAU/;MAU | Показатель возврата пользователей (коэффициент удержания).<br /><br />Например, показатель DAU/MAU равный 50% означает, что средний пользователь открывал приложение 15 дней из предыдущих 31 дня.<br /><br />Соотношение DAU/MAU является мерой лояльности пользователей и дает представление об удержании клиентов.<br /><br />Формула: Ежедневные активные пользователи / активные пользователи за последние 31 день |
| Сессии | Сессии в течение выбранного диапазона дат. |
| Total Revenue (Общий доход) | Доход за выбранный период. Выручка состоит из покупок в приложении и доходов от рекламы. |
| Чистый доход | Чистая доход за выбранный период, агрегированная на основе параметра событие af\_net\_revenue. Для приложений, использующих показатель ROI360 дохода магазина, это валовый доход за вычетом комиссий и налогов магазина приложений (Net = Валовая выручка - комиссии магазина - налоги); расчет определяют сами приложения, которые отправляют af\_net\_revenue. |
| Первые визиты | Количество первых посещений веб-приложения. Подсчитано как строки, где conversion\_name = first\_visit. Доступно только для веб-приложений. |
| Повторные посещения | Количество неорганических повторных посещений веб-приложения. Подсчитано как строки, где conversion\_name = revisit. Доступно только для веб-приложений. |
| Привлечение пользователей | Доступно для кроссплатформенной атрибуции или веб-приложений. Для веб-приложений привлечение пользователя отражает первые посещения, если не настроено событие привлечения пользователя. Для мобильных приложений привлечение пользователя равно количеству установок. При просмотре нескольких приложений вместе показатель Привлечение пользователей = установки + первые посещения (или пользовательское веб-событие, настроенное клиентом). |

## Доступные метрики в приложении

| **метрику** | **Описание** |
| --- | --- |
| Коэффициент конверсии | Процент уникальных пользователей (атрибуции), совершивших событие. Формула: Уникальные пользователи события / атрибуции x 100 |
| Уникальные пользователи | Количество уникальных пользователей (атрибуций), которые выполнили событие |
| Среднее количество | Среднее количество раз, когда это событие было выполнено, в расчёте на одну атрибуцию.<br /><br />Формула: Количество событий / Атрибуций |
| eCPA (эффективная цена за действие) | Эффективная цена за действие (событие).<br /><br />Формула: Затраты / уникальные пользователи события |
| Количество | Количество раз, когда событие было выполнено |
| Доход | Доход, полученный от этого конкретного события |
| Рост ARPU | Средний доход на пользователя.<br /><br />Формула: Доход / уникальные пользователи (пользователи = атрибуции) |
| Валовая прибыль | Доход - затраты |
| ROAS д7 | Окупаемость инвестиций в рекламу.<br /><br />Формула: Доход / затраты * 100 |
| ROI | Окупаемость инвестиций.<br /><br />Формула: (Доходы - затраты) / затраты * 100 |
| Чистый доход | Чистый доход, полученный от данного события (после вычета комиссий магазина приложений и налогов). |
| Чистый ARPU | Средний чистый доход на одного пользователя.<br /><br />Формула: Доход / Уникальные пользователи (пользователи = атрибуции). |
| Чистая валовая прибыль | Чистый доход – стоимость |
| Чистый ROAS | Рентабельность рекламных расходов, рассчитанная на основе чистого дохода.<br /><br />Формула: Чистый доход/ Стоимость * 100 |
| Чистый ROI | Рентабельность инвестиций, рассчитанная на основе чистого дохода.<br /><br />Формула: (Доходы - затраты) / затраты * 100 |

**Показатели чистой выручки**

Показатели чистой выручки (чистый доход, чистый ROI, чистый ROAS, чистый ARPU, чистая валовая прибыль) отражают чистый, а не валовый доход. Чистый доход – это значение, передаваемое в af\_net\_revenue. Рекламодатель самостоятельно определяет способ его расчёта, например доход за вычетом комиссии магазина и/или налогов, валовая прибыль или доход за вычетом комиссии за обслуживание. Для приложений, использующих данные о доходе магазина в ROI360, AppsFlyer рассчитывает чистый доход как валовый доход за вычетом комиссии магазина приложений и налогов (Net = Gross − комиссия магазина − налоги).

Значение берётся из параметра af\_net\_revenue событий в приложении – аналогично тому, как для обычных метрик дохода используется параметр af\_revenue. Значение указывается в валюте транзакции, заданной параметром af\_currency (по умолчанию – USD).

Как формируется значение:

* Если для приложения включен **ROI360 дохода магазина**, AppsFlyer автоматически заполняет поле af\_net\_revenue в регистрируемых событиях покупок в приложении и подписок.
* В противном случае значение берётся из параметра af\_net\_revenue, передаваемого вами в событии в приложении.
* Если чистый доход не передаётся ни одним из этих способов, для метрики отображается значение N/A.

См. <Anchor target="_blank" href="/marketers/ru/docs/about-roi360-store-revenue">раздел «О выручке магазина ROI360</Anchor> и <Anchor target="_blank" href="/marketers/ru/docs/in-app-events-event-structure">Событиях в приложении — Структура событий»</Anchor> .

## Спецификации и ограничения

| **Спецификации** | **Примечание** |
| --- | --- |
| Актуальность данных | Для метрик «Когорты» и «Активность» режим реального времени не поддерживается для веб-приложений, CTV, а также приложений для ПК и консолей.<br /><br />**Примечание:** Показатели LTV для приложений CTV, ПК и консолей доступны в режиме реального времени — это ограничение относится только к данным «Активности» и «Когорт». |
| Детализация по времени | Для веб-приложений, CTV, ПК и игровых консолей данные о когортах и ​​активности доступны только с детализацией по дням. На этих платформах не поддерживается отображение еженедельных и ежемесячных данных. |
| Доход от рекламы | Данные в реальном времени не поддерживаются. |
| Метрики чистого дохода – периоды | Поддерживается для метрик «Активность» и «Когорты». Не поддерживается для LTV. |
| Показатели чистой выручки — актуальность данных | Работа в реальном времени не поддерживается. Данные станут доступны со следующего дня. |
| Метрики чистой выручки - доход от рекламы | События дохода от рекламы не учитываются в метриках чистого дохода.<br /><br />**Совет:** Чтобы увидеть чистый доход с учетом дохода от рекламы, создайте пользовательскую метрику, в которой доход от рекламы прибавляется к чистому доходу, например: Чистый доход + доход (событие: af\_ad\_revenue). См. <Anchor target="_blank" href="/marketers/ru/docs/beta-set-up-custom-metrics-in-my-dashboards">Настройка пользовательских метрик в Моих дэшбордах</Anchor>. |
| Метрики чистой выручки — источник атрибуции | Не поддерживается для SKAN и SSOT. |
| Показатели чистой выручки — платформы | Только для Android и iOS (мобайл). |
| Часовые пояса | Все метрики поддерживаются в местных часовых поясах, за исключением тех, которые доступны только в UTC:<ul><li>Активные пользователи за последние 31 день</li><li>DAU/;MAU</li><li>Активные пользователи с группировкой по месяцам (MAU)</li></ul> |
| Диаграммы | В настоящее время поддерживаются **DAU** в формате строки или столбца |
| Виджеты | Виджеты KPI и таблиц поддерживают все метрики активности. |
| Диапазон данных за день | Ограничен 62 днями на один просмотр |
| События отмены установки | Не включено в данные об активности |
| Исторические данные | До 3 лет (ежедневно) |
| Геогруппировка | Определяется по географии на момент установки; ограничивается 62 ведущими гео |
| Метрики сессий | <ul><li>Данные активности унифицированы для UA и ретаргетинга, начиная с 1 февраля 2025 года.</li><li>Чтобы открыть представление ретаргетинга, примените фильтр **«Тип атрибуции»** и выберите значения **«Повторные вовлечения»** и **«Реатрибуции»**.</li></ul> |
| Метрики объединённого представления | Все метрики поддерживаются только в объединенном представлении |
| Уникальные пользователи из событий в приложении и активные пользователи | Показатели **Уникальные пользователи из событий в приложении** и **Активные пользователи** в разделе «Мои дэшборды» рассчитываются с помощью алгоритма статистической оценки, который сокращает дублирование и обеспечивает целостное представление пользовательской активности. |
| Активные пользователи и актуальные уникальные пользователи: | Если выбранный диапазон дат включает сегодня и предыдущие дни, и виджет не сгруппирован по датам, данные за сегодня не отображаются. |
