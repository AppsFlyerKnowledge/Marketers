> **Краткий обзор.** Создавайте собственные настраиваемые дэшборды внутри AppsFlyer. Вы можете легко выбирать, называть и размещать данные в собственных настраиваемых отчетах.

## Кастомизируемые панели управления

Каждый настраиваемый дэшборд состоит из одного или нескольких виджетов с метриками привлечения пользователей. Чтобы выбрать метрики, формат представления данных, приложения и др., настройте виджет с помощью мастера настройки.

Доступные метрики аналогичны метрикам привлечения пользователей на обзорном дэшборде. Примечание! **Не сравнивайте** их с единым представлением или с представлением ретаргетинга на обзорном дэшборде.

Когда настраиваемый дэшборд задан, он доступен всем пользователям данного аккаунта.

<div id="dashboard-personalization" />

## Персонализация дэшборда

Вы можете персонализировать дэшборд, перемещая виджеты и изменяя их размер.

| Опция персонализации | Описание |
| --- | --- |
| Изменить размер виджета | Перетащите правый нижний угол виджета, чтобы изменить его размер. |
| Положение виджета | Перетащите виджет, чтобы изменить его расположение на дэшборде. |
| Действия | Наведите курсор на виджет в правом верхнем углу и нажмите «Действия». Для каждого виджета доступны следующие опции:<ul><li>Редактировать</li><li>Дублировать</li><li>Удаление</li><li>Экспорт CSV</li></ul> |

<div id="procedures" />

## Процедура

<div id="managing-dashboards" />

<Accordion title="Действия на дэшборде">

| Действие | Описание |
| --- | --- |
| Дублировать | Создает копию текущего дэшборда |
| Переименовать | Изменяет имя дэшборда |
| Экспорт PNG | Создает и загружает файл PNG |
| Удаление | Удаляет дэшборд |

</Accordion>

<div id="add-a-custom-dashboard" />

<Accordion title="Добавление настраиваемого дэшборда">

**Чтобы добавить настраиваемый дэшборд:**

1. В AppsFlyer в боковом меню выберите **Анализ** > **Настраиваемые дэшборды**.  
   Отображается дэшборд.
2. Нажмите + (Добавить новый дэшборд).
3. Введите **название вашего дэшборда**.
4. Нажмите **Добавить**.
5. Добавьте один или несколько виджетов, как описано в следующем разделе.

</Accordion>

<div id="managing-widgets" />

<Accordion title="Управление виджетами">

**Чтобы добавить виджет:**

1. Нажмите кнопку Добавить виджет.
2. Появится окно виджета.

   <Image align="center" alt="WidgetConfigure_us-en.png" src="https://files.readme.io/f04544d8cb8b1d946526c4546565fffb405e5113e09dac65e5a28e218a1170a7-360015793618.png" />
3. Настройте виджет. Воспользуйтесь приведенным ниже руководством по настройке виджета.
4. При необходимости добавьте другие виджеты.

**Руководство по настройке виджетов**

| Параметр | Описание |
| --- | --- |
| Тип виджета | ![WidgetType_us-en.png](https://files.readme.io/00174da67c1b5046033655aad2f0af815d5abb3229cdc7c2f225f689c8adc7d8-360015793638.png)<br /><br />Выберите тип виджета:<ul><li>Круговая Диаграмма</li><li>Столбиковая диаграмма</li><li>Линейная Диаграмма</li><li>Таблица Данных</li><li>География</li><li>метрику</li><li>Диаграмма воронки</li></ul> |
| Описание | Введите описание виджета. |
| Приложения | Выберите одно или несколько приложений, данные по которым следует отображать в виджете. Обратите внимание, если вы выберете все, это означает 100 первых приложений в вашем аккаунте. |
| KPI | <ul><li>Выберите KPI, которые следует отображать в виджете.</li><li>Таблица данных и гистограмма отсортированы в соответствии с первым выбранным KPI.</li></ul> |
| Группировать по | Выберите тип группировки |
| Показать топ | Введите количество отображаемых значений. |
| Pre-Covid | Если выбрана эта опция, будут отображаться данные до начала пандемии COVID-19, за период с 1 по 30 ноября 2019 г. |
| Фильтры | Используйте фильтры, чтобы ограничить данные в виджете:<ul><li>**Countries (Страны, гео)**</li><li>**Медиа-источники**</li><li>**Кампании**</li><li>**каналы**</li></ul>Выберите **Исключить органические**, чтобы явно исключить данные, не атрибутированные к какому-либо медиа-источнику. |

</Accordion>

<div id="export-widget-data" />

<Accordion title="Экспорт данных виджета">

<Image align="center" alt="Widget_table.png" src="https://files.readme.io/b04e80e16d0d34946e6783103fc6fbbdf89b390842db27226b4fdba6c1f7e506-360015717057.png" />

**Чтобы загрузить данные виджета в файл CSV**:

1. Убедитесь, что виджет содержит заголовок и данные.
2. В виджете выберите **Действия**.
3. Выберите **Экспортировать в CSV**.  
   Начнется скачивание файла.  
   Даты в файлах CSV имеют формат дд/мм/гггг. В Excel <Anchor target="_blank" href="https://answers.microsoft.com/en-us/msoffice/forum/msoffice_excel-mso_winother-mso_2010/how-to-convert-ddmmyyyy-to-mmddyyyy/41119ed6-4057-4598-a44c-1ebfdf301a43">их можно будет преобразовать в другой формат</Anchor>, например мм/дд/гггг.

</Accordion>

## Характеристики и ограничения

<div id="traits-and-limitations::6693dfa7" />

<Accordion title="Характеристики и ограничения">

| Специфика | Замечания |
| --- | --- |
| Доступ рекламной сети к отчету | Нет |
| Агентства | Не поддерживается |
| Прозрачность агентства | Да |
| Часовой пояс приложения | Если все приложения в аккаунте имеют одинаковую настройку часового пояса, данные отображаются по часовому поясу приложения. В противном случае данные отображаются по часовому поясу UTC. |
| Валюта приложения | Если все приложения в аккаунте имеют одинаковую настройку валюты, данные отображаются в валюте приложения. В противном случае данные отображаются в долларах США. |
| Данные о затратах | Доступны только при наличии хотя бы 1 зарегистрированной установки. <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#cost-data-availability-and-reports">Узнать больше</Anchor> |
| Органические данные | Доступно |
| Неорганические данные | Доступно |
| eCPA (эффективная цена за действие) | <ul><li>На настраиваемых дэшбордах формула eCPA имеет следующий вид: Общая сумма расходов / Количество действий = eCPA</li><li>Это отличается от других дэшбордов, включая обзорный, где используется формула: Общие расходы / **уникальные пользователи**, совершившие действие = eCPA</li></ul> |
| Актуальность данных | <Anchor target="_blank" href="/marketers/ru/docs/about-data-freshness-and-timezone-support#continuous-aka-realtime">В реальном времени</Anchor>. Эквивалентно обзорному дэшборду. |
| Доступ пользователей аккаунта | Да |
| Ограничения | <ul><li>Опция экспорта всей страницы в PDF недоступна.</li><li>Экспорт в PNG не поддерживается в следующих браузерах: Edge, Firefox 69 (Max).</li><li>Поиск конкретной кампании доступен в случаях, когда имеется менее 100 кампаний. При необходимости сократите период времени и повторите поиск.</li><li>Доступность KPI: Доступны KPI по LTV привлечения пользователей. KPI по ретаргетингу, удержанию клиентов, активности и Protect360 не доступны. Примечание! Не сравнивайте метрики настраиваемого дэшборда с единым представлением или с представлением ретаргетинга на обзорном дэшборде.</li><li>Изменение названия кампании не поддерживается.</li></ul> |
| Часовые пояса | <ul><li>Если все приложения в аккаунте имеют одинаковое название часового пояса, данные будут отображаться по часовому поясу приложения. Если нет, то будет использоваться UTC.</li></ul> |
| Исторические данные | Данные LTV доступны за период до 25 месяцев (2 года + 1 месяц). |

</Accordion>
