## Дэшборд активности

* Содержит органический и неорганический трафик
* Диапазон дат относится к дате события и не основан <Anchor target="_blank" href="/marketers/ru/docs/troubleshooting-discrepancies-in-appsflyer-dashboards-and-reports">на LTV.</Anchor>
* Обновление данных:
  * **Текущий день**: <Anchor target="_blank" href="/marketers/ru/docs/about-data-freshness-and-timezone-support#continuous-aka-realtime">Непрерывно</Anchor>. Пример: DAU, сессии, доход
  * **В среднем:** Ежедневно. Пример: MAU, средний DAU, средний MAU
* Фильтр «Регион» относится к местоположению пользователя во время установки

        * DAU — Активные пользователи за сутки: количество уникальных пользователей, открывших приложение хотя бы один раз в определенный день.

      </td>

        Пример: расчет среднего DAU

        > 📄

        > |  | Воскресенье | Понедельник | Вторник |

        MAU;
      </td>
      <td>
        MAU — Активные пользователи в месяц:

        * **Подробно:** количество уникальных пользователей (считаются только один раз), открывших приложение хотя бы раз в течение предыдущих 31 дня.
        * **Месячный обзор:** количество уникальных пользователей (считаются только один раз), открывших приложение хотя бы раз в течение календарного месяца.
      </td>
    </tr>
    <tr>
      <td><span id="daumau-rate"></span>
        Соотношение DAU/MAU
      </td>
      <td>
        * Эта метрика показывает долю вернувшихся пользователей. Соотношение DAU/MAU 50% означает, что средний пользователь открывал приложение 15 дней из предыдущих 31 дня.
        * Соотношение DAU/MAU является мерой лояльности пользователей и дает представление об удержании клиентов.

      <td><span id="installs"></span>
        Установки

    </tr>

    </tr>

## Спецификации и ограничения

| Спецификации | Примечания |
| --- | --- |
| Актуальность данных | <ul><li>**Метрики:** В реальном времени. См. изображение ниже.</li><li>**Средние метрики**: Ежедневно. См. изображение ниже. **Примечание**: Средние метрики не рассчитываются в режиме реального времени, чтобы избежать искажения среднего значения данными за неполные дни. Если диапазон дат включает текущий день, то происходит следующее:<ul><li>Если диапазон дат включает только текущий день: среднее не отображается.</li><li>Если диапазон дат включает период, в который входит текущий день: среднее рассчитывается без учета данных за текущий день.</li></ul></li><li>**Обработка данных за предыдущий день:** обработка данных начинается в полночь по UTC для данных за предыдущий день. Для приложений, работающих в часовых поясах, отстающих от UTC (UTC-), это означает, что к моменту начала обработки их локальный день может ещё продолжаться, что потенциально приводит к изначально неполным данным. Оставшиеся данные обрабатываются и включаются на следующий день.</li><li>**Доход от рекламы:** <Anchor target="_blank" href="/marketers/ru/docs/roi360-guide-ad-revenue-attribution#data-freshness">записывается с задержкой</Anchor> и отражается в отчете со следующей датой:<ul><li>Агрегированные данные: День 1 (день получения данных).</li><li>Данные уровня пользователя: День 0 (день показа рекламы).</li></ul></li></ul>[![Whats_realtime.png](https://files.readme.io/39969fe7395e1b22910aed5d6ca61f6b5603171650f0d0ce88218a2491c02cc5-4407209143953.png)](https://files.readme.io/39969fe7395e1b22910aed5d6ca61f6b5603171650f0d0ce88218a2491c02cc5-4407209143953.png) |
| Удаления | Не поддерживается |
| Обязательный | С 1 февраля 2025 года все метрики активности являются унифицированными данными (UA и ретаргетинг вместе). Однако данные следующих метрик, полученных до 1 февраля 2025 года, включают только данные о трафике UA:<ul><li>Всего сессий:</li><li>DAU;</li><li>MAU;</li><li>DAU/;MAU</li><li>ARPDAU;</li><li>Затраты</li><li>клики;</li><li>Показы</li><li>Коэффициент конверсии</li><li>eCPI (эффективная стоимость установки)</li></ul>Доступно лишь объединённое представление – пользователи не могут переключиться только на UA или ретаргетинг. |
| ARPDAU; | Возможны расхождения между ARPDAU на дэшборде активности и в сводных таблицах (Pivots). |
| Исторические данные | <ul><li>3 года</li><li>Вкладка «Месячный обзор»: 1 год</li></ul> |
| Отображаемый период | <ul><li>Максимум 2 месяца. Если указан более продолжительный период, он сокращается до двух месяцев, и отображается соответствующее сообщение.</li></ul> |
| Группировка по региону | <ul><li>Агрегирование по региону осуществляется на основе страны, в которой произошла установка.</li><li>Отображает до 62 местоположений (ранжированных по наиболее активным сессиям).</li></ul> |
| по кампаниям | Эта группировка доступна только после выбора определенных медиа-источников. |
| Значения параметров | Значения для таких параметров, как медиа-источник, название кампании и название актива, учитывают регистр. Например, это означает, что «Facebook» и «facebook» будут рассматриваться как отдельные объекты при фильтрации результатов. Чтобы просматривать результаты без учёта регистра, используйте <Anchor target="_blank" href="/marketers/ru/docs/pivot-table-user-metrics">сводную таблицу</Anchor> (Pivot). |
| Агентства | Агентства не имеют доступа к дэшборду активности. <Anchor target="_blank" href="/marketers/ru/docs/manage-data-access-permissions">Подробнее</Anchor> |
| Среднее количество DAU и среднее количество MAU | Метрики Average DAU и Average MAU могут учитывать одного и того же пользователя в нескольких группировках. Например, если пользователь устанавливает приложение через сеть A, а затем взаимодействует с ним через сеть B, он будет отображаться в обеих сетях при группировке по медиаисточнику или кампании. В результате прямое суммирование этих значений может привести к дублированию. Чтобы получить точное общее значение Average DAU или Average MAU, используйте метрику KPI вместо агрегирования значений в таблице. |
| Рекламным сетям | Для некоторых рекламных сетей в таблице активности может отображаться две строки вместо одной. В таких случаях:<ul><li>Показы, клики, стоимость и конверсии следует рассчитывать как сумму обеих строк.</li><li>Сеансы активности, доход от активности, Average DAU, Average MAU, Average DAU/MAU Rate и ARPDAU следует брать только из одной из строк.</li></ul> |
| Режим устаревших органических событий внутри приложения без атрибуции. | Если ваше приложение использует устаревший режим **Неатрибутированные органические события внутри приложения** , показатели органических **Активных пользователей** в реальном времени могут отображаться ниже ожидаемого.
