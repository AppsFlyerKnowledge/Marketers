> **At a glance:** Получайте агрегированные данные о маркетинговых расходах (включая показатели эффективности, связанные с расходами и пожизненной ценностью пользователей (LTV)) через API данных о расходах на уровне приложения или аккаунта медиаисточника.

<div id="overview" />

## Обзор

ROI360 позволяет измерять расходы как на уровне приложения, так и на уровне аккаунта. Благодаря этому заинтересованные стороны могут анализировать расходы с детализацией по отдельным приложениям или по всему аккаунту медиаисточника.

Интеграция затрат управляется в двух разных местах в зависимости от медиаисточника:

* **Интеграция на уровне аккаунта** регулируется в **Настройках затрат**. Эти интеграции настроены на уровне рекламного аккаунта. см. [список поддерживаемых рекламных сетей](#h_01KQ7V7Q6MAEMXKKJ7TV8GC1YR).
* **Интеграция на уровне приложения** регулируется на вкладке «**Затраты**». Эти интеграции настраиваются отдельно для каждого приложения. Если медиаисточник недоступен в **Настройках затрат**, настройте его интеграцию затрат на вкладке **Затраты** на уровне приложения.

> 📘 **Note**
>
> Доступ к настройкам затрат определяется правами, назначенными для каждой роли. Если у вас нет доступа к **Настройкам затрат**, попросите администратора изменить разрешения для вашей роли на странице **Управление пользователями**. Для этого необходимо перейти к **Подключению затрат**.

## Включение API затрат

Существует два способа активации интеграции затрат: на уровне приложения и аккаунта.

<Accordion title="Включение интеграции затрат на уровне приложения (вкладка «Затраты»)">

Чтобы настроить специальное подключение затрат к медиаисточнику для отдельного приложения, выполните следующие действия.

1. В AppsFlyer в боковом меню выберите **Сотрудничество**  **Партнерские интеграции** **Активные интеграции**, затем выберите партнера.
2. Нажмите **Управление интеграцией**.
3. Откройте вкладку **Затраты** интегрированного партнера.
4. Включите параметр **Получить данные по затратам**. Отображаются требования к подключению к партнеру.
5. Настройте интеграцию с партнером для получения данных о расходах и выполните аутентификацию. Способ аутентификации зависит от медиаисточника. [Методы интеграции затрат](#методы-интеграции-затрат) см. ниже.
6. Если в настройках затрат партнера есть **сопоставление идентификаторов сайтов**, выберите нужную конфигурацию из выпадающего списка. См. [сопоставление идентификаторов сайта](#сопоставление-идентификаторов-сайтов) ниже.
7. Нажмите **Сохранить затраты**.
   * Данные о затратах начнут отображаться на ваших дэшбордах в течение 5–6 часов.
   * AppsFlyer собирает данные от партнеров 6 раз в день, в среднем каждые четыре часа.
   * Аккаунт медиаисточника в разделе **Настройки затрат** обновляется в соответствии с вашими действиями на уровне приложения на вкладке **Стоимость**.

</Accordion>

<Accordion title="Включите интеграцию затрат на уровне аккаунта (страница «Настройки затрат»)">

Вам нужно подключить каждый аккаунт медиаисточника один раз, чтобы активировать стоимость для нескольких или всех приложений в вашем аккаунте AppsFlyer.

Чтобы включить интеграцию затрат на уровне аккаунта, следуйте инструкциям:

1. В AppsFlyer в боковом меню откройте **Настройки** **ROI360** **Настройки дохода**.
2. Выберите медиаисточник для получения данных о затратах и нажмите **Далее**.
3. Настройте интеграцию с медиаисточником для получения данных о расходах и выполните аутентификацию. Способ аутентификации зависит от медиаисточника. См. ниже раздел [Методы интеграции по расходам](#методы-интеграции-затрат).
4. Введите (или настройте) название интеграции затрат.
5. Выберите приложения для включения в эту интеграцию затрат.
6. Нажмите **Сохранить интеграцию**.
   * Данные о затратах начнут отображаться на ваших дэшбордах в течение 5–6 часов.
   * AppsFlyer собирает данные от медиаисточника 6 раз в день, в среднем каждые четыре часа.
   * Изменения, внесенные на уровне аккаунта в разделе **«Настройки расходов»**, автоматически применяются на вкладке **«Расходы»** в разделе **«Активная интеграция»** для соответствующих приложений и медиаисточников.

</Accordion>

> 📘 **Note**
>
> Если рекламодатель использует агентство для запуска своих кампаний, то интегрироваться с соответствующими партнерами должно агентство, а не рекламодатель. В противном случае данные затрат будут дублироваться, если и рекламодатель, и агентство интегрируются с медиаисточником, используя одни и те же учетные данные для одного приложения.

## Методы интеграции затрат

Способ включения интеграции затрат зависит от режима интеграции медиаисточника с AppsFlyer. Можно выбрать один из следующих вариантов:

* **Вход:** нажмите **«Войти в `<media source>`»**, чтобы открыть окно входа в систему медиаисточника. Затем следуйте инструкциям для входа в систему медиаисточника.
* **Учетные данные**: введите значения параметров, необходимых для подключения к медиаисточнику, например **ключ API**.
* **Отсутствует:** конфигурация подключения не требуется, кроме включения **Получать данные о стоимости**, как указано [выше](#включение-api-затрат).

Чтобы узнать, какой способ использует конкретный медиаисточник, см. столбец **«Способ интеграции»** в <Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">таблице интеграций с медиаисточниками для получения данных о расходах</Anchor>.

## Сопоставление идентификаторов сайтов

<Anchor target="_blank" href="/marketers/ru/docs/roi360-cost-aggregation-overview#ad-networks-supporting-cost-api">Некоторые партнерские интеграции</Anchor> позволяют выбирать способ заполнения поля <Anchor target="_blank" href="/marketers/ru/docs/raw-data-field-dictionary#attribution::e9b53459">идентификатора сайта</Anchor> при формировании отчетности по данным о затратах. Это гарантирует, что макрос ссылки атрибуции AppsFlyer `site-id` соответствует ожидаемому медиаисточником значению.

* По умолчанию сопоставление идентификаторов сайтов согласовано с макросами AppsFlyer в ссылке атрибуции.
* Если в вашей ссылке атрибуции есть макрос, отличающийся от вариантов макросов для сопоставления идентификаторов сайтов, то данные идентификатора сайта будут заполняться некорректно.

Чтобы настроить сопоставление идентификаторов сайта на уровне приложения, выполните следующие действия:

1. На вкладке **Затраты** интегрированного партнера перейдите в раздел **Сопоставление идентификаторов сайтов** и выберите конфигурацию из выпадающего меню.
2. Нажмите **Сохранить затраты**. Изменения вступают в силу со следующего дня по UTC.

## Удалить интеграции стоимости

Вы можете удалить интеграцию затрат как на уровне приложения, так и на уровне аккаунта. После удаления AppsFlyer больше не сможет извлекать данные о затратах из этого аккаунта. Удаление интеграции не влияет на исторические данные.

<Accordion title="Удаление интеграции затрат на уровне приложения (вкладка «Затраты»)">

Вы можете удалить интеграцию в любое время.

Как удалить интеграцию затрат на уровне приложения:

1. В AppsFlyer в боковом меню перейдите в **Сотрудничество** **Партнерские интеграции** > **Активные интеграции**.
2. Выберите интегрированного партнера, например, Meta Ads.
3. Нажмите **Управление интеграцией**.
4. Откройте вкладку **Затраты**. Отобразится список подключенных аккаунтов.
5. В столбце **Действия** наведите курсор на аккаунт и нажмите **Удалить подключение**.
6. В ответ на запрос подтверждения нажмите **Да, удалить**.

Интеграция затрат, ранее настроенная на уровне приложения, была удалена как на уровне приложения, так и на уровне аккаунта. В результате сбор данных о затратах прекращается немедленно. Это изменение не повлияет на уже собранные исторические данные о затратах.

</Accordion>

<Accordion title="Удалите интеграцию по расходам на уровне аккаунта (страница «Настройки затрат»)">

Чтобы удалить интеграцию затрат на уровне аккаунта, выполните следующие действия:

1. В AppsFlyer в боковом меню выберите **«Настройки»** > **«ROI360 > Настройки расходов»**, затем выберите медиаисточник, интеграцию с которым хотите удалить.
2. В списке интеграций для медиаисточника нажмите запись интеграции.
3. В ответ на запрос подтверждения нажмите **Да, удалить**.

Интеграция затрат, ранее настроенная на уровне аккаунта, была удалена как на уровне приложения, так и на уровне аккаунта. В результате сбор данных о затратах прекращается немедленно. Это изменение не повлияет на уже собранные исторические данные о затратах.

</Accordion>

## Отключение API затрат

Отключение API затрат доступно только на уровне приложения.

Чтобы отключить API затрат, выполните следующие действия:

1. Перейдите в раздел **Активные интеграции** и выберите медиаисточник.
2. Перейдите на вкладку **Затраты**.
3. Выключите параметр **Получить данные по затратам**.
4. Нажмите **Сохранить затраты**.

> 📘 **Note**
>
> Если рекламодатель прекращает сотрудничество с агентством и отключает его права доступа на уровне приложения, данные о расходах продолжают поступать, если у агентства настроено получение таких данных для этого приложения. Рекламодатель должен попросить агентство отключить их интеграцию затрат, чтобы остановить извлечение этих данных.

## Статус API затрат

Операционный статус интеграций затрат доступен следующим образом:

* <Anchor target="_blank" href="/marketers/ru/docs/dashboard-cost-and-ad-revenue-status">Дэшборд состояния интеграций для получения данных о расходах (и доходах от рекламы)</Anchor>: единый список медиаисточников, для которых настроено получение данных о расходах хотя бы для одного приложения в вашем аккаунте.
* Интегрированные партнеры: Статус доступен в контексте отдельного приложения.
* Настройки затрат: На странице **Настройки затрат** можно просматривать статус API затрат как на уровне аккаунта, так и на уровне приложения. Дополнительные сведения см. в разделе «[Просмотр статуса интеграции агрегированной стоимости медиаисточника](#h_01K3DGA6SKBPXEY18VJBCBNCJS)» ниже.

<Accordion title="Просмотр состояния интеграции с медиаисточником для получения данных о расходах (вкладка «Расходы»)">

Вкладка **Затраты** на странице **Активная интеграция** с медиаисточником (актуально для медиаисточников, поддерживающих получение данных о затратах через API) отображает:

* Статус интеграции затрат выбранного приложения.
* Когда последний раз AppsFlyer успешно извлек соответствующие данные о затратах приложения.

Чтобы просмотреть статус интеграции затрат на отдельные медиаисточники для выбранного приложения, выполните следующие действия:

1. В AppsFlyer в боковом меню перейдите в **Сотрудничество** **Партнерские интеграции** **Активные интеграции.**
2. Выберите медиаисточник.
3. На странице медиаисточника **Активная интеграция** выберите в списке приложений над панелью вкладок приложение, статус расходов для которого вы хотите просмотреть.
4. Перейдите на вкладку **Затраты**. Будут показаны статус и время последней синхронизации.

</Accordion>

<Accordion title="Просмотр статуса агрегированной интеграции по расходам для медиаисточника (страница «Настройки затрат»)">

Чтобы просмотреть общее состояние интеграции с медиаисточником для получения данных о расходах, выполните следующие действия:

1. В AppsFlyer в боковом меню выберите **Настройки** **ROI360** Настройки затрат.
2. Выберите соответствующий медиаисточник.
3. На странице медиаисточника в столбце **Статус** можно посмотреть состояние аккаунта медиаисточника. Этот статус отображается, если все приложения, связанные с аккаунтом, имеют одинаковый статус. Если статусы приложений различаются, статус отображается как **Смешанный статус**.
4. Чтобы просмотреть состояние интеграции для конкретного приложения, связанного с аккаунтом медиаисточника, нажмите на строку с аккаунтом медиаисточника. Откроется страница **Интеграция затрат**.
5. Просмотрите статус приложения в списке приложений, связанных с медиаисточником.

</Accordion>

## Характеристики и ограничения

| Характеристика | Описание |
| --- | --- |
| Агентства | Агентства не могут использовать настройки затрат для одновременной интеграции затрат для нескольких приложений. |
| Приложения, которые будут добавлены позже, автоматически наследуют настройки затрат в настройках затрат на уровне аккаунта | В настоящее время не поддерживается |
| Поведение данных о затратах при подключении рекламодателя и агентства к одной рекламной сети | Если и рекламодатель, и агентство подключают интеграцию затрат для одного и того же аккаунта рекламной сети (например, Google Ads), данные о затратах извлекаются из **аккаунта, получающего атрибуцию**.<br /><br />**Пример сценария:**<ul><li>Рекламодатель подключается к интеграции затрат с использованием учетных данных рекламодателя</li><li>Агентство связывает интеграцию затрат с помощью учетных данных агентства</li><li>Атрибуция присваивается аккаунту агентства.</li></ul>**Результат:**<ul><li>ROI360 собирает **данные о затратах от подключенного агентства**.</li><li>Для **подключения рекламодателя** отображается статус «Нет данных».</li></ul> |
| Автоматическое отключение интеграции данных о расходах Google | Интеграции затрат, у которых статус **«Нет данных»** или **«Недействительные учетные данные»** сохраняется более 365 дней подряд, отключаются автоматически. Это относится только к интеграциям с Google. |
| Настройка списка идентификаторов рекламодателей TikTok | Настройте список идентификаторов рекламодателей на уровне аккаунта, используя только те идентификаторы, которые связаны с пользователем TikTok в рекламной сети.<br /><br />Идентификаторы рекламодателей, добавленные в список, но не связанные с пользователем в рекламной сети, не возвращают данных о расходах. |
