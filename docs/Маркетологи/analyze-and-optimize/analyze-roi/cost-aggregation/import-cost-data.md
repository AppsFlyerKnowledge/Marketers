> **Краткий обзор:** Импорт затрат, часть AppsFlyer ROI360, позволяет рекламодателям обеспечить полный и точный охват своих маркетинговых затрат с помощью импорта CSV-файлов через загрузку или электронную почту.

<div id="overview" />

## Обзор

Используйте импорт данных о затратах, чтобы:

* Передавать в AppsFlyer затраты на кампании, направленные на любые маркетинговые цели (мобильные кампании, кампании с привлечением блогеров, CTV и т. д.). Это особенно важно для медиаисточников, которые не сообщают о затратах через API или по ссылке атрибуции.
* Ретроактивно перезаписывать и корректировать ранее полученные данные о расходах.

Данные о расходах передаются в AppsFlyer в CSV-файлах, загружаемых в систему или отправляемых по электронной почте. Как только AppsFlyer получает файл, данные обрабатываются и становятся доступными на дэшбордах и в отчетах в течение нескольких часов. Так вы получаете полное представление о ROI и затратах на кампанию.

**Примечание**:

* Рекламные сети могут импортировать файлы с затратами для своих клиентов при наличии соответствующих разрешений.
* Агентства не могут загружать данные. Они могут подготовить свои файлы и отправить их рекламодателю для загрузки.

<div id="procedures" />

## Процедуры

Чтобы воспользоваться Импортом затрат и отправить данные о затратах в AppsFlyer, вам нужно:

1. [Подготовить CSV-файл](/docs/import-cost-data#prepare-csv-file-with-cost-data) с данными о затратах для отправки.
2. Отправить файл в AppsFlyer через:
   * [Загрузку](/docs/import-cost-data#email-file) в пользовательском интерфейсе AppsFlyer;
   * [Электронную почту](/docs/import-cost-data#email-file). **Примечание**: для приложений на платформах CTV, ПК и игровых консолей используйте только этот способ.

Подробные инструкции см. в следующих разделах.

#### Формат CSV-файла и правила его заполнения

| Правило | Требования |
| --- | --- |
| Запрещенные символы | Поля в формате строки не могут иметь в качестве первого символа `=`, `+`, `-` или `@`. Например, `@example_campign` или `=123` запрещены. |
| Владелец приложения | Допускается один рекламодатель (владелец приложения) на файл. Допускаются несколько приложений от одного аккаунта рекламодателя. |
| Расширение имени файла | Пример CSV: abc123.csv |
| Структура файла | <ul><li>**Формат**: Файлы имеют формат CSV, то есть каждый столбец отделен запятой.</li><li>**Строка заголовка**: Первая строка — это строка заголовка, которая соответствует схеме</li><li>**Строки данных**: Содержат обязательные столбцы. **Примечание**. Убедитесь, что в данных нет пробелов в конце строки. Например, значение [USD] (с пробелом после **D**) необходимо заменить на [USD].</li><li>**Пустые строки**: Не допускается</li><li>**Дублированные строки** с одинаковым ключом: Запрещены. Ключ формируется на основе обязательных полей.</li><li>**Пустые ячейки:** <mark>Пустые значения в файле не допускаются.</mark> Если вы не хотите загружать определенные поля, их не должно быть в файле.</li></ul> |
| Иерархия рекламы | Затраты должны учитываться на уровне кампании, а другие параметры в рекламной иерархии являются необязательными.<br /><br />Любые неполные данные, загруженные на более низком уровне иерархии, перезапишут все данные начиная с уровня кампании и ниже.<br /><br />**Например:** Если вы импортируете файл с затратами кампании для рекламного блока 1 и отдельно импортируете другой файл для рекламного блока 2 той же кампании, то общая стоимость кампании будет заменена и будут показаны только данные рекламного блока 2. Чтобы рассчитать общую стоимость кампании, в импортируемом файле должны присутствовать adset 1 и adset 2. |

</Accordion>

<div id="upload-file" />

<Accordion title="Загрузить файл">

Рекламодатели и рекламные сети могут загружать CSV-файлы для импорта затрат.

**Необходимые условия**: Рекламным сетям требуются [разрешения рекламодателя на импорт данных о расходах](/docs/import-cost-data#cost-import-permissions-for-ad-networks). 

**Для загрузки CSV файла через AppsFlyer UI**:

1. В AppsFlyer в боковом меню выберите **Настройки** > **Импорт затрат.**  
   Откроется страница импорта затрат.
2. Нажмите **+ Импортировать файл затрат**  
   Открывается окно импорта затрат.
3. Перетащите CSV-файл в **окно** импорта файла затрат.  
   Появится сообщение об обработке файла.
4. Если во время загрузки отображается сообщение об ошибке: устраните ее и повторите соответствующие действия.
5. Откроется окно **Импорт затрат: сводка файла** .
6. Выполните одно из следующих действий:
   * Прервите загрузку, нажмите **Отменить импорт**.
   * Завершите процесс импорта, нажмите **Импортировать файл**.  

     Сообщение «All set!» отображается.
   * Если появляется сообщение об ошибке, следуйте [инструкциям в сообщении об ошибке](#error-messages-and-solutions).
7. Нажмите кнопку **Импортировать другой файл** или **Готово**.

</Accordion>

<div id="email-file" />

<Accordion title="Отправка файла по электронной почте">

Рекламодатели и рекламные сети могут отправлять CSV-файлы с данными о расходах по электронной почте.

**Необходимые условия**:

* **Рекламодатели**: 
  * Электронная почта отправителя должна принадлежать зарегистрированному пользователю AppsFlyer.
* **Рекламные сети**:
  * Электронная почта отправителя должна принадлежать зарегистрированному пользователю AppsFlyer.
  * [Разрешение рекламодателя на импорт данных о расходах](/docs/import-cost-data#cost-import-permissions-for-ad-networks).

**Чтобы отправить файл CSV по электронной почте**:

1. Получить токен [для импорта по электронной почте](/docs/import-cost-data#token-for-email-import).
   1. В AppsFlyer в боковом меню выберите **Настройки** > **Импорт затрат.**
   2. В правой верхней части страницы нажмите **Токен для импорта по электронной почте**.
   3. Скопируйте и сохраните токен.
2. Составьте электронное письмо со следующими полями:
   * **Кому**:`adspend-upload@appsflyer.com`
   * **Копия:** **Пользователи, которым должна приходить копия автоматического отчета‌**
   * **Тема**: Вставьте токен для импорта по электронной почте в поле темы.
   * **Вложение**: CSV-файл с данными.
3. Отправить письмо.
   * После получения и обработки файла на электронную почту отправляется уведомление о статусе с информацией о результатах обработки, выявленных проблемах и ошибках. Письмо отправляется всем участникам, указанным в письме, и администратору рекламодателя. Если обнаружены ошибки, следуйте [инструкциям в сообщении об ошибке](#error-messages-and-solutions).
   * Просмотреть статус отправленных файлов можно на [дэшборде импорта затрат](/docs/import-cost-data#error-messages-and-solutions)

</Accordion>

Файл был перезаписан/заменен другими данными.</li></ul> |

</Accordion>

<div id="matched-rows" />

<Accordion title="Сопоставленные строки">

Сопоставление строк — это процесс, при котором данные о расходах, полученные в результате импорта, сопоставляются с данными атрибуции, зарегистрированными в AppsFlyer. Для этого используются названия (не идентификаторы) всех доступных параметров, таких как медиаисточник, кампания, группа объявлений, объявление и т. д. Если все они совпадают, то строки обозначаются как is-matching=TRUE.

Данные о расходах регистрируются и отображаются в дэшбордах и отчетах AppsFlyer независимо от статуса сопоставления.

Процент сопоставленных строк отображается на дэшборде импорта затрат. Если наличие несопоставленных не соответствует ожидаемому или доля сопоставленных строк (%) оказалась выше ожидаемой:

* Загрузите отчет о Несопоставленных данных, чтобы выяснить причину. Отчет о Несопоставленных данных содержит столбец «is-matched», который может иметь значение TRUE (сопоставлены) или FALSE (не сопоставлены).
* При необходимости отмените импорт, сбросив его.
* Смотрите раздел «Действие» в этой таблице для получения более подробной информации.

</Accordion>

## Дополнительные сведения

<div id="using-excel-or-google-sheets-to-prepare-csv-file" />

<Accordion title="Использование Excel или Google Таблиц для подготовки CSV-файла">

При использовании Excel или Google Таблиц для подготовки CSV-файла необходимо правильно отформатировать столбцы даты и расходов перед сохранением файла в формате CSV. После сохранения CSV-файла проверьте правильность форматирования его содержимого. Используйте следующие рекомендации чтобы:

* отформатировать ячейки с датами.;
* отформатировать ячейки с затратами;
* проверить формат содержимого.

<div id="format-date-cells" />

#### Форматирование ячеек с датами

**Чтобы отформатировать ячейки даты в Excel в формате ГГГГ-ММ-ДД**:

1. Выберите ячейки, которые необходимо отформатировать.
2. Щелкните правой кнопкой мыши, затем выберите **Форматировать ячейки**.  
   Откроется окно форматирования ячеек.  
   <Image alt="Formatdate..png" src="https://files.readme.io/43d0f370f299d73b8ce93fec1c912cb7525d0071db779a64a58f5917df2a5531-360004042458.png" width="379px" />
3. Выберите **Настраиваемый**.
4. В поле Тип введите **YYYY-MM-DD**
5. Нажмите **OK**.  
   Дата отформатируется.

<div id="formatting-spend-cells" />

#### Форматирование ячеек с затратами

Обычно Excel форматирует ячейки со значениями с помощью запятой для отделения тысяч, как показано на следующем изображении. Этот формат не подходит для файлов импорта затрат.

<Image alt="mceclip1.png" src="https://files.readme.io/d54e21ddd937dfe25a33bb96193761a5a724c22a35a55bb7d71eb03a6433d7ed-360003949177.png" width="291px" />

**Чтобы отформатировать ячейки с расходами без запятых в качестве разделителей тысяч:**

1. Выберите ячейки, которые необходимо отформатировать.
2. Щелкните правой кнопкой мыши, затем выберите **Форматировать ячейки**.  
   Откроется окно форматирования ячеек.
3. Выберите **Число** .  
   <Image alt="Formatnumbers.png" src="https://files.readme.io/4c1b61d1eae9149e818d4cc9793128fbdaafed5daed9acf6cbc503571475cc0e-34255643022481.png" width="381px" />
4. Снимите флажок **«Использовать разделитель тысяч (,)»**.
5. (Необязательно) Укажите количество **знаков после запятой**. По умолчанию установлено значение 2. Максимально допустимое значение — 5.
6. Нажмите **OK**.  
   Ячейки отформатированы правильно.

<div id="verify-content-format" />

#### Проверьте формат содержимого

**Чтобы проверить формат содержимого**:

1. Используйте редактор для просмотра файла.
   * Windows: Notepad, Notepad++
   * macOS: TextEdit
2. Обратите особое внимание на следующие элементы:
   * **Пробелы:** убедитесь, что перед запятыми и после них, разделяющими поля, нет лишних пробелов. В Excel используйте функцию TRIM для удаления лишних пробелов.
   * **Дата:** Проверьте, чтобы ячейки с датами имели формат ГГГГ-ММ-ДД.
   * **Затраты:** Проверьте, чтобы в ячейках с затратами не было запятых.
   * **Разделители**: Должны использоваться запятые. Если в качестве разделителей используются точки с запятой:
     * Это может происходить, когда в региональных настройках компьютера установлен язык/регион, отличный от английского, особенно часто это случается при выборе немецкого.
     * Способ решения зависит от операционной системы вашего компьютера (macOS или Windows).
     * Чтобы решить эту проблему, найдите последние рекомендации на форумах <Anchor target="_blank" href="https://support.office.com/en-us/article/import-or-export-text-txt-or-csv-files-5250ac4c-663c-47ce-937b-339e391393ba#ID0EAAFAAA=Office_2016-2010">Microsoft</Anchor> или других аналогичных форумах. Используйте следующие поисковые запросы: Операционная система (macOS или Windows) Excel меняет разделитель для файлов CSV.

Ниже приведен скриншот с [примером CSV-файла](https://docs.google.com/spreadsheets/d/e/2PACX-1vQ0oJTWdlNyT1gBHkGaN1QP-tUatugbPBzC2qYVNmjl_T_i3fKo1abYzTp6F7OqGeN_f7bBAJa3hxVz/pub?gid=0&single=true&output=csv), отображаемого в редакторе.

<Image alt="mceclip1.png" src="https://files.readme.io/1398c5e9bad7a46b697e3b21030e64d656162e33a4a63f39475c64993bbe7a72-360003996197.png" width="672px" />

</Accordion>

<div id="token-for-email-import" />

<Accordion title="Токен для импорта по электронной почте">

Токен для импорта по электронной почте используется для проверки авторизации отправителя электронного сообщения для отправки файла импорта затрат.

Токены рекламодателей и рекламных сетей различаются.

* Токен рекламодателя:
  * Один и тот же токен действителен для всех приложений в аккаунте.
  * Токен может получить любой пользователь аккаунта.
* Токен рекламной сети:
  * Для всех рекламодателей используется один и тот же токен.

Рекламодатели и рекламные сети не должны делиться своими токенами друг с другом!

</Accordion>

<div id="cost-import-permissions-for-ad-networks" />

<Accordion title="Разрешения на импорт затрат для рекламных сетей">

Рекламным сетям требуется разрешения рекламодателя на каждое приложение для доступа к импорту затрат.

**Чтобы предоставить рекламной сети разрешение на импорт затрат:**

1. В AppsFlyer **рекламодателю** нужно перейти в боковое меню и выбрать **Сотрудничество** > **Активные интеграции.**   
   Откроется страница интеграции с партнером.
2. Выберите интегрированного партнера.
3. Перейдите на вкладку **Разрешения**.
4. Активируйте **Разрешения для рекламной сети**, если они еще не включены.
5. (необязательно) Добавить пользователей аккаунта.
6. Включите параметр **Использовать импорт данных о расходах.**
7. Нажмите **Сохранить разрешения**.

</Accordion>
