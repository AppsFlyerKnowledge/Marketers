> **Кратко:** Предотвращайте атрибуцию фрод-активности, используя сервис Apple для валидации установки при любой установке iOS (как органической, так и неорганической).

## Процесс валидации квитанций

Процесс валидации чека выглядит следующим образом:

1. SDK AppsFlyer собирает данные квитанции об установке Apple и отправляет их вместе с сообщением о запуске на серверы AppsFlyer.
2. Серверы AppsFlyer выполняют валидацию этих данных квитанции через сервис Apple для валидации установки.
3. Если сервис Apple для валидации установки возвращает коды ошибок, указывающие на недействительность установки:
   * Установка отклоняется и не отображается в нашем дэшборде
   * Рекламная сеть не получает постбэк или вызов API для аннулированной установки
   * Установка и все соответствующие события в приложении регистрируются в отчетах Protect360 о сырых данных: Installs и Blocked in-app events.

> 📘 **Примечания**
>
> * Версия SDK AppsFlyer для iOS должна быть 6.9.2+
> * Валидация установки поддерживается на устройствах iOS с версией iOS 7+.
> * В некоторых случаях Apple не предоставляет данные квитанции установки, и в таких случаях AppsFlyer считает такую установку действительной с точки зрения валидации установки в магазине приложений. Однако Protect360 может заблокировать эту установку по другим причинам, связанным с фродом.
