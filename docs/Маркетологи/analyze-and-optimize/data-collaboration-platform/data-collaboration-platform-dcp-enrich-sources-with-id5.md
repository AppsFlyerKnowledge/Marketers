> **Кратко:** Обогатите собственные данные идентификаторами ID5, чтобы объединить разрозненные пользовательские данные и повысить показатели сопоставления с партнерами по активации, что позволит увеличить аудитории.

<div id="about-id5-enrichment" />

## Об обогащении с помощью ID5

Платформа для совместной работы с данными AppsFlyer интегрируется с ID5 — ведущим поставщиком решений для идентификации в открытом интернете. ID5 связывает разрозненные идентификаторы, такие как IP-адреса, хешированные адреса электронной почты (HEM) и идентификаторы мобильной рекламы (MAID), в единый идентификатор с приоритетом конфиденциальности. Это повышает показатели сопоставления между наборами данных участников совместной работы, благодаря чему больше пользователей можно распознать, объединить и активировать в аудиториях. В этом руководстве объясняется, как работает обогащение с помощью ID5 в DCP, как его настроить и как использовать его для совместной работы и активации.

**Обогащение ID5 помогает вам:**

* Повысьте показатели сопоставления между вашими собственными данными и медиа-партнерами или участниками совместной работы
* Увеличьте размер целевой аудитории
* Объединяйте такие идентификаторы, как HEM, MAID и IP + метка времени, в единую идентичность
* Обеспечьте устойчивость активации по мере отказа от сторонних файлов cookie

**Распространенные варианты применения:**

* **Обогащение собственных данных бренда** — Бренд загружает в DCP источник собственных данных и обогащает его идентификаторами ID5, используя свое подключение к ID5.
* **Совместная работа ретейлера и бренда** — Ретейлер сотрудничает с брендом и предоставляет доступ к своей подписке ID5. В рамках защищенного взаимодействия бренд обогащает данные своих клиентов через подключение ретейлера к ID5, повышая показатели сопоставления без необходимости иметь собственную прямую учетную запись ID5.
* **Активация партнеров** — Обогащенные источники можно отправлять партнерам по активации, которые поддерживаются, чтобы повысить показатели сопоставления. Это означает, что больше пользователей из ваших данных можно сопоставить и включить в аудитории на стороне партнера.

<div id="how-id5-works" />

## Как работает ID5

DCP использует возвращенные идентификаторы ID5 для обогащения вашего источника, в результате чего создается новый обогащенный источник, доступный для сегментации и активации.

**Два поддерживаемых потока обогащения:**

| Сценарий | Description(Описание) | Когда использовать |
| --- | --- | --- |
| Поток с тегами | Владелец данных уже применяет теги сайта ID5 на своем домене, поэтому загруженные им данные уже содержат столбец с идентификатором ID5. | Если вы управляете тегированием ID5 непосредственно на своем сайте и хотите использовать DCP без дополнительного обогащения. |
| Поток обогащения «сервер-сервер» (S2S) | AppsFlyer отправляет выбранный вами источник данных в ID5, ID5 обогащает его идентификаторами ID5 и возвращает в DCP как обогащенный источник. | Если ваш источник не включает столбец ID5 или если вы хотите, чтобы AppsFlyer автоматически выполнял обогащение. |

## Начните работу с обогащением ID5

В этом разделе описано, как создать подключение ID5 в DCP и использовать его для обогащения.

**Необходимые условия:**

* Аккаунт AppsFlyer с разрешениями DCP
* Токен ID5 (предоставляется вашим менеджером аккаунта ID5)
* Источник, содержащий как минимум один из поддерживаемых идентификаторов: HEM, MAID или IP-адрес + метка времени

<div id="create-an-id5-connection" />

<Accordion title="Создайте подключение ID5">

Чтобы использовать обогащение ID5, сначала создайте подключение **Data & Identity** в DCP.

1. Откройте Data Collaboration Platform, выбрав **Collaborate** > **Data Clean Room** в боковом меню AppsFlyer.

   <Image align="center" alt="Щелкните Data Clean Room.png" src="https://files.readme.io/2dc54e035b17aafa17b7eb4c526643284aa7979919f8caa0add13b7e6ae19e0c-41945704690065.png" width="33.49%" />
2. Перейдите в раздел **Управление подключениями** (в правом верхнем углу).
3. На вкладке **Data & Identity** выберите **+ Новое подключение**.

   **<Image alt="+Новое подключение.png" src="https://files.readme.io/815ec20e84d85da413dfe9c9358b54d772461e1eeb3dff3ff7c5c31ced1088ac-42729247721873.png" width="72.63%" />**
4. Выберите **ID5.**

   **<Image alt="Выберите ID5.png" src="https://files.readme.io/a0c53243318fa7eed48ac5886ff5f3272bec0e6fd83a41117d53473757ab16d7-42729260095633.png" width="66.76%" />**
5. Введите свой токен ID5 (если применимо).
6. Нажмите **Save** (Сохранить).

После сохранения подключение станет доступно для ваших источников и совместных проектов (при наличии соответствующих разрешений).

</Accordion>

<div id="enrich-a-source-with-id5" />

<Accordion title="Обогатите источник с помощью ID5">

Вы можете обогащать свои источники с помощью потока S2S.

**Чтобы обогатить источник:**

1. Откройте Data Collaboration Platform, выбрав **Collaborate** > **Data Clean Room** в боковом меню AppsFlyer.
2. Перейдите на вкладку **Источники** и наведите указатель на нужный источник.
3. В меню действий выберите **Обогатить**.

   <Image align="center" alt="Обогатить.png" src="https://files.readme.io/51c3f33da62d84ec9214e178e3bbaef15d6a03a32827ad393166db0dcd9a70fd-42729376739473.png" width="245px" />
4. Щелкните **Начать обогащение**.
5. После завершения процесса обогащения у вас появится новый источник, связанный с исходным, с добавлением идентификаторов ID5.  
   **Примечание:** Если исходный источник когда-либо будет удалён, новый источник также будет удалён.

</Accordion>

<div id="grant-id5-permissions-in-a-collaboration" />

<Accordion title="Предоставление разрешений ID5 в коллаборации">

Владельцы коллаборации могут разрешить участникам использовать подключение ID5 в рамках коллаборации (в соответствии с коммерческим соглашением с ID5).

**Чтобы предоставить участнику разрешения ID5:**

1. Откройте платформу Data Collaboration Platform, нажав **Collaborate** > **Data Clean Room** в боковом меню AppsFlyer.
2. На вкладке **Collaborations** откройте существующую коллаборацию или <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-create-a-collaboration">создайте новую</Anchor>.
3. Нажмите **Сотрудничество с "вашим партнером".**

   **<Image alt="Update collaboration policy.png" src="https://files.readme.io/25d707c47bed9f5f60cd1ba521c4b48f41afbb0e36949f0ffa35cecf9a932ddc-42838633495313.png" width="58.95%" />**
4. Нажмите **Edit collaboration policy**.

   <Image align="center" alt="Click Edit collaboration policy.png" src="https://files.readme.io/07aab2a3165d26779e94f62eb8487893bc725dfa3ad4c406de576480e2ed6c13-42838633497489.png" width="80.3%" />
5. Нажмите **Access permissions**.

   **<Image alt="Click Access permissions.png" src="https://files.readme.io/b239775d71e1fa1dcc23537e73e35b80bff0184c9ee2aa213f644d90251284f3-42838633499281.png" width="78.62%" />**
6. Включите **ID5 connection**.

   <Image align="center" alt="ID5 permissions.png" src="https://files.readme.io/f2831ec4f775b51ef419da33444198de6aabfde3b27d83cc9af623eaed4a865c-42789059643793.png" width="79.6%" />
7. Нажмите **Save** (Сохранить).

После этого участники смогут связать свои собственные источники с коллаборацией и обогащать их, используя подключение ID5 партнёра.

</Accordion>

<div id="traits-and-limitations" />

## Спецификации и ограничения

В этом разделе описаны некоторые ключевые характеристики и ограничения.

| Характеристика/ограничение | Description(Описание) |
| --- | --- |
| Первое обогащение и ежедневные обновления | Первый запуск обогащения начинается сразу и обычно завершается в течение нескольких часов.<br /><br />После первоначального запуска обогащение выполняется ежедневно в фиксированное время обработки, что обеспечивает актуальные сопоставления идентификаторов.<br /><br />Вы можете в любой момент приостановить обогащение, чтобы остановить ежедневные обновления. |
| Зависимость от источника | Если исходный источник удален, обогащенный источник удаляется автоматически. |
| Область активации | В рамках коллаборации рекламодатель может использовать обогащённые данные для активации, но не может загрузить их или отправлять по ним запросы. |
| Ограничения статуса | Обогащать можно только источники со статусом **Активный**. |
| Задержка обогащения данных | Источники в статусе **Waiting** или **Processing** продолжают обогащаться, но становятся доступными для использования только после перехода в статус **Active**. |
| Период хранения данных | ID5 хранит сопоставления от 14 до 90 дней в зависимости от активности. |
| Требование к идентификатору | Если в источнике нет HEM, MAID или IP + отметки времени, обогащение отключено. |
| Конфликты подключений | Совместная работа может включать только одно подключение ID5. Если у обеих сторон есть собственные подключения ID5, ни одно из них нельзя использовать в рамках совместной работы. В этом случае каждая сторона должна отдельно обогащать свои данные в собственной среде, а затем в совместной работе можно использовать только полученные в результате источники с обогащенными данными. |
