> **Кратко:** Определите разрешения для совместной работы в DCP, которые задают, как ваш соавтор может использовать ваши общие данные.

В этой статье описаны разрешения, доступные при совместном использовании данных в рамках совместной работы в платформе Data Collaboration Platform (DCP). Разрешения для совместного использования определяются **политикой совместной работы**, которую вы задаете при <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-create-a-collaboration">создании совместной работы</Anchor>, и указывают, что соавторы могут делать с вашими данными, а также какие ресурсы или партнеров по активации они могут использовать. Помимо этой политики по умолчанию, пользовательские разрешения для данных также можно задавать отдельно для каждого источника. Политика совместной работы определяет:

* [Разрешения на доступ к данным](#разрешения-на-доступ-к-данным)
* [Разрешения на доступ](#разрешения-на-доступ)

<div id="data-permissions" />

## Разрешения на доступ к данным

Выбранные вами разрешения для данных определяют, как ваш соавтор может использовать связанные с ними данные, и применяются ко всем источникам, которые вы связываете с совместной работой. Разрешения также можно изменять отдельно для каждого источника.

### Разрешения для данных включают:

| Разрешение | Description(Описание) |
| --- | --- |
| **Сделать видимым для партнера** | Позволяет соавтору просматривать и использовать источники, которые вы связываете с совместной работой, в соответствии с другими предоставленными вами разрешениями. Если этот параметр отключен, ваши источники будете видеть только вы. |
| **Данные запроса** | Позволяет сотруднику запрашивать данные и создавать агрегированные отчёты. Вы можете указать, может ли соавтор:<ul><li>**Выполнять запросы только по пересекающимся данным** (пересекающийся набор данных) — относится к общим пользователям обеих сторон.<br />**Примечание:** Если выбран этот параметр, размер источника недоступен.</li><li>**Выполнять запросы по всем данным** (универсальный набор данных) — относится ко всем данным, которые вы связываете с совместной работой.</li></ul> |
| **Создать аудитории** | Позволяет соавтору использовать данные при создании своих <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-add-connections">аудиторий</Anchor>. Вы можете указать, может ли соавтор:<ul><li>**Использовать только пересекающиеся данные** (пересекающийся набор данных) — относится к общим пользователям обеих сторон.<br />**Примечание:** Если выбран этот параметр, размер источника недоступен.</li><li>**Использовать все данные** (универсальный набор данных) — относится ко всем данным, которые вы связываете с совместной работой.</li></ul> |
| **Подключения партнеров** | Позволяет соавтору отправлять аудитории, созданные из ваших источников, в партнерские подключения для активации. При включении этого параметра вы можете предоставить разрешение на экспорт для:<ul><li>**Все подключенные партнеры** — при выборе этого варианта вы также можете **разрешить будущие подключения партнеров**, что автоматически разрешит экспорт аудиторий всем медиапартнерам, с которыми сотрудничает AppsFlyer DCP.</li><li>**Только определенные партнеры**<ul><li>При выборе определенных партнеров вы также можете указать, разрешаете ли вы сотруднику использовать только его подключения для активации или ваши (например, только его подключение Meta или ваше подключение Meta).</li><li>Если вы выберете свои подключения, вам нужно будет указать, какие из ваших подключенных аккаунтов сотрудник сможет использовать (например, только ваше подключение Meta A, но ни одно из ваших других подключений Meta).</li></ul></li></ul>**Важные примечания:**<ul><li>Когда ваши партнеры будут готовы <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-build-and-activate-audiences#отправить-аудиторию-для-активации">активировать аудитории</Anchor> на основе ваших источников, им будут доступны только те подключения партнеров, для которых вы предоставили разрешения.</li><li>Если вы не предоставили сотруднику разрешение на публикацию или экспорт аудиторий, то при попытке активировать аудиторию запрос на активацию будет отправлен вам для завершения.</li></ul> |
| **Экспорт файла** | Позволяет сотруднику экспортировать файлы аудиторий в его облачный бакет. |

## Разрешения на доступ

Разрешения доступа определяют ресурсы, к которым может получить доступ ваш сотрудник. Сюда входит возможность предоставить сотруднику доступ к вашим <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-add-connections#create-data-identity-connections">подключениям Data & Identity (data resolution)</Anchor>, чтобы он мог использовать эти подключения для обогащения своих источников.

**Примечание:** Чтобы предоставить доступ, соответствующее подключение Data & Identity должно быть активным.

## Спецификации и ограничения

В этом разделе описаны некоторые ключевые особенности и ограничения разрешений DCP.

| Характеристика/ограничение | Срок |
| --- | --- |
| **Поведение аудитории** | <ul><li>Если аудитория создана из одного источника → доступных партнеров для активации определяют разрешения партнеров для этого источника.</li><li>Если аудитория создана из нескольких источников с разными разрешениями партнеров →<br />применяется наиболее ограничительный вариант.<br />**Пример:** Источник A разрешает всех партнеров, источник B — только Meta → для активации будет доступна только Meta.</li></ul> |
| **Изменения в разрешениях** | **Полное удаление разрешений на активацию:**<ul><li>Срок действия любой существующей аудитории, использующей затронутый источник, истечет.</li><li>Новые аудитории, использующие этот источник, будут работать как сейчас (потребуются новые разрешения на активацию).</li></ul>**Удаление определенного партнера:**<ul><li>Если существующая аудитория подключена только к этому удаленному партнеру → срок действия аудитории истечет.</li><li>Если аудитория подключена к нескольким партнерам →<br />аудитория останется активной, но активация с удаленным партнером больше не будет доступна.</li></ul> |
