> **Кратко:** Узнайте, как настроить медиапартнеров для off-site-кампаний.

Прежде чем вы сможете передавать подходящие конверсии медиапартнерам вашей <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-collaboration-measurement-overview#off-site-campaigns">off-site-кампании</Anchor> и в ответ получать агрегированные данные об эффективности, сначала необходимо подключить DCP к медиааккаунту, который активирует кампанию. Это подключение сообщает AppsFlyer, как отправлять данные конверсии медиапартнеру.

## Требования

Прежде чем можно будет настроить задачу «Медиапартнеры», владелец совместной работы должен назначить ее участнику совместной работы, который владеет сторонним аккаунтом (например, Facebook или Google). Подробнее см. в статье Назначение задач по настройке

<div id="create-a-media-partner-connection" />

<Accordion title="Создайте подключение медиапартнера">

> 📘 **Примечание**
>
> Задача **Media Partners** отображается на странице **Measurement settings** только при настройке <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-collaboration-measurement-overview#off-site-campaigns">off-site-кампании</Anchor>, в которой в качестве метода предоставления используется пользовательский источник. Подробнее см.: <Anchor target="_blank" href="/marketers/ru/docs/set-up-the-conversions-task#set-conversion-data-provision-method">Настройка метода предоставления данных конверсии</Anchor>

Чтобы выбрать или создать подключение медиапартнера, выполните следующие действия:

1. На странице **Measurement settings** нажмите задачу **Media partners** .

   > 📘 **Примечание**
   >
   > * Если диалоговое окно **Media partners** заблокировано, это означает, что задача **Media partners** назначена вашему участнику совместной работы и вы не можете просматривать ее содержимое. Если вы владелец совместной работы, вы можете разблокировать ее и переназначить задачу себе. Однако все предыдущие настройки будут удалены, а задача будет сброшена.
   > * Если панель **Media partners** неактивна, попросите владельца совместной работы назначить вам задачу Conversions.

2. В диалоговом окне Media partners нажмите **+ Connect media partner**.
3. В диалоговом окне **Connect media partner** создайте или выберите подключение медиапартнера к медиааккаунту, который активирует кампанию:
   * **Если доступно существующее подключение, выберите его:**
     * В раскрывающемся списке **Select connection** выберите существующее подключение.
   * **Если подключений нет, создайте новое:**
     1. Нажмите **+ Новое подключение**.
     2. В окне **New media partner connection** выберите медиапартнера, например **Meta Ads** или **Google Ads**.
     3. В поле **Connection name** введите имя нового подключения.
     4. Нажмите **Войти в [медиапартнера]** и пройдите аутентификацию в окне входа медиапартнера.
     5. После завершения аутентификации нажмите **Save**. После сохранения новое подключение автоматически выбирается в раскрывающемся списке **Select connection** диалогового окна **Connect media partner**.

</Accordion>

<div id="set-the-google-ads-conversion-action-id-parameter" />

<Accordion title="Настройте параметр идентификатора ID действия-конверсии Google Ads">

Если вашим медиапартнером является Google Ads, передайте в DCP параметр идентификатора ID действия-конверсии. Идентификатор ID действия-конверсии берется из вашего аккаунта Google Ads и включается в данные конверсии, отправляемые в Google Ads. Действие-конверсия Conversion Actio**n** должно быть типа `UPLOAD_CLICKS`.

Дополнительную информацию о действии-конверсии в Google Ads см. в <Anchor target="_blank" href="https://support.google.com/google-ads/answer/12216226?hl=en">документации Google Ads</Anchor>.

Чтобы настроить идентификатор ID действия-конверсии Google Ads, выполните следующие шаги:

1. В раскрывающемся списке **Select connection** выберите подключение Google Ads.
2. В диалоговом окне **Connect media partner** укажите идентификатор ID действия-конверсии Google Ads хотя бы в **одном** из следующих полей. **Примечание:** Вы можете использовать один и тот же идентификатор для нескольких веб-ресурсов или мобильных ресурсов, а некоторые ресурсы можно оставить неназначенными. Однако для ресурсов без идентификатора ID действия-конверсии атрибуция выполняться не будет.

   * **Действие-конверсия для веб-сайта:** идентификатор ID действия-конверсии, используемый для событий конверсии, созданных на веб-сайте партнера. Это должно быть **действие-конверсия** типа `UPLOAD_CLICKS`.
   * **Действие-конверсия для приложения (для каждого приложения):** идентификатор ID действия-конверсии, используемый для событий конверсии, созданных в приложении партнера по совместной работе. Введите соответствующий идентификатор ID действия-конверсии, также типа `UPLOAD_CLICKS`.

   > 📘 **Примечание**
   >
   > Эти действия-конверсии должны использоваться **только для измерения DCP** и не должны использоваться для другого трафика.

3. Нажмите **Done** , чтобы вернуться в главное диалоговое окно.
4. Убедитесь, что подключение отображается в списке, затем нажмите **Save**.
5. На странице **Measurement settings** убедитесь, что у медиапартнера отображаются зеленая галочка и статус **Connected**.

</Accordion>

<div id="set-the-meta-ads-meta-pixel-and-dataset-id-parameters" />

<Accordion title="Настройте параметры Meta Pixel и идентификатора ID набора данных в Meta Ads">

Если вашим медиапартнером является Meta Ads, передайте в DCP параметры Meta Pixel и идентификатора ID набора данных. Meta Pixel и идентификатор ID набора данных берутся из вашего аккаунта Meta Ads и включаются в данные конверсии, отправляемые в Meta Ads.

См. документацию Meta Ads о <Anchor target="_blank" href="https://www.facebook.com/business/help/952192354843755?id=1205376682832142">Meta Pixel</Anchor> и <Anchor target="_blank" href="https://www.facebook.com/business/help/5818684664831465?id=490360542427371">идентификаторе ID набора данных</Anchor>.

Чтобы задать идентификатор действия-конверсии Google Ads, выполните следующие шаги:

1. В раскрывающемся списке **Select connection** выберите подключение Meta Ads.
2. В диалоговом окне **Подключить медиапартнера** заполните **как минимум одно** из следующих полей идентификаторами Meta или Pixel. **Примечание:** Некоторые ресурсы можно оставить неназначенными. Однако ресурсы без идентификатора ID действия-конверсии не будут атрибутированы.

   * **Meta Pixel:** Идентификатор ID, используемый для событий конверсии, созданных на сайте партнера.
   * **Идентификатор набора данных (для каждого приложения):** Идентификатор ID, используемый для событий конверсии, созданных в приложении партнера.

   > ❗️ **Предупреждение**
   >
   > Набор данных и Meta Pixel должны соответствовать следующим условиям:
   >
   > * Созданы специально для DCP.
   > * Не должны **напрямую получать какие-либо конверсии** от клиента.
   > * Meta Pixel и идентификатор ID набора данных взаимозаменяемы.


   > 📘 **Примечание**
   >
   > Пользователь **системы** , учетные данные которого передаются DCP, должен:
   >
   > * Иметь **доступ** к набору данных.
   > * Получить **разрешение ads\_read** .

3. Нажмите **Готово** , чтобы вернуться в главное диалоговое окно.
4. Убедитесь, что подключение отображается в списке, затем нажмите **Сохранить**.
5. На **странице настроек измерения** убедитесь, что у медиапартнера отображаются зеленая галочка и статус **Подключено** .

</Accordion>
