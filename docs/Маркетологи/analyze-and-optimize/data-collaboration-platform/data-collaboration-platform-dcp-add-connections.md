> **Краткий обзор:** Настройте подключения DCP, чтобы соединить источники данных, обогатить данные и экспортировать аудиторию в облачные хранилища и медиапартнерам.

<div id="about-dcp-connections" />

## О подключениях DCP

Подключения определяют, как DCP получает ваши данные и экспортирует вашу аудиторию. После <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-set-up-your-cloud-services">настройки облачных сервисов</Anchor> подключите их к DCP с помощью окна **Управление подключениями**. Доступны следующие типы подключений:

* [**Подключения источников**](#create-source-connections): для загрузки ваших собственных данных в DCP из облачного хранилища или хранилища данных.
* [**Подключения к облачному хранилищу**](#create-cloud-storage-connections): для экспорта ваших аудиторий в корзины Amazon S3 или Google Cloud Storage (GCS).
* [**Подключения медиапартнеров**](#create-media-partner-connections): для отправки ваших аудиторий рекламным платформам для активации.
* [**Подключения данных и идентификаторов**](#create-data-identity-connections): предназначены для объединения разрозненных пользовательских данных, чтобы повысить коэффициент совпадений и расширить аудитории на стороне партнеров.

DCP поддерживает разные облачные сервисы для разных направлений подключения. Используйте приведенную ниже таблицу, чтобы узнать, какие сервисы можно использовать для каждого типа подключения:

| Облачный сервис | Источник (входящий) | Экспорт в облачное хранилище (исходящий трафик) |
| --- | --- | --- |
| Amazon S3 | ✓ | ✓ |
| Google Cloud Storage | ✓ | ✓ |
| BigQuery | ✓ | - |
| Snowflake | ✓ | - |
| Salesforce Cloud/CRM | ✓ | - |

Для Amazon S3 и Google Cloud Storage одно соединение служит как источником (входящее сообщение), так и местом назначения экспорта в облачное хранилище (исходящее). При создании подключения источника к S3 или GCS автоматически создаётся соответствующее подключение для экспорта в облачное хранилище, и наоборот.

<div id="create-source-connections" />

<Accordion title="Создать подключение источников">

Создавайте подключения источников для передачи собственных данных в DCP.

**Чтобы создать подключение к источнику, выполните следующие действия:**

1. В AppsFlyer перейдите в раздел Сотрудничество > **Данные** Clean Room.
2. Нажмите **Управление подключениями** в правом верхнем углу.
3. Перейдите на вкладку «**Источник**» и нажмите **+ «Новое подключение».**  
   <Image align="center" alt="2026-07-27_13-30-46.png" src="https://files.readme.io/dec879432c0b9d6ba4eeec2c175dfce145c99652ccabb02d37f3434627f9310f-49189748198289.png" width="529px" />
4. Продолжайте использовать приведенные ниже инструкции по [подключению облачных сервисов для получения исходных данных](#подключения-к-облачным-сервисам-для-исходных-данных).

Кроме того, подключение к источнику можно создать непосредственно при настройке источника. Инструкции см. в разделе <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-create-and-manage-sources">Создание источников и управление ими</Anchor>.

<div id="note" />

> 📘 **Примечание**
>
> При создании входящего подключения Source к Amazon S3 или GCS автоматически создается соответствующее исходящее подключение к облачному хранилищу (и наоборот). При удалении подключения Amazon S3 или GCS второе подключение также удаляется автоматически. Поскольку на самом деле это одно базовое соединение, при удалении его с любой вкладки оно удаляется везде, где оно используется.

<div id="cloud-service-connections-for-source-data" />

#### Подключения к облачным сервисам для исходных данных

Подключения источников предназначены для безопасного подключения источников ваших данных к DCP. В диалоговом окне «**Новое подключение**» выберите облачный сервис и заполните сведения о своем поставщике:

**BigQuery:** В диалоговом окне «**Новое подключение**» введите **идентификатор проекта** BigQuery для проекта, содержащего ваши исходные данные. Вы можете найти это на странице BigQuery в консоли Google Cloud.

**Snowflake:** В окне «**Новое подключение**» введите **идентификатор учетной записи Snowflake** и **регион** для учетной записи, содержащей ваши исходные данные. Чтобы найти это, нажмите на название учетной записи в левом нижнем углу консоли Snowflake:

**ACCOUNTADMIN** > **Учетная запись** > наведите курсор на соответствующую учетную запись > **Скопировать идентификатор учетной записи.** Подробности см. в <Anchor target="_blank" href="https://docs.snowflake.com/en/user-guide/admin-account-identifier#finding-the-organization-and-account-name-for-an-account">документации Snowflake</Anchor>.

<div id="important" />

> 🚧 **Важно!**
>
> Найдите идентификатор с меткой **Locator**. Это **не** тот идентификатор, который использовался для создания исходящих подключений Snowflake.

**Amazon S3 и GCS** В окне «**Новое подключение**» введите название <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-set-up-your-cloud-services#cloud-storage-buckets-inbound">корзины</Anchor>, созданной для эксклюзивного использования AppsFlyer Data Clean Room (DCR).

**Облако Salesforce/CRM:** Узнайте<Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-integration-with-salesforce-data-cloud">, как настроить подключение к Salesforce</Anchor>.

<div id="local-file-connection" />

#### Подключение к локальным файлам

Подключения к локальной файловой системе позволяют загружать файлы данных прямо с компьютера в DCP. Этот вариант обычно используется только для тестирования и не рекомендуется для постоянного или крупномасштабного приема данных.

<div id="set-up-a-local-file-connection" />

<Accordion title="Настройте подключение к локальному файлу">

Соединение с локальным файлом используется для тестирования платформы на примере файла-образца. Это позволяет вам ознакомиться с функциональностью DCP до начала обмена данными. Учтите, что оно не предназначено для совместного использования данных, имеет срок хранения 14 дней и не поддерживает автоматические процессы.

Подключение к локальным файлам можно <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-create-and-manage-sources#расположение-источника-локальные-файлы">настроить во время создания источника</Anchor>.

</Accordion>

</Accordion>

<div id="create-cloud-storage-connections" />

<Accordion title="Создание подключений к облачному хранилищу">

Подключения к облачному хранилищу позволяют автоматически экспортировать аудитории DCP в корзину Amazon S3 или Google Cloud Storage (GCS) после каждого обновления аудитории.

**Чтобы создать подключение к облачному хранилищу:**

1. В AppsFlyer перейдите в раздел Сотрудничество > **Данные** Clean Room.
2. Нажмите **Управление подключениями** в правом верхнем углу.
3. Перейдите в **Облачное хранилище** и нажмите **+ Новое** подключение.  
   <Image align="center" alt="2026-07-27_13-30-34.png" src="https://files.readme.io/1da10127617317d0ff466433c89712d78c104b6a943b4b669e1d7180d22df958-49189843742609.png" width="533px" />
4. Откроется окно «**Новое подключение к облачному хранилищу**».
5. В окне<strong>«Новое подключение к облачному хранилищу</strong>» выберите поставщика облачных услуг: **Google Cloud Storage** or **Amazon Simple Storage**.
6. Введите имя бакета:
   * **GCS:** Введите название корзины GCS в формате. `gs://my-bucket`
   * **S3:** Введите название корзины S3.
7. Нажмите «**Проверить подключение**», чтобы убедиться, что DCP может подключиться к вашей корзине.
8. Нажмите **Сохранить**. Новое подключение появится в разделе **Ваши подключения к облачному хранилищу** на вкладке **Облачное хранилище**.

Вы также можете создать подключение к облачному хранилищу непосредственно в конструкторе аудиторий. Инструкции см. в разделе <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-build-and-activate-audiences">Создание и активация аудитории</Anchor>.

<div id="understand-export-path" />

<Accordion title="Понять путь экспорта">

Каждый раз, когда аудитория экспортируется, DCP записывает ее в корзину, используя фиксированный и предсказуемый путь:

```
<bucket>/dcp-output/audiences/<collaboration-id>/t=<audience_name>_<id>/dt=<YYYY-MM-DD>/v=<version>/<file>.csv
```

**Пример содержимого папки для одной поставки:**

```
s3://af-dcr-example-bucket/dcp-output/audiences/8f3a1c02-44b1-4e9a-9c7d-2b6e1a0f5d3e/t=example_audience_6148a3/dt=2026-07-18/v=1/
  ├── part-00000-a1b2c3d4-e5f6-47a8-9b0c-1d2e3f4a5b6c-c000.csv
  ├── part-00001-a1b2c3d4-e5f6-47a8-9b0c-1d2e3f4a5b6c-c000.csv
  └── _SUCCESS
```

| Сегмент пути | Что это значит |
| --- | --- |
| : | Подключенная корзина S3 или GCS. |
| dcp-output/audiences/ | Исправлена папка, которую DCP автоматически создает для экспорта всех аудиторий. |
| : | Уникальный идентификатор сотрудничества, к которому принадлежит эта аудитория. Вы можете найти его в URL-адресе сотрудничества в DCP. |
| t=\_ | Название аудитории (пробелы и специальные символы заменены символами подчеркивания), а также уникальный идентификатор. Это гарантирует, что удаленная и воссозданная аудитория с тем же названием никогда не перезапишет старые файлы и не столкнется с ними. |
| dt= | Дата доставки. |
| v= | Номер версии для экспорта этой аудитории. Она увеличивается с каждой новой поставкой. |
| part-NNNNN--c000.csv | Один из выходных файлов этой поставки – см. ниже раздел «Формат файла и разбиение». |
| \_SUCCESS | Пустой маркерный файл, который создаётся после записи всех частей выгрузки. |

<div id="note-1" />

> 📘 **Примечание**
>
> Эта структура папок создается и управляется автоматически. Не переименовывайте и не меняйте структуру вручную — любой автоматический процесс, который читает эти файлы, должен быть настроен так, чтобы следовать этой структуре путей и ждать появления файла \_SUCCESS перед обработкой файлов-частей, чтобы не обрабатывать неполную выгрузку.

**Формат и разделение файлов**

* Аудитории всегда экспортируются в виде CSV-файлов без сжатия с двумя столбцами: `value` (идентификатор) и `taxonomy` (тип идентификатора).
* Большим аудиториям можно доставлять несколько файлов, а не один файл, `part-00000` пронумерованный и `part-00001` т. д. По умолчанию каждый файл содержит до 500 000 строк. По умолчанию каждый файл содержит примерно 500 000 строк.
* Один файл может содержать разные типы идентификаторов в одних и тех же строках – отфильтруйте нужные вам значения по `taxonomy` столбцу. Общие значения таксономии включают`customer_id`, `mobile_ad_id` `hashed_email`, и`hashed_phone_number_without_plus_sha256`.

**Пример:**

```
value,taxonomy
6f1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c,customer_id
1a2b3c4d-5e6f-4a7b-8c9d-0e1f2a3b4c5d,mobile_ad_id
b7e2c9a1f4d6e8b0a2c4d6e8f0a1b3c5d7e9f1a3b5c7d9e0f2a4b6c8d0e2f4a6,hashed_email
c1d3e5f7a9b1c3d5e7f9a1b3c5d7e9f1a3b5c7d9e1f3a5b7c9d1e3f5a7b9c1d3,hashed_phone_number_without_plus_sha256
```

</Accordion>

<div id="create-media-partner-connections" />

<Accordion title="Создавайте подключения медиапартнеров">

Исходящие подключения медиапартнеров позволяют безопасно подключать аудиторию DCP к поддерживаемым медиапартнерам и активировать персонализированные кампании на их платформах. Медиапартнеры — основное направление для активизации аудитории. Узнайте, как <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-media-partner-connections">настроить подключения с конкретными медиапартнерами</Anchor>.

**Чтобы создать связь с медиапартнером, выполните следующие действия:**

1. В AppsFlyer перейдите в раздел Сотрудничество > **Данные** Clean Room.
2. Нажмите **Управление подключениями** в правом верхнем углу.
3. Перейдите на вкладку **Медиапартнеры** и нажмите **+ Новое подключение**. Если у вас уже есть подключения, вы увидите их в списке **Медиапартнеры**.
4. В диалоговом окне **«Новое подключение медиапартнёра»** выберите нужного медиапартнера.
5. Введите название подключения.
6. Войдите в учетную запись медиапартнера со своими учетными данными и следуйте их инструкциям, чтобы открыть доступ AppsFlyer.
7. Нажмите «**Выбрать идентификатор учетной записи**» и выберите соответствующую учетную запись для этого подключения.
8. Нажмите **Сохранить**. Новое подключение добавлено в список партнеров.

Вы также можете установить подключение с медиапартнером непосредственно в конструкторе аудиторий. Инструкции см. в разделе <Anchor target="_blank" href="/marketers/ru/docs/data-collaboration-platform-dcp-build-and-activate-audiences">Создание и активация аудитории</Anchor>.

</Accordion>
