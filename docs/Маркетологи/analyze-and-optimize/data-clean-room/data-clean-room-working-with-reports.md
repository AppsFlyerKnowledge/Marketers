> **Кратко:** Работайте с отчетами, которые вы настроили в Data Clean Room (DCR).

<div id="introduction" />

## Введение

В этой статье рассказывается о работе с отчетами, которые вы уже создали. Полный список этих отчетов и их статусы можно просмотреть на вкладке **Reports** в DCR.  
  
Если вам нужны инструкции по созданию новых отчетов DCR, см. следующие статьи:

* <Anchor target="_blank" href="/marketers/ru/docs/data-clean-room-creating-attribution-data-reports">Создание отчетов по данным Атрибуции</Anchor>
* <Anchor target="_blank" href="/marketers/ru/docs/data-clean-room-creating-in-app-event-reports">Создание отчетов по событиям в приложении</Anchor>

## Редактирование или удаление отчета

**Чтобы отредактировать отчет:**

1. Перейдите на вкладку **Reports** в **Data Clean Room.**
2. В списке отчетов наведите курсор на строку с отчетом, который требуется отредактировать.
3. Нажмите кнопку «Редактировать» ![edit_button.png](https://files.readme.io/4c3822661beac49fad247c7f5958a535e46031238e975a5323a5550722c89c8a-10753875375377.png), которая отображается справа от строки.
4. На странице **Edit report** внесите необходимые изменения в настройках отчета.
   * Название отчета в настоящее время нельзя изменить.
5. Чтобы изменить место назначения отчета:
   1. Прокрутите вниз до раздела **Report destination**.
   2. Нажмите кнопку «Редактировать» ![edit_button.png](https://files.readme.io/4c3822661beac49fad247c7f5958a535e46031238e975a5323a5550722c89c8a-10753875375377.png) рядом с текущим местом назначения отчета.
   3. Внесите необходимые изменения в диалоговом окне **Report destination**.
   4. Нажмите **Apply**, чтобы применить изменения.
6. Нажмите кнопку **Update**, чтобы сохранить отчет с новыми настройками, или **Discard changes**, чтобы отменить изменения.

**Чтобы удалить отчет:**

1. Перейдите на вкладку **Reports** в **Data Clean Room.**
2. В списке отчетов наведите курсор на строку с отчетом, который вы хотите удалить.
3. Нажмите кнопку «Удалить» ![delete_button.png](https://files.readme.io/10fbd4d4f09ddb56823a2824629f8bb9362b34c95038b3d9e747ffcde7b30381-24740010666129.png) которая отображается справа от строки.
4. В диалоговом окне подтвердите удаление отчета.
