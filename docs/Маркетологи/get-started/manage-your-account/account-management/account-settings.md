> **Краткий обзор:** Используйте страницу **Настройки аккаунта**, чтобы управлять своим личным профилем, настройками аккаунта и возможностями ИИ в одном месте.

<div id="about-account-settings" />

## **О настройках аккаунта**

Страница **Настройки аккаунта** имеет три вкладки:

* [**Профиль**](/docs/account-settings#профиль): Ваши личные данные аккаунта
* [**Аккаунт**](/docs/account-settings#аккаунт): Настройки на уровне учетной записи
* [**Возможности ИИ**](/docs/account-settings#возможности-ии): Управление продуктами на базе ИИ и доступом

<div id="profile" />

## **Профиль**

Раздел **Профиль** отображает ваши данные аккаунта, такие как название аккаунта, электронная почта владельца, веб-сайт и идентификатор аккаунта.

Используйте этот раздел, чтобы просмотреть информацию о вашем аккаунте и обновить поддерживаемые поля профиля.

<div id="account" />

## **Аккаунт**

Раздел **Аккаунт** включает настройки безопасности на уровне аккаунта. Дополнительные настройки самообслуживания аккаунта могут быть добавлены со временем.

<div id="unique-dev-key" />

### <Anchor target="_blank" href="/marketers/ru/docs/dev-key-management">**Уникальный ключ разработчика**</Anchor>

Настройка **Уникальный ключ разработчика** контролирует, создает ли AppsFlyer уникальный ключ разработчика для каждого нового приложения.

Когда включено **создание уникального ключа разработчика для приложений**, уникальный ключ разработчика будет автоматически создан для каждого нового добавленного приложения.

Примечание: Эта настройка применяется только к приложениям, созданным после включения настройки. Она не изменяет ключи разработчиков существующих приложений.

<div id="ai-capabilities" />

## **Возможности ИИ**

Раздел **Возможности ИИ** позволяет администраторам управлять тем, какие поддерживаемые продукты на базе ИИ доступны для аккаунта.

<div id="ai-assistant" />

### <Anchor target="_blank" href="/marketers/ru/docs/ai-assistant">ИИ-ассистент</Anchor>

ИИ-ассистент — ваш личный виртуальный аналитик и помощник по знаниям платформы в AppsFlyer. Используйте его для получения аналитики, измерения эффективности, выявления лучших и худших исполнителей, обнаружения тенденций кампаний и изучения визуальных данных, таких как таблицы и графики, напрямую с любой страницы платформы.

<div id="appsflyer-mcp" />

### <Anchor target="_blank" href="/marketers/ru/docs/beta-appsflyer-mcp">MCP от AppsFlyer</Anchor>

MCP от AppsFlyer подключает ваши данные в AppsFlyer к любой большой языковой модели (LLM), например Claude или VS Code. Задавайте вопросы, получайте аналитику об эффективности и действуйте непосредственно в чате с ИИ.

MCP включён по умолчанию для всех учётных записей.

Чтобы отключить MCP, перейдите в раздел **Account & Profile > AI capabilities**.

Отключение MCP:

* Пользователи больше не могут получать доступ к данным AppsFlyer через MCP в сторонних инструментах ИИ.
* Существующие соединения могут продолжать работать до окончания текущей сессии.
* Не влияет на стандартные подключения к API.
* Не влияет на другие возможности ИИ в AppsFlyer

**Важно:** Если токен MCP используется, его необходимо сначала удалить в **Центр безопасности > Токены AppsFlyer**.

### <Anchor target="_blank" href="/marketers/ru/docs/beta-agent-hub-overview">Agent Hub</Anchor>

Agent Hub — централизованная платформа AppsFlyer для управления ИИ-агентами, которые проактивно доставляют применимые маркетинговые инсайты прямо в ваш рабочий процесс. Эти агенты постоянно анализируют ваши данные, чтобы предоставлять ценные результаты и рекомендовать действенные шаги, все это в рамках совместной работы вашей команды.

Этот параметр доступен только администраторам и включён по умолчанию.

Отключение Agent Hub:

* Пользователи больше не смогут получить доступ к Agent Hub.
* Все существующие агенты будут удалены и не подлежат восстановлению.
* Все активные запуски агента останавливаются.
* Если позже Agent Hub снова будет включён, пользователи снова смогут получить к нему доступ, но им придётся создавать агентов с нуля.

<div id="permissions" />

## **Разрешения**

То, что вы можете просматривать или редактировать на странице **Настройки аккаунта**, зависит от ваших прав пользователя.

В общем:

* Не все пользователи увидят одинаковые настройки
* Некоторые настройки могут быть только для просмотра
* Для изменения настроек уровня аккаунта или параметров, связанных с ИИ, может потребоваться разрешение администратора.
