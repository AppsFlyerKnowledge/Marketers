> **Краткий обзор**. С помощью механизма квоты (лимита на предоставление данных) ограничивается количество отчетов, которые можно сформировать в день через Pull API и на страницах экспорта данных.

<div id="rate-limits-for-reports" />

## Лимиты на предоставление данных для отчетов

Квота определяет, сколько отчетов можно формировать в день, по типам отчетов. Размер квоты зависит от тарифного плана.

**Принципы:**

* **Агентства**: отчеты Pull API, формируемые агентствами, учитываются в квоте рекламодателя на отчеты Pull API. Квота применяется к каждому отчету, каждому дню и каждому приложению одинаково в обоих случаях. Для отчетов со страницы экспорта данных агентства и рекламодатели имеют отдельные квоты. Если вы исчерпали лимит, свяжитесь с менеджером аккаунта.
* **Рекламные сети**: отчеты, формируемые рекламными сетями, учитываются в квоте рекламодателя.
* **День**: квоты указываются на календарный день, начиная с 00:00 UTC

<div id="aggregated-and-analytics-reports" />

### Агрегированные и аналитические отчеты

| Инструмент доставки | Квота |
| --- | --- |
| Сводные данные через Pull API | <ul><li>До 2 дней в диапазоне дат:<ul><li>Максимум один вызов в минуту для приложения в отчете</li></ul></li><li>Диапазон дат 3 и более дней, вызовы ограничены:<ul><li>Макс. 120 вызовов в день на аккаунт</li><li>24 вызовов в день на приложение</li></ul></li></ul> |
| Страница экспорта агрегированных данных | Без ограничений |
| Master API. | Без ограничений |
| Когортный API | 60 вызовов в минуту на аккаунт |
| Агрегированные отчеты SKAN | 10 вызовов в минуту на аккаунт |

### Сырые данные

* Отдельная квота действует для каждого инструмента отчетности, т. е. для Pull API и страницы экспорта сырых данных.
* Для Pull API отчеты, формируемые агентствами, учитываются в квоте рекламодателя. Отчеты, формируемые агентством, могут учитываться в квоте рекламодателя. Единственное исключение — когда агентство использует API-токен рекламодателя вместо собственного. В этом случае запросы неотличимы от запросов рекламодателя и учитываются в квоте рекламодателя. Для отчетов со страницы экспорта данных агентства и рекламодатели имеют отдельные квоты.
* Квоты на получение данных через Pull API применяются на:
  * Отчет
  * День
  * На уровне приложения
  * На уровне аккаунта
* Для рекламодателей квоты зависят от подписки AppsFlyer. **Примечание**. Квоты распространяются также на отчеты, требующие премиум-подписки.
* Дневные квоты рекламных сетей указаны в следующей таблице.

Чтобы разобраться, как это работает, ознакомьтесь с ответами на часто задаваемые вопросы после таблиц.

#### Ежедневная квота рекламной сети по сырым данным

Рекламные сети могут получать следующие типы отчетов по постбэкам:

| Группа | Тип отчета  <br />(у каждого типа отдельная квота) | Квота на уровне приложения | Ежедневная квота на уровне аккаунта |
| --- | --- | --- | --- |
| Постбэки для атрибуции | <ul><li>Установок</li><li>Конверсии по ретаргетингу.</li></ul> | 24 | 120 |
| Доход от рекламы ретаргетинга | <ul><li>Внутренние события приложений</li><li>Конверсии по ретаргетингу.</li></ul> | 12 | 60 |

<div id="faq" />

#### **Вопросы и ответы**

* В: Могу ли я для определенного приложения создать 24 отчета по органическим установкам, используя Pull API, и еще 24 отчета через страницу экспорта сырых данных?  
  О: Да. По каждому инструменту отчетности отдельная квота.
* В: Могу ли я, используя страницу экспорта сырых данных, создать по определенному приложению 24 отчета по органическим установкам, 24 отчета по неорганическим установкам и 24 отчета по конверсиям ретаргетинга?  
  О: Да. По каждому типу отчетов отдельная квота.
* В: В моем аккаунте 25 приложений. Могу ли я создать по каждому из них 10 отчетов по органическим установкам?  
  О: Нет. В совокупности это 250 отчетов, что превышает квоту уровня аккаунта в 120 отчетов.
* В: Учитываются ли Pull API-отчеты, формируемые агентством, в квоте рекламодателя?  
  О: Нет. Для Pull API отчеты, формируемые агентствами, учитываются в квоте рекламодателя. Отчеты, формируемые агентством, могут учитываться в квоте рекламодателя. Единственное исключение — когда агентство использует API-токен рекламодателя вместо собственного. В этом случае такие запросы учитываются как запросы рекламодателя.
