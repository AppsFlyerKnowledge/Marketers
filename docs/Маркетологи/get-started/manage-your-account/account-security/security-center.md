> **Краткий обзор:** Просматривайте и управляйте статусом всех функций, связанных с безопасностью, вашего аккаунта AppsFlyer из одного места.

<div id="what-can-i-do-from-the-security-center" />

## Что я могу сделать в Центре безопасности?

**Центр безопасности** предоставляет краткий обзор статуса безопасности вашего аккаунта AppsFlyer. Нажмите кнопку в любом разделе **Центра безопасности**, чтобы получить доступ к следующим функциям:

| Функция | Описание |
| --- | --- |
| <span id="user-management"></span><Anchor target="_blank" href="/marketers/ru/docs/user-management">Управление пользователями</Anchor> | Создавайте и управляйте пользователями AppsFlyer. Назначайте им разрешения для доступа к необходимым функциям, приложениям и данным. |
| <span id="redirect-allowlist"></span><Anchor target="_blank" href="/marketers/ru/docs/set-up-your-domain-redirect-allowlist">Список разрешённых перенаправлений</Anchor> | Определите разрешённые домены для перенаправления ссылок. |
| <span id="list-of-authorized-agencies-for-ad-networks"></span><Anchor target="_blank" href="/partners/ru/docs/set-up-your-list-of-authorized-agencies">Список уполномоченных агентств</Anchor> (для рекламных сетей) | Управляйте агентствами, которым вы разрешаете запускать кампании через интеграцию с вашей сетью. |
| <span id="api-allowlist"></span><Anchor target="_blank" href="/marketers/ru/docs/set-up-your-api-allowlist">Список разрешённых API</Anchor> | Определите разрешённые IP-адреса для API-запросов. |
| <span id="enhanced-login-security"></span>Усиленная безопасность входа в систему | Настройте <Anchor target="_blank" href="/marketers/ru/docs/set-up-sso-authentication-with-your-identity-provider-idp">систему единого входа (SSO)</Anchor> или <Anchor target="_blank" href="/marketers/ru/docs/implementing-and-using-2fa-login">двухфакторную аутентификацию (2FA)</Anchor>, чтобы защитить свою учетную запись от несанкционированного доступа. |
| <span id="appsflyer-api-and-s2s-tokens"></span><Anchor target="_blank" href="/marketers/ru/docs/managing-appsflyer-tokens">Токены AppsFlyer</Anchor> | Используйте токены AppsFlyer для аутентификации ваших вызовов API и S2S. Управляйте токенами и периодически их обновляйте для максимальной безопасности. |
| <span id="audit-log"></span><Anchor target="_blank" href="/marketers/ru/docs/audit-log">Журнал аудита</Anchor> | Анализируйте активность учетной записи для выявления несанкционированного доступа: входы в систему, действия по управлению пользователями и вызовы API. |

**Доступ к Центру безопасности:**

* На верхней панели откройте меню аккаунта (выпадающий список под адресом электронной почты) > **Центр безопасности.**
