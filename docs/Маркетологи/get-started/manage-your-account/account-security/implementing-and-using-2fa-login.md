> **Краткий обзор:** Используйте двухфакторную аутентификацию (2FA), чтобы добавить дополнительный уровень безопасности в процесс входа в аккаунт. Учётные данные для входа пользователей аккаунта дополняются Google Authenticator или SMS-подтверждением.

## Основные цифры

* 2FA является необязательной функцией, активируемой администратором.
* Возможные опции: **Google Authenticator** и **SMS-подтверждение.**
* Активация/деактивация применяется ко всем пользователям аккаунта.
* Пользователи аккаунта на момент активации смогут войти в систему и им будет предложено настроить 2FA при следующем входе.

## ![admin.png](https://files.readme.io/d54680123b25ab7929285cebd778e0e74bd0d032df994b04d1bca106381c3dc6-360014518718.png) Администратор: управление 2FA

Только администратор может активировать, сбросить или деактивировать настройки 2FA пользователя.

<div id="activate" />

<Accordion title="Активировать">

Если администратор активирует **Google Authenticator** и **SMS-подтверждение**, пользователи аккаунта могут выбрать, какой метод они предпочитают использовать.

> 📘 **Примечание:**
>
> SMS-подтверждение зависит от успешности отправки SMS, которая варьируется в зависимости от мобильного оператора и страны. Поэтому мы настоятельно рекомендуем включить как SMS-подтверждение, так и Google Authenticator, чтобы избежать блокировки из-за неудачной доставки SMS.

**Как активировать 2FA**

1. На верхней панели откройте меню аккаунта (выпадающий список под адресом электронной почты) > **Центр безопасности**.
2. В разделе **Enhanced login security (Улучшенная безопасность входа)** нажмите **Configure login method (Настроить метод входа)**, чтобы получить доступ к странице **Login security (Безопасность входа)**.
3. В разделе **Two-factor authentication (2FA) (Двухфакторная аутентификация (2FA))** активируйте переключатель для **Google Authenticator** и/или **SMS-подтверждения.**

</Accordion>

<div id="reset" />

<Accordion title="Сброс">

Для аккаунтов, использующих 2FA, могут возникнуть ситуации, когда вам потребуется сбросить 2FA пользователя. Имейте в виду, что после сброса для 2FA по умолчанию выбирается **Google Authenticator** .

**Как сбросить 2FA пользователя**

1. В строке меню нажмите значок раскрывающегося списка под вашим электронным адресом.
2. Выберите **Управление пользователями**.
3. На вкладке **Пользователи** нажмите на меню <Image alt="actions_icon.png" src="https://files.readme.io/24ad987d1e77d9dfa8559a370733a7b62a6d86954ec1d552eac9c406445ed927-16162502616593.png" width="25px" /> в крайнем правом углу строки пользователя.
4. В меню выберите **Reset 2FA (Сбросить 2FA)**.

**Примечание:** Администратор может сбросить двухфакторную аутентификацию для другого администратора, но не для себя и не для <Anchor target="_blank" href="/marketers/ru/docs/user-management#администратор">владельца аккаунта</Anchor>. Чтобы сбросить двухфакторную аутентификацию для владельца аккаунта, обратитесь в службу поддержки AppsFlyer.

</Accordion>

<div id="deactivate" />

<Accordion title="Деактивация">

Если 2FA деактивирована, пользователи аккаунта будут входить в систему, используя только своё имя пользователя и пароль.

**Как деактивировать 2FA**

1. На верхней панели откройте меню аккаунта (выпадающий список под адресом электронной почты) > **Центр безопасности**.
2. В разделе **Enhanced login security (Улучшенная безопасность входа)** нажмите **Configure login method (Настроить метод входа)**, чтобы получить доступ к странице **Login security (Безопасность входа)**.
3. В разделе **Two-factor authentication (2FA) (Двухфакторная аутентификация (2FA))** деактивируйте переключатель для **Google Authenticator** и/или **SMS-подтверждения.**
4. Подтвердите деактивацию.

</Accordion>

## Пользователи аккаунта: использование Google Authenticator

**Google Authenticator** является вариантом по умолчанию; однако при следующем входе отображается последний использованный метод 2FA.

Если вы решите не использовать **Google Authenticator**, то экраны настройки и входа будут содержать ссылку на экран **SMS-подтверждения**.

<div id="firsttime-setup" />

<Accordion title="Первоначальная настройка">

Перед использованием 2FA в первый раз каждый пользователь аккаунта должен скачать **Google Authenticator** и приложение для сканирования **QR-кода**. Эти приложения доступны в **Google Play** (Android) и **App Store** (iOS).

**Новый пользователь аккаунта**

1. Следуйте инструкциям, описанным в электронном письме, и создайте пароль.
2. Войдите в **AppsFlyer**, после чего вы будете перенаправлены на страницу настройки 2FA.
3. Настройте 2FA.
   * Скачайте **Google Authenticator** и приложение для сканирования **QR-кода**.
   * Отсканируйте QR-код.
   * Введите код подтверждения, сгенерированный приложением **Google Authenticator**.
   * Нажмите **Verify (Подтвердить)**, затем вы будете перенаправлены на страницу **My apps (Мои приложения)**.

**Существующие пользователи аккаунта**

1. Войдите в **AppsFlyer** (имя пользователя и пароль), после чего вы будете перенаправлены на страницу настройки 2FA.
2. Настройте 2FA.
   * Скачайте **Google Authenticator** и приложение для сканирования **QR-кода**.
   * Отсканируйте QR-код.
   * Введите код подтверждения, сгенерированный приложением **Google Authenticator**.
   * Нажмите **Verify (Подтвердить)**, затем вы будете перенаправлены на страницу **My apps (Мои приложения)**.

</Accordion>

<div id="ongoing-use" />

<Accordion title="Постоянное использование">

**Следуйте этим шагам для постоянного использования.**

1. Войдите в **AppsFlyer** (имя пользователя и пароль), после чего вы будете перенаправлены на страницу входа 2FA.
2. Откройте **Google Authenticator** на своём телефоне, чтобы получить код подтверждения.
3. Введите код на странице 2FA.
4. Нажмите **Verify (Подтвердить)**, затем вы будете перенаправлены на страницу **My apps (Мои приложения)**.

</Accordion>

## Пользователи аккаунта: использование SMS-подтверждения

Если вы решите не использовать **SMS-подтверждение**, то экраны настройки и входа будут содержать ссылку на экран **Google Authenticator**.

<div id="firsttime-sms-setup" />

<Accordion title="Первоначальная настройка SMS">

**Google Authenticator** является методом 2FA по умолчанию. Чтобы переключиться на **SMS-подтверждение**, нажмите на ссылку **SMS-подтверждение**.

**Новый пользователь аккаунта**

1. Следуйте инструкциям, описанным в электронном письме, и создайте пароль.
2. Войдите в **AppsFlyer**, после чего вы будете перенаправлены на страницу настройки 2FA.
3. Настройте 2FA:
   * Введите свой номер телефона (только цифры, без специальных символов) и нажмите **Send code (Отправить код)**.
   * Введите код SMS-подтверждения > нажмите **Verify (Проверить)**.

**Существующие пользователи аккаунта**

1. Войдите в **AppsFlyer** (имя пользователя и пароль), после чего вы будете перенаправлены на страницу настройки 2FA.
2. Настройте 2FA:
   * Введите свой номер телефона (только цифры, без специальных символов) и нажмите **Send code (Отправить код)**.
   * Введите код SMS-подтверждения > нажмите **Verify (Проверить)**.

</Accordion>

<div id="ongoing-sms-use" />

<Accordion title="Постоянное использование SMS">

**Следуйте этим шагам для постоянного использования.**

1. Войдите в **AppsFlyer** (имя пользователя и пароль), после чего вы будете перенаправлены на страницу входа 2FA.
2. Страница **SMS-подтверждение** появится, если она использовалась во время вашего последнего входа. Если нет, нажмите на ссылку внизу страницы 2FA – **Google Authenticator**.
3. Ваш номер телефона отобразится автоматически. Нажмите **Send code (Отправить код)**.
4. Введите код подтверждения, отправленный в SMS.
5. Нажмите **Verify (Проверить)**.

</Accordion>
