> **Обзор:** Защитите свой аккаунт AppsFlyer, настроив список разрешенных API.

## [<Image alt="Список разрешённых API" src="https://files.readme.io/05f8c46f81b679e2881bf72255ae835a70d1cb3be1ea862b90053c2c259f25b6-4423224122385.png" width="609px" />](https://files.readme.io/05f8c46f81b679e2881bf72255ae835a70d1cb3be1ea862b90053c2c259f25b6-4423224122385.png)

## Обзор

Защитите свои данные от несанкционированного доступа, настроив список разрешенных IP-адресов, которые могут выполнять вызовы API к вашей учетной записи AppsFlyer. После активации списка разрешений вызовы API будут разрешены только с указанных IP-адресов, а вызовы с других IP-адресов будут отклонены.

> 📘 **Примечание**
>
> * Только администраторы могут получить доступ к списку разрешенных и управлять им.
> * Использование списка разрешений необязательно и по умолчанию неактивно.
> * Активация списка разрешенных производится на уровне учетной записи и распространяется на все приложения в учетной записи.

## Настройте список разрешенных API

<div id="set-up-the-api-allowlist" />

<Accordion title="Настройте список разрешенных">

**![AppsFlyerAdmin_us-en.png](https://files.readme.io/d67fdedd94c56e8da776e590b12883503f47d36f0d58b996c4c64cc5d0e9c675-16281491712785.png) altAppsFlyerAdmin\_us-en.pngaltДля настройки и активации списка разрешенных API:**

1. На верхней панели откройте меню аккаунта (выпадающий список под адресом электронной почты) > **Центр безопасности**.
2. В разделе «Список разрешенных API» нажмите **Управление списком разрешенных API**.
3. Введите IP-адрес или диапазон IP-адресов в стандартном формате:
   * Примеры: `192.168.1.1`, `185.114.120.140`
   * Для ввода диапазона IP-адресов используйте следующий формат: `185.114.120.1/32`(где `185.114.120.1` — первый адрес в диапазоне, а `185.114.120.32` — последний адрес в диапазоне).
4. Нажмите **Применить.**
5. [Необязательно] Нажмите **+ Добавить**, чтобы добавить дополнительный IP-адрес или диапазон в список.
6. Нажмите кнопку **Сохранить список**.
7. Установите для списка разрешенных статус **Активно.**

   **Примечание:** Список разрешенных должен содержать хотя бы один IP-адрес или диапазон для сохранения и активации.

</Accordion>

<div id="edit-the-api-allowlist" />

<Accordion title="Изменение списка разрешенных">

Вы можете добавлять или удалять IP-адреса из списка разрешенных в любое время (независимо от статуса).

**![AppsFlyerAdmin_us-en.png](https://files.readme.io/d67fdedd94c56e8da776e590b12883503f47d36f0d58b996c4c64cc5d0e9c675-16281491712785.png) altAppsFlyerAdmin\_us-en.pngaltДля добавления IP-адреса или диапазона:**

1. На верхней панели откройте меню аккаунта (выпадающий список под адресом электронной почты) > **Центр безопасности**.
2. В разделе «Список разрешенных API» нажмите **Управление списком разрешенных API**.
3. Нажмите **+ Добавить**, чтобы добавить IP-адрес или диапазон в список.
4. Введите IP-адрес или диапазон.
5. Нажмите **Применить.**
6. Обязательно сохраните изменения, нажав кнопку **Сохранить список**.

   **Примечание:** Статус списка (Активный или неактивный) не изменится при сохранении. Обязательно проверьте состояние переключателя **Активный** и при необходимости активируйте или деактивируйте его.

**![AppsFlyerAdmin_us-en.png](https://files.readme.io/d67fdedd94c56e8da776e590b12883503f47d36f0d58b996c4c64cc5d0e9c675-16281491712785.png) altAppsFlyerAdmin\_us-en.pngaltДля удаления IP-адреса или диапазона:**

1. На верхней панели откройте меню аккаунта (выпадающий список под адресом электронной почты) > **Центр безопасности**.
2. В разделе «Список разрешенных API» нажмите **Управление списком разрешенных API**.
3. Нажмите на значок корзины рядом с IP-адресом, который нужно удалить.
4. Во всплывающем окне подтверждения нажмите **Удалить.**
5. Обязательно сохраните изменения, нажав кнопку **Сохранить список**.

</Accordion>

<div id="api-allowlist-specifications" />

<Accordion title="Характеристики разрешенного списка">

* Для защиты вашего аккаунта от несанкционированных вызовов API, разрешенный список должен быть **Активирован** и содержать хотя бы один IP-адрес или диапазон.
* Разрешенный список применяется ко всем <Anchor target="_blank" href="/marketers/ru/docs/managing-appsflyer-tokens#применение-токена-api-v2">API AppsFlyer, использующим токен V2.0</Anchor><Anchor target="_blank" href="/marketers/ru/docs/managing-appsflyer-tokens#применение-токена-api-v2">. Вызовы из API с токеном V1.0 разрешены с любых API-адресов.</Anchor>
* Можно добавить до 20 IP-адресов или диапазонов в разрешенный список.

</Accordion>
