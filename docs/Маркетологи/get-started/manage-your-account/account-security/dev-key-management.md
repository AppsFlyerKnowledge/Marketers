> **Кратко:** контролируйте и обновляйте Dev Key вашего приложения прямо в настройках приложения. Это обеспечивает большую гибкость и безопасность.

## Что такое Dev Key?

Ключ разработчика (Dev Key) — это уникальный идентификатор вашего приложения, который используется для аутентификации данных о событиях, отправляемых из SDK и через серверные (S2S) интеграции в AppsFlyer. Он необходим для включения атрибуции, сессий и измерения событий в приложении.  
По умолчанию все приложения в вашем аккаунте используют один и тот же Dev Key. Но при необходимости вы можете создать уникальный Dev Key для каждого приложения.  
Чтобы обеспечить больший контроль, вкладка Dev Key Management в настройках приложения позволяет пользователям с правами администратора просматривать Dev Key и управлять ими, включая обновление или замену существующего Dev Key.

## Где найти Dev Key

В AppsFlyer в боковом меню выберите **Настройки** > **Настройки приложения** > **Dev Key Management**.

## Управление Dev Key

На вкладке Dev Key Management администраторы могут:

* Создать уникальный Dev Key для конкретного приложения.
* Назначить Dev Key, который уже используется другим приложением в аккаунте.
* Включить создание уникальных Dev Key по умолчанию для новых приложений.

### Зачем может понадобиться изменить Dev Key

Изменить Dev Key может потребоваться по нескольким причинам:

* **Безопасность**: замените ключ, если он стал известен посторонним, чтобы предотвратить несанкционированный доступ.
* **Перенос аккаунта**: после переноса приложения в другой аккаунт создайте новый Dev Key, чтобы он соответствовал текущему аккаунту.
* **Детализация**: назначайте уникальные ключи для каждого приложения, чтобы упростить мониторинг, устранение неполадок или контроль доступа.

### Как настроить и изменить Dev Key

После создания или назначения нового Dev Key важно:

* Обновить SDK: замените Dev Key в коде SDK вашего приложения.
* Выпустить новую версию: отправьте новую версию приложения с обновленным ключом в магазин приложений.
* Активируйте ключ (обязательно) — активация Dev Key — это **обязательный шаг**, чтобы изменения вступили в силу.
* После того как разработчик обновит SDK с новым Dev Key и новая версия приложения станет доступна в магазине приложений, вернитесь в раздел **Управление Dev Key** и нажмите **Активировать Dev Key**.
* Пока вы не активируете Dev Key:
  * Существующий Dev Key останется активным
  * Новый Dev Key останется в состоянии *Pending*
  * Изменения не повлияют на сбор данных

> 🚧 **Двоеточие (:)**
>
> Активируйте Dev Key только после того, как обновленная версия приложения станет доступна пользователям. Если активировать слишком рано, события в приложении и сессии из старых версий приложения могут перестать записываться.

1. В AppsFlyer в боковом меню выберите Settings > App Settings > SDK authentication.
2. Нажмите Manage Dev Key.
3. Оцените воздействие изменения Dev Key, прежде чем продолжить.
4. Выберите способ настройки нового Dev Key:
   1. **Выбрать существующий Dev Key** — выберите Dev Key, который уже существует в вашем аккаунте (например, Dev Key, используемый другим приложением).
      1. Выбранный Dev Key будет назначен этому приложению в состоянии *Pending*
      2. Ваш текущий Dev Key останется активным, пока вы не активируете новый
      3. **Требуется активация** после того, как обновленная версия приложения станет доступна пользователям
   2. **Сгенерировать новый Dev Key** — создайте совершенно новый уникальный Dev Key для этого приложения.

      1. Новый Dev Key будет создан в состоянии *Pending*
      2. Ваш текущий Dev Key останется активным до активации
      3. **Требуется активация** после того, как обновленная версия приложения станет доступна пользователям

      > 🚧 **Двоеточие (:)**
      >
      > Независимо от выбранного варианта, изменение Dev Key вступит в силу только после того, как вы вручную активируете Dev Key.

5. Нажмите Далее.
6. Скопируйте и отправьте Dev key своему разработчику, чтобы он мог внедрить ваши изменения в SDK и загрузить новую версию вашего приложения в магазин.
7. Dev Key перейдет в состояние ожидания.
8. Нажмите Activate Dev Key.
9. Dev Key перейдет из состояния ожидания в активное.

> 📘 **Примечание**
>
> * Пока пользователи не обновят приложение до последней версии, события в приложении и сессии из более ранних версий не будут регистрироваться. Однако установки (атрибуция) по-прежнему будут обрабатываться корректно.
> * Если вы используете S2S API (API2), изменения Dev Key могут прервать передачу событий «сервер — сервер».
> * После активации Dev Key может пройти до 30 минут, прежде чем данные начнут поступать в систему.

### Как задать уникальный Dev Key для будущих приложений (скоро — 2 квартал 2026 года)

1. В AppsFlyer на правой верхней боковой панели кликните **Настройки учетной записи.**
2. Кликните вкладку **Учетная запись**.
3. В разделе **Безопасность** включите параметр Создать уникальный Dev key для приложения (для использования в будущем).
4. Примечание: при включении уникальных Dev Key для будущих приложений существующие приложения не будут затронуты.
