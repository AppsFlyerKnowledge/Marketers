> **Краткий обзор:** Определите и защищайте вашу учетную запись AppsFlyer от несанкционированного доступа с помощью журнала аудита. Просматривайте и загружайте сводку активности, связанной с безопасностью, в вашей учетной записи.

## Обзор

**Журнал аудита** предоставляет централизованную возможность для просмотра различной активности в вашей учетной записи, такой как входы в систему, доступ к данным, вызовы API, изменения конфигурации и разрешений для интегрированных Партнеров, правила проверки, аудитории и другие важные события. Это играет ключевую роль в обеспечении прозрачности, безопасности и соблюдения правовых норм. Для защиты безопасности вашей учетной записи AppsFlyer рекомендуется периодически проверять, **кто** имеет доступ к вашей учетной записи и **как** он осуществляется. Данные журнала аудита доступны за последние 90 дней.

**Доступ к журналу аудита:**

1. На верхней панели откройте меню учетной записи (выпадающий список адресов электронной почты): **Центр безопасности.**
2. В разделе **Журнал аудита** нажмите **Просмотр журнала аудита.**

## Устранение неполадок

<div id="why-does-an-advertiser-audit-log-show-partner-api-call-requests" />

<Accordion title="Почему в журнале аудита рекламодателя отображаются запросы на вызов API партнера?">

Когда партнер делает запрос API к Приложению, принадлежащему рекламодателю, и партнер, и рекламодатель видят этот запрос в своих журналах аудита.

Когда рекламодатель делает запрос API, используя свой собственный токен, он будет виден только в журнале аудита рекламодателя.

</Accordion>
