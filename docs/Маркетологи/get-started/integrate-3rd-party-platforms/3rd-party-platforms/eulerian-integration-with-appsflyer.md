> **Кратко:** Eulerian — интегрированный партнер AppsFlyer, специализирующийся на анализе и оптимизации операций e-маркетинга в режиме реального времени. Благодаря комплексной системе сбора данных маркетинговый пакет Eulerian предоставляет сочетание решений для веб-атрибуции и управления данными. Эта технология позволяет пользователям централизовать, анализировать, управлять и активировать данные в режиме реального времени.

<div id="important" />

> 🚧 **Важно!**
>
> <Anchor target="_blank" href="/marketers/ru/docs/about-raw-data-identifier-restrictions#ограничения-медиа-источников">Некоторые медиа-источники</Anchor> ограничивают передачу данных третьим лицам. Поэтому постбэки для ограниченных событий не будут отправляться этому партнёру, независимо от настроек отправки постбэков.

<div id="setting-up-eulerian" />

## Настройка Eulerian

**Необходимые условия.** Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом посещении** здесь вам нужно перевести кнопку ***Активировать партнера*** в положение «Вкл.», чтобы включить настройку параметров вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
    Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано ниже.

Окно конфигурации Eulerian включает 4 вкладки: **Интеграция, Ссылка атрибуции, Обогащение данных** и **Разрешения**. Кликните по пунктам ниже, чтобы прочитать о настройке вкладки.

Подробное описание заголовка окна настройки параметров партнера см. <Anchor target="_blank" href="/marketers/ru/docs/user-level-data-retention">здесь</Anchor>.

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

<div id="activate-partner" />

### Активация партнера

При **первом посещении** этого раздела необходимо включить переключатель ***Активировать партнера***, чтобы настроить параметры на вкладке интеграции. Переключатель должен оставаться во включенном положении все время, которое вы работаете с Medialyzer.Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации партнеров</Anchor>.

<div id="general-settings" />

### Общие настройки

**HostID**

Eulerian подключается к AppsFlyer с помощью уникального идентификатора Host ID. Если у вас его еще нет, вы должны получить его в Eulerian, чтобы продолжить интеграцию.

<Image align="center" alt="Eulerian_msc_new_2.png" src="https://files.readme.io/345b05c3960015bfe1b44dd2a298c4216185c2315fb859378e9e337ba2bf913a-360002665949.png" />

При необходимости выполните следующие действия:

* Введите **HostID**
* Включите параметр **Enable**, чтобы отправлять все установки в Eulerian

<div id="default-postbacks" />

### Постбэки по умолчанию

AppsFlyer может отправлять в Eulerian автоматические постбэки после установки пользователем. В этом разделе можно определить отправку этих постбэков.

<Image align="center" alt="Eulerian_new_2.png" src="https://files.readme.io/59cb41cdbec6c06dd4fc2086d238fe2015e5414a474591b23f9a18f8421fb030-360002795789.png" />

Чтобы отправлять постбэки в Eulerian, выберите **События, атрибутированные любому партнеру**.

<div id="in-app-event-settings" />

### Настройки внутренних событий приложения

В этом разделе можно сопоставить ваши события AppsFlyer с Eulerian с помощью постбэков.

<Image align="center" alt="Eulerian_new_3.png" src="https://files.readme.io/c190a6b05c977c8d5fa2a0e5301cdb5be239e56455b066cba93b8c1ffa6fcd9a-360002795829.png" />

1. Введите HostID еще раз.
2. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, заданные на стороне Eulerian.  <br />Получите соответствующий идентификатор ID события в Eulerian и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — AppsFlyer отправляет партнеру все параметры насыщенного события в приложении, за исключением параметра дохода, который содержится в параметре **af\_revenue**.  <br />**Флажок установлен** — AppsFlyer отправляет все параметры, включая значение дохода (если оно есть в событии). |

6. Нажмите **Сохранить**.

После сохранения AppsFlyer начинает отправлять данные в Eulerian для каждой органической и неорганической установки.
