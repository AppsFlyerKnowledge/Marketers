> **Кратко:** Winclap Analytics, интегрированный партнер AppsFlyer, использует данные атрибуции AppsFlyer для бизнес-аналитики и постатрибутивной аналитики.

<div id="important" />

> 🚧 **Важно!**
>
> <Anchor target="_blank" href="/marketers/ru/docs/about-raw-data-identifier-restrictions#ограничения-медиа-источников">Некоторые медиа-источники</Anchor> ограничивают передачу данных третьим лицам. Поэтому постбэки для ограниченных событий не будут отправляться этому партнёру, независимо от настроек отправки постбэков.

<div id="setting-up-winclap" />

## Настройка Winclap

Настройка выполняется со страницы **Активные интеграции**, но, чтобы найти партнера, сначала нужно перейти в <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations">маркетплейс</Anchor>.

<div id="note" />

> 📘 **Примечание:**
>
> Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.
>
> **Чтобы активировать интеграцию:**
>
> 1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите **Сотрудничество**> **Маркетплейс партнёров.Чтобы изменить**: В AppsFlyer в боковом меню выберите **Сотрудничество**> **Активные интеграции**.
> 2. Выберите соответствующее приложение.
> 3. На вкладке **Интеграция** выберите приложение для интеграции и нажмите **Активировать партнера**.
> 4. При **первом посещении** здесь нужно включить переключатель ***Активировать партнера***, чтобы настроить параметры интеграции. Этот переключатель **обязательно** должен быть включен все время, пока вы работаете с партнером.
>     Дополнительная информация по активации партнеров: нажмите <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
> 5. Завершите настройку, используя соответствующие вкладки, как описано ниже. Для подробного описания заголовка окна для конфигурации партнера, нажмите <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#about-the-integrated-partner-page">здесь</Anchor>.

При настройке Winclap Analytics используется только вкладка ***Интеграция***.

<div id="integration-tab" />

<Accordion title="Вкладка «Интеграция»">

На вкладке «Интеграция» есть несколько разделов, которые описаны ниже.

<div id="activate-partner" />

### Активация партнера

При **первом посещении** необходимо включить переключатель ***Активировать партнера***, чтобы настроить параметры вкладки интеграции. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
Этот переключатель должен быть <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активирован</Anchor> все время, пока вы работаете с этим партнером.Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/user-level-data-retention">здесь</Anchor>.

<div id="default-postbacks" />

### Постбэки по умолчанию

AppsFlyer может автоматически отправлять постбэки в Winclap Analytics для установок и повторного вовлечения пользователей. Используйте этот раздел, чтобы определить **источник пользователей** для которых можно отправлять эти постбэки.

![интеграция winclap analytics — постбэки по умолчанию](https://files.readme.io/a45d8d7ab4687876d8dea4b026580d80f4b34c151b00c3c47a701771d16582aa-50896714399761.png)

Для **установок** выберите:

* (По умолчанию) ***Только этот партнер*** для событий, поступающих только от пользователей, атрибутированных Winclap.
* ***Все медиаисточники, включая органические*** для отправки постбэков по любому пользователю, который загружает приложение, в Winclap.

Для **повторного вовлечения** постбэки можно отправлять для ***только этого партнера***.

После сохранения этой конфигурации AppsFlyer отправляет в Winclap Analytics следующие данные для каждой установки, как органической, так и неорганической:

* Идентификатор клика
* Доступно только в <Anchor target="_blank" href="/marketers/ru/docs/about-data-locker-advanced-reports">расширенных отчётах</Anchor>.
* Агент пользователя
* Время клика
* IP
* Страна
* Версия операционной системы на устройстве на момент конверсии.
* Субпаблишер
* Идентификатор устройства для Android & iOS
* UA: время касания, которому была приписана атрибуция.
* API доходов от рекламы
* Время события
* Характеристика
* ID приложения
* Показатель дохода клиента

### In-App Events Settings (Настройки внутренних событий приложения)

В этом разделе можно сопоставить события в приложении, которые нужно отправлять в Winclap Analytics с помощью постбэков:

[![winclap analytics — настройка постбэков для событий в приложении](https://files.readme.io/f14f801a50b3c699f71141a387a9d75586bae7b91aad88f29f97778408ee12fb-50896714404369.png)](https://files.readme.io/f14f801a50b3c699f71141a387a9d75586bae7b91aad88f29f97778408ee12fb-50896714404369.png)

1. Включите переключатель ***Постбэки для событий в приложении*** в положение ON.
2. При необходимости задайте ***окно постбэков по событиям в приложении*** (подробнее о <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#окно-постбэков-по-внутренним-событиям">настройке окна постбэков по событиям в приложении</Anchor>).
3. Чтобы добавить в список событие SDK, нажмите ***Добавить событие***.
4. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверного события.  <br />**Совет**: Не видите нужное событие? Введите название события SDK, нажмите **Создать пользовательское** и выполните сопоставление обычным способом. Подробнее о <Anchor target="_blank" href="/marketers/ru/docs/in-app-event-postback-configuration#пользовательские-события">сопоставлении пользовательских событий</Anchor> читайте здесь. |
| **Идентификатор события партнера** | Уникальное название или идентификатор ID каждого события, определенные Winclap.  <br />Получите в Winclap соответствующий ID для каждого из событий, о которых вы хотите им сообщать, и введите его в это поле. |
| **Sending option (Вариант отправки)** | Выберите вариант отправки события:  <br />**Только для этого партнера** для событий, поступающих **только** от пользователей, атрибутированных этому партнеру  <br />**Все медиаисточники, включая органические** чтобы вся ваша база пользователей была доступна для передачи в отчет партнеру |
| **Отправить данные о событии** | <ul><li>**Нет значений и нет дохода:** отправляет только само событие без значения.</li><li>**Значения, нет дохода:** отправляет все параметры, кроме значения дохода.</li><li>**Значения и доход**: отправляет все параметры события, включая значение дохода (если оно есть в событии).</li></ul> |

5. Нажмите кнопку ***Сохранить***.

После сохранения этой конфигурации AppsFlyer отправляет следующие данные в Winclap Analytics для каждого неорганического события:

* Идентификатор ID клика
* Имя события
* Время события
* Событий в приложении
* Событий в приложении
* Доход от события в долларах США
* Доступно только в <Anchor target="_blank" href="/marketers/ru/docs/about-data-locker-advanced-reports">расширенных отчётах</Anchor>.
* Агент пользователя
* Время клика
* IP
* Страна
* Версия операционной системы на устройстве на момент конверсии.
* Субпаблишер
* Идентификатор устройства для Android & iOS
* UA: время касания, которому была приписана атрибуция.
* API доходов от рекламы
* Время события
* Характеристика
* ID приложения
* Показатель дохода клиента
