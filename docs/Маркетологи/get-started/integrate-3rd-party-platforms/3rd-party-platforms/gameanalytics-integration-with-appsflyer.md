> **Кратко:** Game Analytics — мощный бесплатный инструмент и интегрированный партнер AppsFlyer, который помогает разработчикам понимать поведение игроков, чтобы повышать вовлеченность, снижать отток и совершенствовать монетизацию. Он помогает визуализировать ключевые KPI гейминга в одном удобном представлении и предлагает внутриигровой бенчмаркинг, чтобы сравнить ваши метрики с показателями более чем 14 000 аналогичных игр.

Настройка займет всего несколько минут, и это совершенно бесплатно — без ограничений на использование и скрытых премиум-функций! Если вы хотите увидеть платформу в действии до её интеграции со своей игрой, просто зарегистрируйтесь, чтобы ознакомиться с демо-игрой с уже загруженными данными.

Этой платформе доверяют более 40,000 разработчиков игр по всему миру — от независимых разработчиков до всемирно известных студий — и каждый день она обрабатывает более пяти миллиардов уникальных событий на более чем 2+ миллиардах устройств. GameAnalytics широко интегрируется и предлагает SDK для всех основных игровых движков и платформ. Вы можете бесплатно зарегистрироваться уже сегодня на сайте https://gameanalytics.com/

<div id="important" />

> 🚧 **Важно!**
>
> <Anchor target="_blank" href="/marketers/ru/docs/about-raw-data-identifier-restrictions#ограничения-медиа-источников">Некоторые медиа-источники</Anchor> ограничивают передачу данных третьим лицам. Поэтому постбэки для ограниченных событий не будут отправляться этому партнёру, независимо от настроек отправки постбэков.

## Настройка GameAnalytics

**Необходимые условия:** Перед настройкой интеграции обязательно [свяжитесь с партнёром](#) и откройте у него аккаунт. Перед настройкой интеграции необходимо <Anchor target="_blank" href="/marketers/ru/docs/partner-integrations#contact-details">связаться с партнером</Anchor> и открыть у него аккаунт.

**Чтобы активировать интеграцию:**

1. **Чтобы активировать:** В AppsFlyer в боковом меню выберите**Сотрудничество** > **Маркетплейс партнеров**.  
   **Чтобы изменить**: В боковом меню AppsFlyer выберите **Сотрудничество** > **Активные интеграции**.
2. Выберите соответствующее приложение.
3. Нажмите **Настроить интеграцию**.
4. При **первом заходе** сюда вам нужно перевести кнопку ***Активация партнера*** в положение «Включено», чтобы настройка параметров вкладки интеграции стала возможной. Этот переключатель должен быть активирован все время, пока вы работаете с этим партнером.  
    Дополнительная информация по активации партнеров доступна <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">здесь</Anchor>.
5. Завершите настройку, используя соответствующие вкладки, как описано в следующем разделе:

В окне настройки Game Analytics используется только вкладка ***Интеграция***.

### Активация партнера

При **первом заходе** сюда включите **Активацию партнера**, чтобы настройка параметров на вкладке интеграции стала возможной. Переключатель должен оставаться во включенном положении все время, которое вы работаете с Medialyzer.Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/partner-activation-deactivation">активации партнеров</Anchor>.

### Общие настройки

**Ключ игры**

Game Analytics связывается с AppsFlyer с помощью уникального ключа игры. Если у вас его еще нет, вы должны получить его в Game Analytics, чтобы продолжить интеграцию.

### Постбэки по умолчанию

AppsFlyer может автоматически отправлять в Game Analytics постбэки по пользовательским установкам. В этом разделе можно определить отправку этих постбэков.

<Image align="center" alt="Swrve_msc_new_4.png" src="https://files.readme.io/0144ced7a8f0e6eec2a4847971c1d058efde9bdb0efbef961c6451a4c7e81ccf-18274450980753.png" />

Выберите **События, атрибутированные любому партнеру или органические**, чтобы отправлять постбэки в Game Analytics для любого пользователя, который загружает приложение, или выберите **Выкл.**

<div id="in-app-event-settings" />

### Настройки внутренних событий приложения

<Image align="center" alt="" src="https://files.readme.io/64dd102e95aacda70cb8c0cde471c5c31d6b744543089a2d00a1ab1640fbb1c3-360002219789.png" />

В этом разделе можно настроить сопоставление событий AppsFlyer с Game Analytics через постбэки.

1. Снова введите ключ игры.
2. Установите переключатель "Постбэки внутренних событий приложения" в положение "Включено"
3. В поле «Вариант отправки» выберите значение, которое будет использоваться для всех событий, определенных в SDK.  
   **- Только события, атрибутированные этому партнеру**: партнер будет получать сведения о событиях **только** тех пользователей, которые ему атрибутированы.  
    **- События, атрибутированные любому партнеру или органические**: партнер будет получать сведения о событиях всех пользователей, которые есть в вашей базе.
4. Чтобы добавить в список событие, определенное в SDK, нажмите **Добавить событие**.
5. Введите следующие параметры:

| Имя параметра | Description(Описание) |
| --- | --- |
| **Имя события в SDK** | Имя события, полученное AppsFlyer из SDK, интегрированного в приложение, или из межсерверных событий.  <br />**Совет**. Если в списке нет нужного вам события, убедитесь, что оно активировано на устройстве с неорганической установкой, и повторите поиск. |
| **Идентификатор события партнера** | Уникальное имя или идентификатор ID каждого события, определенные на стороне Game Analytics.  <br />Получите соответствующий идентификатор ID события в Game Analytics и введите его в текстовое поле. |
| **Отправка данных о доходе** | **Флажок не установлен** — AppsFlyer отправляет партнеру все параметры насыщенного события в приложении, за исключением параметра дохода, который содержится в параметре **af\_revenue**.  <br />**Флажок установлен** — AppsFlyer отправляет все параметры, включая значение дохода (если оно есть в событии). |

Нажмите **Save** (Сохранить).

После сохранения этой конфигурации AppsFlyer начинает отправлять следующие данные в Game Analytics для каждой неорганической установки:

* game\_key
* Источник медиа
* Доступно только в <Anchor target="_blank" href="/marketers/ru/docs/about-data-locker-advanced-reports">расширенных отчётах</Anchor>.
