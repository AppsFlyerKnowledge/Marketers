## Что такое MCP от AppsFlyer?

MCP от AppsFlyer позволяет безопасно подключать LLM к платформе AppsFlyer, чтобы вы могли взаимодействовать со своими маркетинговыми данными, используя ИИ-чат бот. MCP от AppsFlyer поможет вам принимать более разумные и быстрые решения на основе данных в режиме реального времени.

С помощью MCP вы сможете:

* Получать актуальную информацию о результатах кампании, трендах и KPI мгновенно.
* Сравнивать такие показатели, как ROAS, установки и LTV.
* Создавайте ссылки OneLink, а также проверяйте и анализируйте шаблоны и ссылки OneLink и устраняйте неполадки.
* Проверяйте подключения аудиторий и устраняйте неполадки.
* Получить руководство по настройке и документацию по продукту.

## Настройка MCP от AppsFlyer

AppsFlyer MCP может подключаться к чат-ассистентам, CLI, IDE, платформам автоматизации и самостоятельно размещаемым агентам. Настройка зависит от используемого вами клиента и поддерживаемого им метода аутентификации.

<div id="authentication-methods" />

## Метод аутентификации:

AppsFlyer MCP поддерживает два метода аутентификации. Используйте метод, который соответствует тому, как вы планируете подключаться к AppsFlyer MCP.

| Метод аутентификации: | Используется для | Лучше всего для | Длительность доступа |
| --- | --- | --- | --- |
| Вход через браузер по протоколу OAuth | Gemini CLI, Copilot CLI, ChatGPT, Claude.ai и Claude Desktop | Оперативные вопросы, исследовательский анализ и разовые отчеты | Действительно в течение 7 дней с момента подключения. Повторная аутентификация требуется по окончании сессии |
| Аутентификация с помощью токена носителя | Claude Code, платформы автоматизации, локально размещённые агенты и интеграции | Автоматизация, запланированные задачи, фоновые агенты и неинтерактивные рабочие процессы | Действительно до ручной отмены |

<div id="browser-based-oauth-login" />

### Вход через браузер по протоколу OAuth

Вход через OAuth в браузере позволяет интерактивно подключаться через браузер. Браузерная авторизация через OAuth позволяет подключаться интерактивно прямо в браузере Когда вы подключаетесь, клиент MCP открывает окно браузера и просит вас авторизоваться в AppsFlyer. После того как вы одобрите доступ, клиент подключится к вашей учетной записи AppsFlyer.

Используйте этот метод для интерактивных сессий, исследовательского анализа и разовых отчетов.

<div id="bearer-token-authentication" />

### Аутентификация с помощью токена носителя

Аутентификация на основе токена носителя позволяет неинтерактивным инструментам подключаться к AppsFlyer MCP, используя токен AppsFlyer MCP. Токен передается в заголовке запроса:

```http
Авторизация: Bearer <YOUR_MCP_TOKEN>
```

Используйте этот метод для автоматизации, запланированных задач, фоновых агентов и интеграций, которые не могут использовать вход через браузер.

Чтобы создать токен, перейдите в **Меню учетной записи > Центр безопасности > Токены AppsFlyer** и создайте токен MCP.

<Accordion title="Claude.ai и Claude Desktop">

Используйте Claude.ai и Claude Desktop с входом через браузер по протоколу OAuth. Эти инструкции применимы к Claude в веб-версии и на десктопе.

<div id="note-1" />

> 📘 **Примечание**
>
> Для пользователей тарифных планов Team и Enterprise только владельцы или администраторы могут добавлять интеграции на уровне всей организации.

<div id="set-up-claude-chat-and-cowork" />

#### Настройка Claude.ai и Claude Desktop

1. Нажмите на свое имя в левом нижнем углу и выберите **Настройки**. Альтернативно, в новом чате нажмите **Поиск и инструменты** > **Управление коннекторами**.
2. Откройте вкладку <Anchor target="_blank" href="https://claude.ai/settings/integrations">Коннекторы</Anchor> .
3. Переключитесь на вкладку **Коннекторы организации**.
4. В разделе Коннекторы кликните **Добавить коннектор**.
5. Введите следующие данные коннектора:
   * **Название коннектора**: AppsFlyer
   * **URL коннектора:** `https://mcp.appsflyer.com/auth/mcp`
6. Нажмите **Добавить**.
7. Переключитесь на вкладку **Ваши коннекторы** .
8. В разделе «Коннекторы» нажмите **Подключить** рядом с соединением AppsFlyer.
9. Войдите в AppsFlyer, когда появится соответствующее сообщение.

<div id="test-the-claude-connection" />

1. В любом окне чата кликните на кнопку настроек.

<Accordion title="Claude Code">

Используйте Claude Code с аутентификацией по токену носителя для автоматизации, планирования и неинтерактивных рабочих процессов.

<div id="add-appsflyer-mcp-to-claude-code" />

#### Добавьте AppsFlyer MCP в Claude Code

1. В AppsFlyer перейдите в **Меню учетной записи > Центр безопасности > Токены AppsFlyer**.
2. Создайте токен MCP.
3. В терминале добавьте сервер AppsFlyer MCP:

   ```bash
   claude mcp add-json appsflyer '{"type":"http","url":"https://mcp.appsflyer.com/auth/mcp","headers":{"Authorization":"Bearer YOUR_APPSFLYER_MCP_TOKEN"}}'
   ```
4. Запустите Claude Code:

   ```bash
   claude .
   ```
5. Проверьте, что MCP-сервер был добавлен:

   ```bash
   claude mcp list
   ```
6. Убедитесь, что `appsflyer` отображается в списке настроенных MCP-серверов.
7. Задайте вопрос по AppsFlyer. Например:

   ```text
   Какие приложения есть в моей учётной записи AppsFlyer?
   ```

   ```text
   «Какие медиа-источники были самыми популярными в США на прошлой неделе для "Mypets.android.com"?»
   ```

   ```text
   Создайте сводку по эффективности "Mypets.android.com" за последний день с разбивкой по кампаниям.
   ```

</Accordion>

<div id="h_cursor-ide" />

<Accordion title="Cursor IDE">

Используйте Cursor IDE для подключения AppsFlyer MCP из вашей локальной среды разработки.

1. Создайте или откройте файл конфигурациив зависимости от области применения:
   * **Для глобальной конфигурации:** `~/.cursor/mcp.json`
   * **Конфигурация для конкретного проекта:** `.cursor/mcp.json`
2. Добавьте следующую запись в`mcpServers` поле в вашем JSON-файле:

   ```json
   {
     "mcpServers": {
       "appsflyer": {
         "url": "https://mcp.appsflyer.com/auth/mcp"
       }
     }
   }
   ```
3. Перезапустите Cursor IDE, чтобы применить новую конфигурацию.
4. Пройдите аутентификацию по запросу для доступа к службам AppsFlyer MCP.

</Accordion>

<div id="h_vs-code" />

<Accordion title="VS Code">

1. Нажмите `Cmd+Shift+P` или `Ctrl+Shift+P`, чтобы открыть Палитру команд (Command Palette).
2. Выберите **Настроить MCP-серверы**.
3. В `.vscode/mcp.json` добавьте конфигурацию MCP-сервера AppsFlyer:

   ```json
   {
     "servers": {
       "appsflyer": {
         "url": "https://mcp.appsflyer.com/auth/mcp"
       }
     }
   }
   ```
4. Сохраните файл и перезапустите чат Copilot.

</Accordion>

<div id="add-appsflyer-mcp-in-chatgpt" />

#### Добавление AppsFlyer MCP в ChatGPT

<div id="note-3" />

> 📘 **Примечание**
>
> Для добавления и публикации коннектора в вашей организации может потребоваться настройка администратором.

1. Добавьте коннектор и опубликуйте его в вашей организации.
2. Введите следующие данные коннектора:
   * **Имя:** MCP от AppsFlyer
   * **URL-адрес:** `https://mcp.appsflyer.com/auth/mcp`
   * Аутентификация: OAuth
3. Чтобы подключиться в первый раз, перейдите в **Настройки > Приложения и источники > AppsFlyer MCP**.
4. Подключитесь к AppsFlyer MCP.
5. Выполните шаги для подключения и войдите в систему, используя свои учетные данные AppsFlyer.

После настройки откройте чат, выберите **Источники** или **Коннекторы** и включите подключение AppsFlyer.

В целях безопасности AppsFlyer MCP отключается примерно каждые 10 часов. Чтобы повторно подключиться, выполните процедуру подключения еще раз.

<div id="h_gemini-cli" />

<Accordion title="Gemini CLI">

Используйте Gemini CLI с входом через OAuth в браузере.

<div id="add-appsflyer-mcp-to-gemini-cli" />

#### Добавление AppsFlyer MCP в Gemini CLI

1. В терминале добавьте сервер AppsFlyer MCP:

   ```bash
   gemini mcp add appsflyer https://mcp.appsflyer.com/auth/mcp -t http
   ```
2. Запустите Gemini CLI:

   ```bash
   gemini
   ```
3. В командной строке Gemini CLI введите:

   ```text
   auth
   ```
4. Завершить процедуру аутентификации в браузере, а затем вернуться в терминал.
5. Задайте вопрос по AppsFlyer. Например:

   ```text
   Какие приложения есть в моей учётной записи AppsFlyer?
   ```

<div id="troubleshoot-gemini-cli-authentication" />

#### Устранение неполадок аутентификации Gemini CLI

Если аутентификация не удалась, запустите Gemini CLI в режиме отладки:

```bash
GEMINI_LOG_LEVEL=debug gemini
```

Затем снова введите `auth` в командной строке Gemini CLI.

</Accordion>

<div id="h_copilot-cli" />

<Accordion title="Copilot CLI">

Используйте Copilot CLI с входом через браузер по протоколу OAuth.

<div id="add-appsflyer-mcp-to-copilot-cli" />

#### Добавьте AppsFlyer MCP в Copilot CLI

1. Откройте терминал.
2. Запустите Copilot CLI:

   ```bash
   copilot
   ```
3. Если вы не вошли в систему, введите следующую команду в промпте Copilot CLI:

   ```text
   /вход в систему
   ```
4. Завершить вход через браузер.
5. В промпте Copilot CLI введите:

   ```text
   /mcp add
   ```
6. Ввести следующие данные сервера MCP:

| Поле | Значение |
| --- | --- |
| Название сервера | `appsflyer` |
| Тип сервера | `HTTP` |
| URL | `https://mcp.appsflyer.com/auth/mcp` |
| Иинструменты | `*` |

7. Нажмите **Ctrl+S**, чтобы сохранить конфигурацию.
8. При появлении запроса выполните процедуру аутентификации AppsFlyer в браузере.
9. Вернитесь в терминал.
10. Задайте вопрос по AppsFlyer. Например:

    ```text
    Какие приложения есть в моей учётной записи AppsFlyer?
    ```

</Accordion>

<Accordion title="Платформы сторонних поставщиков и собственные хостинги">

Используйте ваш MCP токен, чтобы аутентифицировать системы третьих сторон или собственные хостинги с AppsFlyer MCP. Это позволяет автоматизировать процессы и подключать ИИ-интеграции с такими платформами как n8n, Make или вашими собственными агентами на базе LLM.

Токен MCP — это токен носителя уровня учётной записи, который наследует права администратора, создавшего его. Вы можете получить доступ к нему и управлять им в <Anchor target="_blank" href="/marketers/ru/docs/managing-appsflyer-tokens">Центр безопасности > Токены AppsFlyer</Anchor>.

<div id="mcp-connection-details" />

#### Детали подключения MCP

Чтобы подключить вашу автоматизацию или платформу агентов к AppsFlyer MCP, используйте следующую конфигурацию:

* **Тип аутентификации:** Токен предъявителя
* **Базовый URL / Конечная точка:** `https://mcp.appsflyer.com/auth/mcp`
* **Токен носителя:** Ваш токен MCP

<div id="note-4" />

> 📘 **Примечание**
>
> Никогда не делитесь им и не публикуйте свой токен публично. Относитесь к нему как к конфиденциальным учетным данным. Ваш токен MCP предоставляет прямой доступ к вашей среде MCP.

<div id="switch-between-accounts-browser-based-oauth" />

#### Переключение между аккаунтами (OAuth в браузере)

Если вы управляете несколькими аккаунтами AppsFlyer с одного адреса электронной почты, вы можете переключаться между аккаунтами, к которым подключается MCP:

1. В AppsFlyer установите аккаунт, к которому хотите подключиться, в качестве основного.
2. Войдите в систему снова в своем клиенте MCP.

Вы не можете просматривать или запрашивать несколько аккаунтов одновременно в рамках одного подключения.

<div id="connect-multiple-accounts-simultaneously-bearer-token" />

#### Одновременное подключение нескольких аккаунтов (токен носителя)

Чтобы подключиться к нескольким аккаунтам одновременно, например для работы агентства, используйте многоагентный поток вместо OAuth в браузере:

1. Для каждого аккаунта создайте токен MCP в разделе **Меню аккаунта > Центр безопасности > Токены AppsFlyer**.
2. На своей агентской платформе подключайте каждый аккаунт отдельно, используя его собственный токен носителя.

Пример этого процесса можно увидеть в <Anchor target="_blank" href="https://www.youtube.com/watch?v=o5oK-yWuE5E">этом видео</Anchor>.

**Промпт**: “Покажи проблемы в моих активных интеграциях затрат.”

**Ожидаемый ответ ИИ:** ИИ показывает активные интеграции затрат, у которых за последние 7 дней возникали проблемы, упорядоченные по рекламным сетям и подключённым приложениям.

## Дополнительная информация

<div id="h_privacy-and-security" />

<Accordion title="Конфиденциальность и безопасность">

AppsFlyer MCP позволяет выбранному вами инструменту ИИ запрашивать данные AppsFlyer на основе ваших существующих прав доступа.

<div id="data-processing" />

#### Обработка данных:

AppsFlyer MCP действует как безопасный прокси-сервер. Он получает данные AppsFlyer в режиме реального времени и предоставляет информацию, необходимую для ответа на запрос. AppsFlyer MCP не архивирует и не хранит результаты запросов в течение длительного времени.

<div id="credentials" />

#### Учётные данные

Ваши учетные данные AppsFlyer позволяют AppsFlyer MCP выполнять вызовы API от вашего имени. Ваши учетные данные AppsFlyer не передаются инструменту ИИ.

<div id="permissions" />

#### Разрешения

AppsFlyer MCP использует ваши существующие права доступа в AppsFlyer. Пользователи могут получить доступ только к тем приложениям и данным, которые им уже разрешено просматривать в AppsFlyer.

Для доступа через MCP не требуется настраивать отдельный уровень разрешений.

<div id="read-and-write-access" />

#### Доступ на чтение и запись

Большинство инструментов AppsFlyer MCP работают только в режиме чтения и выполнения запросов. Исключение — create\_onelink\_link, который создает ссылки OneLink в вашей учетной записи. Перед созданием ссылки ИИ показывает ее данные и запрашивает подтверждение. Без вашего подтверждения ничего не создается.

<div id="ai-provider-data-usage" />

#### Использование данных провайдера ИИ

Данные, полученные AppsFlyer MCP, могут быть переданы выбранному вами инструменту ИИ для ответа на ваш запрос. Передаются только данные, необходимые для формирования ответа.

AppsFlyer не контролирует, хранит ли выбранный вами инструмент ИИ данные, обрабатывает ли их или обучается на них. Ознакомьтесь с условиями и политиками использования данных вашего провайдера ИИ перед подключением AppsFlyer MCP.

<div id="certifications" />

#### Сертификаты

AppsFlyer имеет сертификаты ISO 27001 и SOC 2. Сертификация по стандарту ISO 42001 находится в процессе получения.

</Accordion>

## Устранение неполадок подключения

Если подключение AppsFlyer MCP не работает, выполните действия для вашего метода аутентификации.

<div id="h_troubleshoot-browser-based-oauth-login" />

<Accordion title="Вход через браузер по протоколу OAuth">

Используйте этот раздел для клиентов, которые подключаются через вход в браузере, например Gemini CLI, Copilot CLI, ChatGPT, Claude.ai и Claude Desktop.

1. **Повторно пройдите аутентификацию сессии.** Сессии OAuth истекают примерно каждые 7 дней. Запустите процесс подключения заново и выполните вход в браузере еще раз.
2. **Завершите процесс аутентификации.** Убедитесь, что вход в браузере завершен успешно. При появлении запроса нажмите **Разрешить** или **Одобрить**, а затем вернитесь к своему клиенту MCP.
3. **Перезапустите сессию.** Перезапустите свой CLI, чат или сессия приложения. Затем повторно подключитесь к серверу MCP.
4. **Проверьте конфигурацию сервера MCP.** Подтвердите следующие значения:

| Поле | Значение |
| --- | --- |
| Тип сервера | `HTTP` |
| URL | `https://mcp.appsflyer.com/auth/mcp` |

5. **Проверьте права доступа пользователя.** Убедитесь, что ваш пользователь AppsFlyer имеет доступ к соответствующим приложениям и запрашиваемым данным.

</Accordion>

<div id="h_troubleshoot-bearer-token-authentication" />

<Accordion title="Аутентификация с помощью токена носителя">

Используйте этот раздел для Claude Code, n8n, Make, автономных агентов и других инструментов автоматизации.

1. **Проверьте, не был ли отозван токен.** Токены могут быть отозваны вручную. Токены, созданные до **10 марта 2026 г., 19:00 UTC**, могут больше не работать.
2. **Создайте новый токен MCP.** Чтобы восстановить доступ:
   1. Войдите в AppsFlyer.
   2. Перейдите в **Меню учетной записи > Центр безопасности > Управление токенами**.
   3. Найдите отозванные токены.
   4. Удалите отозванный токен.
   5. Создайте новый токен MCP.
   6. Обновите свой клиент MCP или автоматизацию с помощью нового токена.
3. **Проверьте заголовок Авторизация.** Убедитесь, что заголовок использует именно этот формат:

   ```http
   Authorization: Bearer <YOUR_MCP_TOKEN>
   ```
4. **Проверьте конфигурацию сервера MCP.** Подтвердите следующие значения:

| Поле | Значение |
| --- | --- |
| URL | `https://mcp.appsflyer.com/auth/mcp` |
| Транспорт | `HTTP` |
| header | `Authorization: Bearer <YOUR_MCP_TOKEN>` |

5. **Проверьте, зарегистрирован ли сервер.** Для Claude Code выполните:

   ```bash
   claude mcp list
   ```
6. **При необходимости добавьте MCP-сервер снова.**

   ```bash
   claude mcp remove appsflyer
   claude mcp add-json appsflyer '{"type":"http","url":"https://mcp.appsflyer.com/auth/mcp","headers":{"Authorization":"Bearer YOUR_APPSFLYER_MCP_TOKEN"}}'
   ```
7. **Проверьте разрешения токена.** Токен MCP наследует разрешения от администратора, который его создал. Убедитесь, что токен имеет доступ к соответствующим приложениям и запрашиваемым данным.

</Accordion>

<div id="h_access-and-permission-issues" />

<Accordion title="Проблемы с доступом и разрешениями">

Если аутентификация проходит успешно, но доступ по-прежнему не предоставляется:

* Доступ к MCP может быть ограничен вашим администратором AppsFlyer.
* Если у вас нет доступа к настройкам Учетная запись & Профиль, доступ к MCP может быть заблокирован.
* Свяжитесь с администратором AppsFlyer, чтобы получить доступ.
* Убедитесь, что у вашего пользователя или токена есть доступ к соответствующим приложениям и запрашиваемым данным.
