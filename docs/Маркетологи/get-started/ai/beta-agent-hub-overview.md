<span class="af-tag af-tag--beta-feature">Beta feature</span>

> **At a glance:** Agent Hub — централизованная платформа AppsFlyer для управления агентами на базе ИИ, которые проактивно предоставляют практические маркетинговые инсайты прямо в ваш рабочий процесс. Эти агенты постоянно анализируют ваши данные, чтобы предоставлять ценные результаты и рекомендовать действенные шаги, все это в рамках совместной работы вашей команды.

## Об Agent Hub

Каждый агент выполняет маркетинговую задачу от начала до конца: он обрабатывает ваши данные, формирует выводы и передает их туда, где работает ваша команда. Agent Hub дает вам доступ к набору агентов, созданных AppsFlyer, которые помогают оптимизировать маркетинговую активность и находить возможности для роста, а также к пользовательскому агенту, который выполняет задачу, заданную вами. Каждый агент действует добросовестно, поддерживая принятие решений вашей командой.

## Страница Agent Hub

Страница Agent Hub состоит из двух вкладок: **Мои агенты** и **Активность**. Используйте эти вкладки, чтобы управлять агентами и просматривать завершённые запуски агентов.

Используйте **раздел «Мои агенты»** для настройки, развертывания и управления агентами. Используйте **раздел «Активность»,** чтобы видеть готовые результаты, просматривать предыдущие запуски, оставлять отзывы и анализировать логику запусков с помощью ИИ-помощника.

<Accordion title="Мои агенты">

На вкладке **«Мои агенты**» отображаются агенты, доступные для вашей учетной записи.

На этой вкладке можно:

* Посмотреть доступных агентов.
* Настроить и запустить агентов.
* Управлять запущенными агентами.
* Отслеживать актуальный статус запуска прямо в карточке агента.

#### Предварительные требования и разрешения

Некоторые функции Agent Hub требуют дополнительной настройки в зависимости от используемых каналов уведомлений.

<div id="set-up-an-agent" />

#### Настроить агента

Агенты могут быть настроены и развернуты для работы по расписанию или вручную. Вы также можете настроить, куда будет отправляться результат работы агента, — например в Slack или на электронную почту.

Вы можете отслеживать статус последнего запуска непосредственно с карточки агента во вкладке **«Мои агенты»**. Чтобы просмотреть готовые результаты и историю запусков, перейдите на вкладку **«Активность**».

Выполните следующие шаги, чтобы настроить и развернуть агента.

1. Войдите в AppsFlyer.
2. В меню слева перейдите в **Agent Hub.**
3. В меню агента, который вы хотите настроить и развернуть, нажмите **Развернуть**.
4. На следующей странице настройте необходимые параметры агента.
5. Добавьте свой адрес электронной почты или подключите свое рабочее пространство Slack, если это необходимо.
   1. Убедитесь, что канал Slack настроен. [См. предварительные требования.](#предварительные-требования-и-разрешения)
6. Выберите расписание запуска (в настоящее время основано на UTC; дополнительные часовые пояса будут скоро добавлены).
7. Нажмите **Развернуть агента**.

Агент появится в разделе **My Agents**. Ниже, в разделах **Prebuilt agents** и **Custom Agent**, приведен полный список доступных агентов и описание функций каждого из них.

</Accordion>

<Accordion title="Таблица активности">

На вкладке **«Активность»** отображаются результаты завершенных запусков агента. Она активируется, когда в вашей учетной записи есть хотя бы один агент с выполненными задачами.

Используйте эту вкладку, чтобы просматривать недавнюю активность агента, видеть предыдущие результаты, оставлять обратную связь и задавать ИИ-помощнику вопросы о конкретном запуске.

Вкладка «Активность» состоит из двух разделов:

| Раздел | Описание |
| --- | --- |
| Последняя активность | Отображает последний завершённый запуск для каждого агента. |
| Предыдущие запуски | Отображаются завершенные запуски за последние 30 дней. |

Вы можете отфильтровать активность по:

* Приложение
* Агент

Примечание: Фильтр агентов основывается на конкретном экземпляре агента, а не на его типе.

<div id="view-activity-output" />

#### Просмотреть результаты активности

Чтобы просмотреть результаты активности:

1. Перейти в **Agent Hub**.
2. Кликните на вкладку **«Активность**».
3. Выберите соответствующие фильтры приложений или экземпляров агентов.
4. Кликните на запуск, чтобы развернуть его.

В развернутом запуске отображается тот же результат, что и в сообщении Slack или в электронном письме.

В развернутом окне запуска вы можете:

* Скопировать результат.
* Оставить положительный или отрицательный отзыв.
* Добавить письменный отзыв.
* Нажмите **«Проанализировать активность»,** чтобы задать ИИ-помощнику вопросы о запуске.

<div id="analyze-activity-with-ai-assistant" />

#### Анализ активности с помощью ИИ-помощника

Используйте **функцию «Анализ активности»,** чтобы задать ИИ-помощнику вопросы о конкретном завершенном запуске агента.

Функция **Анализ активности** доступна для всех агентов. ИИ-помощник открывается в контексте выбранного запуска. Это поможет вам понять, как агент пришел к своему результату, какие данные он использовал и какие факторы он учел или исключил.

Это не обычная беседа с агентом. ИИ-помощник отвечает только на вопросы, касающиеся выбранного запуска. Он не выполняет новую работу агента, не обращается к данным за пределами запуска и не делает прогнозов.

Чтобы задать ИИ-помощнику вопросы о запуске:

1. Перейти в **Agent Hub**.
2. Кликните на вкладку **«Активность**».
3. Нажмите на запуск, чтобы его развернуть.
4. Нажмите **«Проанализировать активность**».
5. Выберите один из предложенных вопросов или введите свой собственный.

Например, вы можете спросить:

* Поясни ход твоих рассуждений
* На каких данных это было основано?
* Почему этот вывод оказался в приоритете?
* Какие факторы учитывал агент?
* Какие факторы исключил агент?

<div id="supported-and-unsupported-questions" />

##### Поддерживаемые и не поддерживаемые вопросы

| Вы можете спросить о | Нельзя спрашивать о |
| --- | --- |
| Как агент получил этот результат | Данные, которые не были включены в запуск |
| Какие данные использовал агент при запуске | Новый анализ, который не вошел в данный запуск |
| Почему некоторые результаты были признаны приоритетными или отклонены | Прогнозы на будущее |
| Контекст и обоснование выбранного запуска | Общие рекомендации по оптимизации вне контекста выполнения запуска |

<div id="notes" />

#### Примечания

При использовании вкладки **«Активность»** и функции **«Анализ активности»** следует учитывать:

* Для данной учетной записи должен быть включен ИИ-помощник. Если ИИ-помощник отключен, **функция «Анализ активности»** недоступна. См. <Anchor target="_blank" href="/marketers/ru/docs/account-settings#agent-hub">Настройки учётной записи</Anchor>.
* В истории активности отображаются только завершенные запуски за последние 30 дней.
* При удалении агента также удаляется вся его предыдущая активность, включая результаты, выводы и данные о логике выполнения. Это действие нельзя отменить.
* ИИ-помощник отвечает только на вопросы, касающиеся выбранного запуска. Он не проводит новый анализ, не имеет доступа к данным за пределами текущего запуска и не делает прогнозов.

</Accordion>

## Типы агентов

В Agent Hub есть два типа агентов: пользовательский агент, который вы настраиваете сами для задачи, которую вы определяете, и готовые к использованию агенты, которые можно развернуть как есть.

<div id="h_01M3PDTFQDFQNMHTWKP23JV1A8" />

<Accordion title="[Закрытая бета-версия] Пользовательский агент">

В то время как готовые к использованию агенты в Agent Hub выполняют конкретные заранее заданные задачи, пользовательский агент выполняет задачу, которую вы настраиваете под свои конкретные требования. Опишите задачу простыми словами, выберите приложение, просмотрите план, который составит агент, и укажите, как и когда вы хотите получить результаты. Затем агент самостоятельно выполняет всю работу от начала до конца — по запросу или по расписанию — и отправляет вам результат.

Он анализирует данные, выполняет указанную задачу и выдает запрошенные результаты. Это может быть ранжированный список, еженедельная сводка по эффективности, анализ первопричин, рекомендация с подтверждающими данными или сложный специальный анализ. Выходные данные принимают ту форму, которая нужна задаче.

Вы ставите агенту задачу так же, как аналитику в своей команде, и он действует по тому же принципу: подтверждает, что правильно понял задачу, показывает, как планирует ее выполнить и что подразумевает под каждым термином, и приступает к работе только после вашего согласования.

<div id="create-a-custom-agent" />

#### Создать пользовательского агента

Три шага: определите агента, просмотрите план, затем настройте и разверните его.

<div id="step-1-define-the-agent" />

##### Шаг 1: Определите агента

1. В AppsFlyer перейдите в **Agent Hub** в меню слева.
2. На карточке пользовательского агента нажмите **Create**.
3. В разделе **Select your app** выберите приложение. Одно приложение на агента.
4. (Необязательно) Настройте фильтры **гео** и **медиаисточник**. Оставьте их пустыми, чтобы включить все.
5. В разделе **Task** опишите задачу или нажмите готовый промпт и отредактируйте его под свои потребности.
6. Нажмите **Создать план**.

<div id="step-2-review-the-agent-plan" />

##### Шаг 2: Проверьте план агента

Агент преобразует вашу задачу в план и показывает его вам перед тем, как что-либо запускать. Здесь вы можете выявить неверно понятое задание или определение, которое не совпадает с тем, как ваша команда измеряет показатели.

| Раздел плана | Что проверить |
| --- | --- |
| Цель | Однострочное переформулирование задачи. |
| План агента | Как агент выполнит задачу. |
| Определения | Все метрики, окна и пороговые значения из вашей задачи, изложенные подробно: что означает «удержание на 7-й день», что означает «значительное снижение», какие медиаисточники входят в область охвата. Измените все, что отличается от ваших собственных определений. |
| Параметр | Приложение, гео и медиаисточник, к которым агент будет применять настройки. |

Отсюда:

* Нажмите **Edit**, чтобы изменить любое поле, затем нажмите **Save changes**.
* **Начать заново** возвращает вас к задаче.
* **Accept plan** позволяет перейти дальше.

<div id="step-3-configure-and-deploy" />

##### Шаг 3: Настройка и развертывание

1. Введите **имя агента**.
2. В разделе **Select how you want to receive the results** выберите **Slack**, **электронную почту** или оба варианта.
   * Slack: нажмите **Подключиться к Slack**, если рабочая область еще не подключена, затем выберите канал.
   * Электронная почта: до пяти адресов пользователей AppsFlyer.
3. В разделе **Расписание запуска** выберите один из вариантов.
4. Нажмите **Развернуть агента**.

Расписание запуска задается в UTC.

Агент появится в разделе **Мои агенты**. Карточка показывает статус последнего запуска. Завершенные запуски находятся в разделе **Активность**, где их можно фильтровать по приложению и имени агента.

<div id="h_01M3PDTFQESQY349XK0SNH5NB8" />

<Accordion title="С какими данными работает пользовательский агент">

У пользовательского агента есть два источника данных — данные на уровне событий и агрегированные данные — и он выбирает между ними в зависимости от задачи; указывать это не нужно. Для некоторых задач агент использует оба источника в рамках одного запуска. В этих редких случаях одна и та же метрика может показывать немного разные значения в двух частях одного запуска. Чтобы понять, какой источник агент использовал во время запуска, изучите рассуждения агента с помощью функции **Анализ активности**.

**Данные на уровне событий.** Необработанные события по всей воронке — от вовлеченности до активности в приложении. Именно это отличает пользовательского агента от дэшборда: вы можете определять собственные метрики и соотношения, работать на уровне отдельных пользователей и отслеживать последовательности событий.

| Включено | Срок |
| --- | --- |
| Типы взаимодействия | Клики и показы |
| Установки и повторные вовлечения | Конверсии |
| Sessions (Сеансы) | События открытия приложения |
| События в приложении | Включая доход от покупок в приложении |
| Аспекты | Медиаисточник, кампания, гео вплоть до города, устройство, версия ОС, версия приложения, рекламное объявление, идентификатор сайта и другие поля необработанных событий |
| Временной диапазон данных | Последние 30 дней |

**Данные активности и когорты (агрегированные).** Все точки данных, доступные в разделе «Мои дэшборды», включая стоимость.

| Включено | Срок |
| --- | --- |
| метрика | Установки, конверсии, первые посещения, сессии, количество событий, уникальные пользователи, активные пользователи, доход, чистый доход, средний доход на пользователя (ARPU), доход на уникального пользователя, количество на уникального пользователя, коэффициент удержания |
| События в приложении, конверсии, удаления, сессии | Количество, уникальные пользователи, доход, чистый доход, количество первых событий |
| Метрики по затратам | Расходы (стоимость), eCPI, ROAS, ROI |
| Аспекты | Медиаисточник, канал, идентификатор и название кампании, идентификатор и название группы объявлений, идентификатор и название рекламного объявления, идентификатор сайта, агентство, ключевые слова, sub\_param\_1, категория, тип и назначение вовлеченности, унифицированный идентификатор приложения, платформа, магазин приложений для установки, версия приложения, версия ОС и код страны (конверсия), тип агрегированного события (конверсия, сессия, в приложении, удаление), название события, название и тип конверсии, тип монетизации, is-attributed, is-organic, is-primary-attribution, дата события (только для когорты), дата события (конверсия), дни после конверсии, валюта клиента |
| Временной диапазон данных | Три года для активности, два года для когорты |

Агрегированные данные доступны в USD и в валюте вашего аккаунта. Агрегированные данные по когортам имеют дневную детализацию.

**Текущие ограничения.** Эти ограничения временные и будут меняться по мере выхода пользовательского агента из беты.

* Данные о вовлеченности и стоимости находятся в разных источниках. Клики и показы доступны только в данных на уровне событий; стоимость доступна только в агрегированных данных. Агент не может объединить эти два источника, поэтому метрики, которые их комбинируют, например CPC, CPM, CTR, IPM и CPA, не возвращают результатов. Метрики на основе стоимости, которым не нужны данные о вовлеченности (spend, eCPI, ROAS, ROI), работают как ожидается.
* Отсутствуют данные: данные, созданные в аудиториях, SKAdNetwork, SSOT, Protect360, Creative и Incrementality; доход от рекламы и доход от подписок (доход включает только покупки в приложении).
* Пользовательские метрики или измерения, которые вы определили в своих дэшбордах, не включены.
* Агрегированные измерения включают данные только начиная с июня 2025 года для платформы, sub\_param\_1, направления вовлеченности, типа вовлеченности и источника (органический vs. неорганический).
* Если данных нет, агент показывает 0, а не N/A.
* «First visits» и «re-visits» доступны только для веб-приложений.

<Accordion title="Сформулируйте хорошую задачу">

План, который составляет агент, настолько хорош, насколько хорош бриф. По возможности укажите следующее:

1. **Задача.** Что именно вы хотите сделать, простыми словами. Помогают глаголы: сравнить, ранжировать, отметить, найти, рекомендовать, обобщить.
2. **Период времени.** Определенное окно, например «последняя полная неделя» или «последние 14 дней по сравнению с предыдущими 14». Не включайте сегодняшний день: данные за него пока неполные.
3. **Охват.** Гео, медиаисточник, кампания или платформа, которые имеют значение. Вы также можете задать гео и медиаисточник как фильтры над полем задачи.
4. **Метрики и пороговые значения.** Укажите KPI и то, как вы их определяете. «Снижение более чем на 10% по сравнению с предыдущей неделей считается значимым» — это правило, которое агент может применять.
5. **Желаемый результат.** Если это важно, укажите это: «таблица, отсортированная по расходам», «краткое резюме с тремя ключевыми выводами» или «только пометка, без пояснений».
6. **Почему.** Одна строка контекста помогает агенту понять, что приоритизировать.

Подробности настройки см. выше в разделе **Предварительные требования и разрешения**.

<Accordion title="Ищите креативные возможности">

**Задача:** Находит самые эффективные креативы и показывает, где они еще не запущены. Агент оценивает эффективность креативов по всем вашим партнерам за последние 30 дней, ранжирует лучшие из них, а затем проверяет каждого партнера, чтобы определить, у кого из них эти лучшие креативы отсутствуют. Вы получаете список конкретных плейсментов, которые стоит добавить, с подтверждающими метриками по каждому из них.

**С чем работает:** Расходы и ROAS на уровне креатива по партнерам за последние 30 дней. Требуется оптимизация креативов.

**Что дает запуск:** Самые эффективные креативы с их расходами и ROAS, а также по каждому партнеру — какие из этих креативов сейчас не запущены и обоснование для их добавления. Доставляется в Slack или по электронной почте.

**Частота:** Настраивается с помощью стандартных параметров расписания или по запросу.

</Accordion>

<Accordion title="Снимки эффективности сборки">

**Задача:** Напишите обновление по эффективности, которое иначе пришлось бы собирать вручную для менеджеров и заинтересованных сторон. Агент читает ваши агрегированные аналитические данные с выбранными KPI, выявляет тренды, лучших по эффективности и важные для периода изменения, а затем превращает всё это в сводку с рекомендациями, готовую к пересылке.

**С чем работает:** Агрегированные аналитические данные по вашим приложениям, гео, медиаисточникам и не только. Премиум-подписка не требуется.

**Результат запуска:**

* Текстовая сводка: основные выводы, что требует внимания, заметные изменения и рекомендуемые дальнейшие шаги.
* Представление «Мои дэшборды», созданное агентом вокруг выбранных вами KPI, чтобы вы могли изучить цифры, лежащие в основе сводки.

И то, и другое доставляется в Slack или по электронной почте.

**Периодичность:** Конфигурируемая. Обычно выбирают еженедельную периодичность.

**Настройка:** Выберите приложение(я), KPI, которые нужно охватить, уровень группировки и любые дополнительные фильтры — медиаисточник, гео, агентство.

**Полезно знать:** Связанное представление «Мои дэшборды» — это временное представление, сгенерированное ИИ, которое находится в разделе **Мои дэшборды** > **AI generated**. Оно перезаписывается свежими данными при каждом запуске и удаляется через 30 дней, если вы его не сохраните.

<Accordion title="Глубокий исследовательский анализ">

**Задача:** Проводит еженедельное исследование того, что изменилось и почему. Каждый понедельник агент сравнивает две последние полные недели (с понедельника по воскресенье) и анализирует исходные данные на уровне событий по партнерам, гео, версиям ОС и версиям SDK, чтобы найти изменения, которые агрегированные дэшборды показать не могут, включая проблемы настройки, которые выглядят как изменения эффективности.

**С чем работает:** С полными исходными данными на уровне событий. Агент намеренно исключает текущую неделю, чтобы избежать частичных или еще не полных данных. Например, в понедельник 26 января он сравнивает 12–18 января с 5–11 января. Премиум-подписка не требуется.

**Что дает запуск:** Текстовый отчет о значимых изменениях от недели к неделе, о том, что к ним привело, и о проблемах настройки, выявленных в процессе. Доставляется в Slack или по электронной почте.

**Периодичность:** еженедельно, по понедельникам или по запросу.

</Accordion>

<Accordion title="Обнаруживает аномалии эффективности">

**Задача:** Ежедневно отслеживает ваши ключевые KPI и сообщает, когда происходит изменение, которого быть не должно. Агент сравнивает каждую метрику с ее ожидаемым диапазоном, отмечает значимые положительные и отрицательные аномалии и объясняет, что изменилось и где: скачок CPI у одного партнера, падение IPM в одном гео или кампания, показатели которой резко просели.

**С чем работает:** С ежедневными данными KPI по партнерам, кампаниям и гео. Премиум-подписка не требуется.

**Что дает запуск:** Уведомления в формате истории: какая метрика изменилась, насколько, у какого партнера, в какой кампании или гео и какова вероятная причина. Доставляется в Slack или по электронной почте. В спокойные дни оповещения не отправляются. [ПОДТВЕРДИТЬ]

**Периодичность:** Конфигурируется с помощью стандартных параметров расписания или по запросу.

</Accordion>

<Accordion title="Выявление проблем с конфигурацией">

**Задача:** Проверяет ваши настройки измерения и предупреждает о пробелах, которые незаметно ухудшают качество данных. Агент проверяет неактивные интеграции в SKAdNetwork и стоимости, отключенную атрибуцию по показам через вероятностное моделирование и другие проблемы конфигурации, чтобы вы могли выявить их до того, как они исказят результаты кампании.

**С чем работает:** Статус интеграции и конфигурации во всех ваших приложениях и у партнеров. Премиум-подписка не требуется.

**Что дает запуск:** Уведомления со списком каждой найденной проблемы, где она находится и как ее устранить. Доставляется в Slack или по электронной почте.

**Периодичность:** Конфигурируется с помощью стандартных параметров расписания или по запросу.

<Accordion title="Мониторинг релизов приложений">

**Задача:** Держит вас в курсе релизов вашего приложения, не дожидаясь команды разработки. Агент отслеживает релизы в магазинах приложений iOS и Android, предупреждает, когда новая версия становится доступна, отслеживает ход развертывания и выделяет важные для маркетинга изменения: новые функции, изменения поведения в приложении, а также добавленные или удаленные события. Это помогает согласовать UA-кампании с тем, что фактически есть в приложении.

**С чем работает:** Данные о релизах в магазине приложений и определения событий в приложении для ваших приложений. Премиум-подписка не требуется.

**Что дает запуск:** Уведомления о релизах с версией, статусом развертывания и сводкой изменений, важных для маркетинга. Отправляется в Slack или на электронную почту.

<Accordion title="Оптимизируйте стратегию борьбы с мошенничеством (Protect360)">

**Задача:** выявляет ранние признаки фрода в вашем трафике и подсказывает, что с этим делать. Агент анализирует ваши данные Protect360 на предмет новых закономерностей, сообщает о ключевых результатах и рекомендует действия, которые снижают подверженность фроду без ущерба для эффективности.

**С чем работает:** данные Protect360. Требуются Protect360 и функции закрытой бета-версии Protect360.

**Что дает запуск:** выводы и рекомендации в дэшборде Protect360.

**Периодичность:** еженедельно, по понедельникам или по запросу.

<Accordion title="Проверка работоспособности веб-приложения">

**Что проверяется:** настройки атрибуции в выбранном веб- приложении и недавние данные SDK или server-to-server. Проверки охватывают сбор данных, события и доход, ссылки кампаний, рефереры, идентификацию и кроссплатформенную настройку. Окно анализа по умолчанию составляет семь дней.

## Часто задаваемые вопросы

<Accordion title="Могу ли я создать своих собственных агентов?">

Да. Пользовательский агент позволяет определить, какую задачу нужно выполнить. См. [**Пользовательский агент**](#h_01M3PDTFQDFQNMHTWKP23JV1A8) выше.

</Accordion>

<Accordion title="Доступен ли Agent Hub для всех типов учетных записей?">

№ В настоящее время Agent Hub доступен только для рекламодателей.

</Accordion>

<Accordion title="Все ли агенты доступны всем подписчикам?">

Доступность агентов варьируется в зависимости от вашей подписки на AppsFlyer и доступа к премиум-продуктам. Свяжитесь с вашим менеджером для получения конкретных деталей.

</Accordion>

<Accordion title="Могут ли администраторы отключить Agent Hub для учетной записи?">

Да. Администраторы могут настраивать доступность Agent Hub в **разделе «Настройки аккаунта» > «Возможности ИИ**».

По умолчанию для данной учетной записи доступен Agent Hub.

Если администратор отключит Agent Hub:

* Все пользователи теряют доступ к Agent Hub.
* Все существующие агенты будут удалены и не подлежат восстановлению.
* Все активные запуски агента останавливаются.

Если администратор позже снова включит Agent Hub, пользователи смогут снова получить к нему доступ, но им придётся создавать и развертывать агенты заново.

Подробные сведения см. в разделе <Anchor target="_blank" href="/marketers/ru/docs/account-settings#agent-hub">Настройки аккаунта</Anchor>.

</Accordion>

<Accordion title="Куда я могу получать уведомления?">

Вы можете получать уведомления по электронной почте или в Slack. Для получения уведомлений по электронной почте вы должны подписаться на уведомления о возможностях ИИ в Центре уведомлений.

</Accordion>

<Accordion title="Почему я не получаю уведомления по электронной почте от Agent Hub?">
