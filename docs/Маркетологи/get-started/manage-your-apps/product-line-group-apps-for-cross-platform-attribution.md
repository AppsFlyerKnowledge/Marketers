> **Кратко:** Сгруппируйте приложения для разных платформ под единым брендом с помощью линейки продуктов. Используйте единый Customer User ID (CUID), чтобы получить кроссплатформенную атрибуцию и инсайты о пути пользователя в мобильных, веб- и CTV-приложениях.

<div id="about-product-line" />

## О линейке продуктов

Линейка продуктов позволяет объединять разные версии одного и того же приложения для разных платформ (например Android, iOS, веб и CTV) под единым брендом. Это упрощает управление приложениями и обеспечивает кроссплатформенную атрибуцию на основе идентификатора пользователя клиента (CUID).

С помощью Линейки продуктов вы можете:

* Измеряйте Lifetime Value (LTV) пользователя на разных устройствах
* Анализируйте поведение на разных платформах
* Внутренне группируйте приложения под одним брендом
* Подключите измерение кроссплатформенного повторного вовлечения

  Примечание. Измерение кроссплатформенного повторного вовлечения является необязательным. Если вы подключите эту функцию, AppsFlyer сможет атрибутировать активность подходящих вернувшихся пользователей медиаисточнику, который повторно вовлек пользователя на разных платформах. Дополнительные сведения см. в статье <Anchor target="_blank" href="/marketers/ru/docs/beta-user-based-cross-platform-re-engagement-attribution">Измерение кроссплатформенного повторного вовлечения</Anchor>.

Например, если пользователь устанавливает ваше приложение на iOS, входит в приложение PlayStation и смотрит контент через телевизор Samsung, вы можете просмотреть весь его путь как путь одного пользователя.

Более подробный обзор линеек продуктов см. в статье <Anchor target="_blank" href="/marketers/ru/docs/beta-user-based-cross-platform-attribution">Пользовательская кроссплатформенная атрибуция</Anchor>.

## Как настроить линейку продуктов

<div id="prerequisites" />

### Требования

* **CUID (Customer User Identifier)** должен быть единым идентификатором (например идентификатором для входа или хешированным адресом электронной почты) на всех платформах.
* Настройте **CUID SDK или** [**s2s**](https://dev.appsflyer.com/hc/docs/set-customer-user-id) **setup.**
* Убедитесь, что приложение задает CUID при каждом запуске, чтобы распознавать одного и того же пользователя на разных устройствах и в разных сессиях.

<div id="how-to-create-a-product-line" />

### Как создать линейку продуктов

1. Перейдите в **Мои приложения**.
2. На верхней панели нажмите **Создать линейку продуктов**.
3. Выберите до 30 приложений, которые хотите включить -> **Создать**.
4. В новом окне:
   1. Добавьте **название линейки Продуктов.**
   2. Включите **Начать измерять и анализировать кроссплатформенные данные.**  
      Примечание: без этого кроссплатформенная атрибуция не будет работать.
   3. Выберите **окно неактивности.**
   4. Выберите, нужно ли включить кроссплатформенное измерение повторного вовлечения.
      1. Выберите **окно повторного вовлечения**.
      2. Выберите **окно неактивности для повторного вовлечения.**
5. Справа вы увидите все приложения в линейке Продуктов.
6. Нажмите **Создать**.
7. Отправьте **инструкции по внедрению CUID** своему разработчику.

**Примечание:** кроссплатформенная атрибуция повторного вовлечения работает поверх кроссплатформенной атрибуции. Прежде чем подключиться к повторному вовлечению, необходимо создать линейку Продуктов, активировать кроссплатформенную атрибуцию и отправлять события с действительным CUID. Чтобы узнать, как работает атрибуция повторного вовлечения между платформами, см. <Anchor target="_blank" href="/marketers/ru/docs/beta-user-based-cross-platform-re-engagement-attribution">Кроссплатформенная атрибуция повторного вовлечения</Anchor>.

<div id="how-to-remove-an-app-from-a-product-line" />

<Accordion title="Как удалить приложение из линейки Продуктов">

<div id="important" />

> 🚧 **Двоеточие (:)**
>
> Не рекомендуется удалять приложение из линейки Продуктов. При удалении или перемещении приложения его настройки кроссплатформенной атрибуции сбрасываются, и будущие события не будут участвовать в кроссплатформенной атрибуции, пока не будет создано новое сопоставление.

1. Перейдите в **Мои приложения**.
2. В разделе **Линейки Продуктов** нажмите на линейку Продуктов, которую хотите изменить.
3. В правой части окна вы увидите все приложения в линейке Продуктов.
4. Наведите указатель на приложение, которое хотите удалить, затем нажмите на **X** у этого приложения.
5. После удаления приложения нажмите **Обновить** в нижней части окна.

</Accordion>

<div id="how-to-add-an-app-to-a-product-line" />

<Accordion title="Как добавить приложение в линейку Продуктов">

1. Перейдите в **Мои приложения**
2. В разделе **Все приложения** наведите указатель на приложение, которое хотите добавить, затем установите флажок.
3. На верхней панели выберите **Добавить в линейку Продуктов**.
4. Выберите линейку Продуктов, в которую хотите добавить приложение.
5. Убедитесь, что в окне линейки Продуктов все указано правильно, затем нажмите **Обновить** в нижней части окна.

</Accordion>

<div id="how-to-delete-a-product-line" />

<Accordion title="Как удалить линейку продуктов">

<div id="important-1" />

> 🚧 **Двоеточие (:)**
>
> Удалять линейку продуктов не рекомендуется. При удалении линейки продуктов ее настройки кросс-платформенной атрибуции сбрасываются, а будущие события не будут учитываться для кросс-платформенной атрибуции, пока не будет создано новое сопоставление.

1. Перейдите в **Мои приложения**.
2. В разделе **Линейки продуктов** нажмите на три точки в строке Линейка продуктов, которую хотите удалить.
3. Выберите **Удалить линейку продуктов**.

</Accordion>

## Спецификации и ограничения

| Специфика | Описание |
| --- | --- |
| Группировка приложений | Приложения должны относиться к одному бренду |
| Максимум приложений | До 30 приложений в одной линейке продуктов |
| Только одна линейка продуктов | Приложение может одновременно входить только в одну линейку продуктов |
| Требование к CUID | Требуется только для кросс-платформенной атрибуции |
| Окно восстановления неактивности | 14–390 дней (по умолчанию: 90 дней) |
| Влияние удаления приложения | При удалении приложения настройки атрибуции сбрасываются<br /><br />Удаление приложения из линейки продуктов влияет на кросс-платформенную атрибуцию с этого момента.<br /><br />• Будущие события в приложении из удаленного приложения не будут учитываться для кросс-платформенной атрибуции в рамках этой линейки продуктов, поскольку события должны поступать из приложений, входящих в линейку продуктов.<br /><br />• Исторические результаты не пересчитываются задним числом |

<div id="faqs" />

## Вопросы и ответы

**Можно ли использовать линейки продуктов только для организации приложений?**  
Важно! Оставьте переключатель кроссплатформенной группировки **выключенным**, чтобы объединить приложения в группу только для управления.

**Что произойдет, если удалить приложение из линейки продуктов?**  
Удалять приложение из линейки продуктов не рекомендуется. При удалении или перемещении приложения его настройки кросс-платформенной атрибуции сбрасываются, а будущие события не будут учитываться для кросс-платформенной атрибуции, пока не будет создано новое сопоставление.

**Влияет ли создание линейки продуктов на результаты классической атрибуции AppsFlyer?**

Нет, создание линейки продуктов не влияет на результаты классической атрибуции AppsFlyer на уровне устройства
