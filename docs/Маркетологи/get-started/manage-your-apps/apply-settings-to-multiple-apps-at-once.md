> **At a glance:** Применяйте одно и то же изменение настройки одновременно к нескольким приложениям, вместо того чтобы повторять это для каждого приложения отдельно.

<div id="about-bulk-app-settings" />

## О групповых настройках приложений

Теперь вы можете применять одинаковые изменения настроек сразу к нескольким приложениям с помощью массовых настроек приложений на странице «Настройки приложений». Это позволяет один раз внести изменение и применить его к другим подходящим приложениям за одну операцию.

Чтобы получить доступ к настройкам приложений, в боковом меню выберите **Настройки** > **Настройки приложений**. Или в разделе **Мои приложения** выберите приложение и откройте его настройки приложения.

<div id="apply-a-setting-to-multiple-apps" />

## Применение настройки к нескольким приложениям

<div id="note" />

> 📘 **Примечание:**
>
> Приложение подходит для массового изменения, если настройка применяется к платформе этого приложения, в нем еще не задано применяемое вами значение, все необходимые предварительные условия уже выполнены и у вас есть доступ уровня «Управление» к его настройкам приложения. Полные критерии для каждой настройки см. ниже в разделе **Характеристики и ограничения**.

**Чтобы применить изменение настройки к нескольким приложениям:**

1. Откройте настройки приложения, параметры которого вы хотите изменить, и измените параметр (переключатель, раскрывающийся список или ползунок).

   <Image alt="Screenshot 2026-09-16 at 14.31.44.png" src="https://files.readme.io/8a1abce58e1e8da4af5899e2e03a2a7fe9e6e9b8e9a04c240585bfd3e7934126-50944987863825.png" width="2557px" />
2. Рядом с измененным полем нажмите **Применить к другим приложениям**.

   <Image alt="aap.png" src="https://files.readme.io/0f2144ca43c6db7ffe9967df5c2b2f2fe3e8cffdbefa77167ed9262a61511774-50945027652113.png" width="612px" />
3. Найдите приложения по названию или идентификатору ID и выберите приложения, к которым нужно применить то же изменение. Приложения, для которых это изменение недоступно, остаются видимыми, но отображаются серым цветом. Наведите курсор на такое приложение, чтобы узнать причину.

   <Image alt="Screenshot 2026-09-16 at 14.32.32.png" src="https://files.readme.io/95c79ce8c176e4a0836661a119ca12b1268b8874181d4fd78c96113e5339d6c9-50945018039953.png" width="1304px" />
4. Чтобы закрыть список и подтвердить выбор, кликните вне списка. Кнопка **Apply to additional apps** заменяется значком с количеством выбранных приложений; нажмите его в любой момент, чтобы изменить выбор.

   <Image alt="ssa.png" src="https://files.readme.io/b93174999053cdbbf5591eb215e6cd10becbd2d1bcb699ff286a8b1523f8a8f0-50944987865361.png" width="1238px" />
5. Повторите эти шаги для всех нужных настроек.
6. Внизу страницы кликните **Save changes** (если вы не выбрали дополнительные приложения) или **Review & Save** (после того как вы включили приложения в массовое изменение). На обеих кнопках в скобках отображается общее количество изменений.

   <Image alt="Screenshot 2026-09-16 at 14.33.32.png" src="https://files.readme.io/6dfb050b984932023455af9022364b37534af276d7bb117ddb05ad0fc25d936c-50945018041489.png" width="2269px" />
7. Если вы добавили дополнительные приложения, проверьте значения «до» и «после» для каждого приложения на экране **Review before saving**. В качестве базового значения используется текущее значение каждого приложения. Перед подтверждением можно удалить любое изменение из пакета.

   <Image alt="Screenshot 2026-09-16 at 14.33.38.png" src="https://files.readme.io/c22f67575fc8ac9cbd868c923b5addfe8c70529ee1183fa7231f080d1b54d18c-50945018042385.png" width="1286px" />
8. Нажмите **Подтвердить & Сохранить**. Это позволяет за одну операцию сохранить исходное приложение вместе со всеми дополнительными приложениями в пакете.

<div id="note-1" />

> 📘 **Примечание:**
>
> Для Aggregated Advanced Privacy перед тем, как изменение вступит в силу, всегда отображается шаг подтверждения. Для атрибуции повторного вовлечения этот шаг подтверждения отображается только при массовом применении изменения.

<div id="important" />

> 🚧 **Важно!**
>
> Все приложения в пакете обновляются одновременно. Результат будет одним из двух:
>
> 1. Успешное выполнение и обновление всех приложений.
> 2. Сбой, и ни одно приложение не будет обновлено.
>    1. Если сохранить не удалось, можно повторить попытку.

<div id="traits-and-limitations" />

## Спецификации и ограничения

| Специфика | Описание |
| --- | --- |
| <span id="supported-settings-ships-first"></span>Поддерживаемые настройки (доступны сейчас) | <ul><li>Агрегированная расширенная конфиденциальность (только iOS)</li><li>Атрибуция повторного вовлечения (iOS, Android)</li><li>Минимальное время между конверсиями повторного вовлечения (iOS, Android)</li><li>SEO-атрибуция (iOS, Android для включения; любая платформа для отключения)</li><li>Маскировка IP-адресов (все платформы, кроме Web)</li><li>Событие лояльного пользователя (iOS, Android)</li><li>Минимальное время между сессиями (iOS, Android)</li></ul> |
| <span id="supported-settings-coming-soon"></span>Поддерживаемые настройки (скоро) | Эти настройки пока не поддерживаются для массовых изменений. В разработке:<ul><li>Окно реатрибуции (мобильные устройства — в днях; веб-сайт — в секундах, без объединения в одно действие)</li><li>Вероятностное моделирование (все платформы; требуется, чтобы фингерпринтинг уже был включен)</li><li>Часовой пояс (все платформы)</li><li>Валюта (все платформы)</li><li>Измерение удаления приложения (для iOS требуется уже загруженный сертификат P12; для Android требуется уже настроенный Firebase)</li><li>Обнаружение переустановки (iOS, Android)</li></ul> |
| <span id="not-supported"></span>Не поддерживается | Аутентификация SDK (ключ разработчика), страна магазина приложений, изменение названия приложения, загрузка сертификата удаления для iOS, идентификатор ID проекта Firebase, а также настройки мест для агентств и партнеров. |
| <span id="why-an-app-might-be-grayed-out"></span>Почему приложение может отображаться серым цветом | Неактивное приложение нельзя выбрать для этого изменения в данной попытке. Будет показана одна из следующих причин:<ul><li>**Несоответствие платформы:** этот параметр недоступен на платформе данного приложения.</li><li>**Уже задано:** для приложения уже установлено применяемое вами значение.</li><li>**Не выполнено предварительное условие:** например, для вероятностного моделирования фингерпринтинг уже должен быть включен.</li><li>**Период ожидания:** часовой пояс нельзя изменить повторно в течение двух дней после предыдущего изменения. Во всплывающей подсказке указана дата, когда параметр снова станет доступен.</li><li>**Нет разрешения:** у вас нет доступа уровня Manage к настройкам приложения для этого приложения.</li></ul> |
| <span id="limits"></span>Ограничения | Практических ограничений на количество приложений, которые можно включить в массовое изменение, нет. |
