> **Краткий обзор.** Доступ члена команды к данным и функциям в AppsFlyer зависит от типа аккаунта, предоставленных ему индивидуальных разрешений и разрешений на уровне аккаунта.

<div id="access-to-data-by-account-type" />

## Доступ к данным по типу аккаунта

Рекламодатели, рекламные сети и агентства имеют доступ к данным в соответствии с типом их аккаунта:

| Типы учетных записей | Доступ к данным |
| --- | --- |
| Рекламодатель | Все свои данные в AppsFlyer, хотя некоторые данные маскируются или хэшируются:<ul><li>трафик, атрибутированный ограниченным медиа-источникам, из-за нормативных требований или условий обмена данными.</li></ul> |
| Рекламная сеть | Данные, атрибутированные рекламной сети |
| Агентство | Данные, относящиеся к кампаниям, проводимым агентством, к которым атрибутирован трафик |

<div id="access-to-data-by-roles-and-permissions" />

## Доступ к данным по ролям и разрешениям

Когда рекламодатель включает переключатель «Разрешение» для рекламной сети (см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-рекламной-сети">Разрешения рекламной сети</Anchor>) или агентства (см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner#разрешения-агентства">Разрешения агентства</Anchor>), доступ к данным дополнительно различается в зависимости от ролей — **администратор** аккаунта и **участники команды** аккаунта, как указано в приведенных ниже таблицах.

**Примечание.** Там, где это разрешено, доступ есть только к трафику, генерируемому агентством / рекламной сетью.

Расшифровка сокращений:

| Сокращение | Значение |
| --- | --- |
| ✓ | Доступ предоставляется, если рекламодатель включил основной переключатель разрешений. |
| P | Доступ предоставляется, если рекламодатель включает дополнительные специфические разрешения. |
| L | Ограниченный доступ предоставляется при наличии разрешения рекламодателя. |
| – | Нет доступа |

Все остальные пользователи имеют доступ в соответствии с назначенными им <Anchor target="_blank" href="/marketers/ru/docs/user-management#управление-ролями">ролями</Anchor>.
