> **Краткий обзор**. Просмотрите KPI коэффициента конверсии в AppsFlyer, чтобы понять сильные и слабые стороны на разных этапах вашей маркетинговой воронки.

## Этапы маркетинговой воронки

Новые пользователи проходят через маркетинговую воронку — от первого просмотра рекламы до генерирования дохода. Каждый из этапов воронки имеет свой уровень успеха. Чем больше пользователь продвигается вперед, тем лучше результаты для мобильного рекламодателя. На следующем изображении представлены этапы маркетинговой воронки.

## Этапы маркетинговой воронки и коэффициенты конверсии

Коэффициенты конверсии помогают рекламодателям понять сильные и слабые стороны на разных этапах маркетинговой воронки. Затем, в соответствии с коэффициентами конверсии, они могут **улучшить слабые стороны и продвинуть больше пользователей по воронке.**

См. в следующей таблице:

* Описания этапов маркетинговой воронки и коэффициентов конверсии
* Где доступны метрики, отмечены как:
  * **AppsFlyer**: Обзорный дэшборд и <Anchor target="_blank" href="/marketers/ru/docs/aggregated-and-analytics-reporting-overview">агрегированные отчеты и аналитика</Anchor>
  * **Магазин приложений**: Данные доступны только в магазине приложений
* Как рекламодатели могут использовать эти метрики для улучшения результатов маркетинга

#### Этапы маркетинговой воронки и коэффициенты конверсии

| Этап | Имя | Описание | Где доступно | Как оптимизировать коэффициент конверсии |
| --- | --- | --- | --- | --- |
| 1 | Показ (impression) | Пользователь просматривает рекламу в вебе или на мобильном. | AppsFlyer: |  |
| 2 | Клик | <ul><li>Пользователь нажимает на объявление и перенаправляется на рекламируемую страницу или действие в приложении.</li><li>Или пользователь переходит на страницу магазина приложения, не нажимая рекламу.</li></ul> | AppsFlyer: |  |
| Коэффициент конверсии | **Показатель кликабельности (клики / показы) \* 100** | <ul><li>Измеряет пользователей, которые кликают по рекламе после ее просмотра.</li><li>Для расчета используйте метрики показов и кликов в AppsFlyer.</li></ul> |  | <ul><li>Улучшите влияние ваших креативов на целевую аудиторию: визуальные эффекты, копирование, локализация и таргетинг.</li><li>Экспериментируйте с новыми аудиториями и медиа-источниками.</li></ul> |
| 3 | App Store | Пользователь приходит на страницу приложения в магазине приложений. | App Store |  |
| Коэффициент конверсии | **Коэффициент перехода в магазин приложений (посещение магазина приложений / клики) \* 100** | Измеряет, сколько пользователей нажали на рекламу и позволили странице приложения в магазине приложений полностью загрузиться. | App Store | Улучшите время загрузки страниц магазина приложений. Удалите крупные элементы, которые замедляют загрузку страницы. |
| 4 | Скачать | Пользователь скачивает приложение из магазина приложений. | App Store |  |
| Коэффициент конверсии | **Коэффициент скачиваний из магазина приложений (скачивания / посещения магазина приложений) \* 100** | Измеряет, сколько пользователей скачивают приложение после посещения страницы приложения в магазине приложений. | App Store | <ul><li>Улучшите сообщения на страницах магазина приложений.</li><li>Попробуйте разные призывы к действию.</li></ul> |
| 5 | Установка | Пользователь устанавливает и открывает приложение на своем устройстве.<ul><li>На ~10% меньше установок по сравнению со скачиваниями.</li><li>Пример: Если AppsFlyer показывает 200 установок в кампании, то приблизительно 220 пользователей скачали приложение.</li></ul> | AppsFlyer: |  |
| Коэффициент конверсии | **Соотношение установок и кликов (установки / клики) \* 100** | Измеряет, сколько пользователей установили приложение после клика по рекламе. | AppsFlyer: | <ul><li>Улучшите таргетинг аудитории.</li><li>Сократите время установки приложений.</li></ul> |
| 6 | Внутреннее событие приложения | Пользователь совершает действие в приложении, например, покупку. | AppsFlyer: |  |
| Коэффициент конверсии | **Показатель конверсии событий (Event CVR)**<br /><br />**(внутренние события / установки) \* 100** | <ul><li>Измеряет количество пользователей, совершающих события внутри приложения после установки. <Anchor target="_blank" href="/marketers/ru/docs/appsflyer-knowledge-base-glossary#cvr-события">[Статья]</Anchor></li><li>Примеры: регистрация, совершение покупки, прохождение уровня и т.д.</li><li>Позволяет рассчитать стоимость одного действия (CPA).</li></ul> | AppsFlyer: | <ul><li>Обеспечьте своевременное информирование и призывы к действию.</li><li>Улучшите пользовательский интерфейс.</li><li>Организуйте кампании ретаргетинга с использованием диплинкинга. <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">[Статья]</Anchor></li></ul> |
