> **Краткий обзор:** настройте окна атрибуции по кликам и просмотрам на основе ваших соглашений с медиа-источниками.

## Окна атрибуции

Настраиваемое окно атрибуции позволяет вам настроить период атрибуции на основе вашего соглашения с медиа-источниками.

Устанавливая окна атрибуции для каждого медиа-источника, AppsFlyer атрибутирует в соответствии с согласованными условиями.

**Типы окон атрибуции**:

* **Окно атрибуции по просмотрам**: максимальный период времени после просмотра рекламного объявления, в течение которого установка может быть атрибутирована этому объявлению. Установки, которые происходят после окончания периода окна атрибуции, считаются органическими.
* **Окно атрибуции по вовлечённым кликам:** максимальный период времени после вовлечённого клика, в течение которого установку можно атрибутировать вовлечённому клику.  Установки, которые происходят после окончания периода окна атрибуции, считаются органическими.
* **Окно атрибуции по вовлечённому просмотру:** максимальный период времени после вовлечённого просмотра, в течение которого установку можно атрибутировать вовлечённому просмотру.  Установки, которые происходят после окончания периода окна атрибуции, считаются органическими.
* **Окно атрибуции по кликам**: максимальный период времени после клика по рекламному объявлению, в течение которого установка может быть атрибутирована этому объявлению. Установки, которые происходят после окончания периода окна атрибуции, считаются органическими.

### Окно атрибуции вероятностного моделирования

Окно атрибуции по методу вероятностного моделирования, используемое для обеспечения точности атрибуции, имеет следующие характеристики:

* Применяется как к кликам, так и к просмотрам
* продолжительность настраивается на период до 24 часов;
* не учитываются параметры длительности окна, отправленные по ссылке атрибуции;
* имеет более короткую длительность, чем окна, используемые детерминистическими моделями.

Подробнее см. в статье <Anchor target="_blank" href="/marketers/ru/docs/appsflyer-attribution-model#probabilistic-modeling">Вероятностное моделирование AppsFlyer</Anchor>.

### Окно атрибуции для SRN

> 🚧 **Важно!**
>
> У каждой SRN есть свое окно атрибуции по умолчанию. Мы рекомендуем установить значение окна атрибуции в AppsFlyer такое же, как в SRN, чтобы минимизировать расхождения. Его изменение может привести к расхождениям. Чтобы узнать больше, посмотрите [пример расхождения с SRN](#сценарии-и-примеры).

1. В AppsFlyer в боковом меню выберите **Сотрудничество**> **Маркетплейс партнёров**.
2. Найдите и выберите SRN – см. <Anchor target="_blank" href="/marketers/ru/docs/self-reporting-networks-srns#srn-интегрированные-с-appsflyer">список поддерживаемых SRN</Anchor>.
3. По умолчанию атрибуция по просмотрам включена.
4. На вкладке **Интеграция** прокрутите вниз до настроек **Атрибуция по кликам** и **Атрибуция по просмотрам**.
5. Используйте ползунки для настройки окна атрибуции.

См. ниже окно атрибуции для каждой SRN:

| СРН | Окно атрибуции по кликам по умолчанию (дни) | Окно атрибуции по просмотрам по умолчанию (часы) |
| --- | --- | --- |
| Google | 30 | 24 |
| Meta Ads | 7 | 24 |
| Snapchat | 28 | 24 |
| Twitter | 14 | 24 |
| Apple Search Ads | 30 | 24 |
| Oath (YahooGemini) | 7 | 24 |

### Окно атрибуции для сети без самостоятельной атрибуции по кликам и просмотрам

1. В AppsFlyer в боковом меню выберите **Сотрудничество**> **Активные интеграции**.
2. Найдите и выберите партнёра.
3. По умолчанию атрибуция по просмотрам включена.
4. Перейдите на вкладку **Ссылка атрибуции**.
5. Выберите, формат измерения времени: в днях или часах.
6. Для настройки окна атрибуции используйте ползунки в разделе **Атрибуция по кликам** (параметр `af_click_lookback`) и **Атрибуция по просмотрам** (параметр `af_viewthrough_lookback`).  
   Выбранное время автоматически отражается в ссылке атрибуции.
7. Выберите параметры, соответствующие кампании: название кампании, группа объявлений и т.д.
8. Скопируйте и сохраните ссылку – это ссылка, которую вы предоставляете рекламной сети.

<div id="h_01JKWVQB6TTA24VAZ9WVJMGY4X" />

### Окно атрибуции для сети без самостоятельной атрибуции по вовлечённым кликам и вовлечённым просмотрам

1. В AppsFlyer в боковом меню выберите **Сотрудничество**> **Активные интеграции**.
2. Найдите и выберите партнёра.
3. На вкладке Интеграция прокрутите вниз до ползунка **Задать окно атрибуции по вовлечённому клику** или до ползунка **Задать окно атрибуции по вовлечённому просмотру**.
4. Настройте окно атрибуции с помощью ползунков.

## Распределение первых запусков приложений

Ниже представлен график, показывающий распределение первых запусков приложений со дня взаимодействия.

[![](https://files.readme.io/8fdc8b23ba9a1b78bdea7bacad99d6ed5e59d57de32f395cb2fd9e5451483962-360001666918.png)](https://files.readme.io/8fdc8b23ba9a1b78bdea7bacad99d6ed5e59d57de32f395cb2fd9e5451483962-360001666918.png)

График даст вам более чёткое понимание количества пользователей, установивших приложение в зависимости от окна атрибуции.

Большинство пользователей, чуть более 97%, которые запускают приложение, делают это в течение 7 дней после взаимодействия с рекламой. Остальные 2% делают это в промежутке между 7-м днем и окончанием окна атрибуции (30-й день).

Фактически, почти 62% пользователей, запускающих приложение, делают это в течение 15 минут после взаимодействия с рекламой. 72% пользователей делают это в течение первого часа.

<Accordion title="Ссылка на атрибуцию без параметра окна атрибуции">

Бывает, что ссылка атрибуции не содержит параметра окна атрибуции. В таких случаях AppsFlyer по умолчанию устанавливает окно атрибуции в 7 дней для кликов и 1 день для просмотров.

</Accordion>

<div id="lookback-in-hours-for-flash-campaigns" />

<Accordion title="Окно атрибуции в часах для флэш-кампаний">

Флэш-кампании – это кампании, цель которых – побудить пользователей установить приложение как можно быстрее и в течение короткого окна продвижения.

Приложение для онлайн-шопинга под названием SuperShopping проводит флэш-кампанию. В рамках этой кампании пользователь, установивший приложение в течение часа, получает специальные предложения.

Александр, ведущий маркетолог в SuperShopping, создаёт ссылку атрибуции и устанавливает окно атрибуции длительностью 1 час. Таким образом, Александр узнает, сколько пользователей откликнулось на кампанию.

Кроме того, разработчик приложения может идентифицировать пользователей, пришедших с этой флэш-кампании, и предоставлять им предложения, которые рекламирует эта кампания.

</Accordion>
