> **Краткий обзор.** Узнайте, как AppsFlyer определяет лояльного пользователя и как вы можете настроить определение.

<div id="what-is-a-loyal-user" />

## Что такое лояльный пользователь?

* Согласно настройкам AppsFlyer по умолчанию, лояльным пользователем является пользователь, который после первой загрузки и открытия приложения открывает его еще три раза.
* Это важный KPI для привлечения пользователей.

<div id="changing-the-loyal-user-definition" />

## Изменение определения лояльного пользователя

Для каждого приложения вы можете задать свое определение лояльного пользователя, выбрав подходящее событие.Чтобы изменить событие для лояльного пользователя, см. <Anchor target="_blank" href="/marketers/ru/docs/app-settings">Настройки приложения</Anchor>. Чтобы изменить триггер события для лояльного пользователя, см. <Anchor target="_blank" href="/marketers/ru/docs/app-settings">Настройки приложения</Anchor>.

<div id="example" />

> 📄 **Пример**
>
> Пользователи, которые регистрируются или совершают покупки в приложении, могут более оправданно считаться лояльными пользователями, чем определение по умолчанию (открывшие приложение три раза).
