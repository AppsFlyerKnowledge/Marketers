> **At a glance:** Получайте подробные данные атрибуции о повторных вовлечениях (пользователях, у которых уже установлено ваше приложение) из органических поисковых систем и ИИ-систем ответов, чтобы оптимизировать конверсии из органического поиска и конверсии на базе ИИ.

<div id="overview" />

## Описание

Атрибуция повторного вовлечения для органического поиска (SEO) и органических ответов ИИ (AEO) — это решение для атрибуции, которое позволяет клиентам AppsFlyer атрибутировать повторные вовлечения (то есть открытия мобильного приложения пользователями, у которых уже установлено ваше приложение) различным органическим поисковым системам и системам ответов ИИ.

Доступ к этим уникальным данным очень полезен для команд SEO (поисковая оптимизация) и AEO (оптимизация для систем ответов) и дает неоценимую обратную связь об их усилиях в SEO и AEO.

<div id="flow" />

### Сценарий

![Схема, показывающая процесс атрибуции органического поиска: от клика пользователя по результату поиска до открытия приложения или перехода пользователя на веб-страницу](https://files.readme.io/4b33060cfa30a4e2786c4a3a213ca41223ae276d63c97ab7c2cb5a997a4b010c-16540659217809.png)

Процесс атрибуции органического поиска выглядит следующим образом:

1. Пользователь набирает в поисковой системе мобильного браузера (Google, Bing и т.д.) определенный поисковый запрос. Поисковая система выводит несколько кликабельных результатов.
2. Ваш веб-разработчик настраивает некоторые из этих результатов поиска так, чтобы они открывали ваше мобильное приложение с помощью Android App Links и iOS Universal Links. Если у пользователя установлено приложение, то при нажатии на результат поиска открывается приложение (без перенаправления в магазин приложений).
3. При запуске приложения AppsFlyer собирает необходимую информацию и может атрибутировать открытие приложения поисковой системе пользователя.
4. Если у пользователя не установлено приложение, он попадает на целевую веб-страницу, где можно использовать любое из нескольких решений AppsFlyer Web-to-app (например, Smart Banners, Smart Script или QR-коды) для перенаправления и атрибуции пользователя.

<div id="setup" />

## Настройка

**Необходимые условия**:

* AppsFlyer Android SDK V6.12.1
* AppsFlyer iOS SDK V6.12.1

**Чтобы настроить атрибуцию к органическому поиску**:

1. Попросите разработчиков включить открытие приложения, следуя инструкциям для <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_android_init_setup#app-opening-methods">Android App Links</Anchor> и <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_ios_init_setup#app-opening-methods">iOS Universal Links</Anchor> (с использованием домена верхнего уровня приложения).
2. В AppsFlyer в боковом меню выберите **Настройки** > <Anchor target="_blank" href="/marketers/ru/docs/app-settings">Настройки приложений</Anchor> и включите:
   * **Атрибуция повторного вовлечения мобильного приложения из SEO (органического поиска) и AEO.**
   * **атрибуцию повторного вовлечения**.

> 📘 **Note**
>
> **Примечание для разработчика**
>
> performOnDeepLinking принудительно импортирует и разрешает URL диплинка при вызове. Это помешает корректной работе функции атрибуции SEO, и в результате атрибуция не будет передаваться в правильный медиаисточник SEO.

<div id="data-availability" />

## Доступность данных

Данные представлены следующим образом:

* В агрегированных данных на дэшбордах и в отчетах поле `media_source` указывает, из какой поисковой системы пришел пользователь. Пример: `google_organic_seo`.
* в отчетах по необработанным данным:
  * Поле `media_source` указывает, из какой поисковой системы пришел пользователь. Пример: `google_organic_seo`.
  * Поле `http_referrer` содержит базовый URL страницы результатов поиска, с которой пользователь был направлен в приложение или на мобильную целевую страницу.
  * Поле `channel` имеет значение `seo` для органического трафика из поисковых систем или `aeo` для трафика из ИИ-систем ответов.

## Дополнительные сведения

<Accordion title="Список поддерживаемых поисковых систем">

Атрибуция органического поиска поддерживает следующие поисковые системы:

* Google
* Bing
* Yahoo
* Ask
* DuckDuckGo
* Яндекс
* Naver
* Daum
* Baidu
* Ecosia
* Coccoc
* Sogou
* Yahoo Япония

> 📘 **Note**
>
> Для других поисковых систем используйте устаревшее решение по атрибуции органического поиска (требует участия разработчика).
>
> На дэшбордах и в отчетах о данных поисковые системы отображаются как `<поисковая система>`\_organic\_seo. Например, google\_organic\_seo.

</Accordion>

<Accordion title="Список поддерживаемых AI-движков ответов">

Атрибуция органического поиска также поддерживает следующие AI-движки ответов:

* ChatGPT
* Claude
* Perplexity
* Manus
* Copilot
* Gemini
* Grok
* Deepseek

> 📘 **Note**
>
> На дэшбордах и в отчетах по данным AI-движки ответов отображаются как `<AI engine>`\_organic\_aeo. Например: chatgpt\_organic\_aeo.

</Accordion>

<Accordion title="Часто задаваемые вопросы">

<Accordion title="Взимается ли дополнительная плата за атрибуцию органического поиска?">

Нет, эта функция включена в подписку.

</Accordion>

<Accordion title="Считаются ли органические SEO-конверсии частью моего пакета?">

Да, так же, как и неорганические конверсии.

</Accordion>

<Accordion title="Можно ли настроить имя медиа-источника SEO?">

№ AppsFlyer определяет имя медиаисточника для organic SEO, и на данный момент его нельзя настроить.

</Accordion>

<Accordion title="Если поисковая система отображает кнопку установки рядом с результатами органического поиска, а пользователь нажимает ее и переходит в магазин приложений, атрибутирует ли AppsFlyer установку к поисковой системе?">

№ В этом случае AppsFlyer не может собрать необходимую информацию для атрибуции. Для атрибуции органического поиска требуется, чтобы приложение уже было установлено.

</Accordion>

<Accordion title="Доступны ли данные по ключевым словам?">

Данные по ключевым словам недоступны в данном решении для атрибуции органического поиска. Однако в редких случаях данные о ключевых словах доступны для Android. См. <Anchor target="_blank" href="/marketers/ru/docs/evaluate-keyword-data#ключевые-слова-android">доступность данных по ключевым словам для Android</Anchor>.

</Accordion>

<Accordion title="Поддерживается ли атрибуция органического поиска в потоке установки?">

Да, вы можете узнать, с какой страницы пользователи, установившие ваше приложение, попали на ваш сайт.

Smart Script делает это следующим образом:

* Собирает домен URL-адреса страницы, называемый веб-реферером
* Создает соответствующий `pid` (позже он отображается как медиаисточник) на основе конкретного источника пользователя
* Сопоставляет его с выбранным вами ключом параметра, например `af_sub1`, в исходящем URL-адресе

Чтобы узнать, как настроить Smart Script для сбора веб-реферера, см. <Anchor target="_blank" href="/marketers/ru/docs/set-up-smart-script-to-convert-web-visitors#seo-referrer-mapping">руководство по настройке OneLink Smart Script V2</Anchor>.

</Accordion>

</Accordion>
