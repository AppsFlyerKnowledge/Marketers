> **Краткий обзор.** Поймите разницу между органическими и неорганическими установками.

![6453OrganicvsNon-organic.jpg](https://files.readme.io/b456433d858a146187429d0a40c200327af685490ea003cd5130f40ad798c7a4-360018880878.jpg)

Неорганические пользователи атрибутируются медиа-источнику, способствующему установке или вовлечению. В случае с органическими пользователями не существует медиа-источника, который был бы связан с установкой или вовлечением.

## Органические и неорганические

| Органические установки  <br />Не атрибутируются медиа-источникам | Неорганические установки (NOI)  <br />Атрибутируются медиа-источникам |
| --- | --- |
| **Не атрибутированы**, медиа-источник отсутствует | **Атрибутированы** медиа-источнику |
| **Атрибуция отсутствует** по следующим причинам:<ul><li>Приложение было установлено без использования ссылки атрибуции. Например, когда пользователь загружает приложение с вашего сайта или из магазина приложений без предварительного просмотра рекламы.</li><li>Не удалось сопоставить клик и запуск приложения. Например, если данные недоступны из-за политики конфиденциальности или установка сначала была атрибутирована другим MMP.</li></ul> | **Атрибуция** установки или запуска по любой из следующих причин:<ul><li>Использование ссылки атрибуции AppsFlyer</li><li>Клик и запуск сопоставлены AppsFlyer</li><li>Заявлено SRN</li></ul> |
|  | **Информация об атрибуции:**<ul><li>Используется *атрибуция по последнему клику:* Последнее взаимодействие с рекламой определяется как способствующее установке приложения или действию.</li><li>Для каждой установки может быть определен только один медиа-источник.</li><li>Подробнее об <Anchor target="_blank" href="/marketers/ru/docs/appsflyer-attribution-model">атрибуции AppsFlyer</Anchor></li></ul> |
