> **Краткий обзор:** Изучите основные типы медиаисточников в AppsFlyer.

Медиаисточник — это сущность, которая показывает рекламу. Медиаисточник -- это ресурс, на котором размещается реклама Платформа AppsFlyer позволяет фиксировать атрибуцию от различных типов медиаисточников.

| Тип медиаисточника | Описание |
| --- | --- |
| <Anchor target="_blank" href="/marketers/ru/docs/self-reporting-networks-srns">Сеть с самостоятельной отчетностью (SRN)</Anchor> | <ul><li>Обеспечьте подтверждение атрибуции и подробную информацию через API между AppsFlyer и сетью.</li><li>Примеры: Meta реклама, Google, Apple Search Ads</li></ul> |
| Не-SRN | <ul><li>Предоставьте информацию об атрибуции, содержащуюся в URL клика.</li><li>Также известны как <Anchor target="_blank" href="/marketers/ru/docs/set-up-an-integrated-partner">сети с поддержкой ссылок атрибуции</Anchor> или рекламные сети.</li><li>Примеры: Unity Ads, Tapjoy, Applovin</li></ul> |
| Собственные медиа | <ul><li>Собственные медиа используют для кампаний <Anchor target="_blank" href="/marketers/ru/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">ссылки OneLink</Anchor>.</li><li>Примеры: Электронная почта, СМС, социальные сети, лендинги, QR-коды и т.п.</li></ul> |
