> **Краткий обзор:** Получите подробные данные о ключевых словах, которые позволяют вам увидеть, какие поисковые запросы наиболее популярны, чтобы вы могли оптимизировать органические конверсии.

## Данные ключевых слов

Органический поиск является ценным источником трафика для ваших приложений. Органические пользователи не несут затрат на привлечение и, как правило, входят в число самых вовлеченных когорт.

С несколькими изменениями на странице вашего приложения возможно увеличить количество новых органических установок. Чтобы оптимизировать органические поиски, вам нужно получить данные об органических ключевых словах для вашего приложения.

### ключевые слова iOS

Если вы работаете с Apple Search Ads, вы можете получить подробные данные о ключевых словах для ваших неорганических пользователей, атрибутированных Apple Search Ads. В iOS данные об органических ключевых словах недоступны.

### Ключевые слова Android

Google делится данными об органических ключевых словах (по URL-адресу реферера) для пользователей, которые делают следующее:

* Используйте устройства Android
* Используйте браузер Chrome
* Посетите Google.com и выполните поиск
* Установите приложение со страницы результатов Google
* Запустите приложение.

SDK извлекает ключевые слова, когда они предоставлены Google в параметре &utm\_term реферера, если он является частью ссылки на Google Play. Значения, где это возможно, содержатся в следующих полях необработанных данных AppsFlyer: http\_referrer, gp\_broadcast\_referrer, keywords.

Ожидайте, что менее 1% органических пользователей Android следуют этой воронке и имеют данные по органическим ключевым словам.

В других сценариях Google не делится данными о органических ключевых словах. Например, пользователи, ищущие в Google Play, не имеют органических данных по ключевым словам.

> 📘 **Примечание:**
>
> Это ограничение применяется Google ко всем внешним поставщикам, включая всех поставщиков атрибуции.

### Используя данные ключевых слов

Органические данные по ключевым словам находятся в следующем:

* Сырые органические данные отчеты  
  В AppsFlyer в боковом меню выберите Отчет > Экспорт необработанных данных, чтобы просмотреть разбивку использованных органических ключевых слов.
* Расширенные отчеты   
  Перейдите к отчетам по сводным таблицам, удержанию и когортам и сгруппируйте по ключевым словам.  
  Сравните качество органических пользователей на основе их ключевых слов.
* Сообщения <Anchor target="_blank" href="/marketers/ru/docs/push-api-streaming-raw-data">Push API</Anchor>

### Тестирование данных органических ключевых слов

1. Используйте устройство Android из <Anchor target="_blank" href="/marketers/ru/docs/registering-test-devices">списка разрешённых</Anchor>.
2. Откройте браузер Chrome и перейдите на Google.com.
3. Используйте сильное ключевое слово для поиска вашего приложения.   
   Этот пример использует "отели сегодня вечером".
