> **Краткий обзор.** Узнайте, что такое атрибуция мобильной рекламы и как AppsFlyer помогает маркетологам точно определять цели для таргетинга, оптимизировать расходы на рекламу и повышать рентабельность инвестиций.

<div id="what-is-app-attribution" />

## Что такое атрибуция приложений?

С точки зрения мобильных приложений, атрибуция **определяет, какие кампании, партнеры и каналы обеспечили установки приложения** и события после установки, например, покупки в приложении. Маркетологи используют эти аналитические данные для измерения и повышения эффективности своих действий в рамках кампаний по привлечению пользователей и ретаргетинговых кампаний.

## Первый вход в систему

При первом создании пользователя по электронной почте приходит приглашение активировать аккаунт. После активации вы можете войти в систему, и аккаунт станет активным. Обратите внимание, что ссылка на активацию действительна в течение 48 часов.

<Image alt="login page.png" src="https://files.readme.io/a55e3d6281c58eea9075a7f8a2b5eb558679d620fc2e66637d7c046afeeaad5a-51073385138705.png" width="322px" />

Есть несколько способов входа в аккаунт AppsFlyer:

* Использование учетных данных: Email и пароль
* Вход в систему через Google: Вход в систему с помощью аккаунта Google
* <Anchor target="_blank" href="/marketers/ru/docs/set-up-sso-authentication-with-your-identity-provider-idp">Вход через SSO</Anchor>

<div id="note" />

> 📘 **Примечание**
>
> Если администратор настроил для вашего аккаунта двухфакторную аутентификацию<Anchor target="_blank" href="/marketers/ru/docs/implementing-and-using-2fa-login">(2FA</Anchor>), вам будет предложено подтвердить вход в систему с помощью другого метода аутентификации.

<div id="using-multiple-accounts" />

## multiple accounts.png

Пользователи могут состоять в нескольких аккаунтах с разными ролями и разрешениями. Они могут переключаться между своими аккаунтами без необходимости повторного ввода учетных данных.

<div id="note-1" />

> 📘 **Примечание:**
>
> * Переключение между аккаунтами и смена основного аккаунта поддерживаются для всех способов входа в систему: по имени пользователя и паролю, с 2FA и через единый вход (SSO). Для переключения также требуется 6-значный код подтверждения, отправленный на электронную почту пользователя, независимо от используемого способа входа в систему.
> * На этом этапе переключение между аккаунтами доступно только для аккаунтов рекламодателей.

<div id="primary-account" />

### Основной аккаунт

Основной аккаунт — это исходный аккаунт, который был создан первым и используется как аккаунт для входа в систему по умолчанию. Войдя в один аккаунт, вы сможете переключиться на другой.

<Image alt="primary-account1.jpg" src="https://files.readme.io/8f1d88543b4797b584fa781bf2dd2563ed91f6eaff45393b186d8da98ccc0c33-51073397865233.jpg" width="672px" />

**Для переключения между аккаунтами:**

1. В строке меню выберите **раскрывающийся список с адресом электронной почты** > **Переключить аккаунт**.
2. Откройте список своих аккаунтов: выберите **Все аккаунты (x)**, где x – общее количество аккаунтов.
3. В диалоговом окне **Мои аккаунты** кликните значок меню с 3 точками для аккаунта, который нужно сделать основным, затем выберите **Сделать основным**. Сообщение подтверждает смену аккаунта.

<div id="switch-between-accounts" />

### Переключение между аккаунтами

1. Выйдите из текущего аккаунта: в строке меню нажмите на **выпадающий список под адресом эл. почты** > **Выйти из аккаунта**.  
   <Image alt="image (73).png" src="https://files.readme.io/b9aaf81a586da0240bb3813a0ad416ac1cf5badc0f976ddc0156e1bd798036df-51074002494481.png" width="313px" />
2. Войдите в систему и выберите другой аккаунт из списка связанных аккаунтов.  
   <Image alt="image (74).png" src="https://files.readme.io/7ff19bd9db1b1f72e06b594ce536200cd6139a1882e56e72877200542944d6f8-51074002495505.png" width="75%" />
3. Введите 6-значный код подтверждения, отправленный на ваш адрес электронной почты.  
   <Image alt="image (769).png" src="https://files.readme.io/ccb2c3e8f8724f95e6ec265697b3851efeaf33ff6aabde4599e3d17c57949a44-51074002496017.png" width="75%" />
4. Нажмите «Сменить аккаунт».   
   <Image alt="image (75).png" src="https://files.readme.io/81e6f17ed80eddcc1d3e55ca9336ed62b82fd1c6694a30a347ba24ae8bed57e4-51074025826705.png" width="75%" />

<div id="note-2" />

> 📘 **Примечание:**
>
> Код подтверждения действителен в течение 15 минут и может быть использован только один раз.
