> **At a glance:** **Вкратце:** При тестировании атрибуции зарегистрируйте ваше тестовое устройство, чтобы убедиться, что каждая установка фиксируется как новая. Зарегистрированное тестовое устройство предотвращает регистрацию установок как переустановок.

<div id="why-register-a-test-device" />

## Почему нужно регистрировать тестовое устройство

При тестировании атрибуции Окно re-attribution ограничивает атрибуцию установки до одной на 90-дневное окно. Поэтому, при многократном использовании одного и того же устройства для проверки атрибуции установок, ничего не регистрируется. Регистрация устройства в качестве тестового предотвращает фиксацию повторных установок как переустановок.

<div id="methods-for-registering-a-test-device" />

## Методы регистрации тестового устройства

Регистрация тестового устройства включает выбор операционной системы устройства (Android, iOS или Windows) и добавление идентификатора устройства.

Вы можете воспользоваться одним из следующих методов для регистрации:

* [Загрузите и установите приложение My идентификатор устройства от AppsFlyer:](#register-a-device-using-the-appsflyer-device-id-app-admin-only) После установки приложения на тестовое устройство вы сможете автоматически зарегистрировать устройство и поделиться его идентификатором в вашей учетной записи AppsFlyer. Устройство будет автоматически добавлено на страницу **Тестовые устройства**.

> 📘 **Note**
>
> * На тестовых устройствах iOS 14+ данный метод регистрации можно использовать только в том случае, если в приложении реализована функция AppTransparency Tracking (ATT) и вы хотите запускать тесты в качестве пользователя, давшего согласие на сбор данных. В противном случае используйте ручной метод.
> * Если в вашей учетной записи AppsFlyer включена двухфакторная аутентификация (2FA), вы не сможете регистрировать тестовые устройства с помощью приложения, поскольку приложение не поддерживает аутентификацию с 2FA. В этом случае используйте ручной метод регистрации тестовых устройств.

* [Вручную добавьте тестовое устройство:](#register-a-device-manually) Любой пользователь учетной записи может напрямую зарегистрировать тестовое устройство, добавив его идентификатор на страницу **Тестовые устройства**.

Имейте в виду следующее:

* Зарегистрированные тестовые устройства доступны для всех приложений, принадлежащих к учетной записи.
* Рекламные сети должны попросить рекламодатели добавить устройства; агентства могут добавлять свои собственные устройства.

<Accordion title="Поддерживаемые идентификаторы устройств">

Идентификаторы устройств включают в себя следующее:

* **Android:** AID (GAID или OAID), IMEI, идентификатор Android

> 📘 **Note**
>
> При регистрации тестового устройства добавлять идентификаторы IMEI или идентификатор Android следует только в том случае, если ваше Приложение собирает и использует эти идентификаторы.

* **iOS:** IDFA, IDFV
* **Windows Phone:** рекламный идентификатор Windows

</Accordion>

<Accordion title="Зарегистрируйте устройство вручную">

Пользователи учетной записи могут вручную зарегистрировать устройство:

1. В AppsFlyer в боковом меню выберите **Настройки** -> **Тестовые Устройства**.
2. Выберите **Тестовые устройства**.
3. Нажмите **+ Добавить устройство**.

   [<Image alt="" src="https://files.readme.io/e28ef06002e423d4cf7863d4c7fd2b269a0ede5c4b996a50cee25ffbedfcd9d1-31773630618769.png" width="50%" />](https://files.readme.io/e28ef06002e423d4cf7863d4c7fd2b269a0ede5c4b996a50cee25ffbedfcd9d1-31773630618769.png)
4. Выполните следующее:
   * **Имя (используйте только английские буквы):** Введите уникальное имя для устройства.
   * **ОС:** Выберите операционную систему.
   * **Тип идентификатора устройства:** Выберите идентификатор устройства.
   * **Идентификатор устройства:** Укажите идентификатор устройства в соответствии с операционной системой:

     Как получить идентификаторы IDFA или IDFV:

     * **IDFA:** Чтобы получить IDFA, установите Приложение AppsFlyer для идентификаторов устройства на свое тестовое устройство. Чтобы узнать, как это сделать, смотрите: [Добавьте устройство](#register-a-device-manually) с помощью Приложения AppsFlyer для идентификаторов устройства (только администратор) выше.
     * **IDFV:** Чтобы получить IDFV, попросите разработчика установить тестовое Приложение для IDFV на ваше тестовое устройство. После установки и запуска Приложение отобразит IDFV. **Примечание:** Инструмент тестирования можно установить только после выполнения предварительных шагов в X-Code разработчиком.

     Чтобы узнать, когда использовать IDFA или IDFV, см. раздел [Регистрация тестового устройства iOS](#регистрация-тестового-устройства-ios).

5. Нажмите **Сохранить**. Устройство отображается в списке зарегистрированных устройств. **Примечание**: Хотя устройство отображается в списке зарегистрированных сразу, регистрация в системе и начало работы могут занять несколько минут.

> 📘 **Note**
>
> **Добавление нескольких идентификаторов**
>
> Могут быть случаи, когда необходимо добавить более одного идентификатора на тестовое устройство, например, чтобы иметь и идентификатор IDFA, и идентификатор IDFV на одном устройстве.
>
> **Для добавления дополнительного идентификатора:**
>
> 1. Нажмите **Добавить устройство**.
> 2. Используйте то же имя для тестового устройства и добавьте второй идентификатор.
> 3. Нажмите **Сохранить**.

</Accordion>

<Accordion title="Снять регистрацию устройства">

На одну учетную запись можно зарегистрировать до 200 устройств.

**Для удаления устройства из списка:**

1. В AppsFlyer в правом верхнем углу нажмите на свой адрес электронной почты.
2. Выберите **Тестовые устройства**.
3. Нажмите на значок удаления, чтобы удалить устройства.

</Accordion>

## Регистрация тестового устройства iOS

Блок-схема ниже демонстрирует возможные шаги при регистрации тестовых устройств iOS.

[![](https://files.readme.io/214818cd73ebc8cd5d3479d27e3074fec55ec7f9e3d4702b17f3c8811270f54e-31773630621585.png)](https://files.readme.io/214818cd73ebc8cd5d3479d27e3074fec55ec7f9e3d4702b17f3c8811270f54e-31773630621585.png)

При регистрации тестового устройства iOS выберите один из следующих вариантов:

<Accordion title="Зарегистрируйте ваше тестовое устройство с помощью идентификатора IDFA">

<div id="when-to-use-idfa-for-test-device-registration" />

#### **Когда использовать идентификатор IDFA для регистрации тестового устройства?**

Вы можете зарегистрироваться в IDFA, если в вашем приложении внедрено отслеживание AppTransparency (ATT) и вы хотите проводить тесты в качестве согласного пользователя. При первом запуске тестируемого приложения обязательно нажмите **Разрешить** в запросе ATT.

<div id="how-to-register-your-test-device-with-an-idfa" />

#### **Как зарегистрировать тестовое устройство с IDFA?**

Чтобы зарегистрироваться с IDFA, зарегистрируйте устройство, используя Приложение AppsFlyer с идентификатором устройства.

</Accordion>

<Accordion title="Зарегистрируйте тестовое устройство с IDFV">

<div id="when-to-use-idfv-for-test-device-registration" />

#### **Когда использовать IDFV для регистрации тестового устройства?**

Когда IDFA недоступен, IDFV - ваш единственный вариант. В следующих случаях вам **необходимо использовать IDFV**:

* **ATT был внедрен**, но вы хотите запускать (программу) тесты в режиме пользователя без согласия. При первом запуске Приложения обязательно нажмите **Не разрешать** в уведомлении ATT.
* **ATT вообще не был внедрен**.

<div id="how-to-register-your-device-with-idfv" />

#### **Как зарегистрировать устройство с IDFV**

1. Прежде чем вы сможете зарегистрировать тестовое устройство с IDFV, ваш разработчик должен установить тестовое Приложение IDFV на вашем тестовом устройстве. Для получения инструкций для разработчика обратитесь к <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/install-the-idfv-test-tool-app">этой статье</Anchor>.
2. После того как ваш разработчик установил тестовое Приложение IDFV, запустите его и скопируйте отображаемый IDFV.
3. [Зарегистрируйте тестовое устройство вручную](#register-a-device-manually) с помощью IDFV.

> 📘 **Note**
>
> **Зачем устанавливать приложение для тестирования IDFV?**
>
> * Инструмент тестирования IDFV используется для извлечения IDFV, необходимого для регистрации тестового устройства.
> * Если на вашем тестовом устройстве не установлено другое Приложение из вашей учетной записи разработчика. В этом случае iOS назначает новый идентификатор поставщика каждый раз при переустановке Приложение. Поскольку тестирование во многих случаях предполагает переустановку приложения, каждая переустановка приводит к тому, что iOS сбрасывает IDFV. **Утилита, выдавая себя за производителя, не позволяет iOS создавать новый IDFV при каждой переустановке приложения на тестовом устройстве.**

</Accordion>

<Accordion title="Тестирование с незарегистрированным устройством">

Используйте эту опцию только если не можете зарегистрировать тестовое устройство ни с IDFA, ни с IDFV. В этом случае для Атрибуции используется вероятностное моделирование. Каждая установка регистрируется как новая установка на тестовом устройстве. Этот метод может помогать в регистрации повторных тестовых установок на одном устройстве, если выполняется хотя бы одно из следующих условий:

* Используется версия AppsFlyer iOS SDK (пакет средств разработки ПО) 6.8.0 или ниже.
* Для Приложения отключено обнаружение повторных установок (не рекомендуется для активных Приложений).
* Тестовая ссылка атрибуции содержит `is_retargeting="true"`. В этом кейсе установки регистрируются как реатрибуции и доступны в дэшборде ретаргетинга и в Отчетах о необработанных данных ретаргетинга.
* Только для iOS: Чтобы Protect360 не помечал клики как мошеннические, добавьте параметр запроса `pid="ios_testing"` в тестовую ссылку атрибуции.

</Accordion>
