> **Краткий обзор.** Если у вас приложение для бронирования отелей, регистрация следующих внутренних событий позволит измерять качество пользователей на протяжении всего их пути.

<div id="-hotel-booking" />

## <Image alt="InApp_Events_hotel.png" src="https://files.readme.io/ffc23cc65b6b6cfe99c12e988cca3df6667058b7e3a672db3639472a17602546-20659548553745.png" width="100px" /> Бронирование отелей

С помощью приложений для бронирования отелей путешественники могут выбрать самые лучшие предложения и легко воспользоваться ими. Мы рекомендуем регистрировать такие внутренние события, как поиск, покупка, бронирование поездки и добавление в список желаний.

Регистрация событий поможет вам определить:

* Какие кампании и медиа-источники привлекают пользователей, которые действительно бронируют отели на время отпуска.
* Какие кампании и медиа-источники привлекают пользователей, которые чаще бронируют и приносят больше дохода.

Предпочтения, такие как оценка отеля, сезон, страна и количество детей, можно атрибутировать пользователям, привлеченным определенными медиа-источниками. Затем вы можете оптимизировать кампании, ориентируясь на выявленные предпочтения.

## Рекомендуемые структуры для предопределенных событий

В следующем разделе представлен список структур для событий, характерных для вертикали бронирования отелей. В каждую структуру входят предопределенное название события и рекомендуемые параметры события. Обратите внимание, что внутренние события приложения могут содержать любые параметры событий, отвечающие потребностям вашего бизнеса.

<div id="complete-registration-af_complete_registration" />

<Accordion title="Завершение регистрации (af_complete_registration)">

**Цель**

Узнать, сколько пользователей установило приложение и зарегистрировалось, какие способы регистрации предпочитают пользователи, какие медиа-источники привлекают пользователей, которые действительно регистрируются.

**Триггер**

Пользователь завершает процесс регистрации.

Параметры события

| Имя поля | Описание | Пример значения |
| --- | --- | --- |
| af\_метод\_регистрации | Тип способа регистрации | email, Facebook |

</Accordion>

<div id="login-af_login" />

<Accordion title="Авторизация (af_login)">

**Цель**

Проанализировать метрику удержания зарегистрированных пользователей.

**Триггер**

Успешный вход пользователя в систему.

**Параметры события**

Можно отправлять без каких-либо дополнительных параметров.

</Accordion>

<div id="search-af_search" />

<Accordion title="Поиск (af_search)">

**Цель**

Узнать, что ищут пользователи, какие результаты поиска наиболее релевантны и приводят к покупкам. Кроме того, можно узнать, что ищут пользователи из конкретных стран и городов и таргетироваться на них соответствующим образом по медиа-источникам.

**Триггер**

Пользователь выполняет поиск.

**Параметры события**

| Имя | Описание | Пример значения |
| --- | --- | --- |
| af\_date\_a | Дата приезда | 2018.07.26 |
| af\_date\_b | Дата отъезда | 01.08.2018 |
| af\_destination\_a | Местоположение пользователя | London |
| af\_destination\_b | Местонахождение отеля | Мадрид |
| af\_num\_adults | Количество гостей | 2 |
| af\_num\_children | Количество детей | 0 |

</Accordion>
