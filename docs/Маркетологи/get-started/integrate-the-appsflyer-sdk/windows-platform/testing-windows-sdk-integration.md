> **Краткий обзор:** Протестируйте интеграцию вашего приложения Windows с AppsFlyer.

* В настоящее время Windows Referrer можно протестировать только одним способом: загрузить приложение в Windows App Store.
* При тестировании с Windows Referrer необходимо учитывать следующие ограничения:
  * Вы должны войти в магазин.
  * На вашем устройстве не должно быть установлено Windows 10 Anniversary Update.
  * На вашем устройстве приложение никогда не должно было быть установлено (реферер Windows действует бессрочно: даже если вы внесены в белый список или прошло более 90 дней, вы не получите атрибуцию по рефереру).

## Тестировать интеграцию SDK

1. Интеграцию SDK необходимо тестировать на зарегистрированном тестовом устройстве. Чтобы зарегистрировать тестовое устройство, выполните действия, описанные <Anchor target="_blank" href="/marketers/ru/docs/registering-test-devices">здесь</Anchor>.
2. Откройте дэшборд AppsFlyer и выберите приложение, которое вы тестируете.
3. Выберите в меню навигации пункт SDK Integration Tests.
4. Вам будут предложены три варианта тестирования:

* Неорганическая установка
* События в приложении
* Диплинкинг

## Тестирование неорганической установки

1. Выберите в раскрывающемся списке одно из своих зарегистрированных устройств
2. Выберите источник установки приложения (Windows Store или Other)
3. Отсканируйте сгенерированный QR-код с помощью зарегистрированного тестового устройства и следуйте инструкциям на устройстве.
4. Дождитесь регистрации неорганической установки на странице Integration Test — это означает, что тест прошел успешно. Это может занять до двух минут. Если к этому времени приложение не зарегистрирует неорганическую установку, см. руководство по устранению неполадок, отображаемое на странице Integration Test.

## Тестирование внутренних событий приложения.

1. Выберите одно из своих зарегистрированных тестовых устройств в раскрывающемся меню и нажмите «Далее».
2. Откройте свое приложение и начните создавать в нем внутренние события.
3. Вы увидите журнал этих событий, поскольку они регистрируются в режиме реального времени.

## Тестирование диплинкинга

1. Чтобы протестировать диплинкинг, для вашего приложения должен быть настроен OneLink. См. <Anchor target="_blank" href="/marketers/ru/docs/create-a-onelink-template">руководство по OneLink</Anchor>
2. Выберите одно из своих зарегистрированных тестовых устройств в раскрывающемся меню и нажмите «Далее».
3. Отсканируйте QR-код с помощью зарегистрированного тестового устройства и следуйте инструкциям, которые будут отображаться на вашем устройстве.
4. Дождитесь, пока диплинк будет успешно зарегистрирован на странице Integration Test.
