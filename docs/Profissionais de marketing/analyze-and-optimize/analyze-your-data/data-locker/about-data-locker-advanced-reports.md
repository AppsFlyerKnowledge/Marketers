> **At a glance:** Os relatórios avançados fornecem dados consolidados, tipados e nomeados de forma consistente em nível de evento em plataformas mobile, web e connected TV (CTV) em um único relatório, para que você gaste menos tempo preparando dados e mais tempo usando-os.

## Sobre os Relatórios Avançados

As seções abaixo explicam como os relatórios avançados consolidam dados por produto, chegam prontos para usar sem preparação adicional e permitem que você controle exatamente o que cada relatório retorna.

### Dados consolidados por produto de dados

Os Relatórios Avançados organizam dados brutos em nível de evento em torno de produtos de dados.

* Cada relatório abrange um produto de dados completo, portanto não há arquivos fragmentados para unir.
* Os dados de mobile, web e CTV ficam em um único arquivo com um esquema compartilhado.

### Dados prontos para uso

Os relatórios legados retornavam todos os campos como strings simples com nomenclatura inconsistente, exigindo que as equipes fizessem conversão de tipos, renomeassem campos e reconciliassem esquemas antes que a análise pudesse prosseguir. Os Relatórios Avançados já incluem a preparação fundamental:

* **Campos tipados:** inteiros, booleanos, carimbos de data/hora e enums, em vez de strings simples.
* **Esquema unificado:** estrutura consistente e validada em todos os produtos de dados.
* **Nomes de campos autoexplicativos:** nomeados de forma consistente e autoexplicativos em todos os relatórios, facilitando o trabalho com os dados diretamente em ferramentas de BI (business intelligence), fluxos de trabalho de analistas e aplicativos com tecnologia de IA.

### Controle preciso sobre o que você recebe

Os Relatórios Avançados permitem adaptar cada relatório exatamente às suas necessidades, sem nenhum pós-processamento:

* **Personalização do esquema:** adicione ou remova campos para atender aos seus requisitos posteriores.
* **Filtros no nível do relatório:** limite os dados a uma plataforma, tipo de conversão, país ou evento específicos.
* **Modelos pré-criados:** comece instantaneamente com configurações de campos e filtros criadas para casos de uso comuns.

## Relatórios Avançados vs. relatórios legados

A tabela abaixo destaca as principais diferenças entre os Relatórios Avançados e os relatórios legados.

|  | Relatórios legados | Relatórios avançados |
| --- | --- | --- |
| **Estrutura de dados** | Fragmentada em vários relatórios | Consolidada, um relatório cobre todo o produto de dados |
| **Tipos de campo** | Todos os campos são entregues como strings simples | Campos tipados: inteiros, booleanos, carimbos de data/hora, enums |
| **Nomes dos campos** | Nomenclatura inconsistente entre relatórios; não otimizada para legibilidade | **Autoexplicativos**, nomes consistentes em todos os relatórios |
| **Esquema** | Inconsistente; estrutura variada entre relatórios | Esquema unificado e validado em todos os produtos de dados |
| **Cobertura de plataformas** | Relatórios separados por plataforma, com esquemas diferentes | Mobile, web e CTV consolidados em um único relatório com um esquema comum |
| **Classificar** | Seleção básica de filtros | Filtros de seleção múltipla no nível do relatório para várias dimensões, além de modelos prontos para casos de uso comuns |
| **Prontidão para IA e BI** | Exigia conversão de tipos, alinhamento de esquema, normalização de campos e renomeação de campos | Tipados, validados e nomeados de forma consistente, com nomes de campo **autoexplicativos** fáceis de interpretar tanto por humanos quanto por aplicações com tecnologia de IA |

## Relatórios disponíveis

Cada relatório corresponde a um Produto de dados, um conjunto de dados selecionado e estruturado que representa um domínio específico dos seus dados de marketing, como conversões, engajamentos ou eventos de usuário. Os seguintes relatórios estão disponíveis hoje.

Ele oferece uma visão unificada das interações do usuário com seus anúncios, com suporte à análise aprofundada da performance do topo do funil, à avaliação de criativos e canais e à otimização de custo e alcance no nível de engajamento.

</Accordion>

<Accordion title="Conversões">

Ao centralizar os dados de conversão, você pode realizar uma análise completa de Growth usando um único conjunto de dados simplificado e mensurar e otimizar com precisão a performance de marketing.

* **Plataformas:** mobile, web, CTV
* **Atualização dos dados:** 1–3 horas

## Modelos de relatório

Os modelos são predefinições de relatório pré-configuradas, projetadas para casos de uso comuns. Cada modelo está associado a um produto de dados específico e vem pré-carregado com os campos e filtros mais relevantes para os casos de uso comuns desse relatório. Ao selecionar um modelo, os campos e filtros corretos são carregados automaticamente. Você pode editar o nome pré-preenchido do relatório antes de salvar.

Depois de salvo, um relatório baseado em modelo é totalmente independente. As alterações no modelo não afetam os relatórios que já foram salvos a partir dele.

Os seguintes modelos predefinidos estão disponíveis:

| Nome do template | Relatório | Descrição |
| --- | --- | --- |
| **Conversões na web** | Conversões | Âncoras de atribuição para web, incluindo primeiras visitas, revisitas e eventos de aquisição de usuários. Todos os eventos de usuário posteriores herdam os detalhes da campanha dessas conversões. |
| **Eventos web** | Eventos de usuários finais | Todos os eventos e sessões na web. Use este relatório como principal para análises no nível de visita e no nível de evento. |

## Filtros no nível do relatório

Os filtros no nível do relatório permitem restringir um relatório a um subconjunto específico de dados, por exemplo, uma plataforma, um tipo de conversão ou um país específico.

O conjunto de filtros disponíveis depende do Produto de dados. A tabela abaixo mostra quais filtros são suportados em cada relatório. Filtros adicionais serão adicionados ao longo do tempo.

| Relatório | Filtros disponíveis |
| --- | --- |
| **Conversões** | Tipo de conversão, país, grupo de plataformas, plataforma, canal de mídia e aplicativo |
| **Engajamentos** | Tipo de campanha, tipo de engajamento, país, canal de mídia e aplicativo |
| **Eventos de usuários finais** | Nome do evento, grupo de plataformas, tipo de conversão, país, atribuição primária, canal de mídia e aplicativo |
| **Eventos de usuário final entre plataformas** | Nome do evento, Grupo de plataformas, Tipo de conversão, País, É atribuição primária, Canal de mídia e Aplicativo |
