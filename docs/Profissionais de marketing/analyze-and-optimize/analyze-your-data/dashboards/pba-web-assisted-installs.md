> **Visão geral:** use o dashboard de instalação auxiliada pela web do PBA para entender o impacto de seus esforços de marketing na web sobre as instalações do aplicativo mobile e para melhorar o desempenho das campanhas na web.

## Análise de instalações auxiliadas pela web

Instalações assistidas pela web medem o impacto dos esforços de marketing da web para impulsionar os usuários a instalar um aplicativo. Os anunciantes visualizam o envolvimento da web no contexto do evento de instalação; eles podem determinar a fonte de mídia que direcionou os visitantes do site para a instalação do aplicativo. Os melhores resultados nas instalações assistidas pela web são alcançados se você definir o CUID no aplicativo e no <Anchor target="_blank" href="/marketers/pt/docs/onboarding-guide-to-people-based-attribution#2">site.</Anchor> 

<div id="web-assisted-installs-headline-metrics" />

### Métricas de título de instalações auxiliadas pela web

As métricas de título exibem o número total de instalações do aplicativo em relação ao número de instalações auxiliadas pelo site, divididas em instalações orgânicas e não orgânicas do aplicativo.

[![WAIHeadline_en-us.png](https://files.readme.io/65310759fd91879aee94495a6ee4736e0e50afa81cfb1935d0f8c2eea6a1d79b-4408021659665.png)](https://files.readme.io/65310759fd91879aee94495a6ee4736e0e50afa81cfb1935d0f8c2eea6a1d79b-4408021659665.png)

Considere os cenários de caso de uso, na tabela a seguir, para a análise de instalações auxiliadas pela web.

| Tipo de instalação | Jornada de instalação | considerações |
| --- | --- | --- |
| Total de instalações | Todas as instalações quem engajam—em algum momento—com uma fonte de mídia da web. | <ul><li>Qual é a contribuição do web marketing em relação a todas as instalações de aplicativos?</li><li>Como os esforços de marketing na web são distribuídos entre fontes de mídia e canais?</li><li>Qual é a contribuição, se houver, dos Smart Banners?</li></ul> |
| instalações orgânicas | O aplicativo é instalado sem o engajamento com uma fonte de mídia mobile. | <ul><li>Qual parte, se houver, de instalações orgânicas é impulsionada puramente pelo tráfego da web?</li><li>Quais são os canais de mídia dominantes?</li><li>Qual é a proporção entre tipos de mídia paga, própria e adquirida?</li></ul> |
| Instalações não-orgânicas | As jornadas do usuário começam na web. O aplicativo é instalado mais tarde depois do engajamento com uma campanha mobile. | <ul><li>Que volume de instalações não orgânicas é influenciado pela web?</li><li>Quais canais e tipos de mídia web influenciam instalações não orgânicas?</li><li>Suas fontes de mídia móvel pagas se sobrepõem às fontes de mídia da web?</li></ul> |

## Dashboard de Instalações Auxiliadas pela Web

**Para acessar o dashboard de Instalações Auxiliadas pela Web:**

| Opção 1 | Opção 2 |
| --- | --- |
| <ol><li>**Meus aplicativos** >**Ver agrupamentos da marca**</li><li>Clique no dashboard PBA.</li><li>Acesse a aba **Instalações auxiliadas pela web**.</li></ol> | <ol><li>Vá para o menu de navegação **People-based attribution** > aba **Instalações Auxiliadas pela Web**</li><li>Saiba mais sobre os outros dashboards PBA: <Anchor target="_blank" href="/marketers/pt/docs/pba-website-attribution-dashboard">Atribuição de sites</Anchor> \| Caminhos de conversão</li></ol> |

<div id="website-assisted-installs-and-reinstalls" />

<Accordion title="Instalações e reinstalações auxiliadas pela web">

![30day_us-en.png](https://files.readme.io/8ed154e962fb82a6381de81b19e7e4da1b258962427ec48a9e2b86ee576958eb-360009706598.png)

As instalações são consideradas como tendo sido influenciadas por um site se ocorrerem dentro de 30 dias após uma visita ao site. Instalações e reinstalações, incluindo redirecionamento de instalações (reatribuições), podem ser orgânicas ou não orgânicas.

Para obter informações sobre a atualização de dados, consulte o <Anchor target="_blank" href="/marketers/pt/docs/about-data-freshness-and-timezone-support#pba-daily">PBA diariamente</Anchor>.

</Accordion>
