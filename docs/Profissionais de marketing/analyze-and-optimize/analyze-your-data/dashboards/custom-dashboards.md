## Dashboards personalizados

Cada dashboard personalizado consiste em um ou mais widgets contendo métricas de aquisição de usuários. Você configura o widget usando o assistente do widget para selecionar métricas, formato de apresentação, aplicativos e outros.

As métricas disponíveis são semelhantes às métricas de visualização de aquisição do usuário do dashboard de visão geral. Atenção! Não compare com a visão geral unificada **nem** com a visualização de retargeting.

Após ser definido, o dashboard fica disponível para todos os usuários da conta.

<div id="dashboard-personalization" />

## Personalização do dashboard

Você pode personalizar um dashboard ao mover e dimensionar widgets.

| Opção de personalização | Descrição |
| --- | --- |
| Redimensionar widget | Arraste o canto inferior direito de um widget para redimensioná-lo |
| Posição do widget | Arraste e solte um widget para alterar sua localização em um dashboard |
| Ações | Passe o mouse sobre um widget no canto superior direito, clique em ações. As seguintes ações estão disponíveis por widget:<ul><li>Editar</li><li>Duplicar</li><li>Excluir</li><li>Exportar CSV</li></ul> |

## Procedimentos

<div id="managing-dashboards" />

<Accordion title="Ações do dashboard">

| Ação | Descrição |
| --- | --- |
| Duplicar | Cria uma cópia do dashboard atual |
| Renomear | Alterar o nome do dashboard |
| Exportar PNG | Cria e baixa um arquivo PNG |
| Excluir | Remover o dashboard |

</Accordion>

<div id="add-a-custom-dashboard" />

<Accordion title="Adicionar um dashboard personalizado">

**Para adicionar um dashboard personalizado:**

1. Na AppsFlyer, no menu lateral, selecione **Analisar**> **Dashboards personalizados**.  
   Um dashboard é exibido.
2. Clique em + (Adicionar novo dashboard).
3. Insira o **Título do seu dashboard**.
4. Clique em **Adicionar**.
5. Adicione um ou mais widgets conforme descrito na seção a seguir.

</Accordion>

<div id="managing-widgets" />

<Accordion title="Gerenciando widgets">

**Para adicionar um widget:**

1. Clique em Adicionar widget.
2. A janela do widget é exibida.

   [![WidgetConfigure_us-en.png](https://files.readme.io/f04544d8cb8b1d946526c4546565fffb405e5113e09dac65e5a28e218a1170a7-360015793618.png)](https://files.readme.io/f04544d8cb8b1d946526c4546565fffb405e5113e09dac65e5a28e218a1170a7-360015793618.png)
3. Configure o widget. Use o guia de configurações do widget a seguir.
4. Adicione mais widgets conforme necessário.

**Guia de configurações de widget**

| Configuração | Descrição |
| --- | --- |
| Tipo de widget | ![WidgetType_us-en.png](https://files.readme.io/00174da67c1b5046033655aad2f0af815d5abb3229cdc7c2f225f689c8adc7d8-360015793638.png)<br /><br />Selecione um tipo de widget:<ul><li>Gráficos de setores</li><li>Diagrama de barras</li><li>Gráfico de linhas</li><li>Tabela de dados</li><li>Geo mapa</li><li>Métrica</li><li>Gráfico de funil</li></ul> |
| Descrição | Insira uma descrição do widget |
| pagos | Selecione 1, vários ou todos os apps para incluir nos dados do widget. Lembre-se de que selecionar todos significa selecionar os top-100 apps em sua conta. |
| KPIs | <ul><li>Selecione os KPIs a serem exibidos no widget</li><li>Tabela de dados e gráfico de barras são classificados de acordo com o primeiro KPI selecionado</li></ul> |
| Agrupar por | Selecionar grupo por |
| Mostrar topo | Insira o número de valores a serem exibidos. |
| Pré-covid | Se selecionado, mostra dados de um período pré-COVID-19 de 1 a 30 de novembro de 2019. |
| Filtros | Use filtros para limitar dados no widget:<ul><li>**Países (geolocalização)**</li><li>**Fontes de mídia**</li><li>**Campanhas**</li><li>**Canais**</li></ul>Selecione **Excluir orgânico** para excluir explicitamente dados não atribuídos a uma fonte de mídia. |

</Accordion>

<div id="export-widget-data" />

<Accordion title="Exportar dados do widget">

![Widget_table.png](https://files.readme.io/b04e80e16d0d34946e6783103fc6fbbdf89b390842db27226b4fdba6c1f7e506-360015717057.png)

**Para fazer download dos dados do widget em um arquivo CSV**:

1. Verifique se o widget contém um título e dados.
2. Selecione **Ações** em um widget.
3. Selecione **Exportar CSV**.  
   O arquivo é baixado.  
   As datas nos arquivos CSV têm o formato dd/mm/aaaa. Você pode <Anchor target="_blank" href="https://answers.microsoft.com/en-us/msoffice/forum/msoffice_excel-mso_winother-mso_2010/how-to-convert-ddmmyyyy-to-mmddyyyy/41119ed6-4057-4598-a44c-1ebfdf301a43">convertê-las para um formato diferente</Anchor>, como mm/dd/aaaa no Excel.

</Accordion>

## Características e limitações

<div id="traits-and-limitations::6693dfa7" />

<Accordion title="Características e limitações">

| Caraterística | Observações |
| --- | --- |
| Acesso da ad network ao relatório | Não |
| Agências | Não compatível |
| Transparência da agência | Sim |
| Fuso horário específico do app | Se todos os apps hospedados na conta tiverem a mesma configuração de fuso horário, os dados serão exibidos usando o fuso horário específico do app. Se esse não for o caso: os dados serão exibidos em UTC. |
| Moeda específica do app | Se todos os apps hospedados na conta tiverem a mesma configuração de moeda, os dados serão exibidos na moeda específica do app. Se esse não for o caso, os dados serão exibidos em USD. |
| Dados de custo | Somente disponível se houver pelo menos 1 instalação registrada. <Anchor target="_blank" href="/marketers/pt/docs/roi360-cost-aggregation-overview#cost-data-availability-and-reports">Saiba mais</Anchor> |
| Dados orgânicos | Disponível |
| Dados não orgânicos | Disponível |
| eCPA | <ul><li>Nos dashboards personalizados, a fórmula do eCPA é: Gasto total / Número de ações = eCPA</li><li>Isso difere de outros dashboards, incluindo a visão geral, em que a fórmula é: Gasto total / **Usuários únicos** que realizaram uma ação = eCPA</li></ul> |
| Atualização dos dados | <Anchor target="_blank" href="/marketers/pt/docs/about-data-freshness-and-timezone-support#continuous-aka-realtime">Tempo real</Anchor>. Equivalente ao dashboard de visão geral |
| Acesso do utilizador à conta | Sim |
| Limitações | <ul><li>A opção de exportação de página inteira para PDF não está disponível.</li><li>A exportação para PNG não é compatível com os seguintes navegadores: Edge, Firefox 69 (máx.).</li><li>A pesquisa de uma campanha específica é limitada aos casos em que há menos de 100 campanhas. Se necessário, restrinja o período de tempo e pesquise novamente.</li><li>Disponibilidade de KPI: Os KPIs de LTV de aquisição de usuários estão disponíveis. KPIs de retargeting, retenção, atividade e Protect360 não estão disponíveis. Atenção! Não compare as métricas do dashboard personalizado com a Visão geral unificada ou as métricas de exibição de retargeting.</li><li>As alterações no nome da campanha não são compatíveis.</li></ul> |
| Fusos horários | <ul><li>Se todos os apps na conta tiverem o mesmo nome de fuso horário, os dados serão exibidos usando o fuso horário do app. Caso contrário, o UTC será usado.</li></ul> |
| Dados históricos | Os dados de LTV estão disponíveis por até 25 meses (2 anos + 1 mês). |

</Accordion>
