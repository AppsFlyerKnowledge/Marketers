> **Resumo:** entenda quais são os tipos básicos de fontes de mídia que você encontra na AppsFlyer.

Uma fonte de mídia é uma entidade que exibe anúncios. A plataforma da AppsFlyer permite que a atribuição de diferentes tipos de fontes de mídia seja registrada.

| Tipos de fontes de mídia | Descrição |
| --- | --- |
| <Anchor target="_blank" href="/marketers/pt/docs/self-reporting-networks-srns">Self-reporting network (SRN)</Anchor>, ou rede de autorrelato | <ul><li>Esse tipo de fonte de mídia confirma a atribuição e fornece detalhes desse processo através de uma conexão de API com a AppsFlyer</li><li>Exemplos: Meta ads, Google, Apple Search Ads</li></ul> |
| Não-SRN | <ul><li>Essa fonte de mídia fornece informações de atribuição obtidos de uma URL de clique.</li><li>Também conhecida como <Anchor target="_blank" href="/marketers/pt/docs/set-up-an-integrated-partner">attribution-link network</Anchor> ou ad network.</li><li>Exemplos: Unity Ads, Tapjoy, Applovin</li></ul> |
| Mídias próprias | <ul><li>Nas mídias próprias, <Anchor target="_blank" href="/marketers/pt/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">links do OneLink</Anchor> são usados em campanhas.</li><li>Exemplos: e-mail, SMS, publicações nas redes sociais, landing pages, QR codes e outros.</li></ul> |
