> **Visão geral:** o acesso a dados e recursos na AppsFlyer depende do tipo de conta do membro da equipe, suas permissões individuais e permissões da conta.

## Acesso aos dados por tipo de conta

Anunciantes, ad networks e agências têm acesso aos dados de acordo com o tipo de conta:

| Tipo de conta | Pode acessar |
| --- | --- |
| Anunciante | Todos os dados do anunciante na AppsFlyer, embora alguns dados estejam mascarados ou com hash:<ul><li>Tráfego atribuído a fontes de mídia restritas devido a requisitos regulatórios ou termos de compartilhamento de dados.</li></ul> |
| Rede de anúncios | Dados atribuídos à ad network |
| Agência | Dados relativos a campanhas realizadas pela agência e às quais o tráfego é atribuído |

## Acesso aos dados por funções e permissões

Quando o anunciante ativa o botão de alternância Permissão para uma ad network (consulte <Anchor target="_blank" href="/marketers/pt/docs/set-up-an-integrated-partner#permissões-da-ad-network">Permissões da ad network</Anchor>) ou uma agência (consulte <Anchor target="_blank" href="/marketers/pt/docs/set-up-an-integrated-partner#permissões-da-agência">Permissões da agência</Anchor>), há uma distinção adicional entre o acesso aos dados de acordo com as funções — **administrador** da conta e **membros da equipe** da conta, conforme listado nas tabelas a seguir.

**Observação:** Quando permitido, o acesso é limitado ao tráfego gerado pela ad network ou pela agência.

Legenda de abreviaturas:

| Abreviatura | Significado |
| --- | --- |
| ✓ | O acesso é concedido quando a opção de permissão principal é ativada pelo anunciante |
| P | O acesso é concedido quando permissões específicas são ativadas pelo anunciante |
| L | O acesso limitado é concedido quando a permissão é habilitada pelo anunciante |
| – | Sem acesso |

#### Acesso para anunciantes

Todos os outros usuários têm acesso de acordo com as <Anchor target="_blank" href="/marketers/pt/docs/user-management#gerenciar-funções">funções</Anchor> atribuídas a eles.
