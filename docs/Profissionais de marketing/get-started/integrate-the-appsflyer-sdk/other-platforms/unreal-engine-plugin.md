> **Visão geral:** Integre a AppsFlyer a jogos desenvolvidos no Unreal Engine para mensurar instalações do aplicativo, eventos in-app, canais de mídia e muito mais.

![256px-Unreal_Engine_4_logo_and_wordmark.svg.png](https://files.readme.io/8ea048105520f976b4e3080f5c8ec44a4d955977a7731fe16114225bd34e9e5e-360002792757.png)

O Unreal Engine permite que você desenvolva jogos mobile de última geração que seus usuários nunca esquecerão e que os farão voltar sempre para mais.

Com a ajuda da AppsFlyer, agora você pode mensurar e analisar seus esforços de marketing enquanto trabalha para promover seus jogos.

Veja algumas das coisas que você pode fazer com o plugin da AppsFlyer para Unreal Engine:

* Mensurar quantos usuários instalam o seu jogo
* Ver quais canais de mídia trazem mais usuários
* Ver quais canais de mídia trazem os melhores usuários
* Registrar e mensurar a atividade do usuário para determinar quais usuários geram mais receita

Para saber mais sobre o plugin da AppsFlyer para Unreal Engine e como implementá-lo, siga as instruções em nosso <Anchor target="_blank" href="https://github.com/AppsFlyerSDK/unreal_appsflyer_sdk">repositório no GitHub</Anchor>.
