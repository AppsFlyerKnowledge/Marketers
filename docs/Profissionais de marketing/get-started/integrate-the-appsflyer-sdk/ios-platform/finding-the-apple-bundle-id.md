> **Visão geral:** encontre o ID do pacote da Apple e use-o conforme necessário.

O ID do pacote da Apple é um identificador exclusivo associado aos aplicativos iOS.

* Os proprietários do aplicativo definem este ID
* A Apple recomenda que os proprietários de aplicativos nomeiem o ID usando uma notação de nome de domínio inversa.  
  Exemplo: com.domínio.nomedoapp

**Para localizar o ID do pacote da Apple:**

1. Faça login na sua conta do [iTunes Connect](https://itunesconnect.apple.com/).
2. Clique no aplicativo relevante
3. Vá para **Geral** > **Informações do aplicativo.**  
   O **ID do pacote** aparece.
