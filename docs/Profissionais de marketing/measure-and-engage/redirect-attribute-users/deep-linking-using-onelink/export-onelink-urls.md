> **Visão geral:** Baixe todos os URLs do OneLink criados na interface de usuário da AppsFlyer.

## Exportar URLs do OneLink

Faça o download de um arquivo CSV de todos os URLs do OneLink criados por template do OneLink usando a configuração do OneLink na interface de usuário da AppsFlyer. (Os URLs do OneLink criados por meio do SDK, da API do OneLink ou do upload em massa não são exportados).

O arquivo CSV contém informações sobre cada link da seguinte forma:

* Nome do link
* Canal de mídia
* Nome da campanha
* URL curta
* URL longa
* Data da última modificação/criação (MM:DD:YY HH:MM)
* Modificado por (e-mail)

<Anchor target="_blank" href="https://docs.google.com/spreadsheets/d/e/2PACX-1vR02eohAyUA2fsr9iGEb0UiZI8v45wH58KGo-45wajF4KNGuk_2S_cY1WW3UV8LwPRg-wm9bkMjvWyZ/pub?output=csv">Amostra de CSV</Anchor>

**Observação**: Se um link for criado inicialmente na interface do usuário da AppsFlyer, mas os parâmetros forem atualizados fora da interface do usuário (usando a API OneLink, uma planilha etc.), os parâmetros atualizados não farão parte do CSV baixado.

Para baixar o CSV:

1. Na AppsFlyer, no menu lateral, selecione **engajamento** > **gerenciar o OneLink**.
2. Selecione o template do OneLink para o qual você deseja uma lista de links.
3. Clique em **Exportar**.  
   O arquivo CSV é baixado.

### Especificações e limitações

| **Caraterística** | **Considerações** |
| --- | --- |
| Agências | Só é possível obter os links que eles criaram com base no template do OneLink. |
| Anunciantes | Só é possível obter os links que eles criaram com base no template do OneLink. |
