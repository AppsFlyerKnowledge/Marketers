| Seção | Detalhes |
| --- | --- |
| **Novidades** | O suporte a **postbacks em reinstalações de aplicativos** já está disponível. Agora é possível diferenciá-los das primeiras instalações. |
| **Data de início** | 09/01/2025 |
| **O que você precisa saber** | Agora os postbacks de instalação também controlam os postbacks de reinstalação. Configure-os na página **Integração ativa**.<ul><li>**Redes compatíveis:** Atualmente disponíveis para parceiros selecionados (exemplo: Unity Ads). Outros parceiros serão adicionados em breve.</li><li>**Localização:** O postback de instalação aparece na seção **Postbacks padrão** da aba **Atribuição**. Também controla os postbacks de reinstalação para redes compatíveis.</li><li>**Configuração:** Você pode alterar o menu suspenso **Para usuários de** de **Somente este parceiro** para **Todos os canais de mídia (incluindo orgânicos)**.</li><li>**Formato:** Os eventos de reinstalação utilizam o mesmo formato de postback que os eventos de instalação, com a macro `is_reinstall=true` anexada.</li><li>**Valor:** Isso permite uma mensuração e otimização aprimoradas, principalmente para parceiros especializados em retargeting.</li></ul> |
| **O que você precisa fazer** | Este recurso está disponível apenas para parceiros designados. Se você tiver interesse em acessá-lo, entre em contato com seu PDM. |
