| **Novidades** | A otimização de criativos tem uma integração de API com a Unity que nos permite obter dados de performance dos criativos. A API será atualizada em breve. Como parte desta atualização, você precisa atualizar a função da organização da sua conta de serviço na Unity para continuar recebendo dados da Unity. |
| --- | --- |
| **Data de atualização** | 10 de outubro de 2024 |
| **O que você precisa saber** | <ul><li>A Unity está introduzindo uma nova integração de API.</li><li>A antiga integração de API pode obter dados até a data de descontinuação, em 14 de novembro de 2024.</li></ul> |
| **O que você precisa fazer** | Você deve atualizar a função da organização da sua conta de serviço na Unity para incluir a função "Advertisers API Stats Viewer" além de outra função, para continuar recebendo dados após 14 de novembro de 2024.<br /><br /><Anchor target="_blank" href="/marketers/pt/docs/creative-optimization-partner-integrations#para-selecionar-uma-função-de-conta-de-serviço-organização">Siga nossas instruções para atualizar a função na Unity</Anchor> |
