      </td>
    </tr>

      <td>
        **Onde:**
      </td>
      <td>
        Página de Exportação de Dados
      </td>
    </tr>
    <tr>
      <td>
        **O que vai mudar?**
      </td>
      <td>
        Use a configuração **Ordem dos campos do relatório (CSV)** para especificar a sequência das colunas nos relatórios.

        | Configuração | Seleção de campo permitida | Considerações |
        | --- | --- | --- |
        | Padrão | Yes | * Os campos selecionados são organizados de acordo com um modelo da AppsFlyer.<br />* A partir de agora, a sequência será mantida. Os campos futuros serão adicionados à direita dos campos atuais. |
        | Alfabético (A-Z) | Yes | Os campos selecionados são ordenados alfabeticamente (crescente). |
        | Alfabético (Z-A) | Yes | Os campos selecionados são ordenados por ordem alfabética inversa (decrescente). |
        | Legado | Sem | * Os campos são dispostos conforme a sequência de colunas nos relatórios elaborados com a versão anterior da página de exportação de dados.<br />* A seleção dos campos é fixa e não pode ser alterada.<br />* Existe alguma variação nos relatórios por campo, dependendo do relatório específico. |

        A [planilha de ordem dos campos](https://docs.google.com/spreadsheets/d/e/2PACX-1vRGYcMOgC5yy_82yn3DWd3ucLE5KtuTA72eJfvu5KVB9fFH_mYwzM3KpR_inQOnat-KzgVjuuvXa6_g/pub?output=xlsx) contém as abas Default e Legacy, com a lista relevante de ordem dos campos.
      </td>
    </tr>
    <tr>
      <td>
        **Procedimento**
      </td>
      <td>
        ![FeldOrder.png](https://files.readme.io/d81e8d0494cbf3a8ee959990200da10889bb7a581c6018711b7163d8fedcd2d8-360020954138.png)

        **Para alterar a ordem dos campos:**

        1. Na aba **Campos do relatório**, selecione uma opção de **Ordem dos campos do relatório (CSV)**.
        2. Se necessário, altere os campos selecionados marcando ou desmarcando os campos necessários.
        3. Clique em **Download**.
      </td>
