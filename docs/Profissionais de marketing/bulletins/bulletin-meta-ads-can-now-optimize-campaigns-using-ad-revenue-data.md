| <span id="whats-new"></span>Novidades | Agora, o Meta ads consegue otimizar suas campanhas de divulgação de aplicativos do Android usando o evento **AdImpression** do postback de receita de anúncios. |
| --- | --- |
| <span id="update-date"></span>Data da atualização | 1 de janeiro de 2025 |
| <span id="what-you-need-to-know"></span>O que você precisa saber | <ul><li>Atualmente, a otimização por meio do evento **Adimpression** está disponível para campanhas de divulgação de aplicativos do Android.</li><li>Quando indisponível, os [critérios de elegibilidade podem não ser atendidos](https://www.facebook.com/business/help/571188993373447?id=561906377587030).</li><li>O evento Adimpression é mapeado para o evento af\_ad\_revenue, que está disponível apenas para planos com uma <Anchor target="_blank" href="/marketers/pt/docs/roi360-guide-cost-and-revenue-data">assinatura do ROI360 advanced</Anchor>. Além disso, você precisa da receita de anúncios a <Anchor target="_blank" href="/marketers/pt/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">nível de impressão (via SDK) ou a nível de impressão (via SDK) com o tipo de integração device-level (via API S2S</Anchor>).<ul><li>Planos sem o ROI360 podem enviar dados de receita de anúncios usando outros nomes de eventos.</li></ul></li></ul> |
| <span id="what-you-need-to-do"></span>O que você precisa fazer | <ul><li>Para clientes do ROI360, use o <Anchor target="_blank" href="/marketers/pt/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">nível de impressão (via SDK) ou o nível de impressão (via SDK) com o tipo de integração device-level (via API ROI360</Anchor>).</li><li><Anchor target="_blank" href="/marketers/pt/docs/meta-ads-in-app-event-mapping#mapeamento-de-dados-de-receita-de-anúncios-para-otimização-de-campanhas">Mapeie o evento af\_ad\_revenue para **Adimpression**</Anchor>.</li></ul> |
| <span id="additional-resources"></span>Recursos adicionais | Consulte a <Anchor target="_blank" href="https://www.facebook.com/business/help/330074040129013">Central de ajuda do Meta Business</Anchor> para saber mais sobre como maximizar o valor das conversões para anúncios de aplicativos no Meta Ads Manager. |
