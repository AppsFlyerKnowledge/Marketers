| **Novidades** | A partir de 1º de abril de 2026, os dados agregados de LTV, como cliques, impressões e instalações, serão retidos por 25 meses (2 anos + 1 mês) em vez de 5 anos. |
| --- | --- |
| **Data de início** | 1º de abril de 2026 |
| **Ação recomendada** | Exporte todos os dados agregados de LTV históricos antes de 1º de abril de 2026 |
| **Informações adicionais** | A mudança se aplica aos dados agregados de LTV nos seguintes produtos e interfaces da AppsFlyer:<ul><li>My Dashboards</li><li>Protect360</li><li>Dashboard da SKAN</li><li>Master API</li><li>Dashboard Pivot</li><li>Dashboard personalizado</li><li>Dashboard de Visão Geral</li><li>Pull API agregada</li><li>Dashboard de atividades</li><li>Dashboard de eventos</li><li>MCP da AppsFlyer</li></ul>**<span id="what-you-should-know"></span>O que você precisa saber**<ul><li>A disponibilidade de dados agregados de LTV, como cliques, impressões e instalações, é limitada a **25 meses (2 anos + 1 mês)**.</li><li>Após 1º de abril de 2026, não será possível acessar os dados agregados de LTV anteriores a 25 meses.</li><li>Consultas ou visualizações que solicitam dados agregados de LTV fora do período de retenção podem retornar **resultados parciais ou vazios**.</li><li>Os dados de atividade e cohort talvez ainda estejam disponíveis para intervalos de tempo mais antigos. Isso pode resultar em diferenças entre os conjuntos de dados.</li></ul> |
