| **Novidades** | Agora, os dados de atividade serão exibidos de forma unificada, o que significa que eles incluirão tanto dados de aquisição de usuários (UA) quanto de retargeting. |
| --- | --- |
| **Data da atualização** | 1 de fevereiro de 2025 |
| **Onde** | Dashboard de atividade, Pivot e Master API. |
| **O que você precisa saber** | <ul><li>Até o momento, algumas métricas de atividade, como por exemplo sessões e DAU, se baseavam somente em dados de UA.</li><li>Agora, todas as métricas de atividade incluem dados de UA e de retargeting. **Atenção**: essas informações sempre serão exibidas de forma unificada; você não pode dividir os dados para visualizá-los somente com base em UA ou retargeting.</li><li>Para algumas ad networks, os eventos anteriormente atribuídos a campanhas de UA agora podem ser atribuídos a campanhas de retargeting.</li><li>Métricas como DAU e MAU podem aumentar por conta dessa alteração, pois o tráfego de retargeting agora faz parte dos cálculos.</li><li>No entanto, antes de 1 de fevereiro de 2025, as seguintes métricas incluem apenas dados de tráfego de UA:<ul><li>Dashboard de atividades<ul><li>Total de sessões</li><li>DAU</li><li>MAU</li><li>DAU/MAU</li><li>ARPDAU</li><li>Custo</li><li>Cliques</li><li>Impressões</li><li>Taxa de conversão</li><li>eCPI</li></ul></li><li>Nos dashboards de Pivot e na Master API: KPIs de atividade</li></ul></li></ul> |
