| **Novidades** | eCPI no Dashboard Overview agora inclui dados orgânicos. |
| --- | --- |
| **Data de início** | 20 de março de 2024 |
| **Onde:** | Painel de Visão geral |
| **O que você deve saber** | <ul><li>Até a data de vigência, os dados orgânicos não eram incluídos na métrica de eCPI; apenas os dados não orgânicos.</li><li>A partir da data de vigência, os dados orgânicos estão incluídos no eCPI.</li><li>Isso pode causar uma queda no eCPI informado no Dashboard Overview.</li></ul> |
