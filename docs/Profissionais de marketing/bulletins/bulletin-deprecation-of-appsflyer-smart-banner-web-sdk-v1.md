> **Resumo:** A partir de 8 de novembro de 2023, o AppsFlyer Smart Banner web SDK v1 foi descontinuado.

| **O que vai mudar?** | O web SDK v1 do Smart Banner da AppsFlyer foi desativado em 8 de novembro de 2023. Para exibir Smart Banners em seu site, você precisa atualizar para a v2. |
| --- | --- |
| **O que você precisa saber** | <ul><li>Se o seu site usa o Smart Banner SDK V1.0, você DEVE integrar a versão mais recente do SDK (v2) para continuar exibindo Smart Banners no seu site.</li><li>Atualizar para a versão mais recente é um processo simples. Clique <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2">aqui</Anchor> para ver o processo.</li></ul>**Suporte a novos recursos**<ul><li>Alguns recursos não são compatíveis com o SDK v1, incluindo os <Anchor target="_blank" href="/marketers/pt/docs/smart-banners-mobile-web-to-app-for-marketers#3-banner-setup">modelos de design de criativos</Anchor> recém-adicionados.</li></ul> |
| **Como saber se você está usando o Smart Banner SDK v1?** | Se o snippet de código do Smart Banner no seu site incluir  <br />https://cdn.appsflyer.com/web-sdk/banner/latest/sdk.min.js  <br />isso significa que você está usando a V1 e deve atualizar.<br /><br />Clique <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/dl_smart_banner_v2">aqui</Anchor> para ver o processo e atualizar. |
