| **Novidades** | A receita de anúncios ao nível de impressão agora está disponível através da API SDK de receita de anúncios em vez do conector SDK de receita de anúncios. |
| --- | --- |
| **A partir da** | versão 6.15 do AppsFlyer SDK |
| **Tudo o que você precisa saber** | <ul><li>Até agora, a receita de anúncios ao nível de impressão estava disponível através do **conector** SDK de receita de anúncios do AppsFlyer. A partir da data efetiva, a integração será feita diretamente através do próprio **SDK** do AppsFlyer (não um conector), utilizando a API SDK de receita de anúncios.</li><li>O conector SDK de receita de anúncios continuará a funcionar com:<ul><li>Versão 6.14.2 e anteriores do AppsFlyer Android SDK.</li><li>Versão 6.14.6 e anteriores do AppsFlyer iOS SDK.</li></ul></li></ul> |
| **O que é preciso fazer** | <ul><li>Se deseja atualizar para a versão 6.15+ do AppsFlyer SDK e atualmente tem o conector SDK de receita de anúncios implementado, precisa remover o conector SDK de receita de anúncios e integrar a API SDK de receita de anúncios.</li><li>É necessário um desenvolvedor. Veja as instruções da API SDK de receita de anúncios do <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/ad-revenue">desenvolvedor</Anchor>.</li><li>Saiba mais sobre a integração da API SDK de receita de anúncios ao nível de <Anchor target="_blank" href="/marketers/pt/docs/integrate-the-roi360-ad-revenue-sdk-api">impressão</Anchor>.</li></ul> |
