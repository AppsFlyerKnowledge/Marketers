> **한눈에 보기:**

Apple 번들 ID는 iOS 앱과 연결된 고유 식별자입니다.

* 앱 소유자가 이 ID를 설정합니다
* Apple은 앱 소유자가 역방향 도메인 이름 표기법을 사용하여 ID 이름을 지정할 것을 권장합니다.  
  예시: com.domain.appname

**Apple 번들 ID를 배치하는 방법:**

1. [iTunes Connect](https://itunesconnect.apple.com/) 계정에 로그인합니다.
2. 관련 앱을 클릭합니다.
3. **일반** > **앱 정보**로 이동합니다.  
    번들 ID/strong>가 표시됩니다. **![iTunes-connect-app-information-en-us.png](https://files.readme.io/236967e7c254e40c3a76565a6da8cc5599e86be1c16e568c7c5b31072b570bd2-360011702958.png)**
