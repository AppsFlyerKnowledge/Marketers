> **한눈에 보기:** 앱스플라이어의 데이터 및 기능에 액세스하는 능력은 팀원 계정 유형, 개별 팀원 권한 및 계정 권한에 따라 달라집니다.

## 계정 유형별 데이터에 액세스

광고주, 애드 네트워크 및 에이전시는 계정 유형에 따라 데이터에 액세스할 수 있습니다.

| 계정 유형 | 액세스 가능 |
| --- | --- |
| 광고주 | 앱스플라이어에서 그의 모든 데이터(일부 데이터는 마스킹되거나 해시됨):<ul><li><Anchor target="_blank" href="/marketers/ko/docs/view-agency-data">비투명</Anchor> 에이전시로 어트리뷰트된 트래픽.</li><li>규제 요구사항 또는 데이터 공유 조건에 따라 제한된 미디어 소스로 어트리뷰트된 트래픽.</li></ul> |
| 애드 네트워크 | 애드 네트워크에 어트리뷰트된 데이터 |
| 에이전시 | 에이전시가 운영하고 트래픽이 어트리뷰트되는 캠페인과 관련된 데이터 |

## 역할 및 권한별 데이터 액세스

광고주가 애드 네트워크 또는 에이전시에 대해 권한 토글을 켜면 다음 표에 나열된 것처럼 역할(계정 **관리자** 및 계정 **팀 구성원**)에 따라 데이터에 대한 액세스 권한이 더 구분됩니다.

**참고:** 허용되는 경우 액세스는 애드 네트워크 또는 에이전시에서 생성된 트래픽으로 제한됩니다.

약어 키:

| 용어 | 의미 |
| --- | --- |
| ✓ | 기본 권한 토글이 광고주에 의해 사용 설정된 경우 액세스 권한이 부여됩니다. |
| P | 광고주가 추가 특정 권한을 사용하도록 설정한 경우 액세스 권한이 부여됩니다. |
| L | 광고주가 권한을 활성화한 경우 제한된 액세스가 부여됩니다 |
| – | 액세스 불가 |
