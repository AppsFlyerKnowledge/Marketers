> **한눈에 보기:** 앱스플라이어의 기본 미디어소스를 이해합니다.

미디어소스는 광고를 표시하는 엔티티입니다.  앱스플라이어 플랫폼을 사용하면 다양한 유형의 미디어소스에서 어트리뷰션을 집계할 수 있습니다.

| 미디어소스의 유형 | 설명 |
| --- | --- |
| <Anchor target="_blank" href="/marketers/ko/docs/self-reporting-networks-srns">SRN(셀프 리포팅 네트워크)</Anchor> | <ul><li>앱스플라이어와 네트워크 간의 API를 통해 어트리뷰션 확인 및 세부 사항을 제공합니다.</li><li>예시 Meta Ads, Google, Apple Search Ads</li></ul> |
| 비SRN | <ul><li>클릭 URL의 어트리뷰션 정보를 제공합니다.</li><li><Anchor target="_blank" href="/marketers/ko/docs/set-up-an-integrated-partner">어트리뷰션 링크 네트워크</Anchor> 또는 광고 네트워크라고도 합니다.</li><li>예시: Unity Ads, Tapjoy, Applovin</li></ul> |
| 소유 매체 | <ul><li>온드 미디어는 캠페인에 <Anchor target="_blank" href="/marketers/ko/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">원링크 링크를</Anchor> 사용합니다.</li><li>예시: 예시: 이메일, SMS, 소셜 네트워크, 랜딩 페이지, QR 코드 등.</li></ul> |

또한 <Anchor target="_blank" href="/marketers/ko/docs/cross-promotion-attribution-for-marketers">크로스 프로모션 어트리뷰션</Anchor>, <Anchor target="_blank" href="/marketers/ko/docs/user-invite-attribution">사용자 초대 어트리뷰션</Anchor>, 및 <Anchor target="_blank" href="/marketers/ko/docs/smart-banners-mobile-web-to-app-for-marketers">스마트 배너</Anchor>를 참조하세요.
