> **한눈에 보기:** 오가닉 설치와 논오가닉 설치의 차이점을 이해하세요.

<Image align="center" alt="6453OrganicvsNon-organic.jpg" src="https://files.readme.io/b456433d858a146187429d0a40c200327af685490ea003cd5130f40ad798c7a4-360018880878.jpg" />

논오가닉 사용자는 인스톨이나 인게이지먼트를 유도한 미디어 소스가 기여한 성과(어트리뷰션)로 기록됩니다. 오가닉 사용자의 경우 인스톨이나 인게이지먼트와 관련된 미디어 소스가 없습니다.

<div id="organic-vs-non-organic" />

## 오가닉 대 논오가닉.

| 오가닉 인스톨  <br />미디어 소스에 어트리뷰션 되지 않음 | 논오가닉 인스톨(NOI)  <br />미디어 소스에 어트리뷰션 됨 |
| --- | --- |
| **어트리뷰션 없음**. 미디어 소스 없음 | **미디어 소스에** 어트리뷰션 됨 |
| **어트리뷰션이 되지 않는** 경우:<ul><li>어트리뷰션 링크를 통하지 않고 앱이 설치됨. 예를 들어, 사용자가 광고를 접하지 않고 직접 귀사의 웹사이트나 앱 스토어에서 앱을 다운로드한 경우입니다.</li><li>클릭과 앱 실행의 주체자를 일치시킬 수 없음 예를 들어, 개인정보 보호 정책에 따라 데이터가 사용할 수 없거나, 이미 다른 모바일 측정 플랫폼으로 인스톨이 기록된 경우입니다.</li></ul> | 인스톨이나 앱 실행에 대한 **어트리뷰션**이 된 경우:<ul><li>앱스플라이어의 어트리뷰션 링크 사용</li><li>앱스플라이어가 광고 클릭과 앱 실행 주체자를 일치시킴</li><li>SRN이 자신의 기여도를 기록</li></ul> |
|  | **어트리뷰션 상세:**<ul><li>*라스트 클릭 어트리뷰션* 사용: 마지막으로 상호작용한 광고가 앱 설치나 유저 활동에 대한 기여도를 인정 받습니다.</li><li>인스톨당 단 하나의 미디어 소스만이 기여도를 인정 받습니다.</li><li><Anchor target="_blank" href="/marketers/ko/docs/appsflyer-attribution-model">앱스플라이어 어트리뷰션</Anchor>에 대해 자세히 알아보세요.</li></ul> |
