## 마케팅 퍼널 단계

신규 사용자는 첫 번째 광고 조회부터 수익이 발생할 때까지 마케팅 퍼널을 거칩니다. 각 퍼널 단계에는 고유한 성공 수준이 있습니다. 사용자가 더 많이 진행할수록 모바일 광고주에게 더 나은 결과를 가져다 줄 수 있습니다. 다음 이미지는 마케팅 퍼널 단계를 보여줍니다.

## 마케팅 퍼널 단계 및 전환율

전환율은 광고주가 마케팅 퍼널의 여러 단계에서 발견되는 강점과 약점을 이해하는 데 도움이 됩니다. 그런 다음 전환율에 따라 **취약한 부분을 개선하여 더 많은 사용자를 퍼널로 진출시킬**수 있습니다.

다음 표를 참조하십시오.

* 마케팅 퍼널 단계 및 전환율에 대한 설명
* 메트릭을 사용할 수 있는 위치(다음과 같이 표시됨):
  * **앱스플라이어**: 앱스플라이어: 개요 대시보드 와 <Anchor target="_blank" href="/marketers/ko/docs/aggregated-and-analytics-reporting-overview">종합 리포트 및 분석</Anchor>
  * 복사됨) App Store: 데이터는 App Store에서만 사용할 수 있습니다.
* 광고주가 지표를 사용하여 마케팅 결과를 개선하는 방법

<div id="marketing-funnel-stages-and-conversion-rates-1" />

#### 마케팅 퍼널 단계 및 전환율

| 무대 | 이름 | 설명 | 가능한 경우 | 전환율을 최적화하는 방법 |
| --- | --- | --- | --- | --- |
| 1 | 노출 | 사용자가 웹 또는 모바일 광고를 조회합니다. | 앱스플라이어 |  |
| 2 | 클릭 | <ul><li>사용자가 광고를 클릭하면 광고된 페이지 또는 앱 활동으로 리디렉션됩니다.</li><li>또는 사용자가 클릭하지 않고 앱의 스토어 페이지를 방문합니다.</li></ul> | 앱스플라이어 |  |
| 전환율 | **클릭률(클릭수/노출수)\*100** | <ul><li>광고를 본 후 클릭하는 사용자를 측정합니다.</li><li>계산하려면 앱스플라이어의 노출 및 클릭 지표를 사용합니다.</li></ul> |  | <ul><li>크리에이티브와 타겟 대상의 친밀도를 높이세요: 비주얼, 카피, 현지화, 타게팅.</li><li>새로운 잠재고객과 미디어소스로 실험해 보세요.</li></ul> |
| 3 | 앱스토어 | 사용자가 앱 스토어의 앱 페이지에 도달합니다. | 앱스토어 |  |
| 전환율 | **클릭-투-앱 스토어 비율(앱 스토어 방문/클릭수)\*100** | 얼마나 많은 사용자가 광고를 클릭하고 앱 스토어의 앱 페이지가 완전히 로드되도록 허용했는지 측정합니다. | 앱스토어 | 앱 스토어 페이지 로드 시간을 개선합니다.  페이지 속도를 늦추는 큰 요소를 제거합니다. |
| 4 | 다운로드 | 사용자가 앱 스토어에서 앱을 다운로드합니다. | 앱스토어 |  |
| 전환율 | **App Store에서 다운로드율(다운로드/App Store 방문)\*100** | 앱 스토어에서 앱 페이지를 방문한 후 앱을 다운로드하는 사용자 수를 측정합니다. | 앱스토어 | <ul><li>앱 스토어 페이지 메시징을 개선합니다.</li><li>다양한 클릭 유도문안을 시도해 보세요.</li></ul> |
| 5 | 인스톨 | 사용자가 기기에 앱을 설치하고 엽니다.<ul><li>~10% 다운로드 대비 설치 수가 적습니다.</li><li>예: 예: 앱스플라이어에 200개의 캠페인 설치가 표시되면 약 220 사용자가 앱을 다운로드했습니다.</li></ul> | 앱스플라이어 |  |
| 전환율 | **클릭 투 설치율(설치/클릭)\*100** | 광고를 클릭한 후 앱을 설치한 사용자 수를 측정합니다. | 앱스플라이어 | <ul><li>잠재고객 타겟팅을 개선합니다.</li><li>앱 설치 시간을 줄입니다.</li></ul> |
| 6 | 인앱 이벤트 | 사용자가 구매와 같은 인앱 작업을 수행합니다. | 앱스플라이어 |  |
| 전환율 | 이벤트 전환율(이벤트 CVR)<br /><br />**(인앱이벤트/인스톨)\*100** | <ul><li>설치 후 인앱 이벤트를 수행하는 사용자 수를 측정합니다. [관련 문서]</li><li>예시 예: 등록, 구매, 레벨 완료 등</li><li>전환당 비용(CPA) 계산을 활성화합니다.</li></ul> | 앱스플라이어 | <ul><li>시기적절한 메시지와 클릭 유도문안을 제공합니다.</li><li>사용자 인터페이스를 개선합니다.</li><li>딥링크(Deep Link)를 사용하여 리타게팅 캠페인을 구성합니다. <Anchor target="_blank" href="/marketers/ko/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">[관련 문서]</Anchor></li></ul> |
