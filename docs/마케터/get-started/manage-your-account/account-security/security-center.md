> **한눈에 보기:** 한 곳에서 귀사의 앱스플라이어 계정의 모든 보안 관련 기능 상태를 검토하고 관리하세요.

## 보안 센터에서 가능한 작업은 무엇인가요?

**보안 센터**를 통해 귀사의 앱스플라이어 계정 보안 상태를 한눈에 확인할 수 있습니다. **보안 센터**의 각 섹션에서 버튼을 클릭하면 다음 기능을 이용할 수 있습니다.

| 기능 | 설명 |
| --- | --- |
| <span id="user-management"></span>유저 관리 | 앱스플라이어 유저를 생성하고 관리하세요. 필요한 기능, 앱 및 데이터에 액세스할 수 있는 권한을 할당하세요. |
| <span id="redirect-allowlist"></span><Anchor target="_blank" href="/marketers/ko/docs/set-up-your-domain-redirect-allowlist">리디렉션 허용 목록</Anchor> | 링크 리디렉션이 허용된 도메인을 정의합니다. |
| <span id="list-of-authorized-agencies-for-ad-networks"></span><Anchor target="_blank" href="/partners/ko/docs/set-up-your-list-of-authorized-agencies">공인 에이전시 목록</Anchor>(광고 네트워크용) | 네트워크 연동을 통해 캠페인을 실행할 수 있는 에이전시를 관리하세요. |
| <span id="api-allowlist"></span><Anchor target="_blank" href="/marketers/ko/docs/set-up-your-api-allowlist">API 허용 목록</Anchor> | API 요청에 허용된 IP 주소를 정의합니다. |
| <span id="enhanced-login-security"></span>강화된 로그인 보안 | <Anchor target="_blank" href="/marketers/ko/docs/set-up-sso-authentication-with-your-identity-provider-idp">단일 로그인(SSO)</Anchor> 또는 <Anchor target="_blank" href="/marketers/ko/docs/implementing-and-using-2fa-login">2단계 인증(2FA)</Anchor>을 구성하여 귀사의 계정을 무단 접근으로부터 보호하세요. |
| <span id="appsflyer-api-and-s2s-tokens"></span><Anchor target="_blank" href="/marketers/ko/docs/managing-appsflyer-tokens">앱스플라이어 토큰</Anchor> | 앱스플라이어 토큰을 사용하여 API 및 S2S 호출을 인증하세요. 최대 보안을 위해 토큰을 관리하고 주기적으로 교체하세요. |
| <span id="audit-log"></span><Anchor target="_blank" href="/marketers/ko/docs/audit-log">감사 로그</Anchor> | 로그인, 유저 관리 작업, API 호출 등을 검토하여 무단 액세스를 식별합니다. |

[altnew-security-center.jpgalt](https://support.appsflyer.com/hc/article_attachments/26342886419985)

**보안 센터에 액세스하려면:**

* 상단 바에서 계정 메뉴(이메일 주소 드롭다운) > **보안 센터**를 엽니다.
