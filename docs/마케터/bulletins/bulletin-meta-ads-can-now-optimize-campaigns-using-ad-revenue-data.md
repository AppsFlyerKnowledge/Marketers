| <span id="whats-new"></span>새로운 소식 | 이제 Meta ads가 광고 매출 포스트백 이벤트 **AdImpression**을 사용하여 귀하의 안드로이드 앱 프로모션 캠페인을 최적화할 수 있습니다. |
| --- | --- |
| <span id="update-date"></span>업데이트 날짜 | 2025년 1월 1일 |
| <span id="what-you-need-to-know"></span>핵심 내용 | <ul><li>현재 **Adimpression** 이벤트를 통한 최적화를 안드로이드 앱 프로모션 캠페인에 사용할 수 있습니다.</li><li>계정이 회색으로 표시되면 [자격 요건이 충족되지 않았을 수 있습니다](https://www.facebook.com/business/help/571188993373447?id=561906377587030).</li><li>Adimpression 이벤트는 <Anchor target="_blank" href="/marketers/ko/docs/roi360-guide-cost-and-revenue-data">ROI360 고급 패키지</Anchor>가 있는 플랜에서만 사용할 수 있는 af\_ad\_revenue 이벤트에 매핑됩니다. 또한, <Anchor target="_blank" href="/marketers/ko/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">노출 레벨(SDK 기반) 광고 수익 혹은 디바이스 레벨(S2S API 기반해) + 노출 수준(SDK 기반) 연동 유형</Anchor>이 필요합니다.<ul><li>ROI360이 아닌 플랜은 다른 이벤트 이름을 사용하여 광고 수익 데이터를 보낼 수 있습니다.</li></ul></li></ul> |
| <span id="what-you-need-to-do"></span>필요한 조치 | <ul><li>ROI360 고객의 경우, <Anchor target="_blank" href="/marketers/ko/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">노출 레벨(SDK 기반) 광고 수익 또는 디바이스 레벨(S2S API 기반) + 노출 레벨(SDK 기반) 연동 유형</Anchor>을 사용하세요.</li><li><Anchor target="_blank" href="/marketers/ko/docs/meta-ads-in-app-event-mapping#mapping-ad-revenue-data-for-campaign-optimization">af\_ad\_revenue 이벤트를 **Adimpression**에 매핑</Anchor>.</li></ul> |
| <span id="additional-resources"></span>추가 리소스 | Meta Ads Manager에서 앱 광고의 성과 목표로 전환값을 최대화하는 방법에 대해 자세히 알아보려면 <Anchor target="_blank" href="https://www.facebook.com/business/help/330074040129013">Meta 비즈니스 지원 센터</Anchor>를 참조하세요. |
