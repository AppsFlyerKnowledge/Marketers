| **새로운 소식** | 업계가 보다 투명한 생태계의 방향으로 나아감에 따라 앱스플라이어는 광고주와 에이전시 간의 투명성을 지원하여 앱스플라이어 리포트와 분석 제품을 최대한 활용할 수 있도록 지원합니다.<br /><br />2023년 8월 14일부터 앱 수준 <Anchor target="_blank" href="/partners/ko/docs/getting-started-agency-onboarding#투명성">에이전시 투명성</Anchor> 토글이 기본적으로 영구적으로 사용 설정됩니다. 이는 앱스플라이어에 가입하는 신규 에이전시 및 신규 광고주 액세스 권한을 가진 기존 에이전시와 관련됩니다. |
| --- | --- |
| **시행일** | 2023년 8월 14일 |
| **변경 전** | 광고주 액세스 권한이 있는 모든 대행사 계정은 **투명성 허용** 토글을 켜거나 끌 수 있습니다. |
| 변경 후: | <ul><li>**투명성 허용** 토글은 앱스플라이어에 가입하는 신규 에이전시와 광고주로부터 앱 레벨 액세스 권한을 부여받은 기존 에이전시에 대해 영구적으로 활성화(켜짐)됩니다 .</li><li>현재 투명성 허용이 해제되어 있는 기존 에이전시는 이 기능을 해제하거나 사용 중지할 수 있는 옵션을 가지고 있습니다. 그러나 한 번 설정되면 영구적으로 설정된 상태로 유지됩니다.</li></ul> |
| 예외 | 에이전시 투명성은 계정 사용 리포트에서 지원되지 않습니다(변경 사항 없음). |
| **장소:** | 에이전시 계정 **앱스플라이어의 사이드 메뉴에서** **설정** > 앱 설정을 선택합니다. |
| **필요한 조치**: | 아무 조치도 필요하지 않습니다. 그러나 비투명성을 적용하는 기관은 투명성 모델로 전환하는 것이 좋습니다. |
