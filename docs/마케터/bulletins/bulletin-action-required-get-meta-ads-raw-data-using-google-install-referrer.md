        **새로운 소식**
      </td>
      <td>
        인스톨 레퍼러를 사용하여 Google Play 스토어로 보내는 광고의 메타 광고 캠페인 로데이터를 얻을 수 있습니다.
      </td>
    </tr>
    <tr>
      <td>
        **변경되는 사항**

        **![Information_icon.png](https://files.readme.io/cc1ff74668360a2be64ec90db8f771d751b0a95847ecaee582c2e31c60e310cf-20445036062993.png)**
      </td>
      <td>
        2021년 10월 29일 **이후에** 메타 광고에서 가져온 사용자의 사용자 수준 어트리뷰션 데이터(로데이터)는 제한됩니다. 메타 광고는 앱스플라이어 같은 MMP에서는 이 데이터를 사용할 수 있도록 하고 있지만, 광고주에게는 그렇게 하지 않습니다.

        그러나 광고가 사용자를 Google Play Store로 디렉트하는 경우 Google 인스톨 레퍼러의 광고주가 어트리뷰션 필드를 사용할 수 있으며, 이 필드는 <Anchor target="_blank" href="/marketers/ko/docs/basic-sdk-integration-guide#attribute-apps-published-on-google-play">앱에 통합</Anchor>되어야 합니다. 레퍼러를 통해 제공되는 필드는 사용자가 사용할 수 있는 앱스플라이어 로데이터 리포트에 입력되며 앱스플라이어에서 광고 ID(LAT-사용 가능)가 없는 사용자를 어트리뷰트할 수 있게 합니다.

        레퍼러 메커니즘을 사용하려면 앱스플라이어 SDK V5.4 이상이 필요합니다.

        **참고:** 리퍼러 데이터는 API에서 제공하는 데이터에 대해 우선권을 가지며 제한되지 않습니다.

        리퍼러의 데이터는 메타 광고에 의해 암호화되고 메타 개발자 계정에서 사용할 수 있는 키를 사용하여 복호화됩니다. 필요한 작업 열에서 설명된 복호화 키를 제공해야 합니다.

        **캠페인 어트리뷰션 필드는 리퍼러를 통해 사용할 수 있습니다.**

        * 광고 ID
        * 광고 이름
        * 광고세트 ID
        * 광고세트 이름
        * 캠페인 ID
        * 캠페인 이름
        * 계정ID
        * 채널
        * 광고 유형(이 필드는 아직 사용할 수 없음)

        **참고**:

        * 리퍼러를 통해 다른 필드를 사용할 수 없습니다.
        * 이 솔루션은 뷰-쓰루 어트리뷰션이 아니라 클릭-쓰루 어트리뷰션에 적용됩니다.
        * 리퍼러 데이터는 사용자가 스토어를 거치지 않기 때문에 리인게이지먼트 캠페인에 적용할 수 없습니다.

        **앱스플라이어가 언제 상기 변경을 시작합니까?**

        * 2021년 10월 29일 시작:
          * 클릭-쓰루 데이터(다시 말하면 어트리뷰션 로데이터)에 대한 메타 광고 제한을 구현합니다.
          * 광고주는 앱스플라이어에서 레퍼러 암호 해독 키를 업데이트할 수 있습니다.
        * 2021년 11월 3일 시작:
          * 앱스플라이어는 레퍼러 메커니즘에서 제공하는 데이터를 사용하여 로데이터를 채우고 어트리뷰트합니다.

        **필요한 조치**
      </td>
      <td>
        **메타 광고에서 암호 해독 키를 얻는 방법:**

        [다음 정보는 Facebook에서 제공하는 정보에 기반합니다]

        1. Meta 개발자 포털에 로그인하세요.
        2. 오른쪽 위에 있는 **내 앱**으로 이동합니다.
        3. 귀사의 복호화 키에 액세스하려는 앱을 선택하세요.
        4. 페이지의 좌측에 있는 **설정** > **기본**으로 이동합니다.

           [![FBUIforKey.png](https://files.readme.io/253be6d4cd2a75cc2c038c5b14ed3df067612c46bea174475adba3d196f25789-30354101891985.png)](https://files.readme.io/253be6d4cd2a75cc2c038c5b14ed3df067612c46bea174475adba3d196f25789-30354101891985.png)
        5. **Android** 섹션으로 아래로 스크롤하면 **패키지 이름** 필드 아래에 **인스톨 레퍼러 암호 해독 키**라는 암호 해독 키가 표시됩니다. **참고**: 이 섹션은 패키지 이름과 구글 플레이 스토어를 설정한 것과 같은 섹션입니다.

        **앱스플라이어에서 레퍼러 메커니즘을 활성화하는 방법.**

        1. [필수] 앱이 앱스플라이어 SDK V5.4 이상을 채택했는지 확인합니다. 이전 버전에 의존하지 마세요.
        2. 다음 중 하나를 선택하세요.
           1. [곧 출시 예정] API를 통해 암호 해독 키를 설정합니다.
           2. 사용자 인터페이스를 통해 암호 해독 키를 설정하는 방법:
              1. 앱스플라이어에서 **설정** > **활성 연동**으로 이동합니다.
              2. 메타 광고를 선택합니다.  

                 ![meta-ads-install-referrer-decryption-key.png](https://files.readme.io/adf6caa8d7cee493695eb8fb7db1b61c60e6a1cef0273e615c43a05ad8a9485d-13963525463825.png)
           3. **연동** 탭에 **인스톨 리퍼러** **암호해독 키**를 붙여넣으십시오.
           4. **연동 저장**을 클릭하세요.

        **향후 로데이터 가용성**
      </td>
      <td>
        * 어트리뷰션 데이터가 레퍼러 메커니즘을 통해 얻어지는 경우 데이터는 제한되지 않으며 로데이터 리포트를 통해 사용 가능합니다.
        * 어트리뷰션 데이터가 API에 의해 얻어지는 경우, 메타 광고가 제공한 사용자의 로데이터가 *제한된* 미디어소스에 할당됩니다.
        * 상기 변경은 변경 전에 가져온 사용자의 로데이터에 영향을 주지 않습니다. 다시 말하면 2021년 10월 29일 08:00 UTC부터입니다.
      </td>
    </tr>
    <tr>
      <td>
        **동일한 상태를 유지하는 사항**
      </td>
      <td>
        앱스플라이어는 메타 광고로부터 기기 수준 데이터를 계속 수신하므로, 어트리뷰션 및 리포트 기능(멀티 터치 속성, LTV, ROI, 코호트, 잔존률 보고서, 사기 방지, 대상 고객 및 기타 서비스 포함)은 변경되지 않습니다. <Anchor target="_blank" href="/marketers/ko/docs/aggregated-and-analytics-reporting-overview">종합 및 분석 리포트 도구</Anchor>를 참조하십시오.

        **참고**: 암호 해독 키를 제공하면, 광고 ID를 갖고 있지 않은 사용자를 어트리뷰션할 수 있습니다(LAT 사용 가능). 이를 통해 어트리뷰션 정확도가 향상됩니다.
      </td>
    </tr>
    <tr>
      <td>
        **어트리뷰션에 대한 변경 사항**
      </td>
      <td>
        GCD를 통한 디퍼드 딥링킹은 Google 인스톨 레퍼러 메커니즘을 통해 안드로이드 앱에 사용할 수 있습니다. iOS 앱에서는 사용할 수 없습니다.
      </td>
    </tr>
    <tr>
      <td>
        **자주 묻는 질문**
      </td>
      <td>
        * **인스톨 레퍼러 암호 해독 키를 업데이트해야 합니까?**  
          일단 제출되면 암호 해독 키를 업데이트하지 않아도 됩니다.
        * **로데이터 보고서에서 사용자 수준 데이터를 볼 수 있는 경우는 언제인가요?**  
          사용자 수준 데이터는 유효한 설치 리퍼러 복호화 키가 제출되고 설치가 Meta 광고에 기여한 것으로 간주되면 원시 날짜 보고서에 표시됩니다.
        * **2021년 10월 29일부터 11월 3일 사이에 발생한 인스톨에 대해 사용자 수준 어트리뷰션 데이터를 사용할 수 있습니까?**  
          유감스럽게도 이 데이터는 사용할 수 없습니다.
      </td>
