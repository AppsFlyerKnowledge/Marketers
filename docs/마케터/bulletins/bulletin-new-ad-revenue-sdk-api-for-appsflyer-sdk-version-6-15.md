| **새로운 소식** | 이제 광고 수익 SDK 커넥터 대신 광고 수익 SDK API를 사용하여 노출 수준 광고 수익을 얻을 수 있습니다. |
| --- | --- |
| **시작하는 버전** | 앱스플라이어 SDK 버전 6.15 |
| **알아두어야 할 사항** | <ul><li>지금까지는 앱스플라이어 광고 수익 SDK **커넥터**를 통해 노출 수준 광고 수익을 제공했습니다. 적용일부터는 광고 수익 SDK API를 사용하여 앱스플라이어 **SDK** 자체(커넥터 아님)로 연동됩니다.</li><li>광고 수익 SDK 커넥터는 다음 버전에서 계속 작동합니다:<ul><li>앱스플라이어 안드로이드 SDK 버전 6.14.2 및 이전 버전.</li><li>앱스플라이어 iOS SDK 버전 6.14.6 및 이전 버전.</li></ul></li></ul> |
| **해야 할 일** | <ul><li>앱스플라이어 SDK 버전 6.15 이상으로 업그레이드하려면, 현재 구현된 광고 수익 SDK 커넥터를 제거하고 광고 수익 SDK API를 연동해야 합니다.</li><li>개발자의 도움이 필요합니다. 개발자 <Anchor target="_blank" href="https://dev.appsflyer.com/hc/docs/ad-revenue">광고 수익 SDK API 지침</Anchor>을 참조하세요.</li><li><Anchor target="_blank" href="/marketers/ko/docs/integrate-the-roi360-ad-revenue-sdk-api">노출 수준 광고 수익 SDK API 연동</Anchor>에 대해 더 알아보기.</li></ul> |
