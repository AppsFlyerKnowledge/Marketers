| 새로운 소식 | 원링크 템플릿이 사용자가 앱 없이 써드 파티 안드로이드 앱 스토어로 리다이렉트할 수 있는 옵션을 제공합니다. |
| --- | --- |
| 시행일 | 2023년 5월 31일 |
| 장소: | 원링크 템플릿 설정 |
| 내용 | 변경 전: 변경 전에: 원링크 템플릿은 사용자가 앱 없이 Apple 앱 스토어, 구글 플레이, 웹 URL로 리다이렉트할 수 있는 옵션을 제공합니다.<br /><br />변경 후: 변경 후에: 원링크 템플릿은 사용자가 앱 없이 다음 써드파티 안드로이드 앱 스토어에 리다이렉트할 수 있는 옵션 또한 제공합니다.<ul><li>화웨이 앱갤러리</li><li>샤오미 마켓</li><li>삼성 갤럭시 스토어</li><li>오포 앱 마켓</li><li>비보 앱 스토어</li></ul> |
| 알아두어야 할 사항 | <ul><li>써드파티 안드로이드 앱 스토어로 리디렉션하려면 다른 스토어에 있는 앱이 원링크 템플릿에서 선택한 안드로이드 앱과 같은 패키지 이름을 가져야 합니다.</li><li>APK 패키지 이름(예: com.shop.app)은 리디렉션에 사용되어 써드파티 앱 스토어를 선택하기 전 기존 APK 패키지 이름을 확정합니다.</li><li>안드로이드 앱에서 패키지 이름만 추출하여 사용자를 리다이렉트합니다. 이런 경우 리디렉션은 가능하지만 어트리뷰션은 가능하지 않습니다.</li><li>Google Play에 없는 안드로이드 앱을 선택하는 경우 모든 안드로이드 사용자를 리디렉트하는 URL을 입력해야 합니다.</li></ul>[![](https://files.readme.io/5e9df9148e5059160401391ef857ad965d1154e1ee7516bc33804de6badc5cd9-4403341605265.png)](https://files.readme.io/5e9df9148e5059160401391ef857ad965d1154e1ee7516bc33804de6badc5cd9-4403341605265.png) |
