| **새로운 소식** | 통합된 활동 데이터에는 UA 및 리타게팅 데이터가 모두 포함됩니다. |
| --- | --- |
| **업데이트 날짜** | 2025년 2월 1일 |
| **업데이트 항목** | 활동 및 피벗 대시보드, 마스터 API |
| **핵심 내용** | <ul><li>지금까지는 세션과 DAU 같은 일부 활동 지표가 UA 데이터만을 기반으로 계산되었습니다.</li><li>이제 모든 활동 지표에는 UA 및 리타게팅 데이터가 모두 포함됩니다. **참고**: UA와 리타게팅 데이터는 하나로 통합되어 표시되며, 각각 별도로 확인할 수는 없습니다.</li><li>일부 애드 네트워크의 경우, 이전에는 UA 캠페인에 어트리뷰트된 이벤트가 이제 리타게팅 캠페인에 어트리뷰트될 수 있습니다.</li><li>업데이트 후, 리타게팅 트래픽이 계산에 포함됨에 따라, DAU 및 MAU와 같은 지표가 증가할 수 있습니다.</li><li>2025년 2월 1일 이전 데이터의 경우, 다음 메트릭은 UA 트래픽 데이터만 포함합니다.<ul><li>액티비티 대시보드:<ul><li>총 세션</li><li>DAU</li><li>MAU</li><li>DAU/MAU</li><li>ARPDAU</li><li>비용</li><li>클릭</li><li>노출</li><li>전환율</li><li>eCPI</li></ul></li><li>피벗 대시보드, 마스터 API: 액티비티 KPI</li></ul></li></ul> |
