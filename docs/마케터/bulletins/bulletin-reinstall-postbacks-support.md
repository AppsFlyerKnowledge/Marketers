| 섹션 | 세부 정보 |
| --- | --- |
| **새로운 소식** | 이제 **앱 재설치 포스트백** 지원이 가능합니다. 이제 처음 설치와 구별될 수 있습니다. |
| 시행일 | 12:30: |
| **핵심 내용** | 이제 postbacks를 설치하면 postbacks를 다시 설치할 수도 있습니다. **Active Integration** 페이지에서 구성합니다.<ul><li>**지원되는 네트워크들** 현재 선택된 파트너와 함께 사용할 수 있습니다(예: Unity Ads). 더 많은 파트너가 곧 추가될 것입니다.</li><li>**지역:** Install postback 는 **Attribution** 탭의 **Default Postbacks** 섹션에 나타납니다. 지원되는 네트워크의 경우, 이제 재설치 후 반환을 제어합니다.</li><li>설정 **사용자용** 드롭다운을 **이 파트너만**으로 변경하여 **모든 미디어 소스(자연 포함)** 로 변경할 수 있습니다.</li><li>**형식:** 재설치 이벤트는 마크로 `is_reinstall=true`가 첨부된 설치 이벤트와 동일한 포트백 형식을 사용합니다.</li><li>창출 가치 이를 통해 특히 리타게팅에 중점을 둔 파트너의 경우 측정과 최적화를 개선할 수 있습니다.</li></ul> |
| **필요한 조치** | 이 기능은 지정된 파트너만 사용할 수 있습니다. 액세스에 관심이 있으시면 PDM에 문의하십시오. |
