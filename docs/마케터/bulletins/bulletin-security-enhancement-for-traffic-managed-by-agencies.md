| **새로운 기능** | 애드 네트워크에서 캠페인을 운영하는 광고주 대리로 트래픽을 관리하는 에이전시를 위한 보안 조치를 강화하고 있습니다. 데이터를 보호하고 보안을 유지하며 프로드를 줄이기 위해서입니다. 2024년 7월 14일부터 광고 네트워크가 승인한 에이전시의 트래픽만이 앱스플라이어에 기록되고 측정됩니다.<br /><br />**참고:**<ul><li>어트리뷰션 링크의 빈 af\_prt 파라미터에도 적용됩니다.</li><li>이는 <Anchor target="_blank" href="/marketers/ko/docs/self-reporting-networks-srns">SRN</Anchor>과 협력하는 에이전시에는 적용되지 않습니다.</li></ul> |
| --- | --- |
| **시행일** | 2024년 7월 31일 |
| **장소:** | <ul><li>**에이전시:** 연동 페이지</li><li>**광고 네트워크:** 보안 센터</li></ul> |
| **알아두어야 할 사항** | <ul><li>**에이전시:**</li><li>**파트너:**</li></ul> |
| **영향** | 지정된 날짜부터 애드 네트워크의 승인 목록에 등록되지 않은 에이전시는 트래픽이 기록 및 측정되지 않으며, 애드 네트워크에서 캠페인을 운영하는 모든 앱의 연동 페이지에 액세스할 수도 없습니다. |
