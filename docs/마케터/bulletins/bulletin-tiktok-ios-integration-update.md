| --- | --- |
| **새로운 소식** | 앱스플라이어는 iOS용 TikTok과의 Advanced Self-Reporting Network(SRN) 연동과 관련된 개인정보 보호 설정을 업데이트하고 있습니다. 변경 사항은 다음과 같습니다:<ul><li>기존의 **‘고급 개인정보 보호(AP)**’ 토글이 새로운 **‘고급 데이터 공유(ADS)**’ 토글로 대체되며, 이를 통해 TikTok은 앱스플라이어 내 다른 SRN 연동 기능과 동일한 기준을 적용받게 됩니다.</li><li>이번 변경 사항에 따라, 앱스플라이어는 광고 ID(IDFA)가 있는지 여부와 관계없이 모든 전환 이벤트를 TikTok과 공유하게 됩니다.</li></ul>이는 iOS 전환의 더 많은 부분이 어트리뷰션으로 반영된다는 뜻이며, TikTok은 더 포괄적인 성과 데이터를 바탕으로 캠페인을 최적화할 수 있습니다. |
| **시행일** | 2025년 6월 4일 |
| **주요 변경 사항:** | 설정이 자동으로 이전되므로 별도의 조치가 필요하지 않습니다. 현재 설정이 새로운 토글 기능과 어떻게 연동되는지 다음과 같습니다:<ul><li>현재 **‘고급 개인정보 보호’가** **꺼져** 있는 경우 → **‘고급 데이터 공유’가** **켜**지게 됩니다</li><li>현재 **‘고급 개인정보 보호’가** **켜져** 있는 경우 → **‘고급 데이터 공유’는** **꺼**지게 됩니다</li></ul> |
