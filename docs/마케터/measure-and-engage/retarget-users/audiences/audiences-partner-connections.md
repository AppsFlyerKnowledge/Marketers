## 파트너 연결 정보

파트너 연결을 사용하면 오디언스를 파트너에게 쉽고 지속적으로 보낼 수 있으므로 맞춤형 캠페인을 제공할 수 있습니다. 다음은 오디언스 파트너, 연결 요구 사항, 각 파트너가 지원하는 사용자 식별자 목록입니다.

**파트너에게 연결하려면 아래 표에서 파트너를 식별하고 다음 단계를 따르세요.**

* 만약 표가 특정 파트너 안내 링크를 포함한다면, 링크를 클릭하고 제공된 지침에 따라 진행합니다.  
  **--또는--**
* 만약 표에 필수 연결 요구 사항 (인증 정보) 목록이 포함되어 있다면,
  1. 파트너로부터 자격 증명을 가져옵니다.
  2. 오디언스에서 <Anchor target="_blank" href="/marketers/ko/docs/audiences-guide#create-a-new-connection">새 파트너 연결 만들기</Anchor> 지침을 따릅니다.

<div id="adobe-audience-manager-aam" />

<Accordion title="Adobe Audience Manager (AAM)">

앱스플라이어는 AAM에서 사용자가 선택한 **Data Source** 에 **Traits**를 만들고 동기화합니다.

**오디언스를 AAM에 연결하려면**:

1. [Adobe Marketing Cloud 대시보드에 로그인하기](https://bank.demdex.com/portal/login/Logout.ddx)
2. Manage Data > Data Sources 로 갑니다.
3. Data Sources 페이지에서, 새로운 Data Source 를 생성합니다.

   [![](https://files.readme.io/4f9e3f508fb70287ba2c605ef9f8099f7151e7530ac3312e752b26130751e428-31237653528593.jpg)](https://files.readme.io/4f9e3f508fb70287ba2c605ef9f8099f7151e7530ac3312e752b26130751e428-31237653528593.jpg)
4. 다음과 같이 형식을 완성합니다.

   * ID Type 을 **Device Advertising ID**로 설정합니다.
   * 데이터 소스 설정 중 Inbound 에서, **Customer ID** 를 활성화 합니다.
5. **저장**을 클릭하세요.  
   **Data Sources** 선택이 표시됩니다.
6. 나중에 사용할 수 있도록 Data Source ID를 기록합니다.
7. 좌측 메뉴에서, Administration > Groups 로 이동합니다.
8. **권한** 탭으로 이동합니다.

   [![](https://files.readme.io/b565e39220e13f58ee603ab2874bd4743b30f98f8395d1ad6b79f556b8fe3cd0-31237648132753.png)](https://files.readme.io/b565e39220e13f58ee603ab2874bd4743b30f98f8395d1ad6b79f556b8fe3cd0-31237648132753.png)
9. 새 그룹을 만듭니다.
10. 생성한 Data Source를 선택합니다.
11. **Save Object**를 클릭합니다.
12. **Admin** > **Users**로 갑니다.

<Accordion title="Amazon S3">

S3 연동을 생성하면, 앱스플라이어는 오디언스 디바이스 ID를 S3 버킷에 직접 전송할 수 있습니다. S3 에 전송된 파일은 다음 특성을 가집니다:

* 파일 이름: 오디언스 이름 및 날짜. 예, my\_audience\_2020-06-23.csv
* 콘텐츠: 디바이스 ID를 포함하면서, 머리글이 없는
* 추가 파일은 매일 작성됩니다. 기존 파일은 삭제되지 않습니다.
* 만약 분할 오디언스가 전송된 경우, 단일 ZIP 파일이 기록되지만 이 압축 파일은 각 파트너로 분할된 별도 파일을 포함하고 있습니다.

**오디언스를 Amazon S3에 연결하려면**:

1. 앱스플라이어에서 오디언스로 가서 오디언스를 선택합니다.
2. **Connect(연결)** 탭을 클릭합니다.
3. **+ 새 연결**을 클릭합니다.
4. **연결** 이름을 입력합니다.
5. **Amazon S3**을 선택합니다.  
   **연결 추가** 창이 열립니다.

   ![image__9_.png](https://files.readme.io/790f8a50bf14fbb4065d9dcee05e31fa866bc73f236f439ec73f2bc833b31be6-31237653533201.png)
6. C **로스 계정 역할 ARN**, **버킷 이름** 및 **지역 이름**을 입력합니다.  
   **참고:** 항상 리전 이름을 입력하는 것이 좋습니다. AWS에서 지역 이름이 기본적으로 자동으로 활성화되지 않으면 여기에 입력해야 하거나 연결을 만들 수 없습니다. AWS 콘솔 홈 페이지에서 지역을 찾으려면 페이지 우측 상단의 국가를 클릭하면 지역이 표시됩니다. <Image alt="region_name.jpg" src="https://files.readme.io/a3b65660a638674cbbe0da2802b4f926929d167d0b528c25c12ded6a90b0e981-31237648137489.jpg" width="355px" />
7. 나중에 사용할 수 있도록 Account ID 와 External ID 를 기록합니다.
8. **AWS** 콘솔에서, **IAM** > **Policies** 로 갑니다.
9. **정책 만들기**를 클릭합니다.
10. **JSON**을 클릭합니다.
11. 다음 정책 스니펫을 JSON 창에 붙여 넣습니다.  

    ```json
    {
    							"Version": "2012-10-17",
    							"Statement": [
    							{
    							"Effect": "Allow",
    							"Action": "s3:*",
    							"Resource": "arn:aws:s3:::BUCKET-NAME/*"
    							}
    							]
    }
    ```
12. **BUCKET-NAME**을 앱스플라이어가 광고주의 오디언스를 업로드하기 원하는 버킷 이름으로 바꿉니다.

    <div id="note" />

    > 📘 **참고**
    >
    > 정책(policy)은 루트 버킷(root bucket)만 포함하고 경로의 추가 디렉토리는 포함하지 않아야 합니다. 예를 들어, 리소스 **arn:aws:s3:::BUCKET-NAME/Directory/\*** 는 지원되지 않습니다. 파일을 특정 디렉토리로 전송해야한다면, 14 단계를 참조하십시오.


    액션 `PutObject`, `DeleteObject` 및 `ListBucket`은 앱스플라이어가 버킷에서 필요한 작업을 수행하기 위해 필수입니다.
13. **정책 검토**를 클릭합니다.
14. 정책 **이름**을 입력합니다.
15. **정책 만들기**를 클릭합니다.
16. AWS 콘솔에서 **액세스 관리**> **역할**로 이동합니다.
17. **역할 생성**을 클릭합니다.
18. AWS 계정과 앱스플라이어 AWS 계정 사이에 계정 간 액세스를 제공하려면 **기타 AWS 계정**을 선택합니다.
19. **계정 ID를 입력합니다. 앱스플라이어 대시보드에서 이미 복사한 계정 ID입니다.**
20. **Require external ID**를 선택합니다. AppsFlyer 대시보드에서 이미 복사한 외부 ID입니다.
21. AWS 계정에서 기존의 정책 중 정책을 선택하라고 뜨면, 이전에 작성한 정책을 선택합니다.
22. 속성 창을 열기 위해, 새로 생성된 롤 이름을 클릭합니다.
23. **Role ARN**을 기록합니다.
24. 앱스플라이어 S3 연동 창에서, ARN과 버킷 이름을 해당하는 필드에 입력합니다.

    파일을 버킷 내의 특정 폴더로 전송하려면, 버킷에 있는 후속 폴더와 함께 "/" 로 구분하여 버킷 이름을 제공합니다. (예: bucketname/foldername/foldername)

    아직 존재하지 않는 폴더 이름을 입력한 경우, 앱스플라이어는 업로드 과정에서 이 폴더를 생성합니다.
25. **Add Connection(연결 추가)** 를 클릭합니다.  
    연동 과정이 완료되고 오디언스가 업로드 되면, 디바이스 ID를 포함한 CSV가 지정된 버킷에 표시됩니다.

</Accordion>
