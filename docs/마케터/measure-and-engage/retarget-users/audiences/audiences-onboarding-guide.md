## 오디언스 정보

앱스플라이어 <Anchor target="_blank" href="/marketers/ko/docs/audiences-guide">오디언스</Anchor>를 통해 손쉽게 오디언스 세그먼트를 만들고 이를 소유 및 유료 광고 채널과 연결하여 더 나은 인게이지먼트와 성과를 위한 맞춤형 캠페인을 진행할 수 있습니다.

오디언스란 귀사가 정의한 특정 기준을 충족하는 앱 사용자 세그먼트(과거 또는 현재)를 말합니다. 기준은 개인적 특성, 행동, 어트리뷰션 소스, 발생한 수익, 지리적 위치, 디바이스 유형 등을 바탕으로 설정할 수 있어 고도로 커스텀된 마케팅 전략이 가능합니다.

처음부터 커스텀 오디언스를 구축하거나, 귀사의 데이터베이스에서 가져오거나, 업계 모범 사례를 기반으로 한 시간 절약형 커스터마이징 가능한 "제안된 오디언스" 중에서 선택할 수 있습니다. 오디언스는 귀사의 매체사 파트너와 연결되고, 회원 식별자를 파트너에게 보내 파트너 측에서 오디언스를 생성할 수 있게 합니다. 이를 통해 오디언스에 완벽하게 맞춤화된 광고를 제공할 수 있습니다. 오디언스는 매일 자동으로 새로워지며 파트너와의 원활하고 동적 프로세스를 통해 공유됩니다. 또한, 캠페인을 발송한 후에는 오디언스에서 직접 캠페인 성과 지표를 모니터링할 수 있습니다.

## 오디언스 온보딩

**오디언스를 사용하려면 아래 단계를 따르세요:**

| 작업 | 목적 | 필요한 조치 | 관련된 사람 |
| --- | --- | --- | --- |
| 1. 오디언스 구독 |  | 영업 담당자에게 연락하거나 [hello@appsflyer.com](mailto:hello@appsflyer.com)*으로 메일을 보내어 구독합니다. | 마케터 |
| 2. 계정 수준의 개인정보 보호정책 설정 | 이는 파트너와 사용자 식별자를 공유하기 위한 계정 수준의 정책을 설정합니다. | 개인정보 보호<Anchor target="_blank" href="/marketers/ko/docs/audiences-user-identifier-policy">정책</Anchor>을 설정하세요. | 마케터 |
| 3. 오디언스 생성 |  | 생성할 오디언스 유형을 선택하세요:<ul><li><Anchor target="_blank" href="/marketers/ko/docs/audiences-guide#create-a-suggested-audience">제안된 오디언스</Anchor> - 업계 모범 사례를 기반으로 한 기성형, 사용자 정의 가능한 오디언스.</li><li><Anchor target="_blank" href="/marketers/ko/docs/audiences-guide#create-a-custom-audience">커스텀 오디언스</Anchor> - 처음부터 오디언스를 생성하세요.</li><li><Anchor target="_blank" href="/marketers/ko/docs/audiences-import-audience-segments-from-internal-systems">가져온 오디언스</Anchor> - 귀사의 내부 시스템(BI 또는 CRM 등)에서 오디언스를 가져옵니다.</li></ul> | 마케터 |
| 4. 오디언스를 귀사의 파트너와 연결하세요 | 오디언스를 파트너와 연결하여 파트너 측에서 오디언스를 만듭니다. 오디언스는 매일 새로워집니다. | <ol><li>파트너 <Anchor target="_blank" href="/marketers/ko/docs/audiences-guide#create-a-new-connection">연결</Anchor>을 추가하세요.</li><li><Anchor target="_blank" href="/marketers/ko/docs/audiences-guide#connect-an-audience-to-media-partners">오디언스를 귀사의 파트너와 연결하세요</Anchor>.</li></ol> | 마케터 |
| **선택 작업** |  | <ol><li>파트너와 통제군으로 오디언스를 나누어 <Anchor target="_blank" href="/marketers/ko/docs/run-an-incrementality-for-remarketing-experiment">Incrementality</Anchor> 실험을 활성화하세요 (성과 증분 측정 솔루션 구독자를 위한).</li><li>유저 <Anchor target="_blank" href="/marketers/ko/docs/audiences-create-better-audiences-with-user-attribute-data">속성</Anchor>을 가져옵니다. 이는 고도로 개인화된 오디언스를 만들기 위해 공유하는 유저 특성입니다.</li></ol> | 마케터 |
| 5. 맞춤형 캠페인을 만들고 이를 파트너 측의 오디언스에게 제공합니다. |  | <ol><li>오디언스에 맞게 캠페인을 조정하세요.</li><li>파트너 측에서 오디언스를 선택하세요.</li><li>오디언스에게 캠페인을 제공합니다.</li></ol> | 마케터 |
| 6. 캠페인 결과를 분석하세요. |  | 오디언스 <Anchor target="_blank" href="/marketers/ko/docs/audiences-guide#campaign-metrics">및 기타 앱스플라이어 대시보드</Anchor>에서 캠페인 결과를 확인하세요. | 마케터, 데이터 분석가 |

* 오디언스를 구독한 후 앱스플라이어는 지난 90일 동안의 모든 인앱 이벤트 데이터를 불러옵니다. 이 과정은 1&#126;2주 정도 걸릴 수 있습니다. 완료되면 알림을 받게 되고 오디언스를 생성할 수 있습니다.
