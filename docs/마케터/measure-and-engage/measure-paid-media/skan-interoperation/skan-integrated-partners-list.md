## 앱스플라이어 SKAN 협력사

이 목록에 등록된 파트너들은 앱스플라이어와 연동이 되어 있으며 iOS SKAN 포스트백을 앱스플라이어에 전송합니다.

이 파트너들은 iOS 기기에서 받은 SKAN 포스트백을 앱스플라이어에 보냅니다. 게다가, 이들은 광고 구조와 리포팅 시스템에 기반한 보조 필드들을 포스트백에 추가합니다. 이런 보조 필드들은 포스트백에 더 많은 데이터를 추가해 귀하의 SKAN 캠페인의 성능 분석에 도움을 줍니다.

SKAN 포스트백은 파트너 연동 탭의 파트너 **활성화** 토글 상태에 관계없이 SKAN 개요 대시보드에 반영된다는 점을 알아두십시오.

다음은 사용 가능한 데이터 보강 필드입니다.

* **위치**: 어트리뷰션된 애드 네트워크가 국가 코드로 보고합니다.
* **보강 캠페인 ID**: 이 ID는 iOS 포스트백에서 보고된 **항상 사용 가능한 SKAN 캠페인 ID와는 구별됩니다.**
* **보강 캠페인 이름**: 리포트와 대시보드에서 표시됩니다.
* **보강 애드셋 ID**: 리포트와 대시보드에서 표시됩니다.
* **보강 애드셋 이름**: 리포트와 대시보드에서 표시됩니다.
* **보강 광고 ID**: 리포트와 대시보드에서 표시됩니다.
* **보강 광고 이름**: 리포트와 대시보드에서 표시됩니다.
* **보강된 비용**: 리포트와 대시보드에서 표시됩니다.
* **뷰-쓰루 어트리뷰션 지원 여부:** 본 필드는 애드 네트워크에서 보강되는 것이 아니라, SKAN 포스트백을 통해서 VTA 사용 가능 여부를 나타냅니다.
* **재다운로드:** 비-SRN을 위해 SKAN 2.0 포스트백의 일부로 제공됩니다.  
  모든 SRN은 SKAN 포스트백으로 인스톨 데이터를 전송합니다. 일부 SRN에서는 신규 앱 설치와 재다운로드를 구분하지 않으며, 그러한 SRN의 재다운로드 데이터는 SKAN 대시보드에서 표시되지 않음을 유의하세요.
