**<span id="setting-up-tune-integration"></span>전제 조건:** **연동 설정 전에 반드시  <Anchor target="_blank" href="/marketers/ko/docs/partner-integrations#contact-details">파트너에게 연락하여</Anchor> 계정을 개설하세요.**

**연동 활성화 또는 편집 방법:**

1. To activate:연동 활성화 방법: 앱스플라이어의 사이드 메뉴에서협업<strong>></strong>파트너 마켓플레이스**를 선택합니다.  
   **편집 방법:** 앱스플라이어의 사이드 메뉴에서 **협업** > 활성 연동을 선택합니다.**
2. 파트너를 검색하여 선택하세요.
3. **연동 설정**을 클릭합니다. 연동 설정 페이지로 이동합니다.
4. 연동 탭에서 **파트너 활성화**를 켭니다.  
   **참고: 파트너와 작업하는 동안에는 토글이 켜져 있어야 합니다(활성화됨).**
5. 다음 섹션에 설명된 대로 관련 탭을 사용하여 구성을 완료하세요.
6. 연동 저장을 클릭합니다.
