> **한눈에 보기:** 요약: 원링크로 생성된 URL을 사용하여 앱 사용자를 웹 URL 또는 소셜 미디어 페이지로 리디렉션합니다.

## 앱 사용자를 웹 URL로 리디렉션

광고주는 외부 웹 페이지 또는 소셜 미디어 사이트로 연결되는 원링크 URL을 게시할 수 있습니다. 앱스플라이어는 앱 내부의 링크에 대한 클릭을 측정하여 광고의 효과를 판단할 수 있습니다.

**선행 조건**: 최소 1개 이상의 앱이 있는 앱스플라이어 계정이 필요합니다.

**앱-투-웹 리디렉션을 설정하려면**:

1. <Anchor target="_blank" href="/marketers/ko/docs/create-a-onelink-template#원링크-템플릿-만들기">원링크 템플릿</Anchor>을 설정합니다.
   * **앱이 설치된 경우** 섹션에서 앱 열기 방법(유니버설 링크, 앱 링크 또는 URI 스키마)을 설정하지 않았는지 확인합니다.
2. <Anchor target="_blank" href="/marketers/ko/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#캠페인을-위한-원링크-링크-생성하기">원링크 커스텀 링크</Anchor>를 만듭니다.
   * **앱이 설치되지 않은 경우** 섹션에서 리디렉션 설정이 원하는 웹 URL인지 확인합니다.
