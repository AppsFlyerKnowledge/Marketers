## 데이터 협업 플랫폼(DCP)에 대해

AppsFlyer 데이터 협업 플랫폼(DCP)은 상거래 미디어 네트워크와 브랜드가 결합된 데이터의 잠재력을 발휘할 수 있는 고급 차세대 솔루션입니다. 보안 및 프라이버시 중심적인 기능을 통해 플랫폼은 원활한 협업을 가능하게 하여 기업이 새로운 광고 수익 흐름을 생성하고 어디서든 정확한 캠페인 활성화를 위한 맞춤형 오디언스를 구축할 수 있도록 합니다.

DCP는 사용자 수준 데이터를 포함한 공유 데이터를 처리하여 익명화된 통찰력을 생성하며, 개별 사용자 정보가 AppsFlyer와 협력 파트너에게 노출되지 않도록 완벽하게 보호합니다. 엄격한 거버넌스와 컴플라이언스가 시행되며, 모든 당사자는 정보의 무단 공유나 오용을 방지하기 위해 접근 및 사용 정책에 동의합니다. 파트너 소스의 데이터를 결합함으로써 기업은 자체 데이터에만 의존하는 것보다 훨씬 더 포괄적이고 영향력 있는 집계된 통찰력을 열어젖힐 수 있습니다.

14,000개 이상의 글로벌 브랜드와 수천 개의 고객 데이터 플랫폼(CDP), 미디어 파트너 및 강화 도구의 협업 생태계에 접근할 수 있게 되면서, DCP는 비교할 수 없는 수익과 결과를 제공하는 영향력 있는 데이터 기반 협업을 주도합니다. DCP는 상거래 미디어 네트워크와 브랜드 모두가 최대의 캠페인 결과와 수익을 달성하고, 파트너십을 강화하며, 경쟁이 치열한 디지털 환경에서 성공할 수 있도록 지원합니다.

**데이터 협업 플랫폼(DCP)은 다음을 가능하게 합니다:**

* 기술적인 지식이 없는 브랜드 측 마케터가 독립적으로 데이터를 활용하여 청중을 구축하고 사이트나 다른 곳에서 광고를 게재함으로써 수익성 있는 새로운 수익 흐름을 창출합니다.
* 모든 소매 미디어 시나리오에서 협업 데이터를 기반으로 SKU 수준의 세분성을 갖춘 캠페인 성과를 측정하여 귀하와 협력하는 브랜드를 위해 마케팅 캠페인 투자를 자신 있게 추진합니다.
* 데이터 전문가 없이도 여러 협업을 위한 데이터를 재구성하고 정규화하며 민감한 정보를 보호합니다.
* IDR 제공업체, 기타 클린룸 및 플랫폼과의 원활한 통합을 생성하고 유지하여 데이터 프라이버시를 보호하면서 생태계 전반에 걸쳐 확장, 적응 및 협업할 수 있습니다.
* 글로벌 및 현지 프라이버시 규정에 부합하는 비즈니스 성장을 하고 있다는 것을 알고 안심할 수 있습니다. 모든 협업에서 안전하고 규정 준수적인 데이터 협업이 보장됩니다.

## 활용 사례

일부 협업 사용 사례 예제를 참조하십시오.

<div id="personalized-marketing-to-consumers" />

<Accordion title="소비자를 위한 개인화된 마케팅">

개인의 쇼핑 행동을 기반으로 맞춤형 광고를 생성하기 위해 상거래 소매업체와 브랜드 간에 익명화된 데이터를 교환합니다.

> 📄 **예시: 비전통적 광고**
>
> 부문 간 협력: 저렴한 패션 브랜드는 기저귀를 자주 구매하는 슈퍼마켓 고객(영유아의 부모 또는 보호자)을 대상으로 합니다. 그들은 유아 의류 광고를 홍보합니다.

> 📄 **예시: 전통적 광고**
>
> 구매 준비가 된 고객에게 도달: 식품 배달 소매업체는 패스트푸드 브랜드와 협력합니다. 소매업체는 식품 배달을 주문하는 광범위한 사용자 기반을 활용하여 브랜드의 특별 세일을 앱에서 직접 홍보합니다. 브랜드는 가시성을 얻고 더 정확하고 개인화된 고객에게 도달하여 캠페인 성과를 향상시킵니다.

</Accordion>

<div id="audience-segmentation-and-targeting" />

<Accordion title="잠재 고객 세분화 및 참여">

익명화된 구매 이력 및 브라우징 행동을 사용하여 "가치를 중시하는 쇼핑객" 또는 "브랜드 충성도가 높은 고객"과 같이 구매 준비가 된 것으로 간주되는 고객 세그먼트를 식별합니다.

> 📄 **예시: 비전통적 광고**
>
> 브랜드는 소매업체와 협력하여 운동화를 홍보합니다. 브랜드는 소매업체의 인앱 검색에서 지난 7일 이내에 운동화를 검색했지만 구매하지 않은 쇼핑객을 참여시키고자 합니다.

> 📄 **예시: 비전통적 광고**
>
> 한 의류 브랜드가 CMN 호텔 체인과 협력하여 열대 지역을 방문하는 여행객들에게 여름 컬렉션을 홍보합니다.

</Accordion>

1. 어떤 데이터를 포함할지 고려하십시오. 목표와 잠재적 협력업체의 목표에 따라 협업에 포함할 유용한 데이터를 결정합니다. 가치 있는 관련 데이터를 정확히 파악합니다.

* **인바운드 연결** 은 소스를 만들 때 자체 데이터에 액세스하는 데 사용됩니다.
* **출발 연결** 플랫폼 내에서 구축된 청중을 위한 목적지로 기능합니다.

**클라우드 스토리지 인프라를 설정하려면:**

## 추가 정보

데이터 협업 플랫폼에 대한 추가 정보를 참조하세요.

<div id="data-clean-room-dcr-and-dcp" />

<Accordion title="데이터 클린룸(DCR) 및 DCP">

데이터 협업 플랫폼(DCP)은 잠재고객 생성 및 활성화를 포함한 데이터 협업의 중심 역할을 합니다. DCP는 다음의 고급 기술에 의존합니다. <Anchor target="_blank" href="/marketers/ko/docs/data-clean-room-overview">데이터 클린룸(DCR)</Anchor> 데이터 협업 및 잠재고객 관리 프로세스에 대한 데이터 프라이버시와 보안을 보장합니다.

</Accordion>

<div id="commonly-used-terms::8d835d5a" />

<Accordion title="자주 사용되는 용어">

데이터 협업 플랫폼과 관련하여 사용되는 몇 가지 주요 용어를 이해합니다.

| 용어 | 설명 |
| --- | --- |
| <span id="audiences"></span>오디언스 | 결합된 데이터 세트에서 DCP 내에서 생성된 세분화된 데이터 파일입니다. 동의된 권한에 따라, 이 오디언스는 미디어 파트너와 함께 활성화되거나 협력자의 클라우드 연결로 전송됩니다. |
| <span id="data-connections"></span><Anchor target="_blank" href="/marketers/ko/docs/data-collaboration-platform-dcp-add-connections">**데이터 연결**</Anchor> | 당사의 1차 데이터가 저장된 클라우드 서비스에 대한 연결입니다. 이 연결은 협력자와 데이터를 공유하거나 DCP에서 생성된 오디언스를 받는 데 사용됩니다. |
| <span id="data-sources"></span><Anchor target="_blank" href="/marketers/ko/docs/data-collaboration-platform-dcp-create-and-manage-sources">데이터 소스</Anchor> | DCP에서 사용되는 1차 데이터 파일의 위치가 있는 구조화된 폴더입니다. 이 폴더는 플랫폼 내에서 데이터를 쿼리하고 오디언스를 구축할 때 사용됩니다. |
| <span id="endemic-advertising"></span>**내재적 광고** | 시장에 자연스럽게 어울리는 광고 배치로, 검색이 이루어지는 전자상거래 사이트에서 일반적으로 판매되는 제품을 설명합니다. |
| <span id="nonendemic-advertising"></span>**비지역광고** | 소매업자가 판매하지 않는 브랜드의 제품이나 서비스를 홍보하기 위해 소매업자의 광고 인벤토리를 매입하고 판매하는 관행입니다. 이는 소매업자의 고객과 그들의 요구에 관련이 있거나 보완적인 브랜드의 제품이나 서비스를 홍보하는 것입니다. |
