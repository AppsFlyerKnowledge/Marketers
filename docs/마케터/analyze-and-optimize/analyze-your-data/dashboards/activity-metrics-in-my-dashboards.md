> **한눈에 보기:** <Anchor target="_blank" href="/marketers/ko/docs/my-dashboards">내 대시보드</Anchor>에서 활동 메트릭을 사용하여 앱 성능을 신속하게 평가하고, 참여 추세를 파악하며, 수익을 분석하고, 문제를 조기에 감지할 수 있습니다. 모든 날짜 범위에서 향상된 정확성과 유연성을 제공합니다.

> 📘 **참고**
>
> 수익 지표는 2026년 7월부터 8월까지 고객 에게 점진적으로 공개될 예정입니다. 아직 해당 아이템이 보이지 않더라도 별도의 조치는 필요하지 않습니다. 해당 아이템들은 이 기간 내에 계정에 추가될 예정입니다. 보다 <Anchor target="_blank" href="/marketers/ko/docs/bulletin-cohort-and-activity-metrics-update-in-my-dashboards">회보: 내 대시보드에서 코호트 및 활동 지표가 업데이트되었습니다.</Anchor> .

## 활동 메트릭에 대하여

내 대시보드의 활동 메트릭은 사용자가 한 곳에서 활동, LTV 및 코호트 데이터를 분석할 수 있도록 합니다. 이를 통해 비즈니스 성과를 모니터링하고 다음과 같은 방법으로 더 깊은 통찰력을 얻을 수 있습니다:

* 실시간 관련성을 통해 **사용자 활동 및 고착도**를 분석합니다.
* **이벤트 성과, 수익 및 세션 추세를 측정합니다.**  
  단일 대시보드에서 **LTV, 실제 및 코호트** 기간에 대한 통합된 가시성을 얻습니다.
* **일일 또는 월간** (활성 사용자) 세분화를 사용하여 보고서를 사용자 정의합니다.

참고: 내 대시보드에서 A**ctivity**라는 용어는 **Actual**로 이름이 변경되었습니다. 이 변경은 이러한 메트릭이 선택한 날짜 범위 동안 실제 사용자 행동을 반영하며 LTV 집계와 연결되지 않음을 명확히 합니다. Actual은 세션, 총 이익 및 총 수익의 기본 기간이기도 합니다.

## 대시보드 정보

**액티비티 뷰(Activity View).**

앱의 전체적인 성과 모니터링을 위해 설계된 **액티비티 뷰** 템플릿은 마케터가 앱 성과를 신속하게 평가하고, 인게이지먼트 추세를 파악하며, 수익을 분석하고, 문제를 조기에 감지할 수 있도록 도와줍니다. 이를 통해 캠페인과 플랫폼 전반에 걸쳐 데이터 기반의 의사결정을 신속하게 내릴 수 있습니다.

**대시보드에 위젯 추가하기**

대시보드의 오른쪽 상단에 있는 **+ 새로 만들기** 버튼을 클릭하여 대시보드에 위젯을 추가하고, 만들고자 하는 위젯 유형을 선택할 수 있습니다: 테이블, KPI, 차트, 인앱 이벤트 테이블, 인앱 이벤트 차트, 또는 커스텀 지표. 더 자세한 지침은 <Anchor target="_blank" href="/marketers/ko/docs/my-dashboards#add-widget">여기</Anchor>에서 확인할 수 있습니다.

**차트 또는 테이블에 메트릭 추가하기**

차트 설정 또는 테이블 설정 대화 상자에서 메트릭 + 더하기 기호를 클릭합니다.

그런 다음 차원별 그룹을 추가하고 필터를 선택할 수 있습니다.

더 자세한 지침은 <Anchor target="_blank" href="/marketers/ko/docs/my-dashboards#add-metric">여기</Anchor>에서 확인할 수 있습니다.

## 사용 가능한 활동 메트릭

* 활성 사용자, 지난 31일의 활성 사용자 및 DAU/MAU를 제외한 모든 메트릭은 코호트 기간 및 LTV를 지원합니다.

| **지표** | **설명** |
| --- | --- |
| 활성 유저 | <ul><li>선택한 기간 동안 세션을 기준으로 앱을 최소한 한 번 이상 연 고유 활성 사용자 수입니다. 선택한 시간 분해 설정에 따라 다릅니다.</li><li>일일이 선택되면 DAU로 표시됩니다.</li><li>월간이 선택되면 MAU로 표시됩니다.</li><li>선택한 날짜별로 그룹화된 선형 차트, 열 차트 또는 테이블에서 볼 때 DAU로 표시됩니다.</li><li>DAU 및 MAU에 대한 원시 데이터 보고서를 쿼리하는 방법에 대한 정보는 다음을 참조하십시오: 일일 및 월간 활성 사용자(Daily Active Users 및 Monthly Active Users) 계산</li></ul> |
| 지난 31일 동안의 활성 사용자 수 | 이전 31일 동안 앱을 최소한 한 번 이상 연 고유 사용자 수(달력 월을 기준으로 하지 않음)입니다. |
| DAU/MAU | 재방문 사용자 비율(스티키니스).<br /><br />DAU/MAU 비율이 50%라는 것은 평균 사용자가 지난 31일 중 15일 동안 앱을 실행했음을 의미합니다.<br /><br />DAU/MAU 비율은 사용자 고착도를 측정하는 척도이며 사용자 유지율에 대한 스냅샷을 제공합니다.<br /><br />공식: 일일 활성 사용자 / 지난 31일간의 활성 사용자 |
| 세션 수 | 선택한 날짜 범위 내의 세션 수입니다. |
| Total revenue | 선택한 기간 동안 발생한 수익입니다. 수익은 인앱 구매 및 광고 수익으로 구성됩니다. |
| 순 이익 | 선택한 기간의 수익 af\_net\_revenue 이벤트 매개변수에서 집계됩니다. ROI360 앱 내 수익 사용하는 앱의 경우, 이는 총 수익 에서 앱 스토어 수수료 및 세금을 뺀 금액입니다(순수익 = 총 수익 - 앱 내 수수료 - 세금). af\_net\_revenue를 직접 전송하는 앱은 계산 방식을 정의합니다. |
| 첫 방문 | 웹 앱 최초 방문 횟수. conversion\_name = first\_visit인 행으로 계산됩니다. 웹 앱에서만 사용 가능합니다. |
| 재방문 | 웹 앱에 대한 논오가닉 재방문 횟수. conversion\_name이 revisit인 행으로 계산됩니다. 웹 앱에서만 사용 가능합니다. |
| 유저 유입 | 크로스 플랫폼 어트리뷰션 또는 웹 앱에서 사용 가능합니다. 웹 앱의 경우, 유저 획득 이벤트가 구성되지 않은 한 유저 획득은 첫 방문을 반영합니다. 모바일 앱의 경우 유저 확보는 설치 수와 같습니다. 여러 앱을 함께 볼 경우, 유저 확보는 설치 수 + 첫 방문 수(또는 클라이언트가 구성한 커스텀 웹 이벤트 )를 합산한 수치입니다. |

## 사용 가능한 인앱 메트릭

| **지표** | **설명** |
| --- | --- |
| 전환율 | 이벤트를 수행하는 고유 사용자(어트리뷰션)의 비율. 공식: 이벤트 고유 사용자 수 / 어트리뷰션 수 x 100 |
| 고유 사용자 | 이벤트를 수행하는 고유 사용자(어트리뷰션) 수 |
| 평균 횟수 | 어트리뷰션당 해당 이벤트가 수행된 평균 횟수.<br /><br />공식: 이벤트 수 / 어트리뷰션 |
| eCPA | 액션당 유효 비용(이벤트).<br /><br />공식: 비용 / 이벤트 고유 사용자 |
| 횟수 | 해당 이벤트가 수행된 횟수 |
| 수익 | 해당 특정 이벤트에서 발생한 수익 |
| ARPU | 사용자당 평균 수익.<br /><br />공식: 매출 / 고유 사용자(사용자 = 어트리뷰션) |
| 총 이익 | 수익 - 비용 |
| ROAS | 광고 투자 수익률.<br /><br />공식: 수익 / 비용 * 100 |
| ROI | 투자 수익률:<br /><br />공식: (수익 - 비용) / 비용 * 100 |
| 순 이익 | 이 특정 이벤트 로 발생한 수익 ( 앱 스토어 수수료 및 세금 공제 후). |
| Net ARPU | 사용자당 평균 순매출<br /><br />공식: 순매출 / 고유 사용자(사용자수 = 어트리뷰션수) |
| 순매출 총이익 | 순 이익 - 비용 |
| Net ROAS | 광고 지출 ( 순매출 기준).<br /><br />공식: 순 이익 - 비용 |
| 순 ROI | 순매출을 기준으로 한 투자 수익률<br /><br />공식: (순매출 - 비용) / 비용 * 100 |

**수익 지표**

순매출 지표( 수익, 순 ROI, 순ROAS, 순 ARPU, 순총이익)는 총 수익 수익 아닌 순매출을 보여줍니다. 수익 은 af\_net\_revenue에 전달된 가치 이며, 광고주는 계산 방식을 정의합니다(예: 앱 내 수수료 및/또는 세금 차감 후 수익 , 총 마진 또는 서비스 수수료 차감 후 수익 ). ROI360 앱 내 수익 사용하는 앱의 경우 앱스플라이어 총 수익에서 앱 스토어 수수료와 세금을 뺀 금액(순 수익 = 총 수익 - 앱 내 수수료 - 세금)으로 계산합니다.

이 가치 일반적인 수익 측정 지표에서 af\_revenue를 사용하는 방식과 마찬가지로 인앱 이벤트 의 af\_net\_revenue 매개변수에서 가져옵니다. 가치 은 거래 통화로 표시되며, af\_currency(기본값은 USD)로 나타냅니다.

가치 채워지는 방식:

* 앱에 **ROI360 앱 내 수익** 기능이 활성화된 경우, 앱스플라이어 인앱 구매 및 구독 이벤트 기록 시 af\_net\_revenue 필드를 자동으로 채웁니다.
* 그렇지 않으면 해당 가치 인앱 이벤트 에서 전송하는 af\_net\_revenue 매개변수에서 가져옵니다.
* 어느 쪽에서도 수익 제공하지 않으면 해당 항목에는 N/A가 표시됩니다.

<Anchor target="_blank" href="/marketers/ko/docs/about-roi360-store-revenue">ROI360 앱 내 수익</Anchor> 및 <Anchor target="_blank" href="/marketers/ko/docs/in-app-events-event-structure">인앱 이벤트 - 이벤트 구조</Anchor> 에 대한 자세한 내용을 참조하세요.

## 사양 및 제한 사항

| **사양** | **비고** |
| --- | --- |
| 데이터 최신성 | 코호트 및 활동 지표의 경우 웹, CTV, PC 및 콘솔 앱에서는 실시간 기능이 지원되지 않습니다.<br /><br />**참고:** CTV 및 PC/콘솔 앱의 LTV 지표는 실시간으로 제공됩니다. 이 제한 사항은 활동 및 코호트 데이터에만 적용됩니다. |
| 시간 단위 | 웹, CTV, PC 및 콘솔 앱의 경우 코호트 및 활동 데이터는 일 단위로만 제공됩니다. 이러한 플랫폼에서는 주간 및 월간 분석이 지원되지 않습니다. |
| 광고 수익 | 실시간 데이터는 지원되지 않습니다. |
| 수익 지표 - 기간별 | 활동 및 코호트 지표를 지원합니다. iOS 14.5+ 이상 버전에서는 지원되지 않습니다. |
| 수익 지표 - 데이터 최신성 | 실시간은 지원되지 않습니다. 데이터는 다음 날부터 이용 가능합니다. |
| 수익 지표 - 광고 수익 | 광고 수익 발생 건은 수익 지표에 포함되지 않습니다.<br /><br />**팁:** 광고 수익 포함한 수익 확인하려면 수익 에 광고 수익 더하는 커스텀 측정항목을 만드세요. 예를 들면 다음과 같습니다. 수익 + 수익(이벤트: af\_ad\_revenue). <Anchor target="_blank" href="/marketers/ko/docs/beta-set-up-custom-metrics-in-my-dashboards">'내 대시보드에서 커스텀 측정항목 설정'을</Anchor> 참조하세요. |
| 수익 지표 - 기여도 분석 소스 | SKAN 및 SSOT 에서는 지원되지 않습니다. |
| 수익 지표 - 플랫폼 | 안드로이드 및 iOS (모바일)에서만 사용 가능합니다. |
| 시간대 | 모든 메트릭은 UTC 전용을 제외한 현지 시간대에서 지원됩니다:<ul><li>지난 31일 동안의 활성 사용자 수</li><li>DAU/MAU</li><li>월별 그룹화된 활성 사용자(MAU)</li></ul> |
| 차트 | 현재 **DAU**를 행 또는 열 형식으로 지원합니다. |
| 위젯 | KPI 및 테이블 위젯은 모든 활동 지표를 지원합니다. |
| 일일 데이터 범위 | 보기당 62일로 제한됩니다. |
| 제거 이벤트 | 활동 데이터에 포함되지 않음 |
| 과거 데이터 | 최대 3년 (일일) |
| 지리 그룹화 | 설치 시점의 지리를 기반으로 하며, 상위 62개 지리로 제한됩니다. |
| 세션 지표 | <ul><li>활동 데이터는 2025년 2월 1일부터 UA 및 리타겟팅을 위해 통합됩니다.</li><li>**귀속 유형** 값을 **재참여** 및 **재귀속**으로 필터링하여 리타겟팅 보기를 볼 수 있습니다.</li></ul> |
| 통합 보기 지표 | 모든 지표는 통합 보기에서만 지원됩니다. |
