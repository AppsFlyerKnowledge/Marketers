## 커스텀 대시보드

모든 커스텀 대시보드는 유저 인입 지표를 포함하는 하나 이상의 위젯으로 구성됩니다. 위젯 마법사를 사용하여 지표, 프레젠테이션 형식, 앱 등을 선택하여 위젯을 구성합니다.

사용 가능한 지표는 개요 대시보드 유저 인입 보기 지표와 유사합니다. 참고! 일러두기! 통합 개요 또는 리타게팅 뷰와 비교하지 **마십시오**.

커스텀 대시보드가 정의되면 계정의 모든 사용자가 사용할 수 있습니다. 

<div id="dashboard-personalization" />

## 대시보드 개인화

위젯을 이동 및 크기 조정하여 대시보드를 개인화할 수 있습니다.

| 개인화 옵션 | 설명 |
| --- | --- |
| 위젯 크기 조정 | 위젯의 맨 아래 오른쪽 모서리를 끌어서 크기를 조정합니다. |
| 위젯 위치 | 대시보드에서 위젯을 드래그 앤 드롭하여 위치를 변경합니다. |
| 작업 | 오른쪽 상단 모서리에 있는 위젯 위에 마우스를 가져가 조치를 클릭하십시오. 위젯별로 다음 조치를 사용할 수 있습니다.<ul><li>수정</li><li>복제</li><li>삭제</li><li>CSV 다운로드</li></ul> |

## 절차

<div id="managing-dashboards" />

<Accordion title="대시보드 액션">

| 작업 | 설명 |
| --- | --- |
| 복제 | 현재 대시보드의 사본 작성 |
| 피봇 이름 수정 | 대시보드의 이름 변경 |
| PNG로 내보내기 | PNG 파일 생성 및 다운로드 |
| 삭제 | 대시보드 삭제 |

</Accordion>

<div id="add-a-custom-dashboard" />

<Accordion title="커스텀 대시보드 추가">

**커스텀 대시보드 추가 방법:**

1. 대시보드가 표시됩니다.
2. + (새 대시보드 추가)를 클릭합니다.
3. **대시보드 제목**을 입력합니다.
4. **Add.** 를 눌러주세요
5. 다음 절에서 설명한 대로 하나 이상의 위젯을 추가합니다.

</Accordion>

<div id="managing-widgets" />

<Accordion title="위젯 관리">

**위젯 추가 방법:**

1. 위젯 추가를 클릭합니다.
2. 위젯 창이 표시됩니다.    

   <Image align="center" alt="WidgetConfigure_us-en.png" src="https://files.readme.io/f04544d8cb8b1d946526c4546565fffb405e5113e09dac65e5a28e218a1170a7-360015793618.png" />
3. 위젯을 설정합니다. 다음의 위젯 설정 안내서를 사용합니다.
4. 필요에 따라 위젯을 더 추가합니다.

**위젯 설정 안내서**

| 설정 | 설명 |
| --- | --- |
| 위젯 유형 | ![WidgetType_us-en.png](https://files.readme.io/00174da67c1b5046033655aad2f0af815d5abb3229cdc7c2f225f689c8adc7d8-360015793638.png)<br /><br />위젯 유형 선택:<ul><li>파이 차트</li><li>바 차트</li><li>선형 차트</li><li>데이터 테이블</li><li>지도</li><li>지표</li><li>깔때기 차트</li></ul> |
| 설명 | 위젯 설명 입력 |
| 앱 | 위젯 데이터에 포함할 1개 이상 또는 모든 앱을 선택합니다. 모두를 선택하는 경우 계정의 최상위 100개 앱을 선택한다는 것에 유의하십시오. |
| KPI | <ul><li>위젯에 표시할 KPI 선택</li><li>선택한 첫 번째 KPI에 따라 데이터 표와 바 차트 정렬</li></ul> |
| 그룹별로 | 그룹 선택 기준 |
| 맨 위 표시 | 표시할 값 개수를 입력합니다. |
| 코로나 이전 | 선택한 경우 코로나 19 이전 날짜 범위인 2019년 11월 1일부터 30일까지의 데이터를 표시합니다. |
| 필터 | 필터를 사용하여 위젯의 데이터를 제한합니다.<ul><li>**국가(지역)**</li><li>**미디어소스**</li><li>**캠페인**</li><li>**채널**</li></ul>미디어 소스에 어트리뷰트되지 않는 데이터를 명시적으로 배제하려면 **오가닉 배제**를 선택합니다. |

</Accordion>

<div id="export-widget-data" />

<Accordion title="위젯 데이터 내보내기">

<Image align="center" alt="Widget_table.png" src="https://files.readme.io/b04e80e16d0d34946e6783103fc6fbbdf89b390842db27226b4fdba6c1f7e506-360015717057.png" />

**위젯 데이터를 CSV 파일로 다운로드하는 방법**:

1. 위젯에 제목 및 데이터가 포함되어 있는지 확인하십시오.
2. 위젯에서 **액션**을 선택합니다.
3. **CSV 내보내기**를 선택합니다.  
   파일을 다운로드합니다.  
   CSV 파일의 날짜 형식은 dd/mm/yyyy입니다. Excel에서 이 형식을 mm/dd/yyyy와 같은 <Anchor target="_blank" href="https://answers.microsoft.com/en-us/msoffice/forum/msoffice_excel-mso_winother-mso_2010/how-to-convert-ddmmyyyy-to-mmddyyyy/41119ed6-4057-4598-a44c-1ebfdf301a43">다른 형식으로 전환</Anchor>할 수 있습니다.

</Accordion>

## 특징 및 제약 사항

<div id="traits-and-limitations::6693dfa7" />

<Accordion title="특징 및 제약 사항">

| 특징 | 비고 |
| --- | --- |
| 리포트에 대한 광고 네트워크 액세스 | 아니요 |
| 대행사 | 지원되지 않음 |
| 에이전시 투명성 | 예 |
| 앱별 시간대 | 계정에 있는 모든 앱의 표준 시간대 설정이 동일하면 앱별 표준 시간대를 사용하여 데이터가 표시됩니다. 그렇지 않은 경우 데이터는 USD로 표시됩니다. |
| 앱별 통화 | 계정에 있는 모든 앱에 동일한 통화가 설정되어 있으면 데이터는 앱 고유 통화로 표시됩니다. 그렇지 않은 경우 데이터는 USD로 표시됩니다. |
| 비용 데이터 | 최소 1개의 기록된 인스톨이 있는 경우에만 사용할 수 있습니다. <Anchor target="_blank" href="/marketers/ko/docs/roi360-cost-aggregation-overview#cost-data-availability-and-reports">더 알아보기</Anchor> |
| 오가닉 데이터 | 사용 가능 |
| 논오가닉 데이터 | 사용 가능 |
| eCPA |  |
| 데이터 최신성 | <Anchor target="_blank" href="/marketers/ko/docs/about-data-freshness-and-timezone-support#continuous-aka-realtime">실시간</Anchor>. 개요 대시보드와 동등합니다. |
| 계정 유저 액세스 | 예 |
| 제한 사항 | <ul><li>전체 페이지를 PDF로 내보내는 것은 사용 불가입니다.</li><li>특정 캠페인 검색은 캠페인 수가 100개 미만인 경우로 제한됩니다. 필요한 경우 기간을 좁히고 다시 검색합니다.</li><li>리타게팅, 리텐션, 활동 및 Protect360 KPI는 사용할 수 없습니다. 참고! 일러두기! 커스텀 대시보드 지표를 통합 개요 또는 리타게팅 뷰 지표와 비교하지 마십시오.</li><li>캠페인 이름 변경은 지원하지 않습니다.</li></ul> |
| 시간대 | <ul><li>계정의 모든 앱의 시간대 이름이 동일한 경우 데이터는 앱 시간대를 사용하여 표시됩니다. 그렇지 않으면 UTC가 사용됩니다.</li></ul> |
| 과거 데이터 | 5년 |

</Accordion>
