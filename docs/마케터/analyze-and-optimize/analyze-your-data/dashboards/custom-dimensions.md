> **한눈에 보기:** 고유한 차원을 정의하고 이를 사용하여 개요 대시보드에서 데이터를 그룹화하고 볼 수 있습니다.

<Embed title="사용자정의 기준" typeOfEmbed="iframe" url="https://fast.wistia.com/embed/iframe/tvcdofnwjo" providerUrl="https://fast.wistia.com" />

## 개요

사용자 지정 차원을 사용하면 기존 차원을 사용하여 비즈니스 목적과 관련된 데이터 분석을 위한 고유한 차원을 만들 수 있습니다. 이러한 차원은 개요 대시보드의 모든 위젯에서 데이터를 그룹화하는 데 사용할 수 있으며, 더 심층적인 인사이트를 얻고 비즈니스 목표에 부합하는 데이터 기반 의사 결정을 내리는 데 도움이 됩니다.

생성한 사용자 지정 기준은 계정 레벨에 있으며, 이는 동일한 앱스플라이어 계정의 다른 앱이 동일한 사용자 지정 기준을 사용할 수 있음을 의미합니다.

### 장점

* 표준 차원 이상의 추가 정보를 캡처하면 데이터에 대한 보다 심층적인 통찰력과 보다 포괄적인 이해를 얻을 수 있습니다.
* 세분화된 분석: 특정 관련 속성 또는 특성을 기반으로 데이터를 그룹화하고 분석하여 사용자 행동, 고객 세그먼트 또는 제품 성능을 보다 자세히 파악할 수 있습니다.
* 향상된 리포트 기능: 고유한 보고 요구 사항에 맞는 사용자 지정 대시보드 및 리포트를 만듭니다.
* 향상된 의사 결정: 비즈니스 목표에 부합하는 사용자 지정 차원을 캡처하여 정보에 입각한 결정을 내릴 수 있습니다. 사용자 지정 차원은 다양한 변수와 요인이 핵심성과지표(KPI)에 미치는 영향을 평가하는 데 필요한 컨텍스트를 제공하여 추세, 패턴 및 최적화 기회를 식별하는 데 도움이 됩니다.

### 사용 사례 예시

| 사용 사례 예시 | 설명 |
| --- | --- |
| 캠페인 의도 | <ul><li>캠페인 이름을 기반으로 합니다.</li><li>가치 이름을 선택하여 다양한 캠페인 목표를 차별화합니다. 예를 들어 브랜드 인지도를 'brd'로 표시하고 사용자 확보 캠페인에 '신규' 또는 'ua'로 레이블을 지정합니다.</li><li>캠페인 이름에 값 이름을 포함합니다. 예를 들어: "US\_Facebook\_BRD" or "UK\_Google\_new".</li><li>앱스플라이어는 캠페인 이름을 구문 분석하고 라벨을 기반으로 데이터를 그룹화합니다.</li></ul> |
| 지역 | <ul><li>지역을 기반으로 합니다.</li><li>여러 지역/국가를 지역으로 그룹화합니다. 예를 들어: 예: 미국, 캐나다 및 멕시코를 "북미"로 그룹화하거나 다른 지역을 사용하여 유럽, APAC 등에 대한 그룹을 만듭니다.</li><li>앱스플라이어는 리전 값(북미, 유럽, APAC 등)을 기준으로 데이터를 그룹화합니다.</li></ul> |
| 온드 미디어 vs 유료 미디어 | <ul><li>미디어 소스를 기반으로 합니다.</li><li>서로 다른 미디어 소스를 "소유"와 "유료"로 그룹화합니다. 예를 들어: 예: 그룹 SMS 및 Facebook 게시물은 '소유' 값으로, Facebook 및 Google은 '유료' 값으로 게시합니다.</li><li>앱스플라이어는 이러한 미디어 소스의 데이터를 각각 "소유" 및 "유료" 값으로 그룹화합니다.</li></ul> |
| 도시 | <ul><li>캠페인 이름을 기반으로 합니다.</li><li>값에는 캠페인 이름에 특정 캠페인이 있는 도시가 포함됩니다. 예를 들어: 예를 들어 뉴욕의 경우 "US\_Facebook\_NY", 샌프란시스코의 경우 "US\_Google\_SF"입니다.</li><li>앱스플라이어는 캠페인 이름을 파싱하고 도시를 기반으로 데이터를 그룹화합니다.</li></ul> |
| UA 매니저 | <ul><li>미디어 소스를 기반으로 합니다.</li><li>특정 팀 구성원에 따라 다양한 미디어 소스를 그룹화합니다. 예를 들어: 예: Google 및 Facebook 캠페인을 'Kevin' 가치로, TikTok 및 Instagram 캠페인을 'Natasha' 값으로 그룹화합니다.</li><li>앱스플라이어는 이러한 미디어 소스의 데이터를 각각 "Kevin" 및 "Natasha" 값으로 그룹화합니다.</li></ul> |

## 절차

<div id="create-a-custom-dimension" />

<Accordion title="맞춤 측정기준 만들기">

**맞춤 측정기준을 만드는 방법은 다음과 같습니다**.

1. Overview 대시보드에서 다음 중 하나를 수행합니다.
   * **메뉴 아이콘(⋮)** > **커스텀 기준**을 클릭합니다.  
     [![](https://files.readme.io/9c7a9e390b27972356f715a1379594fd4e6445274e478a6e469369d6c9fd2123-17109190496017.png)](https://files.readme.io/9c7a9e390b27972356f715a1379594fd4e6445274e478a6e469369d6c9fd2123-17109190496017.png)
   * 차트 또는 표의 p **에 표시**또는 **그룹화** 기준 드롭다운 메뉴에서 **+ 맞춤 측정기준 만들기를** 클릭합니다.
2. 맞춤 측정기준을 처음 만드는 경우 **+ 새 측정기준을** 클릭합니다.  
   **만들기** 탭이 열립니다.
3. 차원의 이름과 설명을 입력합니다. 대시보드 그룹화 옵션에서 이 맞춤 차원을 식별하는 데 도움이 되는 이름과 설명을 선택합니다.
4. 가능한 차원 값을 정의합니다. 차원당 최대 10개의 값이 있을 수 있습니다. 각 값에 대해 다음을 수행합니다.
   1. 값 이름을 입력합니다.
      * 예시: 예: '캠페인 의도'라는 맞춤 측정기준의 경우 값은 '브랜딩' 및 'ua'일 수 있습니다.
   2. 값 이름을 사용해야 하는 경우에 대한 규칙을 정의합니다. 값당 최대 10개의 규칙이 있을 수 있습니다.
      * 각 규칙에는 값의 기반이 되는 기존 차원, 연산자 및 연산자 값이 포함됩니다.
      * 예시: 예: 캠페인 이름에 'brd' 또는 'brnd'가 포함된 경우 값 이름은 'branding'이 됩니다.
      * 다음 표에서는 차원을 정의하는 데 사용되는 다양한 구성 요소를 보여 줍니다.

<table><thead><tr><th>값 이름</th><th>차원(값의 기준)</th><th>운영자</th><th>연산자 값</th></tr></thead><tbody><tr><td rowspan="3">사용자 지정 차원에 사용할 수 있는 값 이름을 결정합니다.</td><td>미디어 소스</td><td rowspan="2">다음에서 선택:  <ul><li>은</li><li>포함</li><li>시작 소스</li><li>다음으로 종료</li></ul></td><td><ul><li>문자열</li><li>드롭다운 선택(연산자가 "is"인 경우)</li></ul></td></tr><tr><td>캠페인 이름</td><td>문자열</td></tr><tr><td>지역</td><td>은 </td><td>드롭다운 선택</td></tr></tbody></table>

5. **저장**을 클릭하세요.

</Accordion>

<Accordion title="맞춤 측정기준 삭제 또는 수정">

**맞춤 측정기준을 삭제하거나 편집하는 방법은 다음과 같습니다**.

1. Overview 대시보드에서 다음 중 하나를 수행합니다.
   * **메뉴 아이콘을** **클릭합니다 > 사용자 지정 차원**.  
     [![](https://files.readme.io/9c7a9e390b27972356f715a1379594fd4e6445274e478a6e469369d6c9fd2123-17109190496017.png)](https://files.readme.io/9c7a9e390b27972356f715a1379594fd4e6445274e478a6e469369d6c9fd2123-17109190496017.png)
   * 차트 또는 표의 p **에 표시**또는 **그룹화** 기준 드롭다운 메뉴에서 **+ 맞춤 측정기준 만들기를** 클릭합니다.
2. **편집** 탭을 클릭합니다.
3. 맞춤 측정기준을 선택하거나 검색합니다.
4. 차원을 삭제하려면 선택한 차원 옆에 있는 **삭제** 아이콘을 클릭합니다.
5. 차원을 편집하려면 사용자 지정 차원 설정을 원하는 대로 변경하고 **저장을** 클릭합니다.

</Accordion>

<Accordion title="맞춤 측정기준 데이터 보기">

사용자 지정 차원을 사용하여 개요 대시보드의 모든 위젯에 있는 데이터를 그룹화하고 볼 수 있습니다.

**맞춤 측정기준 데이터를 보는 방법은 다음과 같습니다**.

1. 개요 대시보드에서 차트 또는 대시보드 위젯으로 이동합니다.
2. **상단 표시** 또는 그룹화 기준 드롭다운 메뉴의 맞춤 측정 **기준** 에서 사용하려는 맞춤 측정기준의 맞춤 측정기준을 확인합니다.  
   [![](https://files.readme.io/e34bcb2ca34546347b391f0ad921319f296a21c41c3783e59a7d808b44d0b6a9-17082706166929.png)](https://files.readme.io/e34bcb2ca34546347b391f0ad921319f296a21c41c3783e59a7d808b44d0b6a9-17082706166929.png)
3. 차트 또는 테이블 데이터는 맞춤 측정기준을 사용하여 그룹화되어 표시됩니다

</Accordion>

<div id="specifications-and-limitations" />

<Accordion title="사양 및 제한 사항">

| 사양 | 비고 |
| --- | --- |
| 사용자정의 기준 | 최대 10개의 사용자 지정 차원을 만들 수 있습니다. |
| 광고주 | 에이전시에서 만든 맞춤 측정기준을 보거나 편집할 수 없습니다. |
| 대행사 | <ul><li>자체 사용자 지정 차원을 만들고 편집하고 대시보드에서 볼 수 있습니다.</li><li>광고주가 만든 맞춤 측정기준을 수정하거나 볼 수 없습니다.</li></ul> |
| 애드 네트워크 | 맞춤 측정기준을 보거나, 만들거나, 편집할 수 없습니다. |
| SKAN 지표 | SSOT가 꺼져 있고 데이터가 커스텀 차원으로 그룹화된 경우 SKAN 지표가 표시되지 않습니다. |
| SSOT | SSOT가 사용 설정되어 있고 데이터가 지역을 기반으로 맞춤 측정기준으로 그룹화되면 데이터가 표시되지 않습니다. |
| 권한 | 모든 팀 구성원은 다른 팀 구성원이 만든 차원을 포함하여 새 차원을 만들고 기존 차원을 편집할 수 있습니다. |
| 대/소문자 구분 | 아니요. 대문자와 소문자는 동일하게 취급됩니다. |
| 기준 값 | <ul><li>최대 10개의 커스텀 기준 값을 사용할 수 있습니다.</li><li>데이터를 사용자 지정 기준 값과 일치시킬 때 순위가 높은 기준에 우선 순위가 부여됩니다. 예시:<ul><li>유료 미디어 대비 온드 미디어 기준의 경우 미디어 소스가 Facebook인 경우 값 1을 유료 미디어로 설정하고, 미디어 소스가 Facebook인 경우 값 2를 온드 미디어로 설정합니다.</li><li>Facebook은 설정에 따라 유료 또는 온드 미디어로 그룹화할 수 있지만, 앱스플라이어는 값 1 설정(유료)에 우선 순위를 부여합니다.</li></ul></li></ul> |
| 연산자 | 연산자 "does not contain"은 아직 사용할 수 없습니다. |
| 기준 규칙 | 기준 값에 대해 최대 10개의 규칙을 가질 수 있습니다. "or"로 연결됩니다. 커넥터 "and"는 아직 사용할 수 없습니다. |

</Accordion>
