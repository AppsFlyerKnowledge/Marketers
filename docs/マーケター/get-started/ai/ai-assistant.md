> **At a glance:** AI Assistantは、AppsFlyer上でデータの分析とプラットフォームの活用を支援するツールです。分析から有益な情報を得る、成果を計測する、成果が高い・低い対象を特定する、キャンペーンの傾向を調べる、表やグラフに示された分析結果を理解する、といった用途に活用できます。AI Assistantに直接質問するほか、マイダッシュボードの［AIで分析（Analyze with AI）］を使って、特定のグラフをその内容に沿って詳しく分析することもできます。

## **AI Assistantの概要**

AI Assistantは、AppsFlyerのデータから有益な情報を見つけ、より的確に判断できるよう、お客様自身による分析と操作方法の確認を支援します。ダッシュボードのデータとあわせて使用すると、マーケティングの成果をすばやく分析し、把握できます。

<div id="what-you-can-do" />

## **利用できる機能**

AI Assistantに普段使う言葉で質問すると、次のような回答を得られます。

* **データに関する回答**：マイダッシュボードの指標や集計項目に加え、AppsFlyerが順次拡充している接続済みデータソースをもとに、成果に関する分析結果、キャンペーンの傾向、成果が高い・低い対象などを確認できます。
* **操作方法の案内**：AppsFlyerのドキュメントに基づき、プラットフォーム内での操作方法、機能の説明、設定方法を確認できます。
* **画面を切り替えずにプラットフォームを管理**：チャット上で、アプリ設定やSDK実装状況の確認、OneLinkテンプレートやリンクの点検、コストと広告収益の連携が正常に動作しているかの確認を行えます。
* **Agent Hubの実行結果の分析**：Agent Hubで完了した実行結果を確認している画面から、その内容について質問できます。詳しくは、<Anchor target="_blank" href="/marketers/ja/docs/beta-agent-hub-overview#ai-assistantを使用したアクティビティの分析">Agent Hubの概要［ベータ版］</Anchor>を参照してください。

質問内容に応じて、回答はテキスト、表、グラフのうち、最も適した形式で表示されます。

## **利用方法**

<Accordion title="AI Assistantの使い方">

1. ナビゲーションバーの星形のAIアイコン<Image alt="ai_star.png" src="https://files.readme.io/a370eeda521facc1222f69ce55c18be9b9d38f9153eb0c7f0ca0b52ea7c6d6d3-38724328822033.png" width="5.74%" />をクリックして、チャット画面を開きます。
2. 質問します。次のいずれかの方法を選べます。
   1. 提案された質問から選択する
   2. 自分で質問を入力する。次のような内容を質問できます。
      1. データに関する質問。
      2. 操作方法に関する質問。
3. 回答をテキスト、表、またはグラフで確認します。
4. 提案された追加の質問を使い、分析や質問の内容をさらに掘り下げます。

<div id="tip" />

> 👍 **ヒント**
>
> AI Assistantの回答は、質問した画面によって異なります。
>
> * **マイダッシュボード**のチャットでは、別の対象を指定しない限り、選択中のアプリに基づいて回答します。
> * それ以外の画面では、別の対象を指定しない限り、アカウント内の最初のアプリに基づいて回答します。
> * 一度に最大20個のアプリを分析できます。

<div id="other-features" />

### その他の機能

* **拡大**ボタンをクリックすると、チャット画面のサイズを変更できます。
* 必要に応じて、<strong>［コピー］</strong>ボタンを使って回答を保存できます。
* 右側のアイコンをクリックすると、新しい会話を開始できます。

</Accordion>

<Accordion title="「AIで分析」の使い方">

マイダッシュボードの任意のグラフから利用できます。

1. ウィジェットにカーソルを合わせます。
2. ［AIで分析（Analyze with AI）］<Image alt="ai_star.png" src="https://files.readme.io/a370eeda521facc1222f69ce55c18be9b9d38f9153eb0c7f0ca0b52ea7c6d6d3-38724328822033.png" width="5.74%" />ボタンをクリックします。
3. 用意された質問（要約、傾向の説明、比較など）を選択するか、自分で質問を入力します。
4. AI Assistantのサイドバーが開き、回答と追加の質問候補が表示されます。
5. 会話を続け、特定のセグメント、指標、期間についてさらに詳しく分析します。

</Accordion>

<Accordion title="Agent HubでのAI Assistantの使い方">

Agent Hubの完了した実行結果から利用できます。

1. Agent Hubの［実行履歴（Activity）］タブに移動します。
2. 完了した実行結果の<strong>［実行結果を分析（Analyze activity）］</strong>をクリックします。
3. 質問を入力します。その実行結果に関する情報があらかじめ読み込まれた状態で、AI Assistantが開きます。

</Accordion>

## **会話履歴**

AI Assistantには会話履歴が保存されるため、背景を最初から説明し直さずに、以前の会話の続きから再開できます。会話履歴は非公開です。会話を閲覧できるのは自分だけで、同じアカウントの他のユーザーは閲覧できません。

**確認方法：** AI Assistantのチャット画面で、閉じる（X）ボタンの横にある履歴アイコンをクリックします。チャットの横にサイドパネルが開き、会話履歴が表示されます。

* 過去30日間の会話が、新しい順に表示されます。
* 各会話には、現在の会話であること、または過去の会話の場合は日時（例：*2月10日 午後3時15分*）が表示されます。
* 30日より前の会話は、ピン留めされていない限り、自動的に履歴から削除されます。
* 会話名で過去の会話を検索できます。

**会話の管理：**

* 会話を**開く**と、内容全体を確認できます。
* 過去の会話を**続ける**と、新しいメッセージがその会話に追加され、一覧の先頭に移動します。
* 会話の**名前を変更**すると、後で見つけやすくなります。
* 会話を**ピン留め**すると、一覧の上部に保持され、アクセスしやすくなります。
* 不要になった会話を**削除**すると、履歴画面から削除されます。ただし、データベースには引き続き保存されている場合があります。

**補足：**

* 過去の会話を再度開くと、表示されるデータは最初に取得した時点の内容です。その会話で新しい質問をすると、AI Assistantは最新のデータを使って回答します。
* 一定時間操作しなかった場合、［新しいチャット］をクリックした場合、または再度ログインした場合は、新しいチャットが自動的に開始されます。それまでの会話は、履歴に保存されます。

## **その他の情報**

<Accordion title="権限と管理者向け設定">

* AppsFlyerプラットフォームと、アカウント内の少なくとも1つのアプリへのアクセス権が必要です。
* AI Assistantを有効・無効にするには、**管理者権限**が必要です。上部バーのアカウントメニューから［アカウント管理］に移動して設定します。

無効にすると、アカウントのすべてのユーザーがAI Assistantを利用できなくなります。

</Accordion>

<Accordion title="回答に使用するデータと情報源">

AI Assistantは、OpenAIの大規模言語モデルとAppsFlyer独自のデータセットを組み合わせ、アカウントに関連する正確な回答を提供します。

AI Assistantは、次のようなAppsFlyerのデータセットを使って回答を生成します。

* **ナレッジベースとDeveloper Hub**：アカウント単位の情報と組み合わせ、操作方法や設定に関する質問に、正確で関連性の高い回答を提供します。
* **AppsFlyerのプラットフォームデータとツール**：マイダッシュボードで利用できるものと同じ集計項目や指標に加え、MCPツールを順次拡充しています。これらのツールを通じて、AI Assistantはアカウントの最新データやプラットフォーム上の操作に直接アクセスできます。対象には、マイアプリやOneLinkの管理、データの分析・計測などが含まれます。詳しくは、<Anchor target="_blank" href="/marketers/ja/docs/beta-appsflyer-mcp">AppsFlyer MCP［ベータ版］</Anchor>を参照してください。

回答の生成に使用するアカウント、ユーザー、アプリの情報は、アクセス権限に応じて制限され、許可された範囲でのみ使用されます。

</Accordion>

<Accordion title="フィードバック">

皆さまのフィードバックは、AI Assistantの改善に役立ちます。回答が分かりにくい、不十分、または正しくない場合は、次の方法を利用してください。

* 高評価・低評価ボタンを使うか、任意のコメントを追加します。
* チャットで会話を続け、回答内容をさらに調整します。

</Accordion>

<Accordion title="制限事項">

次の制限事項は、AI Assistantと「AIで分析」の両方に適用されます。

| 項目 | 説明 |
| --- | --- |
| 質問の文字数制限 | 質問は500文字までです。 |
| データの使用範囲 | アカウント内のデータと、選択したアプリのデータのみを使用します。業界の比較基準となるデータや、他のアカウントのデータは使用しません。 |
| セッション | 4時間操作しなかった場合、または手動で新しい会話を開始した場合は、セッションが終了します。 |
| アクセス権 | ユーザーがアクセス権を持つデータとアプリの結果のみを表示します。 |
| 未対応の機能 | 現時点では、推奨事項の提示、異常検知、予測分析、将来予測には対応していません。 |
| 分析対象のアプリ数 | 一度に最大20個のアプリを分析できます。 |

次の追加の制限事項は、「AIで分析」のみに適用されます。

| 項目 | 説明 |
| --- | --- |
| カスタム指標 | カスタム指標には対応していません。 |
| 週単位・月単位の集計 | 週単位または月単位の集計には対応していません。 |

</Accordion>

<Accordion title="利用の無効化">

管理者は、<strong>［アカウントとプロフィール（Account & Profile）］</strong>から、AI Assistantの有効・無効を切り替えられます。  
有効にすると、プラットフォームのすべてのページに、星形のAIアイコンが表示されます。

AI Assistantを有効・無効にする方法：

1. 上部バーでアカウントメニュー（メールアドレスのドロップダウン）を開き、<strong>［アカウントとプロフィール］</strong>を選択します。
2. <strong>［AI Assistantの有効化］</strong>セクションで、AI Assistantのオン・オフを切り替えます。

</Accordion>

<Accordion title="プライバシーとセキュリティ">

*AppsFlyer AIは、誤った回答を生成する場合があります。 AIの回答は、アカウント内の集計データに基づいています。お客様のデータが保存されたり、AIモデルの学習に使用されたりすることはありません。*

</Accordion>
