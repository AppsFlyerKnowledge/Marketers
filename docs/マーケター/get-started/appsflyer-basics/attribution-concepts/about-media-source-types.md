> **概要：** AppsFlyerにおける基本的なメディアソースの種類を説明します。

メディアソースとは、広告を表示する媒体です。 AppsFlyerでは、さまざまな種類のメディアソースからのアトリビューションを記録できます。

| メディアソースの種類 | 説明 |
| --- | --- |
| <Anchor target="_blank" href="/marketers/ja/docs/self-reporting-networks-srns">Self-Reporting Network（SRN）</Anchor> | <ul><li>AppsFlyerとアドネットワーク間のAPIを通じて、アトリビューションの判定結果と詳細情報を提供します。</li><li>例：Meta広告、Google、Apple Search Ads。</li></ul> |
| 非SRN | <ul><li>クリックURLに含まれるアトリビューション情報を提供します。</li><li><Anchor target="_blank" href="/marketers/ja/docs/set-up-an-integrated-partner">計測リンクを使用するネットワーク</Anchor>、またはアドネットワークとも呼ばれます。</li><li>例：Unity Ads、Tapjoy、Applovin。</li></ul> |
| オウンドメディア | <ul><li>オウンドメディアでは、キャンペーンに<Anchor target="_blank" href="/marketers/ja/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink">OneLinkリンク</Anchor>を使用します。</li><li>例：メール、SMS、SNS、ランディングページ、QRコードなど。</li></ul> |
