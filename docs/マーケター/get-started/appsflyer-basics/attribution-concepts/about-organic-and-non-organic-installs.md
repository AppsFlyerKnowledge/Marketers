> **概要：** オーガニックインストールとノンオーガニックインストールの違いを説明します。

<Image align="center" alt="6453OrganicvsNon-organic.jpg" src="https://files.readme.io/b456433d858a146187429d0a40c200327af685490ea003cd5130f40ad798c7a4-360018880878.jpg" />

ノンオーガニックユーザーは、インストールや広告接触につながったメディアソースに紐付けられます。オーガニックユーザーは、インストールや広告接触に関連するメディアソースが特定されていません。

<div id="organic-vs-non-organic" />

## オーガニックとノンオーガニックの違い

| オーガニックインストール  <br />メディアソースに紐付かない | ノンオーガニックインストール（NOI）  <br />メディアソースに紐付く |
| --- | --- |
| **紐付けなし**：メディアソースがありません。 | メディアソースへの**紐付けあり**。 |
| 以下の理由で**アトリビューションが行われません**。<ul><li>計測リンクを使用せずにアプリがインストールされた。例：広告に接触せず、Webサイトやアプリストアからアプリをダウンロードした場合。</li><li>クリックとアプリ起動を照合できなかった。例：プライバシーポリシーによりデータを利用できない場合や、別のMMPが先にインストールを計測した場合。</li></ul> | 以下のいずれかにより、インストールや起動の**アトリビューションが行われます**。<ul><li>AppsFlyerの計測リンクを使用している。</li><li>AppsFlyerがクリックと起動を照合している。</li><li>SRNが自社の成果として申告している。</li></ul> |
|  | **アトリビューションの補足情報：**<ul><li>*ラストクリックアトリビューション*を使用し、最後の広告接触にアプリのインストールやアクションを紐付けます。</li><li>インストール1件につき、紐付けるメディアソースは1つのみです。</li><li>詳しくは、<Anchor target="_blank" href="/marketers/ja/docs/appsflyer-attribution-model">AppsFlyerのアトリビューション</Anchor>を参照してください。</li></ul> |
