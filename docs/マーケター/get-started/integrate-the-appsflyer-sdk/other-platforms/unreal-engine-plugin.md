> **概要：** 概要： Unreal Engineで開発されたゲームに AppsFlyerを連携し、アプリのインストール数、アプリ内イベント、メディアソースなどを計測します。

![256px-Unreal_Engine_4_logo_and_wordmark.svg.png](https://files.readme.io/8ea048105520f976b4e3080f5c8ec44a4d955977a7731fe16114225bd34e9e5e-360002792757.png)

Unreal Engineを使用すると、ユーザーが決して忘れず、さらに多くのものを求める最先端のモバイルゲームを開発できます。

AppsFlyerで、ゲームの施策に取り組む際のマーケティング活動を計測および分析できるようになりました。

ここでは、AppsFlyer Unreal Engineプラグインでできることのほんの一部を紹介します：

* ゲームをインストールするユーザーの数を計測する
* どのメディアソースが最も多くのユーザーをもたらすかを確認する
* どのメディアソースが最高のユーザーをもたらすかを確認する
* ユーザーアクティビティを記録および計測して、どのユーザーが最も収益を上げているかを判断する

AppsFlyer Unreal Engineプラグインとその実装方法の詳細については、 <Anchor target="_blank" href="https://github.com/AppsFlyerSDK/unreal_appsflyer_sdk">GitHub リポジトリ</Anchor>の手順に従ってください。
