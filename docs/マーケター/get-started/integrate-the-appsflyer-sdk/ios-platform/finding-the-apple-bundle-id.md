> **概要：** AppleのバンドルIDを確認し、必要に応じて使用する方法を説明します。

AppleのバンドルIDは、iOSアプリを一意に識別するためのIDです。

* このIDはアプリの所有者が設定します。
* Appleでは、ドメイン名を逆順にした形式でIDを設定することを推奨しています。  
  例：com.domain.appname

**AppleのバンドルIDを確認するには、次の手順に従ってください。**

1. [App Store Connect（原文ではiTunes Connect）](https://itunesconnect.apple.com/)のアカウントにログインします。
2. 対象のアプリをクリックします。
3. **［一般］** > **［アプリ情報］に移動します。  
   ［バンドルID］**が表示されます。
