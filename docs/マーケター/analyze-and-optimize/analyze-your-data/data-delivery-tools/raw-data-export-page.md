> **概要：** ユーザーレベルのローデータレポートをCSVファイル形式でダウンロードします。1回のダウンロードごとに最大100万行まで出力できます。フィルターを使用して、必要なデータにレポートを絞り込みます。

以下の図は、**ローデータ出力**画面に初めてアクセスする際に表示されます。レポートがダウンロードまたは複製の準備ができている場合は**マイレポート**ページが表示されます。

<Image align="center" alt="RawDataSplash.png" src="https://files.readme.io/febb6a32a3a7b86c5b396cd77ff9e7968057f57ed20fd991d6dbb4899d5eaf07-41225791757969.png" />

**マイレポート**

**マイレポート**画面には、過去に生成され、ダウンロードや複製が可能なレポートが一覧表示されます。リストされているレポートは過去90日間に生成されたもので、ダウンロード有効期間は7日間です。7日を過ぎた場合もレポートが必要な場合は、再度生成する必要があります。

ローデータレポートの説明については、<Anchor target="_blank" href="/marketers/ja/docs/raw-data-reporting-overview">ローデータレポートの概要</Anchor>を参照してください。

レポートの生成やダウンロード手順については、この記事の手順セクションを参照してください。

## 手順

<div id="create-a-default-report" />

<Accordion title="デフォルトレポートの作成">

項目やフィルターをカスタマイズせず、デフォルト設定でレポートを作成できます。

**デフォルトレポートの作成：**

1. AppsFlyer管理画面左メニュー **エクスポート** > **ローデータ出力**を選択してください。
2. + **新しいレポート**をクリックします。
3. 生成するレポートの種類にカーソルを合わせ、**作成**をクリックしてください。
4. ドロップダウンメニューから**今すぐ生成**を選択します。
5. ポップアップ画面で<strong>今すぐ生成をクリックします。</strong>生成には最大10分かかることがあります。
   * レポート生成中でも、作業を続けたり、追加のレポートを作成したり、他のページに移動したりできます。

**デフォルトのレポートフィルター設定：**

| フィルター | デフォルト設定 |
| --- | --- |
| アクティビティの日付 | 過去7日間 |
| ファイルあたりの最大行数 | 200,000 |
| メディアソース | すべてのメディアソース |
| 代理店 | すべての代理店 |
| 地域 | すべてのエリア |

</Accordion>

<div id="create-a-custom-report" />

<Accordion title="カスタムレポートの作成">

フィルターと項目を設定することで、カスタムレポートを作成できます。

**カスタムレポートの作成：**

1. AppsFlyer管理画面左メニュー **エクスポート** > **ローデータ出力**を選択してください。
2. + **新しいレポート**をクリックします。
3. 生成するレポートの種類にカーソルを合わせ、**作成**をクリックしてください。
4. ドロップダウンメニューから **カスタマイズ**を選択します。
5. レポートフィルターを設定します。
   * **アクティビティの日付：** アクティビティの日付範囲を選択します。特定の日付を設定するか、カスタム、昨日、過去7日間などのオプションから選択できます。
   * （オプション）**ファイルあたりの最大行数：** ファイルに含める最大行数を設定します。10万、20万、50万、または100万行から選択します。
   * （オプション）**メディアソース：** 選択したメディアソース経由のデータのみがレポートに含まれます。**項目を追加**]をクリックして、リストにメディアソースを追加できます。
   * （オプション）**代理店：** 選択した代理店に起因するデータのみがレポートに含まれます。**項目を追加**をクリックして、リストに代理店を追加できます。
   * （オプション）**地域：** 選択したエリア（国）経由のデータのみがレポートに含まれます。
   * **レポートタイプ固有のフィルタ**：各レポートタイプは独自のフィルターを持ち、フィルター基準を選択することができます。
6. （オプション）レポートは必要な項目で自動的に埋められます。次のように項目を追加または削除できます：
   1. <span class="af-ol-a"></span> **レポート項目**タブに進み、選択した項目のリストを表示します。必須項目の選択を変更することはできません。
   2. 必要に応じて選択項目を選択またはクリアします。
   3. （オプション） 列の順序を設定するには、**レポート (CSV) 項目の順序**を設定します。
   4. （オプション） 必要に応じて**デフォルトに戻す**をクリックします。
7. **作成**をクリックします。
   * **マイレポート**ページが表示されます。はじめは、ステータスはレポートが生成中であることを示します。
   * 生成には最大10分かかる可能性があります。
   * レポート生成中でも、作業を続けたり、追加のレポートを作成したり、他のページに移動したりできます。

</Accordion>

<div id="download-report" />

<Accordion title="レポートのダウンロード">

**レポートをダウンロードするには**：

1. AppsFlyerのサイドバーから、**エクスポート** > **ローデータ出力**を開きます。
2. レポートをダウンロードするには、ダウンロードアイコン ![DownloadIcon.png](https://files.readme.io/6c00f4922fc3a835a856d7fdf527aa32d2f50570710c1527b039f43a7acbba79-41225791763217.png) をクリックします。生成されたレポートは7日間ダウンロード可能です。

</Accordion>

<div id="duplicate-and-edit-report-settings" />

<Accordion title="レポート設定の複製と編集">

**レポート設定の複製と編集：**

1. AppsFlyerのサイドバーから、**エクスポート** > **ローデータ出力**を開きます。
2. レポート設定を複製して編集するには、![Duplicate.png](https://files.readme.io/f745081f1bf0c4f5861e275a29048fe84e8020f8b3bf4ebe4ad6a8d9254ab4b5-41225784681233.png) をクリックしてください。
3. **作成**をクリックします。生成されたレポートは7日間利用可能です。   
   * **マイレポート**ページが表示されます。はじめは、ステータスはレポートが生成中であることを示します。
   * 生成には最大10分かかる可能性があります。
   * レポート生成中でも、作業を続けたり、追加のレポートを作成したり、他のページに移動したりできます。

</Accordion>

## 追加情報

<div id="traits-and-limitations" />

<Accordion title="特性と制限">

| 特性 | 備考 |
| --- | --- |
| アドネットワークのアクセス | はい |
| 代理店のアクセス | はい |
| 代理店の運用媒体の開示設定 | はい。 ただし、代理店フィルターとメディアソースフィルターの両方を利用する場合、運用媒体非開示の代理店に対してはメディアソースフィルターは適用されませんのでご注意ください。つまり、運用媒体非開示な代理店の場合、フィルターされたメディアソースからのデータだけでなく、すべてのデータが含まれます。 |
| アプリ固有のタイムゾーン | はい |
| アプリ固有の通貨 | はい |
| 制限事項 | ダウンロードあたり最大100万件の記録 |
| オーガニックデータ | 利用可能 |
| 非オーガニックデータ | 利用可能 |
| データの鮮度 | レポートに依存 |
| 過去データ | 過去90日間 |
| アカウントユーザーへのアクセス | <Anchor target="_blank" href="/marketers/ja/docs/user-management">必要な権限を持つロール</Anchor>のユーザー |
| メール配信 | サポートされていません |
| インストール期間 | インストール範囲の日付は、アクティビティ範囲の日付よりも前である必要があります。 |
| ローデータポストバックレポート | 運用媒体非開示の代理店に紐づくイベントのポストバックは、広告主のローデータポストバックレポートには含まれません。 |

</Accordion>

1. レポート項目タブで、**レポート項目の順序** オプションを選択します。
2. 必要に応じて、必要な項目を選択または選択解除して、選択された項目を変更します。

</Accordion>
