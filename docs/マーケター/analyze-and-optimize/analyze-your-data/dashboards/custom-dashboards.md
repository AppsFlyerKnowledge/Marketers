> **概要：** 概要：AppsFlyerでカスタマイズされた管理画面を構築しましょう。独自のカスタマイズレポートに含めるデータを選択し、名前を付け、好きな位置に配置できます。

[![CustomDashboard_us-en.png](https://files.readme.io/6bf2765054a7e7f1e344d15d2ac0c56dbdbd4fe5d0ff285f95bb03066396be0d-360015793598.png)](https://files.readme.io/6bf2765054a7e7f1e344d15d2ac0c56dbdbd4fe5d0ff285f95bb03066396be0d-360015793598.png)

## カスタムダッシュボード

各カスタムダッシュボードは、ユーザー獲得の指標を含む1つ以上のウィジェットで構成されます。ウィジェットウィザードを使用し、指標、表示形式、アプリ等を選択して、ウィジェットを設定します。ウィジェットウィザードを使用し、指標、表示形式、アプリ等を選択して、ウィジェットを設定します。

利用できる指標はオーバービュー管理画面のユーザー獲得指標と同様です。ご注意ください注記！オーバービューの統合およびリターゲティングとは比較**しないでください**。

カスタムダッシュボードを作成すると、アカウント内のすべてのユーザーがそのダッシュボードを使用できるようになります。

## ダッシュボードのカスタマイズ

ウィジェットを移動またはサイズ変更してダッシュボードをカスタマイズできます。

| パーソナライゼーションオプション | 説明 |
| --- | --- |
| ウィジェットのサイズ変更 | 右下隅をドラッグしてウィジェットのサイズを変更します |
| ウィジェットの位置 | ウィジェットを画面上でドラッグ＆ドロップして位置を変更します |
| アクション | ウィジェットの右上隅をマウスオーバーしてアクションをクリックします。ウィジェットごとに次のアクションが可能です：<ul><li>編集する</li><li>複製</li><li>削除</li><li>CSVファイルを抽出する</li></ul> |

## 手順

<div id="managing-dashboards" />

<Accordion title="ダッシュボードのアクション">

| アクション | 説明 |
| --- | --- |
| 複製 | 現在のダッシュボードのコピーを作成します |
| 名前を編集 | ダッシュボードの名前を変更します |
| PNGをエクスポート | PNGファイルを作成してダウンロードします |
| 削除 | ダッシュボードを削除します |

</Accordion>

<div id="add-a-custom-dashboard" />

<Accordion title="カスタムダッシュボードの追加">

**カスタムダッシュボードを追加する方法：**

1. ダッシュボードが表示されます。
2. + をクリックします（新しいダッシュボードが追加されます）。
3. **ダッシュボードのタイトル**を入力します。
4. [**追加**] ボタンをクリックします。
5. 次のセクションで説明するウィジェットを1つ以上追加します。

</Accordion>

<div id="managing-widgets" />

<Accordion title="ウィジェットの管理">

**ウィジェットを追加する方法：**

1. [ウィジェットを追加] をクリックします。
2. ウィジェット画面が表示されます。   

   [![WidgetConfigure_us-en.png](https://files.readme.io/f04544d8cb8b1d946526c4546565fffb405e5113e09dac65e5a28e218a1170a7-360015793618.png)](https://files.readme.io/f04544d8cb8b1d946526c4546565fffb405e5113e09dac65e5a28e218a1170a7-360015793618.png)
3. ウィジェットを設定します。次のウィジェットの設定ガイドをご利用ください。
4. 必要に応じてウィジェットを追加します。

**ウィジェットの設定ガイド**

| 設定 | 説明 |
| --- | --- |
| ウィジェットの種類 | ![WidgetType_us-en.png](https://files.readme.io/00174da67c1b5046033655aad2f0af815d5abb3229cdc7c2f225f689c8adc7d8-360015793638.png)<br /><br />ウィジェットの種類を選択します：<ul><li>円グラフ</li><li>棒グラフ</li><li>折れ線グラフ</li><li>データ表</li><li>地域マップ</li><li>指標</li><li>ファネルチャート</li></ul> |
| 説明 | ウィジェットの説明を入力します。 |
| アプリ | ウィジェットデータに含める 1つ以上のアプリまたはすべてのアプリを選択します。すべてを選択すると、アカウント内の上位100のアプリを意味します。 |
| KPI | <ul><li>ウィジェットで表示するKPIを選択します。</li><li>データ表と棒グラフは最初に選択したKPIに応じてソートされます。</li></ul> |
| グループ化 | グループ化を選択します |
| トップを表示 | 表示する値の数を入力します。 |
| Pre-Covid | 選択すると、Covid-19以前の日付である2019年11月1-30日分のデータが表示されます。 |
| フィルタ | フィルターを使用してウィジェット内のデータをフィルターします：<ul><li>**国（Geo)**</li><li>**メディアソース**</li><li>**キャンペーン**</li><li>**チャネル**</li></ul>**Exclude organic**（オーガニックを除く）を選択すると、メディアソースに紐づかないデータを除外します。 |

</Accordion>

<div id="export-widget-data" />

<Accordion title="ウィジェットデータのエクスポート">

![Widget_table.png](https://files.readme.io/b04e80e16d0d34946e6783103fc6fbbdf89b390842db27226b4fdba6c1f7e506-360015717057.png)

**ウィジェットデータをCSVファイルでダウンロードする方法**：

1. ウィジェットにタイトルとデータが含まれていることを確認してください。
2. ウィジェット内で**アクション**を選択します。
3. **CSV出力**を選択します。  
   ファイルがダウンロードされます。  
   CSVファイル内の日付の形式は、dd/mm/yyyy です。Excelで mm/dd/yyyy のような<Anchor target="_blank" href="https://answers.microsoft.com/en-us/msoffice/forum/msoffice_excel-mso_winother-mso_2010/how-to-convert-ddmmyyyy-to-mmddyyyy/41119ed6-4057-4598-a44c-1ebfdf301a43">別の形式に変換</Anchor>することもできます。

</Accordion>

## 特性と制限

<div id="traits-and-limitations::6693dfa7" />

<Accordion title="特性と制限">

| 特性 | 備考 |
| --- | --- |
| アドネットワークのレポートへのアクセス | いいえ |
| 代理店 | サポートされておらず、計測対象外です |
| 代理店の運用媒体の開示設定 | はい |
| アプリ固有のタイムゾーン | アカウント内の全てのアプリで同じタイムゾーンに設定されている場合、データはアプリ固有のタイムゾーンで表示されます。そうでない場合は、データはUTCで表示されます。 |
| App-specific currency | アカウント内の全てのアプリで同じ通貨に設定されている場合、データはアプリ固有の通貨で表示されます。そうでない場合は、データはUSDで表示されます。 |
| コストデータ | 少なくとも1件のインストールが記録されている場合にのみ使用できます。<Anchor target="_blank" href="/marketers/ja/docs/roi360-cost-aggregation-overview#cost-data-availability-and-reports">詳細はこちら</Anchor> |
| オーガニックデータ | 利用可能 |
| 非オーガニックデータ | 利用可能 |
| eCPA |  |
| データ更新頻度 | <Anchor target="_blank" href="/marketers/ja/docs/about-data-freshness-and-timezone-support#continuous-aka-realtime">リアルタイム</Anchor>。オーバービュー管理画面と同じです。 |
| アカウントユーザーのアクセス | はい |
| 制限事項 | <ul><li>フルページでPDF出力するオプションは使用できません。</li><li>特定のキャンペーンを検索する機能は、キャンペーン数が100件以下の場合に限られています。必要に応じて、期間を絞り込み、再度検索してください。</li><li>リターゲティング、リテンション、アクティビティ、Protect360のKPIは利用できません。ご注意ください注記！カスタムダッシュボードの指標をオーバービューの統合またはリターゲティングの指標と比較しないでください。</li><li>キャンペーン名の変更はサポートされていません。</li></ul> |
|  | <ul><li>アカウント内の全てのアプリが同じタイプゾーン名を使用している場合、データはアプリのタイムゾーンで表示されます。そうでない場合は、UTCで表示されます。</li></ul> |
| 過去データ | 5年 |

</Accordion>
