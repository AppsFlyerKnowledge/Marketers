> **概要：** <Anchor target="_blank" href="/marketers/ja/docs/my-dashboards">マイダッシュボード</Anchor>のアクティビティ指標を使うことで、任意の日付範囲において、アプリのパフォーマンスを迅速に把握し、エンゲージメントの傾向を捉え、収益を分析し、問題を早期に検知できます。精度と柔軟性が向上しています。

> 📘 **注意**
>
> 純収益指標は、2026年7月から8月にかけて段階的にクライアントに展開される。まだ表示されていない場合は、アクションは必要ありません。この期間中、アカウントで使用できるようになります。 <Anchor target="_blank" href="/marketers/ja/docs/bulletin-cohort-and-activity-metrics-update-in-my-dashboards">Bulletin を参照してください。コホートとアクティビティのメトリクスは、My ダッシュボード s</Anchor> でアップデートされます。

## アクティビティ指標について

マイダッシュボードのアクティビティ指標では、アクティビティ、LTV、コホートデータを 1 か所で分析できます。これにより、以下の点を通じてビジネスパフォーマンスの監視や、より深いインサイトの獲得が可能になります：

* リアルタイム性を意識しながら、**ユーザーのアクティビティや定着度**を分析できます。
* **イベントパフォーマンス、収益、セッションのトレンド**を計測できます。  
  **LTV、アクチュアル、コホート** の各期間を 1 つのダッシュボードで統合的に可視化できます。
* **日次または月次**（アクティブユーザー）単位での内訳を用いて、レポートをカスタマイズできます。

※マイダッシュボードでは、**アクティビティ**という用語が**アクチュアル**に改名されました。これは、これらの指標が選択した日付範囲内における実際のユーザー行動を反映したものであり、LTV 集計に基づくものではないことを明確にするためです。セッション、グロス収益、合計収益 では、アクチュアル がデフォルトの期間として設定されています。

## ダッシュボード情報

**アクティビティビュー：**

**アクティビティビュー**のテンプレートは、マーケターがアプリのパフォーマンスを素早く把握し、エンゲージメントの傾向を見極め、収益を分析し、問題を早期に検知できるよう支援します。これにより、キャンペーンやプラットフォームを横断した、迅速でデータドリブンな意思決定が可能になります。

**ダッシュボードにウィジェットを追加する**

ダッシュボード右上の「**+ 新規作成**」ボタンをクリックし、作成したいウィジェットの種類（表、KPI、チャート、アプリ内イベントの表、アプリ内イベントチャート、テキスト、カスタム指標）を選択することで、ウィジェットを追加できます。より詳細な手順は<Anchor target="_blank" href="/marketers/ja/docs/my-dashboards#add-widget">こちら</Anchor>をご確認ください。

**チャート・表に指標を追加する**

チャート設定 または 表設定 のダイアログで、「指標」の＋アイコンをクリックします。

その後、Group by ディメンションを追加し、フィルタ を選択できます。

より詳細な手順はこちらをご確認ください。

## 利用可能なアクティビティ指標

* アクティブユーザー、過去31日間のアクティブユーザー、DAU/MAUを除くすべての指標は、コホート期間および LTV にも対応しています。

| **指標** | **詳細** |
| --- | --- |
| アクティブユーザー | <ul><li>選択した期間中に、少なくとも 1 回アプリを起動したユニークなアクティブユーザー数。選択した時間の内訳設定に基づき、セッションをもとに算出されます。</li><li>日次を選択した場合は DAU、</li><li>月次を選択した場合は MAU として表示されます。</li><li>折れ線グラフ、縦棒グラフ、または日付でグループ化した表では DAU として表示されます。</li><li>DAU および MAU のローデータ取得については、<Anchor target="_blank" href="/marketers/ja/docs/calculate-daily-and-monthly-active-users-dau-and-mau">「日次・月次アクティブユーザー（DAU・MAU）の算出」</Anchor>を参照してください。</li></ul> |
| 過去31日間のアクティブユーザー | 直近 31 日間（暦月ではありません）に、少なくとも 1 回アプリを起動したユニークユーザー数（重複なし）。 |
| DAU/MAU | リピート率（ユーザー定着度）を示す指標です。<br /><br />たとえば、DAU/MAU が 50% の場合、平均してユーザーは直近 31 日間のうち 15 日間アプリを起動したことを意味します。<br /><br />DAU/MAU はユーザー定着度を測る指標であり、リテンションのスナップショットを提供します。<br /><br />計算式：Daily Active users / Active users last 31 daysデイリーアクティブユーザー / 過去31日間のアクティブユーザー |
| Sessions | 選択した日付範囲内のセッション数。 |
| Total Revenue | 選択した期間に発生した収益。アプリ内課金および広告収益を含みます。 |
| ネット収益 | {"af_net_"}収益 イベントパラメータから集計された、選択した期間の正味収益。ROI 360 ストア 収益を使用しているアプリの場合、これは総収益からアプリストア料金と税金を差し引いたものです(純額= 総額- ストア料金- 税金)。{"af_net_"}収益を送信するアプリ自体が計算を定義します。 |
| First visit | ウェブアプリへの初回訪問数。コンバージョン\_name = first\_visit の行としてカウントされます。Web アプリでのみ使用できます。 |
| 再訪問 | ウェブアプリへの訪問を返す非オーガニックの件数。コンバージョン\_name = revisit の行としてカウントされます。Web アプリでのみ使用できます。 |
| ユーザー獲得 | クロス-プラットフォーム属性またはウェブアプリで使用できます。ウェブアプリの場合、ユーザーアクイジションイベントが設定されていない限り、ユーザーアクイジションは最初のビジットを反映します。モバイルアプリ s の場合、ユーザー収集はインストールと等しくなります。マルチの複数のアプリを一緒に表示する場合、ユーザー取得= インストール+ 最初の訪問(またはクライアントによって設定されたカスタムのウェブイベント)。 |

## 利用可能なアプリ内イベントに関する指標

| **指標** | **詳細** |
| --- | --- |
| コンバージョン率 | イベントを実行したユニークユーザー（アトリビューション）の割合。計算式：イベントユニークユーザー ÷ アトリビューション x 100 |
| ユニークユーザー数 | イベントを実行したユニークユーザー数（アトリビューション数）。 |
| 平均回数 | アトリビューションあたりの平均イベント実行回数。<br /><br />計算式：イベント数 / アトリビューション数 |
| eCPA | イベントあたりの実効コスト。<br /><br />計算式：コスト ÷ イベントユニークユーザー |
| カウント | このイベントが実行された回数。 |
| 収益 | 特定のイベントによって発生した収益。 |
| ARPU | ユーザー当たりの平均収益<br /><br />計算式：収益 ÷ ユニークユーザー（ユーザー = アトリビューション） |
| 総利益 | 収益 − コスト |
| ROAS | 広告費回収率 (ROAS) (%)<br /><br />計算式：収益 ÷ コスト x 100 |
| ROI | 投資収益率 (%)。<br /><br />計算式：（収益 ‐ コスト）÷ コスト x 100 |
| ネット収益 | このイベントによって生み出される純収益(アプリストア手数料および税引後)。 |
| ネットARPU | ユーザー一人当たりの平均ネット収益<br /><br />計算式：ネット収益 ÷ ユニークユーザー数（ユーザー数 = アトリビューション数） |
| 純利益 | ネット収益 - コスト |
| ネットROAS | 純収益ベースの広告使う収益率。<br /><br />計算式：ネット収益 - コスト |
| ネットROI | ネット収益に基づく投資収益率。<br /><br />計算式：（ネット収益 ‐ コスト）÷ コスト* x 100 |

広告収益指標

売上総収益ではなく、純収益(純ROI、純ROAS、純ARPU、純利益)を示している。正味収益は、{"af_net_"}収益で送信される値　であり、広告主は(例えば、収益手数料および/または税金、粗利益、またはサービス手数料後の収益後の)算出を定義します。ROI 360 ストア 収益を使用するアプリ s の場合、AppsFlyer は、総額からアプリストア手数料と税金を引いたものとして計算します(純額= 総額- ストア手数料- 税金)。

値　は、通常の収益メトリクスが{"af_"}収益を使用するのと同じ方法で、アプリ内イベントの{"af_net_"}収益パラメータから取得されます。値　は取引通貨で、{"af_currency"} (既定のUSD) で表されます。

値　の入力方法:

* アプリで**ROI360 ストア 収益** が有効になっている場合、AppsFlyer はアプリ内のの購買および購読イベントに{"af_net_"}収益 を自動的に入力し、記録します。
* それ以外の場合、値　はアプリ内の イベントで送信した{"af_net_"}収益パラメータから取得されます。
* 正味収益がどちらからも提供されない場合、メトリクスはN/A を示します。

<Anchor target="_blank" href="/marketers/ja/docs/about-roi360-store-revenue">ROI360についてストア 収益</Anchor>と<Anchor target="_blank" href="/marketers/ja/docs/in-app-events-event-structure">アプリ内イベントs - イベント構成</Anchor>を参照してください。

## 仕様と制限事項

| **仕様** | **注釈** |
| --- | --- |
| データ更新頻度 | リアルタイムは、コホートおよびアクティビティメトリクス用のWeb、Cテレビ、またはPC およびコンソールアプリケーションではサポートされません。<br /><br />**注記：** Cテレビ とPC およびコンソールアプリのLTVメトリクスは実際の-time で使用できます。この制限はアクティビティおよびコホートデータにのみ適用されます。 |
| タイム粒度の細かい度 | Web、Cテレビ、およびPCとコンソールアプリの場合、コホートとアクティビティデータは日常粒度の細かいでのみ利用できます。週次および月次の内訳は、これらのプラットフォームではサポートされません。 |
| 広告収益 | リアルタイムデータはサポートされていません。 |
| 純収益指標-期 | アクティビティメトリクスおよびコホートメトリクスでサポートされます。LTVではサポートされません。 |
| 純収益指標-データフレッシュネス | リアルタイムでの更新はサポートされていません。データは翌日から利用可能です。 |
| 純収益指標-広告収益 | 広告 収益 イベントsは純収益指標には含まれない。<br /><br />**ヒント：** 広告収益を含むネット収益を表示するには、ネット収益に広告収益を追加するカスタムメトリクスを作成します。以下に例を示します。正味収益 + 収益(イベント: {"af_ad_"}収益)。［ベータ機能］マイダッシュボードでのカスタム指標の設定 |
| 純収益指標-要因分析ソース | スキャンとSSOTではサポートされません。 |
| 正味収益指標-プラットフォームs | AndroidとiOS(携帯)のみ。 |
| タイムゾーン | 以下の指標は UTC タイムゾーンのみ対応しています：<ul><li>過去31日間のアクティブユーザー</li><li>DAU/MAU</li><li>月次グループ化されたアクティブユーザー数 (MAU)</li></ul> |
| チャート | 現在、折れ線または縦棒形式での **DAU** のみ対応しています。 |
| ウィジェット | KPI および表ウィジェットは、すべてのアクティビティ指標に対応しています。 |
| 日次データの指定範囲 | 1 ビューあたり最大 62 日間まで指定可能です。 |
| アンインストールイベント | アクティビティデータには含まれません。 |
| 過去データ | 最大 3 年分（日次）まで利用可能です。 |
| 地理的グループ化 | インストール時の地域に基づき、上位 62 地域まで対応しています。 |
| セッション指標 | <ul><li>アクティビティデータは、2025 年 2 月 1 日以降、UA とリターゲティングで統合されています。</li><li>**アトリビューションタイプ** を **リエンゲージメント** および **リアトリビューション** にフィルタリングすることで、リターゲティング軸のデータ を確認できます。</li></ul> |
| 統合ビューの指標 | すべての指標は、統合ビューでのみサポートされています。 |
| アプリ内イベントのユニークユーザー数とアクティブユーザー数 | マイダッシュボードにおける **アプリ内イベントのユニークユーザー数** および **アクティブユーザー数** は、重複カウントを抑え、一貫したユーザーアクティビティを提供する統計的推定アルゴリズムに基づいて算出されています。 |
| アクティブユーザー数およびユニークユーザー数（実数） | 選択した日付範囲に今日を含む場合、ウィジェットが日付ごとにグループ化されていない限り、今日のデータは表示されません。 |
