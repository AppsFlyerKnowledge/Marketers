> **概要：** 広告主と代理店は、広告費と広告収益の連携状況を確認できます。

<div id="cost-and-ad-revenue-integration-status" />

## 広告費・広告収益の連携状況

* このダッシュボードには、広告費・広告収益の連携が現在どのような状態にあるかが表示されます。
  * 広告主は、アカウント内のすべてのアプリ、メディアソース、代理店の連携状況を確認できます。
  * 代理店は、自社が取り扱うすべてのアプリとメディアソースの連携状況を確認できます。
* 広告収益の連携は、ユーザー獲得元のメディアソースではなく、広告収益が発生するメディアソース別に表示されます。
* 対応が必要な連携には、必要な操作が表示されます。
* 広告費・広告収益の連携状況を確認するには、AppsFlyerのサイドメニューから<strong>［設定］</strong>＞<strong>［広告費・広告収益の連携状況］</strong>を選択します。
* 以下の画像と表で、ダッシュボードの各部分を説明します。

| <span id="a-filters"></span>A. フィルター | <ul><li>アプリ</li><li>代理店</li><li>メディアソース</li><li>ステータス</li><li>連携の種類（広告費または広告収益）</li><li>問題</li></ul> |
| <span id="b-headline-metrics"></span>B. 主要指標 | <ul><li>**連携の総数**：ステータスにかかわらず、連携が有効になっているアプリとパートナーの組み合わせの数。例えば、AndroidアプリとiOSアプリがあり、どちらもMeta広告と連携している場合、連携の総数は2件です。</li><li>**要対応**：APIに問題があり、設定の更新が必要なアカウント内のアプリ・メディアソースの数。</li><li>**警告**：データがない、または一時的なネットワークエラーが発生している連携の数。</li><li>**同期待ち**：接続は完了しているものの、データの取得を待っている連携の数。 AppsFlyerにデータが表示されるまで、最大24時間かかる場合があります。</li><li>**有効**：広告費・広告収益のAPIが同期され、正常に動作しているパートナーの数。</li></ul> |
| <span id="c-status"></span>C. ステータス | ダッシュボードでは、ステータスごとに表が分かれており、該当するすべての連携が表示されます。各ステータスの定義は、上記の主要指標を参照してください。<ul><li>**要対応**</li><li>**警告**</li><li>**同期待ち**</li><li>**有効**</li></ul> |
| <span id="d-columns"></span>D. 列 | 各ステータスのセクションには、次の列があります。<ul><li>メディアソース</li><li>アプリ：広告費または広告収益のデータをAPI経由で連携しているアプリ。</li><li>最終同期：最後にデータを受信した日時。</li><li>連携の種類：<ul><li>広告費</li><li>広告収益（アトリビューション）：ユーザー獲得元のメディアソースに紐づけられた広告収益。</li><li>広告収益（集計）：収益化メディアソース（広告を表示したメディアソース）別に集計された広告収益。</li></ul></li><li>キャンペーンの広告費／収益（APIに基づく）：アプリの直近7日間のキャンペーン広告費または広告収益。メディアソース別に表示されます。</li><li>問題：以下の一覧を参照してください。</li><li>操作：API連携に問題がある場合、データを取得できるようにするために必要な操作。<strong>［再接続］</strong>をクリックすると、必要な操作を行えます。</li></ul> |
| <span id="e-problem"></span>E. 問題 | <ul><li>**認証情報が無効**：認証情報が無効なため、AppsFlyerがAPI経由でデータを取得できません。 正しい認証情報で再接続してください。</li><li>**初回同期待ち**：パートナーから初回のデータを取得するのを待っています。数時間後に再度確認してください。</li><li>**有効になっていない**：過去28日間にこのパートナーから広告主または代理店への流入と20件を超えるインストールがありましたが、広告費連携が有効になっていません。広告費連携を有効にしてください。</li><li>**データなし**：連携は有効ですが、パートナーからデータが返されていません。<ul><li>問題発生時に通知を受け取るには、広告収益データの取得失敗に関するメール通知を有効にしてください。</li></ul></li><li>**取得できるデータなし**：連携は有効ですが、稼働中のキャンペーンがないため、過去30日間の広告費データがパートナーから提供されていません。</li><li>**ネットワークの問題**：このパートナーで一時的な問題が発生しています。数時間後に再度確認してください。</li><li>**一般的なエラー**：このパートナーで一時的な問題が発生しています。サポートにお問い合わせください。</li><li>**古いAPIバージョン**：連携設定を確認し、APIの認証情報を更新してください。</li><li>**設定が無効**：収益のアトリビューションに設定したイベント名が見つかりません。設定を確認し、イベントソース名を更新してください。</li><li>**連携が無効**：連携を再接続してください。</li><li>**パートナー側の制限**：パートナー側のシステムで、このアカウントによる広告費の取得が有効になっていません。パートナーにお問い合わせください。</li><li>**連携停止中**：パートナー連携が30日間連続で「警告」ステータスになっていたため、停止されています。パートナーとの連携を再接続してください。<ul><li>問題発生時に通知を受け取るには、広告収益連携の停止に関するメール通知を有効にしてください。</li><li>**注意**：連携が停止中のパートナーは、180日後にステータスダッシュボードに表示されなくなります。</li></ul></li><li>**APIとアトリビューションの不一致**：パートナーのAPIから、アトリビューションデータと一致する広告費データが返されていません。考えられる原因は以下のとおりです。<ul><li>AppsFlyerからパートナーにログインする際に、別の広告アカウント（別のMeta広告アカウントなど）を連携しました。正しいパートナーの広告アカウントを連携していることを確認してください。</li><li>パートナーの広告費連携に設定した認証情報のフィールドのいずれかに誤りがあります。例えば、バンドルIDなどです。連携の認証情報を確認し、修正してください。</li></ul></li><li>**設定エラー**：パートナーのAPIからデータが返されていません。考えられる原因は以下のとおりです。<ul><li>キャンペーンが一時停止されており、データがありません。</li><li>AppsFlyerからパートナーにログインする際に、別の広告アカウント（別のMeta広告アカウントなど）を連携しました。正しいパートナーの広告アカウントを連携していることを確認してください。</li><li>パートナーの広告費連携に設定した認証情報のフィールドのいずれかに誤りがあります。例えば、バンドルIDなどです。連携の認証情報を確認し、修正してください。</li></ul></li></ul> |
