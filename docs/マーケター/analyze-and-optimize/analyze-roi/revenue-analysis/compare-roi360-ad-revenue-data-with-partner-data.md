> **概要：** AppsFlyer ROI360の広告収益データを、メディエーションパートナーやユーザー獲得パートナーのデータと比較します。

ダッシュボードやレポートにデータが反映されるには、データの受信と処理が完了している必要があります。利用可能になるまでの時間は、契約しているROI360パッケージ、パートナーとの連携方式、データの更新頻度、レポートの種類によって異なります。

以下では、AppsFlyerのROI360広告収益データをパートナーのダッシュボードやレポートと比較する方法と、比較に適したタイミングを説明します。

<div id="comparing-appsflyer-data-with-mediation-partner-data" />

<Accordion title="AppsFlyerのデータとメディエーションパートナーのデータの比較">

| 連携方式 | データの種類 | 比較するデータの組み合わせ |
| --- | --- | --- |
| S2S API | 端末単位 | <ul><li>AppsFlyerのアクティビティダッシュボード、またはData Locker経由の単一バージョンの広告収益レポートに表示される総収益を、メディエーションパートナーの総収益データと比較します。</li><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li><li>広告収益イベントの件数（af\_ad revenueイベントとして報告）とインプレッション数は比較しないでください。</li></ul> |
| SDK | 端末単位 | <ul><li>AppsFlyerのアクティビティダッシュボード、またはData Locker経由の単一バージョンの広告収益レポートに表示される総収益を、メディエーションパートナーの総収益データと比較します。</li><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li><li>広告収益イベントの件数（af\_ad revenueイベントとして報告）とインプレッション数は比較しないでください。</li></ul>**注意**：広告収益データは後から変更される場合があります。また、すべてのユーザーが、広告収益SDK Connectorを組み込んだ最新バージョンのアプリに更新しているとは限りません。そのため、AppsFlyerとメディエーションパートナーのデータを比較すると、差異が生じることがあります。 |
| SDK | 広告表示単位 | メディエーションパートナーの収益ダッシュボードのデータを、次のデータと比較します。<ul><li>Data Lockerの広告表示単位の収益レポート。<ul><li>収益イベントの発生当日（Day 0）に比較します。</li><li>ROI360 Advancedをご利用のお客様のみ対象です。</li></ul></li><li>Data Locker経由の単一バージョンの広告収益レポートにある、端末単位の広告収益。<ul><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li></ul></li><li>アクティビティダッシュボードに表示される集計済み収益。<ul><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li></ul></li></ul> |
| SDKとS2Sの併用（速報データを後から精度の高いデータに更新） | 広告表示単位（SDK経由） | メディエーションパートナーの収益ダッシュボードのデータを、次のデータと比較します。<ul><li>アクティビティダッシュボードの収益、またはData Locker経由の単一バージョンの広告収益レポートの総収益。<ul><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li></ul></li><li>Data Lockerの広告表示単位の収益レポート。<ul><li>収益イベントの発生当日（Day 0）に比較します。</li><li>ROI360 Advancedをご利用のお客様のみ対象です。</li></ul></li></ul>**注意**：広告収益データは後から変更される場合があります。また、すべてのユーザーが、広告収益SDK Connectorを組み込んだ最新バージョンのアプリに更新しているとは限りません。そのため、AppsFlyerとメディエーションパートナーのデータを比較すると、差異が生じることがあります。 |
| SDKとS2Sの併用（速報データを後から精度の高いデータに更新） | 端末単位（S2S API経由） | <ul><li>AppsFlyerのアクティビティダッシュボード、またはData Locker経由の単一バージョンの広告収益レポートに表示される総収益を、メディエーションパートナーの総収益データと比較します。</li><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li><li>広告収益イベントの件数（af\_ad revenueイベントとして報告）とインプレッション数は比較しないでください。</li></ul> |

</Accordion>

<Accordion title="AppsFlyerのデータとユーザー獲得パートナーのデータの比較">

ユーザー獲得パートナーが比較用の広告収益データをポストバックやUAシグナルで受信するには、ROI360 Advancedの契約が必要です。

| 連携方式 | データの種類 | パートナー側のデータ取得元 | 比較するデータの組み合わせ |
| --- | --- | --- | --- |
| S2S API | 端末単位 | UAシグナル | <ul><li>AppsFlyerのアクティビティダッシュボード、またはData Locker経由の単一バージョンの広告収益レポートに表示される総収益を、ユーザー獲得パートナーの総収益データと比較します。</li><li>収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li><li>広告収益イベントの件数（af\_ad revenueイベントとして報告）とインプレッション数は比較しないでください。</li></ul> |
| SDK | 端末単位 | UAシグナル | <ul><li>AppsFlyerのアクティビティダッシュボード、またはData Locker経由の単一バージョンの広告収益レポートに表示される総収益を、ユーザー獲得パートナーの総収益データと比較します。</li><li>収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li><li>広告収益イベントの件数（af\_ad revenueイベントとして報告）とインプレッション数は比較しないでください。</li></ul> |
| SDK | 広告表示単位 | 広告収益のポストバック | ユーザー獲得パートナーの収益ダッシュボードのデータを、次のデータと比較します。<ul><li>AppsFlyerのコホートダッシュボード／レポート。<ul><li>対象のメディアソース（ユーザー獲得パートナー）別にデータをグループ化します。</li><li>特定の日付で絞り込んだうえで、af\_ad\_revenueイベントの総収益を確認します。これにより、特定のレポート対象日に発生したインストールから得られた広告収益と、そのインストールに関するポストバックで報告された広告収益を比較できます。</li><li>収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li></ul></li><li>AppsFlyerのアクティビティダッシュボード／Data Locker経由の単一バージョンの広告収益レポート。<ul><li>対象のメディアソース（ユーザー獲得パートナー）別にデータをグループ化します。</li><li>特定の日付で絞り込んだうえで、af\_ad\_revenueイベントの総収益を確認します。これにより、特定のレポート対象日に発生したインストールから得られた広告収益と、そのインストールに関するポストバックで報告された広告収益を比較できます。</li><li>収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li></ul></li></ul> |
| SDKとS2Sの併用（速報データを後から精度の高いデータに更新） | 広告表示単位（SDK経由） | 広告収益のポストバック | ユーザー獲得パートナーの収益ダッシュボードのデータを、次のデータと比較します。<ul><li>ROI360の収益ETLにある、広告収益［SDK広告表示単位］レポート。<ul><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li></ul></li><li>アプリ内イベントのポストバックのローデータレポート。<ul><li>AppsFlyerとメディエーションパートナーの両方でデータの処理が完了するよう、収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li></ul></li></ul> |
| SDKとS2Sの併用（速報データを後から精度の高いデータに更新） | 端末単位（S2S API経由） | UAシグナル | <ul><li>AppsFlyerのアクティビティダッシュボード、またはData Locker経由の単一バージョンの広告収益レポートに表示される総収益を、ユーザー獲得パートナーの総収益データと比較します。</li><li>収益イベントの発生翌日（Day 0＋1）まで待ってから比較します。</li><li>広告収益イベントの件数（af\_ad revenueイベントとして報告）とインプレッション数は比較しないでください。</li></ul> |
