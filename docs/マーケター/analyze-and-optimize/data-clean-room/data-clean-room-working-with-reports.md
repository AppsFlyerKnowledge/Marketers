> **概要：** 概要： Data Clean Room (DCR) で設定したレポートを操作・管理する手順を説明します。

## はじめに

この記事では、作成済みのレポートの使用について説明します。これらのレポートとそのステータスの完全なリストは、DCR の**レポート**タブで確認できます。  
  
新しいDCRレポートの作成手順については、次の記事を参照してください：

* <Anchor target="_blank" href="/marketers/ja/docs/data-clean-room-creating-attribution-data-reports">アトリビューションデータレポートの作成</Anchor>
* <Anchor target="_blank" href="/marketers/ja/docs/data-clean-room-creating-in-app-event-reports">アプリ内イベントレポートの作成</Anchor>

## レポートの編集または削除

**レポートの編集：**

1. AppsFlyer管理画面 > **Data Clean Room** > **レポート**タブに移動します。
2. レポートのリストで、編集するレポートの行にカーソルを合わせます。
4. **レポートの編集**ページで、必要に応じてレポート設定を変更します。
   * 現在、レポート名は編集できません。
5. レポートの接続先を編集するには：
   1. **レポートの接続先**セクションまで下にスクロールします。
   3. **レポートの接続先**ダイアログで必要な変更を行います。
   4. [**適用**] をクリックして、変更を適用します。
6. **更新**ボタンをクリックして新しい設定でレポートを保存するか、**変更を破棄**をクリックして変更を元に戻します。

**レポートの削除：**

1. AppsFlyer管理画面 > **Data Clean Room** > **レポート**タブに移動します。
2. レポートのリストで、削除するレポートの行にカーソルを合わせます。
4. ダイアログで、レポートを削除することを確認します。
