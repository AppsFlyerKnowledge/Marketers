## ブランドディレクトリとは何ですか?

ブランドディレクトリは、AppsFlyerの広告主がコマースメディアネットワーク（CMN）の紹介を最優先で行うための専用ネットワークです。

### 広告主にとっての主なメリット

* **コマースメディアネットワークへの露出：** CMNは、あなたのブランドを発見し、積極的な努力をすることなくオファーを送ることができます。
* **広告主は無料：** ブランドディレクトリへの参加と AppsFlyerのデータコラボレーションプラットフォーム (DCP) の使用は、どちらも広告主様は無料です。
* **コミットメントなし：** CMNとのつながりに関心があることを表明いただければ、ご了承をいただいたうえでご紹介します。

## よくある質問

<div id="does-being-part-of-the-brands-directory-cost-me-anything" />

<Accordion title="ブランドディレクトリに登録すると、費用はかかりますか？">

いいえ、無料です。

</Accordion>

<div id="am-i-committed-to-working-with-cmns-if-i-join-the-brands-directory" />

<Accordion title="ブランドディレクトリに参加した場合、CMNと連携する義務が生じますか？">

いいえ、その必要はありません。これは単に、CMNとのコラボレーションの可能性に関心があることを示すだけです。

</Accordion>

<div id="will-i-need-to-purchase-appsflyer-s-data-collaboration-platform-data-clean-room-or-audiences" />

<Accordion title="ブランドディレクトリに参加する場合、AppsFlyerのDCP、Data Clean Room、またはAudiencesを契約する必要がありますか？">

いいえ、ブランドディレクトリに登録しても、AppsFlyer製品を追加契約する必要はありません。

</Accordion>

<div id="assuming-i-want-to-start-collaborating-with-a-commerce-media-network-should-i-purchase-appsflyer-s-data-collaboration-platform-or-data-clean-room" />

<Accordion title="CMN とのコラボレーションを開始したい場合、AppsFlyerのDCP または Data Clean Roomを購入する必要がありますか?">

いいえ、DCPはCMNとコラボレーションするブランドには無料です。

</Accordion>

<div id="do-i-need-to-buy-appsflyers-data-collaboration-platform-or-data-clean-room-or-audiences-to-join-the-brands-directory-or-to-collaborate-with-a-cmn" />

<Accordion title="ブランドディレクトリに参加する前に、新しい利用規約を確認または検討する必要がありますか?">

いいえ。ブランドディレクトリにオプトインすると、お客様に適した CMN をご紹介できるようになります。オプトインすると、他のネットワークと同様、ネットワークを直接操作できます。

</Accordion>

<div id="if-im-not-using-the-data-clean-room-how-does-this-impact-joining-the-brands-directory" />

<Accordion title="Data Clean Room を使用していない場合、ブランドディレクトリへの参加にはどのような影響がありますか?">

ブランドディレクトリに登録されても、AppsFlyer のサービスに影響を与えることはなく、単に、成長をサポートしてくれる CMN に的を絞った紹介を可能にするだけです。

</Accordion>

<div id="would-cmns-have-access-to-our-firstparty-data-directly-or-will-piipi-data-be-hashed-to-a-certain-degree-similar-to-our-current-ua-networks" />

<Accordion title="CMN はファーストパーティデータに直接アクセスするのでしょうか、それとも PII/PI データは現在の UA ネットワークと同様にある程度ハッシュ化されるのでしょうか?">

ネットワークに参加するために、ファーストパーティデータを共有したり、AppsFlyer 内でデータを公開したりする必要はありません。

</Accordion>

<div id="how-will-you-introduce-me-to-relevant-cmns" />

<Accordion title="関連する CMN をどのように紹介してもらえますか?">

メディアネットワークを提供したい CMN、またはオーディエンス構築やデータクエリ用にファーストパーティデータへのアクセスを提供したいと考えている CMN に関するすべての詳細が記載されたメールが送信されます。

</Accordion>

<div id="can-i-opt-out-of-the-brand-directory-network" />

<Accordion title="ブランドディレクトリネットワークをオプトアウトできますか?">

はい、いつでも可能です。オプトアウトを希望する旨を CSM に知らせると、このネットワークから削除されます。

</Accordion>
