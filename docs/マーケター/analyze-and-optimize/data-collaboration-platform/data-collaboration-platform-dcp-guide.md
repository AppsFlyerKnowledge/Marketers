> **概要：** AppsFlyerのData Collaboration Platformは、コマースメディアネットワークと連携するブランドが双方のデータを活用し、キャンペーン成果を最大化するとともに、新たな広告収益源を生み出せる、シームレスかつプライバシー重視のソリューションです。

## Data Collaboration Platform（DCP）について

AppsFlyerのData Collaboration Platform（DCP）は、コマースメディアネットワークとブランドが双方のデータの可能性を最大限に引き出せるよう支援する、次世代の高度なソリューションです。安全性とプライバシーを重視した機能により、シームレスなデータ連携を実現します。企業は新たな広告収益源を創出し、目的に応じたカスタムオーディエンスを構築して、さまざまなチャネルで精度の高いキャンペーンを展開できます。

DCPは、ユーザーレベルデータを含む共有データを処理して匿名化されたインサイトを生成します。個々のユーザー情報がAppsFlyerや連携パートナーに開示されないよう、厳重に保護されます。厳格なガバナンスとコンプライアンスを適用し、すべての当事者がアクセスおよび利用ポリシーに合意することで、情報の不正共有や不適切な利用を防止します。パートナーが保有するデータを組み合わせることで、自社データだけでは得られない、より包括的で有用な集約インサイトを活用できます。

14,000以上のグローバルブランドに加え、数千のカスタマーデータプラットフォーム（CDP）、メディアパートナー、データ拡充ツールからなる連携エコシステムを活用し、DCPはデータドリブンなコラボレーションを促進して、より大きな収益と成果につなげます。 DCPは、コマースメディアネットワークとブランドの双方がキャンペーン成果と収益を最大化し、パートナーシップを強化して、競争の激しいデジタル環境で成長できるよう支援します。

**Data Collaboration Platform（DCP）では、以下が可能です。**

* 専門的な技術知識を持たないブランド側のマーケティング担当者でも、提供されたデータから自らオーディエンスを構築し、サイト内外で広告を配信できるため、新たな収益源を創出できます。
* あらゆるリテールメディアのシナリオで、共同活用するデータに基づくキャンペーン成果をSKU単位の粒度で計測できます。これにより、自社と連携ブランドの双方が、確信を持ってマーケティング投資を最適化できます。
* データの専門家がいなくても、複数のコラボレーションに合わせてデータを再構成・正規化し、機密情報を保護できます。
* IDRプロバイダー、他のクリーンルーム、各種プラットフォームとのシームレスな連携を構築・維持できます。データプライバシーを保護しながら、さまざまなエコシステムへ拡張・適応し、コラボレーションを進められます。
* グローバルおよび各地域のプライバシー規制に準拠しながら、安心してビジネスを成長させることができます。すべてのコラボレーションで、安全かつコンプライアンスに準拠したデータ連携を確保します。

## ユースケース

コラボレーションのユースケース例を紹介します。

<div id="personalized-marketing-to-consumers" />

<Accordion title="消費者に合わせたパーソナライズドマーケティング">

コマース事業者とブランドの間で匿名化データを共有し、個々の購買行動に基づいて最適化した広告を作成します。

> 📄 **例：ノンエンデミック広告**
>
> 業種をまたぐコラボレーションの例として、手頃な価格帯のファッションブランドが、スーパーマーケットでおむつを頻繁に購入する顧客（幼い子どもの親や養育者）にアプローチします。幼児向け衣料品の広告を配信します。

> 📄 **例：エンデミック広告**
>
> 購買意欲の高いオーディエンスへのリーチ例として、フードデリバリー事業者がファストフードブランドと連携します。事業者は、フードデリバリーを注文する多数のユーザー基盤を活用し、ブランドのセール情報を自社アプリ上で直接訴求します。ブランドは露出を高め、より精度が高くパーソナライズされたオーディエンスにリーチできるため、キャンペーン成果の向上につながります。

</Accordion>

<div id="audience-segmentation-and-targeting" />

<Accordion title="オーディエンスのセグメント化とエンゲージメント">

匿名化された購入履歴や閲覧行動を活用し、「価格を重視する購入者」や「ブランドロイヤルティの高い顧客」など、購買意欲が高いと考えられる顧客セグメントを特定します。

> 📄 **例：ノンエンデミック広告**
>
> ブランドが小売事業者と連携し、ランニングシューズをプロモーションします。ブランドは、小売事業者のアプリ内検索で過去7日以内にランニングシューズを検索したものの、購入には至っていないユーザーにアプローチします。

> 📄 **例：ノンエンデミック広告**
>
> アパレルブランドがコマースメディアネットワーク（CMN）のホテルチェーンと連携し、南国の旅行先を訪れる旅行者に夏物コレクションをプロモーションします。

</Accordion>

## DCPの利用開始

**DCPの利用を開始するには、以下の手順を実施します。**

<span id="h_01J5WC8Z4J352AHSDTRCEP2W9H"></span>**前提条件**

* DCPへのアクセス権が付与されたAppsFlyerの<Anchor target="_blank" href="https://www.appsflyer.com/sign-up/">アカウント</Anchor>。

<div id="step-1-planning" />

<Accordion title="ステップ1 計画">

データコラボレーションで実現できることは多岐にわたります。計画時には、以下を検討してください。

1. 利用するデータの検討自社と連携候補の目的を踏まえ、コラボレーションに含めると有用なデータを検討します。価値があると考えられる関連データを特定します。
2. データを準備し、集約します。

</Accordion>

<div id="step-2-create-your-cloud-storage-infrastructure" />

<Accordion title="ステップ2 クラウドストレージ環境の設定">

クラウドストレージには、コラボレーションで使用するデータソースとオーディエンスが保存されます。クラウドストレージ環境を設定するには、クラウドサービスとDCPの間で受信接続と送信接続を構成します。

* **受信接続**は、ソースの作成時に自社のファーストパーティデータへアクセスするために使用します。
* **送信接続**は、プラットフォーム内で構築したオーディエンスの出力先として使用します。

**クラウドストレージ環境を設定するには：**

1. <Anchor target="_blank" href="/marketers/ja/docs/data-collaboration-platform-dcp-set-up-your-cloud-services">クラウドサービスを設定</Anchor>します。
2. <Anchor target="_blank" href="/marketers/ja/docs/data-collaboration-platform-dcp-add-connections">クラウドサービスをAppsFlyerに接続</Anchor>します。

</Accordion>

<div id="step-3-create-your-data-sources" />

<Accordion title="ステップ3 ソースの作成">

ソースとは、Data Collaboration Platform（DCP）に取り込まれる自社のファーストパーティデータを指します。作成したソースは、後から特定のコラボレーターと安全に共有できます。<Anchor target="_blank" href="/marketers/ja/docs/data-collaboration-platform-dcp-create-and-manage-sources">ソースの作成方法</Anchor>を確認してください。

</Accordion>

<div id="step-4-create-a-collaboration" />

<Accordion title="ステップ4 コラボレーションの作成">

コラボレーションでは、データの共同活用に必要な一連の作業を行います。コラボレーターを招待し、共有データに対してコラボレーターが実行できる操作を定める<Anchor target="_blank" href="/marketers/ja/docs/data-collaboration-platform-dcp-sharing-permissions">権限</Anchor>を設定したうえで、データを共有します。<Anchor target="_blank" href="/marketers/ja/docs/data-collaboration-platform-dcp-create-a-collaboration">コラボレーションの作成方法</Anchor>を確認してください。

</Accordion>

<div id="step-5-run-campaigns-and-measure-the-results" />

<Accordion title="ステップ5 オーディエンスの構築とキャンペーンの実施">

次に、自社とコラボレーターが共同活用するデータから<Anchor target="_blank" href="/marketers/ja/docs/data-collaboration-platform-dcp-build-and-activate-audiences">オーディエンスを構築</Anchor>し、キャンペーンに活用します。

</Accordion>

<div id="h_01JRA57G544BRSJ5JNJRZ4BV4X" />

<Accordion title="ステップ6 計測の設定とインサイトの取得">

共同キャンペーンの成果を確認するため、<Anchor target="_blank" href="/marketers/ja/docs/data-collaboration-platform-dcp-collaboration-measurement-overview">計測を設定</Anchor>します。設定後は、コラボレーションダッシュボードでキャンペーン結果を確認できます。

</Accordion>

## 追加情報

Data Collaboration Platformに関する追加情報です。

<div id="data-clean-room-dcr-and-dcp" />

<Accordion title="Data Clean Room（DCR）とDCP">

Data Collaboration Platform（DCP）は、オーディエンスの作成や有効化を含むデータコラボレーションの中心的なプラットフォームとして機能します。 DCPは、<Anchor target="_blank" href="/marketers/ja/docs/data-clean-room-overview">Data Clean Room（DCR）</Anchor>の高度なテクノロジーを活用し、コラボレーションやオーディエンス管理プロセスにおけるデータのプライバシーとセキュリティを確保します。

</Accordion>

<div id="commonly-used-terms::8d835d5a" />

<Accordion title="主な用語">

Data Collaboration Platformに関連して使用される主な用語を説明します。

| 用語 | 説明 |
| --- | --- |
| <span id="audiences"></span>**オーディエンス** | DCP内で、複数のデータセットを組み合わせて作成するセグメント化されたデータファイル。合意済みの権限に基づき、オーディエンスはメディアパートナーで有効化するか、コラボレーターのクラウド接続へ送信して利用します。 |
| <span id="data-connections"></span>**データ接続** | ファーストパーティデータが保存されているクラウドサービスへの接続。コラボレーターとデータを共有したり、DCPで作成したオーディエンスを受け取ったりするために使用します。 |
| <span id="data-sources"></span>**データソース** | DCPで使用するファーストパーティデータファイルの保存場所を指定した構造化フォルダ。プラットフォーム内でデータをクエリし、オーディエンスを構築する際に使用します。 |
| <span id="endemic-advertising"></span>**エンデミック広告** | その市場に自然に適合する広告掲載。検索が行われているECサイトで通常販売されている商品を広告する形態を指します。 |
| <span id="nonendemic-advertising"></span>**ノンエンデミック広告** | 小売事業者が販売していない商品やサービスであっても、その顧客やニーズに関連・補完するブランドの商品・サービスを訴求するために、小売事業者の広告枠を売買する手法。 |
| <span id="onsiteoffsite-advertising"></span>**オンサイト／オフサイト広告** | 企業が自社のデジタルプロパティ上で行う広告施策（オンサイト）と、外部のプラットフォームやWebサイトで行う広告施策（オフサイト）の区別。 |

</Accordion>
