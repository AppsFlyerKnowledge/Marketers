> **概要：** Protect360ダッシュボードでは、不正なトラフィックや、検証ルールの適用によってブロックされたインストールの状況を把握できます。

## Protect360ダッシュボードについて

Protect360ダッシュボードには、次の特徴があります。

* アカウント単位で不正の集計データを表示します。
* 次の2つの表示があります。
  * インストール（CPI）
  * アプリ内イベント（CPA）
* 不正を次のようなカテゴリに分けて表示します。
  * 偽のインストールと、ハイジャックされたインストール
  * リアルタイムでブロックされた不正と、ポストアトリビューションで判明した不正
  * ユーザー獲得（UA）キャンペーンとリターゲティングキャンペーンで発生した不正
* フィルタやグループ化を使って詳細を絞り込み、不正なイベントを詳しく調べられます。

Protect360ダッシュボードを開くには、AppsFlyerで**最適化** > **Protect360**に移動します。&lt;0>&lt;1> 1>0>

**フィルタとグループ化の画面**

[![p360_filters_2.png](https://files.readme.io/9fd2afbbfc1bdf671ae0427d75c1020085b36da724e40dcfe57da27943e15b0c-4408431325969.png)](https://files.readme.io/9fd2afbbfc1bdf671ae0427d75c1020085b36da724e40dcfe57da27943e15b0c-4408431325969.png)

次のフィルタとグループ化の項目を利用できます。

* 基本フィルタ：
  * アプリ名
  * 流入元の種類：非オーガニック、および／またはオーガニック
  * メディアソース
  * 地域
  * 日付範囲（<Anchor target="_blank" href="/marketers/ja/docs/about-data-freshness-and-timezone-support#protect360-dashboard">タイムゾーンの対応状況</Anchor>をご覧ください）
  * アトリビューションの種類：インストール、リアトリビューション、および／またはリエンゲージメント
  * [課金対象イベント](/docs/protect360-dashboard#payable-events)（アプリ内イベントダッシュボードで利用可能）
* 追加フィルタ：日付選択欄の右にある青い矢印をクリックします。
  * 代理店
  * キャンペーン
  * チャネル
* グループ化：必要な情報を把握できるよう、不正データを分類する項目を選択します。
  * **アプリ**：アプリごとの不正の総数を比較します。
  * **メディアソース**（デフォルト）：アプリが利用するメディアソースごとの検知された不正を比較します。
  * **メディアソース＋キャンペーン**：アプリが利用するすべてのメディアソースの、すべてのキャンペーンで検知された不正を比較します。
  * **メディアソース＋サイトID**：アプリが利用するすべてのメディアソースの、すべてのパブリッシャー（サイトID）で検知された不正を比較します。
  * **メディアソース＋サイトID＋キャンペーン**：アプリが利用するすべてのメディアソースの、すべてのパブリッシャー（サイトID）で検知された不正を、関連するキャンペーン名とともに比較します。
  * **メディアソース＋地域**（アプリ内イベントダッシュボードで利用可能）：アプリが利用する各メディアソースで検知された不正を、関連する国別に比較します。
  * **メディアソース＋アトリビューションの種類**：各メディアソースで検知された不正を、選択したアトリビューションの種類（インストール、リアトリビューション、および／またはリエンゲージメント）別に比較します。
  * **地域**：すべての国で検知された不正を比較します。

## インストールダッシュボード

インストールダッシュボードには、LTVベースのデータが表示されます。これは、選択した日付範囲に発生したインストール、リアトリビューション、リエンゲージメントに関連するデータです。

ダッシュボードの機能は、以下の各セクションで説明します。

<div id="installs-headline-metrics" />

<Accordion title="インストール：主要指標">

主要指標では、次の情報を確認できます。

* **検知された不正なアトリビューション**：不正なインストールの総数。
* **ブロックされたアプリ内イベント**：不正なアプリ内イベントの件数。
* **タグ付けされたアトリビューションの総数**：タグ付けされたアトリビューションの総数。
* **タグ付けされたアプリ内イベントの総数**：タグ付けされたアプリ内イベントの総数。
* **不正な広告接触の影響を受けたインストール**：偽の広告接触が検知されたインストールの件数。
* **インストールあたりの平均エンゲージメント数**：インストールに関連する広告接触の平均件数。

各KPIには、割合（%）が表示されます。この値は、直前の同じ長さの期間に対するKPIの変化を示します。例えば、今週と先週、または選択した日付範囲とその直前の同じ日数の期間を比較します。不正ブロックによる推定削減額がX%増加したと表示される場合、直前の同じ長さの期間では、不正なインストール、リアトリビューション、リエンゲージメントがX%少なかったことを意味します。

* ポストアトリビューション（アトリビューション後）に不正と判明したインストール、リアトリビューション、リエンゲージメント。

#### 検知された不正の推移グラフ

このグラフには、不正なインストール、リアトリビューション、リエンゲージメントの日次件数が、次のいずれかの内訳で表示されます。

* **検知の種類**：リアルタイムでブロックされたインストールと、ポストアトリビューションで不正と判明したインストール。
* **アトリビューションの種類**：インストール、リアトリビューション、リエンゲージメント。
* **流入元の種類**：非オーガニックとオーガニック。
* **検知ステータス**：タグ付け、タグなし、ブロックのデータを比較します。
* **不正な広告接触の影響を受けた割合**：総アトリビューション数に占める、不正な広告接触の影響を受けたと判定された件数の割合。

折れ線グラフまたは棒グラフで表示できます。

<div id="hijacked-installs-attribution-correction-chart" />

#### ハイジャックされたインストールのアトリビューション修正グラフ

このグラフには、インストール、リアトリビューション、リエンゲージメントの成果を不正に獲得しようとしたメディアソースと、最後の有効なアトリビューションに貢献した流入元が表示されます。

次の操作が可能です。

* リアルタイムまたはポストアトリビューションで判明したハイジャック、あるいは検証ルールで検知されたアトリビューションで絞り込む。
* 成果の付け替え先となった有効な流入元、または付け替え元となったハイジャックの流入元を表示するよう設定する。
* グラフを表形式に切り替え、データをCSVでダウンロードする。

**注意：**

* このグラフを利用できるのは広告主のみです。代理店とアドネットワークはアクセスできません。
* ハイジャックがリアルタイムでブロックされた場合、修正後のアトリビューションはProtect360だけでなく、AppsFlyerのダッシュボードとレポートにも表示されます。ハイジャックがポストアトリビューションで判明した場合、修正後のアトリビューションはProtect360のローデータにのみ表示されます。
* このグラフでは、オーガニック**への**付け替えは表示できますが、オーガニック**からの**付け替えは表示できません。

#### 検知された不正のグラフ

このグラフには、発生している不正の種類が割合で表示されます。不正の内訳は、次の項目別に表示できます。

* ブロック理由
* <Anchor target="_blank" href="/marketers/ja/docs/protect360-raw-data-reports#インストール単位偽のインストールのブロック理由の詳細">ブロック理由の詳細</Anchor>
* タグの種類
* タグ付け理由
* タグ付け理由の詳細
* メディアソース
* キャンペーン
* 地域
* アプリ

#### Affiliate Attribution Model

AppsFlyerの新しい**Affiliate Attribution Model**（アフィリエイト向けアトリビューションモデル）は、クリック洪水の問題に直接対処します。その中心となる専用のアトリビューションアルゴリズムは、大量の偽の広告接触が送信されたデバイスを検知し、認証とAIによるリアルタイムの行動分析を使って広告接触を検証します。これにより、偏りがなく不正に強い、実際のユーザーの意図に基づくアトリビューションを実現します。

* **不正な広告接触の影響を受けた割合：** 総アトリビューション数に占める、不正な広告接触の影響を受けたと判定された件数の割合。
* **アトリビューション候補の表示：**
  * 不正な広告接触の影響を受けたアトリビューション1件あたりの候補数：不正な広告接触の影響を受けたと**判定された**アトリビューションにおける、候補の平均数。
  * 不正な広告接触の影響を受けていないアトリビューション1件あたりの候補数：不正な広告接触の影響を受けたと**判定されていない** **データ**における、候補の平均数。
* これらの指標は、時系列の推移グラフにも表示されます。
  * 不正な広告接触の影響を受けたインストールの総数
  * 不正な広告接触の影響を受けたアトリビューション1件あたりの候補数
  * 不正な広告接触の影響を受けていないアトリビューション1件あたりの候補数

不正な広告接触の影響を受けたインストールとは、AppsFlyerのアトリビューション判定ロジックにより、デバイスに大量の偽の広告接触が送信されたと判定されたインストールです。これは、デバイスが大量の偽の広告接触による操作の影響を強く受けたことを示し、具体的にはインストールが不正に操作されたケースを指します。

</Accordion>

| 行動の異常によるブロック | ユーザーのセッションやアプリ内イベントの異常な動作など、行動の異常によってブロックされたインストール。 |
| ポストアトリビューションでの行動の異常検知 | ポストアトリビューションで行動の異常により、不正としてマークされたインストール。 |
| インストール検証によるブロック | ストアでの検証に失敗したことにより、ブロックされたインストールの総数。 |
| **ハイジャックされたインストールのブロック内訳** | **実際のユーザーのアプリインストール成果を横取りしようとする、偽のラストクリックの内訳。** |
| インストールハイジャックによるブロック | その流入元でブロックされたインストールハイジャック。 |
| ポストアトリビューションでのインストールハイジャック検知 | ポストアトリビューションで不正としてマークされたインストールハイジャック。 |
| CTITの異常によるブロック | CTITの異常によってブロックされたインストール。 |
| ポストアトリビューションでのCTITの異常検知 | ポストアトリビューションで不正としてマークされたCTITの異常。 |
| クリック洪水によるブロック | クリック洪水によってブロックされたインストール。クリック洪水とは、大量のクリックを送信し、偶然発生するインストールの直前のラストクリックを獲得しようとする不正です。 |
| ポストアトリビューションでのクリック洪水検知 | ポストアトリビューションで不正としてマークされた、クリック洪水によるインストール。 |
| **クリック** | **その流入元からのクリック**<br /><br />**注意：** クリックデータを表に表示するには、フィルタバーですべてのアトリビューションの種類を選択してください。選択していない場合は「N/A」と表示されます。この条件を満たすように、フィルタの選択内容を調整してください。 |
| 合計（E） | その流入元から受信した、正常なクリックと不正なクリックの総数 |
| ブロック | 不正によってブロックされたクリック |
| **インプレッション** | **その流入元からのインプレッション**<br /><br />**注意：** インプレッションデータを表に表示するには、フィルタバーですべてのアトリビューションの種類を選択してください。選択していない場合は「N/A」と表示されます。この条件を満たすように、フィルタの選択内容を調整してください。 |
| 合計 | その流入元から受信した、正常なインプレッションと不正なインプレッションの総数 |
| ブロック | 不正によってブロックされたインプレッション |
| **アプリ内イベント** | **その流入元からのアプリ内イベント**<br /><br />**注意：** インストールに紐づくアプリ内イベントが対象です。リアトリビューションやリエンゲージメントに紐づくものは含まれません。 |
| 合計（G） | アプリ内イベントの総数 |
| ブロック（H） | ブロックされたアプリ内イベント |
| 割合（%）（H/G） | ブロックされたアプリ内イベント数／アプリ内イベントの総数 |
| **大量の端末を使った不正の指標** | **デバイスIDのリセットやLAT（広告トラッキング制限）を利用し、大量の端末を使って行われる不正の兆候。**<br /><br />**注意：** インストールとリアトリビューションが対象です。リエンゲージメントは含まれません。 |
| インストール（I） | AppsFlyerがまだ識別していない、新しいデバイスIDを持つインストール。 |
| インストールの割合（%）（I/A） | 新規デバイスのインストール数／総インストール数 |
| ロイヤルユーザー率（%） | ユーザーが実在するか、偽のユーザーかを示す一般的なKPI。 |
| **クリック洪水の指標** | **コンバージョン率、アシスト率、CTITの異常に基づく、クリック洪水の不正の兆候。** |
| コンバージョン率（%） | アプリ全体のコンバージョン率よりも低い割合は、クリック洪水の不正の兆候です。<br /><br />**注意**：コンバージョン率のデータを表に表示するには、フィルタバーですべてのアトリビューションの種類を選択してください。選択していない場合は「N/A」と表示されます。この条件を満たすように、フィルタの選択内容を調整してください。 |
| アシスト率（%） | 他のメディアソースよりも高い割合は、クリック洪水の不正の兆候です。概要ページのアシストウィジェットで比較できます。 |
| CTIT > 60分超 | クリックから初回アプリ起動までの時間が60分を超える、インストール、リアトリビューション、リエンゲージメント。計算対象はCTITが25時間未満のインストールのみです。すべてのインストールが対象になるわけではありません。通常、初回アプリ起動の約30%は、ダウンロードから60分を超えて発生します。 |
| CTIT > 5時間超 | クリックから初回アプリ起動までの時間が5時間を超える、インストール、リアトリビューション、リエンゲージメント。計算対象はCTITが25時間未満のインストールのみです。すべてのインストールが対象になるわけではありません。通常、初回アプリ起動の約20%は、ダウンロードから5時間を超えて発生します。 |

#### 表のその他の操作

* **CSVを出力**をクリックすると、表をCSV形式でコンピュータにダウンロードできます。
* 歯車アイコンをクリックすると、次の操作ができます。
  * 列の順序の変更
  * 上記の列の追加・削除
  * アプリで**最近ブロックされたアプリ内イベント**の追加・削除アプリ内イベントを追加するたびに、次の列が表示されます。

| 列 | 説明 |
| --- | --- |
| イベント件数（合計） | そのイベントがブロックされた回数 |
| ユニークユーザー数 | そのイベントがブロックされたユニークユーザーの数 |

これらのKPIの割合が通常とは異なっていても、不正とは限りません。多くのイベントは、ポストアトリビューションで不正と判明したインストールに紐づくためにブロックされる点に注意してください。

CPIダッシュボードのアプリ内イベントデータはLTVベースです。指定した日付範囲に発生したインストールに紐づく、すべてのアプリ内イベントが対象になります。

## アプリ内イベントダッシュボード

アプリ内イベントダッシュボードには、アクティビティベースのデータが表示されます。選択した日付範囲に発生したアプリ内イベントが対象で、日付範囲より前のインストールに紐づくイベントも含まれます。

ダッシュボードの機能は、以下の各セクションで説明します。

<div id="inapp-events-headline-metrics" />

<Accordion title="アプリ内イベント：主要指標">

[![](https://files.readme.io/ea33b3ddafc4265eb74b2e1070a77a6afbad429a1aeb20cd1579127f7e8ee605-360012501757.jpg)](https://files.readme.io/ea33b3ddafc4265eb74b2e1070a77a6afbad429a1aeb20cd1579127f7e8ee605-360012501757.jpg)

* 不正ブロックによる推定削減額

  * 設定した課金対象イベントに基づいて算出されます。

</Accordion>

<div id="payable-events" />

<Accordion title="課金対象イベント">

課金対象イベントとは、広告費が発生するアプリ内イベントです。有効にして設定すると、アプリ内アクティビティダッシュボードには課金対象イベントに関連するデータのみが表示されます。

**アプリ内アクティビティダッシュボードで課金対象イベントを有効にするには**：

* アプリ内アクティビティダッシュボードの**絞り込み**セクションで、課金対象イベントを有効にします。  
  [![](https://files.readme.io/8162f6f4f6dcef50fbe0fd998b7a95d20deeb658dd53bafc216b75df050c734c-360012576718.jpg)](https://files.readme.io/8162f6f4f6dcef50fbe0fd998b7a95d20deeb658dd53bafc216b75df050c734c-360012576718.jpg)

**課金対象イベントを設定するには**：

1. アプリ内アクティビティダッシュボードで、**課金対象イベントの設定**をクリックします。

   [![](https://files.readme.io/00b1f4506f0c7ec8e1e1b90c16cc2232d2862b231b2673d2decc7a90b6c6b6af-360012505217.jpg)](https://files.readme.io/00b1f4506f0c7ec8e1e1b90c16cc2232d2862b231b2673d2decc7a90b6c6b6af-360012505217.jpg)

   課金対象イベントの設定画面が表示されます。

   [![](https://files.readme.io/4643b9d0e0042ca5860d21ec3eb3ff7e4178f92f1f4215db56adda10be41c452-360012580938.jpg)](https://files.readme.io/4643b9d0e0042ca5860d21ec3eb3ff7e4178f92f1f4215db56adda10be41c452-360012580938.jpg)
2. ［任意］新しい課金対象イベントを設定する場合は、**新規追加**をクリックします。
3. ダッシュボードに表示したい課金対象イベントに応じて、ドロップダウンから次の項目を選択します。
   * アプリ
   * アプリ内イベント
   * メディアソース
   * キャンペーン
4. アプリ内イベントのCPAを入力します。
5. **保存**をクリックします。
6. **閉じる**をクリックします。

</Accordion>

<div id="traits-and-limitations" />

<Accordion title="仕様と制限事項">

| 項目 | 補足 |
| --- | --- |
| リターゲティング | <ul><li>インストール（CPI）ダッシュボードでは、インストール、リアトリビューション、リエンゲージメント別に、アトリビューション対象の広告接触の種類の内訳を表示できます。</li><li>アプリ内イベント（CPA）ダッシュボードには、UAインストールに関連する不正イベントが表示されますが、リターゲティングのイベントは表示されません。 **注意**：リアトリビューションに関連する不正イベントのうち、リアルタイムで検知されたものは、ローデータレポートで確認できます。</li></ul> |
| 過去のデータ | Protect360の契約開始時点以降のデータを利用できます。 |
| データの更新頻度 | 日次で更新されます。<ul><li>インストール（CPI）：UTC 16:00</li><li>アプリ内イベント（CPA）：UTC 21:00</li></ul> |
| メディアソースを選択できない場合 | フィルタにメディアソースが表示されない場合、そのメディアソースのトラフィックがすべてブロックされている可能性があります。<br /><br />そのメディアソースで絞り込むには、検知された不正の内訳表にあるリンクを使用できます。 |

</Accordion>
