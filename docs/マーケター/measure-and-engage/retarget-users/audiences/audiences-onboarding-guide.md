> **概要**：AppsFlyer Audiencesを使用して、カスタマイズされたオーディエンスセグメントを構築し、パートナーネットワークに接続することで、最も効果的なユーザー獲得およびリマーケティングキャンペーンを実施できます。

## オーディエンスについて

AppsFlyer <Anchor target="_blank" href="/marketers/ja/docs/audiences-guide">Audiences</Anchor> を使用すると、オーディエンスセグメントを簡単に作成し、それを自社の広告チャネルと有料チャネルの両方に接続できるため、エンゲージメントとパフォーマンスを向上させるカスタマイズされたキャンペーンを配信できます。

オーディエンスとは、定義した特定の基準を満たすアプリのユーザー（過去または現在）のセグメントです。基準は、個人特性、行動、アトリビューションソース、収益、地理的位置、デバイスの種類などに基づき、高度にカスタマイズされたマーケティング戦略を可能にします。

カスタムオーディエンスを最初から作成したり、独自のデータベースからインポートしたりするほか、業界のベストプラクティスに基づいたカスタマイズ可能な「推奨オーディエンス」から選べます。その後、オーディエンスはメディアパートナーに接続され、メンバー識別子がパートナーに送信されて、パートナー側でオーディエンスが作成されます。これにより、オーディエンスに合った広告を配信することが可能になります。オーディエンスは毎日自動的に更新され、シームレスなプロセスでパートナーと共有されます。さらに、キャンペーン送信後は、Audiences内でキャンペーンのパフォーマンス指標を直接監視することができます。

## オーディエンスオンボーディング

**オーディエンスを使用するには、以下の手順に従ってください。**

| タスク | 目的 | 必要な処置 | 関係者 |
| --- | --- | --- | --- |
| 1.オーディエンスをサブスクライブ |  | サブスクライブするには、営業担当者に連絡するか、[hello@appsflyer.com](mailto:hello@appsflyer.com) までメールを送ってください。 | マーケター |
| 2.アカウントレベルのプライバシーポリシーを設定する | これにより、ユーザー識別子をパートナーと共有するためのアカウントレベルのポリシーが設定されます。 | プライバシーポリシーを設定します。 | マーケター |
| 3.オーディエンスを作成する |  | 作成するオーディエンスの種類を選択します。<ul><li><Anchor target="_blank" href="/marketers/ja/docs/audiences-guide#create-a-suggested-audience">推奨オーディエンス</Anchor> - 業界のベストプラクティスに基づいたすぐに使用できるカスタマイズ可能なオーディエンス。</li><li><Anchor target="_blank" href="/marketers/ja/docs/audiences-guide#create-a-custom-audience">カスタムオーディエンス</Anchor> - オーディエンスを一から構築します。</li><li><Anchor target="_blank" href="/marketers/ja/docs/audiences-import-audience-segments-from-internal-systems">インポートされたオーディエンス</Anchor> - 社内システム (BIやCRMなど) からオーディエンスをインポートします。</li></ul> | マーケター |
| 4.オーディエンスをパートナーに接続する | これにより、オーディエンスがパートナーと接続され、パートナー側でオーディエンスが作成されます。オーディエンスは毎日更新されます。 | <ol><li>パートナーの<Anchor target="_blank" href="/marketers/ja/docs/audiences-guide#create-a-new-connection">接続</Anchor>を追加します。</li><li><Anchor target="_blank" href="/marketers/ja/docs/audiences-guide#connect-an-audience-to-media-partners">オーディエンスをパートナーに</Anchor>接続します。</li></ol> | マーケター |
| **オプションのタスク** |  | <ol><li>パートナーとコントロールグループにオーディエンスを分割することで、<Anchor target="_blank" href="/marketers/ja/docs/run-an-incrementality-for-remarketing-experiment">インクリメンタリティ</Anchor>実験を有効にします（インクリメンタリティのサブスクライバー向け）。</li><li><Anchor target="_blank" href="/marketers/ja/docs/audiences-create-better-audiences-with-user-attribute-data">ユーザー属性</Anchor>をインポートします。これらは、高度にパーソナライズされたオーディエンスを作成するためのユーザー特性です。</li></ol> | マーケター |
| 5.カスタマイズしたキャンペーンを作成し、パートナー側のオーディエンスに配信します。 |  | <ol><li>オーディエンスに合わせたキャンペーンを作成します。</li><li>パートナー側でオーディエンスを選択します。</li><li>それをオーディエンスに提供してください。</li></ol> | マーケター |
| 6.キャンペーン結果を分析します |  | キャンペーンの結果を<Anchor target="_blank" href="/marketers/ja/docs/audiences-guide#campaign-metrics">Audiences</Anchor>や他のAppsFlyerダッシュボードで確認します。 | マーケター、データアナリスト |

※ Audiences に登録後、AppsFlyer は過去 90 日間のアプリ内イベントデータを取得します。このプロセスには1～2週間かかる場合があります。完了後、通知が届きオーディエンスの作成が開始可能です。
