> **概要：**

<div id="note-1" />

<div id="note" />

> 📘 **注意**
>
> Pinterestは、インストール後12か月でユーザーレベルのデータを削除するようアトリビューションプロバイダーに要請しています。つまり、これらのユーザーがアプリをインストールしてから12か月後に行ったイベントは、オーガニック経由の成果としてカウントされます。過去の集計データは変わりません。


**<span id="set-up-bing"></span>前提条件:** **連携を設定する前に、必ず<Anchor target="_blank" href="/marketers/ja/docs/partner-integrations#パートナーに連絡する">パートナーに連絡して</Anchor>アカウントを開設してください。**

**連携を有効化または編集する方法：**

1. **有効にする：** AppsFlyer のサイドメニューから**共同作業**> **パートナー・マーケットプレイス**の順で選択します。  
   **編集方法：** AppsFlyer のサイドメニューから、 **共同作業** > **連携を有効にする**の順で選択します。
2. パートナーを検索し選択してください。
3. **連携設定** をクリックして、連携設定ページに移動します。
4. **連携**タブで、連携アプリを選択し、**パートナーの有効化**をオンにします。  
   **注意：** トグルは、パートナーと作業している間、オン<Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation">（有効）</Anchor>にしておく必要があります。
5. 以下の手順に従い、各タブの設定を完了してください。

#### パートナーの有効化

この画面を**最初に開く**際には、次の***パートナーを有効にする***をオンにして、連携タブのパラメータ設定を有効にします。このパートナーと連携を続ける限り、トグルをオンにしておく必要があります。  
パートナーの有効化についての詳細は、 <Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation">こちら</Anchor>をご覧ください。
