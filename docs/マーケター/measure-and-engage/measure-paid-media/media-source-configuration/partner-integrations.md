> **概要**：あなたの業界に特化した新しいメディアソースとプラットフォームを見つけましょう。パートナーマーケットプレイスから、各社のサービスとパフォーマンスについて学び、連絡を取って直接連携できます。

## 概要

パートナーマーケットプレイスには、アドネットワーク、マーケティングパートナー、代理店、分析プラットフォーム、メールサービスプロバイダー（ESP）など、AppsFlyerと連携された10,000を超えるパートナー（AppsFlyerパートナー）が紹介されています。これらのメディアソースとプラットフォームは、さまざまな業種と地域に特化しています。マーケットプレイスでは、**まだ馴染みのないパートナーを見つけて**、そのパフォーマンスやよく利用されている業界などを確認することができます。また、他の業種の新しいサービスを探索し発見することで、成長と進化を促進できます。

パートナーマーケットプレイスから、[既存のパートナー連携にアクセス](/docs/partner-integrations#既存の連携管理)し、さらに多くのアプリを連携に接続できます。

> 📘 **注記**
>
> パートナーマーケットプレイスは現在、広告主アカウントでのみ利用可能で、代理店やパートナーはまだアクセスできません。

<div id="quick-start" />

## クイックスタート

パートナーマーケットプレイスを探索し、新しい機会を発見し、パートナーとのつながりを始めましょう。

**開始するには：**

1. **パートナーマーケットプレイスにアクセスする：** AppsFlyer管理画面 左メニュー **連携** > **パートナーマーケットプレイス** へ移動します。
2. [**パートナーを探す**](/docs/partner-integrations#パートナーを探す)
3. [**パートナーについて知る**](/docs/partner-integrations#パートナーについて学ぶ)：パートナーを選択すると、パートナーの詳細ページにアクセスできます。
4. [**パートナーとの連携**](/docs/partner-integrations#新しいパートナーとの連携)

## パートナーを探す

マーケットプレイスでパートナーを見つけて、何を提供しているかを確認する方法として、いくつかの選択肢があります。

* [パートナーマーケットプレイスのホームページから探索](/docs/partner-integrations#パートナーマーケットプレイスを探索する)する
* パートナーリストを[フィルター](/docs/partner-integrations#パートナーリストのフィルター)する
* 特定のパートナーを[検索](/docs/partner-integrations#パートナーについて学ぶ)する

[![partner marketplace updated.png](https://support.appsflyer.com/hc/article_attachments/30603947718801)](https://support.appsflyer.com/hc/article_attachments/30603947718801)

### パートナーマーケットプレイスを探索する

目的に最も合ったパートナーを簡単に見つけられるよう、カテゴリに応じてセクション分けされています。例：

* **あなたのアプリにおすすめ：** 成長率、リテンション、アプリ内の購入率が高いパートナー。
* [**データクリーンルーム（DCR）パートナー：**](#dcrパートナー)ファーストパーティおよびサードパーティのデータを提供する技術パートナーを活用することで、データを充実させ、キャンペーンのパフォーマンスを最適化できます。
* **あなたのカテゴリで人気のパートナー：** 最もアクティブな連携数を持つメインカテゴリのパートナー。
* **最終訪問：** マーケットプレイスで最近閲覧したパートナー。

#### パートナーカード

![google_meta.png](https://support.appsflyer.com/hc/article_attachments/30603947722129)

パートナーサービスに関する基本情報については、パートナーカードを参照してください。

* **アクティブ**ステータス表示 — 連携がアクティブな場合に表示されます
* 企業名の後には、品質基準を満たすパートナーの場合は**品質バッジ**が表示され、または[**DCRパートナー**](#dcrパートナー) の表示が続きます（詳細は[下記](/docs/partner-integrations#パートナーページ)参照）。
* メディアプラットフォームの種類
* [**紹介してほしい**](/docs/partner-integrations#パートナーに連絡する)
* **アプリの連携：** 過去30日間に計測されたトラフィックを持つパートナーのアクティブなアプリ連携の数
* **ページビュー：** 過去30日間のアドネットワークの詳細ページの閲覧回数
* **設定**アイコン — 連携パートナーに表示されます

#### DCRパートナー

DCRパートナーは、ファーストパーティおよびサードパーティのデータを提供する技術パートナーです。<Anchor target="_blank" href="/marketers/ja/docs/data-clean-room-data-enrichment-through-tech-partner-integrations">AppsFlyerのデータクリーンルーム（DCR）</Anchor>は、DCRパートナーからのユーザーレベルのデータとあなたのユーザーレベルのデータを照合し、強化された連携データを生成します。AppsFlyerはこのデータを使用して集計レポートを作成し、ユーザープライバシーを維持しながら、キャンペーンのパフォーマンスを最適化するための集計インサイトを得られるようにします。

**注：** <Anchor target="_blank" href="/marketers/ja/docs/data-clean-room-overview">DCR</Anchor>プランをご契約でない場合は、パートナーページからリクエストを送信できます。

### パートナーリストのフィルター

ページ上部のフィルターを使用して、検索に関連するパートナーを見つけましょう。パートナーマーケットプレイスページにアクセスすると、アプリのアクティビティ（カテゴリーと対象地域）に基づいたデフォルトのフィルターが適用されます。AppsFlyerは、同じデバイスでの今後のセッションのために、最後の選択内容を自動的に保存します。検索をさらに調整するには、次のフィルターを使用してください：

| フィルター | 説明 |
| --- | --- |
| <span id="category-subcategorysubsubcategory"></span>カテゴリー、サブカテゴリー、  <br />サブサブカテゴリー | パートナーをカテゴリー別にフィルターします（パートナーによって定義されています）。フィールドをクリックすると、カテゴリー、サブカテゴリー、またはサブサブカテゴリーのリストが表示されます。 |
| <span id="target-region"></span>対象地域 | 選択した地域でのアクティビティに応じてパートナーをフィルターします。 |
| <span id="target-geos"></span>ターゲット地域 | 選択した地域で主なアクティビティを行うパートナーをフィルターします。 |
| <span id="supported-capabilities"></span>サポートされている機能 | キャンペーン最適化やA/Bテストなど、パートナーがサポートする機能でフィルターします。これらの機能はパートナーによって定義されています。 |
| <span id="supported-platforms"></span>サポートされているプラットフォーム | iOSやAndroidなど、選択したプラットフォームをサポートしているパートナーをフィルターします（パートナーによって定義されています）。 |
| <span id="pricing-model"></span>料金モデル | 選択した料金モデル（パートナーによって定義）をサポートしているパートナーをフィルターします。 |
| <span id="ad-type"></span>広告タイプ | 選択した広告タイプ（パートナーによって定義）をサポートしているパートナーをフィルターします。 |
| <span id="supported-features"></span>サポートされている機能 | 連携でサポートされている機能に基づいて[パートナーをフィルター](#filter-by-supported-features)します。 |
| <span id="appsflyer-performance-index"></span>AppsFlyerパフォーマンスインデックス | 選択すると、最新のAppsFlyerパフォーマンスインデックスに含まれるパートナーのみが表示されます。 |
| <span id="high-quality-traffic"></span>高品質のトラフィック | 選択すると、不正率が低いバッジを持つパートナーのみが表示されます（先月のトラフィックに基づく）。 |

> 📘 **注記**
>
> 検索バーを使用すると、適用したフィルターがすべてクリアされます。検索バーをまず利用してから、結果が表示された後でフィルターを適用すると、結合された結果が得られます。

### パートナーを探す

![パートナー検索3.png](https://support.appsflyer.com/hc/article_attachments/30603976116369)

特定のパートナーを検索するには、パートナーマーケットプレイスの検索バーを使用してください。パートナーマーケットプレイスで検索バーを使用する場合：

* パートナーを名前またはPIDで検索できます。
* 既存のパートナーには、連携管理 <Image alt="manage_integration_cogwheel.png" src="https://support.appsflyer.com/hc/article_attachments/30603947731089" width="19px" /> アイコンが表示されます。現在選択されているアプリの設定ページに移動します。
* パートナーロゴの左にある緑やオレンジの点は、<Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation#integration-activity-indication">連携のアクティビティレベル</Anchor>を示します。
* パートナーを検索して訪問すると、次回の検索時に最近の5つのパートナーが表示されます。
* [アクティブなパートナー連携内](/docs/partner-integrations#連携済みパートナー)を検索することもできます。

## パートナーについて学ぶ

パートナーの詳細ページから、各パートナーの詳細を確認し、パートナーとつながることができます。パートナーページを表示するには、[パートナーカード](/docs/partner-integrations#パートナーカード)をクリックします。

### パートナーページ

パートナーページからできること：

* [パートナーに連絡する](#パートナーに連絡する)
* [新しい連携を設定する](/docs/partner-integrations#新しいパートナーとの連携)
* [既存の連携を管理する](/docs/partner-integrations#既存の連携管理)

パートナーページで確認できる内容：

* パートナーが品質基準を満たすと、次のバッジが表示されます。
  * **パフォーマンスインデックス**をクリックすると、ページの下部にあるパートナーランキング表が表示されます。このインデックスは、パートナーが最新のパフォーマンスインデックスに登場した場合にのみ表示されます。
  * **高品質のトラフィック**、不正行為率が非常に低い最近数ヶ月間のトラフィックを示します。
* **アプリの連携：** 過去30日間に記録されたトラフィックを持つパートナーのアクティブなアプリ連携の数。
* **ページビュー：** 過去30日間のアドネットワークの詳細ページの閲覧回数
* **サポートされている機能：** パートナーがサポートする[AppsFlyer連携機能](#filter-by-supported-features)を確認します。
* **パートナーのパフォーマンス：** [パートナーのパフォーマンス](/docs/partner-integrations#パートナーのパフォーマンス)のさまざまな側面が品質レベルを示します。
* あなたのカテゴリにおける他のアカウントがこのパートナーをどれくらい閲覧したを確認できます。
* **パートナーの詳細：** パートナーが提供する情報には、サービス、機能、利用規約が含まれます。
* **データクリーンルーム（**<Anchor target="_blank" href="/marketers/ja/docs/data-clean-room-overview">**DCR**</Anchor>**）パートナーと接続する：** DCRをパートナーのデータソースに接続し、データを充実させてキャンペーンのパフォーマンスを最適化します。  
  **注：** <Anchor target="_blank" href="/marketers/ja/docs/data-clean-room-overview">DCR</Anchor>プランをご契約でない場合は、パートナーページからリクエストを送信できます。

> 📘 **注記**
>
> * 左上の**AppsFlyerアイコン**をクリックすると、AppsFlyerプラットフォームで最後にアクセスしたページに戻ります。
> * 左上の**マーケットプレイスアイコン**をクリックすると、パートナーマーケットプレイスで最後にアクセスしたページに戻ります。

#### パートナーに連絡する

AppsFlyerは、お客様に代わって紹介メールを送信することでパートナーとのつながりをサポートします。テキストメッセージは送信前に確認できます。

1. パートナーの詳細ページで、**紹介してほしい**をクリックします。
2. オプションで**メールの全文を表示**にマウスを合わせると、全文メッセージが表示されます。
3. **簡単な紹介を送信**をクリックします。

> 📘 **注記**
>
> * **紹介してほしい**ボタンは、パートナーが関連する連絡先情報を提供した場合にのみ表示されます。
> * 一部のパートナーは、ランディングページ経由で連絡を取りたい場合があります。この場合、**紹介してください**の代わりに**パートナーに連絡してください**というボタンが表示されます。

#### パートナーのパフォーマンス

[![Partner performance page.png](https://support.appsflyer.com/hc/article_attachments/30603976126097)](https://support.appsflyer.com/hc/article_attachments/30603976126097)

マーケターの判断をサポートするために、このセクションではパートナーのパフォーマンスメトリックを示し、品質レベルを明示しています。

**連携済みパートナー**

以下の基準に基づいてパートナーのサービスレベルに関する情報を提供します。

* **生涯平均アクティビティ：** 選択したメディアソースでマーケターがキャンペーンをアクティブに実行している平均期間。測定期間は過去12か月前までで、純トラフィック時間のみが考慮されます。
* **配信継続率：** 過去1年間にメディアソースと連携し、現在もアクティブな広告主の割合。

**地域とカテゴリ率**

* **上位の地域／カテゴリを表示：** デフォルトでは、インストール数でソートされ、パートナーが最もアクティブな上位10の地域とカテゴリが表示されます。パートナーパフォーマンスフィルター（セクションの右上）を適用すると、それに応じた結果が表示されます。
* **地域ごとのカテゴリ：** 選択したカテゴリと地域におけるリターゲティング／ユーザー獲得率の内訳を表示します（選択したオプションにより異なります）。

デフォルトのグラフには、すべてのプラットフォームでパートナーがアクティブな上位10のカテゴリと地域が表示されます。右上隅から最大10件の他の地域またはカテゴリ、利用可能なプラットフォームを選択してデフォルト設定を変更できます。

## 新しいパートナーとの連携

[新しいパートナーを見つけ](/docs/partner-integrations#パートナーを探す)、[そのパフォーマンスについて学習](/docs/partner-integrations#パートナーについて学ぶ)した後、連携の設定を行うことができます。  アプリがパートナーに接続されると、ダッシュボードに非オーガニックデータが表示されるようになります。

> 📘 **注記**
>
> 連携の設定を行う前に、必ずパートナーに連絡してアカウントを開設してください。

**新しいパートナーとの連携を設定するには：**

1. AppsFlyer管理画面 左メニュー **連携** > **パートナーマーケットプレイス**を選択します。
2. パートナーを検索して選択します。 [パートナーの詳細ページ](/docs/partner-integrations#パートナーページ)に移動します。
3. **連携の設定**をクリックします。連携設定ページに移動します。
4. **パートナーをアクティブ化**をオンにし、<Anchor target="_blank" href="/marketers/ja/docs/set-up-an-integrated-partner">残りの連携セクションを設定</Anchor>します。

連携が設定されると、パートナーは<Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation#active-partners">アクティブ</Anchor>になります。次に、**セクション内のアクティブなパートナーを表示**をクリックして、ページをフィルターし、アクティブなパートナーのみを表示できます。

<div id="invite-new-partners-to-appsflyer" />

### AppsFlyerに新規パートナーを招待する

使用中 / これから配信したいアドネットワークがまだAppsFlyerと連携されていない場合は、連携における招待リンクを送信できます。

<div id="validation-period-for-new-integrations" />

#### 新規連携の検証期間

新しいアドネットワークの連携をパートナーマーケットプレイが正式に追加される前に、最大60日間の検証期間が設けられ、AppsFlyerがその期間中にトラフィックの品質を評価します。検証後に品質基準を満たさない場合は、AppsFlyer連携パートナーから削除されます。

> 📘 **注**
>
> * 招待リンクを通じて新規パートナーの招待ができるのは、広告主アカウントにおける<Anchor target="_blank" href="/marketers/ja/docs/user-management#新しいパートナーをappsflyerに招待する">管理者</Anchor>のみです。
> * このオプションは、GrowthおよびEnterprise<Anchor target="_blank" href="/marketers/ja/docs/account-management-plans-payments-and-billing#appsflyer-plans">プラン</Anchor>のお客様に提供されています。

**新しいパートナーをAppsFlyerと連携させるために招待するには：**

1. AppsFlyer管理画面 左メニュー **連携** > **パートナーマーケットプレイス** を選択します。
2. パートナーマーケットプレイスページの右上隅にある3つのドットをクリックして、**新規パートナーの招待**を選択します。   
   [![invite_new_partner.png](https://support.appsflyer.com/hc/article_attachments/30603976129297)](https://support.appsflyer.com/hc/article_attachments/30603976129297)
3. パートナーの名前と関連するメールアドレスを入力します。  
   パートナーには、登録リンクが記載されたメールが送信され、サインアッププロセスが始まります。

## 既存の連携管理

既存の（<Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation#active-partners">アクティブな</Anchor>）連携を管理し、<Anchor target="_blank" href="/marketers/ja/docs/set-up-an-integrated-partner#i-connect-more-apps-optional">さらに多くのアプリをパートナーと連携</Anchor>できます。現在選択されているアプリの<Anchor target="_blank" href="/marketers/ja/docs/set-up-an-integrated-partner">連携設定</Anchor>画面にアクセスするためのいくつかの方法があります。

* AppsFlyer管理画面 左メニュー **連携** > **連携済みパートナー**を選択します。
* マーケットプレイスの**連携済みパートナー**セクションまたは画面（下記参照）から、[パートナーカード](/docs/partner-integrations#パートナーカード)を選択します。
* パートナーマーケットプレイスの検索バーでパートナーを検索するとき、連携パートナーの横に表示される <Image alt="manage_integration_cogwheel.png" src="https://support.appsflyer.com/hc/article_attachments/30603947731089" width="19px" /> アイコンをクリックします。

### 連携済みパートナー

アクティブなパートナー連携を確認する：

* パートナーマーケットプレイスページの上部にある[**連携済みパートナー**セクション](/docs/partner-integrations#連携済みパートナー--セクション)で最近アクセスしたパートナーを表示します。
* [すべてのアクティブなパートナー](/docs/partner-integrations#連携済みパートナー--ページ)を表示します：**連携済みパートナー**セクションから**すべて表示**をクリックします。
* アクティブな連携内の検索バーを使用して、名前またはPIDでパートナーを検索します。
* パートナーマーケットプレイスページの左側のメニューから**アクティブなパートナーを表示セクション**を選択します。これにより、トレンド、おすすめ、人気などのページセクションごとにアクティブなパートナーが表示されます。

> 📘 **注記**
>
> * パートナーカードをクリックすると、パートナーの構成ページに移動します。
> * 品質基準を満たすパートナーの場合、パートナーカードにマウスをホバーすると、**パートナーパフォーマンス**アイコン **![](https://support.appsflyer.com/hc/article_attachments/30603947739793) が表示されます。これをクリックすると、直近の[パートナーのパフォーマンス](/docs/partner-integrations#パートナーのパフォーマンス)が表示されます。**

#### 連携済みパートナー — セクション

[![marketplace_active_integrations_section.JPG](https://support.appsflyer.com/hc/article_attachments/30603947742225)](https://support.appsflyer.com/hc/article_attachments/30603947742225)パートナーマーケットプレイスページの上部にある**連携済みパートナー**セクションでは、現在選択されているアプリ（パートナーマーケットプレイスに入る前に最後に選択されたアプリ）の最近の<Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation#active-partners">アクティブなパートナー</Anchor>が表示されます。

**すべて表示**をクリックすると、**連携済みパートナー**画面が開き、アプリで連携されているアクティブなパートナーがすべて表示されます。

#### 連携済みパートナー — ページ

[![active integratins page.png](https://support.appsflyer.com/hc/article_attachments/30603976137617)](https://support.appsflyer.com/hc/article_attachments/30603976137617)

**連携済みパートナー**画面には、すべての<Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation">アクティブな</Anchor>連携パートナーが表示されます。このページから、連携の管理、アクティブなパートナー内の検索、および現在選択されているアプリに接続されていないパートナーの新しい連携を作成することができます。**連携済みパートナー**画面は2つのセクションに分かれています：

* **現在選択されているアプリ**との連携済みパートナー
* 現在選択されているアプリを除く**他のすべてのアプリ**との連携済みパートナー

> 📘 **注記**
>
> * **連携済みパートナー**画面に表示されるアクティブなパートナーは、現在選択されているアプリ（マーケットプレイスに入る前に最後に選択されたアプリ）に応じて異なります。左上のアプリをクリックして別のアプリを選択すると、どのパートナーが他のアプリに接続されているかを確認できます。
> * リストは、過去3か月間に最も多くアクセスしたパートナー連携順で整理されています。リストをアルファベット順に並び替えることができます。
> * 連携済みパートナーの一部に直近の計測数値がない場合は、**連携済みパートナー**ページにその旨を示すメッセージが表示されます。
