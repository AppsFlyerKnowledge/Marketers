## Partner Marketplaceについて

<div id="based-on-what-data-is-the-information-in-the-partner-performance-section-calculated" />

<Accordion title="パートナーパフォーマンスのセクションの情報はどのデータに基づいていますか？">

指標とグラフはパートナーからAppsFlyerに送信されたトラフィックデータに基づいています。

* グラフデータ：過去2か月にAppsFlyerが受信したインストールデータ
* **生涯平均アクティビティ:**
* **広告主リテンション率:**

**注記：** 注：パフォーマンスデータは集計された統計データに基づいています。統計的妥当性を確保するために、AppsFlyerは厳格なボリュームに関するしきい値と方法論に従い算出しています。

</Accordion>

## Partner Marketplaceを使用する

<div id="what-information-can-i-see-on-a-partner-card-without-entering-the-page" />

<Accordion title="詳細ページを開かなくても表示される「パートナーカード」にはどのような情報が表示されますか？">

各パートナーのページへ移らずとも、パートナーに関する詳細を簡単に閲覧できるように、<Anchor target="_blank" href="/marketers/ja/docs/partner-integrations#パートナーカード">パートナーカード</Anchor>では次の情報を確認できます：

* パートナーがサポートする上位3つの機能
* パートナーのパフォーマンス（AppsFlyerにトラフィックデータがあるパートナー向け）。リンクをクリックすると、パフォーマンスに関する実際のデータを含むパートナーのパフォーマンス表に移動します。
* メディアプラットフォームの種類
* 連携ステータス（<Anchor target="_blank" href="/marketers/ja/docs/partner-activation-deactivation?query=activate">アクティブ</Anchor>な場合）

</Accordion>

<div id="how-do-i-use-filters-with-a-search-query" />

<Accordion title="検索クエリでフィルタを使用するにはどうすればよいですか?">

Marketplaceを開くと、デフォルトで現在のアプリのアクティビティ（業種とターゲットとしている国）に基づいてフィルタが適用されます。フィルタを解除または更新したり、デフォルト設定に戻すことができます。

| 期待する結果 | 適用方法 |
| --- | --- |
| フィルタと検索を組み合わせて結果を表示する | まず最初に検索バーを使用し、検索結果が表示されたあとにフィルタを適用してください。 |
| 検索結果を維持したまま、適用されたフィルタを解除する | 検索バーの下にある全てクリアをクリックしてください。 |
| 検索結果を維持したまま、デフォルトのフィルタに戻す | 検索バーの下にあるデフォルトに戻すをクリックしてください。 |
| 検索をリセットする（フィルタと検索を組み合わせた検索結果を含む） | <ul><li>検索バーで [**X**] をクリックしてください。</li><li>左上の**Partner Marketplace**アイコンをクリックします</li></ul> |

> 📘 **注意**
>
> * AppsFlyerは、同じデバイスでの今後のセッションのために、最後の選択内容を自動的に保存します。
> * <Anchor target="_blank" href="/marketers/ja/docs/partner-integrations?query=marketplace#filters">各フィルタの説明</Anchor>を参照してください。

</Accordion>

<div id="with-the-new-marketplace-how-do-i-integrate-with-new-partners" />

<Accordion title="新しいPartner Marketplaceで、新しいパートナーと連携するにはどうすればよいですか？">

連携自体は連携済みパートナーページから行われますが、新しいパートナーを見つけて接続するには、まず **Marketplace**へアクセスする必要があります。適切なパートナーを見つけやすいように、パートナーは業界別に整理され、パフォーマンスレベルが表示され、効率的に検索できるようフィルタ機能が用意されています。

<Anchor target="_blank" href="/marketers/ja/docs/partner-integrations?query=marketplace#integrate-with-a-new-partner">参照：Partner Marketplaceから新しいパートナーと連携する方法</Anchor>

</Accordion>

## トラブルシューティング

<div id="if-i-see-an-interesting-partner-without-any-contact-details-what-should-i-do" />

<Accordion title="興味のあるパートナーを見つけましたが、連絡先が表示されていない場合はどうすればよいですか?">

すべてのパートナーにお問合せ先を提供してもらえるよう最善を尽くしていますが、それでも見つからない場合は、AppsFlyerの担当者にお問い合わせください。

</Accordion>
