> **概要：** 概要：アプリユーザーを、OneLinkで生成されたURLを使用して Web URLまたはソーシャルメディアページにリダイレクトします。

<div id="redirect-app-users-to-a-web-url" />

## アプリユーザーをWeb URLにリダイレクト

広告主は、外部のWebページまたはソーシャルサイトにユーザーを誘導するOneLink URLを投稿できます。AppsFlyerは、アプリ内でリンクのクリックを計測し、それによって広告の効果を判断することができます。

**前提条件**：少なくとも1つのアプリが登録されたAppsFlyerアカウントを持っていること

**アプリからWebへのリダイレクトを設定する方法**：

1. <Anchor target="_blank" href="/marketers/ja/docs/create-a-onelink-template#onelinkテンプレートの作成">OneLinkテンプレート</Anchor>を設定してください。
   * **アプリがインストールされた場合**のセクションで、アプリ起動の方法（ユニバーサルリンク、アプリリンク、またはURIスキーム）を設定していないことを確認してください。
2. <Anchor target="_blank" href="/marketers/ja/docs/create-deep-linking-and-redirection-links-for-your-campaigns-with-onelink#onelinkリンクの作成">OneLinkカスタムリンク</Anchor>を作成してください。
   * **アプリがインストールされている場合**のセクションで、リダイレクトの設定が正しいWeb URLになっていることを確認してください。
3. **注：**

**リンクをテストする方法**：

**前提条件**：

1. **注：** リンクを自分宛てにメールまたはWhatsAppなどのメッセンジャーアプリ経由で送信し、自分の端末でリンクを押下します。OSのメモ帳アプリや、モバイルブラウザのURLバーに直接貼り付けたりしないでください。
2. Web URLにリダイレクトされるはずです。
