> **概要：** OneLink単独利用のディープリンクスイートでは、有料メディアのアトリビューションパッケージを契約せずに、オウンドメディアの導線（メール、Web、QRコード、ソーシャルメディア、ユーザー紹介、SMS／テキストメッセージなどからアプリへの誘導）でディープリンクとリダイレクトを利用できます。

## OneLink単独利用のディープリンクスイートについて

単独利用のディープリンクスイートは、有料メディアのチャネルやパートナーへのポストバックを伴う連携を必要とせず、**オウンドチャネルで信頼性が高く、規模の拡大にも対応できるディープリンク、リダイレクト、アトリビューション**を利用したいチーム向けの製品です。

次の3つのサブスクリプションプランで利用できます。

* Standard
* Advanced
* Premium

### 利用できる機能

単独利用のディープリンクスイートのすべてのプランで、以下を含むオウンドメディアの基本的な用途に対応しています。

* 適切なアプリ内の遷移先へユーザーを誘導する**ディープリンクとディファードディープリンク**
* **プラットフォームをまたぐリダイレクトと、アプリが未インストールの場合の代替動作**
* AppsFlyerのUIでユーザー自身が行う**リンクの作成と管理**

プランごとの主な違いは、対応する運用規模、リンク管理機能、ブランドドメイン、リンクの一括作成、Smart Banners、OneLink API、ESP連携、Data Lockerなどの高度な機能を利用できるかどうかです。

## 単独利用のディープリンクスイートのプラン比較

### 主な違い

| プラン | 適した用途 | 主な機能 |
| --- | --- | --- |
| **Standard** | オウンドメディアのディープリンクの利用開始 | オウンドメディアの導線に必要な基本的なディープリンク・ディファードディープリンク機能に加え、Smart Scriptとユーザー招待を利用できます。 |
| **Advanced** | 複数チームでのリンク運用の拡大 | **Standard**のすべての機能に加え、リンクの一括作成、ブランドドメイン、Smart Banners、OneLink API（月間最大10万リクエスト）、UIからのローデータのエクスポートを利用できます。 |
| **Premium** | オウンドメディアでの高度なディープリンク施策の実施 | **Advanced**のすべての機能に加え、OneLink APIの上限拡大（月間最大750万リクエスト）、ESP連携、Data Lockerを利用できます。 |

### 機能比較

| 機能 | Standard | Advanced | Premium |
| --- | --- | --- | --- |
| ユーザー招待 | ✓ | ✓ | ✓ |
| Smart Banners | **x** | ✓ | ✓ |
| Smart Script | ✓ | ✓ | ✓ |
| ブランドドメイン | **x** | ✓ | ✓ |
| リンクの一括管理 | **x** | ✓ | ✓ |
| OneLink API | **x** | 月間最大10万リクエスト | 月間最大750万リクエスト |
| ESP連携 | **x** | **x** | ✓ |
| Data Locker | **x** | **x** | ✓ |
| UIからのローデータのエクスポート | **x** | ✓ | ✓ |
| カスタマーサクセスマネージャー | **x** | ✓ | ✓ |

> 📘 **注意**
>
> * 単独利用のディープリンクスイートは、オウンドメディアでの利用のみを対象としています。これらのプランには、有料メディアのアトリビューションに関するパートナー連携は含まれません。
> * OneLinkのほとんどの機能には、有料の<Anchor target="_blank" href="/marketers/ja/docs/account-management-plans-payments-and-billing#appsflyer-plans">AppsFlyerサブスクリプションプラン</Anchor>が必要です。
> * サブスクリプションプランを解約すると、OneLinkのほとんどの機能が利用できなくなり、関連するエンドユーザーの導線に悪影響が生じる可能性があります。
> * Zeroプランでは、ディファードディープリンクはサポートされていません。
