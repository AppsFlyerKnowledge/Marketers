| **概要** | **マイダッシュボード** への移行に伴い、**イベント**、**オーバービュー**、および**アクティビティ**ダッシュボードは提供終了となります。<br /><br />**2026年6月30日**以降、これらの従来のダッシュボードにはアクセスできなくなります。同じデータは マイダッシュボード で引き続き利用できるほか、強化された分析機能、柔軟な表示設定、カスタム指標、高度なフィルター機能、共有ダッシュボードおよびプライベートダッシュボードなどをご利用いただけます。 |
| --- | --- |
| **適用開始日** | **2026年5月30日**より、**分析**タブから従来のダッシュボードを開くと、マイダッシュボード内の対応するテンプレートまたはビューへのリンクを含むポップアップが表示されます。<br /><br />**2026年6月30日**より、従来の **イベント**、**オーバービュー**、および **アクティビティ** ダッシュボードにはアクセスできなくなります。<br /><br />データおよび保存済みのビューは マイダッシュボード で引き続き利用できます。 |
| **対象者** | イベント、オーバービュー、および アクティビティ ダッシュボードを利用しているすべての広告主、代理店、およびパートナー |
| **必要な対応** | 分析業務を中断することなく継続できるよう、提供終了日までに マイダッシュボード の利用を開始してください。<br /><br />開始手順：<ol><li>左側のナビゲーションメニューから**マイダッシュボード**を開きます。</li><li>利用目的に応じたテンプレートまたはビューを開きます：<ul><li>イベントデータの場合：　イベントテンプレート</li><li>オーバービューデータの場合：　**パフォーマンス分析** または **マーケティングオーバービュー** テンプレート</li><li>アクティビティデータの場合：　**アクティビティ** ビュー</li></ul></li><li>指標、フィルター、およびグループ化を使用してビューをカスタマイズします。</li><li>設定内容を共有ビューまたはプライベートビューとして保存します。</li></ol> |
| **ご確認いただきたい事項** | マイダッシュボードは、従来のダッシュボードよりも柔軟性とカスタマイズ性に優れた分析環境を提供します。<br /><br />主な機能：<ul><li>**統合データ：** ユーザー獲得とリターゲティングのデータを一か所で確認可能</li><li>**強化された表機能：** 最大4つのグループ化に対応し、最大100,000行をCSV形式でエクスポート可能</li><li>**ダッシュボードレベルのフィルタ：** ダッシュボード内の複数ウィジェットに対して共通のフィルターを適用可能</li><li>**共有ビューとプライベートビュー：** チームと共有するビュー、または個人専用ビューを作成可能</li><li>**カスタム指標とカスタムディメンション：** ビジネス要件に合わせた独自の指標やディメンションを作成可能</li><li>**期間の比較：** 過去期間との比較分析が可能</li><li>**強化されたチャート：** イベントウィジェット、コホートウィジェット、コンボチャート、複数指標対応チャートを利用可能</li><li>**条件付き書式：** テーブル内の重要なデータを強調表示可能</li><li>**指標ベースの並び替え：** 分析目的に応じた指標でテーブルを並び替え可能</li></ul>**<Anchor target="_blank" href="/marketers/ja/docs/my-dashboards#dashboard-templates"><span id="how-to-find-and-add-dashboard-templates"></span>ダッシュボードテンプレート</Anchor>の検索および追加方法**<ol><li>マイダッシュボードの左側メニューから、任意のダッシュボードを開きます。<br /><Image alt="" src="https://files.readme.io/26afca0c0285c01ff9019495cedd752b0dd823f071f58622a963c669fe38653a-46644427745937.png" width="93px" /></li><li>ダッシュボードのメインページで、ダッシュボード名の右側にある矢印をクリックします。<br /><Image alt="" src="https://files.readme.io/046551ea88a85e488eee6e08fef4bf4eff23dcedc461e461732a1f5413fa4c68-46644427750801.png" width="186px" /></li><li>ダッシュボード名を検索するか、テンプレート一覧から選択します。<br /><Image alt="" src="https://files.readme.io/3cce1e11a371d8dc6cc04ef29f8db9ff82781c414ece3ad07ccdbb2da75ea56b-46644506493969.png" width="186px" /></li></ol> |
| イベントダッシュボードの代替機能 | マイダッシュボードでイベントデータを確認するには：<ol><li>**マイダッシュボード**を開きます。</li><li>**イベント** テンプレートを開きます。</li></ol>イベントテンプレートでは、アプリ内イベントデータを包括的に分析できます。<br /><br />イベントテンプレートには以下の機能が含まれます。<ul><li>**イベントウィジェット：** メディアソース、地域、日付などのディメンション別にアプリ内ユーザー行動を分析</li><li>**コホートベースのイベント分析：** コホートの観点からイベントデータを分析</li><li>**ビジネスKPI：** 収益イベントやその他のカスタム KPI を中心としたビューを構築可能</li><li>**マイダッシュボードの機能：** フィルター、共有ビュー、CSV エクスポート、カスタム指標、最大4つのテーブルグループ化に対応</li></ul> |
| オーバービューダッシュボードの代替機能 | マイダッシュボードでオーバービューデータを表示するには：<ol><li>**マイダッシュボード**を開きます。</li><li>以下のいずれかのテンプレートを開きます。<ul><li>**パフォーマンス分析**</li><li>**マーケティングオーバービュー**</li></ul></li></ol>従来の オーバービューダッシュボードで保存されていたビューは、自動的に マイダッシュボード へ移行されます。<br /><br />パフォーマンス分析 と マーケティングオーバービュー のテンプレートでは、強化されたテーブル機能、ダッシュボードレベルのフィルター、共有ビューおよびプライベートビュー、カスタム指標およびカスタムディメンション、期間比較、強化されたチャート、条件付き書式、指標ベースの並び替えなど、マイダッシュボード の各種機能をご利用いただけます。<br /><br />従来のオーバービューダッシュボードで保存されていたビューは、自動的に マイダッシュボード へ移行されます<br /><br />アカウントで移行機能が有効化された後、60日間利用されていない保存済みビューは削除されます。保持したいビューは事前に開いて保存してください。 |
| アクティビティダッシュボードの代替機能 | マイダッシュボードでアクティビティデータを確認するには：<ol><li>**マイダッシュボード**を開きます。</li><li>**アクティビティ** ビューを開きます。</li></ol>すべてのアクティビティデータはマイダッシュボードで利用できます。<br /><br />アクティビティビューには、以下の機能が含まれます：<ul><li>**指標ベースの並び替え：** 特定の指標でテーブルデータを並び替え可能。セッション実績のあるキャンペーンなど、アクティビティ に表示されるキャンペーンについては、LTV データが存在しない場合でも除外されなくなります。</li><li>**期間別アクティブユーザー分析：** 平均値計算を行わず、指定期間内のアクティブユーザー数を確認可能</li><li>**横並び分析：** アクティビティデータと LTV 指標、コホート指標を同時に確認可能</li><li>**マイダッシュボードの機能：** 条件付き書式、カスタム指標、期間比較、フィルター、共有ビューおよびプライベートビューに対応</li></ul> |
| **<span id="faq"></span>よくある質問**| **<span id="will-i-lose-my-data"></span>データは失われますか？**<br /><br />いいえ。データは マイダッシュボード で引き続き利用できます。基盤となるデータは変更されません。変更されるのは分析インターフェースのみです。<br /><br />**<span id="what-happens-to-my-saved-views-from-the-overview-dashboard"></span>オーバービューダッシュボードの保存済みビューはどうなりますか？**<br /><br />従来の オーバービューダッシュボードで保存されていたビューは、自動的に マイダッシュボード へ移行されます。<br /><br />アカウントで移行機能が有効化された後、60日間利用されていない保存済みビューは削除されます。保持したいビューは事前に開いて保存してください。<br /><br />**<span id="can-i-access-the-legacy-dashboards-after-june-30-2026"></span>2026年6月30日以降も従来のダッシュボードにアクセスできますか？**<br /><br />いいえ。従来の イベント、オーバービュー、および アクティビティ ダッシュボードには、**2026年6月30日**以降アクセスできなくなります。<br /><br />**<span id="what-can-i-do-if-i-need-a-feature-that-isn-t-available-in-my-dashboards"></span>必要な機能がマイダッシュボードにない場合はどうすればよいですか？**<br /><br />CSMまたはAppsFlyerサポートにお問い合わせください。担当 CSM または AppsFlyer サポートまでお問い合わせください。AppsFlyer は継続的に マイダッシュボード の改善を進めており、お客様からのフィードバックをもとに機能ギャップの特定や改善の優先順位付けを行っています。<br /><br />**<span id="where-can-i-learn-more-about-my-dashboards"></span>マイダッシュボード について詳しく知るにはどうすればよいですか？**<br /><br /><Anchor target="_blank" href="/marketers/ja/docs/my-dashboards">**マイダッシュボード**</Anchor>のページをご確認ください。 |
