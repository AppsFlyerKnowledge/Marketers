| **新着情報** | スマートバナーにおいて、アトリビューションのために複数のメディアソースタイプを選択できるようになりました。もはや複数タイプのWeb-to-AppのURLに対応できます。 |
| --- | --- |
| **発効日** | 2021年8月25日 |
| **対象** | Smart Banners - バナーグループの設定 |
| 詳細 | **変更前：**<br /><br />**変更後：** 上記のメディアソースの1つ以上をサポートするように構成することができます。 |
| **お知らせ事項** | <ul><li>既存のスマートバナーやバナーグループがある場合は、設定はそのままです。</li><li>新しいバナーグループでは、UIが変更され、複数のメディアソースオプションを選択できるようになりました。</li><li>現行の Smart Banners Web SDK が統合されている必要があります。この機能は古い（非推奨）Web SDKではサポートされていません。</li></ul>[![](https://files.readme.io/35d3888899ee7d95cb81152ab5a72de5bfcf1df40568b7f2fea00c947658fd42-4406108511633.png)](https://files.readme.io/35d3888899ee7d95cb81152ab5a72de5bfcf1df40568b7f2fea00c947658fd42-4406108511633.png) |
