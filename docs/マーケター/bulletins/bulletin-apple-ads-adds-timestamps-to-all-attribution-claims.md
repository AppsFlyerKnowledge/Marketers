| 項目 | 詳細 |
| --- | --- |
| 変更内容 | 2026年9月1日より：<ul><li>AppleのAdServices APIでは、これまでタイムスタンプが付与されていなかったものを含め、すべてのiOSアトリビューションクレームにエンゲージメントのタイムスタンプが追加されます。 AppsFlyerでは、このタイムスタンプを使用して、設定済みのルックバック期間とラストタッチアトリビューションのルールをこれらのクレームに適用します。</li><li>年齢または性別によるターゲティングを設定した広告グループでは、Appleからアトリビューションのペイロードがfalseで返されるため、これらのエンゲージメントをAppsFlyerでApple Adsにアトリビューションすることはできません。</li></ul> |
| 適用開始日 | 2026年9月1日 |
| 確認事項 | <ul><li>ほとんどのApple Adsキャンペーンでは、これまでのデフォルトのルックバック期間ではなく、広告主が設定したルックバック期間に基づいてエンゲージメントが評価されるようになるため、アトリビューション精度の向上が見込まれます。これには、これまでタイムスタンプなしでクレームされていた、同意していないユーザーからのエンゲージメントも含まれます。</li><li>一方、年齢または性別によるターゲティングを設定した広告グループでは、アトリビューションのペイロードがfalseで返されます。これらの広告グループからのエンゲージメントはApple Adsによってクレームされないため、Apple Adsにアトリビューションすることはできません。</li></ul> |
| 必要な対応 | 対応は不要です。 Apple Ads連携には、この変更が自動的に反映されます。年齢または性別によるターゲティングを設定した広告グループを運用している場合は、9月1日以降のApple Adsレポートを確認し、アトリビューションされたコンバージョン数に変化がないかご確認ください。 |
