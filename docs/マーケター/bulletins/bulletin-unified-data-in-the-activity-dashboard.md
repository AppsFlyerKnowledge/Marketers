| **更新情報** | アクティビティデータは統一され、すべてのデータにはUAデータとリターゲティングデータの両方が含まれます。 |
| --- | --- |
| **更新日** | 2025年2月1日 |
| **対象機能** | アクティビティレポート、ピボットレポート、およびマスターAPI |
| **更新内容** | <ul><li>これまでは、セッションやDAUなど、いくつかのアクティビティ指標はUAデータのみに基づいていました。</li><li>現在、すべてのアクティビティ測定基準には、UAとリターゲティングの両方のデータが含まれています。**注意：** 統合ビューのみ：UAもしくはリターゲティングのみにデータを分割することはできません。</li><li>アドネットワークによっては、これまでUAキャンペーンに紐づいていたイベントがリターゲティングキャンペーンに紐づく場合があります。</li><li>リターゲティングトラフィックが計算に含まれるようになったため、DAUやMAUなどの指標はこの変更により増加する可能性があります。</li><li>2025年2月1日以前のデータについては、次の指標にはUAトラフィックデータのみが含まれます：<ul><li>アクティビティ管理画面：<ul><li>合計セッション数</li><li>DAU</li><li>MAU</li><li>DAU（1日あたりのアクティブユーザー数）とMAU（1ヶ月あたりのアクティブユーザー数）</li><li>ARPDAU</li><li>コスト</li><li>クリック</li><li>インプレッション</li><li>コンバージョン率</li><li>eCPI</li></ul></li><li>アクティビティレポート、ピボットレポート、およびマスターAPIアクティビティKPI</li></ul></li></ul> |
