| <span id="whats-new"></span>What's new | Meta ads can now optimize your Android App promotion campaigns using the ad revenue postback event **AdImpression**. |
| --- | --- |
| <span id="update-date"></span>Update date | January 1, 2025 |
| <span id="what-you-need-to-know"></span>What you need to know | <ul><li>Currently, optimization via the **Adimpression** event is available for Android app promotion campaigns.</li><li>When grayed out, [eligibility criteria may not be met](https://www.facebook.com/business/help/571188993373447?id=561906377587030).</li><li>The Adimpression event is mapped to the af\_ad\_revenue event, which is available for plans with an <Anchor target="_blank" href="/marketers/ja/docs/roi360-guide-cost-and-revenue-data">ROI360 advanced subscription</Anchor> only. Additionally, you need the <Anchor target="_blank" href="/marketers/ja/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">impression-level (via SDK) ad revenue or Impression-level (via SDK) with device-level (via S2S API) integration type</Anchor>.<ul><li>Non-ROI360 plans can send ad revenue data using other event names.</li></ul></li></ul> |
| <span id="what-you-need-to-do"></span>What you need to do | <ul><li>For ROI360 customers, use the <Anchor target="_blank" href="/marketers/ja/docs/roi360-guide-ad-revenue-attribution#integration-types-for-ad-revenue-attribution">impression-level (via SDK) ad revenue or Impression-level (via SDK) with device-level (via S2S API) integration type</Anchor>.</li><li><Anchor target="_blank" href="/marketers/ja/docs/meta-ads-in-app-event-mapping#mapping-ad-revenue-data-for-campaign-optimization">Map the af\_ad\_revenue event to **Adimpression**</Anchor>.</li></ul> |
| <span id="additional-resources"></span>Additional resources | See the <Anchor target="_blank" href="https://www.facebook.com/business/help/330074040129013">Meta Business Help Center</Anchor> to learn more about how to maximize the value of conversions as a performance goal for app ads in Meta Ads Manager. |
