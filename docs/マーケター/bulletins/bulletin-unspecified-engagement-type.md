| 更新情報 | `engagement_type` がない、または不一致の場合のレポートを標準化するため、ローデータレポートおよびダッシュボードのデフォルト値として `click_unspecified` または `impression_unspecified` を導入します。 |
| --- | --- |
| 影響 | **コンバージョン：**  <br />発効日以降、`engagement_type` は空白としてレポートされなくなり、タッチタイプ（すなわち、クリックまたはインプレッション）に応じて、`click_unspecified` または`impression_unspecified` がデフォルトとなります。  <br />  <br />**アプリ内イベントとセッションデータ：**  <br />新しい値は、アプリ内イベントと、発効日以降に記録されたコンバージョンイベントに起因するセッションにのみ適用されます。発効日前に記録された転換イベントに起因するものは影響を受けません。 |
| 発効日 | 2024年12月9日 |
