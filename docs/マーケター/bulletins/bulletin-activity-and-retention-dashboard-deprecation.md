| セクション | 詳細 |
| --- | --- |
| **更新情報** | アクティビティおよびリテンションのレガシーダッシュボードは、2025年10月1日以降利用できなくなります。これは、強化された柔軟なセルフサービスのアナリティクスプラットフォームを提供するための継続的な努力の一環で、<Anchor target="_blank" href="/marketers/ja/docs/my-dashboards">マイダッシュボード</Anchor>内に強力な新機能として導入されています。 |
| **発効日** | 2025年10月1日 |
| **更新内容** | <Anchor target="_blank" href="/marketers/ja/docs/my-dashboards">マイダッシュボード</Anchor>を使用して、現在アクティビティまたはリテンションダッシュボードに基づいて保存されているビューまたはレポートを再作成します。<Anchor target="_blank" href="/marketers/ja/docs/my-dashboards">マイダッシュボード</Anchor>は、高度なカスタマイズと可視化のオプションを提供し、インサイトを向上させます。<br /><br />この変更は、より強力で柔軟なアナリティクス体験を提供するための継続的な取り組みの一環です。<Anchor target="_blank" href="/marketers/ja/docs/my-dashboards">マイダッシュボード</Anchor>には、次のような拡張機能が含まれています：<ul><li>カスタマイズ可能なウィジェットのレイアウト</li><li>柔軟なフィルターと保存可能なビュー</li><li>改善されたチャートオプション</li></ul> |
| **必要な対応** | <Anchor target="_blank" href="/marketers/ja/docs/my-dashboards">マイダッシュボード</Anchor>に移動して、パフォーマンスとリテンションの傾向の分析を続けてください。 |
