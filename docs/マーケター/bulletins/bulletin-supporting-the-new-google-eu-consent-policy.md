| <span id="whats-new"></span>**更新情報** | <Anchor target="_blank" href="https://commission.europa.eu/strategy-and-policy/priorities-2019-2024/europe-fit-digital-age/digital-markets-act-ensuring-fair-and-open-digital-markets_en">Digital Marketing Act</Anchor> (DMA) の施行に向けた Googleの準備の一環として、Googleは<Anchor target="_blank" href="https://www.google.com/about/company/user-consent-policy/?sjid=15416941068016224808-NA">EUユーザーの同意ポリシー</Anchor>を更新しています。 AppsFlyerは、Googleの公式App Attribution Partnerとして、広告主がGoogle Adsのマーケティングチャネルから最大限の価値を得られるようにしながら、Googleのポリシー要件をサポートするために必要な変更を加えています。 |
| --- | --- |
| <span id="effective-date"></span>**発効日** | 2024年3月6日 |
| <span id="relevant-integrations-and-audience"></span>**関連する連携とオーディエンス** | Google広告または GMP DV360 (googleadwords\_int、dv360\_int) と連携したアプリで、欧州経済領域 (EEA) に拠点を置くエンドユーザーが存在するすべての広告主様。 |
| <span id="required-actions"></span>**必要なアクション** | Google の要件に準拠するため、広告主様は EEA と英国のユーザーから個人データの使用に関する同意を得て、Google に送信する必要があります。AppsFlyerは、AppsFlyer SDKを使用してGoogleに同意シグナルを送信することで、このプロセスを容易にします。AppsFlyer SDKをアップデートして、コンプライアンスを確保してください。<Anchor target="_blank" href="/marketers/ja/docs/support-google-eu-consent-policy">詳細については、こちらをご覧ください</Anchor>。 |
