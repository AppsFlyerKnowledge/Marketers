> **概要：** 概要：Apple Search Ads (ASA) のコスト連携時に表示されるサインインエラーを解決しましょう。

| **発効日** | 2021年5月5日から |
| --- | --- |
| **エラー** | AppsFlyerの<Anchor target="_blank" href="/marketers/ja/docs/apple-ads-integration-setup#cost-tab">コスト連携</Anchor>のためにApple Search Adsにサインインしようとすると、次のエラーメッセージが表示されることがあります。  <br />  <br /><br />[![](https://files.readme.io/cb6b1d144ff755dec1545110e77d0a3a68aa4d8fe84d832648bf43e1962387f3-360019847618.jpg)](https://files.readme.io/cb6b1d144ff755dec1545110e77d0a3a68aa4d8fe84d832648bf43e1962387f3-360019847618.jpg) |
| **解決策** | <ol><li>開いているブラウザを全て閉じてください。</li><li>AppsFlyer管理画面を再度立ち上げてください。</li><li>Apple Search Adsコスト連携の有効化を再度お試しください。</li></ol> |
