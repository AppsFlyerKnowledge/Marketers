| **新着情報** | アトリビューションされていないセッションとイベントが、コホート管理画面とレポートに含まれた状態で表示されます。 |
| --- | --- |
| **発効日** | 2024年5月26日 |
| **対象：** | <ul><li>コホート＆リテンション管理画面</li><li>コホートAPI</li><li>Data Locker経由のコホートレポート</li><li>Data Locker経由のアドバンス集計レポート [クローズドベータ]</li></ul> |
| **お知らせ事項** | <ul><li>発効日以前は、アトリビューションされていないセッションとイベントはコホート管理画面とレポートに含まれませんでした。これにより、コホートと他のレポート方法との間で矛盾が生じることがあり、コホートではオーガニックセッションとイベント (および収益) が少なく表示されていました。</li><li>発効日以降、アトリビューションされていないセッションとイベントも、コホート管理画面と各種レポートに「オーガニック」メディアソースに紐づいて表示されます。これにより：<ul><li>従来よりもコホートデータにオーガニックデータが多く表示されるようになる可能性があります。</li><li>アトリビューションされていないセッションやイベントによって、コホートと他のレポート方法の間に矛盾が生じることがなくなります。</li></ul></li></ul> |
