| **更新情報** | Push APIに、3つの新しい項目が追加されました。新しいデータ項目：<ul><li>engagement\_type</li><li>イベントタイプ</li><li>store\_product\_page （Androidのみ）</li></ul>**<span id="engagement_type"></span>engagement\_type**<br /><br />このパラメータは、次のような値もしくは空白でレポートされます： preload / click\_to\_download / click\_to\_app / engaged\_click / engaged\_view / view / listening<br /><br />新しいエンゲージメントタイプの詳細については、 <Anchor target="_blank" href="/marketers/ja/docs/bulletin-engagement-types">こちら</Anchor>をご覧ください。<br /><br />**<span id="event_type"></span>イベントタイプ**<br /><br />パラメータには、次のような値が入ります：install, organic-install, install-in-app-event, organic-install-in-app-event, re-engagement, re-engagement-in-app-event, re-attribution, reinstall, organic-reinstall, re-attribution-in-app-event, skad-installs, skad-re-downloads, skad-in-app-events, skad-postbacks, skad-postbacks-copy<br /><br />**<span id="store_product_page"></span>store\_product\_page**<br /><br />このパラメーターは、既存のiOSと同様の値が入ります。<br /><br />詳細は<Anchor target="_blank" href="/marketers/ja/docs/raw-data-field-dictionary#attribution::4c11e393">こちら</Anchor>をご覧ください。<br /><br /><br /><br />**<span id="h_01HHEP7BBXF30VEK3XCSSK9GEE"></span>注意**<br />**custom\_data**項目は、項目名と項目に入る値の間に、コロンを含むように変更されました。 |
