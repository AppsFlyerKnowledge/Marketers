| セクション | 詳細 |
| --- | --- |
| **概要** | AppsFlyerは、TikTokのiOS向けAdvanced Self-Reporting Network（SRN）連携におけるプライバシー設定を更新します。変更内容は以下の通りです：<ul><li>現在の<strong>高プライバシーモード（AP）</strong>のトグルは、新たに<strong>Advanced Data Sharing（ADS）</strong>トグルへ置き換えられます。これにより、TikTokの設定仕様がAppsFlyer内の他のSRN連携と統一されます。</li><li>この変更に伴い、AppsFlyerは広告ID（IDFA）の有無にかかわらず、すべてのコンバージョンイベントをTikTokへ共有するようになります。</li></ul>その結果、より多くのiOSコンバージョンがアトリビューション対象となり、TikTokはより完全なパフォーマンスデータを基にキャンペーンの最適化を行えるようになります。 |
| **適用開始日** | 2026年6月23日 |
| **更新内容** | 設定は自動的に移行されるため、お客様側での対応は不要です。現在の設定と新しいトグルの対応関係は以下の通りです：<ul><li>現在「**高プライバシーモード**」が**オフ**の場合 → 「**Advanced Data Sharing**」が**オン**に設定されます</li><li>現在「**高プライバシーモード**」が**オン**になっている場合 → 「**Advanced Data Sharing**」は**オフ**に設定されます</li></ul> |
