| **新着情報** | コホートレポートの広告収益の算出方法が、LTVレポートと完全に連携します。**これは、UTC以外のタイムゾーン設定を持つお客様にのみに影響します。** |
| --- | --- |
| **発効日** | 2020年8月6日 |
| **対象** | <ul><li>コホートダッシュボード</li><li>コホートAPI</li><li>Data Lockerでのコホート分析</li></ul> |
| **お知らせ事項** | <ul><li>何もする必要はありません。</li><li>UTC以外のタイムゾーンのお客様は、次のエクスペリエンスを期待する必要があります。<ul><li>**UTC+** タイムゾーンのアプリは、Day 0の広告収益が減少し、Day 1の広告収益が急増することが予想されます。</li><li>**UTC-** タイムゾーンのアプリは、Day 0の広告収益が急増し、Day 1の広告収益が減少することが予想されます。</li></ul></li></ul> |
