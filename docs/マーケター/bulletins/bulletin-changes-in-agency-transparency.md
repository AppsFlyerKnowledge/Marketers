| **新着情報** | 業界がより透明性の高いエコシステムに移行する中、AppsFlyerは広告主と代理店の間の透明性を完全にサポートします。<br /><br />2023年8月14日以降、アプリ単位の<Anchor target="_blank" href="/partners/ja/docs/getting-started-agency-onboarding#運用媒体の開示">代理店の運用媒体開示設定</Anchor>の設定はデフォルトで完全にオンになっています。これは、新たに登録される代理店と、新しい広告主のアクセス許可を持つ既存の代理店に関連しています。 |
| --- | --- |
| **発効日** | 2023年8月14日 |
| **変更前** | 広告主のアクセス権限を持つすべての代理店アカウントは、**代理店の運用媒体開示** の切り替えをオンまたはオフにすることができます。 |
| 変更後： | <ul><li>**代理店の運用媒体開示** トグルは、AppsFlyerに参加する新しい代理店と、 広告主からのアクセスに対してアプリレベルのアクセス許可を付与された既存の代理店に対して永続的に有効（オン）になります。</li><li>現在 代理店の運用媒体開示をオフにしている既存の代理店は、オフのままにするかオンにするかを選択できます。ただし、一度オンにすると、永続的にオンのままになります。</li></ul> |
| 例外 | 代理店の運用媒体の透明性はアカウント使用状況レポートではサポートされていません（変更なし） |
| **対象** | 代理店アカウント**AppsFlyer管理画面左メニュー** **設定** > アプリ設定へ移動します。 |
| 必要な対応 | アクションは必要ありません。ただし、運用媒体開示設定をオフにしている代理店は、オンに設定することをお勧めします。 |
