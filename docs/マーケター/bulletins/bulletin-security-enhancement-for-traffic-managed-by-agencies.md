| **変更点** | データを保護し、セキュリティを確保し、不正を減らすために、アドネットワークでキャンペーンを実行している広告主の代わりに、トラフィックを管理する代理店のセキュリティ対策を強化しています。2024年7月14日現在、アドネットワークに認可された代理店からのトラフィックのみが AppsFlyer に記録され、測定されます。<br /><br />**注記：**<ul><li>帰属リンクの空のaf\_prtパラメーターにも適用されます</li><li>SRNを扱う代理店には適用されません。</li></ul> |
| --- | --- |
| **発効日** | 2022年7月27日 |
| **対象** | <ul><li>**代理店：** 統合ページ</li><li>**アドネットワーク：** セキュリティセンター</li></ul> |
| **知っておくべきこと** | <ul><li>**代理店：**</li><li>**パートナー：**</li></ul> |
| **影響** | 指定された日から、アドネットワークの承認リストに載っていない代理店は、トラフィックを記録・測定できなくなり、アドネットワークでキャンペーンを実施しているすべてのアプリの統合ページにアクセスできなくなる。 |
