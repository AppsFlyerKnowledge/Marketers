| **変更内容** | 2026年4月1日より、LTVの集計データ（クリック、インプレッション、インストールを含む）の保存期間は、従来の5年間から25ヶ月間（2年＋1ヶ月）へ変更されます。 |
| --- | --- |
| **適用開始日** | 2026年4月1日 |
| **推奨対応** | 2026年4月1日までに、必要な過去の集計LTVデータは取得してください。 |
| **追加情報** | 本変更は、以下のAppsFlyer製品およびインターフェースにおける集計LTVデータに適用されます：<ul><li>マイダッシュボード</li><li>Protect 360</li><li>SKAN ダッシュボード</li><li>Master API</li><li>Pivot ダッシュボード</li><li>カスタムダッシュボード</li><li>オーバービュー</li><li>集計 Pull API</li><li>アクティビティダッシュボード</li><li>アプリ内イベント ダッシュボード</li><li>AppsFlyer MCP</li></ul>**<span id="what-you-should-know"></span>ご留意事項**<ul><li>集計LTVデータ（クリック、インプレッション、インストールを含む）の提供期間は、<strong>25ヶ月間（2年＋1ヶ月）</strong>に制限されます。</li><li>2026年4月1日以降、過去25ヶ月を超える集計LTVデータにはアクセスできなくなります。</li><li>保存期間を超える集計LTVデータをリクエストするクエリや可視化では、**結果が一部のみ表示される、または空になる場合があります。**</li><li>より古い期間については、コホートデータおよびアクティビティデータが引き続き利用可能な場合があり、その結果、データセット間で差異が生じる可能性があります。</li></ul> |
