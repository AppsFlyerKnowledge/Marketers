| 概要 | AppsFlyerは、拡張（モバイル以外）プラットフォームリターゲティング計測、リエンゲージメント、リアトリビューションをサポートするようになりました。CTV、PC、およびコンソール。以前は、これらのプラットフォームはUAアトリビューションのみをサポートしていました。<br /><br />拡張プラットフォーム向けリターゲティングには、次の 2 つのコンバージョンタイプがあります。<ul><li>**エンゲージメント**は、すでにインストールした既存のユーザーをアプリに戻したキャンペーンにクレジットされます。</li><li>**リアトリビューション（リターゲティング再インストール**）は、離脱したユーザーにアプリを再インストールして再開させるキャンペーンにクレジットを与えます。詳細については、<Anchor target="_blank" href="/marketers/ja/docs/measure-reinstalls#reattribution">リアトリビューションの測定をご覧ください</Anchor>。</li></ul>これにより、ライフサイクルマーケティングを行う広告主にとって大きなギャップが解消されます。ライフサイクルマーケティングでは、ユーザーを再活性化し、リピート消費推進するし、解約を減らすキャンペーンを正しくクレジットするために、リエンゲージメントとリアトリビューションが必要になります。また、コホートとLTVの精度も向上します。以前は、リターゲティングサポートしていなかったため、その後のアプリアクティビティは元のインストール日に固定されていたため、コホート、ペイバック、LTV分析に歪みが生じていました。AppsFlyerが一般的に拡張プラットフォームを測定する方法の背景については、<Anchor target="_blank" href="/marketers/ja/docs/ctv-pc-and-console-platform-attribution-concepts">CTV、PC、およびコンソールプラットフォームのアトリビューション概念を参照してください</Anchor>。 |
| --- | --- |
| 適用時期 | 2019年8月 |
| 対処方法 | 設定レイヤーには、アプリ、メディアソースまたは連携ション、アトリビューションリンク 3つがあります。<ol><li><Anchor target="_blank" href="/marketers/ja/docs/app-settings#アトリビューション設定">アプリの設定で、**エンゲージメントアトリビューションのトグルをオンに切り替えます**</Anchor>。これはアプリのマスタースイッチです。オフの場合、そのアプリのどのメディアソースでもリエンゲージメントを有効にすることはできません。</li><li>リターゲティング実行するしたい各パートナーまたはメディアソースの「**アクティブインテグレーション**」ページの「インテグレーション」タブで、リアトリビューションクレジットを有効にするには「**リインストールアトリビューション**」を、リエンゲージメントクレジットを有効にするにはエンゲージメントゲージメントアトリビューションを有効にします。**ビュースルークレジットも希望する場合はエンゲージメントビュースルーアトリビューションもオンにし**、それ以外の場合はクリックスルーのみオフのままにしておきます。</li><li>SRN以外のネットワークの場合は、`af_campaign_type=retargeting`アトリビューションリンクに追加してください。このパラメーターを自動的に追加するには、アクティブインテグレーションページのアトリビューションリンクタブでリターゲティング設定を有効にするをオンにします。リンク作成フローについては、<Anchor target="_blank" href="/marketers/ja/docs/retargeting-attribution-guide">リターゲティングアトリビューションガイドとCTV</Anchor> <Anchor target="_blank" href="/marketers/ja/docs/ctv-pc-and-console-platform-direct-attribution-links">、PC、コンソールプラットフォームダイレクトアトリビューションリンクを参照してください</Anchor>。このリンクをキャンペーン使用するしてください。</li></ol>**<span id="h_01KX0FSH3GN11MG98MZQAVJ5NC"></span>注意**<br />現在、これらのプラットフォームで利用できる唯一の自己レポートネットワーク（SRN）であるRokuは、リエンゲージメントのみをサポートしています。リアトリビューションサポートされておらず、設定するアトリビューションリンクもありません。Rokuの場合、トグルがオンになっている限り、すべてのクレームがリターゲティングの対象となります。 |
| ご確認いただきたい事項 | 拡張プラットフォームでリターゲティングを測定する際は、次の注意する。<ul><li>サポートされているプラットフォーム拡張プラットフォーム向けリターゲティングは、Android、iOS、Windows Phone、ウェブサイト以外のすべてのプラットフォームに適用されます。実際には、CTV、PC、コンソールアプリなどがこれに該当します。</li><li>**対象範囲**この機能は、モバイル以外のプラットフォーム（CTV、PC、コンソール）のみを対象としています。クロスプラットフォームモバイル向けリターゲティングはサポートされていません。たとえば、モバイルアプリインストールを促すCTV広告はまだサポートされていません。ただし、PCアプリのインストールにつながるウェブ広告はサポートされています。</li><li>**SRN の制限事項:** 現在、これらのプラットフォームで利用できる唯一のSRNであるRokuは、リエンゲージメントのみをサポートしており、再インストールやリアトリビューションはサポートしていません。これは、今後追加される他の SRN には当てはまらない可能性があります。</li><li>**オプションウィンドウ:** リエンゲージメント期間（デフォルトは30日）は、アプリ内イベントが主にリエンゲージメントコンバージョンに起因する期間を決定します。非アクティブ期間（デフォルトは7日間）は、ユーザーがリターゲティングの対象となるために非アクティブでなければならない期間を決定します。これらのウィンドウはモバイルと同じように作業する。<Anchor target="_blank" href="/marketers/ja/docs/set-retargeting-inactivity-window">リターゲティングアトリビューションガイドとリターゲティング非アクティブ設定期間</Anchor>を参照してください。</li><li>**結果が表示される場所:** マイダッシュボードとData Locker の詳細レポートのみ。従来の Data Locker レポートには、新しいリターゲティングローデータレポートはありません。プラットフォーム固有のダッシュボードの動作については、「概要管理画面 — ユーザー獲得リターゲティング LTV」を参照してください。</li></ul> |
