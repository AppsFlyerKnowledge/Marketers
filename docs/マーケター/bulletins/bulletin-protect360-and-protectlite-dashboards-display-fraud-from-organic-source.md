| **新着情報** | Protect360 と ProtectLITE 管理画面にオーガニックの不正を表示 |
| --- | --- |
| **発効日** | 2021年12月20日 |
| **対象** | Protect360と<Anchor target="_blank" href="/marketers/ja/docs/protect360-dashboard">ProtectLITE</Anchor>管理画面 |
| 詳細 | **変更前：**<br /><br />**変更後：** 変更前：オーガニックインストールの不正はProtect360とProtectLITE管理画面にも表示されます。オーガニックのアプリ内イベント不正はサポートされていません。 |
| **お知らせ事項** | <ul><li>特定された不正のトレンドグラフ</li><li>オーガニックトラフィックには関係ありません。</li><li>ハイジャックされたインストール計測の修正グラフこのチャートは、オーガニックへの補正を表示できますが、オーガニックからの補正は表示できません。</li><li>検出した不正の内訳テーブル</li><li>代理店と広告ネットワーク:</li></ul>推奨：推奨事項：オウンドメディアのメディアソース名をオーガニックと名付けないでください。実際のオーガニックデータと混同してしまう恐れがあります。 |
