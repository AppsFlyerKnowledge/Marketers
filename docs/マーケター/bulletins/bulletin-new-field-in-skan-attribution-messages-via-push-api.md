| **更新情報**<br /><br />Information\_icon.png | Push API経由の<Anchor target="_blank" href="/marketers/ja/docs/push-api-streaming-raw-data#skan-attribution-messages">SKANアトリビューションメッセージ</Anchor>で使用可能な新しい項目：<ul><li>af\_attribution\_flag SSOTが有効の場合：true：インストールはAppsFlyerとSKANの両方によってアトリビューションされていることを示します。false：インストールはAppsFyer計測でオーガニックとして計測されていることを示します。nullの場合には、コンバージョン値はnullになります。</li><li>**measurement\_window**</li><li>**interval**</li></ul>デコードされたイベントレポートで使用可能なすべての項目を表示します。 |
