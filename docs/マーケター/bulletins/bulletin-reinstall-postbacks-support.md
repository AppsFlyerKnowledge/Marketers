| セクション | 詳細 |
| --- | --- |
| **更新情報** | **再インストール時のポストバック**が利用可能になりました。初回インストールと区別したうえでポストバックできます。 |
| **発効日** | 2025年1月9日 |
| **知っておくべきこと** | インストールポストバックにおいて、再インストールのポストバックにも対応します。**連携済みパートナー**画面で設定が可能です。<ul><li>**サポートされているネットワーク**現在、特定のパートナーのみ（例：Unity Ads）で利用可能です。追加のパートナーが近日中に追加されます。</li><li>**設定箇所：** 再インストールポストバックは、**デフォルトポストバック**セクションの**アトリビューション**タブに表示されます。サポートされているネットワークでは、再インストールのポストバックも制御します。</li><li>**設定内容：送信オプション**のドロップダウンを**このパートナーのみ**から**オーガニックを含む、すべてのメディアソース**に変更できます。</li><li>**形式：** 再インストールイベントは、インストールイベントと同じポストバック形式を使用し、マクロ `is_reinstall=true` が追加されます。</li><li>**値：** これにより、特にリターゲティングに焦点を当てたアドネットワーク向けに、計測と最適化が改善されます。</li></ul> |
| **必要な対応** | この機能は指定されたパートナーのみが利用できます。アクセスに興味がある場合は、PDMに連絡してください。 |
