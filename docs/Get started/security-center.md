title: "Security Center"
excerpt: "Review and manage the status of all the security-related features of your AppsFlyer account from a single location."
---
The **Security Center** provides you with an at-a-glance overview of your AppsFlyer account's security status. Click the button in any section of the **Security Center** to access the following features:

| Feature | Description |
| --- | --- |
| [User management](https://support.appsflyer.com/hc/articles/207033806) | Create and manage your AppsFlyer users. Assign them permissions to access the features, apps, and data they need. |
| [Redirect allowlist](https://support.appsflyer.com/hc/articles/25068636064529) | Define allowed domains for link redirects. |
| [List of authorized agencies](/docs/set-up-your-list-of-authorized-agencies) (for ad networks) | Manage which agencies you authorize to run campaigns through your network integration. |
| [API allowlist](https://support.appsflyer.com/hc/articles/4406016140817) | Define allowed IP addresses for API requests. |
| Enhanced login security | Configure [single sign-on (SSO)](https://support.appsflyer.com/hc/articles/360015017198) or [two-factor authentication (2FA)](https://support.appsflyer.com/hc/articles/360010178037) to keep your account safe from unauthorized entry. |
| [AppsFlyer tokens](https://support.appsflyer.com/hc/articles/360004562377) | Use AppsFlyer tokens to authenticate your API and S2S calls. Manage the tokens and replace them periodically to ensure maximum security |
| [Audit log](https://support.appsflyer.com/hc/articles/360007971697) | Review account activity to identify unauthorized access: logins, user management actions, and API calls. |

**To access the Security Center:**

- From the top bar, open the account menu (email address dropdown) > **Security center.**
