**At a glance:** The platform contains multiple dashboards. These dashboards enable you to view your campaign performance and app behavior.

## AppsFlyer dashboards

![OverviewBasic.png](https://files.readme.io/58185f6682891435b05110cc9f7ecfa3204226fef526366f4aab9fbda76b2d8c-OverviewBasic.png)

The primary dashboard is the [Overview](https://support.appsflyer.com/hc/articles/360014697157) dashboard. This contains the lifetime value (LTV) performance of user acquisition (UA) and retargeting campaigns.

List of additional [dashboards](https://support.appsflyer.com/hc/sections/6550925337873-Dashboards).
